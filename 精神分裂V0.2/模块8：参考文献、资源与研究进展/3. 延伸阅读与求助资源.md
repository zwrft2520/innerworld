# 延伸阅读与求助资源

> 本页整理可以真正用上的求助渠道、专业机构和靠谱读物。**电话号码和机构信息可能随时间调整，拨打前请通过官方渠道核实最新有效性**；紧急情况先打 120 / 110 / 12356。

## 一、什么时候该求助

出现以下情况，应尽快联系精神科或求助：

- 持续的幻听、妄想，明显影响生活；
- 情绪持续低落、失眠、出现自伤或自杀念头（**有自杀念头或行为：立即求助，不要独自扛**）；
- 既往确诊者，睡眠、情绪、多疑突然改变，疑似复发；
- 患者有伤害他人的危险。

| 资源 | 用途 | 联系方式 |
| --- | --- | --- |
| **全国统一心理援助热线** | 情绪困扰、心理危机、咨询引导（2024年起全国推广） | **12356** |
| **北京心理危机研究与干预中心热线** | 心理危机、自杀干预（老牌专业热线） | **010-82951332**（以官方最新公布为准） |
| **各地精神卫生中心 / 心理援助热线** | 本地咨询、就诊引导 | 可拨打 **12320** 卫生热线查询本地号码 |
| **急救 / 报警** | 自伤、伤人、木僵、严重药物反应等急症 | **120**（急救）/ **110**（危及人身安全） |

## 三、去哪里看病（专业机构）

精神分裂症属于**重性精神疾病**，应到正规精神卫生机构，而不是普通心理咨询室。

- **国家级 / 代表性精神卫生机构**（供了解水平，不必舍近求远）：
  - 北京大学第六医院（北大六院，国家精神心理疾病医学中心）
  - 上海市精神卫生中心（"600号"，国家精神疾病医学中心）
  - 中南大学湘雅二医院精神卫生研究所
  - 广州市惠爱医院（广州市精神卫生中心）
  - 首都医科大学附属北京安定医院
- **本地怎么找**：每个市一般都有一所**市精神卫生中心**（也叫"XX市精神病院"或综合医院精神科）。可通过 **12320**、当地卫健委官网、地图App搜索"精神卫生中心 / 精神科"，选择**公立、有精神科执业资质**的机构。
- **基层网络**：社区卫生服务中心/乡镇卫生院有**精防医生**，负责登记在册严重精神障碍患者的随访和免费服药管理，确诊后可主动联系纳入管理。

## 四、患者与家属组织 / 公益

- **中国残疾人联合会及各地精协（精神残疾人及亲友协会）**：残疾证办理、家属互助、康复资源对接的重要渠道。
- **家属互助小组**：各地精神卫生中心、精协常组织家属支持活动，强烈建议家属参加。
- 民间公益组织（如郁金香、尚善等心理公益类组织）多面向抑郁症/情绪问题为主，精神分裂症患者家属可重点对接**本地精协**；具体组织的活跃度和联系方式请以官方登记信息为准，本资料库不替其背书。

## 五、怎么挑靠谱的科普书、纪录片、网站

**选择标准**：

- 作者是精神科医生、心理学专业人士或权威机构；
- 有正式出版社/正规媒体出品，注明资料来源；
- 语言克制，承认"个体差异、需就医"，不承诺"包好"；
- 不渲染暴力、不猎奇。

**避雷**：自媒体"亲身经历包治""偏方/气功/诵经治愈"类内容；匿名、无出处、无日期的"养生号"文章。

## 六、就医前可以准备什么

- 整理**病史时间线**：什么时候开始不对劲、主要表现、用过什么药、效果和副作用、有没有家族史。
- 带上**既往病历、检查报告、正在吃的药盒**。
- 列出想问医生的问题（如：这个药副作用怎么处理、能不能减量、多久复查）。
- 尽量由一位了解情况的家属陪同。

## 七、紧急情况下的步骤

1. **先保证安全**：移开身边危险物品，远离高处、利器。
2. **判断类型**：自伤/自杀、伤人冲动、木僵拒食、严重药物反应（高热、肌肉僵硬、意识不清）。
3. **立即打电话**：急症拨 **120**；有人身危险拨 **110**；情绪危机/想不开拨 **12356**。
4. **不要**：强行灌药、捆绑、指责、拍摄。
5. 到院后**如实告诉医生**症状、用药和近期变化。
