# 2. 诊断流程

> **核心结论：**精神分裂症的诊断不是"聊几句就开方"，而是一个**多步骤、需结合病史、精神检查、躯体与实验室排查、有时还需随访观察**的临床判断过程。首次就诊未必能立刻确诊，**这是正常且负责任的做法**。诊断权在精神科执业医师。

## 一、就诊科室

- 首选：**精神科**（综合医院精神科/心理科）或**精神卫生中心 / 精神病专科医院**；
- 若起病突然、伴发热、意识混乱、抽搐、头痛、外伤，应先到**急诊内科/神经内科**排除器质性急症，再转精神科；
- 儿童青少年可就诊儿童精神科/儿童心理科。

【临床共识】不要先靠"心理咨询""算命""网络自查"代替精神科评估；急性精神病性发作**不是单纯聊天能解决的**。

## 二、诊断流程概览

| 步骤 | 内容 | 目的 |
|---|---|---|
| 1. 病史采集 | 现病史、既往史、家族史、成长史、物质使用史 | 勾勒症状时间线与高危因素 |
| 2. 精神检查 | 面谈观察外表、言语、思维、感知、情感、自知力 | 直接评估精神症状 |
| 3. 躯体与神经系统检查 | 体格检查、神经科查体 | 寻找器质性线索 |
| 4. 实验室检查 | 血/生化/内分泌/电解质/妊娠/物质筛查等 | 排除代谢、感染、物质等所致 |
| 5. 脑影像 / 脑电图 | 必要时头颅 CT/MRI、脑电图 | 排除脑器质病变，而非"确诊精神分裂症" |
| 6. 鉴别排查 | 逐项排除双相、抑郁伴精神病性、物质、器质性等 | 确定最可能诊断 |
| 7. 随访观察 | 治疗反应、病程演变、复诊 | 修正和确认诊断 |

## 三、各步骤要点

### 1. 病史采集
医生会详细询问：
- **现病史**：症状从什么时候开始、最初表现、如何加重、对生活工作的影响；
- **既往史**：过去是否有类似发作、其他精神疾病、躯体疾病、脑外伤；
- **家族史**：直系亲属有无精神分裂症、双相、抑郁、酗酒、自杀等；
- **成长史 / 发育史**：童年发育、学习成绩、性格、社交；
- **物质使用史**：酒精、大麻、冰毒、可卡因、致幻剂、激素等使用情况；
- **用药史**：正在/曾经服用的药物（包括处方药、保健品）。

【临床共识】**家属提供的旁证非常重要**——患者常因自知力缺失而低估或否认症状，家属描述的"病前 vs 病后变化"是关键线索。

### 2. 精神检查
医生通过面谈观察：
- **外表与行为**：衣着、卫生、动作、合作程度；
- **言语**：速度、量、连贯性（思维形式障碍）；
- **思维内容**：有无妄想、妄想的主题与确信度；
- **感知**：有无幻觉及其类型、内容；
- **情感**：情绪基调、情感协调性；
- **自知力**：是否认识到自己有病、是否愿意治疗。

### 3. 躯体与神经系统检查
寻找能解释精神症状的躯体线索：意识状态、瞳孔、局灶神经体征、脑膜刺激征、甲状腺、心率血压等。**突发意识改变、局灶体征、发热、抽搐**提示器质性病因，需紧急处理。

### 4. 实验室检查（常见项目）
- 血常规、生化（肝肾功能、血糖血脂）、电解质；
- 甲状腺功能；
- 妊娠试验（育龄女性）；
- 物质/毒物筛查；
- 必要时感染相关检查（如梅毒、HIV、病毒学）。

【临床共识】抽血是为了**排除"是别的病导致的精神症状"**，不是为了"在血里找到精神分裂症"。精神分裂症没有特异性验血指标。

### 5. 脑影像与脑电图
- 适用情形：首次发病、起病突然、有神经系统体征、高龄首发、伴意识/认知改变、怀疑肿瘤/卒中/脑炎/癫痫；
- 头颅 CT/MRI、脑电图可排除脑肿瘤、脑梗、脑炎、癫痫、正常压力脑积水等；
- **正常的影像和脑电图不能确诊精神分裂症，异常也不一定排除它**——它们是"排除性检查"。

## 四、为什么首诊未必立刻确诊

- 病程尚短，可能还在"短暂精神病性障碍 / 分裂样障碍"的时间窗内；
- 物质使用、情绪发作、躯体问题需要时间观察和排查；
- 症状可能被镇静药物或住院环境暂时掩盖；
- 诊断是**动态更新**的：随治疗反应和病程演变，可能修正诊断。

【临床共识】**"第一次没确诊"不等于医生没水平或查不出来**，恰恰是谨慎负责的表现。

## 五、附：就诊准备清单（家属可提前记录）

就诊前把以下信息整理好，能大幅提高就诊效率：

1. **症状时间线**：最早从什么时候、什么表现开始，何时加重；
2. **具体表现举例**：患者说了什么、做了什么（尽量原话、原场景）；
3. **功能变化**：病前 vs 病后（成绩/工作、社交、作息、个人卫生）；
4. **睡眠与饮食**：近期睡眠、进食、体重变化；
5. **物质使用**：烟酒、大麻、兴奋剂、其他药物；
6. **情绪与安全**：有无低落、烦躁、自伤/伤人言语或行为；
7. **既往就诊与用药**：病历、处方、药盒、检查报告；
8. **家族史**：亲属精神疾病史；
9. **当前最担心的问题**：想让医生重点判断什么。

> **提示：**带上既往病历、检查报告和正在服用的所有药物（含药盒），比空口描述更可靠。
