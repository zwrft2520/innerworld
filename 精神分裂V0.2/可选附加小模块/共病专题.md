# 共病专题

> 精神分裂症患者的躯体与精神共病**非常常见，却常被忽视**。很多"变懒、没精神、情绪差"背后，可能是抑郁、代谢问题或物质依赖。本页帮你识别信号、知道何时就医。**共病要主动告诉精神科医生，并与全科/内科共管，不要自行加药。**

## 一、为什么共病容易被忽视

【临床共识】

- 阴性症状（淡漠、少动）会掩盖抑郁、躯体不适；
- 患者常因病耻感或认知损害，不主动诉说身体不舒服；
- 抗精神病药本身会带来代谢、锥体外系等问题，容易被当成"病的一部分"；
- 患者平均预期寿命低于普通人群，**主要死于心血管、代谢等躯体疾病**，而不是精神疾病本身。

因此，主动筛查共病、定期体检，和治精神病性症状同样重要。

## 二、抑郁（最常见也最危险的共病之一）

- **识别信号**：持续情绪低落、兴趣减退、自责、睡眠食欲改变、乏力；**尤其要警惕自伤自杀念头**。
- **与阴性症状鉴别**：阴性症状是"淡漠、没欲望"；抑郁是"难受、痛苦、有想死的念头"。患者能说出"我不开心、不想活"，更像抑郁。
- **风险**：抑郁叠加是精神分裂症患者**自杀风险最高的时期之一**。
- **就医提示**：只要出现消极念头、情绪急剧低落，**立即告诉医生**，不要等下次复诊。

## 三、焦虑障碍与强迫

- 表现：持续紧张、担心、惊恐发作、反复检查/清洗等强迫行为，可与精神病性症状并存。
- 处理：与精神科医生讨论是否需要合并抗焦虑/抗抑郁治疗；**不自行买药**。

## 四、物质使用障碍（酒精、冰毒等兴奋剂、大麻）

- **双向影响**：酒精、冰毒等兴奋剂、大麻既可能诱发或加重精神病性症状，也可能在患者中被用来"自我缓解"副作用或情绪；**大麻是发病的明确危险因素**。
- **表现**：饮酒/吸毒量逐渐加大、戒断时手抖出汗烦躁、瞒着家人。
- **就医提示**：物质滥用会让治疗变得复杂，**一定要告诉精神科医生**；戒断需专业指导，自行硬扛有风险。

## 五、烟草依赖

- 【研究结论】精神分裂症患者吸烟率**远高于普通人群**。
- 危害：吸烟不仅损害心肺，还会**诱导肝酶、影响抗精神病药代谢**（可能影响血药浓度和剂量需求），并加重心血管病。
- 支持：可向医生寻求戒烟帮助（行为干预、戒烟药物），不要突然大幅自行减量导致血药浓度波动。

## 六、代谢综合征与高血脂、高血糖（抗精神病药相关，重点）

【临床共识/中国专家共识2020】部分第二代抗精神病药（如氯氮平、奥氮平等）容易引起体重增加、血糖升高、血脂异常，即**代谢综合征**。

**诊断参考阈值（中国人群标准，满足3项及以上）**：

| 指标 | 异常阈值 |
| --- | --- |
| 腰围（中心性肥胖） | 男 ≥ 90 cm，女 ≥ 85 cm |
| 血压 | ≥ 130 / 85 mmHg 或已知高血压 |
| 甘油三酯（TG） | ≥ 1.7 mmol/L |
| 高密度脂蛋白（HDL-C） | 男 < 1.0 mmol/L / 女 < 1.3 mmol/L |
| 空腹血糖 | ≥ 6.1 mmol/L 或已知糖尿病/糖代谢异常 |

**监测频率建议**：用药前及换药时查基线（体重、腰围、血压、空腹血糖、血脂）；治疗初期体重变化快，建议**每周称体重**；血糖血脂在用药后数周–数月复查，稳定后定期（如每3–6个月）复查。

**处理**：生活方式干预（控制饮食、规律运动、减重）是基础；明显异常时由**精神科 + 内分泌/内科共管**，必要时调药或加用降糖/调脂药。

## 七、体重增加与肥胖

- 识别：短期内体重快速上升、衣服变紧。
- 应对：控制高糖高脂饮食、规律运动；体重增加明显时告诉医生评估是否换药。**不要用节食或减肥药自行处理。**

## 八、心血管疾病与糖尿病

- 患者心血管病、糖尿病风险高于常人（代谢问题 + 吸烟 + 久坐）。
- 定期监测血压、血糖、血脂；出现胸闷、胸痛、多饮多尿、视物模糊等，及时到内科就诊。

## 九、睡眠障碍与睡眠呼吸暂停

- 入睡困难、早醒既可能是**复发预警信号**（睡眠变差常先于症状出现），也可能是抑郁、药物副作用。
- 肥胖、打鼾严重、白天嗜睡者，要警惕**阻塞性睡眠呼吸暂停**，它又会加重代谢问题和日间功能，必要时到睡眠门诊评估。

## 十、乙肝、结核等传染病

- 患者群体中结核、乙肝等感染率相对偏高（居住拥挤、卫生条件、物质使用等因素）。
- 常规体检建议包含肝功能、乙肝、结核筛查；用药（尤其氯氮平等）需监测肝功能和血常规。

## 十一、口腔问题

- 抗精神病药可致**口干**，加上口腔卫生疏于维护，龋齿、牙周病较多见；部分药还有流涎。
- 日常：多喝水、保持口腔清洁、定期牙科检查。

## 十二、共病筛查总表（识别信号 → 筛查/监测 → 何时就医）

| 共病 | 识别信号 | 筛查/监测 | 何时就医（红线） |
| --- | --- | --- | --- |
| 抑郁 | 情绪低落、自责、消极 | 每次复诊询问情绪与自杀念头 | **出现自伤/自杀念头立即就医** |
| 焦虑/强迫 | 紧张、惊恐、反复行为 | 症状评估 | 明显影响生活时告知医生 |
| 物质使用 | 饮酒/吸毒加重、戒断反应 | 询问并观察 | 主动告知，专业戒断 |
| 烟草依赖 | 大量吸烟 | 询问吸烟量 | 想戒烟时找医生协助 |
| 代谢综合征 | 发胖、腰围变大 | 体重/腰围/血压/血糖/血脂按上表 | 血糖血脂明显异常→内科共管 |
| 肥胖 | 体重快速增加 | 每周称体重 | 短期暴涨时评估换药 |
| 心血管病/糖尿病 | 胸闷、多饮多尿 | 定期血压血糖 | 胸痛、持续高血糖→急诊/内科 |
| 睡眠障碍/呼吸暂停 | 失眠、打鼾、嗜睡 | 睡眠观察 | 失眠伴情绪剧变（疑复发）/严重打鼾嗜睡 |
| 乙肝/结核 | 乏力、纳差 | 肝功、乙肝、结核筛查 | 用药期定期查肝功血常规 |
| 口腔问题 | 口干、牙痛 | 定期口腔检查 | 明显龋齿/牙龈问题就诊 |

> **核心提醒**：把"身体不舒服"和"情绪变化"都当成需要告诉医生的信息。精神分裂症不是只治脑子——**身心共管，才是真正的康复。**
