# 照护手册

> 本手册为家属日常照护的**实操工具**，可直接打印使用。所有涉及诊断、用药、调量的内容，一律以精神科医生意见为准；**严禁自行给患者增减、停用药物**，漏服如何补服必须问医生。出现急症先保证安全、再打急救电话。

## 一、日常沟通总原则

- 共情情绪，不争辩妄想结论；低声、慢速、一次一件事。
- 不和患者"较劲"、不翻旧账、不当众数落。
- 先处理情绪，再处理事情；激越时不沟通，先稳定下来。

## 二、分场景话术

| 场景 | 可以这样说 | 避免这样说 |
| --- | --- | --- |
| 谈妄想/幻听 | "我听到你这么说，你一定很难受。先喝口水，我们慢慢说。" | "根本没这回事！你又胡想。" |
| 拒绝服药 | "你是担心药不舒服吗？我们记下来，下次问医生能不能调。" | "不吃就别想出门、你怎么这么不懂事。" |
| 不愿复诊 | "就去开个药、让医生看看你最近睡得好不好。" | "你不看医生就完了！" |
| 情绪激动 | （降低音量）"我在这儿，你先深呼吸，不着急。" | （对吼）"你还敢发火？！" |
| 整日卧床 | "要不要一起下楼走十分钟？就我们俩。" | "你就是烂泥扶不上墙。" |
| 指责家人 | "我听到你的委屈了，我们一件一件说。" | "我们为你付出这么多，你还不知足？" |

## 三、服药管理实操

1. **药盒**：买一周分装的分格药盒（早/中/晚/睡前），由固定的人每周分装一次。
2. **提醒**：手机/闹钟设固定时间，把服药和固定动作绑定（早饭后、睡前刷牙后）。
3. **记录**：用一张表每天打勾，记清哪天吃了、哪天没吃、有没有不舒服。
4. **漏服处理原则**：**不要自行补双倍**。漏服一次怎么办、要不要补，**提前问清主治医生并写下来**，出现漏服按医嘱办；拿不准就联系医生或药师。
5. **副作用观察记录**：复诊时告诉医生——嗜睡/手抖/僵硬、体重变化、泌乳素相关（女性月经异常、男性乳房胀痛）、心慌、坐立不安、口干便秘等。

## 四、复诊/就诊陪同清单

**带什么资料：**

- 既往病历、诊断证明、出院小结；
- 正在吃的**所有药盒**（包括自服的保健品、中成药）；
- 副作用记录表、服药打勾表；
- 近期睡眠、饮食、情绪的简要观察。

**要告诉医生什么：**

- 症状变化（幻听/妄想是减轻还是加重，有没有新症状）；
- 睡眠、情绪、有无消极念头；
- 药物副作用和依从性（有没有漏服、自行停药）；
- 生活事件（工作、家庭变化、是否饮酒/吸毒）。

**要问医生什么：**

- 目前诊断和治疗阶段（急性/巩固/维持）；
- 这个药常见副作用、多久复查一次；
- 出现哪些情况要提前复诊；
- 能否减量/停药的判断标准（**由医生决定，不自行决定**）。

## 五、危机应急清单（识别信号 → 立即怎么做 → 联系谁）

| 危机类型 | 识别信号 | 立即怎么做 | 联系谁 |
| --- | --- | --- | --- |
| **自伤/自杀** | 流露消极言语、安排后事、收藏药物/利器、突然"交代" | 移开危险物品，有人陪伴不离开，**不要说教** | **120** 急救 / **12356** 热线 / 主治医生 |
| **伤人冲动** | 激越、挥拳、拿武器、被命令性幻听驱使 | 保持距离、保证自身安全，疏散旁人，**不要独自上前抢夺** | **110** / **120** |
| **木僵/拒食** | 不动、不语、不进食饮水、长时间保持一个姿势 | 不要强行喂食，注意保暖，尽快送医 | **120** |
| **严重药物反应（警惕恶性综合征 NMS）** | **高热 + 肌肉强直僵硬 + 意识改变**（三联征），可伴大汗、心率快 | 立即停药并送急诊，告诉医生正在用抗精神病药 | **120**（急诊） |
| **命令性幻听** | 听到声音命令他做危险的事、并准备执行 | 陪伴、转移注意力、评估具体指令 | **120** / 主治医生 |
| **走失** | 突然离家、不认路、行为混乱 | 立即寻找并报警，通知社区精防医生 | **110** / 社区精防医生 |

> 红线记住：**高热+僵硬+意识不清**是可能危及生命的药物急症，必须立刻急诊。

## 七、家庭环境安全自查

- 收好刀具、药品、绳索、高处可攀爬物；阳台/窗户有防护。
- 药物**由家属保管、按天分发**，不一次性把大量药交给患者自行保管（尤其有消极念头时）。
- 家中减少囤积白酒、毒品；吸烟患者注意防火。
- 保持作息规律、环境安静，减少强光、噪音、频繁访客等刺激。

## 八、家属自我关怀与喘息

- 你不是24小时看护机器：保留自己的睡眠、工作、社交和就医。
- 学会**喘息**：用社区短期托养、康复站、家属轮班，让自己定期休息。
- 参加**家属互助小组**，和同类家庭交流，比独自硬扛轻松得多。
- 家属自己出现持续失眠、情绪低落时，也要就医——照护者垮了，患者更难。
