# 3.1 阳性症状

> **核心结论：**"阳性症状"指相对于常人状态**新增、增多或被强化**的异常体验（如听到声音、坚信被人害），不是"病情好转"，也不代表"性格外向"。这类症状通常对第二代抗精神病药反应相对较好。本页仅作科普理解，**不能用于自我诊断，也不能据此自行用药**；诊断与治疗方案只能由精神科执业医师判断。

## 一、什么是阳性症状

在精神分裂症的症状体系中，"阳性（positive）"是相对于"阴性（negative，能力减退）"而言的分类术语，指在正常功能之上**多出来**的精神病性体验。它主要包括三类：

1. **幻觉**——无现实刺激时的虚假感知；
2. **妄想**——难以被事实说服的病理性坚信；
3. **思维形式与行为紊乱**——言语、思维组织及外显行为的异常。

此外，紧张症（catatonia）相关的精神运动异常也常被归入阳性/精神病性症状谱。【临床共识】阳性症状往往是急性发作期最显眼、最容易被家属和外人察觉的部分，也是患者初次就诊最常见的原因。

## 二、幻觉（Hallucinations）

幻觉是在没有相应外界刺激时出现的、对当事人而言"像真的一样"的感知体验。需要注意：疲劳、睡眠剥夺、高热、严重抑郁、谵妄、物质使用等也可能引起一过性幻觉，**出现幻觉不等于就是精神分裂症**。

### 1. 幻听（Auditory hallucinations）——最常见
- 患者听到声音，而周围实际无人说话。声音可能来自窗外、隔壁、体内或"脑子里"。
- **评论性幻听**：声音在评论患者的行为或思想（如"他现在在喝水……他做错了"）。
- **命令性幻听**：声音命令患者做某事，这是**需要重点警惕**的类型——命令可能指向自伤、伤人或拒绝进食等，若存在应尽快告知医生并评估安全风险。
- 还可能出现：争论性幻听（两个声音对骂）、思维鸣响（"思维回响"，自己的想法被大声说出来）。

### 2. 其他类型幻觉
| 幻觉类型 | 表现 | 备注 |
|---|---|---|
| 幻视 | 看到人影、面孔、闪光、场景 | 相对少见；突发鲜明幻视更要警惕器质性病因（谵妄、脑病） |
| 幻嗅 | 闻到不存在的气味（异味、焦味） | 可与妄想结合；颞叶病变可出现类似表现 |
| 幻味 | 尝到食物/水中有特殊味道 | 常与被害妄想合并，导致拒食 |
| 幻触 | 感到皮肤有电流、被触摸、虫爬 | 可卡因等物质所致者也常见 |
| 本体/内脏性幻觉 | 感到体内脏器被扭曲、抽取、放入异物 | 常与"被控制感"妄想相联系 |

【临床共识】医生评估幻觉时关注：出现频率、清晰度、内容、患者对其的态度（是害怕、还是坚信不疑）、对生活和安全的影响。

## 三、妄想（Delusions）

妄想是一种**病理性的坚信**，内容与事实和当事人的文化、教育背景不符，且**难以通过摆事实、讲道理说服**。以下是常见主题（描述的是"主题"，不是凭一句话就下诊断）：

| 妄想类型 | 典型表现 |
|---|---|
| 被害妄想 | 坚信被跟踪、监视、投毒、陷害、迫害 |
| 关系妄想 | 把电视新闻、路人谈话、广告都理解成"专门针对自己" |
| 夸大妄想 | 坚信自己有非凡身份、能力、财富或特殊使命 |
| 钟情妄想 | 坚信某人（常为地位较高者）深爱自己，缺乏证据仍不醒悟 |
| 嫉妒妄想 | 无依据地坚信配偶/恋人不忠，反复追查、监视 |
| 疑病妄想 | 坚信自己得了某种重病/内脏烂掉，反复检查阴性仍不相信 |
| 被控制感 | 感到自己的思想、情感、行为被外力（电波、仪器、他人）控制 |
| 思维被洞悉 | 感到自己的想法被广播出去、人人皆知 |
| 思维插入/思维撤走 | 感到有思想被"插入"自己头脑，或自己的思想被外力"抽走" |

【研究结论】"影响、被动、控制体验"（experiences of influence, passivity, control）在 ICD-11 中被列为精神分裂症的**核心特征性症状**，对诊断的指向性较强。

## 四、思维形式与言语紊乱

- **思维破裂/思维松弛**：谈话主题在句子之间毫无逻辑地跳跃，听者无法理解其联系，严重时语词之间完全断裂（"语杂拌"）。
- **思维散漫**：说话绕圈子、答非所问，越说越远离主题，难以回到正题。
- **思维奔逸**：话题随音联、意联快速转换（更常见于躁狂发作，需注意鉴别）。
- **语词新作（neologism）**：自造文字或符号并赋予特殊含义。

【临床共识】判断思维形式障碍时，需先排除语言差异、文化背景、智力发育水平、急性谵妄等因素。

## 五、行为紊乱

- 衣着反常（反季节穿衣、穿着怪异、当众脱衣）；
- 当众做出无目的、不可理解的动作或仪式性行为；
- 情绪反应不协调、冲动、摔东西、无目的来回走动。
- 行为紊乱的患者可能丧失基本自我照料能力（洗漱、进食、如厕）。

## 六、紧张症表现（Catatonia）

紧张症是一组精神运动功能的显著紊乱，**并非精神分裂症所独有**（也可见于心境障碍、器质性脑病）：

- **木僵**：动作、言语显著减少，长时间保持固定姿势；
- **蜡样屈曲**：肢体被任意摆放后像蜡一样维持在不适位置（"空气枕头"）；
- **违拗**：对指令无动于衷，或做出相反动作；
- **缄默**：完全不说话；
- **紧张性兴奋**：突然出现无目的、猛烈的躁动。

【临床共识】出现木僵、拒食、无法饮水、意识状态改变时属于需要尽快医学处理的情况。

## 七、阳性症状的治疗反应与家属观察要点

- **药物反应**：【临床共识】总体而言，幻觉、妄想等阳性症状对抗精神病药（尤其第二代/非典型抗精神病药）的反应相对较好，多数患者在规范治疗后数周内明显减轻。但个体差异大，不能承诺"一定见效"。
- **家属观察要点（供就诊时向医生描述）：**
  1. 首次出现异常表现的时间、持续多久、是持续还是间歇；
  2. 具体听到/看到/相信什么，能不能举例；
  3. 症状对睡眠、饮食、上班/上学、人际的影响；
  4. 是否有命令性声音、自伤或伤人言语或行为——**这一点务必主动告知**；
  5. 发病前后的物质使用（烟酒、大麻、兴奋剂等）；
  6. 症状变化与天气、压力、漏药、睡眠的关系。

> **安全红线：**若患者出现明确的自伤、伤人意图或行为、拒食拒水、突然意识混乱，或命令性幻听驱使行动，应立即联系主治医生或拨打急救/精神科急诊，不要争辩妄想内容，也不要自行约束或给药。
