# 3.4 情绪相关表现

> **核心结论：**精神分裂症不只是"幻觉妄想"，抑郁、焦虑、易激惹等情绪问题在病程各阶段都很常见，并且与**自杀风险**密切相关。情绪症状的来源很多——疾病本身、药物副作用、心理应激、病耻感、物质使用都可能。**不要自行判断"是心病还是药的问题"，应告知医生综合评估。**

## 一、为什么要重视情绪症状

【研究结论】抑郁和焦虑在精神分裂症患者中的发生率显著高于普通人群，且贯穿前驱期、急性发作期、巩固期和康复期。情绪问题往往比精神病性症状更早被患者本人察觉，也是**服药依从性差、社交退缩、生活质量下降**的重要原因，更是自杀风险评估中必须重点关注的线索。

## 二、主要情绪表现

### 1. 抑郁
- 情绪低落、兴趣减退、疲乏、睡眠和食欲改变、自责、无望感；
- 可出现在：前驱期（发病前）、急性发作期（与妄想并存）、发作后（"病耻感+功能受损"所致）、维持期；
- 【研究结论】精神分裂症患者终生自杀风险显著高于一般人群，**合并抑郁是最强的预警因素之一**。

### 2. 焦虑
- 社交焦虑（害怕与人接触）、广泛性焦虑（持续紧张、多思多虑）、惊恐发作；
- 常与被害妄想、幻听、病耻感叠加，使患者更加回避外出和社交。

### 3. 易激惹 / 情绪不稳
- 小事就发脾气、烦躁、冲动、情绪快速波动；
- 可能与阳性症状、睡眠差、药物副作用、应激有关。

### 4. 敌对与愤怒
- 对家人、医护人员充满敌意、抱怨、甚至出现攻击言语；
- 需区分：是妄想（如坚信被家人迫害）驱动，还是情绪调节能力下降、或药物/物质所致。

## 三、如何区分情绪症状的来源

这是临床最常见、也最容易误判的环节。同一种"烦躁、低落"，可能来自完全不同的原因：

| 可能来源 | 典型线索 | 处理方向 |
|---|---|---|
| **疾病本身（抑郁/焦虑共病）** | 情绪低落、兴趣下降、自责早醒，与精神病性症状并存 | 评估后由医生考虑抗抑郁/抗焦虑治疗 |
| **药物副作用** | 尤其是**静坐不能（akathisia）**：内心烦躁、坐立不安、来回踱步，常在加药后出现 | 复诊告知医生，调整药物剂量/种类 |
| **心理应激 / 病耻感** | 知道自己患病后自卑、回避、被歧视后的委屈 | 心理支持、家庭干预、康复教育 |
| **物质使用** | 烟酒、大麻、兴奋剂、镇静药滥用后情绪波动 | 物质评估与戒断干预 |
| **躯体因素** | 感染、疼痛、睡眠剥夺、甲状腺异常等 | 相应检查与处理 |

【临床共识】**静坐不能常被患者和家属误认为"脾气变坏"或"病情加重"**，其实是药物的锥体外系反应之一，及时调整可明显改善。出现"怎么坐都不舒服、总想走动、心里发慌"时，要主动告诉医生。

## 四、情绪症状与阴性症状的鉴别

两者表面都可能"话少、不开心、不出门"，但处理不同：

| 维度 | 抑郁（情绪症状） | 阴性症状 |
|---|---|---|
| 主观体验 | 患者能感受到低落、痛苦，常主诉"我不开心" | 患者往往平淡、不觉得有问题，主诉少 |
| 时间特点 | 可阵发性加重，早晚可有波动 | 相对持续、稳定 |
| 对活动的态度 | 想做但做不到、自责 | 缺乏想做的愿望 |
| 典型伴随 | 早醒、食欲体重下降、消极观念 | 情感迟钝、意志减退、卫生退化 |

【临床共识】区分二者很重要：抑郁需要抗抑郁治疗和心理支持；阴性症状则以康复训练、环境干预为主。把抑郁当成阴性症状"硬扛"，可能错失干预、增加自杀风险。

## 五、何时必须尽快就医（情绪红线）

出现以下任何情况，应尽快联系主治医生或精神科急诊：

1. **流露消极言语**："活着没意思""我是累赘""不如死了算了"；
2. **安排后事、突然把珍爱物品送人、写遗书**；
3. **反复自伤行为**或出现具体的自杀计划；
4. 抑郁突然加重、彻夜不眠、拒绝进食；
5. 出现命令性幻听驱使自伤或伤人；
6. 情绪烦躁到无法静坐、冲动、有攻击倾向。

> **家属须知：**不要回避和患者谈论"你是不是不想活了"——直接、平静地询问**不会诱发**自杀，反而能让患者感到被理解、并争取到干预时机。同时把药物、利器、危险物品妥善收好，并尽快就医。

## 六、应对原则

- 情绪问题要**主动向医生报告**，不要觉得"这是自己的性格问题、不好意思说"；
- 记录情绪波动与服药、睡眠、事件的关系，供医生判断；
- 规律作息、适度活动、避免酒精和大麻；
- 家庭多倾听、少评判，减少病耻感。
