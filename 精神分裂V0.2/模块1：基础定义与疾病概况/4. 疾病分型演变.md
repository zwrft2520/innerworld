# 4. 疾病分型演变

> **核心结论：**精神分裂症过去按"主要症状"被划分为偏执型、青春型、紧张型等几个经典亚型；但 DSM-5（2013）和 ICD-11（2018）先后**取消了这种传统亚型划分**，因为研究发现亚型之间界限模糊、稳定性差、对治疗和预后的指导价值有限。现代临床改为用"症状维度 + 病程描述 + 严重程度标注"来刻画患者。

## 4.1 旧版分类中的传统亚型

【临床共识】在 ICD-10（1990）和 DSM-IV（1994）时代，教科书和病历常用以下亚型。它们至今仍能在旧文献、老病历和部分医生的口头描述中听到：

| 传统亚型 | 主要特征 | 大致预后倾向 |
| --- | --- | --- |
| **偏执型（Paranoid type）** | 以妄想和幻觉为主，妄想内容常为被害、关系、嫉妒、夸大；思维形式和情感相对保留；起病较晚 | 相对较好，是最常见的亚型 |
| **青春型 / 紊乱型（Hebephrenic / Disorganized type）** | 思维破裂、言语杂乱、情感肤浅或不协调、行为幼稚愚蠢；起病多在青少年期 | 相对较差 |
| **紧张型（Catatonic type）** | 以动作行为异常为突出表现：可以是木僵（长时间不动、不言不语）、蜡样屈曲，也可以是兴奋躁动、刻板动作、模仿言语 | 波动大，部分可急性缓解 |
| **单纯型（Simple type / Simple schizophrenia）** | 缓慢起病、逐渐出现孤僻、懒散、社交退缩，**没有明显的幻觉妄想**，容易被当成"懒""不上进" | 起病隐袭、发现晚、预后较差 |
| **未分化型（Undifferentiated type）** | 同时具备多型症状、无法归入上述任何一型 | 视具体症状组合而定 |
| **残留型（Residual type）** | 急性阳性症状缓解后，仍持续有轻度阴性症状或不典型妄想/幻觉 | 描述的是病程阶段，而非独立疾病 |

【临床共识】需要强调：这些亚型描述的是**某个时间点上的症状组合**，不是贴上去就一辈子不变的标签。

## 4.2 为什么 DSM-5 和 ICD-11 取消了传统亚型

【研究结论】过去 20 多年的临床随访研究发现，传统亚型存在几个根本问题：

1. **亚型之间边界模糊、重叠严重**：很多患者既像偏执型又带紊乱型表现，医生之间一致性（诊断一致性 κ 值）不高。
2. **纵向稳定性差**：同一个患者，今年诊断"偏执型"，明年症状变化后可能变成"未分化型"，几年后又成"残留型"——亚型随时间漂移，不像一个稳定的"疾病实体"。
3. **治疗指导价值有限**：不同亚型对同一种抗精神病药的反应并没有显著差别，按亚型选药的依据不足。
4. **"单纯型"等亚型的诊断标准可靠性差**，容易把抑郁症、人格障碍、孤独谱系障碍等误纳进来。

【临床共识】基于以上证据，**DSM-5（2013）正式删除了偏执型、青春型、紧张型、未分化型、残留型等传统亚型的正式编码**；ICD-11（2018）也采取了类似立场，不再把这些亚型作为独立分类。

## 4.3 现代分类如何描述患者：维度 + 病程 + 标注符

【临床共识】取而代之的，是一种更"立体"的描述方式：

- **按症状维度评分**：分别评估阳性症状、阴性症状、认知损害、抑郁/躁狂等心境症状、攻击敌意等，而不是给患者贴一个单一"型"的标签。
- **按病程描述**：首次发作、发作期 / 部分缓解 / 完全缓解；发作次数（单次发作、反复发作、持续状态等）。ICD-11 明确允许在 6A20 诊断后附加这些病程标注。
- **严重程度标注**：用轻度、中度、重度，或用量表（如 PANSS）量化。
- **标注符（Specifiers）**：用于提示有临床意义的特殊特征，例如"伴紧张症""伴焦虑""伴抑郁"等。

## 4.4 紧张症（Catatonia）的新处理

【研究结论】紧张症是一个比较特殊的概念。在传统分类里它是精神分裂症的一个亚型；现代观点则认为：

- 紧张症**不是精神分裂症独有**——它可以出现在重度抑郁、双相情感障碍、神经系统疾病、药物/物质反应中；
- 因此 **DSM-5 不再把紧张症作为精神分裂症的一个亚型，而是作为一个"标注符"**：可以附加在精神分裂症、双相障碍、重性抑郁障碍等多种诊断之后，写作"伴紧张症"；
- 治疗上，紧张症对苯二氮䓬类药物和 MECT（无抽搐电休克）反应常较好，识别它本身有治疗学意义。

【临床共识】这一调整的精神是：**先识别临床现象（紧张症），再判断它出现在哪种疾病背景下**，而不是反过来说"紧张症 = 精神分裂症的一型"。

## 4.5 临床实际中如何"描述"一位患者

【临床共识】既然不再有"型"，医生在病历里通常这样描述一位患者，更准确也更有用：

> "患者为首次发作，目前处于急性期，以妄想（被跟踪、被监视）和评论性幻听为主要表现，伴轻度情感淡漠和社交退缩，无明显冲动伤人行为；PANSS 评分示阳性症状重度、阴性症状中度；病程约 3 个月，既往无类似发作。"

这种描述方式包含了：**病程阶段 + 主导症状 + 严重程度 + 安全风险 + 既往史**，比单纯一句"偏执型精神分裂症"信息量大得多，也更能指导治疗。

## 4.6 给读者的提示

- 老病历、老文献里看到"偏执型""青春型"不必紧张，那是旧时代的语言；
- 听到医生不再说"你是哪一型"，不是"没诊断清楚"，而是现代分类本来就不这么分了；
- 关心的重点应该从"我是哪一型"转向"**我现在的症状维度有哪些、严重到什么程度、下一步治疗目标是什么**"。
