# 3. 长期康复管理

> **核心结论：精神分裂症是需要"全病程长期管理"的慢性疾病，稳定期不等于"可以不管了"。** 康复的成败，往往不取决于急性期治得有多猛，而取决于出院后这几年：规律复诊、坚持服药、管好睡眠与躯体健康、远离酒与毒品。把日常管理做成习惯，比任何一次"抢救式治疗"都重要。

## 一、全病程长期管理理念

【临床共识】

- 精神分裂症的管理是**长期工程**，目标是"预防复发 + 维持功能 + 提高生活质量"，而不是"症状没了就结束"。
- 稳定期停药/停随访是复发最常见的诱因；**越是自我感觉良好，越要守住规律复诊**。
- 管理需要"医疗 + 生活方式 + 社会支持 + 患者自我管理"四条腿走路。

## 二、规律复诊（稳定期也要复诊）

- **稳定期为什么还要复诊**：医生要评估疗效是否仍足够、副作用是否在悄悄累积（体重、血糖、泌乳素、运动症状）、是否有复发苗头、药物是否需要微调。很多问题在复诊时一句话就能解决，拖到复发代价巨大。
- **复诊时谈什么**：
  - 最近睡眠、情绪、社交、工作学习状态；
  - 有没有出现预警信号（见 2. 复发预警信号）；
  - 服药是否规律、有没有漏服或不适；
  - 体重、血糖、血压等躯体指标；
  - 对就业、复学、家庭关系的现实困扰。
- **建议做法**：固定一位主治医生/一家医院，建立连续病历；复诊间隔由医生根据稳定程度决定，稳定后可拉长，但不建议自行取消。

## 三、药物依从性管理

【研究结论】坚持规范服药是降低复发最关键的可干预因素。但**漏服、藏药非常普遍**，不是"患者意志力差"，需要系统性对策：

**常见漏服原因与对策**：
| 漏服原因 | 对策 |
|---|---|
| 忘记吃 | 闹钟/手机提醒、药盒分格、与固定日常动作绑定（如刷牙后） |
| "我好了，不用吃了" | 与医生明确"维持期为什么还要吃"，理解复发代价 |
| 副作用难受、不敢说 | **尽早告诉医生调药**，而不是自行停药 |
| 嫌麻烦、天天吃药 | 与医生讨论**长效针剂**是否适合（见 5.1） |
| 经济/配药不便 | 了解医保、长处方、社区取药，提前备药 |
| 藏药、抗拒 | 动机访谈式沟通，避免当面搜查激化对抗 |

- **漏服了怎么办**：按医生/说明书指引处理，**不要下次加倍补吃**；连续漏服或出现不适，及时联系医生。
- **副作用要早沟通**："有点胖了""月经乱了""坐不住""白天困"——这些都可以和医生商量调整，不必忍到自行停药。

## 四、规律作息与睡眠

- **睡眠是复发的晴雨表**：长期熬夜、作息紊乱会显著增加复发风险。【临床共识】
- 建议：固定起床和睡觉时间、白天适度活动、减少睡前手机和咖啡因、白天多见自然光。
- 出现持续失眠，不要自行长期吃安眠药，应复诊（安眠药有依赖风险，由医生评估）。

## 五、戒酒、戒毒品、限制大麻

【研究结论】【临床共识】

- **酒精、大麻、其他毒品是明确的复发诱发因素**，会与药物相互作用、加重精神病性症状、显著升高复发和暴力风险。
- 尤其**大麻**：被多项研究认定为精神病性障碍的明确高危因素，应完全避免。
- 已形成依赖者，应在复诊时告知医生，一并治疗物质共病，而不是"先戒一阵再说"。

## 六、饮食、体重与代谢管理、运动

- 抗精神病药（尤其奥氮平、氯氮平、利培酮类）易致**体重增加、血糖血脂异常**，长期增加糖尿病、心血管病风险。【研究结论】
- 日常管理：控制高糖高油高盐、规律三餐、少含糖饮料；**每周规律有氧运动**（快走、慢跑、骑车等）。
- 定期监测体重、腰围、血糖、血脂、血压（与 5.1 监测表对应）；发现指标异常尽早和医生、营养师商量。

## 七、压力管理与放松

- 过大压力、重大生活事件是复发诱因。学习识别压力信号、练习放松（呼吸训练、正念、规律运动、兴趣爱好）有帮助。
- 避免在康复初期一次性叠加太多"大目标"（同时换工作、搬家、恋爱），给生活留出稳定的基本盘。

## 八、躯体健康共管（早亡风险）

【研究结论】这是常被忽视、却非常重要的一点：

- 精神分裂症患者的**躯体疾病（尤其心血管、代谢）患病率和早亡风险高于普通人群**——一部分来自疾病本身和生活方式，一部分来自药物代谢影响，也与"只看精神、不管身体"的就医习惯有关。
- **因此要把身体也当病人管**：
  - **年度体检**：血压、血糖/糖化、血脂、肝肾功能、心电图、体重腰围；
  - **牙科**：定期洗牙检查（抗精神病药常见口干，口腔卫生更重要）；
  - **疫苗**：按年龄和状况接种流感、肺炎等疫苗；
  - 出现持续躯体不适（胸闷、气短、严重便秘、黄疸等）及时看综合科，不要都归为"心理作用"。

## 九、戒烟、财务管理与日常生活

- **戒烟**：精神分裂症人群吸烟率高，吸烟影响药物代谢、加重心血管风险，应纳入管理；可向医生求助戒烟方法。
- **财务管理**：学习记账、管理零花钱/生活费，避免在病态支配下大额消费或受骗；必要时在本人同意下由家属协助大额支出。
- **日常生活**：固定日程、承担力所能及的家务、保持个人卫生，都是维持功能的"基本功"。

## 十、家属的角色边界

- **支持但不包办**：帮患者重新学会独立生活，而不是替他做完所有事；适度的自主感有利于康复。
- **自己也要有生活与喘息**：长期照护会耗竭，家属应保留自己的社交、休息和（必要时）心理支持。
- **避免两种极端**：一是"全权代劳、什么都管"，二是"不闻不问、完全推给医院"。
- 出现家庭冲突或照护压力，可求助家庭干预、社区精神卫生服务（见 5.2）。

## 十一、复发后怎么办

- 复发不是"前功尽弃"，而是**需要重新评估和调整治疗**的信号。
- 尽快复诊/住院，恢复规范治疗；分析复发原因（停药？压力？物质？），更新预警计划；不要互相指责。
- 复发后康复节奏应放慢，功能恢复一步步来，不急于马上回到高强度工作/学习。

## 十二、分层管理清单

| 频率 | 管理事项 |
|---|---|
| **每日** | 规律作息与睡眠；按时服药（用提醒工具）；适量运动；远离酒/大麻/毒品；注意个人卫生与饮食 |
| **每周** | 称重 1 次；复盘睡眠与情绪/社交状态；做 3–5 次中等强度运动；整理本周服药是否规律 |
| **每月** | 测血压、腰围；核对药是否备足、有无漏服；回顾有无预警信号；记录身体与情绪变化 |
| **每次复诊** | 谈睡眠/情绪/社交/工作；报告副作用与漏服；查体重、血糖、血脂、泌乳素、心电图等（按医嘱）；讨论是否调整治疗与预警计划 |
| **每年** | 年度全面体检（含心血管、代谢）；牙科检查；按建议接种疫苗；全面复盘康复目标 |

> **一句话记住**：康复不是靠"哪天突然想通"，而是靠每天按时吃药、睡好觉、不碰酒和毒品、定期复诊这些不起眼的小事，年复一年地守住。
