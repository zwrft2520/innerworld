# 常见谣言澄清

> 本页用于澄清社会上对精神分裂症最常见的误解，目的是减少病耻感、鼓励及时就医。所有医学结论以精神科执业医师评估为准；本页不构成诊断或治疗建议。

精神分裂症是一种需要规范治疗的重性精神障碍，但围绕它的谣言很多来源于影视作品、旧观念和个案新闻的以偏概全。下面逐条用"谣言 vs 事实"的方式澄清，并给出听到谣言时可以怎么回应。

## 一、谣言 vs 事实对照表

| 常见谣言 | 事实 | 证据标注 |
| --- | --- | --- |
| "得这个病的就是疯子，没救了。" | "精神分裂症"是疾病名称，不是人格标签。"疯子"是带有侮辱性的旧称，会让患者和家属不敢就医。规范治疗下，相当一部分人症状缓解、可以回归生活。 | 【临床共识】 |
| "精神分裂症患者都是暴力分子、会犯罪。" | 总体上，患者的暴力风险并不高于普通人群；患者自身更常是暴力和歧视的**受害者**而非施害者。仅在急性发作期合并特定症状（如命令性幻听、被害妄想）或同时存在物质（酒精、毒品）使用时，暴力风险才会升高，且这是可以通过治疗控制的。不能凭诊断标签判断某个人是否危险。 | 【研究结论】 |
| "这是鬼神附身、中邪、被脏东西缠上。" | 这是没有科学依据的解释。宗教或民俗慰藉可在不伤害、不延误医疗的前提下作为心理支持，但不能替代专业诊疗，更不能以此羞辱、拘禁或用"驱邪"方式治疗。 | 【临床共识】 |
| "就是单纯心理问题、想不开、心眼小。" | 精神分裂症有明确的生物学基础（神经发育、神经递质、遗传等多因素），不是"想开点"就能好，也不是单纯靠心理咨询能治愈的。心理社会因素只是诱因之一。 | 【临床共识】 |
| "是父母教养失败、性格有缺陷造成的。" | 病因是多因素的，不能归咎于父母或患者本人。这种归因会造成家属自责和家庭内耗，反而不利于康复。 | 【临床共识】 |
| "一得病就终身废了，不能工作、不能成家。" | 不对。是否能工作、独立生活因人而异。在规范治疗、长期随访和支持下，部分患者可以稳定生活、复学复工、建立家庭；也有一部分人需要长期支持。诊断不等于劳动能力的丧失。 | 【研究结论】 |
| "吃药越吃越傻、把人吃呆。" | 抗精神病药可能有嗜睡、锥体外系反应、体重增加等副作用，但合理选药和剂量下，多数人可以正常生活。"傻"更多是急性期症状本身、或药物未调整到合适剂量造成的，可与医生沟通换药调量，而不是自行停药。 | 【临床共识】 |
| "靠意志力就能停药，是药三分毒。" | 不能靠意志力自行停药。骤停抗精神病药会引起撤药反应，并显著升高复发风险；多数复发与不规律服药有关。是否减停必须由精神科医生评估。 | 【临床共识】 |
| "电休克（MECT）是酷刑，会把人电坏。" | 现代无抽搐电休克治疗（MECT）是在麻醉、肌松下进行的规范医疗手段，用于难治性、高自杀风险或紧张症等情况，有明确适应证，不是惩罚性"酷刑"。 | 【临床共识】 |
| "这就是懒、小心眼、装病。" | 患者的退缩、少语、不想动常是阴性症状（意志减退、快感缺失）的表现，是疾病的一部分，不是道德上的懒。 | 【临床共识】 |

## 二、为什么这些谣言危害很大

【研究结论】污名本身会带来一连串实际伤害：

- **延误就诊**：因为怕被叫做"疯子"，患者和家属迟迟不就医，错过早干预的黄金期。
- **社交隔离**：被疏远、被议论，进一步加重阴性症状和抑郁。
- **就业与教育歧视**：能力被否定，丧失回归社会的机会。
- **自我污名**：患者内化了"我没救了"的想法，放弃治疗和康复。

## 三、听到谣言时可以怎么回应（话术示例）

- 听到"他就是个疯子"：
  > "那是一种病，跟高血压、糖尿病一样需要看医生，不能用'疯子'这种词说人。"
- 听到"是不是家里风水/中邪"：
  > "迷信的说法帮不了他。这是有医学原因的，及时去精神卫生中心看病才是正经事。"
- 听到"别跟他来往，危险"：
  > "大多数患者并不危险，反而是更容易被欺负的一方。真正需要担心的是没看病、没吃药的状态，治好了跟正常人一样生活。"
- 听到"吃药不好，停了吧"：
  > "药能不能停得问医生，自己停很容易复发，之前的治疗就白费了。"
- 听到"就是想不开，开导开导就行"：
  > "这不是心理问题，心理咨询治不了急性发病，得先看精神科、规范用药。"

## 四、更尊重的语言

- 说"精神分裂症患者 / 康复者 / 患有精神分裂症的人"，而不是"疯子""癫子""神经病"（"神经病"在医学上指神经系统疾病，与精神疾病不同）。
- 不要说"人格分裂""多重人格"——那是另一种病（解离性身份障碍），与精神分裂症不是一回事。
- 报道或谈论新闻事件时，不要在没有证据的情况下把犯罪行为归因于精神疾病；也不要展示患者发病时的丑态。
