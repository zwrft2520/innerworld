# 佛法智慧资料库 · 目录（面向在家生活与工作）

> 本资料库的主题是"把佛法智慧应用到生活与工作的智慧"，按"认识世界与自我 → 心态与情绪调御 → 工作与职场 → 处世与为人 → 日常与生活 → 逆境与苦难"六个模块编排，覆盖从观念、心态到具体场景的可操作智慧。每篇都是"一个智慧主题的详细内容"，可独立阅读，也可按需查阅。
>
> **立场说明**：本资料库以人间佛教、理性正信为主轴，强调因果、伦理、修心与利他；明确区分正信佛教与算命看事、烧高香买平安、功德交易、附佛外道、"能量/灵性"骗局、求神通求感应等迷信行为。肯定在家身份，平凡生活与本职工作即是道场。
>
> **安全提示**：禅修、静心、冥想、静坐等练习不能替代医疗。患有精神心理疾病者（如精神分裂症、双相障碍、重度抑郁焦虑），应以药物治疗和医生诊断为前提，静坐冥想出现失眠、幻听、情绪剧烈波动等情况应立即停止并就医，不得把病征当作"境界"。涉及情绪、焦虑、逆境、病苦的具体篇目另附各篇安全提示与就医指引，请优先遵守。

---

## 模块1：认识世界与自我

> 目标：建立看待世界与自我的基本框架——无常、缘起、放下执著、中道、因果，为日常心态打地基。

1. 无常：一切都在变化中
2. 缘起：没有孤立存在的"我"
3. 放下执著：少一点"必须"
4. 中道：不走极端的生活智慧
5. 因果：今日的努力是明日的因

## 模块2：心态与情绪调御

> 目标：认识嗔怒、贪婪、恐惧、嫉妒、骄慢、焦虑六种常见烦恼的机制，掌握当场可用、长期可练的对治法，学会与情绪共处而不是被情绪牵着走。

1. 嗔怒：火气上来时怎么办
2. 贪婪与知足：欲望的边界
3. 恐惧与担忧：面对不确定的心
4. 嫉妒与随喜：见不得别人好怎么办
5. 骄慢与谦卑：掂量自己的分量
6. 焦虑的安心法：与不安共处

## 模块3：工作与职场

> 目标：把佛法智慧落到职场——从正命择业、敬业负责，到专注做事、协作利他、面对压力与升迁得失，把工位变成修心的道场。

1. 正命：做正当的事，赚正当的钱
2. 敬业即修行：把工作当功课
3. 专注与深度工作：一心一事的功夫
4. 团队协作与利他：成人之美也是自利
5. 面对压力与失败：跌倒后再起身
6. 升迁得失的平常心：得之淡然，失之泰然

## 模块4：处世与为人

> 目标：掌握四摄法、正语、忍辱、布施等菩萨精神的家常版，处理好家人亲友关系，学会化解恩怨，让人际关系成为修行的道场。

1. 四摄法：与人相处的四把钥匙
2. 说话的艺术：正语怎么用
3. 宽容与忍辱：受了委屈怎么办
4. 感恩与布施：越给予越丰盛
5. 与家人亲友相处：最难的修行在最近处
6. 化解恩怨纠纷：让旧账翻篇

## 模块5：日常与生活

> 目标：把修行落实在衣食住行——简朴、饮食、金钱、时间、独处与家庭，让平凡日子成为修行的日常。

1. 简朴与断舍离：少即是多
2. 饮食与健康养生：身体也是道场
3. 金钱观与理财布施：钱想清楚、用明白
4. 时间管理与定课：给心一个锚点
5. 独处自省：与自己相处的能力
6. 家庭和睦之道：把家经营成道场

## 模块6：逆境与苦难

> 目标：在病苦、失业、失意、失败与死亡面前如何安心——不宿命、不说教，给出谷底自处、随缘精进与痛苦转化的具体路径。

1. 八苦与无常：苦是人生的底色吗
2. 病苦中如何安心：带病生活的智慧
3. 失业失意失败时如何自处：谷底的自处法
4. 随缘与精进：尽力之后，随它去
5. 死亡观与临终关怀：直面终点的功课
6. 从痛苦中长出智慧：逆境的转化

## 使用建议

- **先读模块1**：无常、缘起、因果是后面所有篇目的地基，先建立框架，再看具体场景不会"见木不见林"。
- **按需查阅**：其余模块可按当下遇到的问题直接查阅——最近焦虑就读模块2第6篇，失业期读模块6第3篇，工作不顺读模块3，与人起冲突读模块4第3篇。
- **实修原则**：每篇的【实修提示】都是当天就能开始的小步骤，不求多，选一两件持续做；定课贵在恒常，不在贪多（见模块5第4篇）。
- **安全原则**：身体或心理状态不稳时，以就医、服药、休息为先；佛法提供的是安心与方向，不替代医疗。涉及静坐冥想的练习，务必先读该篇的安全提示与就医红线。
