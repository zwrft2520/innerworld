# 2. 如何建立定课——早晚课模板

> 定课就是"每天固定做的修行功课"。对在家普通人来说，定课不是寺院那种繁复的仪轨，而是一段你每天雷打不动留给自己的时间。本篇讲定课的原则、给出精简版和完整版两套早晚课模板，以及一张可以打印的打卡表。
>
> **安全提示**：精神心理疾病患者，定课以"短、稳、不勉强"为原则；不要因为"没完成功课"而自责、焦虑。功课是帮手，不是新的压力源。

## 一、定课的四条原则

【祖师开示】印光大师、虚云老和尚等近代大德都强调：**定课贵于恒常，不贵于繁多**。每天 10 分钟，坚持一年，胜似一天坐 3 小时、之后三周不碰。

【实修提示】四条原则：

| 原则 | 含义 | 实操 |
|---|---|---|
| **固定时间** | 每天同一时段做，形成节律 | 清晨起床后、或晚上睡前 1 小时，二选一固定 |
| **由短到长** | 从 5–10 分钟开始，慢慢加 | 不要第一天就定 1 小时目标 |
| **贵在恒常** | 宁可短，不可断 | 出差、生病、忙，也要做"最小版"（3 分钟） |
| **不比较、不自责** | 不和别人比，不骂自己"没修好" | 今天状态差，做 5 分钟就下座也是完成 |

【常见误区】
- **误区一**："今天没时间，明天补两回。"——定课不能补。**断了就是断了，明天照常开始**。
- **误区二**："我一定要完成完整的功课才有功德。"——错。3 分钟真诚的静坐，胜似 30 分钟敷衍。
- **误区三**：把定课当 KPI，做不到就焦虑。——定课是养定心，不是加压。

## 二、精简版早晚课（适合初学者、忙碌上班族）

【实修提示】这套模板总共 10 分钟以内，任何人都能做到。

### 早课（约 5 分钟）

```
1. 合掌问讯（10 秒）：对佛菩萨像（或一张自己尊敬的画像、
   或只是合掌当胸），微微鞠躬。
2. 三皈依（1 分钟）：
   "皈依佛，皈依法，皈依僧。
    皈依佛竟，皈依法竟，皈依僧竟。"
   （念三遍）
3. 发愿（1 分钟）：
   "愿我今日，身口意业，皆以善为；
    愿遇一切人、一切境，
    能保持清醒、不起嗔恨、利他利己。"
4. 静坐数息（2 分钟）：上座，数息 1–10 两轮。
5. 回向（30 秒）：
   "愿以此功德，普及于一切，
    我等与众生，皆共成佛道。"
```

### 晚课（约 5 分钟）

```
1. 合掌问讯（10 秒）
2. 反省（2 分钟）：
   回忆今天三件事：
   - 哪个时刻我做得好（善的身口意）？
   - 哪个时刻我没觉察、起了烦恼？
   - 对谁我应该道歉或感谢？
   不批评自己，只是看见。
3. 诵经或念佛（1 分钟）：
   可念《心经》一遍（约 3 分钟，若来不及可只念
   "观自在菩萨……" 开头几句），或念佛号 10 声。
4. 静坐数息（1 分钟）
5. 回向（30 秒）
```

## 三、完整版早晚课（适合有 20–30 分钟时间者）

【实修提示】这套模板参考汉传寺院的朝暮课诵，但已精简为在家可行版本。可根据自己的法门（净土、禅宗、南传）调整。

### 早课完整版（约 20 分钟）

```
1. 净手、漱口、整理佛龛（或清洁一个固定小桌）
2. 上香一支（或不上香，合掌即可）
3. 礼佛三拜（或问讯三次）
4. 三皈依（三遍）
5. 诵《心经》一遍（约 3 分钟）
   或诵《阿弥陀经》选段、或念"南无阿弥陀佛" 108 声
6. 发菩提心：
   "众生无边誓愿度，烦恼无尽誓愿断，
    法门无量誓愿学，佛道无上誓愿成。"（四弘誓愿，三遍）
7. 静坐数息/念佛 10 分钟
8. 回向：
   "愿以此功德，庄严佛净土；
    上报四重恩，下济三途苦。
    若有见闻者，悉发菩提心；
    尽此一报身，同生极乐国。"
```

### 晚课完整版（约 20 分钟）

```
1. 礼佛、问讯
2. 诵《佛说阿弥陀经》（约 15 分钟，净土行人）
   或诵《普贤菩萨行愿品》选段
   或诵"八十八佛忏悔文"选段
3. 静坐/念佛 10 分钟
4. 反省一天身口意（对照五戒十善）
5. 回向（同上）
```

【实修提示】这套模板不是"必须全做"。你可以根据自己的法门和时间，**裁剪成一个你能坚持半年的版本**。

## 四、不同场景下的定课安排

【实修提示】

| 场景 | 建议做法 |
|---|---|
| 忙碌上班族 | 只做精简版早晚课（各 5 分钟） |
| 退休/时间多 | 用完整版，早晚各 20–30 分钟 |
| 出差/旅行 | 做"最小版"：三皈依 + 静坐 3 分钟 + 回向 |
| 生病/身体不适 | 卧床默念佛号、读一段法，不必上座 |
| 情绪极差的一天 | 不勉强做"功课"，先静坐 5 分钟、做慈心给自己 |
| 周末 | 可加一次 30–60 分钟的长坐，或参加共修 |

## 六、定课常见问题

- **问：没有佛龛/佛像怎么办？**
  答：不用。合掌当胸、或面对一张你尊敬的人的照片、或只是安静坐着，都可以。定课的核心是"心"，不是"像"。

- **问：家里人不信佛，反对我做功课怎么办？**
  答：不争论、不张扬。选家人不在的时段做；或把静坐融在他们看不到的时间（早起、睡前）。**修行是你自己的事，不是用来"说服家人"的工具**。

- **问：定课坚持了一段时间，想换法门、换内容，可以吗？**
  答：可以，但建议**至少坚持一个法门 3–6 个月**再评估。换来换去，哪个都入不了门。

- **问：我打坐时总是昏沉，是不是不适合？**
  答：不是不适合，是节奏问题。把时间缩短到 5 分钟、换清晨不睡过头的时间、睁眼留一线，再坚持两周看。

---

> **一句话总结**：定课就是"每天固定留给自己的修行时间"。从 5 分钟开始，固定时段、不中断、不自责——这套早晚课模板，你今天就能开始用。
