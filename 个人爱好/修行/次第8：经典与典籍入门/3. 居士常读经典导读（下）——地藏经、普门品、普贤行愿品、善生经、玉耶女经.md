# 3. 居士常读经典导读（下）——地藏经、普门品、普贤行愿品、善生经、玉耶女经

> **核心要旨：上篇讲了"般若+净土"的核心三经；这五部经，管的是在家学佛人最切身的几件事：孝道与因果（地藏）、危难中求救（普门）、发大愿心（行愿）、在家人如何待人接物（善生、玉耶女）。** 读这五经，不是为了猎奇神通，而是把"出世间的志"落回"在世间的人伦"——这正是人间佛教的精神。

## 一、《地藏菩萨本愿经》（简称《地藏经》）

### 基本档案

| 项目 | 内容 |
|---|---|
| 译者 | 唐·实叉难陀 |
| 篇幅 | 共13品，约1.7万字 |
| 主角 | 地藏菩萨，本生为"大长者子""婆罗门女""光目女"时发愿救母 |
| 核心大愿 | **"地狱不空，誓不成佛；众生度尽，方证菩提。"** |
| 地位 | 汉地"佛教孝经"，超度、荐亡、植福常诵 |

### 经中主要内容

| 品目要点 | 大意 |
|---|---|
| **忉利天宫神通品** | 佛陀升忉利天为母说法，嘱地藏菩萨：佛灭度后，度脱众生 |
| **阎浮众生业感品** | 地藏菩萨本生故事——光目女因母堕恶道，发广大誓愿救度 |
| **观众生业缘品** | 详述造不同业者堕不同恶道的果报 |
| **校量布施功德缘品** | 布施、供养、修庙、造像的功德 |
| **嘱累人天品** | 佛陀咐嘱地藏，末法中护持众生 |

【经典依据】地藏菩萨的大愿（常被引用，大意）：**"若有众生，恭敬礼拜地藏菩萨，乃至一七日、一七日莫退初心，地藏菩萨当遣土地鬼神，卫护是人。"** 经中详述因果业报：什么样的因得什么样的果，善有善报、恶有恶报，丝毫不爽。

### 在家怎么用《地藏经》

- **孝道**：诵地藏经回向给过世父母、师长——这是汉地最通行的超度方式；
- **深信因果**：读经后会对"起心动念都有果报"生敬畏，不敢做亏心事；
- **不要走偏**：

| 常见误区 | 正解 |
|---|---|
| 诵地藏经=给死人念的，活人不必读 | 【常见误区】活人更要读——它讲因果、讲孝道、讲起心动念的果报，是最好的"行为规范手册" |
| 念了就有鬼来找/半夜害怕 | 那是心理暗示。至诚念地藏菩萨圣号，菩萨与护法护持，不必自己吓自己 |
| 把它当道教《玉历宝钞》式的"地府手册" | 《地藏经》讲的是业力变现的境界，不是客观存在的"阎罗王办公大楼"。不要拿去和封建迷信混用 |
| 求地藏菩萨保佑升官发财 | 菩萨教的是"种善因得善果"，不是"行贿式求保佑" |

## 二、《观世音菩萨普门品》（简称《普门品》）

### 基本档案

| 项目 | 内容 |
|---|---|
| 出处 | **《妙法莲华经》第二十五品**（不是独立经） |
| 译者 | 鸠摩罗什译《法华经》，本品单独流通极广 |
| 主角 | 观世音菩萨，由无尽意菩萨请问而说 |
| 核心 | 观世音菩萨**寻声救苦**、三十二应身、十四种无畏 |

### 经中主要内容

【经典依据】佛陀告无尽意菩萨："**若有无量百千万亿众生受诸苦恼，闻是观世音菩萨，一心称名，观世音菩萨即时观其音声，皆得解脱。**"——这就是"观世音"名号的由来：观照众生称名的音声，即时救度。

| 救苦内容 | 大意 |
|---|---|
| **七难** | 大火、大水、恶鬼、刀兵、枷锁、恶贼、风雨灾难——称名即免 |
| **三毒** | 多贪、多嗔、多痴——称名即得离 |
| **二求** | 求男得男、求女得女（恭敬供养观音菩萨） |
| **三十二应** | 菩萨应以何身得度，即现何身说法——佛身、比丘身、居士身、妇女身、甚至天龙鬼神身 |

【祖师开示】"**家家阿弥陀，户户观世音。**"——观音信仰是汉地最深植民间的信仰。观音之所以深入人心，不在他有多大神通，而在他"**寻声救苦**"的慈悲——你苦，他就来。

### 在家怎么用

- **急难时**：真心念"南无观世音菩萨"，比慌乱有效；
- **日常**：早晚诵一遍《普门品》（约2500字，20分钟）或只念"观世音菩萨"圣号；
- **学其精神**：观音菩萨的精神不是"等别人求我"，而是"**寻声**"——主动去听周围人的苦。在家学观音，就是在家人有难时搭把手；
- **不要把观音当成有求必应的许愿机**：菩萨救的是"苦"，不是满足贪心。

## 三、《普贤行愿品》（《华严经·入法界品》末章）

### 基本档案

| 项目 | 内容 |
|---|---|
| 出处 | **《大方广佛华严经》第四十卷**（八十华严最后一品），昙怑难陀译 |
| 流通本 | 常单独流通，称《大方广佛华严经普贤行愿品》 |
| 核心 | 普贤菩萨**十大愿王**，导归极乐 |

### 十大愿王（必须知道）

【经典依据】普贤菩萨说偈，十大愿王为：

```
一者礼敬诸佛
二者称赞如来
三者广修供养
四者忏悔业障
五者随喜功德
六者请转法轮
七者请佛住世
八者常随佛学
九者恒顺众生
十者普皆回向
```

【现代阐释】这十大愿，是一个菩萨"应该怎么活"的完整大纲：

- **礼敬诸佛**——对一切人、一切生命保持恭敬；
- **称赞如来**——多说别人的好，不诽谤不嫉妒；
- **广修供养**——尽己所能供养三宝、帮助需要的人；
- **忏悔业障**——定期反省，不护短；
- **随喜功德**——别人好时真心高兴，不嫉妒；
- **请转法轮、请佛住世**——希望善法久住；
- **常随佛学**——以佛为榜样修正自己；
- **恒顺众生**——随顺众生的根机去度化，不摆架子；
- **普皆回向**——功德不独享，回向给一切众生。

【祖师开示】十大愿王最后导归极乐——普贤菩萨以此大愿，"**愿临命终时，得生极乐世界，面见阿弥陀佛**"。这就是为什么净土宗把《行愿品》并入五经一论：**华严的极果，终归净土。**

### 在家怎么用

- **每天发愿**：早晚诵一遍十大愿王，哪怕只念一遍偈颂；
- **对照修身**：十大愿像十面镜子，看自己今天做到几条；
- **回向**：每天结束时，把功德"普皆回向"——心量一下子打开。

## 四、《善生经》（在家伦理经）

### 基本档案

| 项目 | 内容 |
|---|---|
| 出处 | 汉译有两本：《长阿含经·善生经》（佛陀耶舍译）、《中阿含·善生经》 |
| 主角 | 善生长者子，每天晨起先沐浴、向六方礼拜 |
| 核心 | 佛陀告诉他：礼拜六方，不是拜天地鬼神，而是礼敬**六种人际关系** |

### 六方礼拜——在家人的伦理表

【经典依据】佛陀对善生说：所谓六方，实为六种应善待的关系：

| 方位 | 对应关系 | 责任 |
|---|---|---|
| **东方** | 父母 | 子女要奉养、传承家业、光宗耀祖 |
| **南方** | 师长 | 学生要恭敬、听从、供养 |
| **西方** | 妻/夫 | 夫妻要相敬、体贴、忠实 |
| **北方** | 朋友 | 朋友要互敬、互助、劝谏过失 |
| **下方** | 仆从/下属 | 主家要合理安排工作、给衣食、体恤疾苦 |
| **上方** | 沙门、婆罗门（修道者） | 在家人要供养、恭敬、护持正法 |

【现代阐释】这是佛经里最"接地气"的一篇。它告诉在家人：**修行不是要你离家出世，而是把家庭、工作、朋友关系都尽到本分。** 把这六个方位的责任尽好，就是在家人最好的修行。

### 对现代生活的启发

- 东方（父母）：孝顺不是给钱就行，要陪伴、要耐心；
- 西方（夫妻）：《善生经》讲夫妻要"相待以礼"，不是"娶来/嫁来伺候我"；
- 北方（朋友）：朋友有过错要敢劝，不是酒肉朋友；
- 下方（下属/晚辈）：当老板、当长辈，要体恤下面的人；
- 上方（修道者/老师）：要恭敬正法，但不迷信个人。

## 五、《玉耶女经》（为妻之道）

### 基本档案

| 项目 | 内容 |
|---|---|
| 译者 | 东晋·昙摩难提译（一说求那跋陀罗译） |
| 主角 | 玉耶女，豪贵家女，嫁至须达多长者家，骄慢不顺 |
| 核心 | 佛陀亲自为她说法，教她为妇之道 |

### 经中主要内容

佛告玉耶女，为妻者当以**五善**对待夫家（大意）：

1. **早起**：先于夫起，后于夫眠；
2. **和颜悦色**：不恶口、不发脾气；
3. **奉公顾家**：善理家政，不私积财物；
4. **敬事丈夫**：爱敬、不欺瞒；
5. **孝敬公婆**：视公婆如父母。

同时佛也讲了**五恶妇**：恶口骂夫、懒惰自私、外心向人、赌博挥霍、不敬公婆。

【现代阐释】这篇经常被批为"封建男权"，但若放在2500年前的语境，它的进步意义在于：**它把"为妻之道"讲得具体、可操作，并要求妻子修行成佛的资格——不是丈夫的附属品。** 对现代读者，应抽取其中的普世价值：

- 婚姻中双方都应和颜悦色、彼此尊重；
- 持家要勤俭、不挥霍；
- 孝敬公婆是相互的——现代男性同样要孝敬岳父母；
- 把这篇经当"古代表达"，取其"婚姻中互相尽责"的内核，不必照搬细节。

## 六、五经主旨对照表

| 经 | 解决什么问题 | 在家人怎么用 |
|---|---|---|
| 《地藏经》 | 因果、孝道、荐亡 | 孝亲、深信因果、回向先人 |
| 《普门品》 | 急难、救苦、慈悲 | 遇难称念观音、学其寻声救苦 |
| 《行愿品》 | 发大愿、心量 | 每天发愿、普皆回向 |
| 《善生经》 | 人伦、家庭责任 | 尽好六种关系的本分 |
| 《玉耶女经》 | 为妻之道、婚姻伦理 | 取其婚姻互敬的内核 |

## 七、常见误区

| 误区 | 真相 |
|---|---|
| 《地藏经》讲地狱=宣扬封建迷信 | 它讲的是**业力**的运作，不是客观地理。把它读成"地府游记"是误解 |
| 观音菩萨是女的 | 【常见误区】菩萨无男女相，应何身得度现何身。汉地多现女相，是慈悲应化 |
| 《玉耶女经》是压迫女性 | 2500年前能讲出"为妻要修五善、可成佛"已是进步；取其互敬内核即可 |
| 诵这些经可以"包治百病、有求必应" | 经典的力量在于转化你的心，不是替代现实。生病看医生、遇事尽力做，诵经是安心与培福 |
