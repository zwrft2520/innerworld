# 佛教常用名词术语表

> **核心要旨**：本表是一份"佛教入门词典"，按主题分类，给拼音/读音、简要解释，供在家居士读经、听法、与同修交流时查阅。**不求学术完备，只求遇到时能看懂、不被吓住。**

## 使用说明

- 按主题分 12 类，每类按概念常见度排序；
- 每个词条给：拼音（多音字/易读错的）+ 一句话解释；
- 太学术、对在家修行无关的术语不收；
- 遇到本表没有的，优先查正规佛学辞典（如《佛光大辞典》），不要问"灵性博主"。

## 一、基础教义类（核心世界观）

| 词条 | 拼音 | 简要解释 |
|---|---|---|
| 佛陀 | Fótuó | 意为"觉者"，指释迦牟尼（历史上的觉者）；广义指一切圆满觉悟者 |
| 三宝 | sān bǎo | 佛（觉悟者）、法（教法）、僧（和合众），是佛教的皈依处 |
| 三法印 | sān fǎ yìn | 诸行无常、诸法无我、涅槃寂静——判定是否佛法的三个标准 |
| 四圣谛 | sì shèng dì | 苦、集、灭、道——佛陀初转法轮的核心教法 |
| 八正道 | bā zhèng dào | 正见、正思惟、正语、正业、正命、正精进、正念、正定——解脱的八类正确行为 |
| 缘起 | yuán qǐ | 一切现象由因缘和合而生，无独立自性 |
| 性空 | xìng kōng | 一切法无固定不变的自性；不是"什么都没有"，是"不执着" |
| 因果 | yīn guǒ | 善因善果、恶因恶果；不是"宿命"，是业力的规律 |
| 业 | yè | 身、口、意的行为所形成的力量；分善业、恶业、无记业 |
| 轮回 | lún huí | 众生在天、人、阿修罗、畜生、饿鬼、地狱六道中生死流转 |
| 涅槃 | niè pán | 烦恼断尽、不再轮回的境界；不是死亡，是解脱 |
| 解脱 | jiě tuō | 从烦恼、轮回中出来；与涅槃近义 |
| 菩提 | pú tí | 觉悟；发菩提心=上求佛道、下化众生 |
| 般若 | bō rě | 圆满的智慧（不是普通聪明）；六度之一 |
| 无明 | wú míng | 迷惑、不明事理；是轮回的根本 |
| 我执 | wǒ zhí | 执着有一个恒常的"我"；烦恼的总根源 |
| 法执 | fǎ zhí | 执着一切法实有；破我执后还要破法执 |
| 分别 | fēn bié | 对事物起高下、好恶的念头；是烦恼的入口 |
| 执着 | zhuó | 抓住某样东西不放；修行的核心是"不执着" |

## 二、修行方法类（止观、禅定）

| 词条 | 拼音 | 简要解释 |
|---|---|---|
| 修 | xiū | 调伏身心、改正行为；不是"打坐"的同义词 |
| 行 | xíng | 修行的实践；"解"是理解，"行"是落实 |
| 止 | zhǐ | 梵语"奢摩他"，把心定于一处、停止散乱 |
| 观 | guān | 梵语"毗婆舍那"，以智慧观照诸法实相 |
| 止观 | zhǐ guān | 止（定）与观（慧）的合称；禅修的核心 |
| 四禅八定 | sì chán bā dìng | 初、二、三、四禅 + 四无色定；禅定的深浅次第 |
| 初禅 | chū chán | 离生喜乐，离欲恶不善法 |
| 二禅 | èr chán | 定生喜乐，离寻伺、内清净 |
| 三禅 | sān chán | 离喜妙乐，行舍、念、正知 |
| 四禅 | sì chán | 舍念清净，不苦不乐 |
| 四无色定 | sì wú sè dìng | 空无边处、识无边处、无所有处、非想非非想处 |
| 四念处 | sì niàn chù | 身、受、心、法四观；不净观、苦观、无常观、无我观 |
| 五停心观 | wǔ tíng xīn guān | 对治烦恼的五种观法（不净、慈愍、因缘、界分别、数息） |
| 数息观 | shǔ xī guān | 默数呼吸以摄心；最基础的禅法 |
| 慈心观 | cí xīn guān | 散播"愿一切众生安乐"的观法；诱发不良反应最少 |
| 不净观 | bù jìng guān | 观身不净，对治贪欲 |
| 经行 | jīng xíng | 慢步行走中念佛/摄心；久坐后的替代修行 |
| 打七 | dǎ qī | 连续 7 天密集禅修/念佛；有禅宗七、净土七 |
| 闭关 | bì guān | 独自（或共住）一段时期专修；**在家有病史者慎行** |
| 不倒单 | bù dǎo dān | 不躺卧、夜不倒单的苦行；**在家居士不必学** |
