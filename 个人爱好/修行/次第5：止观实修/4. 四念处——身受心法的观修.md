# 4. 四念处——身受心法的观修

> 四念处（身、受、心、法）是佛陀在《大念处经》中亲说的"一乘道"——"众生清净、离愁泣、灭苦恼、得正法者，唯四念处"。如果说数息是在练"心的稳定"，四念处就是在练"心的清醒"：把身、受、心、法当作观察对象，如实知道，不迎不拒。本篇给出四念处的观修框架表和可直接照做的入门步骤。
>
> **安全提示**：精神心理疾病患者在练习"受念处"时，若强烈负面感受（恐惧、愤怒、悲伤）被持续唤起而难以平复，应缩短时间、回到呼吸上，必要时暂停并就医。观受不是要你反复咀嚼痛苦，而是"知道它生、知道它灭"。

## 一、四念处的总框架

【经典依据】《大念处经》（长部第22经）与《中念处经》（中部第10经）系统阐述四念处。《杂阿含经》中多处说："四念处者，谓身念处、受念处、心念处、法念处。"

四念处的总义是：于身、于受、于心、于法，**随观念住**（身身观念住、受受观念住、心心观念住、法法观念住），除世贪忧。

| 念处 | 观察对象 | 核心所观 | 对治的烦恼 |
|---|---|---|---|
| **身念处** | 这个身体 | 呼吸、威仪、正知、身体各部分、界分别、墓墟想 | 净相贪（贪著身体美净） |
| **受念处** | 苦、乐、舍三种感受 | 受生时知道"乐受生"，受灭时知道"乐受灭" | 贪爱（顺境起贪） |
| **心念处** | 当下这一念心 | 贪心、嗔心、痴心、散心、定心、广大心、定心、解脱心——如是知 | 无明（不知心的状态） |
| **法念处** | 法（五盖、五蕴、六处、七觉支、四圣谛） | 盖（烦恼）起知起、灭知灭；觉支修则满 | 邪执（于法颠倒） |

【现代阐释】四念处本质上是一套"系统性的自我观察训练"：身（身体感觉）、受（情绪/快感）、心（注意力的状态）、法（规则/念头）。这与现代正念疗法（MBSR/MBCT）的主体框架高度相通，但其宗教目标是通向解脱，而非仅减压。

## 二、身念处：六类观法

【经典依据】《大念处经》中身念处包含以下几类（此处列其名目大意）：

1. **入出息念**：即上一篇的数息/随息（已详）；
2. **四威仪**：行、住、坐、卧时，"行时知行，住时知住，坐时知坐，卧时知卧"；
3. **正知**：一切动作（前视、后视、屈伸、饮食、大小便、语默）皆以正知而行；
4. **厌逆想（身体部分）**：观察此身从头发、头皮、皮肤、骨、肉、筋、脉，至大小便，"此身中有种种不净"——为对治净相贪；
5. **界分别**：观此身由地（坚）、水（湿）、火（暖）、风（动）四大组成，"无有我、我所"；
6. **墓墟想（九相/死尸观）**：于尸体膨胀、青瘀、烂坏、鸟啄、骨散等相，思惟"此身亦复如是，未来必当如是"。

【实修提示】在家初学者，先练第 2、3 类（威仪、正知），这是最日常的；第 4、6 类（不净、墓墟想）需在有指导的前提下修，不宜自行天天观死尸（易引生厌世、恐惧）。界分别观可日常用（见下）。

### 日常身念处练习：正知三步

吃饭时、走路时、刷牙时，随时可练：

```
1. 动作前：知道"我现在要吃饭/要走路/要刷牙"（动机）
2. 动作中：知道手在动、嘴在嚼、脚在迈（身体感觉）
3. 动作后：知道这一动作结束
```

【常见误区】把"正念吃饭"吃成了"修行任务"——吃饭时紧张地监控自己，反而吃不好。正知是"轻松知道"，不是"严格监督"。

## 三、受念处：观三种感受

【经典依据】《大念处经》："比丘，乐受生时，了知'我生乐受'；乐受灭时，了知'我灭乐受'。苦受生时，了知……不苦不乐受（舍受）生时，了知……"（大意）。

【实修提示】受念处的关键不是"消除苦受"，而是"不被受牵着走"。

| 感受类型 | 生起时 | 你的惯性反应 | 正念的做法 |
|---|---|---|---|
| **乐受**（舒服、愉快） | 知道"这是乐受" | 想抓住、延长（起贪） | 知道它会变，不执着 |
| **苦受**（痛、烦、不自在） | 知道"这是苦受" | 想逃避、推开（起嗔） | 知道它会灭，不抗拒 |
| **舍受**（不苦不乐、平淡） | 知道"这是舍受" | 容易昏沉、无聊 | 知道这也是无常，不散乱 |

### 观受的现场步骤（情绪来时）

```
1. 停一下：在情绪刚起的那一刻，先不要反应、不要说话
2. 命名：在心里说"这是苦受（烦）/乐受（爽）/舍受（平）"
3. 找位置：这个感受在身体哪里？胸口？胃？眉皱？
4. 看变化：它是增强了？减弱了？还是换了位置？
5. 不迎不拒：知道"它生、它灭"，继续手头的事
```

【现代阐释】这与认知疗法（CBT）中"情绪命名"（affect labeling）的研究发现一致：用语言给情绪贴上标签，能降低杏仁核的激活。佛法的观受，比这更深一步——不止命名，还看到它无常、无主。

【安全提示】创伤后应激、惊恐发作期间，观受可能让负面情绪被"放大觉察"而失控。此时应回到呼吸或接地技术（参见焦虑模块），等稳定后再观受。

## 四、心念处：观心的状态

【经典依据】《大念处经》心念处："比丘，心有贪时，了知'心有贪'；心离贪时，了知……心有嗔、离嗔；心有痴、离痴；心收摄、心散乱；心广大、心不广大；心未定、心已定；心解脱、心未解脱——如是知。"（大意）。

【实修提示】心念处比受念处更细：你不只是知道"我很烦"（受），还要知道"我的心现在是跑掉了、还是在这儿、还是收缩了"。

| 心的状态 | 怎么识别 | 正念反应 |
|---|---|---|
| 贪心（粘着、贪着） | 心里反复想那件好事/那个人 | 知道"这是贪的心"，不批判，回到呼吸 |
| 嗔心（恼怒、排斥） | 胸口紧、想骂人/摔东西 | 知道"这是嗔的心"，不跟着它说话 |
| 痴心（昏沉、无聊、发呆） | 眼皮沉、脑子糊 | 知道"这是痴/昏沉的心"，睁眼、提神 |
| 散心（掉举） | 念头一个接一个停不下来 | 知道"心在散"，从数息重新来 |
| 摄心（安静、在当下） | 呼吸清楚、念头少 | 知道"心在这儿"，稳住 |

【常见误区】"发现自己起了贪心、嗔心，很自责"——这已经是第二层烦恼（对烦恼的烦恼）。心念处只要求"知道"，不要求"立刻消灭"。

## 五、法念处：五盖、五取蕴、六处、七觉支、四圣谛

【经典依据】法念处是四念处中最宏大的一类，《大念处经》列出五大组：

1. **五盖**：贪欲盖、嗔恚盖、昏沉睡眠盖、掉举恶作盖、疑盖——盖覆心者；
2. **五取蕴**：色、受、想、行、识——一切身心现象的聚合；
3. **六处**：眼耳鼻舌身意六根与色声香味触法六境的接触；
4. **七觉支**：念觉支、择法觉支、精进觉支、喜觉支、轻安觉支、定觉支、舍觉支；
5. **四圣谛**：苦、集、灭、道。

【实修提示】在家初学，法念处**先从五盖入手**（因为五盖是日常最常遇到的障碍），七觉支作为对治框架，其他可后续在经论中学习。

### 五盖与对治对照表（日常随时可用）

| 五盖 | 表现 | 对治方法 |
|---|---|---|
| **贪欲盖** | 满脑子想美食、美色、买东西、刷短视频停不下 | 不净观、观无常、离开诱惑源、守呼吸 |
| **嗔恚盖** | 怨、怒、烦、想报复 | 慈心观（见第 5 篇）、忍辱、先离开现场 |
| **昏沉睡眠盖** | 坐下来就打瞌睡、没精神 | 提神、洗冷水脸、缩短时间、先补觉 |
| **掉举恶作盖** | 念头纷飞、后悔过去、担心未来、坐不住 | 数息、诵经、散步、听法 |
| **疑盖** | 怀疑佛法、怀疑自己、怀疑老师、犹豫不决 | 多闻、思维因果、不退失善行、找善知识问 |

【现代阐释】五盖几乎就是现代心理学所说的"注意力的五种干扰模式"。佛法的独特处在于：不把它们当"病"要治掉，而是当"盖"——知道它盖着，它就开始松。

## 六、四念处一日练习模板

不必一次坐全四念处，日常随时穿插：

```
【早晨下床】身念处：知道脚踩地、身体起立（威仪）
【刷牙吃饭】身受并观：知道手在动、味道、冷热（正知）
【上班路上】心念处：知道心是紧的、还是松的
【工作中被激怒】受念处+心念处：知道"苦受、嗔心"，先停三秒
【午休】法念处：今天哪个盖最重？（贪？嗔？昏沉？）
【晚课坐 15 分钟】：数息（身念处）为主，结束前观一下今天的受与心
【睡前】法念处：今天有没有哪个觉支（念、精进、喜、轻安）生起？
```

---

> **一句话总结**：四念处不是四个分开的题，而是同一面"如实观察身心"的镜子——身怎么动、受怎么起、心怎么跑、法怎么盖，一一知道，不跟不拒。这就是"念住"。
