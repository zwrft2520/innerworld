# 佛教修行次第资料库 · 目录（面向在家居士）

> 本资料库以"道次第"为纲，依"道前基础 → 下士道 → 中士道 → 上士道 → 止观实修 → 生活中修行 → 法门指要 → 经典入门 → 保任护持"的顺序编排，对应从初发心到长期保任的完整学修路径。
>
> **立场说明**：本资料库以人间佛教、理性正信为主轴，强调因果、伦理、修心与服务人群；明确区分正信佛教与算命看事、烧高香买平安、功德交易、附佛外道、"能量/灵性"骗局、求神通求感应等迷信行为。肯定在家身份，平凡生活与本职工作即是道场。
>
> **安全提示**：禅修、念佛等练习不能替代医疗。患有精神心理疾病（如精神分裂症、双相障碍、重度抑郁焦虑）者，应以药物治疗和医生诊断为前提，禅修从短、从缓；出现失眠、幻听、情绪剧烈波动等情况应立即停止并就医，不得把病征当作"境界"。

## 次第1：道前基础与正信入门

> 目标：建立对佛教的正确认识，辨别正信与迷信，明确在家居士的定位与学修地图。

1. 什么是真正的修行——正信与迷信、玄学的区别
2. 佛陀生平与佛教简史
3. 修行的整体地图——五乘佛法、道次第与在家居士的定位
4. 为什么要修行——从离苦得乐到上求下化
5. 如何择师择法——善知识的标准与网络资源辨别
6. 三皈依的意义与学佛态度

## 次第2：下士道·人天基础

> 目标：认识暇满人身的价值，建立无常观、因果观与基本伦理，在生活中培福修善。道次第中下士道重在"求人天乐果、不堕恶趣"，是一切修行的地基。

1. 暇满人身与人生难得
2. 念死无常——不是消极，是珍惜与精进
3. 三恶趣苦与敬畏之心
4. 因果业力正解——不是宿命论
5. 五戒十善与在家伦理
6. 培福之道——布施、孝亲与行善的日常做法

## 次第3：中士道·发出离心

> 目标：看清轮回与烦恼的本质，生起真实的出离心，掌握戒定慧三学总纲与居士戒的开遮持犯。出离心不是厌世逃避，而是不再以"有漏之乐"为究竟归宿。

1. 三苦八苦与轮回过患
2. 烦恼的根源——贪嗔痴与我执
3. 十二因缘——流转与还灭
4. 出离心的真义——不是厌世逃避
5. 戒定慧三学总纲
6. 居士戒详解——五戒开遮持犯与八关斋戒

## 次第4：上士道·发菩提心

> 目标：从自度走向度他，修习菩提心、四无量心、六度四摄，把菩萨精神落实在家常生活。

1. 大小乘分野与大乘精神
2. 菩提心的功德与修法——七因果与自他相换
3. 四无量心——慈悲喜舍
4. 六度详解（上）——布施、持戒、忍辱
5. 六度详解（下）——精进、禅定、般若
6. 四摄法与菩萨戒精神的日常应用

## 次第5：止观实修

> 目标：系统掌握禅修的准备、坐姿、数息、四念处、五停心观等核心方法，了解止观关系与常见偏差，安全、如法地实修。

1. 禅修前的准备与发心
2. 七支坐法与调身调息
3. 安那般那念——数息法逐步引导
4. 四念处——身受心法的观修
5. 五停心观（含慈心观完整引导词）
6. 止与观的关系
7. 禅修常见问题与偏差——掉举昏沉、幻境与"走火入魔"辨析

## 次第6：生活中的修行

> 目标：把修行从蒲团延伸到工作、家庭、人际与逆境之中，建立定课，掌握烦恼对治与临终关怀的实操方法。

1. 生活禅理念——佛法在世间
2. 如何建立定课——早晚课模板
3. 工作中修行
4. 家庭与亲密关系中修行（含吵架时的用心）
5. 烦恼对治实操——嗔恨、焦虑、恐惧、嫉妒、骄慢、怀疑
6. 逆境中的修行——失业、疾病、贫穷、被伤害时如何安心
7. 临终关怀与死亡准备——助念常识

## 次第7：法门指要

> 目标：了解净土、禅宗、南传内观及各宗派的修法特点，学会选择与自己根机相应的法门，处理好一门深入与广学多闻的关系。

1. 净土法门——信愿行与念佛方法
2. 禅宗——参话头、默照与生活禅
3. 南传内观——四念处内观
4. 其他宗派概览——天台、华严、唯识、律宗、密宗
5. 如何选择适合自己的法门——一门深入与广学多闻

## 次第8：经典与典籍入门

> 目标：了解经律论三藏与大藏经结构，掌握居士常读经典的主旨与读法，学会恭敬读经、依义不依语，并获得可靠的入门书单。

1. 经律论三藏与大藏经结构
2. 居士常读经典导读（上）——《心经》《金刚经》《阿弥陀经》
3. 居士常读经典导读（下）——《地藏经》《普门品》《普贤行愿品》《善生经》《玉耶女经》
4. 如何读经与入门书籍推荐

## 次第9：保任与长期护持

> 目标：认识修行阶段与验相，辨别魔境、不求神通，对治常见修行病，处理好修行与心理健康的关系，护持长期道心。

1. 修行阶段与验相——禅定境界、魔境辨析、不求神通
2. 常见修行病与对治——精进过头、形式化、增上慢、退心
3. 修行与心理健康——禅修反应与心理疾病的区分
4. 长期道心护持——共修、发愿、回向与定课
5. 在家修行常见疑问

## 使用建议

- **初学路径**：按次第1 → 次第2 顺序阅读，配合"可选附加模块"中的作息模板与术语表；不必急于禅修，先建立正见与伦理生活。
- **已入门者**：可从次第3、次第4 入手深化发心，同时以次第5 建立稳定的止观实修，以次第6 落实生活。
- **实修原则**：见（正见）、行（戒定）、果（证悟）并重；解行并进、一门深入；定课贵在恒常，不在贪多。
- **安全原则**：身体不适或心理状态不稳时，以就医、服药、休息为先；修行是长期的事，不与医疗争先后。
