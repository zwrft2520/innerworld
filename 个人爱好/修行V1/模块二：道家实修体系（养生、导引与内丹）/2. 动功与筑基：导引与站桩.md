# 2. 动功与筑基：导引与站桩

> 初学者十个有九个一上来就想盘腿静坐，结果腿麻、心烦、越坐越累——这是跳过了筑基。道家讲"性命双修"，身是载道之器：筋骨僵、气血浮、腰胯紧，直接静坐只是在硬扛身体，谈不上修心。本篇讲两条筑基腿：**站桩（混元桩）**和**导引（八段锦、易筋经、五禽戏）**。先把身体活动开、气血引下去，后面的静坐才坐得住。
>
> **安全红线（先读）**：正在接受精神科治疗者（如精神分裂症、双相、重度抑郁焦虑）应以药物治疗和医生诊断为前提，静坐意守等练习不能替代治疗；若练习中出现幻听幻视、失眠加重、情绪剧烈波动、惊恐发作，应立即停止并就医，不得把病征当作"境界"或"业障"硬扛。

## 一、为什么要"先动后静"

【现代阐释】现代人久坐办公室，普遍三个毛病：

1. **上实下虚**：气血聚在头面肩颈（头痛、肩紧、失眠），腿脚冰凉无力。
2. **筋膜僵硬**：久坐导致髋、腰、肩活动度下降，盘腿根本盘不下去。
3. **心神浮越**：一天到晚对着屏幕，神全散在外面，坐下就胡思乱想。

【实修要领】在这种身体状态下直接打坐，只会经历三件事：腿麻 → 心烦 → 打瞌睡。道家的解法很朴素：**先用动功把筋骨拉开、把气血引到脚下、把上半身的紧张卸掉，再去静坐**——此时一坐下来，身体不累、心自然容易安。

| 阶段 | 做什么 | 达到什么状态 |
|---|---|---|
| 第一步 | 导引（八段锦等） | 身体热、关节开、呼吸顺 |
| 第二步 | 站桩 | 气沉下盘、肩颈松、心渐静 |
| 第三步 | 静坐 | 腿不麻、心易定，此时再谈意守 |

## 二、混元桩（无极桩）逐条要领

【经典依据】站桩源于古代"导引吐纳"与武术基功，近代王芗斋先生创"意拳（大成拳）"，将站桩系统化，强调"松静自然、不动之动"。此处讲的是养生版混元桩，不求武术发力，只求养气放松。

【实修要领】下面把整条桩法按"脚下→躯干→头颈→双手→心法"逐层拆开，每层都可独立检查。

### （1）脚下——根要扎稳

```
□ 双脚：与肩同宽，脚尖平行朝前（不要外八字）
□ 十趾：轻轻抓地，像树根扒住泥土，但不要绷紧
□ 膝盖：微微弯曲，松紧以"膝盖不超过脚尖"为度
□ 重心：落在两脚涌泉穴稍前侧，不是脚跟也不是前脚掌
□ 感受：脚底有"踩在地上"的踏实感，不是虚飘
```

【常见误区】膝盖绷得笔直 → 压力全压在关节上；膝盖过度前屈超过脚尖 → 伤膝。记住：**微屈、留弹性**，像随时可以轻轻弹动。

### （2）躯干——中正松沉

```
□ 尾闾：微微前收，臀部像坐在一张高凳上（似坐非坐）
□ 松腰：腰眼处放松，不要塌腰也不要僵腰
□ 塌胯：胯根松开，像骨盆往下沉
□ 含胸：胸口微微内含（不要挺胸，也不要驼背）
□ 拔背：后背微微向上撑圆，像有一根线从脊椎轻轻拎起
```

【现代阐释】"含胸拔背"四个字是桩法的灵魂：含胸是让胸口不绷，拔背是让脊椎正直。两者合起来，胸腔自然打开又不僵硬，呼吸才能深到腹部。

### （3）头颈——虚灵顶劲

```
□ 百会：头顶百会穴像被一根细线轻轻向上提（虚灵顶劲）
□ 下颌：微微内收，不要仰头也不要低头
□ 舌抵上腭：舌尖轻搭上门牙后方的上颚（搭鹊桥）
□ 双目：垂帘——眼皮微闭，留一线之光
```

【实修要领】舌抵上腭是传统说法，讲法是"接通任督二脉"。理性地看：它让口腔放松、口水分泌增多、呼吸更柔，不至于口干舌燥。不必神秘化。

### （4）双手——抱球于胸前

```
□ 位置：双手环抱在胸前，高度约膻中到下丹田之间
□ 形状：像怀里抱着一个不轻不重的大球，既不压也不坠
□ 沉肩：肩膀向下松沉，不要耸肩
□ 坠肘：两个肘尖自然下垂，有重量感
□ 腋下：腋下虚空，像各夹着一个鸡蛋（不能夹碎也不能掉）
□ 十指：自然舒展，左右指尖相对，间距约三拳
```

### （5）心法——松、静、自然

```
□ 从头到脚逐层扫描放松：头顶松 → 眉眼松 → 肩松 → 胸口松 → 腹松 → 胯松 → 膝松 → 脚底松
□ 意念：轻轻放在下丹田，或放在脚底涌泉穴
□ 不追求：不追求气感、不追求发热、不追求"入静"
□ 上虚下实：上身松空，下身沉稳
□ 时长：初学者从 5–10 分钟开始，逐渐加到 15–30 分钟
```

【祖师开示】王芗斋先生论站桩，大意是："不求形骸似，但求神意足"——姿势大致对就行，关键是**松静自然、神不外驰**。死抠一个手指角度反而紧张，那是舍本逐末。

### （6）站桩口诀（代码块速查）

```
脚下：与肩同宽，十趾微抓，膝微屈不过尖
躯干：尾闾微收，含胸拔背，松腰塌胯
头颈：虚灵顶劲，下颌微收，舌抵上腭，目垂帘
双手：环抱如抱球，沉肩坠肘，腋下虚
心法：节节松，意守下丹田，上虚下实
时长：从 10 分钟起，逐日加 2–3 分钟，不勉强
```

## 三、三大传统导引术：八段锦、易筋经、五禽戏

【实修要领】三种导引术都源自古代，动作各有侧重，初学者按自身状态选一种即可，不必贪多。

| 功法 | 动作数 | 特点 | 适合谁 | 建议场景 |
|---|---|---|---|---|
| **八段锦** | 8 式 | 动作柔和简单，口诀顺口，疏通三焦、调理脾胃 | 零基础、办公室人群、中老年人 | 晨起 10 分钟唤醒，或静坐前热身 |
| **易筋经** | 12 式（版本不一） | 动作偏刚劲，强调伸筋拔骨、脊柱拧转 | 身体僵、想拉伸筋膜者 | 每周 3–4 次，配合站桩 |
| **五禽戏** | 5 组（虎鹿熊猿鸟） | 模仿动物姿态，活泼有趣，活动全身 | 觉得八段锦太单调者 | 当作日常活动，不拘形式 |

### （1）八段锦：最推荐的入门第一式

【经典依据】八段锦相传出自宋代，歌诀广为流传："双手托天理三焦，左右开弓似射雕，调理脾胃须单举，五劳七伤往后瞧，摇头摆尾去心火，两手攀足固肾腰，攒拳怒目增气力，背后七颠百病消。"

【现代阐释】八式动作对应八个方向的拉伸与开合，整套 10–15 分钟做完，身体微微发热、呼吸变长。它最大的优点是**动作标准化、网上有大量免费教学视频**，跟练即可，不花钱。

【实修要领】注意：口诀里的"去心火""固肾腰"是古人对体感方向的描述，不是医疗承诺。理性看待：它就是一套温和的全身拉伸操，做了身体舒服，仅此而已。

### （2）易筋经与五禽戏：舒筋拔骨

【经典依据】五禽戏相传为东汉华佗所创，模仿虎、鹿、熊、猿、鸟五种动物的神态动作；易筋经相传与天台宗菩提达摩传说相关，实际成型于明清（具体成书年代学界有争议，不必纠结）。

【现代阐释】两者核心都是**通过脊柱的屈伸、拧转带动全身筋膜**。中医讲"筋长一寸，寿延十年"是夸张的比喻，实际意思是：关节活动度好、血液循环畅，人自然舒服。

【常见误区】把导引术当成"绝世武功秘籍"去抠每一个细节、追求"气感走经络"。初学者跟着视频把动作做舒展、做顺，就已经赚到了。

## 四、动功中的安全与收功

### （1）动功的禁忌

【实修要领】

- 饭后至少隔 45 分钟再做，否则气血聚在脾胃，运动易致胃胀。
- 大风、大汗淋漓后不要立即吹空调、吹风扇——毛孔开张时最易受风。
- 动作慢、匀、舒展，不要憋气、不要用蛮力。
- 膝盖有旧伤者，八段锦中"两手攀足"等弯腰动作幅度减小即可。

### （2）收功五步法（动功后必做）

【实修要领】无论是站桩还是导引，结束时都不要一拍屁股就走。参照模块六的收功规范，做一个简化版：

```
1. 出定提醒：心里说一句"我要收功了"，做 3 次深长呼吸。
2. 干浴面：双手搓热，从下巴往上、往外洗脸 9 次。
3. 干梳头：十指弯曲当梳，从额头梳到后颈 9 次。
4. 摩腹搓腰：双手叠放肚脐，顺逆各摩腹 9 圈；再搓热后腰肾俞。
5. 拍腿散行：从大腿到小腿轻拍一遍，等麻感退去再走动。
```

【为什么必做】运动或站桩时气血趋表、心率偏快，猛然停下或吹风，容易出现头晕、鼻塞、肩紧。这三五分钟收功，是给身体一个"从运动切回日常"的缓冲。

## 五、给初学者的一周安排建议

【实修要领】给一个零门槛起步方案，照着做即可：

| 时间 | 内容 | 时长 |
|---|---|---|
| 早起后 | 八段锦一遍 | 10–12 分钟 |
| 上午工作间隙 | 站桩（从 5 分钟开始） | 5–15 分钟 |
| 晚饭后 1 小时 | 散步 15 分钟 + 站桩 | 20 分钟 |
| 睡前 | 身体扫描放松（可选） | 5 分钟 |

【现代阐释】关键不是每天练多久，而是**天天做**。站桩 10 分钟坚持半年，比一次猛练两小时然后放弃强一百倍。身体的改变是以"周"和"月"为单位的，不是以"次"。

**就医红灯提示**：练习站桩或导引时，若出现头晕、心慌、胸闷、关节刺痛，立即停止；若关节持续疼痛或运动后身体明显不适，应就医排查，不要迷信"气冲病灶、痛就对了"之类说法。

---

> **一句话总结**：道家筑基讲究"先动后静"——先用八段锦把身体活动开，再用混元桩把气血引到下盘，等身体松了、心浮降了，后面的静坐才坐得住。
