# 4. 现代人每日实修日课设计

> 本篇把前面三篇（姿势、呼吸、观心）拼成一张普通人一天能真正执行的时间表。上班族不可能像出家人那样坐两小时——所以这套日课的设计原则是：**短、碎、不断**。哪怕每天只做十分钟，连续三个月，也远胜过偶尔一次坐两小时然后放弃。
>
> **安全红线（先读）**：正在接受精神科治疗者（如精神分裂症、双相、重度抑郁焦虑）应以药物治疗和医生诊断为前提，静坐意守等练习不能替代治疗；若练习中出现幻听幻视、失眠加重、情绪剧烈波动、惊恐发作，应立即停止并就医，不得把病征当作"境界"或"业障"硬扛。

## 一、日课设计的三条底层原则

【实修要领】在看具体时间表之前，先把原则钉死——不然后面全白搭：

| 原则 | 说明 |
| :--- | :--- |
| **一、贵在不断，不在长** | 每天10分钟 × 90天 > 一天2小时 × 3天。持续性是唯一的硬指标 |
| **二、嵌入日常，不额外挤时间** | 绑在起床、开手机前、睡前这些已有动作上，不重新"找时间" |
| **三、座上修一分，座下用十分** | 日课真正的产出，是白天情绪冒头那三秒能不能停一下 |

【现代阐释】大多数人放弃修行，不是因为"没毅力"，而是一开始就把目标定成"每天打坐一小时"——这个目标对上班族根本不现实，失败几天就自我否定，然后彻底放弃。**正确做法是：先定一个"再忙也做得到"的最小剂量，把它变成习惯，再慢慢加。**

## 二、标准版日课：约40分钟，分三段

【具体步骤】这是理想情况下的完整一天：

### （1）晨起唤醒（10–15分钟）

```
时间点：起床后，排空大小便、饮半杯温水之后

内容二选一：
  □ 方案A：八段锦完整一遍（约10–12分钟）
  □ 方案B：混元桩站桩10分钟（姿势见模块五第1篇第四节）

目的：把一夜静止的身体松开，让白天的神气提起来。
注意：刚醒不要立刻猛练，先喝温水、活动关节，再开始。
```

### （2）日间"事上练"：碎片化微觉察（散在全天）

【实修要领】这部分**不占整块时间**，而是嵌入你本来就在做的动作之间：

```
□ 每次打开手机、或切换工作任务之前：
    → 做三次有觉知的深呼吸（吸—呼—吸—呼—吸—呼）；
    → 每次约15秒，一天累计十几次。

□ 情绪刚冒头的瞬间（烦躁、想争辩、想抱怨、想刷手机逃避）：
    → 先停三秒，把注意力移到胸口或呼吸上；
    → 观察身体哪里紧绷（肩？胃？下巴？）；
    → 三秒之后再开口回应、再决定怎么做。

□ 吃饭时：
    → 至少一口饭认真嚼，不看手机；
    → 这是最简单的"观食"练习。
```

【现代阐释】这三秒的"停一下"，才是日课真正的价值所在。座上练的所有"回来"，都是为了白天情绪上来这一下能用上。

### （3）晚间收摄（20–25分钟，睡前1小时）

```
时间点：晚饭后、洗漱完毕、关闭电子屏幕之后（不要躺到床上才开始）

步骤：
1. 采用端坐或散盘（见模块五第1篇），调姿；
2. 修习"数息观"或"身体扫描"15–20分钟：
    → 数息：从1数到10循环，跑了就从1重来（见模块五第2、3篇）；
    → 身体扫描：从脚趾到头顶，一处一处轻轻觉知，不评判；
3. 结束前花3分钟做儒家自省（见下）；
4. 做收功：搓热手心、摩面、轻拍全身，然后下座。
```

【实修要领】**儒家自省3分钟怎么做**——对着三个问题过一遍今天：

```
□ 今天处事，有没有尽心？（答应的事做到了吗？该负责的推了吗？）
□ 今天待人，有没有真诚？（有没有说违心话？有没有背后议论人？）
□ 今天起心动念，有没有偏？（有没有嫉妒？有没有占便宜的念头？）

发现问题：不写检讨、不自责，只是"知道"——这就是《了凡四训》讲的
"耻心、畏心、勇心"最平实的日常用法（见模块四儒家日课篇）。
```

## 三、迷你版日课：10分钟，再忙也做得到

【实修要领】加班、出差、生理期、生病、心情低落——任何"今天实在不行"的日子，用这一版。**它存在的唯一目的，就是让你不断。**

```
早晨（3分钟）：
  □ 站在原地，三次深长呼吸 + 十个缓缓的扩胸伸展。

日间（2分钟，至少一次）：
  □ 情绪冒头时，停三秒，把注意力放到呼吸上。

晚上（5分钟）：
  □ 端坐床上或椅子上，数息5分钟；
  □ 一句话自省："今天有没有一件事，我可以做得更好？"
  □ 搓手摩面，睡觉。
```

【现代阐释】迷你版的关键不是"练了多少"，而是**"今天我没断"**。这个"没断"的连续性，比内容重要十倍。

## 四、两套方案对比：你该用哪套

| 维度 | 标准版（约40分钟） | 迷你版（约10分钟） |
| :--- | :--- | :--- |
| 适合日子 | 正常上班、周末 | 加班、出差、生病、情绪低谷 |
| 晨起 | 八段锦/站桩10–15分钟 | 三次呼吸+简单伸展3分钟 |
| 日间 | 多次微觉察、情绪三秒停 | 至少一次情绪三秒停 |
| 晚间 | 数息/身体扫描15–20分钟+自省3分钟+收功 | 数息5分钟+一句话自省 |
| 心理定位 | "正式练" | "只是别断" |

【实修要领】**灵活切换，不要硬撑标准版**。今天状态差就切迷你版，这不是偷懒，是可持续。连续三个月"标准+迷你混搭"，比发誓"每天一小时"失败两周要强得多。

## 五、一周日课表样例

【具体步骤】照着填一周试试：

| 星期 | 晨起 | 日间 | 晚间 |
| :--- | :--- | :--- | :--- |
| 一 | 八段锦 | 三次深呼吸×3 | 数息15分钟+自省 |
| 二 | 站桩10分钟 | 情绪三秒停×2 | 身体扫描15分钟+自省 |
| 三 | 八段锦 | 三次深呼吸×3 | 迷你版5分钟 |
| 四 | 站桩10分钟 | 情绪三秒停×2 | 数息15分钟+自省 |
| 五 | 八段锦 | 三次深呼吸×3 | 数息15分钟+自省 |
| 六 | 八段锦（可稍久） | 全天觉察放松 | 身体扫描20分钟+自省 |
| 日 | 休息/散步 | 一天里记得几次深呼吸就好 | 5分钟数息+自省 |

【现代阐释】注意这张表里**没有"每天必须怎么样"的死规定**——周三故意留了迷你版，周日故意放松。日课不是另一份KPI，是一种照顾自己的节奏。

## 六、常见障碍与纠偏

【常见误区】

| 障碍 | 表现 | 纠偏方法 |
| :--- | :--- | :--- |
| **"没时间"** | 每天都说等周末再补 | 立刻切迷你版，哪怕只做3分钟；不断比补做重要 |
| **"坐完更累"** | 上座就昏沉、下座腰酸 | 缩短时间到10分钟，检查姿势、别吃太饱、别坐太暖 |
| **"情绪上来来不及停"** | 事后才反应过来刚才又炸了 | 正常——先练"事后复盘"，再慢慢练"事中停"，急不来 |
| **"做了一周没感觉"** | 期待马上变平静 | 至少给三个月；检验标准是三个月后身边人说你变了，不是一周后 |
| **追求"境界"** | 等某次特别静、特别舒服的体验 | 不要追；那是副产品，追它就乱（见模块五第2、3篇） |

## 七、反迷信与边界

【现代阐释】日课设计上最常见的两种骗局：

- **"21天开悟营""49天闭关班"**——收高价、包承诺、让你辞掉工作去山里。正信修行不打包票，也不靠关门速成。
- **"必须按这个时辰、这个方位、这个手势才有效"**——把日课做成繁琐仪轨，制造你的焦虑和依赖。真正的日课简单到你在酒店、在出差、在病房都做得到。

**检验标准始终只有一个**：三个月后，下座的你——情绪更稳一点？待人更缓一点？处事更清醒有担当一点？这三条有任何一条在往好的方向走，你就没白练；如果一条都没有，把日课重新读一遍，看看是不是漏了"事上练"那一段。

---

> **一句话总结**：日课不是任务表，是照顾自己的节奏——早晨松开身体，白天停三秒，晚上收摄自省；贵在不断不在长，三个月后那个更稳的你，就是全部成果。

### 参考来源

- 儒家《大学》"吾日三省吾身"（语出《论语·学而》，曾子之言），日课自省所本。
- 《了凡四训》（明·袁了凡），论改过三心——耻心、畏心、勇心。
- 《童蒙止观》（智者大师），论晨间、初夜用功与日常调心。
- 传统《八段锦》歌诀（宋代以来流传），本篇仅借其晨练导引之意，不作任何医疗功效表述。
- 圣严法师《禅修指引》《圣严法师教禅坐》（法鼓文化），论现代人日常禅修安排（大意引述）。
- 南怀瑾《静坐修道与长生不老》（老古文化），论收功、日常作息与调息（大意引述）。
