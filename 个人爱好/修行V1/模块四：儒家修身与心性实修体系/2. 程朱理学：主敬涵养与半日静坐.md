# 2. 程朱理学：主敬涵养与半日静坐

> 宋明理学不是"存天理灭人欲"那种被误解的口号，它是一套可操作的心性功夫。程朱一系的核心功夫是两个字："敬"和"静"——程颐讲"涵养须用敬，进学则在致知"，朱熹门下把它落到每日作息上，叫"半日静坐，半日读书"。本篇把"主敬"拆成内外两面，把"半日静坐半日读书"改造成现代人能执行的作息。
>
> **安全红线（先读）**：正在接受精神科治疗者（如精神分裂症、双相、重度抑郁焦虑）应以药物治疗和医生诊断为前提，静坐意守等练习不能替代治疗；若练习中出现幻听幻视、失眠加重、情绪剧烈波动、惊恐发作，应立即停止并就医，不得把病征当作"境界"或"业障"硬扛。

## 一、"主敬"二字：儒家不是只靠道德说教

【经典依据】《河南程氏遗书》（程颐语）："涵养须用敬，进学则在致知。"朱熹把这两句定为学者两大纲领："大凡学者，无爵禄职位之拘，则合半日读书，半日静坐以验之。"（大意引述）

【现代阐释】很多人以为儒家修心就是"你要做好人"，这是把伦理学当成了空话。程朱之所以了不起，是因为他们给"做好人"配了一个可操作的心法——"敬"。敬不是对谁恭敬，是**自己对自己的心保持一种收摄、郑重的状态**。

### （1）内：主一无适

【经典依据】程颐解释"敬"："主一之谓敬。""无适之谓一。"——心主于一处，不东张西望，就是敬。

【实修要领】"主一无适"翻译成现代话：**做一件事的时候，心就在这件事上**。吃饭就吃饭（尝到味道），回邮件就回邮件（想清楚措辞），听人说话就真听（而不是在想自己待会儿说什么）。

```
□ 每次开始一件事，先停三秒，心里说一句："现在就做这一件。"
□ 发现走神了，不骂自己，温和地把心拉回手头这件事。
□ 一天下来数一下：今天"主一"成功了几次？拉回来几次？
  拉回来的次数，就是功夫在长的证据。
```

【现代阐释】这和佛家修止是同一个道理（见模块三第1篇）：功夫不在"不想事"，在"回来"。朱熹自己也说，人怎能无念？只是"念有邪正"，主敬就是把念收在该在的地方。

### （2）外：整齐严肃

【实修要领】程朱讲的"敬"从来不是只在心里头，它必须从身体上表现出来：

| 外相 | 具体做法 | 对心的作用 |
|---|---|---|
| 衣冠端正 | 在家办公也穿戴整齐，不穿睡衣开一天会 | 身体端正，心自然不轻浮 |
| 坐立如斋 | 坐不歪靠、站不驼背 | 体态是心态的外壳 |
| 步履稳重 | 走路不慌不忙，不拖着鞋走 | 身忙脚乱，心必浮躁 |
| 神色不变 | 不轻易嬉皮笑脸、不轻易失态 | 收住外放的神气 |

【现代阐释】这不是讲排场。心理研究早就发现：体态和表情会反过来影响情绪（具身认知）。你把背挺起来、把衣服穿整齐，那股"随便"的劲儿会先松下来。程朱八百年前就懂这个道理，所以他们不讲"你要开心"，而讲"你先坐正"。

【常见误区】把"整齐严肃"练成刻板、端着、家人都不敢靠近你。朱熹的意思是"收敛"，不是"僵硬"。真正主敬的人，外人看着是稳重可亲，不是一身冷气。

## 二、"半日静坐，半日读书"：程朱版的日课结构

【祖师开示】朱子门人记载，老师常教："每日半日静坐，半日读书，如此三年，何事不办？"（大意引述）这不是要你脱产，是说一天的功夫要**两边都有**：一边把心养静，一边把理讲明，缺一不可。

### （1）为什么必须"静坐"配"读书"

【现代阐释】程朱和王阳明后来最大的分歧，就在这里。程朱认为：只静坐不读书，容易坐成"枯木禅"——心是静了，但一遇事还是糊涂；只读书不静坐，道理是懂了，但心浮气躁，道理全在嘴上，落不到身上。所以必须**涵养（静坐、主敬）和进学（读书、穷理）两只脚走路**。

| 偏废 | 表现 | 结果 |
|---|---|---|
| 只静坐不读书 | 每天坐一小时，坐完还是不会处理事 | 静是"枯静"，遇事即乱 |
| 只读书不静坐 | 经史读了一堆，张口就来 | 理是"口头禅"，心还是乱的 |
| 静书并重 | 坐时养未发之中，读时穷事物之理 | 心有定盘星，又有真见识 |

### （2）"半日"在今天的现代版作息建议

【实修要领】古人"半日"是因为他们本来就以读书求道为业。现代上班族不可能真的分出六小时静坐读书。把"半日"按比例压缩，落到可执行的最小单元：

```
【早晨·20分钟主敬涵养】
  5分钟：端坐或站立，什么都不做，觉察呼吸与身体（体会未发之中）
  15分钟：读一段儒家典籍（《论语》《大学》《近思录》），
          不求多，就读一章，合上能讲出一句今天怎么用。

【白天·每两小时一次"主一"微练习】
  手头这件事开始前停三秒，心收回来再做。

【晚上·20分钟静坐省察】
  先静坐10分钟（或散步慢走），再花10分钟写当日复盘：
  今天哪件事心散了？哪个念头不正？明天要注意什么？
```

【常见误区】一上来就要求自己每天静坐一小时、读书一小时，三天就放弃。程朱的"半日"是理想态，**先从每天10分钟开始，能坚持三个月，比什么都强**。

【纠偏方法】断了几天怎么办？不要自责"我怎么这么没用"，第二天直接从10分钟重新接上。主敬的功夫，怕的不是断，是断了之后连自己都不看了。

## 三、静坐具体怎么做：体会"喜怒哀乐未发之前的气象"

【实修要领】程朱一系的静坐，不是数息，不是观想，核心是**体会"未发之中"——情绪还没被任何事勾起来之前，心本来的那个样子**。做法如下：

### （1）步骤

```
1. 坐正：椅子前三分之二，脚平放，手放腿上，脊柱自然竖直，
   不憋气、不挺胸过度。
2. 先观察：此刻我心里在想什么？身体哪里紧？只是看着，不赶。
3. 进入"未发"：让心停在"还没有任何情绪起伏"的那个状态里。
   不追求什么体验，只是安安稳稳地坐。
4. 妄念来了：知道"念头来了"，不追、不压，让它自己过去，
   回到"安稳坐着"这件事上。
5. 下座前：搓搓手、搓搓脸，慢慢动一动，不要一起身就猛冲。
```

### （2）时间与时长

- 初学每天10分钟即可，最多不超过30分钟。
- 早起后最好（心还没被一天的事搅乱）；晚上也可，但严重失眠者晚上不要独坐太久，可改成身体扫描后直接睡（失眠问题请遵医嘱）。
- 吃饱、喝醉、刚发完脾气——不要上座。

### （3）出现这些情况，立即停止并就医

【实修提示】静坐是养心的练习，不是治病手段。出现下列任何一种情况，不要硬扛，不要把它当成"气脉发动""境界现前"：

- 幻听、幻视、被人控制感；
- 失眠明显加重、连续彻夜难眠；
- 情绪剧烈波动、惊恐发作、无故大哭大怒；
- 头部持续紧绷胀痛、血压骤升。

**有精神心理疾病史者，一切以精神科医生诊断与药物治疗为准**；本练习只是辅助身心调养，不能替代治疗。

## 四、读书穷理：读什么、怎么读

【实修要领】程朱讲"进学在致知"，读书不是看热闹，是**从书里找自己当天能改的那一条**。

| 阶段 | 推荐书目 | 读法 |
|---|---|---|
| 入门 | 《论语》《大学》《中庸》 | 每天一段，能背诵最佳；读完问：今天我哪件事可以用这一条？ |
| 进阶 | 《近思录》（朱熹、吕祖谦编） | 宋儒语录分类，全是修身实战经验 |
| 再进 | 《朱子语类》 | 朱子和弟子的问答，最见功夫细节 |

【具体步骤】每读一段，做三件事：
1. 原文是什么（搞懂字面）。
2. 它说的是人的哪种毛病（对号入座）。
3. 明天遇到类似场景，我具体怎么做（落到一件事上）。

【现代阐释】朱熹自己讲读书法："读书譬如饮食，从容咀嚼，其味必长。"（大意引述）读一百条而不改一条，不如读一条而真改一件事。

## 五、程朱一路的边界与检验标准

【现代阐释】最后必须划清三条线：

1. **不是禁欲主义**："存天理灭人欲"灭的是"过度的、自私的欲望"，不是正常的饮食男女。朱熹自己也讲"饮食者，天理也；要求美味，人欲也"（大意引述）。
2. **不是读经迷信**：儒家实修和算命、看风水、求灵签、拜文昌求考试及格毫无关系。把孔子当神拜、烧香求保佑，是民间宗教，不是程朱的功夫。
3. **检验标准在座下**：你静坐读书三个月，真正的成绩是——
   ```
   □ 遇事先能坐得住三秒，再开口；
   □ 答应的事，更能记得、更能做到；
   □ 家人发现你脾气软了、不是压着，是真的松了；
   □ 没有变得看谁都不顺眼、觉得自己"有修养别人都俗"。
   ```

---

> **一句话总结**：主敬是"内主一无适、外整齐严肃"，静坐养未发之心，读书穷应事之理——两边并进，功夫才不会落空；检验它的，永远是你下座之后待人处事的那个样子。
