# 4. 儒家日常日课：省察与改过

> 前面三篇讲的是儒家修心的道理和流派，这一篇讲"每天具体怎么做"。儒家把功夫落在两件小事上：曾子的"吾日三省吾身"，和袁了凡在《了凡四训》里系统讲的"改过三法"与功过格。本篇把它们改造成现代上班族能打印、能执行的每日自省表。
>
> 本篇若配静坐省察使用，**有精神心理疾病史者以医嘱为准，练习中出现幻听幻视、失眠加重、情绪剧烈波动、惊恐发作立即停止就医**。

## 一、曾子三省：最古老的晚间复盘模板

【经典依据】《论语·学而》："曾子曰：吾日三省吾身——为人谋而不忠乎？与朋友交而不信乎？传不习乎？"

【现代阐释】这三句话，是中国历史上第一份、也是最干净的"每日复盘模板"。曾子每天睡前问自己三个问题：

| 曾子原话 | 现代翻译 | 对应现代生活 |
|---|---|---|
| 为人谋而不忠乎 | 替人办的事，我尽心了吗？ | 工作任务、答应别人的事，是敷衍了还是真尽力了？ |
| 与朋友交而不信乎 | 跟人交往，我守信用了吗？ | 说了几点到就几点到；答应回的消息回了没？ |
| 传不习乎 | 学来的道理，我真照着做了吗？ | 这几天读的、听的道理，有没有一条落到行动上？ |

【实修要领】注意这三问全是**对着"我自己"发问**，不是问"别人对我怎么样"。儒家日课的全部秘密就在这里：把审视的镜头，从"外境"转回到"我这一天的身、语、意"。

【具体步骤】睡前两分钟，直接照下面这个模板走一遍：
```
【今日三省】
1. 为人谋：今天我答应别人/被安排的事，哪一件是敷衍过去的？
   → 具体那件事是______。明天怎么补？______。
2. 与朋友交：今天有没有说话不算话的地方？
   → 是______。下次怎么改？______。
3. 传不习：这几天我知道的道理（早睡、少刷手机、好好说话……），
   今天哪一条没做到？
   → 是______。明天具体怎么做？______。
```

## 二、改过三法：耻心、畏心、勇心

【经典依据】明代袁了凡在《了凡四训·改过之法》中提出：改过者，第一要发**耻心**，第二要发**畏心**，第三要发**勇心**。三心俱发，则有过斯改，如春冰遇日，何患不消乎？（原文大意）

【现代阐释】袁了凡这个人本身就是个反迷信的故事：他早年被算命先生算定一辈子的功名、俸禄、无子，后来他按云谷禅师教的"功过格"每天记善恶、努力改过，命运全改了——**他用这本书证明的不是"算命准"，而是"人能改命"**。这一点要先讲清楚，免得有人把《了凡四训》当成算命书来读。

### （1）耻心：知耻近乎勇

【实修要领】耻心不是羞耻、不是自责到想死，是**看见自己那个老毛病时，心里"咯噔"一下：我怎么又这样？**

```
□ 今天又因为一件小事冲家人发火了——咯噔：我这样跟我讨厌的
  那种人有什么区别？
□ 今天又拖延到半夜才干活——咯噔：我这是在浪费自己的日子。
```

【纠偏方法】注意：耻心发完就要转成行动，**不能停在自我攻击上**。自责一百次不改一次，那不是耻心，是内耗。耻心的下一步，永远是勇心。

### （2）畏心：敬畏因果、敬畏良知

【实修要领】"畏"不是怕鬼神惩罚，是三层敬畏：

```
1. 敬畏因果：今天说的一句伤人的话，迟早会以某种方式回来；
   今天偷的一次懒，迟早要还。
2. 敬畏良知：那个"咯噔"你骗不了自己——可以骗全世界，骗不了
   自己心里那一下。
3. 敬畏他人：那件没人看见的小事，其实都在塑造你是个什么样的人。
```

【现代阐释】所以《了凡四训》讲"暗室屋漏之中，常如面对帝天"——不是真的有天帝在看，是**你自己在看自己**。这和《大学》的"慎独"是同一回事（见本模块第1篇）。

### （3）勇心：像毒蛇咬手指一样立刻切

【经典依据】袁了凡原话大意：改过如"毒蛇啮指"——手指被毒蛇咬了，你不会犹豫，立刻拿刀砍掉。发现自己一个老毛病又冒头，就要这样当机立断，不找借口、不拖延、不"明天再说"。

【具体步骤】发现自己正要犯老毛病的那个瞬间：
```
□ 话到嘴边要伤人——停三秒（勇心的"勇"，是敢停）。
□ 手要伸出去拿不该拿的东西——立刻收回来。
□ 心里又要开始反复回放别人那句话——直接起身，倒杯水/走两步。
```

【常见误区】把"改过"理解成一次大彻大悟、以后永不再犯。真相是：**同一个毛病，你会改一百次**。今天比上次早三秒觉察到，就是进步。

## 三、功过格：现代版每日善恶记账

【经典依据】功过格是袁了凡系统推行的日课工具：每天把做的善事、恶事按轻重记账（善记功、恶记过），月底结算。这东西看似古老，其实是最硬核的自我量化工具。

【实修要领】现代版不必照搬"日行一善记几分"的旧格式（那套分值容易变成功利计算），但**记账这件事本身极其有用**。给你一张可以直接打印或抄写的现代版：

### （1）每日自省表（可打印版）

```
═══════════════════════════════════════
        每日自省表  ·  日期：____年__月__日
═══════════════════════════════════════

【一、今日三省】（曾子模板）
1. 为人谋而不忠乎？
   敷衍的一件事：____________________
2. 与朋友交而不信乎？
   说话不算数的地方：________________
3. 传不习乎？
   今天没做到的那条道理：____________

【二、今日善的三件小事】（大小都算）
1. ________________________________
2. ________________________________
3. ________________________________

【三、今日过的三件小事】（不自责，只记录）
1. 哪句话/哪个念头/哪个行为：________
   背后的私心是：____________________
2. ________________________________
3. ________________________________

【四、改过三心自检】
□ 耻心：今天看到自己老毛病时，有没有"咯噔"一下？
□ 畏心：有没有在"没人看见"的地方也守了分寸？
□ 勇心：发现要犯老毛病时，有没有当场停住？

【五、明天一件具体的事】
明天我要在____________这件事上，
做到：____________________________

【六、今日检验座下功夫】
情绪失控次数：__ 次
对家人/同事态度：□比昨天好 □一样 □更差
今天有没有"事后拍大腿"：________________
═══════════════════════════════════════
```

### （2）怎么用这张表

【具体步骤】
1. 打印30张，放床头。
2. 每晚睡前5分钟填，**不许拖到第二天**——拖了就忘了。
3. 写"过"的时候**不自我批评**，只记录事实和背后的私心。自我攻击会让人第二天再也不想填。
4. 每周日晚上回看一周的表，找**重复出现的那个毛病**——那就是你下一阶段主攻的事。

【现代阐释】功过格的核心价值不是"积德"，是**让你看见自己每天在哪些小地方漏**。你会发现：大错很少，全是小漏——一句不耐烦的话、一次拖延、一次明知该发的消息拖着不发。这些小漏，一年下来就是你的人生。

## 四、配合静坐省察的一种简易用法

【实修要领】这张表可以直接干填；如果愿意，也可以在填表前先静坐或慢走5分钟，让心先收一收再写。做法：

```
1. 坐下/站定，5次深呼吸。
2. 从今天早上第一件事开始，像放电影一样过一遍这一天。
3. 哪一幕心里有波动（高兴或不舒服），就停在那一幕，
   在表里记下来。
4. 不评判，只是"看见"。
```

【实修提示】这只是收心的五分钟，不是复杂的打坐。**有精神心理疾病史者以医嘱为准；如果填表、回想过程中出现情绪剧烈波动、惊恐发作，立刻停止，喝温水、离开桌面，必要时联系主治医生**。不要把回想童年阴影、反复自我剖析当成日课目的——儒家省察只问"今天的事"，不问"我为什么会这样"。

## 五、儒家日课的边界：不是道德绑架，更不是算命

【实修提示】最后划三条线：

1. **不是自责大会**：填这张表的目的是"看见+改下一件"，不是把自己批倒批臭。哪一天表里全是"过"、没有一条"善"，说明你已经在自我攻击了——第二天先不写过，先写三善。
2. **不是功利账本**：不要算"我今天积了几分善，明天会得什么好处"。袁了凡自己说，功过格的真意是**养这颗改过的心**，不是换世俗回报。
3. **不是算命、改运术**：《了凡四训》反的就是"命由天定"。它讲的是"命由我作，福自己求"（原文大意）——这是中国典籍里最彻底的一句话：**你的命不是算出来的，是你每天这五个小时、这三句话、这一张表，一笔一笔写出来的**。

【现代阐释】所以儒家日课和迷信最大的区别就在这里：它不要求你信任何神，只要求你**对自己诚实**。这是它最大的理性底色。

---

> **一句话总结**：睡前五分钟，用曾子的三问看自己，用袁了凡的耻心、畏心、勇心去改下一件事——功夫不在多大，在每天那张表里你敢不敢对自己诚实。
