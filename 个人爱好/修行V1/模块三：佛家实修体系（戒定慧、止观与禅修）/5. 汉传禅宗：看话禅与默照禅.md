# 5. 汉传禅宗：看话禅与默照禅

> 禅宗是汉传佛教最有特色的一脉。到了宋代，禅宗内部发展出两种影响深远的禅法：临济宗大慧宗杲的**看话禅**（参话头），和曹洞宗宏智正觉的**默照禅**。这两种都是高阶止观，不适合没有定力基础的初学者贸然模仿。本篇讲清它们的来历、怎么操作、适合谁，以及——最重要的——为什么它们不是"开天眼"，为什么座上出现的光影境界不是开悟。
>
> **安全红线（先读）**：正在接受精神科治疗者（如精神分裂症、双相、重度抑郁焦虑）应以药物治疗和医生诊断为前提，静坐意守等练习不能替代治疗；若练习中出现幻听幻视、失眠加重、情绪剧烈波动、惊恐发作，应立即停止并就医，不得把病征当作"境界"或"业障"硬扛。

## 一、禅宗的底色：不立文字，直指人心

【经典依据】相传灵山会上，佛拈花，迦叶微笑——禅宗由此肇始。达磨祖师西来，六祖慧能《坛经》确立"明心见性"宗旨。禅宗不重繁琐义学，强调**直接在当下一念上用功**，亲见自家本来面目。

【现代阐释】对普通人而言，禅宗最大的价值是：**它把"修行"从念经拜佛拉回到当下这一念**。你不需要懂多少佛学，只需要学会在每一个当下，清清楚楚、不跟着念头跑。

## 二、看话禅：大慧宗杲与参话头

### （1）历史渊源

【祖师开示】南宋临济宗**大慧宗杲禅师**（1089–1163），痛感当时学人把禅当成"默照"、落于枯寂，遂大力提倡"看话头"。他最著名的话头是"狗子还有佛性也无？"——赵州和尚答"无"，大慧叫学人死死盯住这个"无"字。

【经典依据】大慧宗杲《大慧普觉禅师语录》中反复开示：但将妄想颠倒心、思量分别心、好生恶死心，一齐放下，只看个"无"字（大意引述）。

### （2）怎么参

【实修要领】选一句无义味的话头（无意义、无法用逻辑推理回答的句子），常用的有：

```
□ "念佛是谁？"
□ "拖死尸的是谁？"
□ "父母未生之前，如何是我本来面目？"
□ "赵州狗子还有佛性也无？——无"
```

操作要点：
1. **不是找答案**——不要在脑子里推理"是谁""是什么"；
2. 在话头**生起之前**的那个源头处，提起一个"疑情"：不懂、不解、全神贯注地"是个什么？！"；
3. 这个疑情要**像一团疑团堵在胸口**，吃饭也是它、走路也是它、睡觉也是它；
4. 其他妄念来了，不要赶，都收归到话头上——以一念（疑情）抵万念。

### （3）大疑情怎么起

【实修要领】初学者最容易把"参话头"变成"念话头"——嘴上或心里反复念"念佛是谁念佛是谁"，那只是持咒，不是参。**疑情**的标志是：

- 不是"念"，而是"堵"——胸口像吞了一个东西，吐不出咽不下；
- 不是"想答案"，而是"整个生命都在追问"；
- 行住坐卧，这个疑团不散。

【祖师开示】大慧宗杲说："疑情生时，如吞了个热铁丸相似，吐也吐不出，咽也咽不下。"——这是描述，不是让你真难受。疑情起得对，人是又紧又清明的，不是昏沉的。

### （4）什么叫"桶底脱落"

【现代阐释】当疑团凝到极处，某天因缘聚会（可能是听见一声、看见一花、被人一棒），疑团啪地一下碎掉——那一瞬间能观所观双忘，本地风光显现，古人叫"明心见性""桶底脱落"。

【反迷信提醒（必读）】
- 这是极少数人、长期大精进后才可能出现的经验，**不是打坐追求就能有的，更不是光靠念句子念出来的**；
- **参禅中出现的一切光影境界——看见光、看见佛菩萨、听见声音、身体轻飘、觉得自己开悟了——统统不是开悟**。那只是久坐后身心变化产生的现象，和昏沉、掉举一样，是路上的风景；
- 把光影当开悟，到处跟人讲"我见佛了""我开悟了"，禅宗祖师叫这个"口头禅""野狐精"，是走偏的开始。

## 三、默照禅：宏智正觉与默而常照

### （1）历史渊源

【祖师开示】与大慧宗杲同时代的曹洞宗**宏智正觉禅师**（1091–1157），提倡"默照禅"。他在《默照铭》中说："默默忘言，昭昭现前。"

【现代阐释】默照不立话头。坐下来之后：
- **默**：不随妄念流转，不追过去、不攀未来，所有念头来了，不跟它走，也不压它；
- **照**：同时保持清清楚楚、历历分明的觉知——像一面镜子，物来则应，物去不留。

### （2）"默而常照"怎么理解

【实修要领】初学者最容易把默照坐成两块：

| 偏差 | 表现 | 纠正 |
|---|---|---|
| **只默不照** | 昏沉、发呆、坐成木头 | 提起觉知，眼微睁，肩膀松而神不外散 |
| **只照不默** | 念头乱飞，跟着编故事 | 回到"不随"——知道它来了，不跟 |
| **默照双修** | 念头来来去去，自自然然，知道得清清楚楚，又不粘着 | 这才是正位 |

【现代阐释】用现代话说，默照就是一种"无选择的觉知"：不刻意抓某个所缘，只是让心清清楚楚地安住着，任何身心现象经过都知道，但不被卷走。和四念处（见模块三第4篇）相通，只是更"松"、更不费力。

## 四、两种禅法对比

| 维度 | 看话禅 | 默照禅 |
|---|---|---|
| 创立者 | 大慧宗杲（临济宗） | 宏智正觉（曹洞宗） |
| 所缘 | 一句无义味话头 | 不立所缘，纯任觉知 |
| 用心 | 紧——提起大疑情 | 松——默而常照 |
| 对治 | 妄念纷飞、分别太重的人 | 心思细腻、 Already 比较静的人 |
| 风险 | 太紧张——胸闷、失眠 | 太松——落入枯定昏沉 |
| 适合人群 | 思维活跃、妄念多的知识分子 | 性格沉静、已有禅坐基础者 |

【祖师开示】大慧宗杲当年批评默照禅是"堕在黑漆桶里"，宏智一系反过来看话头是"扬眉瞬目"。**两家之争，本质是对机不同**——没有哪个更高明，只看哪个适合你当下的状态。

## 五、重要忠告：高阶法门，不可抢跑

【实修要领】看话禅和默照禅，都是建立在**相当的定力基础**上的高阶功夫。

```
抢跑的典型表现：
□ 从没正经数过息，上来就参话头
□ 没坐过三个月稳定坐垫，直接学默照
□ 把"不打妄想"当成目标，硬压念头
□ 一有什么体验就觉得自己"见性了"
```

【纠偏方法】老老实实从数息开始（模块三第3篇），先能稳定坐 30 分钟、心不散乱，再谈参话头或默照。这一步省不掉。

【祖师开示】历代禅宗大德（包括虚云老和尚）都反复强调：**参禅的基础是"二十本日课"、是长期打坐功夫、是持戒清净**。没有这些，一切高深法门都是空中楼阁。

**就医红灯提示**：参禅或默照过程中，若出现持续幻听幻视、分不清定中体验与现实、情绪持续剧烈波动、惊恐发作——立即停止练习并就医。定中出现的光影与病征之间，普通人很难自己判断，稳妥起见：**只要影响到日常生活，就找医生，不要找"师父"**。

## 六、禅宗与迷信的边界

【反迷信提醒】社会上把禅宗和下列东西混在一起的，全部是附佛外道或商业骗局：

- 把"开悟"包装成高价课、闭关营、加持费；
- 声称"师父有神通""他看你一眼就能给你消业"；
- 用"本来面目""本来清净"作为不听医嘱、不吃药的理由；
- 搞崇拜式的师生关系——不许质疑、必须奉献。

【检验标准】正信的禅宗师父，一定叫你**先做人、先持戒、先老实打坐、先去看病吃药**。除此之外都要警惕。

---

> **一句话总结**：看话禅用一个大疑情把万念收住，默照禅在松坦中保持清明——都是高阶止观，前提是先把数息的基本功坐扎实；座上任何光影都不是开悟，下座后待人更清醒慈悲，才是真消息。
