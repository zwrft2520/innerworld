# 4. 资料库备注栏

本资料库用于知识整理和科普，不构成诊断、用药或法律意见，不能替代精神科就诊、急诊评估或当地正式政策解释。内容可能过时，使用前应核对原始来源和发布日期。

## 资料条目记录模板

每项重要结论可按以下格式记录：

- **主题/结论：**
- **资料类型：**指南 / 系统综述 / 临床试验 / 观察研究 / 基础研究 / 个人经验
- **来源与版本：**
- **发布日期或研究年份：**
- **访问日期：**
- **研究对象与适用范围：**
- **主要结果：**
- **证据局限与不确定性：**
- **利益冲突或资助信息：**
- **是否适用于常规临床：**是 / 否 / 尚不确定
- **下次复核日期：**

## 内容维护原则

1. 关键医学结论附可核实的原始来源；网页资料保留访问日期。
2. ICD、DSM 和临床指南注明版本，避免把旧版内容当作现行标准。
3. 将指南建议、研究关联、理论假说和个人经验分开表述。
4. 对未定论结果明确注明：**“尚在研究，未用于常规临床”**。
5. 不公布患者可识别的病史、照片、联系方式或未经授权的经历。
6. 发现错误或新指南时，记录修改日期和修改原因，避免静默替换重要结论。
7. 涉及法律、医保、残疾评定和求助热线的信息，应标明适用地区并定期向官方渠道核验。
