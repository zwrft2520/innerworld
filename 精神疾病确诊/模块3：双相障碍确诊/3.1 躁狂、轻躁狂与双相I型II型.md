# 3.1 躁狂、轻躁狂与双相I型II型

双相障碍的名字容易让人以为就是“抑郁加高兴”，但诊断的关键在“发作”：一段持续几天到几周、明显不同于平时的情绪和精力改变。这一页讲躁狂与轻躁狂的时间门槛、功能影响和精神病性症状，以及双相 I 型与 II 型怎么分。适合被诊断为抑郁但怀疑自己有过“高涨期”的人，也适合想理解“轻躁狂为什么算病”的家属。

## 一、躁狂与轻躁狂：同一条线上的两个刻度

躁狂和轻躁狂共享同一组症状，区别在**持续时间、功能影响和有没有精神病性症状**。

| 维度 | 轻躁狂 | 躁狂 |
|---|---|---|
| 持续时间 | 连续至少四天，大部分时间 | 至少一周，或短于一周但因病情严重需住院 |
| 变化程度 | 明显不同于平时，别人能看出来 | 明显异常，常导致功能严重受损 |
| 功能 | 通常不造成严重损害，不需要住院 | 工作社交严重受损，或需住院 |
| 精神病性症状 | 没有 | 可以有，如夸大、被害妄想 |
| 自知力 | 常觉得“我很好”，不认为有病 | 常明显受损 |

【指南】DSM-5-TR 对躁狂要求持续至少一周、几乎每天大部分时间，并且造成明显功能损害、需要住院，或伴精神病性症状；轻躁狂则要求连续至少四天，变化能被他人观察到，但没有明显功能损害、不需要住院、没有精神病性症状。ICD-11 的表述略有差异，实际判断以原文和医生访谈为准。

时间门槛只是入口，不是全部。有的人症状只持续三天，但严重到需要住院，仍可能按躁狂处理；有的人持续一周，但功能基本维持，医生会仔细区分。**不要用“有没有满七天”自行判断。**

## 二、不只是“高兴”：症状群怎么组合

躁狂的核心不只是情绪高涨，还包括**精力或目标性活动明显增加**。情绪可以是高兴、过度自信，也可以是易怒、一点就着。很多患者并不觉得“快乐”，而是烦躁、停不下来、睡不好。

常见的症状群包括：

- **自我评价膨胀**：觉得自己能力超群、有特殊使命，别人都不懂；
- **睡眠需求减少**：只睡三四个小时也不困，不是失眠后疲惫，而是“睡够了”；
- **话多、语速快**：停不下来，别人插不上嘴，电话打很久；
- **思维奔逸**：想法一个接一个，自己觉得“脑子转得特别快”；
- **注意力易转移**：说到一半就换话题，容易被外界小事带走；
- **活动增多**：同时开很多项目，走路快、动作多，静不下来；
- **冒险行为**：大手笔花钱、投资、赌博、危险驾驶、性行为失控。

这些症状要一起看，不能单凭“话多”或“睡得少”下结论。一个人平时就外向、话多，和“明显不同于平时”是两回事；一个人熬夜赶工，第二天累得不行，也不等于睡眠需求减少。**判断的参照系是“他平时的样子”和“别人有没有觉得他变了”。**

## 三、双相 I 型与 II 型

| 维度 | 双相 I 型 | 双相 II 型 |
|---|---|---|
| 必要条件 | 至少一次躁狂发作 | 至少一次轻躁狂发作，加至少一次重性抑郁发作 |
| 是否有躁狂 | 有 | 从来没有 |
| 抑郁发作 | 可有可无 | 必须有 |
| 常见误解 | “I 型更轻” | “II 型更轻” |
| 功能影响 | 躁狂期可能严重受损、住院 | 轻躁狂期功能相对保留，但抑郁期损害常很重 |

**双相 I 型**的诊断门槛是“至少一次躁狂发作”，不要求一定有抑郁发作。也就是说，一个人可能只出现过躁狂，没有明显的抑郁期，仍然可以诊断为双相 I 型。躁狂可以伴精神病性症状，也可能需要住院。

**双相 II 型**要求至少一次轻躁狂发作和至少一次重性抑郁发作，并且从来没有过躁狂发作。它常被误认为“比较轻的双相”，这是不准确的：II 型的轻躁狂确实不造成严重功能损害，但抑郁发作往往频繁、功能负担重，自杀风险并不低，功能损害也可能很重【指南】。**不要因为“只是 II 型”就掉以轻心。**

还有一种情况是“环性心境”：长期在轻躁狂样和抑郁样之间波动，但达不到发作标准，持续两年以上（儿童青少年一年以上）。它不属于 I 型或 II 型，但同样会带来功能损害，详见 3.3。

## 四、病程、功能与需要排除的情况

双相障碍通常是发作性的：一段时间明显偏离基线，之后回到接近平时的状态，也可能留下一些残留症状。发作频率、发作间期能不能完全恢复、有没有快速循环（一年四次以上）、有没有混合特征，都会影响诊断标注和治疗方向。

功能损害要看具体场景：躁狂期可能把积蓄花光、丢掉工作、破坏关系；轻躁狂期可能“看起来效率很高”，但事后发现决定草率；抑郁期则可能无法工作、卧床、回避社交。**“发作间期完全正常”不是诊断的必要条件**，很多人会有残留的睡眠、注意力或情绪问题。

需要排除的情况至少有三类：

| 看起来像双相 | 可能是 | 线索 |
|---|---|---|
| 话多、精力旺、睡得少 | 物质或药物所致 | 近期用兴奋剂、类固醇、甲状腺素、抗抑郁药，或停药 |
| 兴奋、易怒、思维乱 | 躯体疾病所致 | 甲亢、库欣综合征、谵妄（急性意识混乱）、脑卒中、多发性硬化、神经梅毒 |
| 情绪不稳、冲动 | 其他精神障碍 | 边缘型人格、ADHD、创伤后应激、精神分裂症或分裂情感性障碍 |

**物质和药物**是最常被漏掉的一类。咖啡因、可卡因、冰毒、大麻、类固醇、甲状腺素、某些抗抑郁药都可能引起类似躁狂的表现；酒精戒断也会引起激越、失眠、幻觉。**躯体病**方面，甲亢、库欣综合征、高钙血症、谵妄、脑部病变都可能模仿躁狂，首次发作、年龄偏大或有神经症状时尤其要查。**其他精神障碍**方面，精神分裂症和分裂情感障碍以精神病性症状为主，边缘型人格的情绪波动多在几小时内、由人际事件触发，ADHD 则是从童年起持续存在的注意力与冲动问题，详见 3.4。

## 五、就诊准备与需要立即处理的情况

- [ ] 第一次出现“明显不同于平时”的高涨或易激惹是什么时候，持续了几天；
- [ ] 那段时间睡多久，是不困还是睡不着；
- [ ] 话量、语速、活动量、花钱、性行为、冒险行为有什么变化；
- [ ] 别人有没有说过“你像变了个人”，事后自己怎么评价；
- [ ] 有没有出现夸大、被害、被控制等想法，或听到别人听不到的声音；
- [ ] 高涨期之后有没有“跌下来”，抑郁持续多久；
- [ ] 既往发作次数、间隔、有没有一年四次以上；
- [ ] 当时有没有喝酒、用兴奋剂、吃类固醇或其他药；
- [ ] 有没有甲状腺病、脑部疾病、癫痫等躯体病史；
- [ ] 家族中有没有双相、精神病性症状、自杀或药物诱发躁狂；
- [ ] 目前用药、剂量变化和停药情况；
- [ ] 工作、学习、财务、人际关系受了多大影响。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现**自杀念头、计划或准备**，或已经自伤：不要独处，立即联系信任的人陪同，拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 出现**混合状态**：整夜不睡、思维飞奔、冲动易怒，同时极度绝望，风险很高，尽快精神科急诊评估。
> - 出现**幻觉、被害或夸大妄想、命令性幻听**，或有伤人风险：先保证安全，拨打 **120** 或 **110**。
> - 躁狂期出现**完全不吃不喝、几天不睡、行为失控、暴力风险**：需急诊精神科评估。
> - **木僵、缄默、拒食拒水、长时间不动**：可能是紧张症，立即急诊。
> - 服药后出现**高热、肌肉僵硬、大汗、意识改变**，或**严重皮疹、面唇肿胀、呼吸困难**：立即停药并急诊。
>
> 如果拿不准“算不算严重”，按严重处理。宁可白跑一趟，不要赌。

## 六、常见误区

- **“双相就是抑郁加兴奋。”** 双相的核心是发作性的情绪和精力改变，可以只有躁狂，也可以以抑郁为主；轻躁狂不一定表现为“兴奋”。
- **“轻躁狂不算病，不用治。”** 轻躁狂可能带来冲动决定、关系破裂和财务损失，也常是双相 II 型的入口，需要评估和随访。
- **“双相 II 型比 I 型轻。”** II 型的抑郁负担和自杀风险并不低，不能按“轻重”排序。
- **“一次高兴就是躁狂。”** 要看持续时间、是否明显不同于平时、功能影响和别人的观察。
- **“躁狂就是创造力爆发。”** 轻躁狂时确实可能效率高、点子多，但判断力下降、冲动和随后的崩溃同样真实，不能浪漫化。
- **“情绪波动大就是双相。”** 边缘型人格、ADHD、创伤反应、甲亢、物质使用都可能表现为情绪不稳，需要纵向史和排除。
- **“吃药会失去自我。”** 治疗目标是减少发作、恢复功能，不是把人变得平淡；具体方案要和医生讨论，不要自行停药。
