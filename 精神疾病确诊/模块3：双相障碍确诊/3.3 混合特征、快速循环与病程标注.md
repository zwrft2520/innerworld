# 3.3 混合特征、快速循环与病程标注

同样是双相，有的人一年只发作一次，有的人一年四次以上；有的人躁狂期纯粹“往上走”，有的人却在高涨的同时绝望、想死。这些差别会写进诊断的“标注”里，直接影响治疗和随访。这一页讲混合特征、快速循环、环性心境，以及医生写在诊断后面的那些标注是什么意思。适合病程反复、情绪变化复杂，或想看懂自己诊断书的人。

## 一、混合特征：不是“又高兴又难过”那么简单

混合特征指的是：在一次发作里，同时出现相反极性的症状。DSM-5-TR 的做法是加标注：躁狂或轻躁狂发作中，如果同时有至少三项抑郁症状；或抑郁发作中，如果同时有至少三项躁狂/轻躁狂症状，并且这些症状几乎每天出现、占据发作的大部分时间，就可以标“伴混合特征”。容易重叠的症状（比如易激惹、注意力分散）不能重复计算。

| 发作类型 | 混合时的常见表现 | 主要风险 |
|---|---|---|
| 躁狂伴混合 | 情绪高涨或易怒，同时绝望、自责、想死 | 冲动、自杀、伤人 |
| 抑郁伴混合 | 情绪低落，同时思维奔逸、话多、活动增多、整夜不睡 | 自杀、冲动、治疗复杂 |
| 轻躁狂伴混合 | 精力旺、点子多，同时焦虑、抑郁、烦躁 | 易被误认为“焦虑”或“性格问题” |

混合状态最危险的地方，是**绝望和行动力同时存在**。单纯抑郁的人可能没有力气实施自杀，单纯躁狂的人可能不觉得绝望；混合状态的人既有想死的念头，又有冲动、失眠、精力，风险明显升高。**混合状态属于急症边界，不要在家观察。**

混合特征也容易被误诊。抑郁伴混合的人，可能因为“话多、坐不住、睡不着”被当成焦虑，加了镇静药或抗抑郁药，反而更糟；躁狂伴混合的人，可能因为“说想死”被当成单纯抑郁。**纵向了解发作的全貌，比只看当下几分钟重要。** 同时还要排除物质或药物所致、甲状腺等躯体因素，以及边缘型人格的应激性情绪波动。

## 二、快速循环：一年四次以上

快速循环不是一种独立的病，而是病程标注：在过去十二个月里，至少有四次心境发作，可以是躁狂、轻躁狂或重性抑郁；发作之间要有明显缓解（至少两个月）或直接转换为相反极性。也就是说，四次“情绪不好”不一定是快速循环，必须是达到发作标准的心境发作。

| 概念 | 定义要点 | 常见诱因或关联 |
|---|---|---|
| 快速循环 | 十二个月内四次以上心境发作 | 抗抑郁药、甲状腺功能减退、物质使用、月经周期 |
| 超快速循环 | 几天到几周内反复切换 | 争议较大，需仔细排除物质和躯体因素 |
| 环性心境 | 两年以上轻躁狂样与抑郁样波动，达不到发作标准 | 常被当性格，功能损害持续 |

快速循环在临床上女性更常被报告，但原因可能包括就诊行为、诊断习惯和共病差异，不能简单归因于“女性体质”。**抗抑郁药是重要的可逆因素**：有些人单用或反复加用抗抑郁药后，发作越来越频繁；甲状腺功能减退、酒精或其他物质、睡眠剥夺也可能推波助澜。治疗上，医生通常会重新审视抗抑郁药、评估甲状腺、优化心境稳定剂，而不是继续“加一种药压症状”。

## 三、环性心境：长期的“小波浪”

环性心境（cyclothymia）是双相谱系里更长期、更轻的一种模式：至少两年（儿童青少年一年）反复出现轻躁狂样和抑郁样的症状，但达不到躁狂、轻躁狂或重性抑郁发作的完整标准；在这两年里，几乎没有连续两个月完全无症状；并且造成功能损害，不能用其他精神障碍更好地解释。

它和“性格起伏大”的区别在于**持续时间、功能损害和不可控性**。一个人平时情绪丰富、遇到好事开心、遇到坏事难过，是正常波动；环性心境的人则在几年里反复出现精力、睡眠、自信、兴趣的明显起落，工作、关系、财务反复受影响，自己也觉得“控制不住”。

环性心境也容易和边缘型人格障碍混。后者的人际关系、自我认同、冲动和自伤模式更突出，情绪波动常由被抛弃、被批评等事件在几小时内触发；环性心境更偏向自发的、持续数天的轻躁狂样或抑郁样状态。两者可以共病，诊断要谨慎。

## 四、病程标注：医生写在诊断后面的那几行

双相障碍的诊断不只是一个名字，后面常跟着一串标注。它们不是“附加标签”，而是对治疗和预后有实际意义的信息。

| 标注 | 含义 | 为什么重要 |
|---|---|---|
| 当前发作类型 | 躁狂、轻躁狂、抑郁、混合 | 决定当下治疗重点 |
| 严重度 | 轻、中、重，有无精神病性症状 | 决定是否需要住院、是否用物理治疗 |
| 缓解状态 | 部分缓解、完全缓解 | 判断疗效和复发风险 |
| 快速循环 | 一年四次以上 | 提示治疗需要调整，尤其是抗抑郁药 |
| 混合特征 | 同时有相反极性症状 | 自杀和冲动风险更高 |
| 季节模式 | 每年同一时段发作 | 帮助提前预防和安排随访 |
| 围产期起病 | 孕期或产后发病 | 涉及母婴安全和用药权衡 |

这些标注需要纵向信息才能填准。医生会问：第一次发作什么时候、之后每年几次、每次持续多久、之间能不能完全恢复、有没有季节规律、产后有没有变化、有没有精神病性症状、有没有快速循环。**诊断书写得细，随访才有依据。**

## 五、记录与就医

- [ ] 用时间线记下每次发作的起止时间、极性（高/低/混合）、严重度；
- [ ] 记录睡眠时长和睡眠需求，而不只是“睡得好不好”；
- [ ] 记录用药变化和症状出现的时间关系，尤其是抗抑郁药；
- [ ] 记录月经周期、产后、季节变化与发作的对应；
- [ ] 记录一年内的发作次数，判断是否达到快速循环；
- [ ] 记录有没有精神病性症状、自杀念头、冲动行为；
- [ ] 记录功能变化：工作、学习、财务、关系、自理；
- [ ] 找一位知情者帮忙核对，尤其是轻躁狂期；
- [ ] 把甲状腺、贫血、物质使用等检查结果带给医生；
- [ ] 复诊时主动问：“我的诊断后面有没有标注？需不需要更新？”

> **什么时候需要联系医生 / 去急诊**
>
> - 出现**自杀念头、计划或准备**，或已经自伤：不要独处，立即联系信任的人陪同，拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 出现**混合状态**：整夜不睡、思维飞奔、冲动易怒，同时极度绝望，风险很高，尽快精神科急诊评估。
> - 出现**幻觉、被害或夸大妄想、命令性幻听**，或有伤人风险：先保证安全，拨打 **120** 或 **110**。
> - 躁狂期出现**几天不睡、完全不吃不喝、行为失控、暴力风险**：需急诊精神科评估。
> - **木僵、缄默、拒食拒水、长时间不动**：可能是紧张症，立即急诊。
> - 服药后出现**高热、肌肉僵硬、大汗、意识改变**，或**严重皮疹、面唇肿胀、呼吸困难**：立即停药并急诊。
>
> 如果拿不准“算不算严重”，按严重处理。宁可白跑一趟，不要赌。

## 六、常见误区

- **“混合就是又高兴又难过。”** 混合特征有明确的症状组合和时间要求，不是情绪矛盾这么简单；它比单纯发作更危险。
- **“一年发作四次就是快速循环。”** 必须是达到发作标准的心境发作，并且有缓解或极性转换，不是四次心情不好。
- **“快速循环是治不好的。”** 它治疗更复杂，但找出诱因（抗抑郁药、甲减、物质）后可以改善。
- **“环性心境就是性格问题。”** 它持续两年以上、造成功能损害，是一种需要评估的障碍，不是“矫情”。
- **“诊断后面的标注不重要。”** 标注影响治疗选择、住院判断和预后沟通，值得问清楚。
- **“情绪波动大就是双相。”** 边缘型人格、ADHD、创伤、甲亢、物质使用都可能，需要纵向史和排除。
- **“抗抑郁药可以随便加。”** 在双相里，抗抑郁药可能诱发转躁、混合和快速循环，必须由医生权衡。
- **“症状好了就不用复诊。”** 双相是慢性、复发性的病，维持治疗和随访能减少下一次发作。
