# 3.2 双相抑郁的识别

双相障碍患者最常见的就诊状态不是躁狂，而是抑郁。很多人因为抑郁去看医生，拿了几年抗抑郁药，直到某次“用药后像变了个人”或“怎么治都不好”，才被重新考虑双相。这一页讲双相抑郁和单相抑郁的差别、哪些线索值得警惕、抗抑郁药转躁怎么识别，以及误诊的代价。适合被诊断为抑郁但反复发作、疗效不佳，或家族中有双相的人。

## 一、为什么双相抑郁总被漏掉

原因不神秘，主要有三个。第一，**抑郁期更长、更常求助**，躁狂或轻躁狂期往往不觉得自己有病，甚至觉得“状态最好”。第二，**轻躁狂的主观体验不痛苦**，患者不会主动报告，家人也可能把它当成“有活力”。第三，**多数抑郁筛查工具不查轻躁狂**，PHQ-9 得分再高，也不会提示双相。

还有一个容易被忽略的点：双相抑郁的首次发作常常就是抑郁，躁狂可能几年后才出现。医生在第一次就诊时只能根据现有信息判断，写“抑郁发作”并继续随访，是合理的；但如果多次复诊都没有主动追问轻躁狂史，就可能一直停在单相诊断上。需要排除的至少有三类：单相抑郁、物质或药物或躯体病所致的心境改变、以及边缘型人格、ADHD、创伤后应激等以情绪不稳为主的精神障碍。

| 漏诊原因 | 具体表现 | 可以怎么补 |
|---|---|---|
| 轻躁狂不痛苦 | 觉得“那阵子效率高、心情好” | 换问法，问睡眠、话量、花钱、冲动 |
| 只关注当下抑郁 | 医生问情绪、睡眠、食欲，不问高涨期 | 主动提供既往“状态特别好”的时段 |
| 量表不覆盖 | PHQ-9、HAMD 都没有轻躁狂条目 | 加用 MDQ 等筛查，但仍需访谈 |
| 家属不知情 | 高涨期可能被视为“正常”或“性格外向” | 找伴侣、父母、老同学核对 |

## 二、双相抑郁的线索：和单相抑郁比

双相抑郁和单相抑郁在抑郁期可以非常像，但有一些统计上的倾向。下面这些线索不是“确诊条件”，只是提示医生“需要更仔细地问”。

| 线索 | 更偏单相抑郁 | 更需要考虑双相 |
|---|---|---|
| 睡眠 | 入睡困难、早醒 | 睡得过多、白天嗜睡 |
| 食欲 | 下降、体重减轻 | 增加、体重上升、渴望甜食 |
| 动作 | 焦虑、坐立不安 | 明显迟缓、木僵样 |
| 发作特点 | 持续时间较长 | 发作频繁、间歇期较短 |
| 起病 | 各年龄段 | 青少年期、产后、季节相关 |
| 家族史 | 抑郁为主 | 双相、精神病性抑郁、药物诱发躁狂 |
| 治疗反应 | 抗抑郁药逐渐起效 | 无效、越用越烦躁，或一用就转躁 |

**“非典型特征”**是双相抑郁常被提到的一组表现：睡得过多、吃得过多、体重增加、四肢沉重像灌了铅、对好消息仍有短暂反应、对被拒绝特别敏感。这些特征在单相抑郁里也不少见，所以不能单凭“我睡得多”就判断双相。真正有价值的是**组合**：早发、反复、产后或季节性、伴精神病性症状、家族史、抗抑郁药反应差，这些加在一起，才值得高度警惕。

双相抑郁也可能伴**混合特征**：抑郁的同时思维奔逸、话多、活动增多、冲动、整夜不睡。这种状态自杀风险高，也更容易被误认为“焦虑”或“抑郁加重”。

## 三、抗抑郁药转躁：识别与处理

抗抑郁药可能诱发躁狂、轻躁狂或混合状态，这是双相诊断里最重要的线索之一，也是治疗中最需要警惕的风险【指南】。它通常发生在用药后数天到数周，加量后更明显；表现不是“心情变好”，而是**睡眠需求减少、话多、思维快、活动多、花钱或冒险行为增加、易怒**，持续几天，而不是一两个小时。

要和几种情况区分：

- **药物激活**：坐立不安、心慌、失眠、烦躁，但没有情绪高涨、夸大或活动增多；
- **抑郁好转**：愿意出门、能做事，但睡眠、判断力、消费都在正常范围；
- **混合状态**：抑郁没走，又出现思维快、冲动、整夜不睡，风险最高；
- **物质或躯体因素**：同时喝酒、用兴奋剂，或甲亢、感染等。

发现可疑变化，正确的做法是**尽快联系开药医生**，把用药时间、剂量变化、症状出现的时间线说清楚。**不要自行停药或加药**：突然停抗抑郁药可能引起撤药反应，也可能让情绪更快摆向另一头。如果出现精神病性症状、明显冲动或自杀念头，按急症处理。

还要说明：一次药物诱发的躁狂或轻躁狂，不等于“终身双相”。DSM-5-TR 有“物质或药物所致双相障碍”这一类别，医生会结合既往史、家族史和后续病程重新评估。**不要自己给自己改诊断，也不要因为怕转躁就拒绝所有药物治疗。**

## 四、误诊的代价

把双相抑郁当单相抑郁治，最直接的代价是**治疗方向不对**：单用抗抑郁药可能诱发转躁、混合状态，让发作更频繁；也可能出现“药越换越多、效果越来越差”。对患者来说，这意味着更长的病程、更多的请假和住院、更重的经济负担，以及更高的自杀风险。

反过来，把单相抑郁误当双相、长期按双相治疗，也会带来不必要的药物负担、体重和代谢问题，以及“我是不是疯了”的标签压力。**区分的目的不是选一个更重的标签，而是找到更匹配的治疗。**

误诊还会影响人生决定：有人因为“抑郁”反复请假、辞职，后来才发现是双相；有人被当成“性格不稳定”，其实是未被识别的发作。**准确的纵向病史，比一次量表分数更能改变结局。**

## 五、怎么问、怎么记、什么时候就医

- [ ] 第一次抑郁发作是什么时候，当时有没有“状态特别好”的时期；
- [ ] 高涨期持续几天，睡眠需求减少到什么程度；
- [ ] 那段时间有没有话多、思维快、花钱多、冲动、易怒；
- [ ] 有没有人说过“你像变了个人”，事后自己怎么评价；
- [ ] 抑郁期有没有睡得过多、吃得过多、四肢沉重；
- [ ] 有没有产后、季节性、青春期起病的规律；
- [ ] 抗抑郁药使用后有没有出现转躁、混合或“越治越糟”；
- [ ] 家族中有没有双相、精神病性抑郁、自杀或药物诱发躁狂；
- [ ] 有没有甲状腺病、脑部疾病、物质使用；
- [ ] 发作频率、间隔、一年有没有四次以上；
- [ ] 工作、学习、财务、关系受了多大影响；
- [ ] 目前所有药物、保健品、酒精和咖啡因使用情况。

记录时尽量用时间线：哪年哪月、什么状态、持续多久、有没有用药、什么时候恢复。旧照片、消费记录、工作考勤、家人回忆都能帮忙。MDQ 等工具可以筛查，但不能确诊，详见 3.5。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现**自杀念头、计划或准备**，或已经自伤：不要独处，立即联系信任的人陪同，拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 出现**混合状态**：整夜不睡、思维飞奔、冲动易怒，同时极度绝望，风险很高，尽快精神科急诊评估。
> - 出现**幻觉、被害或夸大妄想、命令性幻听**，或有伤人风险：先保证安全，拨打 **120** 或 **110**。
> - 用药后出现**转躁、行为失控、几天不睡**：尽快联系开药医生，不要自行停药或加药。
> - **木僵、拒食拒水、长时间不动**：可能是紧张症，立即急诊。
> - 服药后出现**高热、肌肉僵硬、大汗、意识改变**，或**严重皮疹、面唇肿胀、呼吸困难**：立即停药并急诊。
>
> 如果拿不准“算不算严重”，按严重处理。宁可白跑一趟，不要赌。

## 六、常见误区

- **“我只是抑郁，不可能是双相。”** 双相抑郁比躁狂更常见，很多人第一次就诊就是抑郁；关键是有没有轻躁狂史。
- **“我从来没有兴奋过。”** 轻躁狂也可能是易激惹、思维快、活动多、睡得少，不一定表现为“开心”。
- **“抗抑郁药吃完心情好了，说明对症。”** 要看好到什么程度：睡眠需求减少、话多、冲动、花钱失控，不是单纯好转。
- **“一次转躁就一定是双相。”** 需要排除物质、药物、躯体原因，也要看后续病程。
- **“双相抑郁不能吃抗抑郁药。”** 有时会在心境稳定剂基础上短期联合，是否使用由医生权衡，不要自行决定。
- **“双相 II 型比较轻，不用认真治。”** II 型的抑郁负担和自杀风险并不低。
- **“情绪波动大就是双相。”** 边缘型人格、ADHD、创伤反应、甲亢都可能，需要纵向史和排除。
- **“确诊双相就完了。”** 双相是可以管理的慢性病，规律治疗和随访能显著减少发作；诊断是起点，不是终点。
