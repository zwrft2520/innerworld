# 12.4 器质性与药物所致精神障碍的排查

一个人突然变得多疑、话多、睡不着、说看到东西，家里人第一反应是“精神出问题了”。但在精神科，医生最先问的往往是另一串问题：最近发不发烧？有没有换药？查出过甲亢吗？喝酒吗？——因为甲状腺、维生素 B12、感染、自身免疫性脑炎、药物和酒精，都能把一个人变得“像精神病”。这一页讲医生按什么顺序排、哪些检查不能省、以及为什么“先查身体”不是敷衍。

## 一、为什么必须先排“器质性”，以及哪些信号提示要查

【指南】DSM-5-TR 和 ICD-11 都保留了一条基本规则：精神障碍的诊断，要求症状**不能更好地用躯体疾病、物质或药物的生理效应来解释**。这不是说精神障碍“不真实”，而是诊断顺序问题——先排除能改的、能致命的、能治好的。

原因很实际：**漏诊代价大**（脑炎、低血糖、低钠、酒精戒断、硬膜下血肿，延误几小时到几天，结果可能完全不同）；**治疗方向相反**（器质性原因要治病因，原发性精神障碍要精神科治疗，方向错了越努力越糟）；而且**排除躯体原因，不等于说“你的痛苦是假的”**——很多器质性原因纠正后，痛苦才真正缓解。

现实里并非每个首次就诊的人都要做全套检查。医生会根据年龄、起病方式、伴随症状、既往病史来决定查多深。下面这些线索出现得越多，越应该优先考虑器质性原因【临床经验】：

- [ ] **首次发病年龄很极端**：儿童期起病，或四十岁以后**第一次**出现精神病性症状。
- [ ] **起病很急**：几小时到几天内从正常变得完全不正常。
- [ ] **意识或注意力波动**：时清时浊、白天糊涂晚上闹（见 [12.3 谵妄与痴呆](<12.3 谵妄与痴呆.md>)）。
- [ ] **认知下降**：记不住刚发生的事、算不清账、找不到路。
- [ ] **神经系统体征**：口角歪斜、肢体无力、走路不稳、说话不清、眼球活动异常、抽搐、手抖。
- [ ] **伴随躯体症状**：发热、剧烈头痛、呕吐、体重明显下降、盗汗、心慌、怕热多汗。
- [ ] **自主神经不稳定**：心跳忽快忽慢、血压波动、大汗、体温异常。
- [ ] **病程不典型**：持续恶化不缓解、治疗完全无效、或反复“发作—恢复—再发作”且模式古怪。
- [ ] **有明确诱因**：新加药、加量、换药、停药、饮酒或戒酒、感染、手术、外伤、妊娠或产后。

## 二、常被漏掉的几类躯体原因

| 病因 | 容易被当成 | 关键线索 |
|---|---|---|
| 甲状腺功能亢进 | 焦虑症、惊恐障碍 | 心悸、怕热、多汗、手抖、体重下降、腹泻 |
| 甲状腺功能减退 | 抑郁症、痴呆 | 乏力、怕冷、便秘、水肿、反应慢、情绪低落 |
| 维生素 B12 缺乏 | 抑郁、认知下降、神经症 | 舌炎、四肢麻木、走路不稳、素食或长期服二甲双胍 |
| 感染（尿路、肺、败血症） | 谵妄、精神分裂症首发 | 发热、尿痛、咳嗽、老年突然糊涂 |
| 自身免疫性脑炎 | 精神分裂症、紧张症 | 精神症状首发＋癫痫＋口面部不自主动作＋记忆下降 |
| 低钠、低钙、低镁 | 焦虑、意识混乱、抽搐 | 近期输液、利尿剂、呕吐腹泻、大量饮水 |
| 低血糖 | 醉酒、行为异常、惊恐 | 心慌、出汗、手抖、意识模糊，进食后好转 |
| 肝性脑病、尿毒症 | 痴呆、人格改变 | 扑翼样震颤、黄疸、少尿、便秘或消化道出血后加重 |
| 系统性红斑狼疮 | 抑郁、精神病性发作 | 皮疹、关节痛、脱发、口腔溃疡、蛋白尿 |
| 慢性硬膜下血肿 | 痴呆、抑郁、卒中 | 老年人、近期跌倒、服用抗凝药、逐渐加重的头痛 |
| 正常压力脑积水 | 痴呆、帕金森病 | 步态不稳＋尿失禁＋认知下降三联征 |
| 癫痫（尤其颞叶） | 惊恐发作、幻觉、人格改变 | 发作性恐惧、似曾相识感、自动症、发作后混乱 |

【指南】**自身免疫性脑炎**值得单独说，因为它是“精神科最容易漏、神经科最该抢时间”的一类。以抗 NMDAR 脑炎为例，患者常是年轻人，最初表现是行为紊乱、幻觉、妄想、言语减少、情绪剧烈波动，甚至木僵；随后出现癫痫、口面部不自主运动、自主神经不稳、通气不足。早期头颅 MRI 可能正常，脑电图可能只显示弥漫性慢波。**精神症状＋癫痫＋运动异常＋记忆下降**这个组合，应该尽快请神经科会诊，而不是只调精神科药物。

## 三、药物与酒精：最常见的两类“人造”病因

### 药物

药物引起的精神症状，特点往往是：**用药或加量后出现，减量或停药后好转，再次使用又出现**。常见类别包括：

- **糖皮质激素**：失眠、欣快、易激惹、抑郁、躁狂样表现、精神病性症状，与剂量和个体敏感性有关。
- **抗胆碱能药物**（部分抗过敏药、解痉药、抗帕金森药）：记忆下降、意识模糊、幻觉，老年人尤其敏感。
- **左旋多巴及多巴胺受体激动剂**：幻觉、冲动控制问题（赌博、购物、性冲动）。
- **部分抗生素**（如喹诺酮类）：失眠、焦虑、意识混乱，罕见精神病性症状。
- **异烟肼**：可致情绪和认知改变，通常与维生素 B6 状态有关。
- **干扰素、部分免疫抑制剂、抗癫痫药**：抑郁、疲劳、认知变慢、行为改变。
- **苯二氮䓬类和镇静催眠药**：老年人可出现“矛盾反应”——本想镇静，结果更躁、更糊涂。
- **阿片类**：嗜睡、意识模糊、幻觉。
- **中成药、保健品、减肥产品**：成分不明，可能含重金属、激素或未标注的活性成分。

【临床经验】最重要的是**一份完整的用药清单**，包括你自己觉得“不算药”的东西。很多“治不好的焦虑”在停掉某种感冒药、止咳药或减肥茶后明显好转；很多“新发的抑郁”发生在开始用某种药之后的几周内。但请注意：**不要自行停药**。突然停激素、抗癫痫药、抗抑郁药、苯二氮䓬类，本身就可能引起严重反应。正确做法是把清单带给医生，由医生判断。

### 酒精

酒精可以以三种方式制造精神症状，处理各不相同：

1. **急性中毒**：话多、走路不稳、判断力差、记忆断片，严重时意识模糊、呕吐误吸、呼吸抑制。
2. **戒断**：停酒或减量后 6–24 小时出现手抖、出汗、心慌、焦虑、失眠；12–48 小时可能出现癫痫；48–96 小时可能出现**震颤谵妄**——意识混乱、生动幻觉、高热、大汗、心跳快，这是可以致命的急症。
3. **慢性损害**：维生素 B1 缺乏导致 Wernicke 脑病（眼球活动异常、走路不稳、意识混乱）和 Korsakoff 综合征（近事记忆严重受损、用编造填补空白）；长期饮酒还可致肝性脑病、小脑萎缩、周围神经病。

长期大量饮酒的人**不能自行硬戒**。突然停酒是上述急症最常见的诱因，需要在医生指导下处理。

## 四、查多深，以及就诊前准备什么

| 层次 | 什么时候做 | 通常包括 |
|---|---|---|
| 第一层 | 几乎每个首次评估 | 血常规、电解质、血糖、肝肾功能、甲状腺功能、维生素 B12、尿常规、心电图 |
| 第二层 | 有红旗信号或第一层异常 | 感染指标、血氨、血气、尿毒物、妊娠试验、梅毒血清学、HIV、自身免疫抗体、头颅 CT 或 MRI、脑电图 |
| 第三层 | 高度怀疑特定疾病 | 腰穿、脑脊液自身抗体、内分泌激发试验、肿瘤筛查、专科会诊 |

这张表不是“必须全做”，而是告诉你医生在想什么。育龄女性在用药前通常会做妊娠试验；老年人首次出现精神症状，头颅影像的门槛会放低；免疫功能受损、静脉药瘾、近期旅行史的人，感染筛查会提前。

- [ ] **时间线**：把“哪天开始不对劲”和“哪天开始吃某种药”“哪天发烧/摔倒/喝酒”画在同一张纸上。
- [ ] **用药清单**：药名、开始时间、剂量变化、是否自行停过。包括中药、保健品、外用药。
- [ ] **既往检查**：把做过的化验和影像按时间整理，避免重复。
- [ ] **躯体症状**：体重变化、发热、盗汗、疼痛、排便排尿、月经、视力听力变化。
- [ ] **饮酒与吸烟**：种类、大致量、最近有没有减量或停。
- [ ] **家族史**：甲状腺病、自身免疫病、癫痫、精神疾病。
- [ ] **功能变化**：能不能上班、开车、管钱、独自出门。
- [ ] **带一个知情人**：很多细节本人记不清，家属的描述常常是诊断的关键。

> **什么时候需要联系医生 / 去急诊**
>
> - **意识改变＋发热＋肌肉僵硬＋大汗＋心跳快**：可能是恶性综合征或血清素综合征，**立即停药并拨打 120**。
> - **突然出现幻觉、被害感，同时有发热、头痛、抽搐、说话不清、肢体无力**：立即急诊，警惕脑炎、卒中、颅内感染。
> - **长期饮酒或长期服镇静药者突然停用后出现手抖、大汗、幻觉、抽搐**：立即急诊，不要在家“扛过去”。
> - **糖尿病用药者出现心慌、大汗、意识模糊、行为异常**：先按低血糖处理（清醒者立即进食含糖食物），不缓解或已昏迷立即拨打 **120**。
> - **木僵、缄默、拒食拒水超过一天、长时间维持奇怪姿势、对外界几乎无反应**：可能是紧张症，需急诊精神科评估，同时排查器质性病因。
> - **服用新药后出现严重皮疹、面唇肿胀、呼吸困难**：立即停药并急诊。
> - **出现自杀念头或自伤行为**：不要独处，联系家人陪同，拨打 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。

## 五、常见误区与下一步

**误区一：“查了都正常，说明肯定是心理问题。”** 常规检查正常只能排除一部分疾病。脑炎早期、部分内分泌病、自身免疫病，常规化验可能都正常。如果症状持续恶化或出现新体征，需要复查和升级检查，而不是简单归因。

**误区二：“既然是药物引起的，停掉就好了。”** 有些药物不能突然停（激素、抗癫痫药、苯二氮䓬类、抗抑郁药），突然停可能引起戒断、反跳甚至抽搐。减停方案要由开药医生定。

**误区三：“精神科医生只会开精神药，不会看身体。”** 规范的精神科评估一定包含躯体病史、用药史和必要的实验室检查；遇到可疑体征，会转诊神经科、内分泌科或感染科。

**误区四：“器质性就是治不好的脑损伤。”** 恰恰相反，这一类里有很多是**可逆**的：甲状腺功能异常、维生素 B12 缺乏、低钠、感染、药物反应、硬膜下血肿。查出来的意义，正在于它们能改。

**误区五：“只要查出甲状腺有问题，精神症状就都归它。”** 甲状腺功能异常和抑郁、焦虑可以并存。纠正甲功后症状没完全缓解，仍需单独评估精神障碍。**不要把所有症状都归给一个原因**（见 [13.5 共病与多重诊断](<13.5 共病与多重诊断.md>)）。

如果找到明确的躯体或药物原因，处理方向是**治病因＋对症支持**，同时观察精神症状是否随之缓解。如果排查后仍无明确病因，也不等于“什么都没查出来”——这本身是一条重要信息，它让医生更有把握按原发性精神障碍来治，并把这作为后续随访的基线。

【临床经验】最理想的模式不是“精神科”和“其他科”二选一，而是**同时进行**：该查的查，该治的治，该等的等。对患者和家属来说，最有用的态度是：既不因为“怕是躯体病”而拒绝精神科评估，也不因为“说是心理问题”就放弃必要的躯体检查。
