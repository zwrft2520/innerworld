# 5.4 精神病性症状的鉴别诊断

幻觉、妄想、行为紊乱，不等于精神分裂症。双相、抑郁、物质、药物、甲状腺、脑炎、谵妄，都可能做出同样的表现。鉴别诊断不是“多查几项”，而是沿着时间、物质、躯体三条线，找出最可能的原因。这一页讲医生通常怎么排，以及哪些情况不能等。

## 先问三个问题

面对一位刚出现精神病性症状的人，医生通常会先问：

1. **什么时候开始、怎么发展？** 突然几小时、几天，还是几周、几个月？有没有前驱期？有没有波动？
2. **有没有物质或药物？** 酒、大麻、冰毒、致幻剂、处方药、激素、减肥药、保健品，最近有没有加量或停药？
3. **有没有躯体线索？** 发热、头痛、抽搐、意识波动、体重下降、心悸、乏力、尿便异常、近期感染？

这三个问题能快速把方向分开：突然起病伴意识波动，先想谵妄、感染、物质；亚急性起病伴情绪高涨，先想双相；慢性起病伴阴性症状，才更像精神分裂症。

同时要记录病程和功能：症状持续多久、是否几乎每天存在、能否工作学习、能否自理、和家人关系如何。没有病程和功能，只凭一次访谈的“幻觉+妄想”，很容易把短暂反应、物质中毒或心境发作误当精神分裂症。

## 三类常见来源：心境、物质、器质

### 心境障碍伴精神病性症状

双相躁狂或抑郁发作时可以出现幻觉、妄想。判断的关键是时间关系：

- 精神病性症状是否只在大幅情绪发作期间出现？
- 情绪症状是否占病程的大部分？
- 情绪正常时，精神病性症状是否完全消失？

如果精神病性症状只在心境发作时出现，更可能是心境障碍伴精神病性特征。若情绪正常时仍有至少两周的独立精神病性症状，且心境发作占病程大部分，要考虑分裂情感性障碍。

躁狂伴精神病性特征常表现为夸大、被害、被控制，语速快、睡眠需求少、行为冲动。抑郁伴精神病性特征常表现为罪恶、贫穷、躯体疾病相关的妄想，伴严重抑郁和自杀风险。两类都需要尽快精神科评估。

### 物质与药物

这是最容易被漏掉、也最容易纠正的一类。常见包括：

- 兴奋剂：冰毒、可卡因、部分减肥药。
- 大麻、致幻剂、氯胺酮。
- 酒精：急性中毒、戒断性幻觉、酒精性精神病。
- 镇静催眠药戒断。
- 糖皮质激素、多巴胺受体激动剂、抗胆碱能药物、部分抗癫痫药。
- 过量使用甲状腺素、减充血剂、部分感冒药。

判断要看时间关系：症状是否在用药后出现、停药后缓解、再次使用后复发。尿检、血药浓度、停药观察都有帮助。但“查出物质”不等于“精神病性症状全是物质所致”，两者可以共病。

### 器质性原因

躯体疾病所致精神病性障碍常被误认为“原发性精神病”。需要想到：

- 内分泌与代谢：甲状腺功能异常、甲状旁腺异常、电解质紊乱、低血糖、肝性脑病、尿毒症。
- 营养：维生素 B12 缺乏、烟酸缺乏。
- 感染与免疫：梅毒、HIV、自身免疫性脑炎、系统性红斑狼疮。
- 神经系统：脑卒中、脑肿瘤、癫痫、多发性硬化、痴呆、谵妄。
- 缺氧、睡眠严重剥夺、术后状态。

线索包括：年龄偏大首次发作、急性或波动性起病、伴意识改变、发热、头痛、抽搐、局灶神经体征、认知下降、体重下降、既往躯体病史。医生会根据线索安排血液、影像、脑电图、腰穿等检查。

| 原因 | 线索 | 首查方向 |
|---|---|---|
| 物质/药物 | 用药或停药时间关系、尿检 | 毒物筛查、用药核对 |
| 心境障碍 | 情绪发作与精神病性症状同步 | 纵向病史、精神检查 |
| 器质性疾病 | 发热、头痛、抽搐、意识波动 | 血检、影像、脑电图 |
| 自身免疫性脑炎 | 年轻、癫痫、运动异常、意识下降 | 脑脊液、MRI、抗体 |

## 两个不能漏的急症

### 自身免疫性脑炎：容易被当成“精神分裂”的急症

自身免疫性脑炎，尤其是抗 NMDAR 脑炎，常以精神症状起病：焦虑、失眠、易激惹、幻觉、妄想、言语紊乱、行为异常。之后可能出现癫痫、口面部不自主运动、自主神经不稳定、意识下降、记忆和语言障碍。

它不常见，但漏诊代价大。以下线索要提高警惕（并非只见于年轻女性，儿童和男性也可发病）：

- 年轻患者，女性更常见，急性或亚急性起病。
- 前驱期有发热、头痛、乏力。
- 精神症状后出现癫痫、运动异常、意识波动。
- 记忆、语言、定向明显下降。
- 常规抗精神病治疗效果差，或出现不明原因发热、心动过速、血压波动。

诊断需要脑脊液、脑电图、头颅 MRI 和自身抗体检测，由神经科/精神科共同判断。不是每个精神病性患者都要查自身抗体，但“精神症状 + 癫痫/运动异常/意识下降”不能只当精神分裂症。

### 谵妄：注意力波动是关键

谵妄是急性、波动性的注意力障碍和意识改变，常伴幻觉（多为视幻觉）、错觉、定向障碍、睡眠紊乱、行为紊乱。它起病快，白天晚上波动，注意力难以维持。

高危人群：老年人、住院患者、术后、感染、疼痛、脱水、电解质紊乱、多重用药、酒精或镇静药戒断。

谵妄是急症，不是“精神分裂症加重”。处理要找到并纠正病因，而不是只加抗精神病药。家属常能提供关键信息：昨天还好好的，今天突然不认识人、看到虫子和人影、夜里特别乱。

## 就诊前可以准备什么

- [ ] 记录症状从什么时候开始，几小时、几天还是几个月。
- [ ] 记录症状有没有波动，白天晚上是否不同。
- [ ] 记录发热、头痛、抽搐、意识模糊、走路不稳。
- [ ] 列出所有药物、保健品、减肥药，注明开始和停用时间。
- [ ] 记录酒、大麻、冰毒、致幻剂等使用情况。
- [ ] 带上既往甲状腺、血常规、电解质、影像、脑电图结果。
- [ ] 记录情绪发作史和家族史。
- [ ] 记录近期感染、手术、旅行、动物接触。
- [ ] 记录功能变化：工作、学习、自理、钱财管理。

## 常见误区与急症边界

### 常见误区

**误区一：幻觉就是精神分裂症。** 幻觉可见于心境障碍、物质、谵妄、癫痫、脑炎、听力障碍和正常入睡前体验。

**误区二：年轻人不会得脑炎。** 自身免疫性脑炎恰恰多见于年轻人，且常以精神症状起病。

**误区三：查出物质就完事了。** 物质使用和精神障碍可以共存，需要分别评估，不能用一个解释盖住全部。

**误区四：谵妄是“疯了”。** 谵妄是躯体急症，处理病因是第一位。

### 什么时候需要联系医生或去急诊

> **立即拨打 120 或去急诊**：首次精神病性症状伴发热、剧烈头痛、抽搐、意识模糊或波动、颈项强直、局灶无力、说话不清；高热伴肌肉僵硬、大汗、意识改变；木僵拒食；明确的自杀或伤人计划。
>
> **尽快联系精神科或拨打 12356**：首次出现幻觉或妄想、症状快速加重、停药后复发、抑郁加重。
>
> 不要因为“以前诊断过精神分裂症”就把新出现的发热、抽搐、意识变化归为“老毛病”。

鉴别诊断不是为了否定患者的体验，而是为了找到可治疗的原因。有些原因纠正后症状会明显改善，有些需要长期治疗；方向不同，结果可能完全不同。
