# 4.2 广泛性焦虑与惊恐障碍

广泛性焦虑和惊恐障碍常被混在一起：一个是“总在担心”，一个是“突然被恐惧击中”。但两者的时间门槛、害怕的对象、治疗重点并不相同。这一页把两者的诊断线索拆开，也讲清楚哪些躯体病会伪装成它们。适合反复心慌、担心，或被一句“焦虑症”打发的人读。

## 广泛性焦虑：担心的不是一件事，而是所有事

广泛性焦虑的核心不是某一次强烈恐慌，而是长期、弥散、难以控制的担心。担心内容常围绕工作、金钱、家人健康、孩子、琐事，一天里大部分时间都在想“万一”。【指南】

医生通常会看：

- 担心是否涉及多个领域，而不是只围绕一件事。
- 是否明显过度，与事情的实际风险不相称。
- 是否难以控制，自己也觉得“想停停不下来”。
- 是否持续数月，且大部分日子都存在。
- 是否伴随坐立不安、容易疲劳、注意力难集中、易激惹、肌肉紧张、睡眠差。
- 是否造成工作、学习、社交或家庭功能的损害。

这里的“数月”在 DSM-5-TR 里通常是六个月左右；ICD-11 对时间的要求表述不同，以原文和医生判断为准。六个月不是机械门槛，而是帮助区分“近期压力下的担心”和“长期特质性担忧”。

广泛性焦虑的身体症状常比“心理担心”更突出：肩颈紧、头痛、胃胀、腹泻、手抖、心悸、喉咙发紧、入睡困难。很多人先跑心内科、消化科，查了一圈没大问题，最后才到精神科。

广泛性焦虑还容易和抑郁共病。判断时要看先后和主次：是先长期担心、后来情绪低落，还是抑郁发作后开始反复担心；有没有兴趣减退、早醒、体重下降、自杀念头。两者共病很常见，不代表诊断错了。

## 惊恐发作：几分钟内冲到顶点的恐惧

惊恐发作的特点是“突然”和“很快到顶”。不是慢慢累积的紧张，而是在几分钟内出现强烈恐惧或不适，伴随一组躯体或认知症状。DSM-5-TR 列举了十余项，通常要达到至少四项才称为一次完整发作；少于四项的称为有限症状发作。【指南】

可以把这些症状分成四组来记：

| 症状群 | 常见表现 | 容易混淆 |
|---|---|---|
| 心脏呼吸 | 心悸、胸闷、胸痛、气短、窒息感 | 心绞痛、心律失常、哮喘、肺栓塞 |
| 神经前庭 | 头晕、站不稳、发抖、出汗、发冷或发热、麻木 | 低血糖、前庭疾病、癫痫 |
| 胃肠 | 恶心、腹部不适 | 胃肠病、食物中毒 |
| 认知 | 濒死感、失控感、失真感、脱离感 | 其他焦虑、解离、创伤反应 |

惊恐发作可以是“非预期”的（没有明显诱因）、情境性的（特定场合触发），也可以是情境易感的。夜间从睡眠中惊醒的惊恐发作也不少见。发作本身不危险，但第一次发作的人常坚信自己“要死了”或“要疯了”，这种体验是真实的，不是矫情。

## 惊恐障碍：发作之后那一个月的担心

惊恐障碍的关键不只是发作，而是发作之后的变化：持续担心再次发作、担心发作的后果（心脏病、失控、发疯），或者因为发作而明显改变行为（不敢独处、不敢运动、不敢坐地铁、反复查体）。这种担心通常持续一个月左右。【指南】

要把惊恐障碍和“一次惊恐发作”分开。很多人一生中会有一次惊恐发作，但不发展成障碍。只有反复发作，加上持续担忧或行为改变，才更接近惊恐障碍。

惊恐障碍常与广场恐惧共病。判断时要看：害怕的是“发作本身”，还是“发作时逃不掉、没人帮”？前者更像惊恐障碍，后者要考虑广场恐惧。两者可以同时存在。

功能损害很具体：频繁跑急诊、反复做心电图、不敢开车、不敢出差、依赖家人陪同、用酒精压惊。病程上，惊恐障碍常起病于青少年后期到三十多岁，女性更常见，但任何年龄都可能出现。

## 必须排除的躯体与物质原因

| 要排除的情况 | 线索 | 常做的检查 |
|---|---|---|
| 心律失常 | 突发心悸、晕厥、有心脏病史 | 心电图、动态心电图、心脏超声 |
| 甲亢 | 怕热、多汗、体重下降、手抖、腹泻 | 甲状腺功能 |
| 嗜铬细胞瘤 | 阵发性头痛、大汗、心悸、血压飙升 | 医生按线索安排儿茶酚胺相关检查 |
| 低血糖 | 饥饿、出汗、手抖、意识模糊，进食后缓解 | 血糖，必要时进一步检查 |
| 物质或药物 | 咖啡因、能量饮料、酒精戒断、兴奋剂、激素 | 用药史、尿检 |
| 其他精神障碍 | 抑郁、双相、创伤后应激、强迫、疾病焦虑 | 纵向病史与精神检查 |

嗜铬细胞瘤很罕见，但它的“阵发性心悸、头痛、大汗”与惊恐发作极像，医生会在有线索时排查，不必人人都查。相反，有心脏病危险因素的人，第一次剧烈胸痛必须先按心脏急症处理。

## 就诊清单与常见误区

### 就诊前可以准备什么

- [ ] 记录最近一次发作：日期、时间、当时在做什么、从开始到高峰多久、持续多久。
- [ ] 写下发作时的具体身体感觉，尤其是胸痛的性质、有没有放射、有没有晕厥。
- [ ] 记录发作频率：一周几次、一个月几次、有没有夜间发作。
- [ ] 记录担心什么：再次发作、心脏病、失控、发疯，还是别的。
- [ ] 列出因为发作而改变的行为：不敢独处、不敢运动、不敢坐车、反复就医。
- [ ] 记录咖啡、能量饮料、酒精、尼古丁、减肥药、感冒药的用量。
- [ ] 带上既往心电图、甲状腺功能、血糖、动态心电图结果。
- [ ] 写下家族史和正在服用的所有药物。

### 常见误区

**误区一：惊恐发作会把人吓死。** 惊恐发作本身通常不会直接造成死亡，但第一次发作、或有心脏病危险因素时，必须先把心脏问题排除。不要把“年轻、查过心电图”当成永久保险。

**误区二：发作时深呼吸就好。** 缓慢呼吸对部分人有帮助，但过度深呼吸可能加重头晕、手脚麻。惊恐发作时更重要的是降低刺激、陪着当事人、避免让其独处后驾车，并尽快就医评估。

**误区三：广泛性焦虑就是爱操心。** 正常操心能停下来，广泛性焦虑的担心难以控制、持续时间长、伴随躯体症状和功能损害。

**误区四：不发作就是好了。** 惊恐障碍常伴随回避，回避不解决，发作可能被“养”回来。评估要看功能恢复，不只是发作次数。

### 什么时候需要联系医生或去急诊

> **立即拨打 120 或去急诊**：首次出现压榨性胸痛、胸痛持续不缓解、放射到手臂或下颌、冷汗、晕厥、严重气短、口唇发紫、心跳极快且伴头晕、意识模糊、单侧无力或说话不清。不要先假定是惊恐发作。
>
> **尽快联系精神科或拨打 12356**：发作频率明显增加、无法出门、无法工作、出现自杀念头、靠酒精或镇静药应对、停药后出现抽搐或意识混乱。
>
> 有心脏病、高血压、糖尿病、吸烟史或家族史的人，第一次剧烈惊恐应优先急诊排查。

确诊后，医生通常会评估共病、讨论心理治疗（如认知行为治疗）和是否需要药物，并安排随访。治疗目标是恢复功能，而不是追求“永远不焦虑”。
