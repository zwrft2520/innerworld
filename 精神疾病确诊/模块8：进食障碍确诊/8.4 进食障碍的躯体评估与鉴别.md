# 8.4 进食障碍的躯体评估与鉴别

进食障碍的诊断看起来是“心理”问题，但真正决定一个人要不要住院、能不能回家、有没有生命危险的，往往是躯体指标：电解质、心率、骨密度、月经。这一页讲这些检查各自在看什么、哪些躯体病会伪装成进食障碍、以及哪些信号意味着必须马上处理。**读完能带走一句：进食障碍的躯体评估不是“顺便查一下”，它是诊断的一部分。**

## 一、三项最要紧的躯体指标

### 电解质：低钾是最常见的“隐形炸弹”

反复催吐、滥用泻药或利尿剂，会把钾、氯、钠连同胃液一起丢掉。血钾低到一定程度，人可能只是觉得乏力、腿软、心慌，但心电图已经在变化：T 波低平、U 波出现、QT 间期延长，严重时室性心律失常甚至心脏骤停。

常见的电解质模式（仅作理解用，不能自行对号）：

| 模式 | 常见于 | 提示 |
|---|---|---|
| 低钾 + 低氯 + 代谢性碱中毒 | 反复催吐 | 胃酸丢失 |
| 低钾 + 代谢性酸中毒 | 滥用泻药 | 肠道碳酸氢盐丢失 |
| 低钠 | 大量饮水“压体重”、滥用利尿剂 | 严重时可致抽搐、意识改变 |
| 低磷、低镁 | 营养不良、再喂养初期 | 再喂养综合征的核心 |

**再喂养综合征**值得单独说：长期饥饿后突然增加进食，胰岛素分泌上升，磷、钾、镁迅速进入细胞，血磷骤降，可导致心力衰竭、心律失常、抽搐、意识障碍。它常发生在“开始好好吃饭”之后的几天内，所以恢复进食必须慢慢来，并在医疗监测下进行。这也是为什么不能家属自己在家“猛补”。

### 心率与血压：最便宜的危重信号

营养不良时，心脏会“省着跳”：静息心率偏慢、血压偏低、手脚发凉。看起来“很平静”，其实是代偿能力快用完了。

医生会做**立卧位血压**：躺着测一次，站起来 1 分钟和 3 分钟各测一次。收缩压明显下降或舒张压明显下降、伴头晕，提示体位性低血压，是脱水、血容量不足和自主神经调节受损的表现。

各地住院参考线不完全一样，很多中心会把以下情况列为需要紧急评估：静息心率持续很低（如低于每分钟 50 次）、站立后血压明显下降、低体温、晕厥史。**这些是参考线，不是绝对标准；具体判断由医生结合整体情况决定。**

### 骨密度与月经：被拖得最久的两件事

长期低体重、营养不足会抑制下丘脑—垂体—性腺轴，表现为月经停止（继发性闭经）、性欲下降；青少年则可能表现为初潮推迟、乳房发育停滞。骨骼在缺乏雌激素和营养的情况下，骨量积累不足、骨密度下降，骨折风险升高，而且**这部分损失不一定能完全恢复**。

所以规范评估会问：月经初潮年龄、最近一次月经、停经多久、是否规律；必要时做骨密度检查（双能 X 线吸收法）。男性同样会有性腺轴抑制，只是更少被问到。

需要强调：DSM-5-TR 已经不再把“闭经”列为神经性厌食的必要条件。**有月经不代表没病，没月经也不等于就是厌食**——运动员、压力大、多囊卵巢、甲状腺问题、高泌乳素血症都可以导致闭经。

## 二、门诊常做的检查，各自看什么

| 检查 | 主要看什么 | 异常可能提示 |
|---|---|---|
| 血常规 | 贫血、白细胞、血小板 | 营养不良、感染、骨髓抑制 |
| 电解质（钾钠氯钙镁磷） | 清除行为、再喂养风险 | 心律失常、抽搐、无力 |
| 肝肾功能 | 转氨酶、白蛋白、肌酐、尿素 | 饥饿性肝损、脱水、肾前性损伤 |
| 血糖 | 低血糖 | 长期饥饿、严重肝损 |
| 甲状腺功能 | TSH、游离 T4、T3 | 甲亢（鉴别）；低 T3 综合征（正常甲状腺性病态综合征，T3 低、TSH 正常或偏低） |
| 心电图 | 心率、QT 间期、心律失常 | 低钾、低镁、药物影响 |
| 骨密度 | 腰椎、髋部 | 骨质疏松/骨量减少 |
| 淀粉酶 | 腮腺来源的淀粉酶 | 反复催吐导致腮腺肿大 |
| 尿常规、尿比重 | 脱水、感染、滥用利尿剂 | 肾前性损伤、电解质丢失 |

检查项目不是越多越好，医生会根据体重、清除行为、症状挑重点。**检查正常也不能排除进食障碍**——很多患者早期化验完全正常。

评估时医生会同时记录两件事：**病程**（体重下降持续多久、停经多久、暴食清除多久）和**功能状态**（能不能上学上班、能不能自己出门、需不需要人陪）。同样是低钾，刚出现两周和反复两年，处理强度不同；同样是心率慢，还能正常上课和已经卧床，意义也不同。这也是为什么复诊时的“这段时间怎么样”比单次化验更有信息量。

## 三、会伪装成进食障碍的躯体疾病

这是鉴别诊断里最容易被漏的一组，因为它们真的会让人“吃不下、瘦下去”：

- **甲状腺功能亢进**：怕热、多汗、心慌、手抖、大便次数多，**食欲常常是增加的**，体重却下降。关键区别是“吃得多还瘦”，而厌食是“吃得少”。少数甲亢患者食欲不高，需要靠化验区分。
- **糖尿病（尤其 1 型）**：多饮、多尿、多食、体重下降、乏力；血糖和酮体可以很快出问题。还有一类需要特别问：**故意少打或漏打胰岛素来控制体重**（有时被称作“代偿性胰岛素省略”），既有糖尿病又有进食障碍，风险叠加。
- **胃肠疾病**：炎症性肠病、乳糜泻、慢性胃炎、胃轻瘫、肠系膜上动脉压迫综合征（消瘦后脂肪垫消失，压迫十二指肠，出现餐后腹胀、呕吐）。这些会有腹痛、腹泻、呕吐、便血等定位症状。
- **慢性感染与肿瘤**：结核、HIV、淋巴瘤、消化道肿瘤，常伴低热、盗汗、淋巴结肿大、贫血、炎症指标升高。
- **肾上腺皮质功能减退**：乏力、低血压、体重下降、恶心、皮肤色素沉着，化验可见低钠、高钾——注意这与催吐造成的低钾方向相反。
- **药物与物质**：兴奋剂、减肥药、泻药滥用、化疗药、部分抗抑郁药、甲状腺素过量，都可导致食欲下降和体重减轻。

医生的思路通常是：先看有没有“定位症状”（发热、腹痛、腹泻、多尿、心悸、手抖），再看化验，而不是一上来就把人归到精神科。

## 四、会伪装成躯体病的进食障碍

反过来，也有很多人反复看消化科、内分泌科、心内科，查了一圈“没大毛病”，最后才发现是进食障碍。常见路径：

- 反复腹胀、便秘、反酸 → 消化科；
- 心悸、胸闷、乏力 → 心内科；
- 月经紊乱、不孕 → 妇科/生殖科；
- 头晕、低血糖、电解质异常 → 急诊；
- 牙齿敏感、龋齿 → 口腔科。

如果多个科室都查不出明确病因，而人又明显消瘦、怕冷、心率慢、情绪低落，接诊医生通常会想到问一句：“最近吃饭怎么样？有没有在控制体重？”

同时要和精神科内部的其他情况区分：

- **抑郁障碍**：食欲下降、体重减轻，但核心是持续情绪低落、兴趣丧失，没有怕胖和体像扭曲；
- **焦虑与强迫**：进食仪式、怕污染、怕噎，回避的动机是减焦虑，不是减重；
- **回避限制性摄食障碍（ARFID）**：对进食本身缺乏兴趣、对食物质地/颜色敏感、怕噎怕吐，同样没有体像问题；
- **精神病性障碍**：坚信食物被下毒，或受命令性幻听支配而拒食；
- **孤独症谱系**：对食物质地、温度、摆放有强烈偏好，看起来“极度挑食”。

## 五、急症信号：这些情况不要等门诊

> **什么时候需要联系医生 / 去急诊**
>
> 出现以下任一情况，立即拨 **120** 或去最近医院急诊，不要等预约：
>
> - 晕厥、差点晕倒、站起来眼前发黑；
> - 心跳很慢、很快或很乱，胸闷、胸痛、心悸到难受；
> - 抽搐、意识模糊、说话含糊、反应明显变慢；
> - 持续呕吐、无法进水、尿量明显减少；
> - 呕血、咖啡色呕吐物、黑便；
> - 剧烈腹痛且持续加重、腹部胀到无法呼吸；
> - 明显低体温、手脚冰凉、嗜睡叫不醒；
> - 刚恢复进食几天内出现乏力加重、心慌、水肿（警惕再喂养综合征）；
> - 有自杀念头、自伤行为或已写下计划——低体重合并自杀风险，需要住院评估。
>
> 到急诊时，请主动说三句话：“我最近吃得很少/有催吐或泻药”“我体重掉了多少、多快”“我在吃什么药”。这三句话能显著改变急诊的处理路径。也可拨 **12356** 心理援助热线。

## 六、就诊准备清单

- [ ] 身高、体重、最近三个月的变化曲线（有体检记录最好）
- [ ] 最近两周典型的一天饮食，包括饮料、代餐、零食
- [ ] 清除行为：催吐、泻药、利尿剂、灌肠、减肥药，各自频率
- [ ] 运动量与“不运动就难受”的情况
- [ ] 月经史：初潮年龄、最近一次、是否规律、停经多久（女性）；男性问性欲与晨勃
- [ ] 症状：头晕、心悸、怕冷、乏力、便秘、脱发、腹胀、反酸
- [ ] 有没有晕倒、抽搐、呕血、黑便
- [ ] 既往检查结果：血常规、电解质、肝肾功能、甲状腺、心电图、骨密度、胃镜
- [ ] 用药清单：处方药、中药、保健品、减肥产品、代购药
- [ ] 家族史：进食障碍、甲状腺病、糖尿病、抑郁、酒精使用
- [ ] 情绪与风险：抑郁、焦虑、自伤、自杀念头
- [ ] 想问医生的问题：需要查哪些项目、多久复查一次、什么情况下要住院

## 常见误区

- **“化验正常就没问题。”** 早期进食障碍的化验常常完全正常，正常结果不能排除诊断。
- **“心率慢是身体好、是运动员体质。”** 在明显消瘦、吃得很少的背景下，心率慢是代偿，不是健康。
- **“月经来了就说明没事。”** 闭经不是诊断的必要条件，有月经也可能存在严重限制性进食。
- **“补钙就能防骨折。”** 骨密度下降的主因是营养不足和性腺轴抑制，单补钙不够。
- **“先减肥，减完再看心理。”** 进食障碍背景下的减重容易强化症状，顺序应由医生判断。
- **“查不出病就是心理作用。”** 查不出病，恰恰提示需要问进食行为，而不是否定症状。

## 确诊之后通常怎么走

确诊后的第一步通常不是“谈饮食”，而是评估躯体安全：电解质、心电图、生命体征、体重下降速度、再喂养风险。安全之后，才是营养康复与心理治疗。合并抑郁、焦虑、强迫、创伤时，处理顺序由医生根据风险决定。**本页不涉及具体药物与剂量。**

对家属来说，最实用的是记住两条：**别在家自行“加餐补救”，也别把急诊当小题大做。**
