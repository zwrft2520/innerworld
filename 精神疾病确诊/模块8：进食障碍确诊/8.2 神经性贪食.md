# 8.2 神经性贪食

神经性贪食最容易被误解成“管不住嘴”，实际上它的核心是一段反复出现的失控进食，加上事后的补偿行为，以及强烈的羞耻感。这一页讲医生依据什么考虑这个诊断、为什么体重正常的人也可能很严重、以及和其他“吃得多”的情况怎么分开。读完之后，你大概能判断：**暴食本身不是诊断，暴食加反复补偿、再加自我评价被体重体形绑住，才构成医生关注的方向。**

## 一、核心是“暴食 + 补偿”，不是“吃得多”

【指南】按 DSM-5-TR 的思路，医生考虑神经性贪食时会看三件事：反复出现暴食发作；反复使用不恰当的补偿行为来防止体重增加；自我评价过度受体重和体形影响。暴食和补偿都要达到一定频率（通常按每周至少一次、持续三个月来把握），而且这些表现不能只发生在神经性厌食的病程里。具体条目与时间门槛以 DSM-5-TR、ICD-11 原文和医生访谈为准。

“一定频率”这句话很重要。逢年过节吃撑一次、聚餐后愧疚两天，不构成诊断；诊断看的是**反复、持续、失控**，以及它有没有把生活拧歪。

### 暴食长什么样

暴食（binge eating）不是“胃口好”，通常有几个特征：

- **量**：在一个独立时间段里吃下的东西，明显多于多数人在同样情境下的量；
- **失控**：吃着吃着停不下来，或者明知道不该吃还是继续；很难在想要的时候停下；
- **速度**：吃得比平时快很多，几乎不咀嚼；
- **感受**：吃到不舒服、胀痛仍继续；常常独自吃，因为羞于被别人看见；
- **事后**：强烈的厌恶、内疚、抑郁、自我谴责。

暴食时吃的东西往往是平时禁止自己吃的：甜食、油炸、主食、整袋零食。这和“嘴馋”不同——嘴馋是享受，暴食是失控加痛苦。

### 补偿行为：清除只是其中一种

补偿行为不只催吐。医生会逐一问：

- 自我诱吐；
- 滥用泻药、利尿剂、减肥药、灌肠；
- 禁食或极度限制下一餐；
- 过度运动（不是为了健康，而是为了“抵掉”刚才吃的）；
- 在 1 型糖尿病中故意少打或漏打胰岛素（有时被称作“代偿性胰岛素省略”，风险很高）。

很多人以为“吐出来就没吸收”，其实催吐只能排出胃里的一部分，热量吸收已经发生；而且反复催吐带来的电解质紊乱和心律失常，比体重问题更危险。

### 自我评价被体重体形绑住

这一条常被家属忽略。患者可能体重完全正常，但一天的大部分注意力都在体重、围度、镜子、食物上；一天的心情由早上称的数字决定。这种“自我价值 = 体重”的结构，是进食障碍诊断里的关键，也是它和普通“爱美”的分界线。

## 二、体重多正常，所以更容易被漏掉

神经性贪食患者的体重**多数在正常范围**，少数偏低或偏高。这带来两个后果：

1. **家人看不出来**。饭桌上可能一切正常，暴食发生在深夜、独处、外卖；
2. **医生也容易漏**。因为不瘦、不吐在明面上，主诉常是“胃不舒服”“月经乱”“情绪差”“牙齿敏感”，进食问题要主动问才会说出来。

【研究】贪食的患病率在女性青少年和年轻成人中相对较高，但男性、年长者、体重偏高者同样存在，只是更少被识别。男性患者更常被误认为“健身/增肌”或“就是能吃”。

医生常看的躯体线索包括：

| 线索 | 可能提示 |
|---|---|
| 腮腺、下颌角反复肿大（“蛙腮”） | 长期催吐 |
| 牙釉质磨损、牙齿敏感、多龋 | 胃酸反复接触牙面 |
| 手背指关节处的茧或色素沉着 | 用手指诱发呕吐时的摩擦 |
| 血钾低、血氯低、代谢性碱中毒 | 催吐或滥用泻药、利尿剂 |
| 反复腹胀、便秘或腹泻 | 泻药依赖、肠道功能紊乱 |
| 月经不规律或停经 | 体重波动、营养不足、内分泌紊乱 |

这些线索只是提示，不是诊断依据。有这些表现的人也可能因为其他原因（如唾液腺疾病、胃食管反流、药物副作用）出现类似情况。

## 三、病程、功能损害与严重度

医生会问时间线：第一次暴食大概什么时候？那时有没有在节食？暴食和节食常常是一对循环——越严格限制，越容易在某个点崩掉，暴食后又更严格限制，循环加固。

病程上，贪食多在青少年后期到二十多岁起病，常常先有一段节食或减重经历。有人持续几个月，有人断断续续十几年。**“时好时坏”是常见形态，不代表不严重。**

功能损害通常体现在：

- **经济**：大量花钱买食物，事后又为钱焦虑、借钱、瞒着家人；
- **社交**：拒绝聚餐，或聚餐后立刻找借口离开去吐；逐渐不出门；
- **学业工作**：注意力被食物和体重占据，效率下降、缺勤；
- **身体**：反复就医查胃、查牙、查月经，却没人问到进食行为；
- **情绪**：羞耻、自责、抑郁、焦虑，部分人出现自伤。

严重度上，DSM-5-TR 主要按暴食和补偿行为的频率分档（轻度、中度、重度、极重度）。但临床判断不会只看次数：血钾、心律、有没有晕厥、有没有自杀风险，权重更高。

## 四、躯体并发症与需要急诊的信号

贪食的危险，很多时候不在体重，而在**清除行为**：

- **电解质紊乱**：低钾最常见，可导致乏力、心悸、心律失常，极端情况下心脏骤停；低氯、代谢性碱中毒也常见；
- **心血管**：心悸、胸闷、心电图改变（QT 延长、心律不齐）、体位性低血压、晕厥；
- **消化系统**：反流性食管炎、食管溃疡、贲门黏膜撕裂（呕血）、罕见但致命的食管或胃破裂；滥用泻药导致结肠功能紊乱；
- **口腔**：牙釉质侵蚀、龋齿、牙齿敏感、牙周问题；
- **腺体**：腮腺、唾液腺肿大；
- **其他**：脱水、皮肤干燥、指关节胼胝、月经紊乱、骨质疏松风险升高；
- **药物相关**：长期滥用吐根糖浆可致心肌损伤；滥用利尿剂、泻药可致严重脱水与肾前性损伤。

> **什么时候需要联系医生 / 去急诊**
>
> 出现以下任一情况，不要等到下次门诊：呕血或咖啡色呕吐物、剧烈腹痛且不缓解、心跳很快或很乱、胸闷胸痛、晕厥或差点晕倒、明显肌肉无力到站不稳、抽搐、意识模糊、一天内反复呕吐无法进水、尿量明显减少。请立即拨打 **120** 或去最近医院急诊，并主动告诉医生“我有反复催吐/用泻药”，因为这直接决定要不要查血钾和心电图。
>
> 如果出现自杀念头、自伤行为，或已经写下了计划，请让家人陪着，拨 **120** 或去精神科急诊；也可拨 **12356** 心理援助热线。**贪食合并抑郁和自杀风险并不少见**，不要独自扛。

## 五、与暴食障碍、厌食、抑郁的区分

“吃得多”有好几种，方向不同，处理也不同：

| 情况 | 暴食 | 补偿行为 | 体重与关键区别 |
|---|---|---|---|
| 神经性贪食 | 有，反复 | 有（催吐、泻药、禁食、过度运动等） | 多数正常；自我评价被体重体形绑住 |
| 暴食障碍 | 有，反复 | 没有 | 常偏高；暴食后痛苦但不用清除/禁食等补偿 |
| 神经性厌食（暴食清除型） | 有 | 有 | 明显偏低；整体表现符合厌食 |
| 抑郁障碍 | 可能暴食（非典型抑郁） | 少见 | 可能增加；核心是情绪低落、兴趣丧失，不是体像 |

还有几类需要排开：

- **躯体疾病**：甲亢（吃得多、瘦、心慌）、糖尿病（多食多饮多尿）、胃肠疾病、寄生虫、吸收不良；
- **药物**：糖皮质激素、部分抗精神病药、部分抗抑郁药、胰岛素或降糖药引起的食欲增加；
- **其他精神障碍**：夜间进食综合征、冲动控制问题、双相躁狂期的进食增多、边缘型人格的冲动行为、创伤后的情绪性进食。

医生通常还会问：暴食前是什么情绪？孤独、无聊、愤怒、被批评之后？——这决定了治疗重点，也帮助区分“进食障碍”与“用吃来调节情绪”。

## 六、羞耻与隐瞒：为什么难开口

羞耻是贪食最典型的体验之一。很多人从来没跟任何人说过催吐，连配偶都不知道；有人专门练习“无声呕吐”，有人把食物包装藏起来，有人用两三个外卖账号。

这带来一个现实问题：**越羞耻，越晚就诊；越晚就诊，躯体风险越高。** 医生问这些问题不是为了评判，而是因为不问就查不出原因。

如果你准备开口，可以用一句很朴素的话起头：“我吃东西会控制不住，吃完会想办法吐掉，这件事我没跟别人说过。”剩下的医生会接着问。你也可以先写在纸上递给医生，很多人这样更容易说出口。

## 七、就诊准备清单

- [ ] 暴食频率：最近一个月大概多少次，一次吃多少（用具体食物举例比“很多”有用）
- [ ] 失控感：能不能中途停下，通常吃到什么程度才停
- [ ] 补偿方式：催吐、泻药、利尿剂、减肥药、灌肠、禁食、过度运动，各自频率
- [ ] 体重变化：现在、最高、最低；有没有被家人说“最近瘦了/胖了”
- [ ] 躯体症状：心悸、乏力、晕倒、呕血、腹痛、牙齿敏感、腮腺肿
- [ ] 月经情况（女性）；性欲与精力变化
- [ ] 情绪：暴食前后的情绪，有没有抑郁、焦虑、自伤、自杀念头
- [ ] 花钱与藏食物的情况：家人可补充观察
- [ ] 既往检查：血钾、电解质、心电图、胃镜、牙科记录
- [ ] 用药与保健品：减肥药、泻药、代购药、中药
- [ ] 家族史：进食障碍、抑郁、焦虑、酒精使用
- [ ] 想问医生的问题：需要查哪些血、要不要做心电图、心理治疗怎么安排

## 常见误区

- **“吐出来就不会胖，所以没事。”** 催吐不能完全阻止吸收，却会带来低钾和心律失常。
- **“体重正常，说明不严重。”** 贪食的严重度更多看频率、电解质和情绪风险，不看体重。
- **“就是自制力差。”** 暴食时的失控是症状，不是道德缺陷；靠“下决心”通常无效。
- **“多吃点、别吐就好了。”** 突然停止清除可能引发电解质波动，最好在医生指导下调整。
- **“只有女生才会得。”** 男性也会，且更容易被漏诊。
- **“这是减肥的后遗症，瘦下来就好了。”** 减重往往是诱因，不是解法；不处理循环，体重反弹后行为照旧。

## 确诊之后通常怎么走

规范做法通常包括：先评估躯体风险（电解质、心电图、牙齿），再安排心理治疗（认知行为取向的进食障碍治疗是常用的一线思路【指南】），必要时联合营养咨询与精神科药物。合并抑郁、焦虑、创伤时，治疗顺序由医生根据风险决定。**具体用什么药、用多久，不在本页范围。**

对家属来说，最有帮助的不是监督和盘问，而是：不评论体重和外貌，不在饭桌上审判，把“去就诊”当成一件正常的事陪着去。
