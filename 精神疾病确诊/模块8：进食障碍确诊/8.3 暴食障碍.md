# 8.3 暴食障碍

暴食障碍是最常见、也最容易被当成“胖是因为不自律”的一类进食障碍。它和神经性贪食的关键差别只有一句话：**暴食之后没有反复的清除或补偿行为**。这一页讲医生依据什么考虑这个诊断、体重与代谢在其中扮演什么角色、以及它和贪食、抑郁、单纯肥胖怎么分开。

## 一、反复暴食 + 失控 + 痛苦，三者缺一不可

【指南】按 DSM-5-TR 的思路，医生考虑暴食障碍时会看：反复出现的暴食发作；暴食时明显感觉失控；暴食后有明显痛苦（厌恶、内疚、抑郁）；并且没有反复使用不恰当的补偿行为。频率通常按每周至少一次、持续三个月把握。具体条目与时间门槛以 DSM-5-TR、ICD-11 原文和医生访谈为准。

这里的重点是“三者缺一不可”：

- **只有吃得多**，没有失控感，可能只是食量大、社交性进食、或药物引起的食欲增加；
- **只有失控感**，量并不大（有人把“吃了一块蛋糕”也叫暴食），更可能是限制性进食后的心理反弹或焦虑；
- **只有痛苦**，没有暴食，可能指向抑郁、羞耻感或体像问题。

### 暴食的具体样子

医生会问得很细，因为“暴食”这个词每个人理解不同：

- 一个独立时间段内吃下的量，明显多于多数人在同样情境下的量；
- 吃得比平时快很多；
- 吃到身体不舒服、撑得难受还继续；
- 不饿的时候也大量进食；
- 因为羞于被看见而独自吃；
- 事后强烈自责、情绪低落。

DSM-5-TR 还列了几个“伴随特征”，比如吃得比平时快、吃到撑得难受还继续、不饿时也大量进食、因羞于被看见而独自吃、事后厌恶自己或情绪低落。这些不是必须全部满足，而是帮助医生判断这是不是典型的暴食，而不是“节假日吃多了”。

### 失控感：最难描述、也最关键

很多人形容不出来，只会说“停不下来”“像有人在推着我吃”“手不听使唤”。可以这样自测式回忆（不是诊断）：**当时你能不能选择停下？停下来有多难？** 如果答案是“想停但停不下来”，这个信息对医生很重要。

## 二、没有清除行为，是它和贪食的分水岭

| 特征 | 暴食障碍 | 神经性贪食 |
|---|---|---|
| 反复暴食 | 有 | 有 |
| 暴食时失控感 | 有 | 有 |
| 清除/补偿行为 | 没有 | 有（催吐、泻药、禁食、过度运动等） |
| 典型体重 | 常偏高，也有正常或偏低 | 多数正常 |
| 典型情绪 | 暴食后内疚、抑郁、羞耻 | 同左，常更强烈，伴体像焦虑 |
| 就诊常见主诉 | 减肥失败、血糖高、情绪差 | 胃不舒服、月经乱、牙齿问题 |

需要提醒：两者可以互相转换。有人在严格节食后先出现贪食，后来停止催吐，行为模式就变成暴食障碍；也有人反过来。**诊断看的是某一段时间的模式，不是一个人的永久属性。**

## 三、体重与代谢：相关，但不是同一件事

暴食障碍与体重偏高在统计上相关【研究】，但两者不是一回事：

- **多数体重偏高的人没有暴食障碍**。肥胖是一个身体状态，成因包括遗传、药物、睡眠、活动量、社会经济条件；
- **不少暴食障碍患者体重正常甚至偏低**；
- **把“胖”直接等同于“暴食障碍”，是一种常见的诊断错误**，也会加重体重污名。

暴食障碍真正需要关注的是代谢后果：

- 2 型糖尿病风险升高，血糖控制更差；
- 高血压、血脂异常；
- 非酒精性脂肪肝；
- 睡眠呼吸暂停（夜间憋醒、打鼾、白天嗜睡）；
- 关节负担、活动受限；
- 反复减重—反弹的“体重循环”，本身对代谢不利。

所以医生通常会查：身高体重、腰围、血压、空腹血糖或糖化血红蛋白、血脂、肝功能、必要时做睡眠监测。这些检查不是给暴食障碍“确诊”用的，而是评估它已经造成了什么。

## 四、病程、功能损害与严重度

暴食障碍常起病于青少年后期或二十多岁，也可能中年才明显。病程往往很长，很多人“减了十几年肥”，从没把暴食当成一个需要治疗的问题。

功能损害常被低估：

- **身体**：体重上升、血糖血脂异常、关节痛、睡眠差；
- **心理**：羞耻、自我厌恶、抑郁、焦虑，部分人回避社交和亲密关系；
- **社会**：回避游泳、拍照、体检；因体重被议论、被歧视；
- **经济**：反复买减肥产品、代餐、私教课程，花费大量金钱；
- **医疗**：反复减重门诊、内分泌门诊，却没人问“你会不会控制不住地吃”。

严重度上，DSM-5-TR 按暴食发作频率分档（轻度、中度、重度、极重度）。但临床上更看功能损害和代谢并发症：一个每周暴食两次、已经出现糖尿病的人，比一个每周四次、代谢正常的人更需要积极处理。

## 五、鉴别：和贪食、抑郁、单纯肥胖分开

至少四类情况需要排开：

**1. 神经性贪食。** 关键是有没有反复补偿行为。有些人会隐瞒催吐，医生需要直接问，或看腮腺、牙齿、手背、血钾。

**2. 抑郁障碍。** 非典型抑郁可以表现为食欲增加、体重增加、嗜甜，容易被当成暴食障碍。区别在于：抑郁的核心是持续的情绪低落和兴趣丧失，进食增多是其中一个表现；暴食障碍的核心是失控的暴食发作和围绕它的痛苦，情绪问题常是后果而非原因。两者也常常并存，需要医生判断先后与主次。

**3. 单纯肥胖与代谢疾病。** 没有反复失控暴食，只是体重高，不构成暴食障碍。反过来，也不能因为体重高就默认有暴食障碍。甲状腺功能减退、库欣综合征、下丘脑性肥胖等躯体原因也要排开。

**4. 药物与其他精神障碍。** 糖皮质激素、部分抗精神病药、部分抗抑郁药、胰岛素或降糖药可引起食欲明显增加；夜间进食综合征（晚上吃得最多、夜间醒来进食）、持续进食（整天不停地少量吃）、冲动控制问题、双相躁狂期的进食增多，都需要区分。Prader-Willi 综合征等遗传病也会有明显贪食，但通常起病更早、伴发育与智力问题。

## 六、体重污名：为什么很多人不愿就诊

“你这么胖，就是吃出来的”——这句话在诊室里出现的频率很高，也是很多人不敢就医的原因。体重污名会带来两个后果：患者把暴食藏得更深；医生把注意力全放在减重上，漏掉进食行为本身。

可以主动说的一句话是：“我不是来减肥的，我是想说我吃东西会失控。”这句话能把话题从体重挪到行为，而行为才是诊断的入口。

同时也要说清楚：**暴食障碍的治疗目标通常不是“降到某个体重”，而是减少暴食发作、改善情绪与代谢指标。** 只盯着体重，容易再次陷入“节食—暴食”的循环。

## 七、就诊准备清单

- [ ] 暴食频率：最近一个月多少次，通常在什么时间、什么情境
- [ ] 一次大概吃多少：用具体食物描述（“两碗饭、一整袋面包、一盒冰淇淋”）
- [ ] 失控程度：能不能中途停，什么情况下更容易失控
- [ ] 有没有清除行为：催吐、泻药、利尿剂、禁食、过度运动（这一条必须如实说）
- [ ] 体重轨迹：最高、最低、近一年变化；有没有反复减重
- [ ] 代谢相关：血糖、血脂、血压、脂肪肝、打鼾与白天嗜睡
- [ ] 情绪：暴食前后的情绪；有没有抑郁、焦虑、自伤、自杀念头
- [ ] 用药：激素、抗精神病药、抗抑郁药、降糖药、减肥药
- [ ] 家族史：肥胖、糖尿病、进食障碍、抑郁、酒精使用
- [ ] 想问医生的问题：需不需要查血糖血脂、心理治疗怎么排、要不要同时看营养科

## 常见误区

- **“暴食障碍就是贪吃。”** 暴食是有失控感和痛苦的发作，贪吃是享受，两者体验完全不同。
- **“不催吐就不严重。”** 暴食障碍的代谢后果和抑郁风险都很实在，不需要“吐”才算病。
- **“减到标准体重就好了。”** 不处理暴食循环，减重后反弹概率高，且可能加重羞耻。
- **“胖的人都有暴食障碍。”** 多数体重偏高的人并没有暴食发作。
- **“这是意志力问题，管住嘴就行。”** 靠意志对抗失控发作，通常失败并加重自责。
- **“孩子能吃是福。”** 如果孩子反复吃到难受、躲着吃、事后自责，需要问一问。

## 确诊之后通常怎么走

规范做法通常包括：心理治疗（认知行为取向的进食障碍治疗、人际心理治疗是常用思路【指南】）、营养与代谢管理、处理共病（抑郁、焦虑、睡眠呼吸暂停）。药物可能在合并抑郁或特定情况下使用，**具体方案由面诊医生决定，本页不涉及剂量**。减重手术不是暴食障碍的常规首选，术前通常需要先处理暴食行为。

对家属来说，最有用的是把评论体重的话咽回去，把“陪你去看医生”说出来。

> **什么时候需要联系医生 / 去急诊**
>
> 暴食障碍很少像厌食那样急，但有些情况不能等：剧烈腹痛且持续加重、呕吐不止、腹胀到无法呼吸（警惕急性胃扩张，虽罕见但凶险）；胸痛、心悸、晕厥；糖尿病患者出现低血糖或明显高血糖伴乏力、恶心、呼吸深快；进食时突然呛咳、呼吸困难（噎食）。
>
> 如果出现自杀念头、自伤行为，或已经写下计划，请不要独处，让家人陪着，拨 **120** 或去精神科急诊；也可拨 **12356** 心理援助热线。暴食障碍合并抑郁和自杀风险并不少见，**“只是吃的问题”这个说法会耽误事**。
