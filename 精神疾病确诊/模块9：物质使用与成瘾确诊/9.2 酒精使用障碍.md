# 9.2 酒精使用障碍

酒精是中国人最常接触的成瘾物质，也是最容易被“应酬”“解压”“助眠”这些说法遮住的一类。酒精使用障碍的诊断并不看你喝什么酒、跟谁喝，而看控制、后果和身体反应。这一页讲医生怎么问饮酒史、耐受和戒断意味着什么、肝病与酒精所致精神障碍怎么识别，以及**为什么有些人不能自己在家硬戒**。

## 一、饮酒模式：量、频率、情境、失控

医生问饮酒史，通常不只问“喝不喝”，而是问出一张时间表：

- **喝什么、多少度、一次多少**：用“几两白酒/几瓶啤酒/几杯红酒”描述，比“一点”有用；
- **多久一次**：每天、每周几次、还是“一喝就连续几天”；
- **什么时候喝**：晚饭时、应酬时、睡前、还是**早上醒来先喝一口**；
- **和谁喝**：只在场合上喝，还是独自在家喝；
- **空腹喝**：空腹饮酒吸收快，伤害更大；
- **喝了之后做什么**：睡觉、发脾气、开车、失忆。

几个在临床上被反复提到的警示信号：

| 信号 | 含义 |
|---|---|
| 晨起饮酒（“回魂酒”） | 提示夜间已出现戒断，需要用它缓解 |
| 独自饮酒、藏酒 | 羞耻与失控的常见表现 |
| 一喝就停不下来（“一口就喝到断片”） | 控制受损的典型描述 |
| 因喝酒推掉工作、家庭、爱好 | 功能损害 |
| 明知肝病、胰腺炎、胃出血仍喝 | 危险使用 |

需要说明：**“每天喝”不等于酒精使用障碍，“偶尔大醉”也不等于没问题**。诊断看的是模式、失控与后果的组合。中国居民膳食指南对成年人饮酒有“如饮酒应限量”的表述，但限量建议不是诊断标准，也不能拿来给某个人“下结论”。

### 病程与功能损害

酒精使用障碍的病程差异很大：有人二十多岁开始每天大量饮酒，十多年后因肝病就诊；有人四十岁后因应酬逐渐加量，退休后才明显；也有人平时不喝、一喝就连续几天。**起病越早、喝得越密、戒断越重，病程越容易迁延。**

功能损害是诊断的必要部分，通常分布在：工作（缺勤、失误、被辞退）、家庭（争吵、冷战、离婚、子女照护受影响）、经济（酒钱、负债）、健康（肝病、外伤、胰腺炎）、法律（酒驾）。评估时医生会分别问本人和家属，因为两者报告常常不一致：本人低估，家属高估。

## 二、耐受与戒断：为什么不能自己硬戒

### 耐受

长期饮酒后，肝脏代谢酶被诱导、中枢神经系统适应，同样量的酒效果变弱。表现为“以前二两就上头，现在半斤才有感觉”。耐受提高意味着身体已经在改变，也是过量中毒风险上升的原因之一。

### 戒断：一张有时间表的过程

酒精是镇静类物质，长期使用后大脑习惯了它的抑制，一旦撤掉，神经系统会“反弹”过度兴奋。戒断反应通常按以下节奏出现（个体差异大，仅作理解）：

- **停酒后 6–24 小时**：手抖、出汗、心慌、恶心、焦虑、失眠、血压升高；
- **12–24 小时**：可能出现幻觉（酒精性幻觉症），意识通常清醒，能分辨“这是幻觉”；
- **24–48 小时**：可能出现癫痫样抽搐（“酒精性癫痫”），尤其在既往有戒断抽搐史的人；
- **48–96 小时**：**震颤谵妄**（delirium tremens，DT）——意识模糊、定向力差、明显震颤、大汗、发热、心跳很快、幻觉、极度不安。这是酒精戒断最危险的形式，不处理可危及生命。

还有一个现象叫**“点燃效应”**（kindling）：每一次严重的戒断，都会让下一次戒断来得更快、更重。所以“上次自己扛过来了”不是可以再扛的理由，而是风险更高的信号。

**这也是本页最重要的一句话：长期大量饮酒的人不要自行突然停酒。** 正确做法是先做评估，在医疗监护下戒断，必要时用苯二氮䓬类药物替代并逐渐减量（具体方案由医生决定，本页不涉及剂量）。

## 三、酒精相关躯体损害：肝病只是其中一件

长期饮酒几乎影响每个系统：

- **肝脏**：酒精性脂肪肝 → 酒精性肝炎 → 肝硬化；肝硬化后可能出现腹水、黄疸、食管胃底静脉曲张出血、肝性脑病；
- **胰腺**：急慢性胰腺炎，反复上腹痛、脂肪泻、血糖升高；
- **消化道**：胃炎、反流、食管炎、Barrett 食管、消化道出血；
- **心血管**：高血压、酒精性心肌病、心律失常（“假日心脏综合征”——周末大量饮酒后房颤）；
- **神经系统**：周围神经病变（手脚麻木）、小脑变性（走路不稳、说话含糊）、认知下降；
- **营养与代谢**：硫胺素（维生素 B1）缺乏可致**韦尼克脑病**（意识模糊、眼球运动异常、走路不稳），延误可发展为**科萨科夫综合征**（近事记忆严重受损、编造内容填补空白）；
- **感染与外伤**：免疫力下降、肺炎、结核；跌倒后硬膜下血肿；
- **肿瘤**：口腔、咽、食管、肝、结直肠等风险升高【研究】；
- **生殖与胎儿**：男性性功能下降、女性月经紊乱；孕期饮酒可致胎儿酒精谱系障碍。

这些损害有一个共同点：**早期往往没感觉**。很多人第一次发现，是体检肝酶升高，或一次呕血。

## 四、酒精所致精神障碍

酒精不只是“伤身”，它本身就能制造精神症状：

- **酒精性幻觉症**：停酒后出现听幻觉，意识清楚，可持续数天到数周；
- **酒精所致精神病性障碍**：被害妄想、嫉妒妄想（“我配偶出轨”），常与长期大量饮酒有关；
- **酒精所致抑郁障碍**：饮酒期或戒断期出现情绪低落、兴趣丧失，停酒后多数在数周内改善；
- **酒精所致焦虑障碍**：戒断期心慌、出汗、坐立不安，很容易被误当成“焦虑症”；
- **酒精所致睡眠障碍**：酒能让人入睡快，但会破坏后半夜睡眠，长期反而加重失眠；
- **酒精所致认知障碍/痴呆**：以记忆、执行功能下降为主；
- **震颤谵妄**：见上文，属急症。

区分“酒精所致”与“原发性”，关键看时间关系：症状是否只在饮酒期或戒断期出现、停酒后是否在数周内明显缓解、既往是否在没有饮酒时也有同样发作。这一部分在 [9.4 物质所致精神障碍与原发性障碍](<9.4 物质所致精神障碍与原发性障碍.md>) 里详细讲。

## 五、鉴别：这些情况也可能“像喝酒喝出来的”

| 情况 | 相似之处 | 关键区别 |
|---|---|---|
| 原发性焦虑/抑郁 | 心慌、出汗、失眠、情绪低 | 起病早于饮酒、停酒后仍持续、无戒断时间关系 |
| 双相障碍 | 话多、兴奋、少睡、冲动 | 有明确的躁狂/轻躁狂发作史，不只出现在饮酒期 |
| 癫痫 | 抽搐 | 酒精性抽搐多在停酒后 24–48 小时；原发性癫痫有既往发作与脑电图特点 |
| 低血糖 | 手抖、出汗、意识模糊 | 测血糖可辨；饮酒后进食少的人风险更高 |
| 肝性脑病 | 意识模糊、行为异常、手抖 | 有肝硬化背景、血氨升高、扑翼样震颤 |
| 硬膜下血肿 | 意识改变、头痛、嗜睡 | 近期跌倒史，需影像学 |
| 镇静药戒断 | 与酒精戒断几乎一样 | 用药史；两者常叠加，风险更高 |

医生还会排除：甲状腺功能异常、低钠血症、感染、药物相互作用。**不要把“喝酒的人出现精神症状”一律归给酒精**，也不要一律归给精神科——两头都可能漏。

## 六、筛查与就诊准备

常用筛查工具是 AUDIT（酒精使用障碍筛查问卷）和 AUDIT-C（简版），它们用于发现风险、决定是否需要进一步评估，**不能用来确诊**。分数高提示值得细问，分数低也不能完全排除，尤其当事人低报时。

就诊前可以准备：

- [ ] 饮酒清单：种类、度数、每次量、每周次数、最近一次喝是什么时候
- [ ] 有没有晨起饮酒、独自饮酒、藏酒、断片
- [ ] 最长一次停酒多久，停时出现过什么症状
- [ ] 有没有戒断抽搐、幻觉、谵妄史（这一条直接关系戒断方案）
- [ ] 躯体问题：肝病、胰腺炎、胃出血、高血压、心律不齐、手脚麻木、走路不稳
- [ ] 情绪与睡眠：抑郁、焦虑、失眠、噩梦
- [ ] 功能影响：工作、家庭、经济、驾驶、法律
- [ ] 用药清单：镇静催眠药、止痛药、中药、保健品（与酒精叠加的风险）
- [ ] 家族史：酒精使用、抑郁、双相
- [ ] 近期化验：肝功能、血常规、凝血、血糖、电解质、腹部超声
- [ ] 想问医生的问题：需不需要住院戒断、有没有戒断风险、家属怎么配合

家属提供的信息很重要，尤其是“他自己说一周喝两次，实际每天都喝”这类差异。**记录比质问有用**：把空瓶、外卖记录、酒后行为记下来，比争吵更能帮医生判断。

> **什么时候需要联系医生 / 去急诊**
>
> 以下情况不要在家观察：
>
> - 停酒后出现**抽搐**、**幻觉**、**意识模糊**、**大汗发热心跳很快**——警惕戒断抽搐与震颤谵妄，立即拨 **120**；
> - 呕血、咖啡色呕吐物、黑便——警惕消化道出血；
> - 剧烈上腹痛、呕吐不止——警惕急性胰腺炎；
> - 意识不清、叫不醒、呼吸慢、体温低——警惕酒精中毒、低血糖；
> - 头部外伤后嗜睡、呕吐、瞳孔不等大；
> - 出现被害感、极度兴奋、冲动伤人风险——先保证安全，拨 **120** 或 **110**。
>
> 另一条常被忽略：**长期大量饮酒者不要自行“干戒”**。如果本人愿意停酒，先联系精神科或戒酒门诊评估，安排安全的戒断方式。也可拨 **12356** 心理援助热线。

## 常见误区

- **“红酒养生，所以不算。”** 酒精本身就是致癌物，酒的种类不改变风险。
- **“我酒量好，说明肝好。”** 酒量好多是耐受，不代表器官没受损。
- **“能自己停几天，就没成瘾。”** 停几天后再喝、且越喝越多，恰恰是控制受损的表现。
- **“戒断熬过去就行。”** 震颤谵妄有生命危险，硬扛是在赌。
- **“喝酒的人不会得抑郁，是喝出来的。”** 两者可以互相加重，需要分别评估。
- **“只要不喝就没事了。”** 长期饮酒造成的肝损、神经损害、认知损害，需要单独评估和处理。

## 确诊之后通常怎么走

规范做法通常包括：评估戒断风险与躯体状况、在医疗监护下完成戒断、补充营养（尤其硫胺素）、处理肝病等并发症、心理社会干预（动机访谈、认知行为取向、家庭参与）、必要时使用减少渴求或预防复发的药物。**具体药物与方案由面诊医生决定，本页不涉及剂量。**

对家属来说，最有用的是：把“你怎么又喝”换成“我们一起去看看医生”，并在本人同意的前提下参与治疗。
