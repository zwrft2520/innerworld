# 9.4 物质所致精神障碍与原发性障碍

同一个幻觉，可能来自精神分裂症，也可能来自连续几天的冰毒；同一段抑郁，可能是原发性抑郁，也可能是停酒后的戒断期。这两类情况处理方式不同，误判的代价也不同。这一页讲医生靠什么把“物质所致”和“原发精神障碍”分开，尿检能证明什么、不能证明什么，以及判断不清楚时应该先做什么。**读完能带走一句：时间关系是线索，不是判决；停药观察比一次化验更有分量。**

## 一、判断的四个支点

【指南】DSM-5-TR 对“物质/药物所致精神障碍”的思路，大致可以拆成四问：症状是不是在中毒或戒断期间（或刚结束后）出现？这种物质本身有没有能力产生这类症状？症状能不能用独立的精神障碍更好地解释？症状是否只出现在谵妄过程中？这四问没有一条能单独定案，必须合起来看。

### 支点一：时间关系

时间关系是最有用、也最容易被误用的线索。

- **支持物质所致**：症状在开始使用、加量、或停药后短时间内出现；症状的起伏与使用/停用同步；以前每次用这种物质都出现类似表现。
- **支持原发**：症状在长期不使用物质时也出现过；首次发作明显早于物质使用；停药很久后仍持续。

多数物质所致的精神症状会在停用后数天到数周内明显减轻。临床上常把“停用后一段时间仍不缓解”作为转向原发诊断的重要提示，但**具体观察多久、怎么算缓解，DSM-5-TR 与 ICD-11 的表述不完全一样，也因物质种类而异**（比如大麻、苯二氮䓬类半衰期长，症状拖得更久）。所以不要拿“满一个月”当硬杠。

### 支点二：停药观察

停药观察是这套判断里最朴素、也最可靠的一步：在安全的前提下，让当事人停用一段时间（同时处理戒断），再看症状剩下多少。

- 如果停用后幻觉消失、情绪回到基线，物质所致的可能性大；
- 如果停用后症状依旧、甚至更清楚，原发障碍的可能性上升；
- 如果停用后症状先好转、后来又出现，需要考虑两种可能：复吸，或原发障碍在停药后显露。

停药观察有两个前提：**安全**（不能让人在无人看护下自行硬戒酒精或镇静剂）和**时间**（观察期要足够长，且期间最好有尿检或家属确认没有复吸）。

### 支点三：尿检

尿检（尿液药物筛查）是重要工具，但它证明的东西比很多人以为的少。

| 能证明 | 不能证明 |
|---|---|
| 最近一段时间内用过某类物质 | 用的是什么纯度、多少量、用了多久 |
| 当事人是否如实报告（配合访谈） | 症状是不是由该物质引起 |
| 戒断期间是否偷偷复吸 | 精神障碍是原发还是继发 |
| 是否存在混用 | 新型精神活性物质（常检测不到） |

还有两个现实问题：

- **窗口期**：不同物质在尿里能查到的时间差别很大。酒精代谢快，常规尿检查不到，需要测乙基葡萄糖醛酸苷等指标；大麻在规律使用者体内可存留较久；可卡因、阿片类、苯丙胺类通常只有几天。**尿检阴性不等于没用过，阳性也不等于“就是它导致的”。**
- **假阳性与假阴性**：部分药物、食物（如大量罂粟籽）可能造成假阳性；合成大麻素、部分新型物质常规筛查查不出。有疑问时需要用质谱等确证方法。

所以尿检的正确用法是：**配合访谈，验证时间线，而不是代替诊断。**

### 支点四：纵向病史与旁证

医生会尽量还原一条时间线：第一次精神症状是几岁？那时有没有用物质？有没有在不使用物质的时期也发作过？家族里有没有精神分裂症、双相、抑郁？病前功能如何（学业、工作、人际）？

旁证同样重要：家属观察到的“用之前就有点不对劲”、旧病历、学校记录、体检记录。**很多“物质所致还是原发”的难题，最后是靠时间线解开的，而不是靠一次急诊访谈。**

## 二、先按物质所致处理，还是先治原发

这是临床上最实际的问题，也是家属最常问的：“到底该按哪个治？”

比较稳妥的顺序通常是：

1. **先保证安全**：处理中毒、戒断、自伤自杀风险、冲动伤人风险、躯体并发症。这一步不分原发继发。
2. **处理可逆因素**：补液、纠正电解质、补充硫胺素、控制兴奋激越、治疗感染或外伤。
3. **创造“干净”的观察窗**：在医疗支持下停用相关物质，尽量让症状在没有物质干扰的情况下显露。
4. **重新评估**：症状是否持续、是否符合某个原发障碍的完整标准（病程、功能损害、排除条件）。
5. **该治就治**：如果原发障碍的证据足够，按原发障碍治疗；如果仍不明确，按“待观察”处理，同时处理共病，而不是无限期等待。

这里有一个常见的极端：**“等戒了再说”**。对酒精、镇静剂依赖者，这句话有时是必要的；但对有明显抑郁、精神病性症状、自杀风险的人，一味等待戒断会耽误治疗。反过来，另一个极端是**“一看到用物质就把所有症状归给它”**，结果原发障碍被漏掉，出院后很快复发。

【临床经验】多数成瘾治疗机构采取的是“整合治疗”：物质使用与精神症状同时处理，而不是先治好一个再治另一个。

## 三、共病：双重诊断是常态而不是例外

【研究】物质使用障碍与抑郁、焦虑、PTSD、ADHD、双相、精神分裂症的共病率很高。共病不是“多贴一个标签”，它影响病程、治疗反应和风险：

- 抑郁 + 酒精：自杀风险叠加，酒精会削弱冲动控制；
- 焦虑 + 镇静剂：容易形成“焦虑—用药—耐受—反跳—更焦虑”的循环；
- PTSD + 兴奋剂或大麻：常被当作“自我治疗”失眠与噩梦；
- ADHD + 兴奋剂：处方兴奋剂滥用与未治疗 ADHD 都常见，需要仔细区分；
- 精神分裂症 + 物质：症状加重、复发率升高、抗精神病药依从性下降。

评估共病时，医生会尽量判断“谁先谁后、谁在维持谁”，但也要接受一个现实：**有时分不清先后，仍然可以同时治疗。**

## 四、容易混淆的几种情况

| 表现 | 更像物质所致 | 更像原发障碍 |
|---|---|---|
| 幻觉、被害感 | 使用兴奋剂/大麻/酒精后数小时至数天出现，停用后较快缓解，自知力恢复 | 停用数周仍存在，伴阴性症状、思维形式障碍、功能持续下降 |
| 情绪低落 | 停酒或停兴奋剂后出现，数周内改善 | 起病早于物质使用，或停用后持续超过数周 |
| 焦虑、心慌 | 戒断期、咖啡因或兴奋剂之后 | 起病早于物质使用，无戒断时间关系 |
| 失眠 | 兴奋剂、戒断期 | 长期存在，与物质无关 |
| 意识模糊、注意力波动 | 中毒、戒断性谵妄、感染、电解质紊乱 | 谵妄本身即为躯体急症，不属于“原发精神障碍” |

还有几类必须排开的“模仿者”：

- **躯体疾病**：甲亢、低血糖、低钠、感染、肝性脑病、自身免疫性脑炎、癫痫发作后状态；
- **药物**：激素、抗胆碱能药、部分抗生素、抗帕金森药、部分中药——重点是“新加的药”与症状的时间关系；
- **谵妄**：意识水平和注意力波动是核心，属急症，不能按精神病性障碍处理；
- **做作性障碍/装病**：少见，但涉及法律或赔偿时需谨慎，不能只凭印象判断。

## 五、就诊准备清单

- [ ] 症状时间线：第一次出现是什么时候，当时有没有用物质
- [ ] 物质时间线：第一次使用、最近一次使用、用量、频率、是否混用
- [ ] 有没有“不用物质的时期”也出现同样症状，持续多久
- [ ] 停药后症状是好转、不变还是加重（家属观察很关键）
- [ ] 既往精神科诊断与用药，包括停药原因
- [ ] 家族史：精神分裂症、双相、抑郁、物质使用
- [ ] 病前功能：学业、工作、人际、性格变化
- [ ] 躯体排查：甲状腺、血糖、电解质、肝肾功能、感染指标、必要时影像
- [ ] 尿检/血检结果（如有），以及检测时间
- [ ] 想问医生的问题：现在按哪个方向治、观察多久、什么时候复评

> **什么时候需要联系医生 / 去急诊**
>
> 以下情况不要等门诊：
>
> - 意识模糊、注意力涣散、胡言乱语、认不出人——可能是谵妄，属急症；
> - 停酒或停镇静药后抽搐、幻觉、大汗发热——戒断谵妄，可致命；
> - 胸痛、心跳极快或很乱、高热、抽搐；
> - 叫不醒、呼吸慢、嘴唇发紫——警惕过量；
> - 出现命令性幻听、坚信被迫害而准备“反击”、有明显伤人风险——先保证安全，拨 **120** 或 **110**；
> - 自杀念头、自伤行为或已写下计划。
>
> 到急诊时，请如实说明物质使用情况，即使涉及违法内容——医生关注的是抢救，不是追责。也可拨 **12356** 心理援助热线。

## 常见误区

- **“尿检阳性就说明精神病是吸毒吸出来的。”** 阳性只能说明用过，不能说明因果。
- **“尿检阴性就说明他没吸毒。”** 窗口期、假阴性、新型物质都会让结果失真。
- **“等戒干净了再看精神问题。”** 有自杀风险或严重精神病性症状时，等待可能有害。
- **“既然有物质使用，就不用治抑郁了。”** 共病需要同时处理，否则互相拖累。
- **“一次急诊看到幻觉就定了精神分裂症。”** 诊断需要纵向病程，急诊访谈只是起点。
- **“物质所致的精神症状会自己好，不用管。”** 多数会缓解，但期间的冲动、自伤、事故风险是真实的。

## 确诊之后通常怎么走

规范做法通常包括：先处理安全与可逆因素，再在“干净”的观察窗内复评；明确原发障碍的，按原发障碍治疗；不明确的，标注“待观察”并安排随访；同时处理物质使用与精神共病。**药物选择与疗程由面诊医生决定，本页不涉及剂量。** 对家属来说，最有帮助的是记录时间线、保管好药物、减少家中酒精与镇静剂的可及性。
