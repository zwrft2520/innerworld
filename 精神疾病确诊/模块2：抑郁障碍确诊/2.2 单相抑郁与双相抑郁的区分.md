# 2.2 单相抑郁与双相抑郁的区分

很多人被诊断为抑郁后，会听到医生反复问一些“奇怪”的问题：有没有一段时间睡得很少却很精神？有没有花钱特别大手大脚？有没有觉得自己特别有能力？这些问题的目标只有一个——把单相抑郁和双相抑郁分开。这一页讲为什么要追问轻躁狂史、抗抑郁药后“像变了一个人”可能意味着什么、双相抑郁有哪些容易被忽略的特征。适合已经确诊抑郁但疗效不理想、家族里有双相、或正在用抗抑郁药的人。

## 一、医生为什么总要追问“轻躁狂”

“单相抑郁”不是 DSM-5-TR 里的正式名称，而是临床上的简称：只有抑郁发作，没有躁狂或轻躁狂发作。双相障碍则至少要有过一次躁狂或轻躁狂，抑郁并不是必需条件。两者在抑郁期的表现可以非常像，但治疗方向不同：双相抑郁通常需要以心境稳定剂（俗称情绪稳定剂）为骨架，单用抗抑郁药可能带来转躁、混合状态或循环加速的风险【指南】。

难点在于，轻躁狂常常不被当成病。处在轻躁狂里的人，往往觉得自己“终于正常了”“状态最好”，不会主动告诉医生；家人也可能觉得“那段时间挺有活力”。于是，患者带着抑郁来就诊，医生只看到抑郁，诊断就停在单相。

| 线索 | 更支持单相抑郁 | 更支持双相抑郁 | 需要核对什么 |
|---|---|---|---|
| 既往高涨期 | 从没有过持续几天的高涨或易激惹 | 有过四天以上的轻躁狂，或一周以上的躁狂 | 睡眠需求、话量、花钱、计划性 |
| 家族史 | 抑郁为主 | 双相、精神病性抑郁、自杀或严重药物反应 | 尽量问到两级亲属 |
| 起病年龄 | 各年龄段均可 | 青少年期、产后或季节相关起病更常见 | 第一次发作的时间点 |
| 治疗反应 | 抗抑郁药逐渐起效 | 抗抑郁药无效、越用越烦躁，或一用就“变了一个人” | 用药与症状变化的时间关系 |

单靠一条线索不能定方向。医生会把起病年龄、发作次数、发作间期、产后或季节规律、精神病性症状、家族史、药物反应拼在一起看，再决定要不要按双相重新评估。**不要因为自己“对上了两条”就自行改诊断或停药。**

需要排除的至少有三类：单相抑郁（从来没有轻躁狂或躁狂）、物质或药物所致的心境改变（兴奋剂、类固醇、甲状腺素、抗抑郁药等）、以及其他精神障碍（边缘型人格、ADHD、创伤后应激、分裂情感）。三类的线索不同，处理方向也不同。诊断双相还要求发作达到时间门槛（轻躁狂四天、躁狂一周）并造成明显功能改变或需要住院，不能只凭一次情绪波动。

## 二、双相抑郁常见的“非典型”特征

抑郁的“非典型特征”是一个术语，指与“典型”抑郁（失眠、食欲下降、体重减轻）相反的一组表现：睡得过多、食欲增加、体重增加、四肢像灌了铅一样沉重、对好消息仍有短暂的情绪反应、对被拒绝特别敏感。这些特征在双相抑郁中更常见，但在单相抑郁里也不少见，所以只能当线索，不能当证据。

临床上，以下情况会让医生更警惕双相：

- 抑郁发作来得早，青少年期或二十岁前后首次发作；
- 产后或季节性发作明显，每年同一时段复发；
- 抑郁反复发作、次数多，但每次持续时间相对短；
- 抑郁伴精神病性症状，尤其是罪恶、贫穷、虚无等与心境一致的妄想；
- 家族中有双相、精神病性抑郁或抗抑郁药诱发的躁狂；
- 抗抑郁药治疗效果差，或一加量就出现激越、失眠、话多；
- 抑郁中混着思维奔逸、冲动、易激惹等“往上走”的症状。

反过来，单相抑郁也有它的典型样子：入睡困难、早醒、食欲下降、体重减轻、情绪持续低落、对什么都提不起兴趣。但**这些只是统计倾向，不是诊断公式**。有的人双相抑郁表现得很“典型”，有的人单相抑郁也会睡得多、吃得多。

## 三、抗抑郁药后“像变了一个人”

这是门诊里最值得重视的信号之一。用药后出现明显变化，可能有几种完全不同的解释，处理方式也不同：

| 观察到的变化 | 更像转躁或混合 | 更像其他情况 |
|---|---|---|
| 睡眠需求明显减少，只睡三四小时仍精力旺盛 | 是 | 也可能是失眠，但失眠通常伴疲惫 |
| 话明显变多、语速快、想法一个接一个 | 是 | 焦虑时也会话多，但通常伴担心 |
| 花钱、投资、赌博、性行为明显失控 | 是 | 冲动控制问题也可能，但多有既往史 |
| 坐立不安、来回走动、心里烦躁 | 可能是混合或激越 | 也可能是药物激活或静坐不能（坐不住、总想走动） |
| 情绪突然轻松、愿意出门 | 不一定 | 可能只是抑郁好转 |

真正的转躁或轻躁狂，通常是**一组症状一起出现、持续几天**，而不是某一晚睡不好。混合状态更危险：人一边绝望、一边停不下来，冲动和自杀风险都会升高。发现这些变化，正确的做法是**尽快联系开药医生，不要自行停药或加药**。突然停药可能引起撤药反应，也可能让情绪更快地摆向另一头。

还要说明：抗抑郁药诱发的躁狂或轻躁狂，在 DSM-5-TR 里可以归为“物质或药物所致双相障碍”，不等于这个人“一定终身是双相”。但它是一个需要认真对待的信号，医生会重新询问既往史、家族史，并调整随访频率。

## 四、怎么把轻躁狂史问出来

直接问“你有没有躁狂过”，多数人会回答“没有”，因为这个词太吓人，而且轻躁狂的主观体验并不痛苦。换一种问法，信息会多很多：

- [ ] 有没有一段时间，睡得比平时少很多，却不觉得困、白天照样有劲；
- [ ] 有没有一段时间，话比平时多，别人插不上嘴，或者电话打个不停；
- [ ] 有没有一段时间，觉得自己特别有本事、计划特别多，同时开好几件事；
- [ ] 有没有一段时间，花钱明显超过平时，事后后悔；
- [ ] 有没有一段时间，特别容易发火、看谁都不顺眼，持续几天；
- [ ] 有没有一段时间，性欲明显增强，或做出平时不会做的冒险决定；
- [ ] 那段时间持续了几天，是一天里的几小时，还是连续几天大部分时间；
- [ ] 那段时间之后，是不是“跌”回抑郁，或者需要很久才恢复；
- [ ] 家人、伴侣、老同学有没有说过“你那阵子像变了个人”；
- [ ] 当时有没有喝酒、用兴奋剂、吃类固醇或其他药。

问的时候尽量带着具体时间段，比如“去年春天”“生完孩子那半年”，再找一位知情者核对。病历、旧照片、消费记录、工作考勤都能帮忙还原。MDQ 等筛查工具可以提示方向，但不能确诊，详见 3.5。

## 五、误诊的代价与常见误区

把双相抑郁当单相抑郁治，代价不只是“药不对”。抗抑郁药单用可能诱发躁狂、混合状态，让情绪波动更快；也可能让抑郁反复发作、治疗效果越来越差。对患者来说，这意味着更长的病程、更多的请假和住院、更重的经济负担，以及更高的自杀风险。反过来，把单相抑郁误当双相、长期按双相治疗，也会带来不必要的药物负担和标签压力。**区分的目的不是贴一个更“重”的标签，而是找到更匹配的治疗方向。**

- **“我从来没有兴奋过，所以不可能是双相。”** 轻躁狂不一定表现为兴奋，也可能是易激惹、思维快、活动多、睡得少。而且双相 II 型只有轻躁狂，没有躁狂。
- **“抗抑郁药吃完变开心了，说明药对症。”** 要看他是不是“好过头”了：睡眠需求减少、话多、冲动、花钱失控，这些不是单纯的好转。
- **“双相就是抑郁加兴奋，情绪起伏大就是双相。”** 双相的核心是**发作性**的心境和精力改变，持续几天到几周，而不是一天之内随事情起伏。
- **“一次转躁就说明我是双相。”** 需要排除物质、药物、躯体原因，也需要看后续病程；一次药物诱发事件不等于终身诊断。
- **“既然是双相，就绝对不能碰抗抑郁药。”** 双相抑郁有时仍会在心境稳定剂基础上短期联合抗抑郁药，是否使用、用多久，要由医生权衡，不能自行决定。
- **“我怕转躁，所以干脆不吃药。”** 不治疗的双相抑郁同样有自杀和功能损害风险，正确做法是让医生知道你的顾虑，一起定方案。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现**自杀念头、计划或准备**，或已经自伤：不要独处，立即联系信任的人陪同，拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 出现**混合状态**：整夜不睡、思维飞奔、冲动易怒，同时极度绝望或想死，风险很高，需尽快精神科急诊评估。
> - 出现**幻觉、被害或夸大妄想、命令性幻听**，或有伤人风险：先保证安全，拨打 **120** 或 **110**。
> - 用药后出现**高热、肌肉僵硬、大汗、意识改变**，或**严重皮疹、面唇肿胀、呼吸困难**：立即停药并急诊。
> - **木僵、拒食拒水、长时间不动**：可能是紧张症，需急诊精神科评估。
>
> 如果拿不准“算不算严重”，按严重处理。宁可白跑一趟，不要赌。
