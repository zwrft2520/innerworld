# 2.3 抑郁的躯体原因与药物因素

有些“抑郁”背后是甲状腺、贫血、睡眠呼吸暂停，或者某种正在吃的药；也有些抑郁与躯体病同时存在，互相加重。这一页讲医生在什么情况下会怀疑“不是单纯抑郁”、常见的躯体与药物因素有哪些、什么时候必须查。适合首次出现抑郁、治疗效果不好、或正在长期服药的人，也适合想理解“为什么要抽血、为什么要问喝酒”的家属。

## 一、为什么抑郁要先想“不是抑郁”

抑郁症状没有特异性。乏力、兴趣下降、注意力差、睡不好、食欲改变，既可以是抑郁障碍，也可以是甲减、贫血、感染、疼痛、药物副作用。**“排除躯体原因”不是否定你的痛苦，而是避免把可治疗的病当成精神病，也避免把精神病拖成慢性。**

需要同时排除的至少有三类：

| 类别 | 例子 | 为什么容易混 |
|---|---|---|
| 躯体疾病 | 甲减、贫血、B12 缺乏、睡眠呼吸暂停、脑卒中、帕金森病 | 直接造成乏力、迟钝、情绪低落 |
| 物质与药物 | 酒精、镇静药、类固醇、干扰素、某些降压药 | 用药后出现，或停药后加重 |
| 其他精神障碍 | 双相、焦虑、创伤、人格、痴呆或谵妄 | 症状重叠，需要看病程和发作性 |

躯体病和抑郁常常是双向的：慢性病会增加抑郁风险，抑郁也会影响服药、饮食、睡眠和复诊，让躯体病更难控制。所以医生不会简单地二选一，而是看时间关系、严重度、能不能用躯体病解释全部症状。**无论原因是什么，抑郁障碍的诊断仍要求症状持续两周以上并造成功能损害**；排查躯体因素不是为了否定诊断，而是为了让诊断更准确。

## 二、常见躯体原因

| 问题 | 可能表现 | 一般怎么查 |
|---|---|---|
| 甲状腺功能异常 | 甲减：怕冷、便秘、体重增加、反应慢；甲亢：心悸、手抖、消瘦、易怒、失眠 | 促甲状腺激素、游离甲状腺激素 |
| 贫血与营养缺乏 | 乏力、气短、头晕、面色差；B12 缺乏可伴手脚麻、走路不稳、记忆力下降 | 血常规、铁蛋白、维生素 B12、叶酸 |
| 睡眠呼吸暂停 | 打鼾、憋醒、白天嗜睡、晨起头痛、注意力差 | 睡眠监测，必要时耳鼻喉评估 |
| 神经系统疾病 | 脑卒中后、帕金森病、多发性硬化、癫痫 | 神经系统查体、影像，按线索选择 |
| 内分泌与代谢 | 库欣综合征、高钙血症、糖尿病、肝肾疾病 | 电解质、血糖、肝肾功能、激素检查 |

**甲状腺**是最常被想到的一个。甲减可以表现得像“抑郁”：没劲、怕冷、便秘、体重增加、反应慢、情绪低；甲亢则更像焦虑：心慌、手抖、出汗、失眠、易怒。一次促甲状腺激素检查就能提供重要线索，但甲状腺抗体、影像等要根据情况加做。

**贫血和 B12 缺乏**也常被漏。缺铁性贫血会让人乏力、气短、注意力下降；B12 缺乏除了贫血，还可能引起手脚麻木、走路不稳、记忆力下降、舌头疼，老年人尤其要留意。长期素食、胃手术后、长期服用某些抑酸药的人风险更高。

**睡眠呼吸暂停**是“睡多久都不解乏”的常见原因。典型表现是打鼾、被憋醒、白天困得厉害、晨起头痛、注意力差。它既可以直接造成抑郁样表现，也会加重原有抑郁。体重偏高、颈围粗、下颌后缩的人风险更高，但瘦人也会有。

此外，脑卒中后抑郁、帕金森病伴抑郁、多发性硬化、慢性疼痛、糖尿病、肿瘤、慢性感染都可能表现为抑郁。**不是每个抑郁患者都要做全套检查**，但首次发作、症状不典型、治疗反应差、年龄偏大、有明显躯体症状或体重变化时，医生通常会安排针对性检查。

## 三、药物、酒精与其他物质

| 类别 | 常见例子 | 线索 |
|---|---|---|
| 激素与免疫药物 | 糖皮质激素、干扰素、某些激素类药物 | 用药后情绪波动、失眠、易怒，减量后变化 |
| 皮肤科与神经系统用药 | 异维A酸、部分抗癫痫药、部分降压药 | 说明书有情绪相关警示，换药后出现 |
| 镇静催眠与止痛药 | 苯二氮䓬类、阿片类 | 白天嗜睡、反应慢、情绪低、依赖 |
| 酒精与其他物质 | 长期大量饮酒、大麻、兴奋剂 | 饮酒量增加、停用后难受、社会功能下降 |

药物与抑郁的关系，不能只靠说明书“对号入座”。同一种药，有人吃了没事，有人会出现明显情绪变化；时间关系、剂量变化、是否合并其他药，都要由医生判断。**不要因为看到“可能引起抑郁”就自行停药**，尤其是激素、抗癫痫药、抗凝药、降压药，突然停用可能带来更严重的后果。

酒精值得单独说。长期大量饮酒会破坏睡眠、消耗营养、加重绝望感，也可能直接诱发抑郁；抑郁的人又常借酒缓解情绪，形成恶性循环。酒精戒断还会引起焦虑、失眠、手抖、出汗，严重时抽搐、幻觉、意识混乱，**不能自行硬戒**。大麻、兴奋剂、镇静药的使用和戒断，也可能模仿或加重抑郁。

## 四、什么时候必须查、查什么

以下情况提示需要更积极地排查躯体与药物因素：

- [ ] 第一次出现抑郁发作，尤其是中老年首次发作；
- [ ] 体重在短期内明显下降，或伴有发热、盗汗、疼痛；
- [ ] 有怕冷、心悸、手抖、便秘、脱发、月经紊乱等躯体症状；
- [ ] 打鼾、憋醒、白天嗜睡明显；
- [ ] 手脚麻木、走路不稳、记忆力下降、性格改变；
- [ ] 有局灶神经症状、头痛、抽搐、意识波动；
- [ ] 抑郁治疗效果差，或反复发作、剂量越用越大；
- [ ] 长期饮酒、使用镇静药或其他物质；
- [ ] 正在使用激素、干扰素、异维A酸等药物；
- [ ] 孕期或产后、围绝经期、甲状腺病或贫血史；
- [ ] 免疫功能低下、静脉用药、多个性伴侣等感染风险；
- [ ] 家族中有甲状腺病、贫血、神经系统疾病。

常见的基础检查包括血常规、促甲状腺激素、电解质、血糖、肝肾功能、钙、维生素 B12、叶酸、铁蛋白；根据情况加做妊娠试验、尿药筛查、HIV 或梅毒检测、睡眠监测、心电图、脑影像。**检查不是越多越好**，而是围绕线索选择。查得过多可能带来假阳性、额外焦虑和费用，查得太少则可能漏掉可治疗的原因。

## 五、查出来之后：别走两个极端

一个极端是“查出了甲状腺问题，就认为抑郁全是甲状腺引起的”，自己把精神科药停了。甲状腺病可以引起抑郁样症状，但抑郁也可能同时存在；甲状腺功能恢复正常后，情绪不一定立刻好转。另一个极端是“检查都正常，就说明我是装病”。**躯体检查正常，恰恰支持抑郁障碍的诊断，而不是否定它。**

比较稳妥的做法是：

- 把最近半年的用药、保健品、饮酒、体重、睡眠、月经情况整理给药医生；
- 躯体科医生和精神科医生之间互通信息，不要各看各的；
- 不自行停用任何处方药，尤其是激素、抗癫痫药、抗凝药；
- 不因为“查不出原因”就拒绝精神科随访，也不因为“查出一点问题”就拒绝心理和药物治疗；
- 复诊时主动报告新出现的症状，尤其是发热、皮疹、意识变化。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现**自杀念头、计划或准备**，或已经自伤：不要独处，立即联系信任的人陪同，拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 出现**幻觉、被害或夸大妄想、命令性幻听**，或有伤人风险：先保证安全，拨打 **120** 或 **110**。
> - **意识时清时浊、发热、剧烈头痛、抽搐**：先按躯体急症处理，警惕脑炎、感染、代谢紊乱、谵妄（急性意识混乱、注意力忽清忽浊）。
> - **长期大量饮酒或镇静药突然停用后出现抽搐、幻觉、意识混乱**：立即急诊，不能自行硬戒。
> - 服药后出现**高热、肌肉僵硬、大汗、意识改变**，或**严重皮疹、起疱脱皮、面唇肿胀、呼吸困难**：立即停药并急诊。
> - **木僵、拒食拒水、长时间不动**：可能是紧张症，需急诊精神科评估。
>
> 如果拿不准“算不算严重”，按严重处理。宁可白跑一趟，不要赌。

## 六、常见误区

- **“抑郁就是心理问题，不用查身体。”** 首次发作、非典型表现、治疗反应差时，躯体排查是诊断的一部分。
- **“查了甲状腺正常，就说明医生在乱开检查。”** 排查是排除法，正常结果同样有诊断价值。
- **“查出贫血，补铁就能治好抑郁。”** 贫血可能加重抑郁，但抑郁障碍有自己的病程和治疗，需要分别评估。
- **“喝酒能助眠、能解愁。”** 酒精破坏睡眠结构，加重抑郁和焦虑，长期还会造成依赖和戒断风险。
- **“药物说明书上写了抑郁，就必须马上停。”** 要看时间关系、发生率和医生评估，擅自停药可能更危险。
- **“老年人没劲、睡不好是正常衰老。”** 老年抑郁常以躯体症状出现，也可能是甲减、贫血、睡眠呼吸暂停或药物所致。
- **“产后情绪差是矫情。”** 产后激素、睡眠剥夺、贫血、甲状腺炎都可能参与，持续两周以上或影响照顾婴儿要就医。
- **“只要查出躯体病，就不用看精神科。”** 两者常并存，分别治疗并不矛盾。
