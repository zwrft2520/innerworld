# 1.5 鉴别诊断与共病的基本原则

“医生说我既是抑郁又是焦虑，还有边缘型人格，到底是几个病？”这是门诊里很常见的问题。另一头，也常有人问：“我查了甲状腺、做了核磁，都正常，为什么医生还不肯下结论？”这两个问题指向同一件事：精神科诊断不是把症状往格子里塞，而是一个不断排除、排序、验证的过程。这一页讲三条基本原则——先排除、再辨析、后排序；也讲共病到底意味着什么，以及为什么“多贴几个标签”往往不是好事。

## 为什么“先排除”是铁律

精神科有一条几乎不容妥协的原则：**在把症状归因于精神障碍之前，先排除躯体疾病、物质使用和药物影响。** 这条原则的道理很朴素——漏掉一个甲状腺功能亢进，代价是持续几个月甚至几年的错误治疗；漏掉一个脑炎，代价可能是不可逆的损伤。

【指南】DSM-5-TR 和 ICD-11 在多数障碍的诊断标准里都写有排除条件，例如“症状不能由某种物质的生理效应或另一种躯体疾病更好地解释”。这不是客套话，而是诊断成立的必要条件。也就是说，一个诊断即使症状条目全都符合，只要存在更能解释全部表现的躯体或物质原因，这个诊断就不成立。

为什么精神症状这么容易被躯体病“冒充”？因为大脑是全身的一部分。甲状腺激素、血糖、电解质、氧饱和度、炎症因子、肝肾功能、药物浓度，任何一项异常都可能改变注意力、情绪、睡眠、思维速度和行为。表现上，它们和“原发性”精神障碍可以几乎一模一样。

反过来也要提醒一句：**检查正常，不等于症状是“想出来的”。** 目前多数精神障碍没有确诊性的化验指标，检查正常排除的是“别的病”，不是排除你的痛苦。这两件事经常被混为一谈，结果要么是患者觉得“医生在说我装病”，要么是家属觉得“查不出毛病就是矫情”。

## 三类“模仿者”

鉴别诊断的对手主要来自三个方向。下面这张表不是完整清单，但覆盖了门诊最常遇到的几类。

| 方向 | 常见例子 | 医生会问/查什么 |
|---|---|---|
| 躯体疾病 | 甲亢、甲减、贫血、维生素 B12 缺乏、低血糖、电解质紊乱、睡眠呼吸暂停、颞叶癫痫、脑血管病、自身免疫性脑炎、慢性感染、激素异常 | 起病快慢、发热、体重变化、心悸、打鼾、抽搐、视物异常；血常规、甲功、血糖、电解质、肝肾功能、心电图，必要时脑电图或影像 |
| 物质使用 | 酒精（醉酒与戒断）、大麻、苯丙胺类、阿片、镇静催眠药、咖啡因、尼古丁、致幻剂 | 使用种类、频率、最后一次使用时间、停用后有没有抖动/出汗/幻觉；必要时尿检 |
| 药物与其他 | 糖皮质激素、干扰素、异烟肼、左旋多巴、抗胆碱能药、部分抗生素、抗癫痫药、口服避孕药、化疗与免疫抑制药、含激素或重金属的保健品 | 用药清单、开始与加量时间、减量后是否好转、说明书副作用 |

这三类之所以重要，是因为它们**通常可以纠正**。把甲减当抑郁治，抗抑郁药效果往往有限；把酒精戒断当焦虑治，可能错过抽搐和谵妄的风险；把激素引起的躁狂当双相治，停药才是关键一步。

除了这三类，还有一类常被忽略：**其他精神障碍**。强迫症和广泛性焦虑都表现为反复思考，双相抑郁和单相抑郁都表现为情绪低落，创伤后应激和边缘型人格都表现为情绪不稳与自伤，孤独症谱系和社交焦虑都表现为回避社交。这些“精神科内部的模仿者”，靠的不是化验，而是时间线、起病年龄、症状结构和对治疗的反应来区分。

## 时间关系：判断“谁引起谁”的实用线索

发现一个人既有躯体病又有精神症状，不等于两者有因果关系。判断因果，最实用的工具是**时间关系**。

| 时间线索 | 提示 |
|---|---|
| 精神症状在用药加量或物质使用后数天内出现 | 更支持物质/药物所致 |
| 减量、停药或戒断后症状明显减轻 | 更支持物质/药物所致 |
| 再次使用后症状重现 | 因果关系更强 |
| 躯体病确诊在前，精神症状随后出现并随躯体病波动 | 更支持躯体疾病所致 |
| 精神症状先出现多年，躯体病后来才有 | 更可能是两个独立问题 |
| 症状与月经周期、季节、轮班、时差稳定相关 | 提示内分泌、昼夜节律因素 |

还有几个实用做法：**停药观察**（在医生指导下，评估症状是否随停药改善）、**治疗躯体病后再评估**（比如先把甲状腺功能调到正常，再看情绪）、**尿检或血药浓度**（在知情同意下）、**向家属核对使用情况**（很多人不会主动提饮酒或助眠药）。

需要强调的是，时间关系只是线索，不是判决。有些躯体病早期症状很轻，有些物质使用的隐瞒很常见，有些“原发性”精神障碍也会在躯体病之后首次发作。所以规范的做法是：**保留两种可能，边治边看，定期复核**。

## 共病不是“多贴几个标签”

共病（comorbidity）指一个人同时符合两个或以上障碍的诊断标准。它在精神科非常常见：抑郁与焦虑共病、创伤后应激与抑郁共病、物质使用与几乎任何精神障碍共病、孤独症谱系与注意力问题共病。共病不是诊断水平不够的表现，而是真实存在的现象。

但“共病”这个词经常被误用。下面几种情况，看起来像共病，其实不是。

**第一种，把一个病的不同症状拆成几个病。** 抑郁的人本来就会注意力差、担心、睡不好、容易发脾气。如果把这些分别写成“注意力障碍”“广泛性焦虑”“失眠障碍”“间歇性暴怒”，就变成了四个标签，但实际上可能只是一个抑郁发作的不同侧面。

**第二种，把因果关系当成并列关系。** 长期失眠可以引起情绪低落，长期焦虑可以引起抑郁，创伤可以同时引起闪回、回避和抑郁。这些情况下，写两个诊断不算错，但治疗的重点不一样——先处理哪个，取决于哪个是“上游”。

**第三种，把人格特质和发作混在一起。** 一个人平时就敏感、容易紧张，抑郁发作时更明显。如果只写“人格障碍”，可能漏掉可治疗的发作；如果只写“抑郁”，可能忽略长期模式对治疗关系的影响。

**第四种，诊断遮蔽（diagnostic overshadowing）。** 一个人已经有精神科诊断，后来出现新的躯体症状（头痛、腹痛、乏力、体重下降），容易被一句“这是你的焦虑/抑郁躯体化”带过去，从而漏掉真正的躯体病。这是临床上真实存在、且后果严重的偏差，尤其容易发生在老年人、慢性精神障碍患者和有物质使用史的人身上。

判断共病是否成立，通常要看三件事：**每一组症状是否各自达到诊断门槛**（而不是勉强凑数）、**它们的时间关系是什么**（同时起病、先后起病、还是一个引起另一个）、**分开处理后是否各自有独立反应**（比如抑郁改善后焦虑仍持续，才更像两个问题）。

## 诊断顺序与优先级

当一个人同时存在多个问题时，医生不会平等对待所有诊断，而是按优先级排序。排序的依据通常有四条。

**第一，先处理危及生命的。** 自杀风险、拒食导致的电解质紊乱、谵妄、恶性综合征、酒精或镇静药戒断、严重激越，这些优先于任何“定性”问题。这时候诊断的作用是快速指向处理，而不是求全。

**第二，先处理可逆的。** 药物引起的、感染引起的、甲状腺引起的、睡眠呼吸暂停引起的、维生素缺乏引起的，只要能纠正病因，症状往往随之改善。这类问题排在“原发性精神障碍”之前。

**第三，先处理“上游”。** 如果焦虑是失眠的结果，先治失眠；如果抑郁是长期创伤反应的一部分，创伤相关的工作不能一直往后拖；如果物质使用是维持失眠和情绪不稳的原因，戒断与减量是绕不开的一步。

**第四，先处理对治疗影响最大的。** 双相障碍被误当单相抑郁治疗，可能诱发转躁；强迫症合并抽动，用药选择不同；孤独症谱系合并焦虑，治疗方式需要调整。这些“会影响方案”的诊断，需要在早期就辨明。

排序不是一次完成的。常见的做法是：**先给一个工作诊断，按最可能的方向处理，同时把“待排除”写在病历里，四周到八周后复核。** 随着信息增加，顺序可能调整，甚至主诊断会换人。这不是摇摆，而是规范。

这里还有一个常被忽略的排序问题：**病因性诊断优先于症状性诊断**。比如“甲状腺功能减退所致精神障碍”比“抑郁障碍”更具体，只要证据支持，就应该写前者；只有在排除之后，才写“原发性”。同理，“酒精所致精神病性障碍”与“精神分裂症”在时间关系明确时，前者优先。

## 就诊前可以做的准备

鉴别和共病靠的是信息，而信息很大一部分掌握在患者和家属手里。

- [ ] 把最近一年的用药列全：药名、开始时间、加量时间、停药时间（不必写剂量，带药盒即可）。
- [ ] 记下饮酒、吸烟、咖啡、助眠药、止痛药的使用频率和最近一次时间。
- [ ] 整理近期的化验与检查报告，特别是甲功、血常规、血糖、电解质、心电图。
- [ ] 写下慢性病清单：高血压、糖尿病、甲状腺病、肝病、肾病、癫痫、自身免疫病。
- [ ] 记录症状出现的顺序：哪个先来，哪个后来，间隔多久。
- [ ] 注意有没有“周期性”：与月经、季节、轮班、熬夜的关系。
- [ ] 回忆有没有发热、头痛、抽搐、视物异常、体重明显变化、打鼾憋醒。
- [ ] 写下家族史：精神障碍、自杀、住院、酒精问题。
- [ ] 准备一个问题清单：还需要排除什么？先治哪个？多久复核一次？

> **什么时候需要联系医生或去急诊**
>
> - 意识时清时浊、注意力飘忽、看到虫或人影、伴发热或感染：警惕谵妄，立即急诊。
> - 高热、肌肉僵硬、大汗、意识改变、肌酸激酶升高：警惕恶性综合征或严重药物反应，立即急诊。
> - 开始新药或加量后出现高热、震颤、躁动、腹泻、反射亢进：警惕严重药物反应，立即急诊。
> - 长期大量饮酒或镇静催眠药突然停用后出现抽搐、幻觉、意识混乱：立即急诊，不要自行硬戒。
> - 严重皮疹、起疱脱皮、面唇肿胀、呼吸困难：立即停药并急诊。
> - 自杀念头、自伤行为、拒食超过一天、木僵：立即 **120** 或急诊，也可拨打 **12356** 心理援助热线。

## 常见误区

**“检查都正常，就不用再查了。”** 有些问题需要动态观察（如自身免疫性脑炎、间歇性卟啉病、睡眠呼吸暂停），一次正常不能排除全部。症状变化时，医生可能会重复或补充检查。

**“有两个诊断，说明医生没本事。”** 共病是真实存在的。真正需要警惕的是“标签越贴越多、却没有一个能解释主要功能损害”的情况。

**“先治哪个都一样。”** 顺序会影响效果和安全。双相被当单相抑郁治、谵妄被当焦虑治、戒断被当失眠治，都是有代价的。

**“既然是焦虑引起的，躯体症状就不用管。”** 诊断遮蔽是明确的临床风险。新出现的躯体症状，尤其伴体重下降、发热、疼痛性质改变时，需要重新评估。

**“共病就是病得更重。”** 共病通常提示需要更综合的方案，但不等于预后一定差。很多人在规范处理后，两三个问题会一起改善。
