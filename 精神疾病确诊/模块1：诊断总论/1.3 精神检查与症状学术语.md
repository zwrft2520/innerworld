# 1.3 精神检查与症状学术语

病历上那些“思维散漫”“情感平淡”“自知力不全”，到底在说什么？很多人拿到出院小结，像在读一份外语文件。这一页把精神检查的七个维度拆开，把最常出现的术语翻译成大白话，并说明医生为什么在意这些细节。读完你会发现：精神检查不是随便聊天，而是一次有结构的观察；术语也不是玄学，它们描述的是可以被看见、被追问的东西。

## 精神检查不是“聊天”

精神科门诊里，医生和你说话的时间可能只有二十分钟，但这段对话同时在做四件事：**建立关系、收集信息、观察状态、评估风险**。聊天是随意的，精神检查是有结构的——医生心里有一张表，从你进门那一刻就开始填。

他看什么？看你走进来的姿态、坐下后离他多远、有没有眼神接触、手放在哪里、说话时表情和内容是否一致、回答是简洁还是绕圈、有没有突然停住、提到某个话题时是否明显紧张。他问什么？除了“哪里不舒服”，还会问睡眠、食欲、精力、注意力、有没有听到别人听不到的声音、有没有觉得被针对、有没有想过结束生命。这些问题不是随口闲聊，每一条都对应诊断标准里的某个位置。

所以精神检查有几个特点，值得患者和家属知道。

**它同时看“内容”和“形式”。** 你说“我最近很累”，这是内容；你说这句话时语速很慢、停顿很久、眼睛不看人，这是形式。两者都是信息。有时候形式比内容更能说明问题，比如一个人反复说“我没事”，但坐立不安、反复起身、手心出汗。

**它会交叉验证。** 医生说“家里人说你这两个月几乎不出门”，不是要拆穿你，而是在比对不同来源的信息。说法不一致很常见，本身也是信息，医生会追问“为什么你觉得还好，家人觉得严重”。

**它包含风险询问。** 问自杀、自伤、伤人，是每一次规范评估的固定动作，不是因为你“看起来危险”。直接回答反而更安全——隐瞒风险不会让风险消失，只会让帮助来得更晚。

**它不需要你“表现正常”。** 有些人进诊室前会特意整理情绪、挑好听的说，结果医生看到的是一个“状态不错”的人，回家后却完全另一副样子。如实呈现，包括难堪的部分，才对诊断有帮助。

## 七个维度：一项一项看

规范的精神检查通常覆盖下面七个方面。不同医院格式略有差异，但核心内容相近。

| 维度 | 具体看什么 | 常见术语 |
|---|---|---|
| 外观与行为 | 衣着、卫生、姿势、步态、眼神接触、动作多少、有无怪异动作 | 精神运动性迟滞、激越、刻板动作、紧张症行为 |
| 言语 | 语速、音量、话量、流畅度、能否被打断 | 思维奔逸、思维迟缓、思维中断、病理性赘述 |
| 情绪与情感 | 当下心境、表情是否与内容相称、情绪波动 | 情感平淡、情感不协调、情感倒错、易激惹 |
| 思维形式 | 话与话之间有没有逻辑、是否跑题、是否空洞 | 思维散漫、破裂性思维、思维贫乏、思维被插入 |
| 思维内容 | 有没有固定、难以纠正的错误信念 | 妄想、牵连观念、超价观念、强迫观念 |
| 知觉 | 有没有看到、听到、闻到不存在的东西 | 幻觉、错觉、命令性幻听、假性幻觉 |
| 认知与自知力 | 注意力、记忆、定向力；如何看待自己的病 | 注意力涣散、记忆减退、自知力缺乏 |

下面挑最常被误解的几组词，逐个翻译。

## 情绪与情感：容易混淆的几个词

日常语言里“情绪”和“情感”是一个词，临床上要分开。**心境（mood）**指一段时间里持续的背景情绪，比如“这两个月一直低落”；**情感（affect）**指当下这一刻表现出来的情绪反应，比如说话时的表情、语调、眼泪。一个人可以心境低落，但当下情感表达还算丰富；也可以心境描述不清，而当下情感明显迟钝。

**情感平淡**是最常被误读的一个。它不是“没感情”“冷血”，而是**情感表达的范围和强度明显收窄**：说话语调平、脸上变化少、讲到高兴或难过的事都没有相应反应。它常见于精神分裂症谱系，也可见于重度抑郁、帕金森病、长期使用某些药物、创伤后麻木。【指南】重要的是，情感平淡描述的是“外在表达变少”，不等于内心没有感受——很多当事人事后会说“我心里其实很难受，但脸上做不出来”。

**情感不协调**指情感表达与谈话内容、或与当下情境明显不匹配。比如讲亲人去世时笑，或讲一件小事时突然痛哭。它在精神分裂症中较常见，但不是专属，严重解离、脑器质性损害、文化表达差异都可能出现。

**情感倒错**比不协调更进一步：表达出的情感方向与内容相反。

**易激惹**指小事就能引发明显愤怒或争吵，常见于抑郁、躁狂、焦虑、创伤后反应、慢性疼痛、失眠和物质戒断。它容易被家人描述成“脾气变差”，但背后可能是抑郁、也可能是躁狂期的开始，需要结合睡眠需求和整体状态判断。

**情感脆弱（情绪失禁）**指轻微刺激就控制不住地哭或笑，常见于脑卒中后、多发性硬化等神经系统疾病，也可能是极度疲惫下的正常反应。

## 思维：形式与内容的区别

这是术语最密集的地方，也是最容易被网上文章断章取义的地方。先记住一个区分：**思维形式**说的是“怎么想、怎么讲”，**思维内容**说的是“想了什么”。

### 思维形式

**思维奔逸**：话明显变多、变快，一个念头接一个念头，话题不断跳，别人很难插话，常伴“脑子转得飞快”的主观感受。常见于躁狂或轻躁狂发作，也可见于焦虑激动、甲亢、某些药物作用。

**思维迟缓**：思考变慢、反应变慢、说话少而慢、停顿多，本人常觉得“脑子像生锈”。常见于抑郁发作，也可见于甲状腺功能减退、药物镇静、睡眠严重不足。

**思维中断**：说话说到一半突然停住，片刻后换一个话题，本人可能说“脑子突然空了”。**思维阻滞**类似，但更强调“被外力挡住”的体验。这类描述在精神分裂症中较常见，但一次出现说明不了什么，疲劳、焦虑、注意力涣散也会有类似表现。

**思维散漫**：句子之间缺乏逻辑联系，听的人抓不住重点，问东答西，但单个句子还算通顺。**破裂性思维**更严重，句子之间也失去联系，变成词的堆砌。

**病理性赘述**：讲话绕来绕去、细节过多、抓不住重点，但方向大体还在。常见于癫痫相关障碍、老年认知下降、部分人格特点。

**思维贫乏**：不是“不想说”，而是“没什么可说”，回答简短空洞，缺乏内容。常与情感平淡、意志缺乏一起出现。

**持续言语**：反复重复同一个词或同一句话，常见于痴呆、脑器质性损害。

### 思维内容

**妄想**是核心概念。它指一种**固定的、与事实不符的信念**，即使有相反证据、即使周围人都不同意，当事人仍然坚信，而且这种信念通常与他的文化背景不相符。常见主题有被害（有人害我）、关系（别人的话都在说我）、夸大（我有特殊能力）、嫉妒（伴侣不忠）、罪恶（我罪不可赦）、被控制（我的身体被别人操纵）、被洞悉（别人能知道我在想什么）。

需要注意两点。第一，妄想不是“想法奇怪”，很多人有奇怪的爱好和观点，但能接受讨论、会随证据调整，那叫超价观念或普通信念，不叫妄想。第二，妄想的内容受文化影响，某些在特定宗教或民俗语境中常见的说法，不能简单判为妄想——这正是精神检查要问“你们那里的人怎么看”的原因。

**牵连观念**指把外界无关的事认为与自己有关，比如觉得路人咳嗽是在暗示自己、电视里的台词在说自己。轻微的牵连观念在焦虑、疲惫、社交敏感的人身上也会短暂出现；只有当它固定、泛化、影响行为时，才更有临床意义。

**超价观念**指一种强烈但尚未达到妄想程度的信念，通常与个人经历、价值观紧密相关，能被部分说服。**强迫观念**则是反复闯入的、本人认为不合理却无法摆脱的想法，通常伴随强烈的抵抗和痛苦，与妄想的“坚信”不同。

## 知觉、认知与自知力

**幻觉**指没有相应外界刺激时产生的真实知觉体验——真的“听到”“看到”，不是想象，也不是“觉得好像”。最常见的是**幻听**，包括**命令性幻听**（声音命令去做某事，这一项必须高度重视）、**评论性幻听**（声音评论自己的一举一动）、**争论性幻听**（两个声音争吵）。幻视在成人中相对少见，出现时要更多考虑躯体或药物因素；**幻触**（虫爬感）常见于物质戒断或躯体疾病；**嗅幻觉**（闻到别人闻不到的味道）尤其要警惕神经系统问题。

**错觉**与幻觉不同：错觉是**有外界刺激但感知错了**，比如把衣架看成一个人、把风声听成哭声。健康人在昏暗、疲劳、发烧、刚睡醒时都可能出现，本身不代表障碍。

**假性幻觉**指“听到”的声音不在外界空间，而在脑子里，本人知道它不是通过耳朵来的。这个概念在中文教材里常见，但不同学派的界定有差异，实际诊断中更看重体验的整体结构而不是单个标签。

**认知**在精神检查里主要指注意力、记忆力、执行功能和定向力。抑郁和焦虑会造成明显的注意力下降（“看书看不进去”），容易被误认为“变笨了”；老年人出现记忆下降，需要区分抑郁相关的假性痴呆、谵妄和真正的认知障碍。

**自知力**指一个人如何看待自己的状态：是否认为这些体验不正常、是否认为自己需要帮助、是否愿意配合评估和处理。自知力不是“听话”，也不是道德评价。它常常随病情波动——急性期坚信自己没病，好转后才发现“当时确实不对”。医生评估自知力，是为了判断需不需要家属参与、要不要更严密的安全安排，而不是给你打分。

## 家属能观察和记录什么

家属的描述常常比当事人更完整，但也容易只看到“行为”，漏掉“体验”。下面这份清单可以直接照着记，复诊时带给医生。

- [ ] 睡眠：几点上床、几点睡着、夜里醒几次、几点起、白天睡不睡。
- [ ] 吃饭与体重：吃得多少、有没有明显变化、有没有躲着吃或催吐。
- [ ] 说话：话变多还是变少、语速、能不能被打断、有没有突然停住。
- [ ] 情绪：一天里什么时候最差、有没有毫无原因的哭泣或大笑、有没有明显易怒。
- [ ] 行为：出门次数、洗漱、房间状态、有没有重复动作、有没有长时间不动。
- [ ] 知觉与想法：有没有自言自语、侧耳倾听、突然紧张、说“有人针对我”。
- [ ] 功能：上班上学是否中断、家务是否还能做、社交是否明显减少。
- [ ] 风险：有没有说“活着没意思”、有没有自伤、有没有把东西送人。
- [ ] 用药与物质：吃了什么、什么时候停的、有没有喝酒。
- [ ] 记录方式：用手机备忘录按日期写一两行，比事后回忆准确得多。

> **什么时候需要联系医生或去急诊**
>
> - 听到命令自己做危险事情的声音，或坚信有人要害自己、因此准备“反击”：先保证安全，拨打 **120**，必要时 **110**。
> - 出现自杀念头、自伤行为，或已经在准备：不要独处，立即 **120** 或急诊，也可拨打 **12356** 心理援助热线。
> - 长时间保持一个姿势、不说话、不吃不喝、对外界刺激没有反应：可能是紧张症或木僵，立即急诊。
> - 意识时清时浊、注意力飘忽、看到虫或人影、伴发热或感染：警惕谵妄，立即急诊。
> - 服药后高热、肌肉僵硬、大汗、意识改变：立即急诊。
> - 首次出现幻觉或妄想，伴头痛、抽搐、视物异常：按神经系统急症处理，立即急诊。

## 常见误区

**“病历写我‘情感平淡’，是不是说我冷血？”** 不是。它描述的是情绪的外在表达变少，是症状描述，不是人格评价。很多人在恢复后会说，当时心里有感受，只是表达不出来。

**“思维散漫是不是就是说话没逻辑？”** 日常的“跳跃”通常还能听懂大意，思维散漫是听的人完全抓不住主线，本人也说不清自己要表达什么。两者程度不同，需要医生判断。

**“有幻觉就是精神分裂症。”** 幻觉可见于双相、抑郁伴精神病性特征、物质中毒或戒断、癫痫、脑炎、谵妄、听力障碍、极度睡眠剥夺。只凭幻觉这一条，无法确定是哪种。

**“自知力差就是不讲理。”** 自知力受损是症状的一部分，尤其在急性期。这时候争论“你有没有病”通常没有帮助，先处理状态、保证安全更重要。

**“术语越专业，诊断越可靠。”** 术语只是描述工具。同一个词在不同医生那里可能有细微差别，真正可靠的是完整的病史、纵向观察和排除过程。
