# 1.2 诊断流程：从主诉到结论

很多人形容第一次看精神科：“我讲了二十分钟，医生就写了个诊断。”也有人相反：“去了三次，医生还是说再观察。”这两种体验背后，其实是同一套流程——只是有的人走完了，有的人还在路上。这一页把一个规范的精神科评估拆成看得见的步骤，告诉你每一步医生在找什么、你能提供什么，以及为什么“一次门诊就下结论”本身并不可靠。

## 一次评估大致经过哪些环节

精神科没有“一管血定乾坤”的检查，诊断靠的是**多来源信息的交叉印证**。规范的评估通常包含下面这些环节，顺序会因人而异，但很少有哪一环可以被真正跳过。

| 环节 | 医生在找什么 | 你能提供什么 |
|---|---|---|
| 主诉 | 最困扰的一件事，以及它持续多久 | 用一句话说清“最难受的是什么、多久了” |
| 现病史 | 起病时间、诱因、症状组合、波动、功能变化 | 时间线：什么时候开始、什么时候变重、什么情况下好转 |
| 既往史 | 以前有没有类似发作、诊断、用药、住院 | 旧病历、药盒、检查单 |
| 个人史与发育史 | 成长、学业、工作、婚恋、重大转折 | 童年是否就有注意力、社交、情绪上的困难 |
| 家族史 | 亲属中有无精神障碍、自杀、住院 | 知道多少说多少，不必羞于提 |
| 精神检查 | 当下的外观、言语、情绪、思维、知觉、认知、自知力 | 如实回答，不必“表现得正常一点” |
| 量表 | 严重度基线、筛查漏项、随访对比 | 按最近两周的真实情况填，不要揣测“医生想听什么” |
| 躯体与实验室检查 | 排除甲状腺、贫血、电解质、感染、药物等 | 近期体检、用药清单、月经史、饮酒史 |
| 风险评估 | 自伤、自杀、伤人、走失、拒食、物质使用 | 直接说，不要怕“说了会被抓起来” |
| 形成假设与随访 | 最可能的解释、需要排除什么、观察多久 | 问清楚“下次复诊要看什么变化” |

## 问诊：主诉、现病史与家属的作用

### 主诉与现病史：把一团乱麻讲成一条线

主诉是整份病历的第一句话，通常只有一行：**最主要的问题 + 持续时间**。比如“情绪低落、兴趣减退三个月”“反复担心半年，加重两周”“听见有人议论自己一个月”。这一行看似简单，却决定了后面所有提问的方向。

现病史是主体，医生会按一条隐含的时间线来问：

- **什么时候开始的？** 是突然几天之内，还是慢慢几个月？有没有明确的诱因（失业、分手、生育、生病、搬迁、亲人去世）？
- **一开始是什么样？** 很多人只记得“最严重的时候”，而最早的信号往往更有诊断价值。
- **怎么变化的？** 是一直差不多，还是一阵好一阵坏？有没有完全不难受的时期？这一点对区分“发作性”和“持续性”的障碍特别关键。
- **有没有伴随的东西？** 睡眠、食欲、体重、精力、性欲、注意力、疼痛、身体不适。
- **有没有反过来影响生活？** 请假了没有、成绩掉了没有、关系出问题了没有、有没有不敢出门。
- **有没有自己想过办法？** 喝过酒、用过助眠药、找过咨询、去过别的医院、吃过什么药、效果如何、有没有副作用。

家属在这里的作用很大。当事人处在抑郁或焦虑中时，记忆常偏向负面，容易低估自己以前的好状态；而家属能提供“他以前不是这样”的对照。反过来，家属也容易只看到行为问题（不出门、发脾气、不吃饭），看不到当事人内部正在经历什么。**最好的病史是两个人分开讲，再由医生拼起来。**

## 精神检查：医生在看什么、问什么

精神检查不是“聊聊天”，而是一次有结构的观察。医生同时在做两件事：听你说什么（内容），看你怎么说（形式、速度、表情、坐姿、眼神）。它通常包括外观与行为、言语、情绪与情感、思维形式与内容、知觉、认知功能、自知力几个方面，具体内容在 [1.3 精神检查与症状学术语](<1.3 精神检查与症状学术语.md>) 里有逐项解释。

这里只说三个容易被误解的点。

**第一，医生会问一些“听起来很奇怪”的问题。** 比如“有没有人跟踪你”“有没有听到别人听不到的声音”“有没有觉得电视在说你”“有没有觉得自己的想法被别人拿走”。这些不是暗示，也不是诱导，而是常规筛查。被问到不代表医生觉得你有，很多人回答了“没有”，这段就过去了。

**第二，医生会观察你的“不一致”。** 嘴上说“我没事”，眼睛却一直看着地面、手指不停搓；说“我很开心”，脸上没有表情；描述痛苦的事情时语气像在讲别人的故事。这些不一致不是“装”，而是症状的一部分，也是判断的重要线索。

**第三，医生会评估自知力。** 也就是你如何看待自己现在的状态：觉得是生病了、需要帮助，还是觉得都是别人的问题、自己没病。自知力不是“听话程度”，也不影响你作为人的价值，但它直接影响治疗能不能配合、需不需要家属参与、要不要考虑住院评估。

## 量表与躯体排查：各自管什么

量表在评估里是有用的，但它的作用和很多人想的不一样。

| 用途 | 说明 | 不能做什么 |
|---|---|---|
| 筛查 | 用几个问题快速找出可能被漏掉的方向 | 不能凭分数下诊断 |
| 量化严重度 | 给“轻、中、重”一个可比较的基线 | 不能替代医生的整体判断 |
| 随访对比 | 两次分数变化，帮助看治疗有没有起效 | 不能反映全部功能与风险 |
| 科研与质控 | 让不同研究、不同医院的数据可比 | 不能说明病因 |

量表分数受很多因素影响：最近两周的状态、填表时的情绪、对题目的理解、是否想让医生重视、文化程度、躯体疾病。同一个分数，放在不同人身上含义不同。所以规范的做法是：**量表提示方向，医生面谈确认，纵向观察定案**。看到“PHQ-9 18 分”就认定“重度抑郁”，是把尺子当成了医生。

### 躯体排查：什么时候必须查

精神科诊断有一条基本原则：**先排除“不是精神科的原因”**。这不是过度检查，而是因为漏掉躯体病的代价太大。

- **首次发作、年龄偏大、症状不典型**：通常需要血常规、甲状腺功能、血糖、电解质、肝肾功能，必要时心电图、脑电图或影像。
- **伴发热、头痛、抽搐、意识波动、视力改变、步态异常**：优先按神经系统急症处理。
- **长期饮酒、营养不良、进食障碍**：需要关注维生素缺乏、电解质紊乱。
- **正在服用其他科药物**（激素、抗过敏药、降压药、抗病毒药、避孕药等）：需要核对说明书与用药时间关系。
- **老年人首次出现精神症状**：尤其要排查感染、药物相互作用、谵妄和认知下降。

检查正常，不代表“病是装的”；检查异常，也不代表精神症状就是它引起的。两者需要医生结合时间关系判断。

## 为什么一次门诊不够

这是最值得理解的一点。一次门诊通常只有十几到几十分钟，而诊断需要的信息量远不止这些。

**第一，门诊看到的是横断面。** 你走进诊室的那几十分钟，可能正好是这周状态最好的一天，也可能正好是最差的一天。而诊断标准里的病程要求，靠的是纵向信息。

**第二，状态会影响表达。** 极度焦虑的人讲不清时间线，抑郁的人容易只讲负面，躁狂的人可能觉得自己完全正常、是家人多事，精神病性症状的人可能因为不信任而隐瞒。同一个人，在不同状态下给出的病史可以差别很大。

**第三，诊断需要“排除”，而排除需要时间。** 停药观察、戒酒观察、治疗甲状腺、改善睡眠呼吸暂停，这些都需要几周才能看出精神症状是否随之改变。

**第四，有些障碍本身就要求“观察一段时间”。** 比如儿童的情绪和行为问题要看跨场景表现，人格相关的问题要看长期模式，短暂的精神病性症状要看会不会持续。急着下结论，反而容易误判。

**第五，治疗反应也是诊断信息。** 抗抑郁药无效、情绪稳定剂有效，这些反馈会反过来修正最初的判断。所以医生常说“先按这个方向治，两周后复诊再说”，这不是敷衍，而是诊断流程的一部分。

### 诊断不是“对症状”

很多人以为诊断就是“症状清单打勾”，其实医生做的是**假设—验证**：先形成几个可能的解释，再用病史、检查、随访逐一排除，最后留下最能解释全部信息的那一个。

举个例子。一个人说“我最近什么都不想干、睡不着、注意力很差”。可能的解释至少有五种：抑郁发作、双相抑郁、甲状腺功能减退、睡眠呼吸暂停、酒精或药物影响。它们的症状高度重叠，但处理方向完全不同。医生要问的不是“你有几条症状”，而是：有没有过一段时间睡得少却精力特别好？体重和怕冷有没有变化？打不打呼噜？最近喝不喝酒？这些问题的答案，才决定了诊断往哪边走。

所以，**诊断的质量很大程度上取决于“问了什么”，而不是“看了多久”**。同一位医生，问得细、愿意等、会主动追问轻躁狂史和物质使用，和只对着量表打分的医生，给出的结论可能完全不同。

## 去就诊之前：准备清单与常见误区

把下面这份清单写在一张纸上，比临场回忆有效得多。

- [ ] 一句话主诉：最难受的是什么，从什么时候开始。
- [ ] 一条时间线：起病、加重、好转的关键节点，尽量写月份。
- [ ] 症状清单：睡眠、食欲、体重、精力、注意力、情绪、焦虑、幻觉或奇怪想法、自伤念头。
- [ ] 功能变化：工作/学习/家务/社交，具体掉了多少，有没有请假或休学。
- [ ] 用药记录：药名、开始与停用时间、效果、副作用（不必写剂量，带着药盒即可）。
- [ ] 物质使用：酒、烟、咖啡、助眠药、其他物质，频率和量。
- [ ] 躯体情况：慢性病、近期检查结果、是否怀孕或备孕、月经情况。
- [ ] 家族史：亲属中有无精神障碍、住院、自杀。
- [ ] 风险情况：有没有自伤自杀念头、计划、过往尝试。
- [ ] 三个问题：最可能的诊断是什么？还需要排除什么？下次复诊看什么变化？

> **什么时候需要联系医生或去急诊**
>
> 评估过程中如果出现下列情况，不要等到预约日：
>
> - 自杀念头变得频繁、具体，或已经开始准备：不要独处，拨打 **120** 或去急诊，也可拨打 **12356** 心理援助热线。
> - 出现命令性幻听、坚信被迫害、明显激越或有伤人风险：先保证安全，拨打 **120**，必要时 **110**。
> - 服药后出现高热、肌肉僵硬、意识改变、大汗：立即急诊。
> - 服药后出现大面积皮疹、起疱、面唇肿胀、呼吸困难：立即停药并急诊。
> - 突然停用酒精或镇静催眠药后出现抽搐、幻觉、意识混乱：立即急诊。
> - 出现木僵、拒食、缄默、长时间保持一个姿势：急诊精神科评估。

### 常见误区

**“医生问得太少，肯定不靠谱。”** 问得少确实可能是问题，但也要看问的是什么。有的医生用结构化访谈，问题密集而短；有的医生让你先讲十分钟再追问。判断标准不是时长，而是有没有问到病程、功能、躯体、物质、风险和家族史。

**“量表分数高，诊断就重。”** 量表测的是这周的痛苦程度，不是障碍的严重度分级。诊断里的“重度”还看功能损害、精神病性症状和风险。

**“医生说观察，就是没本事。”** 观察是诊断工具之一。尤其是首次发作、青少年、老年人、症状不典型的情况，仓促定论的风险更大。

**“换个医院就能马上确诊。”** 换医生可能带来新的视角，但如果每次只提供碎片信息，结果往往还是“建议随访”。带着完整的时间线和旧病历去，比换多少家都有效。

**“检查都正常，说明我是装的。”** 精神障碍目前本来就没有确诊性的化验指标。检查正常排除的是“别的病”，不是排除你的痛苦。
