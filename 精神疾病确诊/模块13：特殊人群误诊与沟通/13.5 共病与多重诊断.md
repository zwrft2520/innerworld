# 13.5 共病与多重诊断

拿到诊断书，上面写着三个、四个甚至五个病名，很多人第一反应是：“我到底有几个病？是不是医生在乱贴标签？”反过来，也有人把所有不舒服都归给一个诊断：“这都是抑郁引起的”“这都是精神分裂症的阴性症状”。这一页讲共病为什么常见、诊断该按什么顺序排、以及什么时候多个诊断是必要的、什么时候是过度。

## 一、共病是常态，不是例外

【研究】在精神科门诊和住院人群中，同时符合两个以上诊断的比例很高。这不是医生水平差，而是因为这些障碍本来就共享症状、共享风险因素、常常互为因果。

| 组合 | 为什么要一起看 | 常见误判 |
|---|---|---|
| 抑郁＋焦虑 | 两者共享失眠、注意力差、易激惹 | 只治一个，另一个拖后腿 |
| ADHD＋焦虑 | 注意力差既可能是 ADHD，也可能是焦虑 | 把 ADHD 当焦虑，或反之 |
| 创伤＋抑郁＋物质使用 | 创伤后常借酒助眠，酒又加重抑郁 | 只诊断物质依赖，忽略创伤 |
| ASD＋ADHD | 两者可同时存在，DSM-5 起允许共诊 | 只认一个，漏掉另一个 |
| 双相＋物质使用 | 躁狂期冲动饮酒、吸毒 | 把双相发作当成“喝酒闹事” |
| 慢性躯体病＋抑郁 | 糖尿病、心脏病、疼痛与抑郁互相恶化 | 把抑郁当成“病的正常反应” |
| 人格问题＋创伤 | 长期创伤会塑造人格模式 | 只贴人格标签，忽略创伤 |

共病之所以常见，至少有三个原因：**症状重叠**（失眠、疲劳、注意力差、易激惹，几乎出现在所有障碍里）；**互为风险因素**（焦虑久了会抑郁，抑郁久了会酗酒，ADHD 长期受挫会发展出焦虑和低自尊，创伤会改变情绪调节和人际关系）；**同一个底层因素**（遗传、早期逆境、睡眠紊乱、慢性炎症，可能同时增加多种障碍的风险）。

## 二、诊断不是越多越好

共病的另一面是**过度诊断**。一个人带着四五个标签走出诊室，未必说明医生看得仔细，也可能是每个症状都被单独命名了一次。

过度诊断的代价是具体的：**治疗互相打架**（同时按双相、边缘型人格、ADHD、焦虑来治，用药方向可能冲突）；**多药叠加**（药越多，相互作用、副作用、依从性差的风险越高）；**身份被标签占满**（“我是双相加边缘加 ADHD 加 PTSD 的人”，比“我有一段很难的时期，正在处理几件事”更难恢复）；**真正的问题被淹没**（当所有症状都有一个现成标签，那个没被命名的原因——睡眠呼吸暂停、甲状腺、创伤、家暴——就更难被看见）。

所以判断“多个诊断是否合理”，不看数量，看三件事：**每个诊断是否都有独立的病程和功能损害；每个诊断是否都能解释一组不能被其他诊断解释的症状；治疗上是否需要分别处理。**

## 三、排顺序：五个问题，两种陷阱

诊断不是并列的清单，而是有先后的结构。临床上常用的排序逻辑可以拆成五个问题：

**第一，有没有躯体、药物或物质原因？** 这一步永远排在最前（见 [12.4 器质性与药物所致精神障碍的排查](<12.4 器质性与药物所致精神障碍的排查.md>)）。甲状腺功能异常可以同时模仿焦虑和抑郁；长期饮酒可以同时制造抑郁、焦虑、失眠和幻觉。

**第二，哪些是发作性的，哪些是长期的？** 这一点决定了诊断的“层级”。**发作性**（几周到一个疗程，有明确起止）：抑郁发作、躁狂发作、惊恐发作、精神病性发作；**持续性**（几年，稳定）：人格模式、焦虑特质、心境恶劣；**发育性**（从早期就有，贯穿一生）：ADHD、ASD、学习障碍。把发作当特质，会误诊人格；把特质当发作，会误诊双相。一个从小就这样、跨场景、稳定不变的模式，更可能是发育或人格层面的问题；一个“以前不是这样、最近两个月变了”的改变，更可能是发作。

**第三，时间上谁先谁后？** 先后顺序是判断“原发”和“继发”的重要线索。先有创伤，后有回避和警觉，更支持创伤相关障碍；先有长期注意力困难，后有焦虑和低自尊，更支持 ADHD 为主、焦虑为继发。但时间先后不是唯一证据，因为很多障碍会互相加重。

**第四，哪些症状能被一个诊断解释，哪些不能？** 这是“奥卡姆剃刀”的用法：优先用最少的诊断解释最多的症状。但如果剩下的一组症状有独立的病程、独立的治疗反应，就不能硬塞进同一个诊断。

**第五，哪个最危险、最影响功能？** 治疗的优先级不完全等于诊断的优先级。一个人同时有轻度社交焦虑和重度抑郁伴自杀念头，先处理的是后者。

| 排序问题 | 要问自己的话 | 影响的决定 |
|---|---|---|
| 器质性 | 最近查过身体吗？换过药吗？ | 先查还是先治 |
| 发作/持续 | 是“最近变了”还是“一直这样” | 发作性疾病还是人格/发育 |
| 先后 | 哪个先出现？ | 原发与继发 |
| 解释力 | 一个诊断能解释几组症状？ | 减少还是增加诊断 |
| 风险 | 现在最危险的是什么？ | 治疗先做什么 |

排序时要避开两个陷阱。

**陷阱一：重复计数。** 诊断标准里有一条常被忽略的规则：**一个症状如果能被另一个障碍更好地解释，就不应该同时算给两个诊断。** 这叫排除条款，目的是防止同一个症状被数两次。常见的重复计数包括：**注意力不集中**（抑郁发作时会出现，ADHD 也有；如果只在抑郁期出现，就不该单独诊断 ADHD）；**体重下降与拒食**（抑郁可以导致食欲下降，但如果有对体重增加的强烈恐惧、体像障碍、限制性进食行为，就要考虑厌食症）；**易激惹**（可见于抑郁、双相、ADHD、PTSD、对立违抗、ASD、睡眠不足，不能因为有易激惹就加一个“双相”）；**幻觉**（可见于精神分裂症、双相、抑郁伴精神病性症状、物质所致、器质性、谵妄）；**冲动与自伤**（可见于边缘型人格、抑郁、双相、ADHD、ASD、创伤，单靠自伤不能诊断人格障碍）。

**陷阱二：把所有症状都归给一个病。** 这更隐蔽，因为它听起来很“专业”。“这是精神分裂症的阴性症状”——可能是抑郁、是药物副作用、是长期住院导致的退缩、是甲状腺功能减退；“这是抑郁引起的”——可能是甲状腺、贫血、睡眠呼吸暂停、慢性疼痛、药物，也可能两者并存；“这是人格问题”——可能是未识别的 ASD、ADHD、创伤、双相、癫痫、听力下降；“这是焦虑”——可能是心律失常、低血糖、嗜铬细胞瘤、甲亢、药物反应。

一个实用的自查：**如果某个症状对针对“主诊断”的治疗毫无反应，就值得重新问一次“它真的属于这个病吗”。**

## 四、就诊时怎么讲清楚，以及可以问什么

共病的就诊最怕“说成一团”。可以按下面的结构准备一页纸：

- [ ] **时间线**：把每个问题的起点画在一条线上（例如：十二岁开始注意力差 → 二十岁第一次抑郁发作 → 二十五岁开始喝酒助眠 → 二十八岁出现闪回）。
- [ ] **分栏写症状**：哪一些是长期存在的，哪一些是最近几个月才有的，哪一些是吃药后出现的。
- [ ] **每个症状的功能影响**：具体到“因为什么做不了什么”。
- [ ] **用药史**：吃过什么、吃了多久、有没有效、有没有副作用。**不要只写药名，要写反应。**
- [ ] **治疗史**：心理咨询做过几次、什么流派、有没有帮助。
- [ ] **家族史**：不只是“有没有精神病”，还包括自杀、酗酒、住院、服药、学习困难。
- [ ] **你自己最想解决的一个问题**：一次门诊很难解决五件事，先定一个目标。

医生给出多个诊断时，这些问题值得问：

| 你想知道的 | 可以这样问 |
|---|---|
| 每个诊断的依据 | “这几个诊断里，哪一个是最确定的？依据是什么？” |
| 诊断之间的关系 | “这些是各自独立的，还是有一个是主要的、其他是继发的？” |
| 会不会重复计数 | “我这两个诊断有重叠的症状，您是怎么分开的？” |
| 治疗优先级 | “如果只能先治一个，您会先治哪个？为什么？” |
| 观察期 | “有没有哪个诊断现在还不确定，需要再观察几个月？” |
| 复诊时看什么 | “下次复诊，您希望我重点记录什么，来判断诊断对不对？” |

【临床经验】好的医生不会把诊断当成不可讨论的判决。他们会告诉你哪个诊断把握大、哪个是“工作假设”、哪个需要随访。**如果一个诊断完全无法解释、也不允许提问，那本身值得警惕。**

> **什么时候需要联系医生 / 去急诊**
>
> - **同时在吃多种精神科药物，出现嗜睡、走路不稳、手抖、心跳异常、发热、意识模糊**：尽快联系开药医生或急诊，警惕药物相互作用。
> - **同时服用多种镇静药、止痛药或酒精**：呼吸抑制风险显著升高，出现呼吸变慢、叫不醒，立即拨打 **120**。
> - **出现自杀念头、自伤行为，或开始囤药**：不要独处，让家人保管药物，立即联系医生或去急诊，也可拨打 **12356** 心理援助热线。
> - **多个诊断同时存在、治疗方案互相冲突时**：可以要求一次“用药重整”或多学科会诊，不要自行加减任何一种药。
> - **木僵、拒食拒水、意识混乱、抽搐**：立即急诊。

## 五、常见误区与下一步

**误区一：“诊断越多，说明病越重。”** 诊断数量反映的是症状的复杂程度和分类方式，不等于严重程度。一个诊断也可能很重，五个诊断也可能都很轻。

**误区二：“共病就是医生没本事，找不准一个病。”** 共病是真实存在的临床现象，不是诊断失败。但共病也需要证据，不能靠“多贴几个保险”。

**误区三：“既然是共病，就要每个都吃药。”** 不一定。优先处理最影响功能和最危险的问题，其他问题可能通过心理治疗、生活方式、环境调整来处理。

**误区四：“一个病能解释所有症状，就不该有第二个诊断。”** 只有在“解释得通”的前提下才成立。如果某个症状有独立的病程、独立的治疗反应，硬塞进一个诊断反而会误导治疗。

**误区五：“诊断变了，说明之前的医生是错的。”** 诊断改变常因为信息增加（比如补充了童年史、发现了躯体原因、观察到了发作）。判断医生水平，不看他是否从不改口，而看他是否**根据新信息修正**。

共病的处理原则通常是：**先稳定最危险的部分，再逐步处理其他部分；优先用非药物手段处理不紧急的问题；定期复核每个诊断是否仍然成立。**

【临床经验】一个有用的习惯是：每次复诊带一张“当前诊断与用药表”，让医生和你一起看——哪些诊断还有证据、哪些药还在起作用、哪些可以减。诊断不是刻在石头上的，它应该随着你而变化。
