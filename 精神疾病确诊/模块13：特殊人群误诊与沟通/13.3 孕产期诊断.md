# 13.3 孕产期诊断

怀孕和产后，是精神障碍最容易“第一次出现”的时期之一，也是最容易被一句“当妈的都这样”带过去的时期。产后情绪低落、产后抑郁、产后精神病，看起来都和“情绪不好”有关，但严重程度、起病时间、处理方式完全不同——其中产后精神病是可以危及母亲和婴儿生命的急症。这一页讲医生怎么把它们分开，以及家属该盯住哪些信号。

## 一、先分三件事，再把情绪低落与产后抑郁讲清楚

| 维度 | 产后情绪低落 | 产后抑郁 | 产后精神病 |
|---|---|---|---|
| 起病 | 产后 2–5 天最明显 | 产后数周内，也可更晚 | 多在产后 2 周内，常 48 小时至 2 周 |
| 核心 | 哭泣、情绪波动、焦虑、疲惫 | 持续低落、兴趣减退、自责 | 幻觉、妄想、意识混乱、行为紊乱 |
| 自知力 | 清楚，知道“我有点不对劲” | 多数清楚，但可能觉得“我不配当妈” | 常受损，不认为自己有病 |
| 严重度 | 轻，多可自缓 | 中到重，影响照护能力 | 急症，需立即精神科干预 |

这三者不是同一条线上的轻重档，而是**性质不同的三种状态**。把产后精神病当“严重一点的抑郁”来处理，是最危险的误判。

### 产后情绪低落：多数会自己过去，但不是“不用管”

产后三到五天，很多产妇会突然变得爱哭、易怒、焦虑、睡不好、觉得自己什么都做不好。这被称为“产后情绪低落”（baby blues），非常常见，不同研究报告的比例差异很大。它的特点是：**来得快、程度轻、两周内逐渐缓解**，不需要药物治疗，但需要实实在在的支持——有人帮忙做饭、有人接手夜里一次喂奶、有人听她说“我真的很累”，而不是“你想太多了”。

需要提醒的是：**“会自己过去”不等于“可以不管”。** 如果超过两周仍不缓解，或程度在加重，就不再是情绪低落，而要考虑产后抑郁。家属最容易犯的错，是在第二周、第三周还说“再等等看”。

### 产后抑郁：不是矫情，也不是“不会当妈”

【指南】产后抑郁的诊断框架和一般抑郁障碍相同：持续至少两周的情绪低落或兴趣减退，加上睡眠、食欲、精力、注意力、自我评价、无望感等方面的改变，并且造成明显的功能损害——抱不动孩子、无法喂奶、不敢单独和孩子待在一起、什么事都做不了。

产后抑郁有几个容易被忽略的特点：

- **焦虑比低落更突出。** 很多产妇的主诉是“我总是担心孩子会出事”“我一听到他哭就心慌”，而不是“我很难过”。
- **强迫性想法常见。** 反复检查孩子有没有呼吸、反复洗奶瓶、反复想“我会不会伤害他”（见下一节）。
- **自责与“我不配”。** 觉得自己不是好妈妈，觉得孩子跟着自己倒霉。这种想法本身可能是症状，不是事实判断。
- **对孩子的感情淡漠。** 有的母亲说不出“我爱他”，并因此极度羞耻。这可能是抑郁的表现，不代表她真的不爱孩子。
- **睡眠问题难以判断。** 新生儿本来就夜醒频繁，所以不能只用“睡不好”判断抑郁，要看**有机会睡的时候能不能睡**、以及白天是否持续疲惫。
- **孕期也会发生。** 产前抑郁同样常见，且与产后抑郁相关。

筛查常用 EPDS（爱丁堡产后抑郁量表），共十道题，界值因版本和地区不同（有的用九分、十分，有的用十三分），**分数只提示需要进一步评估，不能确诊**。特别要注意：EPDS 里有涉及自伤念头的一道题，任何阳性回答都必须被认真追问。

## 二、产后精神病：精神科最急的情况之一

【研究】产后精神病相对少见，研究估计大约每一千次分娩中有一到两例，但它属于**精神科急症**，因为风险直接指向母亲和婴儿。

典型表现：

- **起病急**：常在产后几天到两周内，突然变得不对劲。家属常描述“她好像换了个人”。
- **幻觉与妄想**：听到不存在的声音（有时内容与婴儿有关）、坚信孩子被掉包、被监视、被伤害，或坚信自己或孩子有罪。
- **意识与注意力波动**：说话跳跃、答非所问、搞不清时间地点，类似谵妄。
- **情绪剧烈波动**：极度兴奋、话多、不睡，或极度恐惧、绝望，可在几小时内切换。
- **严重失眠**：连续几天几乎不睡，且不觉得困。
- **行为紊乱**：抱着孩子不放、拒绝任何人接近、反复检查婴儿、做出危险举动。

**风险包括自杀和伤害婴儿。** 这不是为了吓人，而是这类疾病最需要被看见的部分。产后精神病需要**立即精神科急诊评估，多数需要住院**，并且不能把母亲和婴儿单独留在一起。有双相障碍史、既往产后精神病史、家族史的人，风险明显更高，应在孕期就提前告知医生并制定计划。

**不要等“出了月子再说”。** 产后精神病的窗口期就是最初两周，等待的代价可能是不可逆的。

## 三、产后强迫：最容易被误认为“她想伤害孩子”

这一节值得单独讲，因为它决定了一个母亲是被理解，还是被报警。

很多产后女性会出现**闯入性的、与伤害婴儿有关的想法**：把孩子从阳台扔下去、用刀划他、把他放进微波炉，甚至与性有关的内容。这些想法让她们极度恐惧、羞耻，不敢告诉任何人，因为“说出来别人会以为我是怪物”。

| 维度 | 产后强迫 | 产后精神病 |
|---|---|---|
| 对想法的态度 | 极度害怕、厌恶、拼命抵抗 | 可能相信这是真的，或被要求去做 |
| 自知力 | 清楚“这不是我想做的” | 常受损 |
| 是否实施 | 几乎不会，且会主动回避（把刀收起来） | 风险真实存在 |
| 伴随症状 | 反复检查、清洗、求保证 | 幻觉、妄想、意识混乱、失眠 |

**有闯入性想法，不等于有伤害孩子的意图。** 相反，越是为此痛苦、越是回避的人，越可能是强迫。但这句话不能反过来用：任何**具体的计划、准备行为、命令性幻听、或“我觉得我应该这么做”的信念**，都必须按急症处理。

## 四、必须排除的原因，以及孕期用药

孕产期的情绪变化，不都是“心理问题”。以下这些必须先排：

| 原因 | 线索 |
|---|---|
| 产后甲状腺炎 | 心慌、怕热、手抖、体重下降，或相反地怕冷、乏力、便秘；产后数月内出现 |
| 贫血 | 乏力、头晕、心慌、面色苍白，尤其分娩时出血多 |
| 感染 | 发热、下腹痛、恶露异味、乳房红肿热痛、尿痛 |
| 睡眠剥夺 | 连续多日碎片化睡眠，情绪和认知明显变差，补觉后改善 |
| 疼痛 | 伤口痛、腰痛、乳房胀痛，未充分处理 |
| 药物与激素 | 某些促排卵、激素、止吐、降压药物 |
| 分娩创伤 | 分娩过程中的恐惧、失控感、侵入性操作，之后出现闪回、噩梦、回避 |
| 双相障碍 | 既往有情绪高涨期、产后出现兴奋不睡话多 |
| 物质使用 | 酒精、镇静药、兴奋剂 |

已经确诊精神障碍的女性怀孕后，最常见的两个极端是：**自己把药全停了**，或者**什么都不敢说，硬扛到产后**。两者都可能带来风险。

【指南】规范的做法是：在备孕或发现怀孕时，尽快同时联系精神科和产科，把“停药的风险”和“继续用药的风险”放在一起讨论，包括病情复发的风险、孕期和产后的特殊风险、哺乳的考虑。这个决定没有标准答案，需要个体化权衡，**不能由患者自己拍板，也不能由某一个科单独决定**。

如果你正在服药并发现怀孕，**不要自行停药**，尽快联系开药医生。突然停药可能导致失眠、焦虑、病情复发，部分药物突然停用还会出现撤药反应。

## 五、家属能做什么，以及就医提示与常见误区

- [ ] 具体地接手：今晚你负责一次喂奶、这周你负责做饭、今天你带她出门走二十分钟。
- [ ] 不问“你为什么还不开心”，改问“今天哪件事最难”。
- [ ] 留意睡眠：如果她连续两三天几乎不睡，还很有精神，这不是“恢复得好”，要警惕。
- [ ] 留意语言：她说“我不配当妈”“孩子跟着我倒霉”“不如一起走了”，都要当真。
- [ ] 留意行为：反复检查婴儿、不敢单独和孩子待在一起、把孩子抱得不肯放手、说听到声音。
- [ ] 不评判她的想法：听到“我有时会想伤害孩子”，第一反应应该是“谢谢你告诉我”，而不是惊恐或指责。
- [ ] 保留求助渠道：产科、精神科、社区妇幼保健、心理援助热线，提前存好。
- [ ] 照顾自己：伴侣的抑郁和焦虑在产后也很常见，同样需要被看见。

> **什么时候需要联系医生 / 去急诊**
>
> - **出现伤害自己或婴儿的念头、计划或行为**：立即拨打 **120**（必要时 **110**），**不要让孩子和母亲单独待在一起**，并让另一个成年人全程陪护。
> - **听到命令她伤害孩子的声音，或坚信孩子被掉包、被魔鬼附身**：立即精神科急诊。
> - **连续两三天几乎不睡，同时话多、兴奋、行为紊乱**：立即精神科急诊。
> - **意识混乱、答非所问、搞不清时间地点**：立即急诊，同时排查感染、甲状腺、电解质、药物。
> - **拒食、拒水超过一天，或木僵、长时间不动、不说话**：立即急诊。
> - **产后大出血、发热伴下腹痛、乳房红肿热痛、伤口化脓**：立即急诊，这些是产科急症。
> - **情绪低落超过两周且越来越重，或无法照顾自己和孩子**：尽快精神科或产科门诊，不必等到“满月”。
> - 任何让你觉得“她不太对”的时刻，都可以先打电话给产科或精神科问一句。**宁可白问，不要赌。**

**误区一：“产后情绪不好是正常的，忍忍就过去了。”** 情绪低落多数会缓解，但产后抑郁和产后精神病不会靠忍过去。区别在于持续时间和严重程度。

**误区二：“喂奶不能吃药，所以只能扛。”** 是否用药、用哪种，需要精神科和产科一起评估，哺乳期也有可行的方案。**自行硬扛导致病情加重，对母婴的风险往往更大。**

**误区三：“想到伤害孩子，说明我是个坏妈妈。”** 闯入性想法在产后强迫中很常见，越是为此痛苦的人，越不可能真的去做。但这需要专业评估来区分，不能自己下结论。

**误区四：“产后精神病是性格问题或受了刺激。”** 它更可能与双相谱系、睡眠剥夺、免疫和激素变化相关，是疾病，不是道德失败。

**误区五：“第一胎没事，第二胎也不会有事。”** 既往产后精神病是再次发生的强烈风险因素，第二次怀孕应提前告知医生并制定预防计划。

处理通常分层：情绪低落以支持和休息为主；产后抑郁以心理治疗、社会支持和必要时的药物治疗为主；产后精神病以**尽快控制症状、保证母婴安全**为第一优先，常需住院，并安排出院后的随访和家庭支持计划。

【临床经验】对家庭来说，最重要的不是“谁对谁错”，而是**把风险说出口**。一个能在饭桌上说“我最近有过很可怕的念头”的家庭，比一个只能谈“宝宝真可爱”的家庭，安全得多。
