# 13.2 老年诊断

同一位老人，可能同时在吃七种药、有三种慢性病、听力下降、最近又摔了一跤。在这种背景下判断“他是不是抑郁”“他是不是痴呆了”“他是不是疯了”，比在年轻人身上难得多，也更容易被一句“年纪大了”带过去。这一页讲老年精神科诊断的几条特殊规则，尤其是**老年第一次出现精神病性症状**该怎么查。

## 一、老年诊断为什么不一样

年轻人看精神科，医生主要听症状；看老年人，医生还要同时看四样东西——它们会把任何精神症状放大、扭曲，也会制造出并不存在的精神症状。

| 放大器 | 具体表现 | 会造成什么误判 |
|---|---|---|
| 躯体共病 | 心脏病、糖尿病、慢阻肺、肾衰、肿瘤、疼痛 | 乏力、食欲差、失眠被当成抑郁；缺氧、感染被当成痴呆 |
| 多重用药 | 五种以上药物同时使用 | 药物本身引起抑郁、谵妄、幻觉、跌倒 |
| 认知与感官下降 | 听力、视力、记忆、处理速度 | 听不清被当成“多疑”；看不清被当成“幻觉” |
| 社会变化 | 退休、丧偶、独居、经济下降、搬离熟悉环境 | 悲伤被当成抑郁；孤独被当成退缩 |

【指南】因此，老年精神科评估通常比年轻成人更长：要问躯体病史、逐一核对用药、做认知筛查、评估日常功能（吃饭、穿衣、洗澡、如厕、行走，以及做饭、购物、管钱、服药、出行）、看跌倒风险和营养状态，还要问照护者能不能撑住。

**功能评估是关键词。** 诊断痴呆不只看“记性差”，而是看**日常生活能力是否已经需要人帮**；判断抑郁严重度，也常看“还能不能自己做饭、管钱”。一个能做八道菜、能自己坐公交的老人，和一个把盐当糖、出门就迷路的老人，即使量表分数相同，意义也完全不同。

## 二、老年抑郁：常不说“难过”，而说“难受”

老年抑郁最容易被漏掉，因为它长得不像教科书。

- **主诉以躯体为主**：吃不下、睡不好、没力气、浑身疼、便秘、头晕、心慌。问情绪，回答“还行吧”“我这个年纪还有什么好不好的”。
- **兴趣减退比情绪低落更突出**：以前天天去公园下棋，现在不去了；以前爱看戏，现在电视都不开。
- **认知损害明显**：反应慢、记不住事、注意力差，过去叫“抑郁性假性痴呆”，治疗抑郁后可以部分改善。
- **焦虑、易激惹、疑病**：反复担心自己得了重病，反复检查。
- **精神病性症状在老年抑郁中并不少见**：可能出现与罪恶、贫穷、疾病相关的妄想（“我早就该死了”“家里已经破产了”），也可能有幻听。这类表现容易被误认为痴呆或精神分裂症。
- **自杀风险更高**：老年男性是自杀率最高的人群之一【研究】，而且往往求助更少、计划更周密、手段更致命。

所以，问老年抑郁不能只问“你心情好吗”，要问：“最近还有什么事让你觉得有意思？”“这半个月，你早上醒来最想做什么？”“有没有觉得活着是负担？”后面这句，很多老人会诚实地回答。

筛查工具常用 GDS-15（老年抑郁量表简版）或 PHQ-9，但都只是筛查。**量表分数不能替代面谈**，尤其是听力差、文化程度低、方言不同的老人。

## 三、多重用药，以及谵妄、痴呆、抑郁的叠加

【指南】老年人常常同时看四五个科，每个科开两三种药，再加上子女买的中成药和保健品。药物之间的相互作用、抗胆碱能作用的叠加、肝肾功能下降导致的蓄积，都可能制造精神症状。要特别留意的几类：

- **镇静催眠药与苯二氮䓬类**：跌倒、记忆下降、白天嗜睡、矛盾性激越。
- **抗胆碱能作用强的药**（部分抗过敏药、解痉药、抗帕金森药、部分抗抑郁药）：意识模糊、幻觉、便秘、尿潴留。
- **降压药、利尿剂**：体位性低血压、头晕、跌倒；电解质紊乱可引起意识改变。
- **糖皮质激素**：失眠、欣快、易激惹、抑郁。
- **抗精神病药**：在痴呆老人中用于行为症状时，需要非常谨慎，与跌倒、卒中风险以及死亡风险升高相关，通常只在严重激越、有伤害风险时由医生短期使用。
- **阿片类、抗癫痫药**：嗜睡、意识模糊、认知变慢。

有时候，减少一种不必要的药，比增加一种新药更有效。但这必须由医生来做。**不要自行停用任何处方药**——突然停降压药可能反跳性高血压，突然停抗癫痫药可能诱发癫痫，突然停苯二氮䓬类可能出现戒断和谵妄。

谵妄、痴呆、抑郁这三者可以单独出现，也可以互相叠加，最典型的情形是：**一个轻度痴呆的老人，因为一次尿路感染或换了一种药，突然变得糊涂、躁动——这是谵妄叠加在痴呆上；等感染控制后，他恢复到的状态可能比之前更差。** 也有另一种情形：**一个抑郁的老人，因为不想动、不说话、吃得少，被当成痴呆；治疗抑郁后，认知明显好转。**

区分要点在 [12.3 谵妄与痴呆](<12.3 谵妄与痴呆.md>) 里有详细表格，这里只记三句话：**突然变差、一天之内波动——先想谵妄**；**几年缓慢下滑、日常生活越来越依赖别人——想痴呆**；**几周内出现、情绪和兴趣改变突出、常伴躯体主诉——想抑郁**。三者重叠时，处理顺序通常是：先处理谵妄的诱因（感染、药物、脱水、疼痛），再评估抑郁，最后做长期的认知和功能评估。

## 四、老年第一次出现精神病性症状：默认先查身体

这是本页最需要强调的一段。**六十岁以后第一次出现幻觉、妄想、严重猜疑，器质性原因的比例远高于精神分裂症。** 晚发性精神分裂症样精神病确实存在，但它是排除之后的诊断，不是第一诊断。

| 方向 | 典型线索 |
|---|---|
| 谵妄 | 急性起病、注意力波动、意识时清时浊、有感染或换药诱因 |
| 痴呆（尤其路易体） | 认知波动、反复生动的视幻觉、动作慢、僵硬、睡着时把梦演出来 |
| 药物 | 新加或加量后出现，减量后好转；抗胆碱能、激素、左旋多巴、镇静药 |
| 感觉剥夺 | 听力下降后的被害感；视力下降后的幻视（Charles Bonnet 综合征，患者常自知“不是真的”） |
| 抑郁伴精神病性症状 | 妄想内容与罪恶、贫穷、疾病相关，情绪低落突出 |
| 妄想障碍 | 除妄想外谈吐、功能相对保留，妄想内容不离谱 |
| 脑器质性 | 卒中、肿瘤、硬膜下血肿、正常压力脑积水、癫痫 |
| 代谢与感染 | 电解质紊乱、甲状腺功能异常、维生素 B12 缺乏、尿路感染、梅毒 |

对这类患者，医生通常会做：详细病史（一定带知情人）、完整用药清单、神经系统查体、认知筛查、头颅影像、脑电图（按需）、血液检查（血常规、电解质、肝肾功能、甲状腺功能、维生素 B12、必要时梅毒血清学）、尿常规。**不要因为“他以前一直很正常”就跳过这些。**

家属去就诊时，可以准备：

- [ ] **所有药盒**：直接把药盒、药瓶装袋带来，比口述准确。包括中药、保健品、外用药、别人给的药。
- [ ] **最近三个月的“变化点”**：换药、住院、跌倒、丧偶、搬家、感染、手术。
- [ ] **基线功能**：半年前他能不能自己买菜、做饭、管钱、坐公交？现在差在哪？
- [ ] **认知的具体例子**：重复问同一件事、忘关煤气、认错人、在熟悉的小区迷路。
- [ ] **精神症状的原话**：他具体说了什么？“有人要害我”是“感觉”还是“坚信”？有没有因此做什么？
- [ ] **睡眠与饮食**：几点睡、几点醒、夜里起来几次、最近体重变化。
- [ ] **听力与视力**：有没有助听器、眼镜？最近有没有明显下降？
- [ ] **安全**：有没有走失、跌倒、用火、乱吃药、给陌生人开门。
- [ ] **照护者状态**：谁在照顾？一天睡几小时？有没有撑不住的感觉？

> **什么时候需要联系医生 / 去急诊**
>
> - **任何突然出现的意识混乱、认不出人、看到不存在的东西**：立即急诊，按谵妄处理（见 [12.3 谵妄与痴呆](<12.3 谵妄与痴呆.md>)）。
> - **老年第一次出现幻觉、被害感、说话混乱**：尽快精神科急诊评估，同时查感染、药物、代谢和脑影像。
> - **跌倒撞到头后出现嗜睡、呕吐、意识变差**，尤其正在服用抗凝药：立即拨打 **120**，警惕硬膜下血肿。
> - **拒食、拒水超过一天，或明显脱水（口干、尿少、站起来头晕）**：尽快就诊或急诊。
> - **木僵、缄默、长时间不动、对外界几乎无反应**：需急诊精神科评估，同时排查躯体原因。
> - **说“活着没意思”“不想拖累家里”，或开始整理东西、交代后事**：不要独处，立即联系医生；有明确计划或已实施，拨打 **120** 或去急诊。
> - **出现伤人、放火、持械等行为，家中无法保证安全**：拨打 **120**（必要时 **110**）。
> - **走失**：立即报警（**110**），不要等二十四小时。

## 五、常见误区与下一步

**误区一：“人老了就这样。”** 衰老会带来变化，但不会带来持续加重的幻觉、妄想、拒食和功能骤降。这些是症状，不是年龄。

**误区二：“他这是老糊涂，查也白查。”** 一部分认知下降是可逆的：甲状腺功能减退、维生素 B12 缺乏、抑郁、药物、慢性硬膜下血肿、正常压力脑积水。查出来能改，就值得查。

**误区三：“药越多越好，多开点总没坏处。”** 老年人对药物更敏感，多种药物叠加的风险是实实在在的。定期做“用药重整”（由医生核对哪些还需要、哪些可以减）是有价值的。

**误区四：“他疑心重，是性格变了。”** 老年突然出现的猜疑，优先排查听力下降、谵妄、痴呆、药物和抑郁，而不是先归为“性格”。

**误区五：“老人不会自杀。”** 事实相反。老年自杀的成功率更高，而且常被“他只是心情不好”掩盖。任何自杀表达都要认真对待。

老年精神科的处理通常不是单一手段，而是同时做几件事：**精简和优化用药**、**治疗可逆的躯体因素**、**处理抑郁或精神病性症状**、**认知与功能支持**（作业治疗、认知训练、环境改造）、**照护者支持与喘息服务**、**安全安排**（防跌倒、防走失、用火用电、驾驶、财务）。

【临床经验】对家属最实用的一句话是：**把“他病了”和“他老了”分开看。** 属于老的，接受并适配；属于病的，检查并治疗。把两者混在一起，既容易过度治疗，也容易放弃本可以改善的部分。
