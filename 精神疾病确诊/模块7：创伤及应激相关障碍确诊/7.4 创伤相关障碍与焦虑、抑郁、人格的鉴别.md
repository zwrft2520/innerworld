# 7.4 创伤相关障碍与焦虑、抑郁、人格的鉴别

经历过创伤的人来就诊，主诉常常不是“我有闪回”，而是“我睡不着”“我高兴不起来”“我一谈恋爱就崩”。这时候，医生面对的是一个容易出错的岔路口：把创伤反应误当成抑郁，把抑郁误当成创伤，把长期的关系困难直接归给人格问题。这一页讲 PTSD 与焦虑、抑郁、双相、边缘型人格的重叠在哪里，以及“先后顺序”和“因果链”为什么是鉴别诊断的核心工具。

## 一、为什么会混：四重原因

1. **症状本来就重叠**。PTSD 有情绪低落、兴趣减退、注意力差、失眠；抑郁也有这些。PTSD 有过度警觉、惊跳；焦虑也有。
2. **共病率很高**。PTSD 与重性抑郁的共病在不同研究中常被引用为接近一半，与焦虑障碍的共病也很常见。【研究】共病不是例外，是常态。
3. **时间上互相纠缠**。创伤后先出现抑郁，几个月后才出现闪回；或者先有长期焦虑，遇到事件后加重。只问“现在有什么症状”，很难分开。
4. **叙事会被诊断塑造**。一个人被诊断为抑郁多年，可能从没人问过创伤史；反过来，一个人一旦被贴上“创伤”的标签，之后所有症状都可能被归给创伤。

## 二、与抑郁、焦虑的边界

### 抑郁：看“事件锚定”和“弥漫程度”

| 维度 | 更像 PTSD | 更像抑郁发作 |
|---|---|---|
| 触发 | 具体线索引发闪回、惊恐、僵硬 | 清晨加重，与具体线索关系不大 |
| 内容 | 反复回到同一个场景、同一种恐惧 | 弥漫的自我否定、无望、兴趣丧失 |
| 回避 | 回避特定地点、人、话题 | 回避社交是因为没力气、没意义 |
| 睡眠 | 噩梦、易醒、警觉 | 早醒或入睡困难，不一定有噩梦 |
| 自责 | 围绕事件：“我当时应该……” | 围绕自我：“我这个人就是失败” |

两者**可以同时成立**，这时诊断会写“PTSD 共病重性抑郁障碍”。共病不是诊断不精确，而是临床事实。

一个实用追问：**“如果那件事从来没发生，你现在的情绪会不一样吗？”** 回答往往能提示症状与事件的关联强度。

### 焦虑：威胁是“过去留下的”，还是“未来可能发生的”

广泛性焦虑的核心是“未来会出事”的担忧，内容随生活变化：钱、健康、工作、家人。PTSD 的核心是“过去的事还在发生”的体验：闪回、噩梦、被触发。

- 焦虑的人怕“万一”，PTSD 的人怕“又来”。
- 焦虑的人警觉是泛化的，PTSD 的人警觉常被特定线索点燃。
- 惊恐发作两者都可有，但 PTSD 的惊恐常与创伤线索绑定。

PTSD 也常与惊恐障碍、社交焦虑、广场恐惧共病。回避行为尤其容易混：一个不敢坐公交的人，可能是怕惊恐发作（广场恐惧），也可能是怕路过事发地点（PTSD）。

## 三、与双相、边缘型人格的边界

### 双相：看“发作性”和“精力”

这是最容易被漏掉的一条，因为漏掉的代价很大（治疗方向完全不同）。

| 维度 | 更像 PTSD／CPTSD | 更像双相障碍 |
|---|---|---|
| 情绪变化 | 由线索触发，几分钟到几小时 | 持续数天到数周的发作 |
| 睡眠 | 失眠、噩梦，但精力通常下降 | 睡眠需求明显减少而精力旺盛 |
| 活动 | 回避、退缩 | 目标性活动增多、话多、计划多 |
| 自我评价 | 羞耻、无价值 | 夸大、自信膨胀 |
| 家族史 | 不一定 | 常有双相或抑郁家族史 |

提醒两点：第一，双相患者常共病 PTSD，创伤史不会“排除”双相；第二，抗抑郁药后出现“像换了个人”，要回头追问轻躁狂史，而不是简单归为“创伤被激活”。

### 边缘型人格：最容易吵起来的一条边界

边缘型人格障碍（BPD）与复杂性创伤的重叠非常高，研究里两者共病常见，临床上常被混用。【研究】

| 维度 | 更偏 CPTSD | 更偏 BPD |
|---|---|---|
| 起病 | 症状明确围绕创伤，闪回与回避突出 | 长期的关系、身份、冲动模式，跨情境 |
| 自伤 | 多为调节解离与闪回 | 多为调节被抛弃感、表达痛苦、影响他人 |
| 关系 | 难以信任、易被触发 | 剧烈起伏、理想化与贬低交替、害怕被弃 |
| 身份 | 自我感缺失、羞耻 | 身份紊乱、目标与价值观反复改变 |
| 独处 | 可能偏好独处以避免触发 | 常难以忍受独处 |

这里必须说清楚两件事：

1. **BPD 不是“人格有缺陷”，也不是“矫情”。** 它是有明确诊断标准、有有效治疗、且常与创伤相关的一种障碍。用贬义的方式说“你就是人格问题”，既不准确，也有害。
2. **有创伤史不等于有 BPD，有 BPD 也不等于一定有创伤史。** 两者相关，但不是因果等式。

## 四、因果链、时间顺序与病程功能

鉴别不是“二选一”，而是画出一条时间线：

1. **事件之前**：有没有长期的焦虑、情绪低落、冲动、人际困难？如果有，说明这些可能是原发的或体质性的。
2. **事件之后**：症状在多久内出现？是否与事件内容相关？是否随事件线索波动？
3. **之后的变化**：有没有完全缓解的时期？有没有发作性的精力改变？有没有物质使用？
4. **当前维持因素**：睡眠、酒精、持续的威胁、家庭环境、经济压力。

四种常见的因果链：

- **创伤 → PTSD → 抑郁**（最常见）；
- **抑郁 → 回避与退缩 → 更容易遭遇事件**（间接路径）；
- **长期焦虑 → 事件后症状更重**（易感因素）；
- **双相或 BPD → 事件被卷入发作**（事件是触发，不是全部原因）。

诊断顺序的一般原则是：**先排除躯体与物质原因，再处理最危险、最可治的部分，最后才做人格层面的判断**。人格诊断通常需要长期观察，不宜在急性期下结论。

两条辅助线：

- **病程形态**：PTSD 慢性波动、与线索相关；抑郁是发作性，可有完全缓解期；双相是发作性且伴精力改变；BPD 是长期、跨情境、从青春期早期就有端倪。
- **功能损害形态**：PTSD 的损害集中在回避与警觉；抑郁集中在动力与兴趣；双相集中在发作期的失控与后果；BPD 集中在关系与冲动控制。

这两条线不能单独定诊断，但能帮医生判断“哪个是主线”。

## 五、就诊准备、误区与就医时机

### 就诊准备清单

- [ ] 画一条时间线：创伤事件、首次情绪问题、首次就医、首次用药
- [ ] 标注有没有“完全正常的时期”，持续多久
- [ ] 记录情绪波动的持续时间：几小时，还是几天
- [ ] 记录睡眠需求的变化：是睡不着，还是不需要睡
- [ ] 记录自伤的时间与情境：是为了缓解闪回，还是因为害怕被抛弃
- [ ] 记录关系模式：是否长期剧烈起伏
- [ ] 列出既往诊断与用药反应，特别是“吃药后像变了个人”
- [ ] 家族史：双相、抑郁、自杀、物质使用

### 常见误区

- **“有创伤史就一定是 PTSD。”** 创伤是风险因素，不是诊断本身。
- **“抑郁就是 PTSD 的一部分，不用单独治。”** 共病需要分别评估，治疗重点可能不同。
- **“BPD 就是创伤造成的。”** 相关，但不是简单因果；BPD 也有遗传与气质因素。
- **“诊断人格问题就是给这个人判死刑。”** 人格障碍可以治疗，且诊断会随年龄与治疗改变。
- **“先把创伤挖出来，其他症状就会好。”** 顺序常常相反：先稳定，再处理记忆。
- **“共病就是医生没本事，不能给一个明确诊断。”** 共病是真实的临床现象，不是诊断失败。

### 什么时候需要联系医生或去急诊

> - 出现自杀念头、自伤行为，或已经做了计划——立即拨打 **120**，或去最近医院急诊，不要独处。
> - 出现明显的兴奋、几天不睡、话多停不下来、冲动消费或冒险——尽快精神科急诊评估，警惕躁狂发作。
> - 出现命令性幻听、坚信被迫害——立即急诊。
> - 自伤伤口较深、出血不止、或伴感染——先急诊处理伤口。
> - 大量饮酒或镇静药后意识混乱、抽搐——立即急诊。
> - 目前仍处在暴力或控制关系中——先保证安全，报警（**110**）或联系庇护机构。

鉴别创伤相关障碍，靠的不是“哪个症状更像”，而是三件事：**事件锚定、时间顺序、功能损害形态**。三者对上，诊断才站得住；对不上，就要考虑共病、躯体原因，或者干脆写到“待观察”。
