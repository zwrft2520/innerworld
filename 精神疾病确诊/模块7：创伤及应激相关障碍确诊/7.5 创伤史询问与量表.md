# 7.5 创伤史询问与量表

“医生会不会让我把那天的事从头讲一遍？”这是很多人不敢去精神科的原因之一。答案是：不需要。诊断创伤相关障碍，不靠你复述细节，而靠症状模式、时间线、功能损害和排除条件。这一页讲医生通常怎么问创伤史、PCL-5 这类量表能做什么不能做什么、以及为什么“不强迫披露”不是客气话，而是一条专业原则。

## 一、询问创伤史的目的，不是“挖出来”

先明确三件事：

1. **为了诊断**：确认症状是否与事件相关，判断是否符合创伤暴露的前提。
2. **为了安全**：了解目前是否仍处在危险中（施害者是否还在身边、是否有自伤风险）。
3. **为了治疗计划**：决定先稳定还是先处理记忆。

不是为了满足好奇，也不是为了让你“哭出来就好了”。**披露本身不是治疗**，在准备不足时强行披露，可能造成再创伤化。【临床经验】

## 二、怎么问：从远到近，从功能到细节

专业询问通常遵循几条原则：

- **先说明目的与边界**：“我需要了解大概发生了什么，来判断你的症状和它的关系。细节你可以不说，随时可以停。”
- **从一般到具体**：先问“有没有经历过让你觉得生命受威胁、或身体受到严重伤害的事”，再逐步缩小。
- **用行为化、中性的语言**：避免“你是不是被……”这种带预设的追问。
- **多问影响，少问细节**：“这件事之后，你睡觉怎么样？”“有没有什么地方你不敢去？”
- **允许沉默和拒绝**：沉默不是不配合，可能是解离、羞耻或恐惧。
- **注意节奏**：一次门诊不必问完，可以分次。

| 场景 | 容易造成伤害的问法 | 更安全的问法 |
|---|---|---|
| 开场 | “你到底经历了什么？从头说。” | “我需要了解一个大概，不用讲细节，你可以随时停。” |
| 追问 | “他为什么打你？你是不是做了什么？” | “那次之后，你身上有没有受伤？当时有人帮你吗？” |
| 性相关 | “具体做了什么？” | “有没有人违背你的意愿碰过你？说是或不是就可以。” |
| 童年 | “你父母是不是虐待你？” | “小时候在家里，有没有人让你觉得害怕、或者没人管你？” |
| 反应 | “你怎么还在想这件事？” | “这些画面一般什么时候来？来了之后你做什么？” |

## 三、几个结构化工具，以及量表的局限

### 工具各自管什么

**生活事件清单（LEC-5）**：列出十几类可能的事件（自然灾害、事故、暴力、性侵、战斗、严重疾病、亲人意外死亡等），让受试者勾选“经历过、目睹过、听说过、工作接触过”。它的作用是**系统不漏项**，不是打分诊断。

**童年创伤问卷（CTQ）**：覆盖情感虐待、身体虐待、性虐待、情感忽视、身体忽视五个方面。它用于研究和临床筛查，能帮助梳理“长期、反复”的模式，但**不能替代访谈**，也不该被当成“创伤分数”。

**不良童年经历问卷（ACE）**：十类童年逆境，常用于公共卫生研究。它的问题是“累积风险”，不是诊断工具；分数高不等于一定有病，分数低也不等于没有受到影响。

**PCL-5（DSM-5 版创伤后应激障碍检查表）**：20 个条目，对应 DSM-5 的 PTSD 症状群，0–4 分评分，总分 0–80。它有三个常见用途：

- **筛查**：常被引用的参考界值在 31–33 分之间，提示“可能符合 PTSD，需要进一步评估”；
- **严重度监测**：治疗前后对比，看变化；
- **随访**：追踪症状波动。

**它不能确诊。** 确诊需要由受过训练的专业人员做结构化访谈（如 CAPS-5），结合病程、功能损害和排除条件。PCL-5 的分数高低，也不等于痛苦的大小。

### 量表的局限

| 局限 | 具体表现 |
|---|---|
| 回忆偏差 | 时间越久，记忆越容易被重构；情绪状态也会影响回忆 |
| 回避与否认 | 有人不愿承认症状，分数偏低；有人希望被看见，分数偏高 |
| 急性期 | 事件后几天填，症状还在变化，预测力有限 |
| 文化与语言 | 条目翻译、表达习惯、对“闪回”的理解差异 |
| 共病 | 抑郁、焦虑、解离都会推高分数 |
| 反复测量 | 可能变成求保证行为，短期安心、长期强化焦虑 |

还有一个常被忽略的问题：**量表本身可能成为一种仪式**。有人每天测一次，分数高就恐慌，分数低就怀疑自己“装病”。如果出现这种情况，应该和医生讨论，而不是继续测。

### 分数高时，还要想到别的解释

PCL-5 高分不等于只有 PTSD。至少要过一遍这几类：

- **抑郁与焦虑**：情绪低落、担忧、失眠都会推高条目分；
- **解离与解离障碍**：麻木、失真感会被误答成“情感麻木”；
- **物质与药物**：酒精、镇静药、兴奋剂既造成症状，也干扰作答；
- **躯体与睡眠问题**：疼痛、睡眠呼吸暂停、甲状腺问题会模仿警觉与疲劳；
- **急性应激与适应障碍**：时间线还没走到“一个月”，分数却已经很高。

病程与功能仍然是必需的：症状从什么时候开始、有没有缓解期、是否随周年日或新闻波动；工作、学业、睡眠、人际、育儿、经济分别受到什么影响。量表分数不能替代这两块——一个 40 分但生活基本维持的人，和一个 25 分但已经无法出门的人，医生给出的判断会不一样。这也是为什么量表只能做筛查与随访，不能单独构成诊断。

## 四、不要强迫披露：一条专业原则

“不强迫披露”不是纵容回避，而是基于几个现实理由：

- **再创伤化**：在缺乏稳定与安全感时详述创伤，可能引发闪回、解离、自伤冲动；
- **解离状态下信息不可靠**：人在解离时可能记不清、说不清，甚至事后不记得说过什么；
- **信任需要时间**：披露的前提是“我说话是安全的”，这在第一次门诊往往还不成立；
- **目的不同，要求不同**：治疗性评估和法律取证是两件事，后者需要专门的程序与规范。

替代做法是：**先问功能，后问内容**。比如不问“他具体怎么打的”，而问“那段时间你能上学吗”“晚上能睡着吗”“有没有人知道”。这些信息同样能支持诊断。

如果对方说“我不想说”，专业的回应是：“好，那我们不说这部分。以后你想说的时候再告诉我。”——然后继续问别的。

特殊情境要额外留意：

- **儿童**：用适龄语言，避免诱导性提问（“是不是某某做的？”），注意非施害方的照护者是否在场；孩子的叙述易受暗示，需要更谨慎。
- **老年**：可能有早期的创伤史从未被问过；同时要区分创伤反应与痴呆、抑郁、躯体疾病。
- **男性**：性侵与家暴的披露率低，羞耻感强，常以酒精、易怒、工作狂呈现。
- **性少数与少数群体**：要区分“创伤事件”与“长期的社会歧视压力”，后者也会造成持续警觉与回避，但不一定符合 PTSD 的创伤前提。
- **司法与工伤情境**：评估目的不同，需提前说明“这次评估的用途”，避免让当事人误以为在治疗。

## 五、就诊准备、误区与就医时机

### 就诊前可以准备的清单

- [ ] 先想清楚：哪些我愿意说，哪些暂时不说（可以写在纸上）
- [ ] 事件的大致时间与类型（不需要细节）
- [ ] 症状清单：睡眠、噩梦、闪回、回避、易怒、麻木
- [ ] 功能：请假日数、能否出门、能否照顾孩子
- [ ] 目前是否仍处在不安全的环境
- [ ] 酒精、镇静药、其他物质的使用
- [ ] 有没有自杀念头、自伤行为
- [ ] 想问医生的问题：
  - [ ] 我需要做量表吗？结果代表什么？
  - [ ] 会不会需要做躯体检查？
  - [ ] 治疗大概分几个阶段？
  - [ ] 如果我说不下去，可以怎么处理？

### 常见误区

- **“不问细节就是不负责。”** 诊断不依赖细节，依赖症状、时间线、功能和排除。
- **“量表分数高才是真的受过伤。”** 分数是筛查工具，不是伤害的度量。
- **“必须一次讲完，医生才能帮我。”** 可以分次，可以只说大概，可以随时停。
- **“我不说，医生就诊断不出来。”** 医生可以从功能、回避、警觉、睡眠等侧面获得信息。
- **“PCL-5 高分就是 PTSD。”** 它提示需要进一步评估，确诊靠临床访谈。
- **“反复测一测心里有底。”** 反复测量可能是求保证，反而维持焦虑。

### 什么时候需要联系医生或去急诊

> - 在谈到创伤时出现强烈解离、失控、自伤冲动——先停下，联系医生；若已发生自伤，立即拨打 **120** 或去急诊。
> - 出现自杀念头、计划或准备行为——立即急诊，不要独处。
> - 披露后持续数日失眠、无法进食、无法照顾自己或孩子——尽快联系医生。
> - 目前仍处在暴力、控制、性侵环境中——先保证安全，报警（**110**）或联系当地庇护机构。
> - 出现解离性漫游、长时间失忆——尽快急诊评估。
> - 大量饮酒或镇静药后意识混乱、抽搐——立即急诊。

这一页想留下三句话：问创伤史的目的是判断关联与安全，不是让你复述；量表负责筛查和随访，访谈负责诊断；披露的节奏，应该由承受的人掌握。
