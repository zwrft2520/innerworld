# 7.3 复杂性创伤与解离的识别

有些人的创伤不是“一件事”，而是很多年：从小被打、被骂、被忽视、被性侵，或长期处在暴力的婚姻、家庭、机构里，逃不掉也说不出口。这类经历留下的影响，往往比单次事件更广，涉及情绪、自我认同、亲密关系和身体。这一页讲两件事：复杂性创伤在诊断上是什么样子，以及解离——那种“我不像我了”“这段记忆没了”的体验——怎么被识别和评估。

## 一、复杂性创伤：ICD-11 里的一个独立诊断

“复杂性创伤后应激障碍”（英文缩写 CPTSD）在 **ICD-11** 中是一个正式诊断，位置与 PTSD 并列。【指南】它的结构是：

- **PTSD 的三个核心群**：再体验（闪回、噩梦）、回避、当前威胁感（过度警觉）；
- **加上三个“自我组织紊乱”（DSO）的领域**：
  1. **情感调节困难**：一点小事就爆发，或长期麻木、空、无法感受；
  2. **自我概念受损**：持续羞耻、觉得自己有缺陷、无价值、失败；
  3. **关系困难**：难以信任、难以靠近、容易被触发，或在关系里反复讨好、退缩、失控。

需要强调：**DSM-5-TR 没有把 CPTSD 列为独立诊断**，它把这些表现分散在 PTSD、抑郁、解离障碍、人格障碍等条目下。所以同一个人的诊断名称，可能因为医生用哪套系统而不同。这不是谁对谁错，是分类系统的差异。【指南】

另外一个常见误解：CPTSD 不是“PTSD 更严重一点”。区别不在严重度，而在**症状的广度**——是否扩展到情绪调节、自我认同和关系模式。

## 二、长期人际创伤：为什么它不一样

典型的长期人际创伤包括：童年期反复的身体虐待、情感虐待、性虐待、严重忽视；长期家庭暴力；被控制、被拐卖、被强迫从事某种活动；长期霸凌；战争与难民经历；在封闭机构中受到系统性对待。

它和单次事故的差别在于四点：

1. **反复发生**：大脑学到的不是“这件事过去了”，而是“这件事随时会再来”；
2. **无法逃离**：尤其童年，施害者往往是照顾者，依赖与恐惧绑在一起；
3. **发生在关系里**：所以“人”本身变成了危险的来源，信任变得困难；
4. **发生在发育期**：影响情绪调节、自我感、依恋模式的形成。

这解释了一个常被误解的现象：为什么有些人明明离开了那个环境很多年，仍然一遇到相似的语气、表情、关门声就崩溃。那不是“还没放下”，是身体记住了。

## 三、解离：大脑的“断电”与“隔开”

解离是一个连续谱，从日常的“走神”到严重的身份与记忆断裂。常见的类型：

| 类型 | 体验描述 | 外人看到的样子 |
|---|---|---|
| 人格解体 | 觉得自己不是自己，像在旁观自己，身体陌生 | 说话像在念稿，情感平淡 |
| 现实解体 | 世界变假、变平、像隔着玻璃，声音变远 | 反应慢，像“不在场” |
| 解离性遗忘 | 记不起某段时间、某件事，甚至自己的信息 | 被问到时说“不知道”“一片空白” |
| 身份混乱 | 不同状态下像变了个人，喜好、语气、记忆不连贯 | 家人觉得“前后不像同一个人” |
| 解离性漫游 | 无目的出行，事后不记得怎么到的 | 突然出现在异地 |

**关键区分**：解离不是“装”，也不是“疯”。它是大脑在过载时切断连接的一种保护反应。很多人第一次听到“解离”这个词会说：“原来那种感觉有名字。”

也要和几个东西分开：

- **走神**：普通的注意力漂移，不伴记忆空白和身份改变；
- **癫痫的局灶性发作**：可有发呆、无目的的重复动作（自动症）、事后遗忘，需要神经科评估；
- **精神病性症状**：解离时的“内部声音”常是自己的想法变成声音，能与现实保持一定距离；幻听则更像“外面传来的声音”，常伴妄想；
- **物质作用**：酒精、大麻、镇静药都可造成类似体验。

## 四、评估、病程功能与需要排除的情况

**访谈**比量表重要得多。医生通常会问：

- 有没有“时间丢失”“事后发现自己在别处”；
- 有没有“觉得自己不是自己”“世界不真实”；
- 记忆是连续的，还是像有断片；
- 别人有没有说过“你刚才像变了个人”；
- 这些体验是什么时候开始的，和压力、睡眠、特定话题有没有关系。

**量表**方面，常用的有：

- **DES-II（解离体验量表）**：28 个条目，0–100% 自评，用于筛查解离体验的强度；它不能诊断，分数高只说明“值得进一步评估”。【研究】
- **结构化访谈**：如 SCID-D 一类的半结构化访谈，由受过训练的专业人员使用，用于区分解离性遗忘、人格解体、身份混乱等。
- **创伤史问卷**：如生活事件清单（LEC-5）、童年创伤问卷（CTQ），用于系统梳理经历，但**不是诊断工具**，也不该在第一次见面就要求逐条详述。

评解离有一个原则：**先建立稳定，再碰内容**。在一个人还没有基本的安全感和调节能力时，深挖创伤细节可能造成再创伤化。这不是回避，是顺序问题。

复杂性创伤的特点是**长期、跨情境、广泛**：

| 领域 | 常见表现 |
|---|---|
| 病程 | 症状常从童年或青春期开始，持续多年，随生活压力波动 |
| 情绪 | 长期低落、羞耻、易怒，或麻木、空虚 |
| 自我 | “我是坏的”“我不配”“我是负担” |
| 关系 | 难以信任、过度讨好、反复进入伤害性关系、或完全回避亲密 |
| 身体 | 慢性疼痛、胃肠不适、疲惫、躯体化 |
| 功能 | 学业中断、工作不稳、社交狭窄、育儿困难 |

功能损害的广泛程度，是复杂性创伤区别于单次事件 PTSD 的重要线索之一。

需要排除的情况：

| 类别 | 为什么像 | 区分线索 |
|---|---|---|
| 边缘型人格障碍 | 都有情绪不稳、自伤、关系困难、身份混乱 | 人格模式长期跨情境；CPTSD 的症状更明确围绕创伤与闪回 |
| 双相障碍 | 都有情绪大起大落 | 双相是发作性、有明确的持续天数与精力改变 |
| 精神分裂症谱系 | 都有“听到声音”、现实感异常 | 解离的声音多在脑内、可与现实检验共存；精神病性症状更持久 |
| 抑郁与焦虑 | 都有情绪症状 | 是否有事件锚定、解离、闪回 |
| 躯体疾病 | 慢性疼痛、疲惫、胃肠症状 | 检查结果、病程、与创伤线索的时间关系 |
| 物质与药物 | 酒精、镇静药可致遗忘与解离样体验 | 时间关系、停药观察 |

## 五、就诊准备、误区与就医时机

### 就诊前可以准备的清单

- [ ] 你想说到哪里、不想说什么，可以先写下来
- [ ] 有没有“时间丢失”“事后发现自己在别处”
- [ ] 有没有“不真实感”“像在旁观自己”
- [ ] 记忆是连续的，还是断断续续
- [ ] 别人有没有说过你“像变了个人”
- [ ] 情绪波动的触发点：语气、表情、关门声、某个地点
- [ ] 自伤、自杀念头（请如实说，这关系到安全）
- [ ] 睡眠、酒精与药物使用
- [ ] 目前是否仍处在不安全的环境里（这条最重要）

### 常见误区

- **“复杂性创伤就是 PTSD 的严重版。”** 不是。区别在症状广度，不在分数高低。
- **“解离就是多重人格。”** 解离是一个谱系，身份混乱只是其中一端，且诊断需要严格评估。
- **“谈创伤一定要把细节全讲出来。”** 不必。稳定优先，节奏由你掌握。
- **“时间久了自然会好。”** 一部分人会，一部分人需要针对性治疗；长期回避常让症状固化。
- **“有创伤史就一定能解释一切。”** 创伤是重要线索，但不能替代鉴别诊断。躯体病、物质、其他精神障碍都要排。
- **“诊断了 CPTSD 就没救了。”** 诊断描述的是当前状态和需要，不是判决。

### 什么时候需要联系医生或去急诊

> - 出现自杀念头、自伤行为，或已经做了计划——立即拨打 **120**，或去最近医院急诊，不要独处。
> - 发生解离性漫游、长时间失忆、不认识熟悉的人或地方——尽快急诊评估。
> - 目前仍处在暴力、控制、性侵的环境中——先联系可信任的人、报警（**110**）或当地庇护机构，安全优先于诊断。
> - 解离发作时出现冲出马路、自伤、误食等危险行为——先保证环境安全，必要时急诊。
> - 出现命令性幻听让你伤害自己或他人——立即急诊。
> - 大量饮酒或镇静药后出现意识混乱、抽搐——立即急诊。

确诊之后，医生通常会先评估安全（是否仍在危险环境、有无自伤自杀风险）、稳定程度（睡眠、物质使用、支持系统），再决定治疗顺序。复杂性创伤的治疗通常分阶段：先建立稳定与情绪调节能力，再处理创伤记忆，最后重建关系与生活。具体方案由面诊医生或治疗师决定。
