# 4. 常见误区澄清

> 这一篇专门拆那些让人更羞耻、更不敢求助的说法。每一条误区背后，都站着一个不好意思看病的人。如果你曾对号入座过任何一条，请把它划掉。

## 误区—事实—可以怎么想

| 误区 | 事实 | 可以怎么想 |
|---|---|---|
| 抑郁就是性格软弱、心胸狭窄 | 抑郁是有生物学和心理基础的疾病，和坚强与否无关 | "我生病了，不是我这个人差" |
| 就是想不开，想开点就好了 | 抑郁时大脑的情绪调节功能下降，"想开"恰恰做不到 | "我需要治疗，而不是被劝两句" |
| 穷人/闲人才抑郁，矫情 | 各阶层、各职业、各文化都会得病，名人也不例外 | "和我有没有钱、忙不忙没关系" |
| 单一原因造成的，比如失恋/失业 | 是素质、心理模式、环境、躯体因素叠加 | "不用逼自己找一个罪魁祸首" |
| 都怪父母遗传，或都怪我自己 | 多基因遗传、共享环境共同作用，谁都不该被追责 | "这不是任何一个人的错" |
| 男人/强者不会抑郁 | 男性患病率略低但求助率更低，常以易怒、酗酒、逃避表现 | "我也可以是那个会求助的强者" |
| "我经历的事不够惨，所以不配得病" | 发病看易感性与叠加，不看"苦难排行榜" | "我的痛苦不需要别人审批" |
| 得了抑郁就是一辈子完了 | 多数人经规范治疗可明显好转、恢复功能 | "这是一段可以过去的病程" |

## 为什么这些误区必须拆

【临床共识】污名和自我指责是抑郁者延误就医、不坚持治疗的主要原因之一。"我是不是太矫情了"这个念头本身，往往就让人把号又退了。

【个人体验】很多康复者回忆，最难的不是症状本身，而是"我是不是活该"。把这句话换掉，治疗之路就走顺了一半。

## 一个小练习

下次脑子里冒出"我是不是太脆弱了"，把它改写成：

> "我的身体和大脑现在生病了，就像我感冒时不会骂自己免疫力差一样。"

## 五、身边人常说的话，你可以这样回应

| 别人常说 | 内心真实 OS | 你可以试着说 |
|---|---|---|
| "你就是想太多" | 我也不想，但停不下来 | "这不是想不想的问题，是生病了" |
| "比你惨的人多了" | 那为什么我还是这么难受 | "痛苦不需要比赛，我的感受是真的" |
| "出去旅旅游就好了" | 我连出门都没力气 | "现在更需要的是看病和规律治疗" |
| "你就是闲的" | 我每天累到崩溃 | "忙和闲都可能抑郁，这不是原因" |
| "为了孩子/家人也要振作" | 我已经很努力在撑了 | "正是为了他们，我要规范治疗" |

## 六、关于"是不是我爸妈害的"

很多人患病后会翻旧账：是不是我父母的教育方式？是不是家里的气氛？【个人体验】去责怪一个已经生病的家庭，和去责怪自己一样，都不解决问题。早年经历确实是风险因素之一，但你现在成年了，治疗室、药物、自我照顾都在你自己手里。把力气从"追责"转到"康复"，路会顺很多。

## 七、一个判断标准

下次再听到任何一句让你羞耻的话，问自己：**"如果我得的是肺炎/骨折，这句话还说得出口吗？"** 说不出口，那它就不该被用在抑郁身上。

## 八、家属/伴侣常有的误区

- "他就是跟我闹情绪，哄哄就好"——情绪低落不是撒娇，哄和劝代替不了治疗。
- "家里没人得过，他怎么会得"——没有家族史也完全可能患病。
- "都住院了，是不是疯了"——精神科住院和内科住院一样，是为了系统治疗，不是"发疯"。

【个人体验】很多患者最需要的一句支持是："这不是你的错，我们一起想办法。"如果你正在读这篇，也请把这句话留给自己。
