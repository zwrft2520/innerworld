# 3. 医生诊断流程

> 你可能会奇怪：医生为什么问这么多、还要我抽血？这一篇把诊室里会发生的事提前告诉你——**诊断不是做一道题，而是把"症状、病程、功能损害、躯体排查"拼在一起判断。**

## 一、诊断是怎么建立的

### 1）病史采集与精神检查
医生会像"望闻问切"一样观察和提问：外表与衣着、言语快慢与多少、情绪是低落还是易怒、思维内容有没有消极念头、注意力和记忆力如何、你对自己病情有没有认识（自知力）。这些都是诊断信息，不是闲聊。

### 2）病程标准
【临床共识】按 ICD-11 / DSM-5，抑郁发作通常要求核心症状持续**至少两周**，且造成明显功能损害。医生反复问"多久了"，是在卡这条时间线。

### 3）严重程度与功能损害
症状多不多、轻还是重，更重要的是：还能不能上班、上学、照顾自己、维持人际关系。功能受损越明显，治疗越积极。

## 二、为什么要做一堆检查

| 常见检查 | 排查什么 |
|---|---|
| 血常规 | 贫血等血液问题可表现为乏力情绪低 |
| 生化（肝肾功、血糖血脂） | 躯体疾病、用药前基线 |
| 甲状腺功能 | 甲减/甲亢酷似抑郁/焦虑 |
| 维生素 B12、叶酸、维生素 D | 缺乏与情绪障碍相关 |
| 必要时头颅影像/脑电图 | 排除脑器质病变（老年、起病突然、有神经症状时） |

【临床共识】这些检查不是过度医疗，而是因为**有些躯体疾病和药物会伪装成抑郁**，漏掉了会耽误真正的病。

## 三、为什么医生要追问"你以前有没有特别嗨的时候"

这是在排查**双相情感障碍**（见"鉴别诊断"篇）。如果既往有过持续几天异常兴奋、话多、挥霍、睡眠需要减少、冲动的时期，诊断和用药策略会完全不同——单用抗抑郁药可能诱发转躁。

## 四、关于"一次就能确诊吗"

不能。【临床共识】抑郁的诊断主要靠临床访谈，量表只是辅助。首次就诊信息不全、症状可能变化，医生有时会说"先观察、用药后复诊再看"，这不是敷衍，是负责任。

## 五、就诊流程速查表

| 环节 | 会发生什么 | 我需要准备什么 | 大概多久 |
|---|---|---|---|
| 挂号 | 选科室、挂号 | 证件、医保卡 | 线上几分钟/现场排队 |
| 初诊访谈 | 问症状、病史、观察 | 带"就诊前信息整理" | 15–30 分钟 |
| 开检查 | 抽血、约化验 | 空腹要求（如需） | 半小时内 |
| 复诊 | 看结果、调药 | 记录用药反应 | 10–20 分钟 |
| 确诊与方案 | 解释诊断、开药/心理治疗建议 | 提前写好问题清单 | 视情况 |

## 六、精神检查到底在查什么

| 观察维度 | 医生在看什么 | 你不用紧张，自然表现就好 |
|---|---|---|
| 外表与行为 | 衣着整洁度、动作快慢、是否退缩 | 平时怎样就怎样 |
| 言语 | 语速、音量、话多还是话少 | 慢慢说没关系 |
| 情绪 | 是低落、焦虑、易怒还是平淡 | 真实感受可以直接说 |
| 思维内容 | 有没有消极念头、自罪、疑病 | 这是诊断关键，别隐瞒 |
| 认知功能 | 注意力、记忆力、定向 | 不是考试，不会就说不会 |
| 自知力 | 你是否认为自己需要治疗 | 说"我也不知道算不算病"很正常 |

## 七、为什么第一次不给"最终答案"

【临床共识】抑郁是临床诊断，没有验血指标。第一次门诊信息有限，医生要排除躯体病、看药物反应、观察症状变化，有时需要 1～3 次复诊才能稳定诊断。这期间你觉得"医生是不是没把握"——不是，是负责任。

## 八、你在诊断过程中的权利

- 有权问"我这个诊断依据是什么"；
- 有权问"为什么要做这项检查"；
- 有权对治疗方案提出疑问（副作用、疗程、替代方案）；
- 如果对第一位医生判断有疑虑，可以换一位复诊，这不叫"不配合"。
