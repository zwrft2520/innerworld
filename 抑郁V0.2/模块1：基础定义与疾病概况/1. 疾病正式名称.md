# 1. 疾病正式名称

> 本页用于解释"抑郁障碍""抑郁症"这些名字到底指什么、两套国际诊断体系（ICD 与 DSM）在命名上有什么差别。它不能替代医生的面诊诊断：你病历上的具体诊断，以接诊机构采用的分类版本和医生判断为准。

## 1.1 你会在不同地方看到的几个名字

- **抑郁障碍（Depressive Disorders）**：一组以持续情绪低落、兴趣或愉悦感下降等为主要表现的精神障碍的总称，是临床上比较规范的大类名称。
- **重性抑郁障碍（Major Depressive Disorder，MDD）**：DSM-5/DSM-5-TR 中的具体诊断名称，也就是老百姓口中"抑郁症"最常对应的那个正式诊断。
- **抑郁症**：日常俗称和科普用语，顺口、好懂，但它不一定严格对应某一套分类里的某一个编码。就诊、填保险或医疗资料时，最好直接使用病历上写的那个诊断。
- **抑郁情绪 / 心情不好**：这不是诊断，而是人人都会有的正常情绪状态，详见 1.3。

【临床共识】对外交流时，"抑郁障碍患者"或"正在经历抑郁发作的人"是中性、尊重的说法；"抑郁症"在科普语境下也完全可用。

## 1.2 两套国际分类：ICD-11 与 DSM-5 的命名差异

目前国际上主要用两套诊断与编码系统，它们的思路大体一致，但名称和编码不完全对等。看病时你可能在不同医院、不同资料里看到不同写法，这并不矛盾。

| 项目 | ICD-11（世界卫生组织） | DSM-5 / DSM-5-TR（美国精神医学学会） |
|---|---|---|
| 上位类别 | 抑郁障碍（Depressive disorders） | 抑郁障碍（Depressive Disorders） |
| 单次发作 | **单次发作性抑郁障碍（编码 6A70）** | 重性抑郁障碍，单次发作（Single Episode） |
| 反复发作者 | **复发性抑郁障碍（编码 6A71）** | 重性抑郁障碍，反复发作（Recurrent） |
| 长期轻度低落 | **恶劣心境障碍（编码 6A72，持续 2 年以上）** | 并入"持续性抑郁障碍（Persistent Depressive Disorder）" |
| 用途 | 国际健康统计、病历编码、医保对接 | 临床研究、学术与心理治疗沟通常用 |

【临床共识】两点差异请特别注意：
1. ICD-11 至今仍把"恶劣心境（dysthymia）"单独列为一个类别（6A72）；而 DSM-5 把它和其他形式的慢性抑郁合并成了"持续性抑郁障碍"。所以你可能在一份资料里看到"恶劣心境"、在另一份里看到"持续性抑郁障碍"，它们指的是很接近的长期低落状态。
2. 编码是给医院、医保、统计用的"内部编号"，不是给你自我对号入座的清单。**本文不把任何一串编码当作你个人的诊断依据。**

## 1.3 "抑郁情绪"不等于"抑郁障碍"

这是本页最重要的一点。人在失落、熬夜、被骂、失恋、失业、考试失败后出现几天低落，是非常正常的心理反应，**不自动等于得了抑郁症**。

要达到临床诊断的程度，医生通常会综合评估以下几条：

| 判别维度 | 一过性心情不好 | 可能需要考虑抑郁障碍 |
|---|---|---|
| 持续时间 | 几天到一两周，事情过去后慢慢好转 | 核心低落或兴趣下降持续约 **2 周以上**，几乎每天大部分时间都如此 |
| 功能影响 | 该吃吃、该睡睡，基本能照常生活 | 明显影响工作、学习、人际或自理，比如"连刷牙都像搬石头" |
| 伴随表现 | 主要是情绪差 | 同时出现睡眠、食欲、注意力、自我评价等多方面改变 |
| 能否被其他原因解释 | 由具体事件引起 | 无法用最近的事件、躯体疾病、酒精或药物完全解释 |

【个人体验】很多人会说："我又没有哭，是不是就不算抑郁？"——不是。有人表现为麻木、空虚、易怒，而不是流泪。反过来，"我已经难过好几天了"也不代表一定是病。**判断权在专业人员，不在这张表。**

## 1.4 为什么名字的用法有讲究（去羞耻化）

- 抑郁是一种**可以被诊断、可以被治疗的疾病**，和"想不开""矫情""意志力差"没有必然关系。
- 诊断名称是医疗沟通工具，它**不能定义你这个人**，也不能预测你的未来。康复后，你仍然是原来那个你，只是经历过一场需要治疗的病。
- 避免用"他就是想太多""她太脆弱"这类话概括患者——这既是对疾病的误解，也会让真的生病的人更不敢求助。

【临床共识】如果你正在读这份资料，并且怀疑自己可能处于抑郁状态，最有价值的下一步不是给自己贴标签，而是带着这份"我大概持续了多久、影响了哪些事"的记录，去精神科或心理科门诊谈一次。
