# 4. 名词释义

> 病历、医生嘴里、科普文章里经常蹦出一堆术语："复发性""恶劣心境""季节性""难治性……"。这一页把它们翻译成大白话，并附上"患者需要知道的事"。**这些解释只帮你读懂资料，不能用来给自己下诊断。**

## 4.1 一张表先看全：术语 → 是什么 → 对你意味着什么

| 术语 | 大白话定义 | 患者提示 |
|---|---|---|
| **抑郁发作（Depressive Episode）** | 一次达到诊断标准的、持续的抑郁阶段 | 医生说"你这是一次发作"，不等于你"一辈子都会这样" |
| **单次发作性抑郁障碍（ICD-11: 6A70）** | 人生中第一次、目前也只发作过这一次 | 仍需足疗程治疗，因为有复发可能 |
| **复发性抑郁障碍（ICD-11: 6A71）** | 之前发作过一次以上，这次是新一轮发作 | 复发 ≠ 你失败了；更需要维持治疗和预警意识 |
| **持续性抑郁障碍 / 恶劣心境（ICD-11: 6A72；DSM-5 称 Persistent Depressive Disorder）** | 长期（成人≥2年、儿童青少年≥1年）的轻度低落，症状不如重性发作那么剧烈，但拖得久 | 很多人"我以为我天生就是这种性格"——其实可能是病 |
| **伴季节性模式（季节性情感障碍）** | 抑郁发作与季节有规律关联，最典型是**秋冬发作、春夏缓解** | 光照治疗是公认有效手段之一 |
| **伴精神病性症状的抑郁** | 严重抑郁时出现幻觉、妄想（如坚信自己有罪、家很穷、身体烂了） | 这是需要尽快就医的信号，不等于精神分裂症 |
| **围产期抑郁** | 孕期或产后出现的抑郁 | 不是"矫情"，家人需重点识别和支持 |
| **伴混合特征（With mixed features）** | 抑郁发作的同时，伴随轻度的情绪高涨、话多、精力旺盛等躁狂样症状 | 提示医生警惕双相情感障碍，用药选择会不同 |
| **伴焦虑痛苦特征（With anxious distress）** | 抑郁同时明显坐立不安、紧张、担心失控 | 焦虑越重，治疗反应和风险评估越要重视 |
| **缓解（Remission）** | 症状显著减轻、基本不再符合发作标准 | 缓解 ≠ 治愈，仍可能有残余症状，不能自行停药 |
| **复燃（Relapse）** | 还在同一轮发作的恢复期内，症状又加重回来了 | 多与过早减停药物有关 |
| **复发（Recurrence）** | 已经完全缓解、稳定了一段时间之后，**新的一轮**发作 | 需要更长维持期 |
| **难治性抑郁（TRD）** | 经过两种及以上足剂量、足疗程的抗抑郁药规范治疗仍效果不佳 | 不等于"治不好"，有增效、联合、物理治疗等多种路径 |

## 4.2 重点术语展开讲

### （1）复燃 vs 复发：很多人搞混，其实差别很大

- **复燃（Relapse）**：你这次发作还没真正好利索，只是暂时轻了一点，结果症状又卷土重来。好比火灾刚压下去，余烬又烧起来。
- **复发（Recurrence）**：你已经彻底好了、稳定了好几个月甚至更久，然后**新的一次**发作。好比火彻底扑灭了，几年后别处又着了一次。

【临床共识】这个区分直接影响治疗策略：复燃更强调"赶紧把这次压住、别减药"；复发更强调"维持更久、学会识别预警信号"。

### （2）恶劣心境 / 持续性抑郁障碍：最容易被误认成"性格"的一种

【个人体验】这种状态特别坑人：它不像重性抑郁那样"轰"地一下把你击倒，而是**两三年、甚至十几年**都笼罩在一层淡淡的灰雾里——"我一直都这样""我天生就是个不快乐的人""可能人生本来就是苦的"。直到某次遇到重大压力，爆发一次重性抑郁，去看病才被点醒："原来前面那十几年也是病。"

【临床共识】ICD-11 仍把它单列为"恶劣心境障碍（6A72）"，要求成人持续至少 2 年、且这两年里没有连续 2 个月以上完全无症状；DSM-5 则把它并入"持续性抑郁障碍"。名称不同，说的都是这一类"慢性轻度低落"。

### （3）伴精神病性症状的抑郁：吓人，但要分清

- 典型表现：**心境协调的妄想**——内容和抑郁情绪是"配套"的，比如坚信自己犯了大罪、家里穷到活不下去、内脏已经烂掉。
- 也可出现幻听（比如听到有人骂自己、说自己该死）。
- 【临床共识】关键区别：这些症状是**继发于严重抑郁**的，抑郁好转后它们通常随之消失；这和"原发性精神病性障碍（如精神分裂症）"的起病方式、病程都不同。出现这类体验，请尽快就医。

### （4）难治性抑郁：不是"没救了"

- 一般指经过**两种及以上不同种类的抗抑郁药、足量足疗程（通常每种 ≥ 4–6 周）**规范治疗后，疗效仍不理想。
- 【临床共识】"难治"是治疗反应的描述，不是预后的判决书。下一步通常包括：换药、联合用药、增效剂、心理治疗联合、物理治疗（如 MECT、rTMS 等，详见治疗模块）。

## 4.3 你就诊时可以主动问医生的几句话

- "我这次是单次发作，还是复发性的？"
- "我现在算急性期、巩固期，还是已经在维持期了？"
- "我的症状里有没有需要特别标注的特征（比如焦虑、季节性）？"
- "如果以后出现 XX 情况，是算复燃还是可能要按复发处理？"
