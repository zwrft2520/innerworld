# 家属参考附录

> 写给陪伴抑郁患者的家人、伴侣、父母、成年子女、朋友。【临床共识】你的角色是**支持者，不是医生**。你不需要治好他，但你可以成为他最稳的那块地板。照顾好你自己，才能真正陪他走下去——这不是自私，是长期主义。

> 【重要声明】本附录面向家属，但语气同样平等：抑郁是疾病，不是"想不开"；患者本人不是"在闹情绪"，家属也不是"活该受罪"。本章所有医学建议不替代面诊，用药与治疗方案请遵精神科医生医嘱。

## 一、先定位：你到底是谁

- 你**不是**治疗师：不要自己诊断、不要替他调药、不要评判"这个医生靠不靠谱"。
- 你**是**：稳定的陪伴者、就医协助者、生活节律的共同维持者、安全的观察者。
- 一条黄金原则：**"我在"比"我懂"更重要；"陪着"比"解决"更重要。**

## 二、"该说 / 不该说"对照表（12 对以上，直接可用）

| 别再说 | 试着这样说 | 为什么 |
|---|---|---|
| "你就是想太多 / 想开点" | "我看到你最近很难受，这不是你的错。" | 否定感受只会让他闭嘴。 |
| "你就是太闲了，忙起来就好了" | "你愿意的话，我陪你做点小事；不想动也没关系。" | 把疾病归因为懒，是二次伤害。 |
| "你看别人比你惨多了" | "痛苦没法比，你现在是真的在受苦。" | 比较不会减轻痛苦，只会让人不敢求助。 |
| "你要坚强 / 你必须撑住" | "累了就歇，我陪着你，不用在我面前撑。" | 坚强的要求对急性发作期是压迫。 |
| "为了我 / 为了孩子 / 为了这个家，你也要好起来" | "你对我很重要，但你不需要为了我硬撑；我们一起面对。" | 道德绑架会加重内疚，内疚是抑郁的燃料。 |
| "你就是懒 / 不上进" | "我注意到你最近起不来，是身体/情绪出问题了，我们去看看？" | 疾病导致的退缩不是懒惰。 |
| "药有副作用，别吃了 / 是药三分毒" | "药的副作用可以跟医生说，咱们一起复诊问问。" | 劝自行停药可能致命。 |
| "我都为你做了这么多了，你怎么还这样" | "我有点累，但我没怪你；我们一起想办法。" | 付出感一旦说出口，就变成了债务。 |
| "你就是玻璃心 / 太脆弱" | "你现在比平时脆弱，是病在影响，不是你这个人不行。" | 把状态和人格分开。 |
| "你就是矫情 / 装病" | "我可能不太懂，但我看到你是真的不舒服，我信你。" | 信任比理解更基础。 |
| "出去玩玩 / 旅旅游就好了" | "等你状态好一点，我们再考虑出门；现在你想在家待着就在家待着。" | 强迫社交对急性期是消耗。 |
| "我早就跟你说过……" | "不说教了，现在最重要的是你好不好。" | 事后诸葛亮只会让人羞愧。 |
| "你倒是说话啊 / 你整天闷着算什么" | "不想说话也没关系，我坐这里陪你。" | 允许沉默。 |
| "你这样让我很崩溃 / 我快被你逼疯了" | "我今天状态也不太好，我先去自己待一会儿，晚一点再陪你。" | 家属的情绪要表达，但不要倒在患者身上。 |
| "一切都会好起来的" | "我不知道什么时候会好，但我会一直在。" | 虚假的乐观不如真实的陪伴。 |

## 三、实际可以做的 8 件事

1. **陪诊**：第一次就诊、复诊时陪他去，帮忙记医生说的话——抑郁发作时注意力很差，回家就忘。
2. **提醒服药，但不监督对立**："该吃药了哦"是温柔提醒；不要翻包检查、不要质问"你今天吃没吃"。
3. **维持生活节律**：一起按时吃饭、一起晒太阳10分钟、晚上一起散步——不催促，只同行。
4. **把任务拆到极小**：不是"你要振作"，而是"能不能一起把碗洗了""能不能下楼拿个快递"。
5. **帮他筛信息**：把网上那些"七天治愈"的垃圾内容挡掉，把靠谱的资料（12356、正规医院）放他手边。
6. **保护他的隐私**：不跟亲戚邻居说"他病了"；不发朋友圈；病历、药盒收好。
7. **配合治疗**：医生建议住院就住院，建议心理治疗就帮他预约；**不要替他拒绝治疗**。
8. **观察并记录**（见第六节）。

## 四、沟通原则（5 条）

1. **倾听多于建议**：他说的时候，先复述"我听到你是说……"，别急着给方案。
2. **允许沉默**：坐在一起不说话，也是陪伴。
3. **不承诺对自杀/自伤保密**：如果他告诉你"我不想活了"，**不要替他保密**——先保证他人身安全，再解释为什么不能替他守这个秘密。
4. **不道德绑架**："你这样我怎么办"这类话不要说。
5. **尊重自主权**：他不想说话、不想出门、不想见人，在**没有安全风险**的前提下允许他；但就诊、吃药这种关键事项，要温柔而坚定地推动。

## 五、危机时家属怎么办（只写安全，不写方法）

> 如果你发现他有以下情况：表达强烈的"不想活了/活着没意思"、安排后事、告别、把珍贵东西送人、突然异常平静、已经藏药/藏工具——**这是危机信号**。

- **直接问**："你是不是有过不想活的念头？有没有想过怎么做？"——**直接问不会"提醒"他自杀，反而让他感到被看见**。问完不要慌、不要骂。
- **不离人**：在确保你自身安全的前提下，不要让他独处。把可能被用于自伤的危险物品移开（不要展开具体方法，让专业人员处理）。
- **立刻求助**：
  - **12356**（全国24小时心理援助热线，免费，2025年已全国普及，核实日期2026-10-11，以当地官方公布为准）
  - **120**（急救）/ **110**（公安，现场有人身威胁时）
  - 直接送**有精神科急诊的三甲医院/精神卫生中心**。
- **住院不是抛弃他**：急性期住院是最安全的选择，配合医生；不要因为"面子"拒绝住院。
- **事后**：他情绪平复后，不要指责"你差点把我吓死"，而是说"我当时很怕失去你，我们以后遇到这种情况怎么办"。

## 六、如何观察与记录（给家属的小本子）

每天花两分钟记一下，复诊时给医生看，比回忆一个月前强得多：

- **睡眠**：昨晚大约几点睡、醒几次、几点醒、白天补不补觉。
- **饮食**：今天吃了多少、有没有食欲、体重变化。
- **言语**：有没有突然说"活着没意思""你们以后怎么办""我是累赘"。
- **行为**：有没有把东西送人、开始清理手机/电脑、辞掉重要工作、突然异常平静。
- **药物反应**：有没有明显嗜睡、心慌、恶心、手抖、"好像变兴奋了/话特别多/睡得很少却不困"（后者要警惕转躁）。
- **情绪**：是平稳、低落、还是烦躁易怒。

> 【临床共识】"睡得少却精神特别好、话多、花钱冲动"是**双相转躁**的线索，要第一时间告诉医生。

## 七、家属自己也要被照顾

- **你不是他的医生，也不是他的药**。把全部生活押在他身上，两个人都会垮。
- **给自己喘息**：和其他家属轮班、请护工、每周留半天给自己的事。这不是抛弃，是让你能撑得久。
- **你可以有自己的情绪**：委屈、疲惫、生气都是正常的；找你自己的朋友、心理咨询、家属支持团体（很多精神卫生中心有家属互助小组）。
- **不要自责**："我是不是哪里做得不好"——抑郁是疾病，不是你造成的。
- **处理你自己的病耻感**：你愿不愿意告诉自己的朋友/同事，同样是一个需要你自己权衡的事；不必勉强。

## 八、不同对象的特别提示

- **青少年家属**：不要把问题归为"青春期叛逆"；持续两周以上的低落、厌学、自伤痕迹（手臂划痕）、网络上的消极帖子，都要认真对待；**青少年抑郁自杀风险更高**，不要等。
- **老年家属**：老人常说"我老了没用了""给你们添麻烦"，这不是谦虚，是危险信号；老人躯体化多（头痛、胃肠不适），检查没大问题时要想到情绪问题。
- **伴侣家属**：抑郁期他可能不想亲热、不想说话、对什么都没兴趣——这是病，不是对你没感情；等他好了，关系会慢慢回来。不要在他最需要你的时候谈"我们是不是不合适"。

## 九、康复期如何陪伴

- **不催促**："你怎么还不好"是最伤人的话。
- **容忍反复**：偶尔几天状态回落是正常的，不是"前功尽弃"。
- **庆祝小进步**：今天他出门买了个菜、今天他自己热了饭——具体地、真诚地夸。
- **逐步还给他自主权**：病好一点之后，让他自己做决定、自己安排生活，不要一直当"病人"照顾。

## 十、家属一周陪伴自检（每周日花2分钟勾选）

- [ ] 这周我有没有说过"想开点/你就是太闲"？（说过没关系，下周注意）
- [ ] 这周我有没有陪他按时复诊/取药？
- [ ] 这周我有没有观察并记录他的睡眠、情绪、言语、行为？
- [ ] 这周我有没有留半天给自己喘息？
- [ ] 这周我有没有把自己的情绪倒给他？（有的话，下周找朋友/咨询师）
- [ ] 这周我有没有把他当"病人"而不是"人"对待？
- [ ] 我和他的紧急联系电话是否仍然存在手机里？
