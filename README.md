## 疾病正式名称
> 核心原则：收录**官方标准命名、编码、别名、曾用名、易混名词**，每条标注来源；区分「标准诊断名」「俗称/旧名」「易混淆名词」。

### 一、现行标准正式名称（优先放最前面）
1. **中文标准名称：精神分裂症**
    - 国内《中国精神障碍分类与诊断标准》（CCMD，现已基本不再作为临床诊断标准，但可做历史记录）、《中国精神分裂症防治指南》统一中文名称
    - 英文标准名称：**Schizophrenia**
2. 国际疾病编码与对应命名
    - ICD-11（国际疾病分类第11版，国内现行使用）
      疾病名称：精神分裂症
      编码：**6A20**
      可补充：ICD-11下包含的子条目名称（如精神分裂症，首次发作；反复发作型；持续型等）
    - DSM-5（美国精神医学学会诊断手册，国内临床参考使用，不作为国内法定诊断依据）
      疾病名称：**Schizophrenia（精神分裂症）**
      说明：DSM-5已经取消传统的偏执型、紧张型等亚型分类

> 补充备注：
> ICD是**国内医疗卫生、病历、医保、残疾评定的官方编码体系**；DSM是学术界常用参考标准，二者诊断条目略有差异，资料库要写明这点。

### 二、历史曾用名称（旧命名，现在不再使用，用于了解名词演变）
1. 早发性痴呆（Dementia praecox）——克雷佩林原始命名，非常重要，疾病史必收
2. 青春痴呆（旧译）
3. 布鲁勒：**精神分裂症（Schizophrenia）** 1908年定名由来（schize=分裂，phren=心智；Bleuler提出，原意是“心智内部各功能解离”，不是人格分裂）

> 这一段可以简单写命名历史，解释这个名字本身带来巨大大众误解的根源。

### 三、中文别名、书面简称（病历/文献里偶尔见到）
- 简称：分裂症（临床病历简写，**非正式全称**，仅书面简写）

> ⚠️注意：**分裂性精神病、分裂样精神病不是精神分裂症！** 不要混在名称里，放在【易混淆名词】

### 四、大众俗称（放在这里，专门用来做误区辨析）
> 明确标注：**不属于医学正式名称，民间叫法，存在污名化，不推荐使用**
- 疯子、神经病（重点辨析：医学上神经病是神经内科疾病，和精神疾病完全两码事）
- 精神病（广义，精神分裂只是其中一类，不能等同）

### 五、极易混淆、常被大众当成“同一个病”的名词（重点澄清，独立子项）
> 这些**不是精神分裂症**，很多普通人会搞混，资料库单独列出区分：
1. 分裂样障碍 / 分裂样精神病（DSM-5 / ICD-11：症状类似，但病程不足，部分后续才发展为精神分裂症）
2. 分裂情感性障碍（同时有精神病性症状+明显心境发作，独立诊断）
3. 解离性身份障碍（旧称多重人格、人格分裂 ——**重点！大众最大误区，和精神分裂完全不是一回事**）
4. 妄想性障碍（以持续妄想为主，幻觉较轻，独立疾病）

### 六、可选附加补充内容（放在名称模块末尾）
1. 名词词义解读：Schizophrenia词源拆解（Bleuler命名本意：思维、情感、感知之间的内在联系断裂，≠一个人分裂成多个人格）
2. 名称争议简述：学界一直有人提出改名提议（因为“分裂”二字持续造成巨大误解），例如曾提议“思觉失调症”，写明：
    - **思觉失调症：是中国台湾地区使用的中文名称；中国大陆临床、病历、官方文件不采用该名称**
3. 一句话小结：中国大陆法定医学正式名称只有**精神分裂症，英文Schizophrenia，ICD编码6A20**。
