# 1. 就诊触发信号

> 双相最耽误事的两种情况：一是躁狂期觉得"我好极了，根本没病"，拒绝就医；二是抑郁期觉得"我就这样了，看也没用"，硬扛。这一篇帮你和家人判断：**哪些变化说明该尽快约门诊，哪些情况必须立刻去急诊**。
> 本资料仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。

## 一、双相最容易被忽略的一点：那不是"状态好"

【临床共识】双相情感障碍和单纯抑郁最大的区别，就是它有"上去"的那一段——躁狂或轻躁狂。而这一段**往往被本人当成好事**：精力旺盛、灵感爆棚、效率奇高、熬夜都不困。很多人拖了好几年才就医，不是因为没有症状，而是因为"那段时间我状态特别好"。

【个人体验】一位康复者回忆："我那段时间三天只睡几个小时，觉得自己思路特别快、要干一番大事，刷爆了三张卡。我妈说我不对劲，我骂她不懂。直到我在低谷躺了一个月，医生问我：'你以前有没有过一段，好得不正常？'我才反应过来——那不是好状态，是病的一半。"

**所以本篇最重要的一句话：如果你（或家人）有过一段"异常地好、异常地能熬、异常地敢花钱"的时期，它和持续的低落一样，都是要看医生的信号。**

## 二、该尽快预约精神科门诊的信号（不必急诊）

出现以下情况，建议尽快挂精神科/心境障碍门诊，不必等到"完全垮掉"：

| 信号 | 具体表现 |
|---|---|
| 睡得少却不困 | 连续几天只睡很少时间，白天却精力旺盛、不觉得缺觉（注意：这是"睡眠需要减少"，不是失眠痛苦） |
| 话多、脑子转得快 | 话停不下来，别人插不上嘴；脑子里念头一个接一个、像在放快进 |
| 异常自信或夸大 | 觉得自己有超常能力、特殊使命；判断明显脱离现实 |
| 冲动行为明显增多 | 突然大额消费、盲目投资、鲁莽开车、高危性行为、停掉工作去"创业" |
| 注意力随境转移 | 一点小事就被带跑，一件事没做完又扑向下一件 |
| 持续的情绪低落 | 心情低、兴趣减、疲乏、早醒、自我评价低，持续数周以上 |
| 情绪明显"两极摆" | 一段时间亢奋、一段时间低落，交替出现或一起出现 |
| 家人朋友反复说"你不对劲" | 旁观者清，尤其在躁狂期，本人往往丧失自知力 |
| 已经反复发作过 | 无论上次是轻是重，再次出现类似苗头 |
| 靠喝酒/熬夜/某些药才能"稳住" | 开始用物质或极端作息自我调节 |

【临床共识】【研究结论】双相是一种发作性疾病，**早期识别、早期治疗能显著缩短发作时间、减少冲动造成的损失（金钱、关系、工作）**。躁狂期一次发作造成的财务和社交破坏，可能需要很多年才修复。

## 三、【最高优先级】出现这些情况，立即急诊/拨打急救

这是本篇最关键的分流，请和家人一起记住：

| 危险信号 | 为什么危险 | 行动 |
|---|---|---|
| 出现自伤、自杀念头或具体计划 | 抑郁相、尤其**混合相**（既躁又郁）时自杀风险最高 | **立即急诊或拨打12356/120**，身边留人 |
| 激越、冲动、有伤人或毁物倾向 | 严重躁狂期可能出现攻击行为 | **立即急诊或拨打110/120**，保证周围人安全 |
| 完全不吃不喝、彻夜不眠多日、话乱、幻觉妄想 | 重性躁狂/精神病性发作，身体可能快速衰竭 | **立即急诊住院评估** |
| 服药后高热、意识混乱、肌肉僵硬大汗 | 可能是5-羟色胺综合征等药物急症 | **立即急诊** |
| 首次剧烈胸痛、晕厥、意识异常 | 不是"情绪问题"，先排除躯体急症 | **先打120、先救命**，不要当成躁狂或抑郁硬扛 |

【临床共识】**"首次剧烈胸痛/意识异常等，先排除躯体急症"**——双相患者也会得心脏病、甲亢急症、药物不良反应。不要因为"我有双相"就把所有身体不舒服都归因于情绪。

## 四、分流表：急诊 / 尽快门诊 / 先自我观察并记录

| 你的情况 | 建议行动 |
|---|---|
| 有自伤/自杀念头或计划、有伤人冲动、彻夜不眠多日伴幻觉 | **立即急诊 / 拨打120或110** |
| 首次剧烈胸痛、晕厥、意识异常 | **立即打120，先排除躯体急症** |
| 又出现以前发作过的苗头（异常亢奋或持续低落） | 尽快预约门诊，不必等下次发作 |
| 睡眠/精力/情绪明显偏离常态，持续数日到数周 | 尽快门诊评估 |
| 家人反复说"你这段时间不太对" | 认真对待，安排就诊 |
| 偶尔情绪波动、压力期明显，但休假后能恢复 | 先记录、自我观察，持续不缓解再就诊 |

## 五、为什么"家人觉得不对"很重要

【临床共识】躁狂/轻躁狂期，**本人的自知力（即"知道自己病了"的能力）常常受损**。你可能真心觉得自己状态绝佳，而身边人的观察往往更早、更准。

- 躁狂期最典型的家庭冲突：本人认为"我好得很"，家人觉得"你太夸张了"。
- 抑郁期则相反：本人自责"我就是懒"，家人看到的是"他快撑不住了"。

【个人体验】所以如果你读到这篇，而你其实是家属——请不要只听当事人一句"我没事"。可以用《模块9》里的沟通话术，温和而坚定地陪他去医院。很多双相患者第一次被确诊，都是被家人"押"去的。

## 六、自我调节多久没效，就该看医生

| 情况 | 建议观察期 |
|---|---|
| 情绪低落、睡眠变化，自己调整作息、运动、倾诉 | 1～2 周不缓解，或越来越重 |
| 已经出现"睡少却不困、话多、敢花钱"等轻躁狂苗头 | **不必等时间，尽快就诊**——这类信号不是"自我调节"能压回去的 |
| 既往确诊过、又出现熟悉的发作感觉 | 直接联系主治医生，按既定方案复诊 |

【临床共识】**睡眠是双相最敏感的前哨**：一旦连续熬夜、作息紊乱，常常是转躁的前奏。发现自己"最近睡得特别少还特别精神"，不要当成好事，这是最该就诊的信号之一。

## 七、一句话记住

**"好得不正常"和"糟得提不起劲"，是同一枚硬币的两面——都要看医生。有自伤/伤人念头、彻夜不眠伴胡言乱语、首次剧烈胸痛晕厥，先打120；其余的，尽快挂精神科或心境障碍门诊，别硬扛。**
