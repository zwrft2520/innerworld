# 3. 就诊前准备清单

> 双相的诊断非常依赖"病史"——而病史最关键的部分，恰恰是你和家人**回忆起以前那些"好得不正常"或"糟得不正常"的阶段**。门诊时间短，靠临场回忆最容易漏掉躁狂期。这一篇是**可以直接打印、照抄填写的模板**，带它去诊室，医生几分钟就能抓住重点。
> 本资料仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。

## 一、为什么双相就诊尤其要提前写下来

【临床共识】医生诊断双相，最需要的信息是：**有没有过躁狂/轻躁狂发作、抑郁发作多久、发作怎么交替、对生活影响多大、有没有躯体疾病和用药史**。而躁狂期的本人常常不觉得那是病——这正是很多双相被误诊为"单相抑郁"的原因。你提前把"以前那段时间"写下来，直接决定了医生能不能一次看对。

你不需要写得像病历，大白话、举例子、写日期就够。

## 四、"上去"那段的自查（躁狂/轻躁狂信号，勾选）

请回忆自己**状态异常好/异常亢奋**的那段时间，有没有出现：

- [ ] 明显觉得睡得少却不困（比如连续几天只睡很少，白天照样精神）
- [ ] 话变多、说话快、别人插不上嘴
- [ ] 脑子里念头特别多、转得特别快
- [ ] 注意力很容易被无关的东西带走
- [ ] 异常自信、觉得自己特别厉害、有特别计划
- [ ] 花钱大手大脚、盲目投资、买一堆没用的东西
- [ ] 鲁莽开车、高危性行为、停学/辞职去"干大事"
- [ ] 脾气变得特别容易被激惹、和人吵架打架
- [ ] 活动量明显变大（同时开很多件事、忙个不停）

> 这些只是给你回忆用的提示，**不是诊断标准**。有没有、严重到什么程度，由医生判断。

## 十二、就诊当天要带的东西（出门前对照）

- [ ] 身份证、医保卡
- [ ] 这本填好的"就诊前准备清单"（尤其那张情绪波动时间线）
- [ ] 既往病历本、出院小结、所有检查报告
- [ ] 正在吃的所有药的药盒（或手机拍照）
- [ ] 一位了解你多年状态的**家属或老朋友**一起去——躁狂期的病史，他们往往记得比你清楚
- [ ] 一支笔、一张纸（记医生说的要点）
- [ ] 如有强烈自伤念头或身体极度不适，请家属陪同，必要时直接挂急诊

## 十三、就诊当天的小提醒

- **说具体事，别只下诊断**：别说"我觉得我是双相"，说"过去两年我有过两次连续熬夜还特别精神、疯狂花钱的时期，中间还躺了一个多月"。
- **该说的别瞒**：喝酒、熬夜、冲动消费、自伤念头、以前吃过的药——当着家属不好说，可以请医生单独谈话。
- **没听清就问**："这个病要监测什么？多久抽一次血？什么情况要立刻回来？"

【个人体验】很多人第一次被确诊双相时，反而有一种如释重负的感觉："原来我那些忽上忽下、花钱失控的年头，不是我人品差、不是我懒，是一种有名字、有办法的病。"

## 十四、一句话总结

**双相的病史，一半在抑郁期的记忆里，一半在家人的眼睛里。花十分钟把"情绪波动时间线"填好，再带个了解你的人去，这一次就诊的价值会大很多。**
