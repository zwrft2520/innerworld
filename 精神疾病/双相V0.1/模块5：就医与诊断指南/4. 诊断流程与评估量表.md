# 4. 诊断流程与评估量表

> 双相没有"拍个片子就知道"的仪器，它是**临床诊断**——靠精神检查、完整病史（本人+家属）、排除躯体疾病，再对照诊断标准。量表（MDQ、HCL-32、YMRS、PHQ-9 等）只是**筛查和监测工具，不能单独确诊**。双相还常常需要观察几次发作、经过一段时间才能把分型定准。
> 本资料仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。

## 一、医生是怎么诊断的（五步）

| 步骤 | 内容 | 你需要做的 |
|---|---|---|
| 1. 精神检查 | 医生面对面观察你的情绪、言语、思维、行为，询问症状 | 照实说、举例子 |
| 2. 病史采集（本人） | 情绪波动史、发作起止、诱因、既往用药、家族史 | 带上《就诊前准备清单》 |
| 3. 病史补充（家属） | 躁狂期你自己往往不自知，家属观察非常关键 | 带了解你的家属一起 |
| 4. 躯体与实验室排查 | 甲功、血常规、肝肾功能、血糖、心电图等，排除甲亢等"伪装成双相"的病 | 按医嘱抽血、做检查 |
| 5. 对照诊断标准 | 结合 DSM-5 / ICD-11 判断是I型、II型、环性心境，是否共病 | 由医生下结论 |

【临床共识】为什么医生总要你先查甲功？因为**甲状腺功能亢进**会心慌、兴奋、消瘦、失眠，看上去很像躁狂；某些药物、物质、脑部疾病也会造成类似情绪波动。把这些排除掉，双相的诊断才干净。

【临床共识】ICD-11 里双相及相关障碍的编码是：**6A60 双相I型障碍、6A61 双相II型障碍、6A62 环性心境障碍**（以 WHO ICD-11 浏览器实际查询为准）。DSM-5 对应"Bipolar and Related Disorders"一章。你不需要自己对号入座，但可以在病历上看到这些编号。

## 二、为什么双相常常"一时半会儿定不了型"

【临床共识】这是双相诊断最特殊的一点：

- 很多人第一次就诊时，正处在**抑郁发作**里，医生眼前的你"就是个抑郁症"；
- 而区分"单相抑郁"和"双相抑郁"的关键——**你以前有没有过躁狂/轻躁狂**——你自己可能不记得、或不觉得那是病；
- 所以相当一部分患者最初被诊断为"抑郁"，**直到某次治疗中出现了转躁、或家属补充了病史，才修正为双相**。

【个人体验】这不是医生水平差，而是双相本身就藏在抑郁的表象下面。所以：**如果你有过"好得不正常"的时期，一定要主动说**——这一句话可能直接改变你的诊断和治疗方向。

## 三、几个常用量表是干什么的（了解即可）

> 【重要声明】**以下所有量表仅用于筛查和辅助评估，不能据此确诊，也不能用来判断要不要吃药、要不要停药。** 它们是"体温枪"，不是"诊断书"。

| 量表 | 查什么 | 谁来评 | 用途 |
|---|---|---|---|
| **MDQ 心境障碍问卷** | 既往有没有过躁狂/轻躁狂的一群症状 | 自评 | **筛查双相**，尤其在抑郁患者中找出"藏着的双相" |
| **HCL-32 轻躁狂症状清单** | 轻躁狂的典型表现（精力、社交、性欲、消费等） | 自评 | 辅助识别双相II型（轻躁狂较轻、更易被忽略） |
| **YMRS 杨氏躁狂量表** | 当前躁狂症状的严重程度 | **医生/他评** | 躁狂发作时评估轻重、随访疗效；**你不需要自己填** |
| **PHQ-9** | 抑郁症状的程度（9题） | 自评 | 评估抑郁相、监测变化；**第9题自伤念头≥1分要立即告诉医生** |
| **GAD-7** | 焦虑程度 | 自评 | 双常常合并焦虑，一起填 |
| **HAMD / MADRS** | 抑郁严重程度 | **他评** | 医生用，你不用自己打分 |

【临床共识】**MDQ 和 HCL-32 是给"抑郁背后可能藏着轻躁狂"的人用的筛查工具**。它的意义在于提醒医生："这个人可能不只是抑郁"——但分数高低都不直接等于"是双相"，最终仍靠完整病史和医生判断。

## 四、MDQ 大致问哪些（示意，不是让你自测确诊）

MDQ 通常围绕你**一生中**是否出现过这样一段时期：比平时更开心/更易怒、精力更旺、睡得更少、话更多、想法更快、更爱社交/更爱花钱/性欲更强、同时开很多件事、更容易冲动。这些症状是否在**同一段时间**一起出现、造成了什么问题（工作、家庭、花钱、法律麻烦）。

- 它筛的是"**有没有过那样一段时期**"，不是"你现在严不严重"；
- **分数提示风险，不代替诊断**；
- 把结果拿给医生看，比你自己在网上对答案有用。

## 五、量表的正确用法（务必记住）

1. **按真实感受填**，不要为了"想确诊"或"想显得轻"改答案。
2. **不要天天测**。一周最多一次；分数本身的涨跌不该成为新的焦虑源。
3. 用**同一份量表、同一回顾周期**前后比较，别今天 MDQ、明天换个网上的"双相测试"。
4. 把分数和日期记下来，**复诊时带给医生看**——比你说"好像好一点"更有用。
5. **分数下降 ≠ 可以停药；分数升高也不必恐慌**，要结合"能不能上班、能不能管住冲动、睡得好不好"一起判断。
6. 网上各种"三分钟测双相"小程序鱼龙混杂，**以 MDQ、HCL-32、PHQ-9 等标准化工具为准，并交给医生解读**。

## 六、医生可能怎么排除"看着像双相"的其他病

| 容易混淆的情况 | 怎么区分 |
|---|---|
| **甲亢** | 查甲功；心慌兴奋伴消瘦、手抖 |
| **物质/药物引起的情绪波动** | 酒精、兴奋剂、激素、某些药物可诱发亢奋；靠病史和物质使用史区分 |
| **精神分裂症** | 双相在发作间期通常社会功能可恢复；精神病性症状与心境发作是否同步出现 |
| **ADHD** | 注意力问题从小就有、长期稳定，不是"发作性"的高低起伏 |
| **边缘型人格障碍** | 情绪波动多与人际关系被抛弃感相关，不是数周数月的躁狂/抑郁发作 |
| **单相抑郁** | 关键看**从无躁狂/轻躁狂**——这也是为什么要主动回忆"好得不正常"的时期 |

【临床共识】**双相与单相抑郁的鉴别，直接决定治疗方向**：如果是双相却长期只吃抗抑郁药，可能诱发转躁、快速循环（详见《模块6·药物治疗》）。这就是为什么医生对"你以前有没有过亢奋期"这个问题格外较真。

## 七、一句话记住

**诊断靠精神检查 + 本人和家属一起回忆的完整病史 + 排除甲亢等躯体疾病 + 对照标准；量表是温度计，不是判决书。双相常常要观察几次发作才能定准型——所以"主动说出那段好得不正常的日子"，比任何量表都重要。**
