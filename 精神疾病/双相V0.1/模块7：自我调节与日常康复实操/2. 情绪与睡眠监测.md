# 2. 情绪与睡眠监测

> **双相障碍的管理，从"看不见"变成"看得见"开始。** 情绪和睡眠不是凭感觉猜的，而是可以像记体温一样记下来的。坚持记几周，你会第一次看清自己的"过山车"长什么样，也能在转躁/转抑郁的最早期就抓到信号。本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。

## 一、为什么双相患者必须记"情绪日记"

【临床共识】双相障碍的特点是情绪在**两个方向**上摆动：躁狂/轻躁狂一端，抑郁一端，甚至混合。单靠"我今天心情不好"这种模糊感觉，你很难分辨自己是在"正常波动"还是"开始转相"。而医生在门诊只有十几分钟，他需要你提供过去几周的客观记录，才能判断：

- 你现在处于哪个相？
- 睡眠变化是不是转躁的早期信号？
- 药物起效了吗？副作用是什么？
- 复发苗头出现在哪一天？

【个人体验】很多康复者说："记日记之前，我觉得自己情绪是随机乱变的；记了一个月才发现——原来每次'睡少了'之后三四天，我就开始话多、乱花钱。"**规律一旦被看见，你就不再被它牵着走。**

## 二、最核心的一个信号：不是"失眠"，是"睡眠需要减少"

【临床共识】双相有一个和普通失眠完全不同、却最容易被误读的信号：

> **"我明明只睡了三四个小时，白天却一点都不困、精力反而很旺。"**

这叫**"睡眠需要减少"（decreased need for sleep）**，它是躁狂/轻躁狂发作的核心症状之一，和"想睡睡不着"的普通失眠完全两回事：

| | 普通失眠 | 双相的"睡眠需要减少" |
|---|---|---|
| 主观感受 | 痛苦、想睡睡不了 | **不困、甚至觉得"少睡反而更精神"** |
| 白天状态 | 疲惫、难受 | 精力旺盛、话多、脑子转得快 |
| 常见意义 | 焦虑、睡眠障碍 | **转躁的早期信号，要高度警惕** |

【临床共识】所以你记睡眠的时候，**不能只记"睡了几小时"，还要记"白天精力够不够、困不困"**。连续几天"睡得少 + 不困 + 精力旺"，是必须尽快联系医生的信号。

## 三、可抄写模板一：每日情绪睡眠记录表

建议用手机备忘录、Excel 或笔记本，每天晚上花 2 分钟填一行。**关键是坚持，不是完美。**

| 日期 | 上床时间 | 起床时间 | 实际睡眠时长 | 夜醒次数 | 白天困不困(0-10) | 情绪打分(-5~+5) | 精力打分(-5~+5) | 话多不多 | 今天主要事件/诱因 | 服药是否按时 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 例10/20 | 23:30 | 7:00 | 7.5h | 0 | 3 | +1 | +1 | 一般 | 上班正常，下午和同事小争执 | ✅ | 平稳 |
| 例10/21 | 1:00 | 5:30 | 4.5h | 0 | 0(不困!) | +3 | +4 | 话多 | 加班赶项目，喝了两杯咖啡 | ✅ | ⚠️睡得少却很精神 |
|  |  |  |  |  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |  |  |  |  |

**打分说明（自己定一个固定标准，别每天换）：**

- **情绪打分 -5 ~ +5**：-5 = 极度抑郁/绝望，0 = 平稳，+5 = 极度高涨/易激惹；
- **精力打分 -5 ~ +5**：-5 = 连床都起不来，0 = 正常，+5 = 精力爆棚、停不下来；
- **白天困意 0~10**：0 = 完全不困，10 = 困得睁不开眼。

> 【个人体验】建议在日历上把每天的分数点连成线。你会亲眼看到那条曲线是怎么慢慢往上飘（转躁）或往下掉（转抑郁）的——**视觉化的趋势，比任何感觉都诚实。**

## 四、可抄写模板二：情绪发作自查表

当你感觉"今天好像不太对劲"，花 1 分钟自查，对照下面两组信号打勾：

### 🟠 往躁狂/轻躁狂方向飘

- [ ] 最近睡得比平时明显少，白天却不困、精力更旺
- [ ] 话变多、语速变快，别人插不上嘴
- [ ] 脑子转得特别快，一个念头接一个念头，停不下来
- [ ] 容易烦躁、没耐心，一点小事就想发火
- [ ] 想买东西、想投资、想花钱的冲动变强
- [ ] 觉得自己特别行、特别有本事、有很多计划要做
- [ ] 注意力很容易被新鲜事吸引，一件事做一半就换下一件
- [ ] 社交变多、深夜还在约人、不想睡觉

### 🔵 往抑郁方向掉

- [ ] 对以前喜欢的事提不起兴趣
- [ ] 早上醒得特别早，醒了就再也睡不着
- [ ] 整天乏力、动一下都觉得累
- [ ] 不想说话、不想见人、想躲起来
- [ ] 出现消极念头："没意思""是个负担""不想撑了"
- [ ] 吃饭明显变少或变多，体重短期内波动
- [ ] 注意力没法集中，脑子像灌了浆糊

> **打勾越多、持续越久，越要早点联系医生。** 哪怕只中两三条，也别等。

## 五、可抄写模板三：睡眠记录表（更细的版本）

|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |  |

【临床共识】双相患者尤其要警惕：**连续几天睡眠被压缩（熬夜、加班、倒时差、节假日狂欢），是诱发躁狂/快速循环最常见的扳机之一。** 记睡眠记录的意义，就是在"睡得少却不困"刚出现的头几天就抓住它。

## 六、怎么把记录坚持下来

【个人体验】记日记最容易失败的原因，是"记太复杂、三天就放弃"。几个实用技巧：

- **固定时间记**：把它绑在一个每天必做的动作上，比如"刷完牙躺床上就填一行"。
- **只要一行，不要小作文**：手机备忘录一行 5 个数字就够。
- **允许断更**：漏记两三天没关系，接着记就行，不要有"打卡羞耻"。
- **每周回看一次**：周末花 5 分钟看一眼这一周的曲线，你自己就能发现规律。
- **复诊时带给医生看**：这是你门诊时最有价值的东西，比"我感觉好点了"有用十倍。

## 七、关于自评量表：只能筛查，不能确诊

【临床共识】门诊和科普里常用几个量表辅助你和医生了解状态，**注意：它们只是筛查工具，不能用来自我诊断或自行调药**：

| 量表 | 用途 | 提醒 |
|---|---|---|
| **MDQ 心境障碍问卷** | 筛查你有没有"轻躁狂/躁狂史"，帮助区分单相抑郁和双相 | 阳性不等于确诊，需医生面诊 |
| **HCL-32 轻躁狂症状清单** | 自查近几天有没有轻躁狂倾向 | 同上 |
| **PHQ-9** | 评估抑郁症状严重程度 | 分数变化可给医生参考 |
| **YMRS 杨氏躁狂量表** | 由医生/专业人员评定躁狂严重程度 | 不建议自己打分自己下结论 |

> 量表打出来只是个"提示"，真正的判断永远是医生结合你的病史、病程、社会功能后做出的。

---

> **最后提醒**：情绪和睡眠监测不是为了把自己变成病人，而是为了把"复发"这种大事，拆成"这几天睡少了、话多了"这些你能亲手干预的小事。早看见几天，就能少闯很多祸。
