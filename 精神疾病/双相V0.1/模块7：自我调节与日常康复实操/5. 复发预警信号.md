# 5. 复发预警信号

> **双相复发最值钱的窗口，是发作刚冒头的那几天。** 这时候症状还轻、自知力还在、家人还能沟通，一个电话、一次提前复诊，往往就能把一次大发作拦下来。这一页教你识别自己的"早期信号"，并在第一时间联系医生和家人。本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。

## 一、为什么"早期信号"对双相特别重要

【临床共识】双相障碍的发作很少是"突然一下就崩了"，大多有一个**几天到几周的渐进过程**：

- **转躁方向**：从"睡得少却不困"开始，几天内话越来越多、花钱越来越冲、觉得自己越来越行；
- **转抑郁方向**：从"提不起劲、不想见人"开始，慢慢滑向早醒、消极、回避。

如果你和家人能在这个阶段就识别出来、联系医生，很多时候只需要门诊调整一下治疗、睡好觉，就能避免一次住院。**这就是所谓的"早期间断"——在复发刚冒头时就介入。**

> 【个人体验】很多康复者回头看，才发现每次大发作前，自己其实早几天就"不对了"，只是当时没把它当回事。这一页就是帮你把这些"不对"提前列出来。

## 二、转躁/轻躁狂的早期信号

【临床共识】以下信号出现时，往往是"正在往上飘"，越早干预越好：

### 睡眠与精力
- [ ] **开始睡得比以前少，白天却不困、精力更旺**（这是最核心的早期信号）
- [ ] 早上醒得异常早，醒了再也躺不住
- [ ] 觉得"睡三四个小时就够了"，还为此得意

### 思维与言语
- [ ] 话变多、语速变快，别人插不上嘴
- [ ] 脑子里念头一个接一个，停不下来，计划越列越大
- [ ] 注意力特别容易被新鲜事带走，一件事做一半就换
- [ ] 觉得自己脑子特别快、特别聪明、想通了很多大事

### 情绪与行为
- [ ] 容易烦躁、没耐心，一点小事就想发火、想争论
- [ ] 购物、花钱、投资、刷礼物的冲动变强
- [ ] 社交突然变多，深夜还在约人、不想回家
- [ ] 开始觉得自己"特别行、要干一番大事业"，做重大决定（辞职、投资、闪婚闪离）
- [ ] 咖啡因、酒精喝得越来越多

> **以上信号只要连续几天出现两三条，就不要再观察了——今天就联系医生或家人。**

## 三、转抑郁的早期信号

【临床共识】以下信号出现时，往往是"正在往下掉"：

### 情绪与想法
- [ ] 对以前喜欢的事突然提不起兴趣
- [ ] 变得不想说话、不想见人、想一个人躲起来
- [ ] 脑子里开始出现消极的话："没意思""我是个负担""不想撑了"
- [ ] 自我评价变低，觉得自己什么都做不好

### 精力与身体
- [ ] 整天乏力，起床都费劲
- [ ] **早上醒得特别早，醒了就再也睡不着**（和转躁的早醒不一样，这里是伴随疲惫和绝望）
- [ ] 吃饭明显变少或变多，体重短时间波动
- [ ] 注意力没法集中，工作学习效率明显下降

### 行为
- [ ] 开始回避社交、推掉约定
- [ ] 个人卫生开始忽略
- [ ] 药物开始漏服、懒得复诊

> **只要"消极念头"开始反复出现，就不要等，立刻联系医生和信任的人——抑郁相和混合相的自杀风险，是双相管理中最需要警惕的事。**

## 四、混合状态：特别要警惕的一种"中间地带"

【临床共识】双相还有一种很凶险的情况叫**混合特征/混合发作**：同一时间里，躁狂和抑郁的症状缠在一起——

- 脑子里转得飞快、停不下来，却又觉得绝望、空虚；
- 精力很旺、坐不住，却又被强烈的无价值感和消极念头笼罩；
- 可能烦躁、易激惹，甚至出现伤害自己的冲动。

> **混合状态的自杀风险尤其高**——因为它既有抑郁的绝望，又有躁狂带来的冲动和行动力。一旦出现"又烦又绝望、脑子转得快却停不下来"的组合，不要拖，立即就医。

## 五、我的个人预警信号清单（模板）

每个人的早期信号都不一样。**请在你现在状态平稳的时候，花10分钟，凭自己历次发作的经验，把下面这张表填出来**，存在手机里，给信任的家人也存一份：

## 六、发现信号后：怎么"早期间断"

【临床共识】识别出信号后，具体怎么做：

1. **不要硬扛、不要"再观察几天看看"**——越早期介入，代价越小。
2. **今天就联系医生**：打门诊电话/线上问诊，说明"我最近出现了XX信号，担心要复发"，很多医生会让你提前复诊。
3. **告诉一个信任的家人/朋友**：把上面那张"预警信号清单"给他看，说"如果我出现这些，麻烦你提醒我、陪我去医院"。
4. **立刻守住三件事**：按时服药、按时睡觉、不碰酒精咖啡。
5. **暂停一切重大决策和大额支出**（参考《1. 急性躁狂与轻躁狂期应对方法》）。
6. 如果已经出现消极念头、自伤冲动、激越失控，不要等门诊号——直接按《模块8》走急诊/热线。

## 七、给家人：怎么识别"他自己没意识到的早期信号"

患者早期往往自知力下降，这就需要家人做"第二双眼睛"：

- **观察睡眠**：他是不是最近睡得越来越少、却说自己特别精神？
- **观察花钱和行为**：有没有突然大手笔消费、做以前不会做的冲动决定？
- **观察情绪**：是不是变得特别话多、特别易激惹、特别"自信"？
- **不要争论"你是不是病了"**，用具体事实说："你已经连续好几天只睡三四小时了，我有点担心，我们去医生那里看看好不好。"
- **提前约定授权**：清醒时和患者说好——"如果你开始出现这些信号，哪怕我反对，你也帮我联系医生。"

---

> **最后提醒**：复发不是失败，它是这种病的常态。真正决定预后的，不是"你会不会复发"，而是"复发后你多快能被接住"。把这张预警清单填好、存好、给家人一份——你就是在给未来那个可能"上头"或"下坠"的自己，提前留好了一只伸过来的手。
