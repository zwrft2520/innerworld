# 2. 心理因素

> 如果说生物学决定了"情绪调节系统有多敏感"，心理因素就决定了"这套系统在压力下怎么运转"——你的气质、认知模式、情绪调节能力、应对方式，都在影响你会不会转相、转多快。好消息是：**心理因素恰恰是心理治疗最能改变的部分**。

## 2.1 气质与性格：那些从小就有的"底色"

【研究结论】临床上发现，双相障碍患者在发病前，常带有某些**气质特征**，它们不是病，而是"易感底色"：

| 气质类型 | 通俗描述 |
|---|---|
| **情感旺盛型气质** | 天生精力充沛、热情、外向、情绪反应强、闲不住、爱社交 |
| **环性气质** | 从小情绪就容易在"偏高"和"偏低"之间来回晃，像情绪的背景杂音 |
| **抑郁气质** | 偏敏感、多虑、容易自责、追求完美 |

【个人体验】"我从小就是那个特别热情、特别精力旺盛、闲不住的孩子——大人都夸我活泼。直到后来我才明白，那份'活泼'的底色里，藏着日后双相的易感体质。"

【争议观点】谈气质不是给人贴标签——这些是**连续谱上的倾向**，多数有这些气质的人并不会发展成双相障碍。它们只是"易感性"，不是命运。

## 2.2 认知模式：看待世界的习惯

【研究结论】双相患者在认知模式上，常带有一些相似倾向：

| 认知倾向 | 内心独白举例 |
|---|---|
| **高目标、高抱负** | "我要同时做好几件大事" |
| **过度乐观/高估自己** | "这次一定成，没问题"（轻躁狂期更明显） |
| **完美主义** | "做不到最好就等于失败" |
| **反刍思维** | 低落时反复回想自己的过错、失败 |
| **情绪化决策** | 跟着当下的情绪走，而不是理性评估 |

【临床共识】认知行为治疗（CBT）用于双相，就是帮你**识别这些自动冒出来的念头，学会在情绪高涨时踩刹车、在低落时跳出反刍**——这是被研究证实有效的辅助手段。

## 2.3 情绪调节与应对方式

【临床共识】双相患者的情绪调节往往有这些特点：

- **情绪反应强、恢复慢**：一件小事就能引发强烈情绪，且平复需要更长时间；
- **冲动应对**：情绪上来时，倾向于立刻行动（挥霍、吵架、刷爆购物车），而不是先停一下；
- **压抑 vs 爆发**：有人习惯压抑，压到极限后突然崩溃；有人一点就着。

【个人体验】"我以前情绪一上来就跟着走——高兴就疯狂消费，生气就立刻回怼。后来学着'停 10 分钟再反应'，很多冲动就过去了。"

## 2.4 自尊与自我评价的波动

【个人体验】双相患者的自尊常随相别摆动：

- **躁狂/轻躁狂期**：自我评价异常膨胀，"我无所不能"；
- **抑郁期**：自我评价跌到谷底，"我一无是处"。

【临床共识】这种自尊的大幅摆动，让患者很难对自己形成一个稳定、现实的评价。心理治疗的一部分，就是帮你建立**不随相别剧烈波动的自我评价**——既不飘上天，也不踩到地。

## 2.5 早年创伤：过去的事，不会真的过去

| 创伤类型 | 与双相的关系 |
|---|---|
| 童年情感忽视/虐待 | 升高日后情绪障碍风险，影响情绪调节能力发展 |
| 童年被欺凌、长期被否定 | 容易形成"我不够好"的底色 |
| 重大创伤（丧失、暴力、事故） | 可作为发病的应激扳机 |

【临床共识】如果你的病程里伴随着反复闪回、噩梦、过度警觉，要主动告诉医生——这会影响治疗方向（可能需要创伤聚焦的心理治疗）。**创伤不是"想开点"就能翻篇的。**

## 2.6 心理因素是"易感性/调节因素"，不是病因全部

【争议观点】必须强调：

- 这些心理因素**单独不导致**双相障碍——它是生物-心理-环境多因素叠加的结果；
- 谈它们不是为了"追责"你的性格或童年，而是为了**找到可以干预的着力点**；
- 气质和早年经历很难改变，但**认知模式、情绪调节、应对方式，是可以通过训练重新塑造的**。

## 2.7 这些心理因素能改变吗？——能

| 因素 | 能否被改变 | 通过什么 |
|---|---|---|
| 高目标/过度乐观 | 中等 | CBT、决策前"冷静期"练习 |
| 完美主义/反刍 | 较易 | CBT 思维记录、认知重构 |
| 冲动应对 | 较易 | "停 10 分钟再反应"、延迟决策 |
| 情绪恢复慢 | 中等 | 情绪调节训练、正念/放松 |
| 早年创伤 | 可修复 | 创伤聚焦治疗（如 EMDR），需专业指导 |

【个人体验】康复者常说："念头还是会冒出来——'我要干一票大的'或者'我真没用'。但我现在认得它了：'哦，这是我那个老模式又来了。'认得它，它就没那么容易牵着我走。"
