# 双相情感障碍（双相）｜患者版资料库
> 面向患者、家属自学，重点放在识别发作、就医、用药、日常自我管理、危机求助

## 模块1：疾病基础与名称词条
> 对应你之前做的「疾病正式名称」子条目，可单独拆分
1. 标准正式名称：双相情感障碍（旧称：躁郁症）
2. ICD-11 / DSM-5 分型子条目：
    - 双相Ⅰ型障碍：至少1次完整躁狂发作，常伴随重度抑郁发作
    - 双相Ⅱ型障碍：无完整躁狂，只有**轻躁狂发作 + 重度抑郁发作**（最容易被误诊为单纯抑郁症）
    - 环性心境障碍：长期（≥2年）反复轻躁、轻度抑郁波动，未达到重度发作标准
3. 别名、俗称、易混淆名词（躁郁症；区分：不是单纯抑郁症、不是精神分裂）
4. 基础科普：什么是躁狂、轻躁狂、抑郁发作；大脑情绪调节环路的简单解释（患者易懂版本，避免过度专业术语）
5. 常见误区：
    - 误区1：双相就是一会儿开心一会儿难过，只是情绪不稳定
    - 误区2：轻躁狂是“状态变好、精力爆棚，不需要治疗”
    - 误区3：抑郁期只需要吃抗抑郁药

## 模块2：发作症状识别（患者自查核心）
> 重点：区分【抑郁发作】【轻躁狂发作】【躁狂发作】【混合发作】，提供患者可观察的主观感受
1. 抑郁发作症状（和抑郁症重叠，但双相抑郁治疗方案不一样）
    - 情绪、动力、睡眠、食欲、自责、自杀想法、注意力减退
2. 轻躁狂发作（极易漏诊！）
    - 主观感受：精力突然变多、想法飞快、话变多、自信心暴涨、不需要睡觉、冲动消费/冲动决定；**还能维持基本社会功能，患者常会觉得这是“最好的自己”**
3. 躁狂发作（重症）
    - 明显冲动、夸大妄想、连续不睡、疯狂花钱、高危行为、易激惹暴怒，可能出现精神病性症状（幻觉妄想），往往需要住院
4. 混合发作：同时存在躁狂+抑郁症状（烦躁、想法多同时绝望、想自杀，自杀风险很高）
5. 发作预警信号（患者自我监测清单，资料库实用部分）
    - 睡眠变化是最敏感前兆：连续几天只睡2-4小时但完全不困，往往是轻躁启动
6. 病程特点：发作期+间歇期；复发风险，诱发因素

## 模块3：病因与风险因素（患者视角，不玄学）
1. 遗传风险（家族史）
2. 大脑神经递质：多巴胺、5-HT、去甲肾上腺素、下丘脑-垂体轴简化科普
3. 环境触发因素：熬夜、压力、重大变故、酒精/毒品、**单用抗抑郁药诱发躁狂**（重点警示）
4. 区分：不是性格问题、不是想太多、意志力薄弱

## 模块4：就医与诊断相关
1. 什么时候必须尽快就诊/急诊
2. 需要挂什么科室：精神科（不是心理咨询科单独诊断）
3. 诊断流程：病史采集、家属信息很重要、量表筛查（YMRS杨氏躁狂量表、汉密尔顿抑郁量表等）
4. 常见误诊情况：双相Ⅱ型常被误诊抑郁症；部分发作带精神病性症状，容易和精神分裂混淆
5. 检查项目：甲状腺功能、血常规、肝肾功能、电解质（排除躯体疾病导致情绪波动）

## 模块5：药物治疗（核心，患者版，强调遵医嘱）
> 资料库子条目可拆分：心境稳定剂、抗精神病药、谨慎使用的抗抑郁药
1. 核心药物：**心境稳定剂（双相治疗基石）**
    - 锂盐（碳酸锂）、丙戊酸钠、卡马西平、拉莫三嗪；作用、起效时间、常见副作用、需要抽血监测项目、注意事项
2. 第二代抗精神病药（用于躁狂、混合发作、维持期预防复发）
    - 喹硫平、奥氮平、利培酮、阿立哌唑、鲁拉西酮等；对应躁狂/抑郁维持的用途、副作用说明
3. 抗抑郁药：**双相慎用！**
    - 重点警示：一般不单用抗抑郁药，容易诱发躁狂/快速循环；仅医生评估后，联用心境稳定剂短期使用（比如安非他酮等）
4. 维持治疗概念：即使完全没有症状，维持用药预防复发；擅自停药是复发首要原因
5. 药物副作用管理：体重变化、嗜睡、手抖、脱发、内分泌变化；出现哪些副作用需要立刻联系医生，哪些可以复诊再沟通
6. 禁忌：不要自行加量、减药、停药；不要酒精、 recreational drug

## 模块6：物理治疗方案
1. MECT改良电休克：适用场景（重度抑郁、难治发作、有强烈自杀风险、严重躁狂激越），患者视角的术前术后说明、短期记忆影响
2. rTMS：辅助，部分双相抑郁可使用；躁狂期一般不做

## 模块7：心理治疗与康复（不能替代药物，辅助）
1. CBT认知行为治疗：识别情绪预警、纠正灾难化思维、识别冲动想法
2. IPSRT 人际关系与社会节律治疗【双相最推荐的心理治疗】：稳定作息、规律日常节律，减少发作（重点！睡眠节律对双相极其关键）
3. 家庭治疗：帮助家属理解疾病、减少冲突
4. 心理教育：学习疾病知识，学会自我监测
5. 社交/职业康复：间歇期如何逐步恢复工作、学习

## 模块8：自我管理与日常实操（患者最实用板块）
1. 情绪日记/情绪追踪：记录情绪分值、睡眠、压力、触发事件（可提供简易模板）
2. 稳定节律：固定起床睡觉时间（哪怕周末），睡眠管理是重中之重
3. 识别个人专属的「发作早期预警清单」（个人化，每个人前兆不一样）
4. 冲动行为预案：轻躁期容易冲动消费、冲动决策，提前设置保护措施
5. 生活方式：运动、营养；严禁酒精、大麻等物质
6. 压力管理、减压方法

## 模块9：危机识别与求助渠道
1. 高危信号清单：
    - 自杀自伤想法、计划
    - 躁狂发作，冲动危险行为、妄想幻觉
    - 完全无法自理、拒食不眠
2. 紧急求助方式：急诊、急救电话、危机干预热线
3. 提前制定「危机预案」：稳定期和家属约定，一旦发作谁帮忙送医

## 模块10：预后与常见误区科普
1. 预后：规范治疗下多数人可以长期稳定，保留社会功能；反复发作会增加功能损害
2. 常见误区清单
    - 轻躁狂是好状态不用吃药
    - 没有情绪波动就可以停药
    - 双相只要调节心态就能痊愈不用吃药
    - 躁狂=性格外向，抑郁=矫情
3. 关于快速循环型：一年≥4次发作，属于难治亚型
