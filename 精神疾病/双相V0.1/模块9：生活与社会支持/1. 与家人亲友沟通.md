# 1. 与家人亲友沟通

> **双相最让家人崩溃的地方，是它"来回摆"——昨天还亢奋得像打了鸡血，今天就跌到谷底。他们没见过这种病，很容易把它当成"你脾气差""你意志薄弱""你一阵一阵的"。这一页给你准备好话术、"该说/不该说"对照表和具体的求助清单，让你不必每次都从零解释。**
>
> 本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断。

## 一、先理解：双相为什么沟通起来特别难

【个人体验】双相患者在沟通中常遇到几种典型困境：

- **"我躁狂的时候觉得自己特别正常，是他们大惊小怪"**——可等你回到抑郁相，才发现自己上次冲动花掉了三个月工资、跟人吵翻了关系。
- **"他们只看到我砸东西、乱花钱，不看我痛苦的时候"**——家人被躁狂相吓到，往往只记得"你发病时多可怕"。
- **"我不想让父母担心，结果瞒着瞒着，漏服了药、熬夜了也没人提醒"**。
- **病耻感**：怕被单位知道、怕被催婚时被议论、怕谈恋爱被嫌弃。

这些感受都很真实。但【临床共识】研究告诉我们：**家人的理解、规律作息的共同维持、对早期复发信号的观察，是双相患者预防复发最重要的保护因素之一。** 问题不是"要不要说"，而是"对谁说、说多少、怎么说"。

## 二、三个版本的"解释话术"

不必对所有人和盘托出。下面是按对象分的三个版本，直接照抄也行。

### 对父母（尤其老一辈，最容易说"你就是脾气怪"）

> "爸、妈，我这段时间去医院查了，医生说是**双相情感障碍**——你们可能听过老名字叫'躁郁症'。这不是我性格有问题，是大脑里管情绪的那个'开关'出了毛病：有时候会莫名其妙地兴奋好几天、睡得特别少也不困、话特别多、控制不住地想花钱；有时候又会突然跌到谷底，什么都不想干。
>
> 它是有生物学基础的病，跟高血压糖尿病一样需要长期吃药和复诊，不是我'作'、也不是我'意志不坚定'。我现在在认真治，会慢慢稳住的。
>
> 你们不用劝我'想开点'，也不用专门盯着我。你们能帮我的，是：发现我连着几天睡得特别少还特别兴奋、或者突然闷头不说话很久的时候，提醒我一句'你最近睡得不好，要不要跟医生说一声'。"

> 如果父母还是半信半疑：让他们陪你去一次复诊，让医生当面说。**医生一句话，顶你说十句。**

### 对伴侣（同住、朝夕相处的人）

> "我想认真跟你说一下我的情况。我被诊断为双相情感障碍，在长期吃药和复诊。
>
> 这个病的特点是情绪会像坐过山车一样来回摆。我可能有一阵子突然特别兴奋、话多、不想睡觉、看什么都看不顺眼容易发火；也可能有一阵子整个人缩起来，不想说话、不想动，觉得什么都没意思。**这不是针对你，也不是我变心了，是病在波动。**
>
> 我需要你做的，不是劝我开心或者劝我别生气，而是：
> 1. 我连着两三点才睡、还精神得很的时候，问我一句'你今天睡够了吗'；
> 2. 我乱花钱、乱承诺什么大事的时候，先别急着跟着做，等我两三天再商量；
> 3. 我低落的时候，不用讲大道理，陪我待着就行；
> 4. 提醒我按时吃药、按时复诊，但别翻我包检查。
>
> 我也会尽量把我的状态告诉你，不让你猜。"

### 对朋友 / 同事（不需要深入，只要不误解）

> "跟你说个事：我这段时间在应对一个情绪方面的问题，在治疗中。可能有时候我突然特别能聊、特别有精力安排一堆事，有时候又推掉聚会、回消息慢、不想说话——**这不是忽冷忽热针对你，是我在治病。** 你愿意的话，偶尔约我散散步、正常跟我来往，就帮大忙了。"

## 三、"该说 / 不该说"对照表

双相家属和朋友最容易说错的话，往往不是恶意，而是不了解。下面这张表，你可以直接转发给家人：

| 家人/朋友典型反应 | 背后可能是 | 你可以怎么应对 |
|---|---|---|
| "你就是脾气差 / 性格有问题" | 把疾病当成性格缺陷 | 不争论，"医生说是大脑里管情绪的地方出了问题，跟脾气是两码事。" |
| "你就是闲的，忙起来就好了" | 不了解双相的生物学基础 | "忙反而是我转躁的诱因之一，我现在最需要的是规律作息。" |
| "你上次不是挺好的吗？怎么又这样了" | 不知道双相是波动病程 | "双相就是会波动的，跟感冒好了也会再感冒一样，不是我故意反复。" |
| "你兴奋的时候不是挺正常的吗，装的吧" | 只看到轻躁狂期"状态好" | 轻躁狂期看起来像"打了鸡血"，但那是病理状态，不是真正的好状态。 |
| "别吃那些药了，是药三分毒" | 出于关心但不懂 | "药的副作用我会跟医生说，自行停药复发的代价大得多。" |
| "你怎么又乱花钱 / 又乱发脾气了" | 被躁狂相伤到 | 等你状态平稳后再谈，不要在躁狂高峰期争论；先把大额支出拦住。 |
| "为了这个家你也要振作" | 想鼓励但变成压力 | 低落期听到这种话只会更内疚，内疚是抑郁和混合相的燃料。 |
| "你看谁家谁谁不是也好好的" | 不了解个体差异 | 微笑着不接话，把科普发给他。 |
| 过度保护：什么都不让你做、天天盯着 | 担心，但方式让你窒息 | "我知道你担心我，但我也需要慢慢恢复自己做事。" |
| 反复问"你什么时候能彻底好" | 焦虑和不确定 | "医生说双相是长期管理的病，像高血压一样要长期稳住，我会定期复诊。" |

> 【争议观点】有些家人确实长期不理解、甚至贬低你。**你没有义务把每个人都教育成合格的支持者。** 把精力留给真正愿意听的人。

## 四、提出"具体可操作"的帮助请求

你越具体，对方越容易帮到你：

| 模糊的求助 | 更具体、对方更好接的版本 |
|---|---|
| "我可能要发病了" | "我连着三天只睡了三四个小时还特别精神，你陪我明天去复诊好吗？" |
| "帮我看着点钱" | "这个月如果我要刷信用卡买超过 2000 块的东西，你先拦我一下，等我两天再说。" |
| "我好难受" | "我今天什么都不想干，你陪我在家待着，各看各的手机也行。" |
| "提醒我吃药" | "你晚上九点给我发个消息问'药吃了吗'就行，不用盯着我吃。" |
| "我睡不着" | "我今晚又睡不着，你别跟我聊大事，陪我把灯关了躺一会儿。" |

**双相患者特别适合请家人做的几件小事：**

- 观察并记录：最近睡眠是不是变少了？是不是突然话特别多、特别易怒？是不是开始大手笔花钱？这些是复发早期信号；
- 提醒服药、提醒复诊，但不要翻包检查；
- 周末一起维持规律作息——按时吃饭、晚上一起散步 10 分钟，不催促，只同行；
- 在你躁狂高峰期，**陪你把大额支出、大额承诺先放一放**，等两三天再决定；
- 复诊时陪诊，帮你记医嘱（躁狂期和抑郁期注意力都差，回家就忘）。

## 五、一段可直接转发给家人的科普

> "双相情感障碍（旧称躁郁症）不是'脾气差'，也不是'矫情'。它是大脑里调节情绪的系统出了故障——就像一个温度自动控制坏了的空调，不是制冷就是制热，很少停在舒适区。它有明确的生物学基础和遗传倾向，是需要长期服药、规律作息、定期复诊的慢性病，和高血压、糖尿病需要长期管理是一个道理。
>
> 正在吃药的人，请不要劝他'是药三分毒别吃了'——双相自行停药后复发的风险很高，而且复发一次，治疗难度可能就上一个台阶。
>
> 你能做的最好的事：
> 1. 不评判、不说'想开点'；
> 2. 注意他的睡眠——**睡得突然变少却不困、话变多、花钱变冲，这是要复发的信号，第一时间告诉他的医生**；
> 3. 在他情绪平稳的时候，和他一起把作息稳住；
> 4. 如果他说'不想活了'，不要替他保密，帮他打 12356 或送医。"

## 六、不同对象的特别边界

**和伴侣：**
- 躁狂期你可能特别易怒、特别爱说话、特别想花钱/社交/做决定，**那不是伴侣做错了什么**；抑郁期你可能不想亲热、不想说话，那也不是对伴侣没感情。提前说清楚。
- 关系里的大事（钱、工作、要不要孩子、分手离婚），**尽量在你状态平稳时讨论，别在躁狂高峰或抑郁谷底做决定**——躁狂期做的决定，事后往往要还很久。
- 不要把"你必须陪我熬过去"变成控制；也不要把伴侣的疲惫当成"他不爱我了"。

**和父母 / 成年子女：**
- 如果你是患者本人：告诉父母"我在治疗，不需要你们全天候盯着"，把边界讲清楚。
- 如果你是青少年双相患者的家长：**不要把孩子的情绪起伏当成"青春期叛逆"**——持续几天的极度亢奋、睡得极少还不困、挥霍、易怒毁物，是要就医的信号，不是"中二病"。
- 不要在孩子面前反复说"都是我们害了你"——内疚会加重病情。

**和朋友：**
- 你有权只告诉"需要知道的人"，不必对全朋友圈公开。
- 双相康复者社群（正规医院组织的家属/病友团体）往往比普通朋友更懂你，可以同时建立。

| 类别 | 我可以找谁 | 能提供什么 | 联系方式 |
|---|---|---|---|
| 能倾诉情绪的人 | （朋友/家人） | 听我说、不评判 | |
| 能观察我状态的人 | （同住家人） | 注意睡眠/情绪/花钱变化，提醒我 | |
| 能帮我拦住大额支出的人 | （伴侣/父母） | 我冲动消费时先拦一下，等两天 | |
| 能陪诊的人 | （家人） | 陪复诊、帮记医嘱 | |
| 专业支持 | （医生/治疗师/热线） | 诊断、治疗、危机干预 | 医生电话：____；12356 |

> 如果某几栏是空的，没关系——这正是你接下来可以慢慢搭建的。

---

> **最后，请记住：** 你不需要一次让所有人都理解你。先找到一个人，告诉他。双相是个漫长的病，**你身边那个愿意陪你规律睡觉、陪你复诊、在你乱花钱时拦你一下的人，就是你最重要的保护因素。**
