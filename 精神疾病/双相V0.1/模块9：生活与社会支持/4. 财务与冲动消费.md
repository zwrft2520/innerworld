# 4. 财务与冲动消费

> **双相躁狂期最现实的后果之一，不是情绪崩溃，而是钱——一夜之间花光积蓄、盲目投资、借高利贷、给主播打赏、替人担保、冲动借贷给朋友，等回到现实才发现窟窿已经补不上了。这一篇是给你和家人的"财务防弹衣"：在你状态好的时候，提前把防护搭好；真的冲动起来，让制度替你踩刹车。**
>
> 本资料库仅作健康知识参考，不替代专业金融、法律建议。涉及具体合同与债务问题，请咨询正规金融机构/律师（法律援助可拨 12348）。

## 一、为什么双相患者特别容易在钱上出事

【临床共识】挥霍、冲动消费、盲目投资、轻率的大额财务承诺，本身就是躁狂/轻躁狂的**诊断症状之一**（"过度参与有明显痛苦后果的高风险活动：无节制购物、轻率的性行为、盲目投资、鲁莽驾驶"）。也就是说——

- 你躁狂期刷爆信用卡时，**不是"我管不住手"，是病在发作**；
- 你那时候觉得"我马上要赚大钱了""这钱花出去会十倍回来"，**那种笃定感是病造成的，不是真的商业判断**；
- 等你回到抑郁相，才看到账单——那时候你连起床都费劲，更别说处理债务。

> 【个人体验】很多康复者回忆起自己的躁狂期，用的词是"被一股力量推着"——根本停不下来，脑子一热就下单、就转账、就签字。**这不是意志力的问题，是大脑奖赏系统在病理状态下失控。** 所以不要靠"我下次忍住"，要靠制度。

## 二、躁狂期常见的财务"坑"清单

下面这些，是康复者和家属高频提到的真实场景，对照看看你中过几条：

- [ ] 疯狂网购/直播打赏，一次花掉一个月工资；
- [ ] 盲目投资：炒股/炒币/加盟/网贷理财，"这次一定赚"；
- [ ] 大额借贷：信用卡套现、网贷、甚至借高利贷；
- [ ] 给朋友"义气"转账、替人担保借钱；
- [ ] 冲动买大件：车、表、奢侈品、根本用不上的电器；
- [ ] 冲动辞职/裸辞创业，断了收入来源；
- [ ] 一时冲动把存款全取出来做"大项目"；
- [ ] 给游戏充值、给主播大额打赏；
- [ ] 冲动在网上签各种"课程加盟""代理"合同；
- [ ] 因为觉得自己"特别有魅力"，冲动进行高危的财务承诺。

> 中过几条不丢人——这是病的症状，你要做的是**提前装刹车，而不是事后自责**。

## 三、财务保护安排：在你状态好的时候搭好

【临床共识】财务保护的核心思路是：**把"躁狂高峰期的你"和"大额财务决策"隔离开。** 具体做法：

### 1. 设定"冷静期"规则

和自己（也和家人）约定一条铁律：

> **任何超过 X 元的支出/投资/转账，一律等 48 小时再决定。**

X 由你根据自己的收入定（比如 2000 元、5000 元）。48 小时后如果你还在正常睡眠、情绪平稳，再做决定。躁狂期的冲动，绝大多数撑不过 48 小时。

### 2. 限制高风险工具

- **信用卡**：保留 1 张日常用的就够，其他的在状态平稳期注销或调低额度；不要为了"方便"办一堆卡。
- **网贷/消费贷 App**：状态好的时候就卸载，不要留着"应急"——躁狂期你根本不会记得这是"应急"。
- **股票/币圈交易 App**：如果你的躁狂期曾经炒过，考虑在平稳期就把账户交给家人共管、或者干脆销户。
- **大额转账**：把银行卡的单日转账限额调低到你能接受的范围。

### 3. 授权一个你信任的人"共管"

这是最有效但也最难开口的一步。在你状态平稳的时候，和你最信任的家人（伴侣/父母）谈：

> "我跟你说个正事。我这个病，有时候会突然特别亢奋、控制不住花钱。我想请你帮我一个忙：如果我哪天突然要花一大笔钱、要借大钱、要做投资，你先拦我一下，问我一句'你最近睡眠怎么样'，等我两天再决定。"

具体可以做的安排（和家人商量着来，不勉强）：

| 安排方式 | 怎么做 |
|---|---|
| **共管账户** | 大额资产放一个双方共管的账户，大额支取需要两个人确认 |
| **信用卡副卡额度** | 日常用一张额度不高的卡，大额卡由家人保管 |
| **手机支付免密关掉** | 关掉小额免密支付，每笔都输密码——多一步操作，多一分冷静 |
| **家人保管银行卡/证件** | 极端情况下（反复躁狂挥霍），身份证、大额银行卡由家人保管，用时再取 |
| **紧急联系人知晓网贷账户** | 让家人知道你有哪些账户，万一出事能帮你止血 |

> 【争议观点】把钱交给家人管，听起来像"我不信任自己"。但康复者普遍的经验是：**这不是不信任，是像糖尿病患者把胰岛素放在固定位置一样，是对自己疾病的尊重。** 你状态好的时候设计的制度，是用来保护那个失控的自己的。

### 4. 提前做好财产与法律安排

- **写一份"复发应对财务备忘"**（不是遗嘱，是备忘）：你的账户、保单、贷款、欠别人的钱、别人欠你的钱——写下来放在家人知道的地方。万一你躁狂期被送住院，家人不至于两眼一抹黑。
- **不要在躁狂高峰期签任何大额合同**：加盟、代理、担保、借条、合伙协议——一律等 48 小时、等睡眠正常、最好跟你信任的人商量后再签。
- **担保是高危行为**：双相患者躁狂期特别容易"义气"替人担保。记住：**担保不是签字，是你替别人还钱的法律责任。**

## 四、如果已经花出去了：发作后怎么补救

【个人体验】如果你刚从一次躁狂挥霍中清醒过来，先做这几件事，不要先骂自己：

1. **先把"出血点"堵住**：关掉免密、注销多余卡片、卸载网贷和交易 App。
2. **列一张真实清单**：现在到底欠了多少、有哪些分期、有哪些要还的——写下来，数字比你想象的小（也可能比你想象的大，但写出来就不可怕了）。
3. **不要"翻本"**：这是最致命的一步——亏了就想"再投一笔赚回来"，结果窟窿更大。**已经亏的钱，不要再往里加一分。**
4. **和家人坦白，一起面对**：瞒着只会利滚利。家人帮你一起跟银行/平台协商分期，比你一个人硬扛强。
5. **已经涉及高利贷/暴力催收**：保留证据，拨 **110**，法律援助拨 **12348**。不要害怕，你不是第一个遇到这种事的人。
6. **复诊时告诉医生**：躁狂挥霍本身就是发作证据，医生可能需要调整治疗方案。
7. **不要因为这次就否定自己**：这是病的症状，不是你人品差。你现在做的补救，就是你在负责。

---

> **最后，请记住：** 躁狂期花出去的钱，不是"你管不住自己"，是病在发作。你现在要做的，不是自责，而是**在自己清醒的时候，给那个会失控的自己提前装一道护栏**。钱可以慢慢挣回来，别让一次躁狂把后几年的生活都押进去。
