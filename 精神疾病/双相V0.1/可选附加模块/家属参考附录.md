# 家属参考附录

> 写给陪伴双相情感障碍患者的家人、伴侣、父母、成年子女、朋友。【临床共识】你的角色是**支持者，不是医生**。你不需要治好他，但你可以成为他最稳的那块地板——尤其在他躁狂期冲动挥霍、抑郁期瘫倒、混合期危险的时候。照顾好你自己，才能真正陪他走下去——这不是自私，是长期主义。

> 【重要声明】双相不是"脾气差""一阵一阵矫情"，是有生物学基础、需要长期管理的疾病。患者本人不是"在闹情绪"，家属也不是"活该受罪"。本章所有医学建议不替代面诊，用药与治疗方案请遵精神科医生医嘱；本文不提供任何调药方案。

## 一、先定位：你到底是谁

- 你**不是**治疗师：不要自己诊断、不要替他调药、不要评判"这个医生靠不靠谱"。
- 你**是**：稳定的陪伴者、就医协助者、作息节律的共同维持者、**财务与安全的观察者**、早期复发信号的"第二双眼睛"。
- 一条黄金原则：**"我在"比"我懂"更重要；"守住节律和钱"比"劝他想开点"更重要。**

> 双相和单纯抑郁最不一样的地方：你不只要防他"垮下去"，还要在他"飘上去"的时候**把他拉回来**。很多家属只在他低落时着急，没意识到他"突然特别好、特别能花钱、特别能熬夜"才是更要警惕的信号。

## 二、早期"间断"：怎么认出他要复发了

【临床共识】双相复发前，往往有一两周的**早期信号**，家属是最容易先看到的人。每天花两分钟观察，比复发了再抢救便宜得多。

### 要"飘上去"（转躁/轻躁狂）的信号

- **睡眠需要突然变少**：连着几天只睡三四个小时，却不觉得困、还精力旺盛（注意：不是"失眠痛苦"，是"不想睡、不困"）；
- **话变多、语速变快**：跟人抢话、电话打个没完、家里安静不下来；
- **特别易激惹**：一点小事就炸、跟家人同事起冲突、路怒；
- **花钱开始大手大脚**：突然网购、打赏、投资、买大件、给人转账；
- **自我评价膨胀**：觉得自己特别厉害、要干大事、辞了职要创业；
- **社交突然密集**：半夜约人、连续通宵聚会；
- **注意力随境转移**：一件事没做完就跳去下一件。

### 要"掉下去"（转抑郁）的信号

- 话变少、不想出门、对以前喜欢的事没兴趣；
- 睡觉变多或严重失眠、食欲明显变化；
- 说"活着没意思""你们以后怎么办""我是累赘"；
- 把珍贵的东西送人、开始清理手机/电脑、突然异常平静。

### 混合状态信号（最危险）

- 又烦躁又低落：坐立不安、想砸东西，同时说活着没意思——**这种状态自杀风险最高，不要当成"他就是脾气坏"。**

> 发现上面任何一组信号连续出现几天，**温柔但坚定地提醒他联系医生提前复诊**，不要等"它自己过去"。

## 三、"该说 / 不该说"对照表（15 对，直接可用）

| 别再说 | 试着这样说 | 为什么 |
|---|---|---|
| "你就是脾气差 / 性格有问题" | "医生说这是大脑管情绪的地方出了问题，跟脾气是两码事。" | 把疾病当性格缺陷，是二次伤害。 |
| "你上次不是挺好的吗，怎么又这样" | "双相本来就是会波动的，跟感冒好了也会再感冒一样。" | 不知道它是波动病程。 |
| "你兴奋的时候不是挺正常吗，装的吧" | "你那几天睡得少还特别精神，其实是要复发的信号，我们去看看？" | 轻躁狂期看起来像"打了鸡血"，不是真的好。 |
| "想开点 / 你就是想太多" | "我看到你最近很难受，这不是你的错。" | 否定感受只会让他闭嘴。 |
| "别吃那些药了，是药三分毒" | "药的副作用可以跟医生说，咱们一起复诊问问。" | 劝自行停药可能诱发复发，代价很大。 |
| "你怎么又乱花钱了！"（躁狂高峰期） | 先拦住大额支出，不当场吵架；等他稳一点再说。 | 高峰期争论没用，先把出血点堵住。 |
| "为了这个家你也要振作" | "你对我很重要，但你不需要为了我硬撑；我们一起面对。" | 道德绑架加重内疚。 |
| "你就是懒 / 不上进" | "我注意到你最近起不来、睡不好，是身体/情绪出问题了，我们去看看？" | 疾病导致的退缩不是懒惰。 |
| "你看谁家谁谁不是也好好的" | "痛苦没法比，你现在是真的在受苦。" | 比较不会减轻痛苦。 |
| "出去玩玩 / 旅旅游就好了" | "等你状态稳一点再考虑出门；现在先把觉睡好最重要。" | 强迫出游/熬夜旅行是转躁诱因。 |
| "我都为你做了这么多了，你怎么还这样" | "我有点累，但我没怪你；我们一起想办法。" | 付出感说出口就变成债务。 |
| "你倒是说话啊 / 整天闷着算什么" | "不想说话也没关系，我坐这里陪你。" | 允许沉默。 |
| "你这样让我很崩溃 / 我快被你逼疯了" | "我今天状态也不太好，先自己待一会儿，晚一点再陪你。" | 家属情绪要表达，但别倒在患者身上。 |
| "一切都会好起来的" | "我不知道什么时候会完全好，但我会一直在。" | 虚假乐观不如真实陪伴。 |
| "你要是不想活了跟我说说"（敷衍） | "你说出来，我不会替你保密，我会帮你找医生/打12356，因为你的安全比保密重要。" | 危机时不能答应保密。 |

## 四、实际可以做的 10 件事

1. **陪诊**：第一次就诊、每次复诊陪他去，帮忙记医嘱——发作期（不管躁狂还是抑郁）他的注意力都差，回家就忘。
2. **提醒服药，但不监督对立**："该吃药了哦"是温柔提醒；不要翻包检查、不要质问"你今天吃没吃"。发现他**自己偷偷停药**，温柔而坚定地问原因、联系医生。
3. **守住睡眠（这是双相家属最关键的任务）**：周末也别让他熬夜、别纵容他通宵打游戏/刷手机；晚上固定时间一起关灯睡觉。**睡眠一乱，情绪就乱。**
   - 【个人体验】很多家属后来都说，自己做过最有用的事，不是劝、不是讲大道理，而是**每晚到点一起把灯关了、把手机放到客厅**——这件不起眼的小事，拦住了不知道多少次转躁。
4. **守住钱**：见第五节。
5. **观察并记录**（见第六节），复诊时给医生看。
6. **配合治疗**：医生建议住院就住院，建议心理治疗就帮他预约；**不要替他拒绝治疗**，也不要因为"面子"拒绝住院。
7. **帮他筛信息**：把网上那些"七天治愈""断药断食治愈双相"的内容挡掉，把靠谱资料（12356、正规医院）放他手边。
8. **保护隐私**：不跟亲戚邻居到处说；不发朋友圈；病历、药盒收好。
9. **不做重大决定的同盟**：他躁狂期要辞职、要离婚、要借大钱、要加盟——你有责任说"这件事我们等三天再决定"。
10. **庆祝小稳定**：这周他连续七天睡够了、这个月没乱花钱——具体地、真诚地肯定。

【研究结论】大量临床研究显示，把家属纳入治疗、教家属识别复发早期信号、改善家庭沟通的**家庭焦点治疗（FFT）**和家庭干预，能显著降低双相患者的复发率、延长发作间隔。也就是说：你这个"家属"做得好，本身就是治疗的一部分，不只是"陪着"。

## 五、财务安全：家属的另一项核心任务

【临床共识】躁狂期的挥霍、盲目投资、借贷、担保，是双相家属最常面对的现实危机。你能做的：

- **在他状态好时，和他一起**把日常信用卡额度调低、注销多余的网贷账户、卸载交易类 App、关掉支付免密；
- **约定一个"刹车规则"**：他要花超过你们约定金额（比如两三千），你有权问一句"你最近睡眠怎么样？这个决定等两天吗？"
- **大额资产共管**：反复挥霍过的家庭，大额存款放共管账户、大额卡由你保管，不是不信任他，是保护那个会失控的他；
- **他躁狂期突然要借钱、担保、投资、加盟**：先稳住他（"咱们明天再去银行"），当晚就联系医生；
- **已经欠了网贷/高利贷**：保留证据，拨 110，法律援助拨 12348；不要怕丢人，这是病的症状，不是人品问题。

## 六、家属观察记录本（每天两分钟，复诊给医生看）

| 观察项 | 今天的情况 |
|---|---|
| 睡眠 | 昨晚几点睡、几点醒、睡了几小时、白天补不补觉 |
| 情绪 | 平稳 / 低落 / 亢奋 / 易激惹 / 混合（烦躁+绝望） |
| 言语 | 话变多还是变少？有没有说"活着没意思""你们以后怎么办"？ |
| 行为 | 有没有开始大手大脚花钱、疯狂网购/投资、辞掉重要事、跟人决裂？ |
| 节律 | 吃饭、出门、作息有没有被打乱？ |
| 药物反应 | 有没有明显嗜睡、手抖、恶心、"好像变兴奋了/睡得很少却不困"？ |

> 【临床共识】**"睡得少却精神特别好、话多、花钱冲动"是转躁线索；"突然异常平静、把东西送人"是抑郁危机线索。** 这两类都要第一时间告诉医生。

## 七、危机时家属怎么办（只写安全，不写方法）

> 如果你发现他有以下情况：表达强烈的"不想活了/活着没意思"、安排后事、告别、把珍贵东西送人、突然异常平静、已经在伤害自己——**这是危机信号**。混合状态（又烦躁又有想死念头）风险尤其高。

- **直接问**："你是不是有过不想活的念头？"——**直接问不会"提醒"他自杀，反而让他感到被看见**。问完不要慌、不要骂。
- **不离人**：在确保你自身安全的前提下，不要让他独处。把危险物品从他身边移开（不要自己展开处理方法，交给专业人员）。
- **立刻求助**：
  - **12356**（全国统一心理援助热线，24 小时免费，国家卫健委设置，2025 年起全国统一使用；核实日期 2026-10-20，号码可能调整，以当地官方公布为准）
  - **120**（医疗急救）/ **110**（公安，现场有人身威胁或他拒不自保时）
  - 直接送**有精神科急诊的三甲医院 / 精神卫生中心**。
- **住院不是抛弃他**：急性期住院是最安全的选择，配合医生；不要因为"面子"拒绝住院。
- **首次剧烈胸痛、意识异常、抽搐等**：不要当成情绪问题，先拨 120 排除躯体急症。
- **事后**：他情绪平复后，不要指责"你差点把我吓死"，而是说"我当时很怕失去你，我们以后遇到这种情况怎么办"。

## 八、不同对象的特别提示

- **青少年患者家属**：不要把孩子的情绪剧烈波动当成"青春期叛逆"。连续几天极度亢奋、睡得极少还不困、挥霍、毁物，或长期低落、提到活着没意思、手臂上有划痕——**早就医，不要等**。
- **育龄女性患者家属**：如果她在吃丙戊酸/卡马西平，提醒她**必须可靠避孕**；计划怀孕要提前几个月和医生谈。不要在她怀孕后劝她"为了孩子自己把药停了"。
- **伴侣家属**：躁狂期他可能特别易怒、特别爱花钱/社交/对人冷淡——那不是针对你；抑郁期他可能不想亲热不想说话——那也不是没感情。**不要在他发作高峰期谈分手离婚。**
- **老年患者家属**：晚年新出现的情绪波动，先陪他查甲状腺、脑血管等躯体问题，不要直接当"老了脾气怪"。

## 九、家属自己也要被照顾

- **你不是他的医生，也不是他的药**。把全部生活押在他身上，两个人都会垮。
- **给自己喘息**：和其他家属轮班、每周留半天给自己的事。这不是抛弃，是让你能撑得久。
- **你可以有自己的情绪**：委屈、疲惫、生气都正常；找你自己的朋友、心理咨询、家属支持团体（很多精神卫生中心有家属互助小组）。
- **不要自责**："我是不是哪里做得不好"——双相有生物学和遗传基础，不是你造成的。
- **处理你自己的病耻感**：你愿不愿意告诉别人，同样是你自己权衡的事，不必勉强。

## 十、家属一周自检（每周日花2分钟勾选）

- [ ] 这周我有没有说过"想开点/你就是脾气差/别吃药了"？（说过没关系，下周注意）
- [ ] 这周我有没有留意他的睡眠？有没有连续几天睡得少还精神好？
- [ ] 这周我有没有陪他按时复诊/取药？
- [ ] 这周有没有拦住他的大额冲动支出？
- [ ] 这周我有没有把自己的情绪倒在他身上？（有的话，下周找朋友/咨询师）
- [ ] 这周我有没有留半天给自己喘息？
- [ ] 我和他的紧急联系电话是否还存在手机里？
