# 5. 快速循环

> 快速循环不是一种"永久人格标签"，而是一个**病程标注**：一年内出现 **≥ 4 次**情感发作（躁狂、轻躁狂、抑郁或混合），每次之间有明确的缓解期，或直接转向另一相。它让患者像坐过山车一样在高低之间频繁切换，更容易被误诊、更容易慢性化。好消息是：它**可以随治疗改变**，不是一辈子就这样了。

## 5.1 什么是快速循环

【临床共识】快速循环（rapid cycling）的诊断标准：

> **在过去 12 个月内，出现至少 4 次情感发作**——可以是躁狂、轻躁狂、抑郁或混合发作。每次发作需满足相应临床相的时长标准，且发作之间有**至少两个月的部分/完全缓解**，或从一相直接转向另一相。

【个人体验】经历过的人这样描述：

> "我这一年像被按了循环键——刚从低落里爬出来没两周，又开始兴奋少睡；兴奋没几天，又突然跌到谷底。我根本不知道下周的我会是什么样。"
> "别人一年最多情绪波动几次，我一个月就能高低来回一次。我不敢做任何长期计划，因为计划永远赶不上我转相。"

## 5.2 它"快"到什么程度

【临床共识】快速循环是一个连续谱：

| 模式 | 频率 | 通俗描述 |
|---|---|---|
| 典型发作 | 一年 1～3 次 | 相对稳定，高低交替间隔较长 |
| **快速循环** | **一年 ≥ 4 次** | 频繁切换，间歇短 |
| 超快速循环 | 一个月内多次 | 几乎每月都在转相 |
| 超超快速（每日循环） | 一天内高低切换 | 一天里在几小时内波动，接近混合状态 |

【争议观点】后两种极快的模式，在临床上常与"混合特征"重叠——它们是不是独立的快速循环，还是严重混合状态，医生之间仍有讨论。但无论如何，频繁转相都提示需要更积极的治疗。

## 5.3 哪些因素和快速循环有关

【研究结论】临床上观察到，下列因素常与快速循环模式相关：

| 相关因素 | 说明 |
|---|---|
| **抗抑郁药单药治疗** | 在双相障碍中，长期单用抗抑郁药（无心境稳定剂保护）可能诱发或加重转躁、快速循环——这是最需要警惕的一点 |
| **睡眠紊乱/作息不规律** | 熬夜、倒班、时差、作息颠倒，是转相的常见扳机 |
| **甲状腺功能异常** | 尤其是亚临床甲状腺功能减退，与快速循环相关；医生常会查甲功 |
| **物质使用** | 酒精、兴奋剂（如咖啡因过量、可卡因、冰毒等）可诱发转相 |
| **女性与产后** | 部分研究提示女性、产后阶段更易出现快速循环模式 |
| **未规范治疗/自行停药** | 不规律用药、频繁漏服，让情绪失去稳定锚 |

【临床共识】这正是为什么治疗双相时，医生会**坚持让你规律服心境稳定剂、规律作息、定期复查甲功**——这些都是在帮你"打破循环"。

## 5.4 快速循环自查/记录模板（可打印）

> 用法：建议用情绪日记，记录每次情绪发作的起止日期和类型。**一年下来数一数：≥ 4 次，就要在就诊时主动告诉医生。**

| 序号 | 起止日期 | 持续天数 | 发作类型（躁狂/轻躁狂/抑郁/混合） | 当时可能的诱因（熬夜？压力？用药变动？） |
|---|---|---|---|---|
| 1 | __月__日 – __月__日 | ___天 | | |
| 2 | __月__日 – __月__日 | ___天 | | |
| 3 | __月__日 – __月__日 | | | |
| 4 | __月__日 – __月__日 | | | |

【个人体验】把这些记录带复诊，比你口头描述"我一年到头都在反复"有用得多——医生一眼就能看出你的循环频率和规律。

## 5.5 关键认知：它是"标注"，不是"判决"

【临床共识】请记住这一点，非常重要：

> **快速循环是对"当前病程模式"的描述，不是一个固定不变的人格标签。**

- 它**可以随治疗改善**——规范使用心境稳定剂、规律作息、调整用药后，很多患者的循环频率会明显下降；
- 它**会波动**——这一年循环快，不代表下一年还会这样；
- 它**提示治疗需要调整**——而不是"这个病没救了"。

【个人体验】康复者常说："我曾经一年高低来回五六次，觉得自己这辈子就这样了。后来规律吃药、固定作息、复查甲功，慢慢一年只发作一两次。循环是可以被打破的。"

## 5.6 出现快速循环模式，该怎么办

【临床共识】

1. **记录情绪日记**：把每次转相的时间、类型、可能诱因记下来，复诊时给医生看。
2. **规律作息是第一抓手**：固定起床时间、避免熬夜、减少倒班/时差——睡眠节律稳不住，循环很难停。
3. **不要自行加药/停药**：快速循环的用药调整必须由医生判断；尤其不要因为"低落期"就自己加抗抑郁药，或因为"兴奋期"就自己停心境稳定剂。
4. **复查躯体指标**：按医嘱复查甲功、肝肾功能、血药浓度等。
5. **警惕物质**：减少酒精、咖啡因过量，避免兴奋剂。

> 安全提示：若在快速循环中出现任何自伤/自杀念头、冲动伤人、严重挥霍或彻夜不眠，请立即联系家属就医或拨打 12356 心理援助热线（24 小时免费；核实日期 2026-10-20，号码可能调整，以当地官方公布为准）；紧急情况拨 120 / 110。
