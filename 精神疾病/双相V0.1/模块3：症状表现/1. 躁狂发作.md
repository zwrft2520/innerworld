# 1. 躁狂发作

> 躁狂发作不是"心情特别好"，而是一种**情绪、思维、精力同时被拧到最大档**的病理性高涨：你可能连续几天几夜不睡却毫无困意，话多到停不下来，觉得自己无所不能，然后做出冲动消费、盲目投资、高危性行为、鲁莽驾驶等事后追悔莫及的事。本页帮你把"那种不对劲的高"翻译清楚——**它不是天赋降临，是病的症状；对照不用于自我确诊，最终由精神科医生面诊判断。**

## 1.1 什么是躁狂发作

【临床共识】躁狂发作（manic episode）是双相 I 型障碍的核心事件：在**至少连续 1 周**的几乎每一天、大部分时间里，出现明显异常的**心境高涨、扩张或易激惹**，同时伴有**活动增多或精力增加**，症状足以严重损害社会功能、需要住院，或伴有精神病性症状（如幻觉、妄想）。

【个人体验】经历过的人这样描述它：

> "那段时间我一天只睡两三个小时，白天还精神得像充了电。我觉得自己突然开了窍，要辞职创业、要把所有积蓄投进去、还要同时追两个人。"
> "我不觉得我有病，我觉得我'终于活过来了'。是我妈说我三天没合眼、说话别人根本插不上嘴，硬把我拉去医院的。"
> "我全程在发火——谁劝我，我跟谁吵，觉得全世界都在阻拦我做一件大事。"

## 1.2 诊断标准里的"三高"与七个伴随症状

【临床共识】诊断躁狂发作，核心是**心境异常**加上**活动/精力异常**，并在下列伴随症状中出现 ≥ 3 项（若心境仅表现为易激惹，则需 ≥ 4 项）：

| 类别 | 具体症状 |
|---|---|
| **自我评价过高 / 夸大** | 从"我今天状态真好"到坚信自己有特殊天赋、身份、超能力，甚至妄想级别 |
| **睡眠需要减少** | **注意：是"睡得很少却不觉得困"，不是"想睡睡不着"**——连续只睡 2～3 小时仍精力旺盛 |
| **话多** | 说话又快又响、别人插不上嘴、强迫性地说个不停，感觉"不说不行" |
| **思维奔逸** | 脑子里念头一个接一个飞快跳转，主观体验为"思维赛跑""舌头追不上脑子" |
| **注意力容易被吸引** | 注意力随境转移，鸡毛蒜皮的小事都能把思路拉走，想法像脱缰的弹珠台 |
| **目标指向活动增多** | 工作、学习、社交、性活动、制定宏大计划同时爆增；坐不住 |
| **冲动/高风险行为** | 挥霍、盲目投资、鲁莽驾驶、不安全性行为、愚蠢的商业决策——事后常追悔 |

## 1.3 按"情绪 / 思维 / 躯体 / 行为"四个角度拆解

### ① 情绪症状

【个人体验】两种完全不同的"高"：

- **高涨/扩张型**：莫名的欣快、话痨、对谁都热情、觉得世界无比美好，"看人都顺眼"；
- **易激惹型**：一点就着、极度不耐烦、挑剔、和人吵架甚至动手——这一型在临床上非常常见，尤其在男性患者中。

【临床共识】情绪可以在这两极之间快速摆动：上一秒还春风得意，下一秒因为一件小事暴怒，再下一秒又跌到委屈想哭——这就接近后面要讲的"混合特征"。

### ② 思维症状

- **夸大**：从轻度的"我能力特别强"到妄想级别的"我是天选之人""我认识大人物""我有发明能改变世界"；
- **思维奔逸**：说话从一个话题跳到另一个话题，旁人听起来"前言不搭后语"，但患者自己觉得逻辑飞快、处处是灵感；
- **注意随境转移**：谈话中突然被窗外的车声、手机的一条通知带走思路。

【临床共识】当夸大达到坚信不疑、与现实完全脱节的程度（如坚信自己腰缠万贯、有特殊使命），就属于**精神病性症状**——这往往提示发作更重、需要尽快医疗介入。

### ③ 躯体症状

- **睡眠需要显著减少**（关键鉴别点，见下）；
- 不知疲倦，连续活动一整天仍觉得"还能再战五百回合"；
- 坐立不安、来回踱步、手抖、心跳加快；
- 食欲下降（光顾着兴奋，忘了吃）；
- 有的患者几天几夜不睡、不喝不吃，身体快速透支。

### ④ 行为症状

| 行为类别 | 典型表现 | 事后代价 |
|---|---|---|
| **挥霍** | 疯狂购物、买根本用不上的东西、打赏主播、大额转账 | 负债、信用卡爆掉 |
| **盲目投资/创业** | 辞职、押上全部身家做"大项目"、频繁借钱 | 钱财尽失、家庭矛盾 |
| **高危性行为** | 一夜情、不加保护、与陌生人发生关系 | 性传播感染、意外怀孕、关系破裂 |
| **鲁莽驾驶** | 超速、飙车、酒驾、危险并线 | 交通事故、法律后果 |
| **激越/冲动伤人** | 吵架、摔东西、与人肢体冲突 | 肇事肇祸、报警、受伤 |
| **社交/工作爆炸式增多** | 通宵聚会、同时开几个项目、疯狂发朋友圈 | 体力透支、人际关系崩盘 |

## 1.4 关键鉴别：睡眠需要减少 ≠ 失眠

【临床共识】这是家属和患者本人最容易误判的一点，请务必记住：

| 维度 | 躁狂的"睡眠需要减少" | 普通失眠/焦虑的"睡不着" |
|---|---|---|
| 主观感受 | **睡得少，但不困、不难受，甚至觉得不需要睡** | 想睡但睡不着，痛苦、疲惫 |
| 白天状态 | 精力旺盛、坐不住、话多 | 疲惫、头昏、注意力差 |
| 驱动力 | "我有太多事要做，舍不得睡" | "我想睡，但脑子停不下来" |
| 常见场景 | 连续几天只睡 2～3 小时仍通宵干活/聚会 | 入睡困难、早醒，白天补觉 |

【个人体验】家属常说的一句话是："他/她不是失眠，是根本不睡，还越不睡越精神。"——当你身边有人出现这种模式，而不是普通的辗转反侧，就要高度警惕躁狂可能。

## 1.5 严重程度：什么时候算"躁狂"而不是"状态好"

【临床共识】同样是"话多、兴奋、效率高"，医学上怎么区分？

| 维度 | 一般的"状态好" | 病理性躁狂 |
|---|---|---|
| 持续时间 | 几小时到一两天，自然回落 | **≥ 1 周**几乎天天如此 |
| 功能影响 | 提高效率、开心 | **明显损害**工作、人际、财务，或需住院 |
| 判断能力 | 知道自己兴奋，能收敛 | 缺乏自知力，不觉得有问题 |
| 冲动行为 | 有分寸 | 出现挥霍、高危行为、夸张计划 |
| 精神病性症状 | 无 | 可出现夸大妄想、幻听等 |
| 身边人反应 | "你今天气色不错" | "你不对劲，我们很担心" |

## 1.6 躁狂发作自查清单（可打印）

> 用法：过去至少一周，几乎每天大部分时间里，下列条目符合打勾。**勾中越多、且已经影响生活/财务/关系，请尽快到精神科就诊；若出现冲动伤人、自伤、严重挥霍或彻夜不眠，请联系家属立即就医。**

- [ ] 心情异常高涨、特别开心，或者特别容易发火，持续 ≥ 1 周
- [ ] 一天只睡很少（如 2～3 小时）却不觉得困，白天依然精力旺盛
- [ ] 话多到别人插不上嘴，或者说话又快又大声、停不下来
- [ ] 脑子里念头飞转、一个接一个，觉得"灵感爆发"
- [ ] 自我评价异常膨胀，觉得自己特别厉害、有特殊计划/使命
- [ ] 注意力特别容易被小事带跑，没法专注一件事
- [ ] 同时爆增很多活动：疯狂购物、盲目投资、频繁社交、通宵聚会
- [ ] 出现挥霍、盲目投资、高危性行为、鲁莽驾驶等冲动行为
- [ ] 家人/朋友明确说"你最近不对劲"，并为此担心
- [ ] 出现坚信不疑的夸大想法、听到不存在的声音等（**此条为紧急信号**）

## 1.7 给患者和家属的三句话

1. **"我状态好、效率高"不一定是真的好**——当它持续一周以上、伴随睡眠需要减少和冲动行为，往往是躁狂发作。
2. **本人常常不自知**，这正是这个病最麻烦的地方；家属的观察往往比患者本人更早、更准。
3. **及早干预，恢复得更快、代价更小**——不要等挥霍了一大笔钱、出了交通事故、闹到要住院才就医。

> 安全提示：若首次出现剧烈胸痛、意识不清、抽搐等躯体急症信号，请先拨打 120 排除躯体疾病，不要把身体问题误当情绪问题硬扛。
