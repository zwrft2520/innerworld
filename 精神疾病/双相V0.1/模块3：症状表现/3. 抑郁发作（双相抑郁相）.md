# 3. 抑郁发作（双相抑郁相）

> 双相障碍的患者，一生中**大部分时间其实是在抑郁相里**——情绪低落、兴趣丧失、精力下降、思维迟缓、自责、睡不好或睡不醒、吃不下或暴食、注意力差、出现消极念头。它的"样子"和单相抑郁症非常像，但**治疗方向常常不一样**：误把它当单相抑郁单用抗抑郁药，可能诱发转躁或快速循环。本页帮你识别双相抑郁相，并理解它和单相抑郁的细微差别。

## 3.1 双相抑郁相的核心症状

【临床共识】双相抑郁相的症状与重性抑郁发作基本一致：在**至少连续 2 周**里，几乎每天大部分时间出现下列核心症状，且造成痛苦或功能损害：

| 类别 | 具体表现 |
|---|---|
| **情绪** | 情绪低落、悲伤、空虚、麻木；易激惹（尤其男性、青少年） |
| **兴趣/快感** | 兴趣减退、快感缺失——以前喜欢的事提不起劲 |
| **精力** | 精力下降、持续疲劳、"连刷牙都要动员半天" |
| **思维** | 思维迟缓、注意力下降、犹豫不决、自我评价过低、自责自罪、无价值感 |
| **躯体** | 睡眠改变（失眠或嗜睡）、食欲/体重改变（下降或上升） |
| **行为** | 行动迟缓或烦躁不安；社交退缩；出现消极/自伤念头 |

【个人体验】双相患者描述抑郁相的几句话：

> "不是普通的心情不好，是那种从骨头里透出来的沉——像穿了件湿透的棉袄，脱不掉。"
> "我理智上知道以前喜欢打游戏，但现在手柄拿到手里，'哦'一声就放下了。"
> "我一天能睡 12 个小时还是累，醒着也只想躺着，连手机都不想刷。"

## 3.2 双相抑郁相 vs 单相抑郁：治疗方向为什么不同

【临床共识】这是本页最重要的一点：**双相抑郁相在表面上和单相抑郁几乎无法区分**，但治疗原则差别很大。

| 维度 | 单相抑郁 | 双相抑郁相 |
|---|---|---|
| 既往史 | 从无躁狂/轻躁狂发作 | **既往有过躁狂或轻躁狂发作** |
| 治疗主线 | 抗抑郁药常为主力 | **以心境稳定剂/第二代抗精神病药为基础**，抗抑郁药需谨慎 |
| 单用抗抑郁药 | 常规选择 | **可能诱发转躁、轻躁狂、快速循环**——须由医生评估 |
| 发作模式 | 相对稳定的单次/复次抑郁 | **高低交替**，可在抑郁后转为躁狂/轻躁狂 |

【临床共识】**这正是为什么医生一定要反复追问你"以前有没有过特别兴奋、特别能睡少、特别自信的阶段"**——如果有，你就是双相抑郁相，而不是单相抑郁。这个区分直接决定用药方案。

## 3.3 哪些"线索"提示这可能是双相抑郁，而不是单相

【研究结论】下面这些特征，在临床上提示抑郁背后可能藏着双相，值得就诊时主动告诉医生：

| 线索 | 具体表现 |
|---|---|
| **嗜睡 vs 失眠** | 抑郁时**过度睡眠**（一天睡 10～14 小时仍累），而不是典型的早醒、入睡困难 |
| **暴食 vs 食欲下降** | 抑郁时**食欲亢进、体重增加**，尤其偏好碳水化合物 |
| **运动性迟滞** | 动作明显变慢、说话变慢、整个人"卡住"，而不是焦虑性烦躁 |
| **情绪反应性** | 遇到好事时情绪能暂时好转（而单相抑郁常持续低沉） |
| **症状突发突止** | 抑郁来得突然、缓解也快，发作之间有相对"正常"的间歇 |
| **季节模式** | 秋冬抑郁、春季/夏季转为高涨，呈季节性交替 |
| **发作年龄早** | 青少年或 20 岁出头就出现第一次抑郁发作 |
| **多次抑郁发作** | 反复多次抑郁，且对抗抑郁药反应"特别好"或"特别快转躁" |
| **家族史** | 一级亲属有双相障碍患者 |
| **不典型特征** | 灌铅样肢体沉重、被人压制感、对拒绝过度敏感 |

【争议观点】这些线索只是"提示"，不是诊断标准——最终分型必须由精神科医生结合完整病史判断。但你主动提供这些信息，能大大减少误诊。

## 3.4 双相抑郁相自查清单（可打印）

> 用法：最近至少 2 周，几乎每天大部分时间符合打勾。**若出现具体的自伤/自杀计划或觉得自己控制不住，请立即告诉身边人并拨打 12356 心理援助热线，或前往医院急诊。**

- [ ] 情绪低落、空虚、麻木，几乎每天如此
- [ ] 对以前喜欢的事提不起兴趣，感受不到快乐
- [ ] 精力明显下降，做小事都觉得吃力
- [ ] 睡眠改变：失眠、早醒，**或**睡得过多仍疲惫
- [ ] 食欲/体重改变：明显下降，**或**暴食、体重上升
- [ ] 思维变慢、注意力下降、做决定困难
- [ ] 自我评价低、自责、觉得自己没用/没希望
- [ ] 行动明显变慢，或坐立不安
- [ ] 反复想到死、自伤，或出现具体计划（**此条为紧急信号**）
- [ ] 既往有过"特别兴奋、少睡、话多、效率爆表"的阶段（**此条提示需告知医生**）

## 3.5 一个必须单独说的红灯：自伤/自杀念头

【个人体验】在抑郁相最低落的时候，脑子里可能冒出"如果我不在了，大家都轻松""活着没什么意思"这种念头。这是**疾病本身的症状**，不是你这个人"坏"或"对不起谁"。

【临床共识】**一旦你出现具体的自伤或自杀计划、或者觉得自己可能控制不住——请立刻行动：**

- 告诉身边一个可信任的人，不要独自待着；
- 拨打全国心理援助热线 **12356**（2025 年起由国家卫生健康委推出的统一心理援助热线，24 小时免费；核实日期 2026-10-20，号码可能调整，以当地官方公布为准）；
- 情况紧急时直接拨打 **120** 或前往最近医院急诊；公安求助可拨 **110**。

详细的危机识别与急救步骤，见本资料库模块 8"危机识别与求助"。

## 3.6 给患者的三句话

1. **抑郁相不是你的错，也不是"想不开"**——它是双相障碍的一个临床相，是病，需要规范治疗。
2. **一定要告诉医生你有没有过"特别兴奋、少睡"的阶段**——这决定了你是单相还是双相，用药完全不同。
3. **不要因为"现在是低落期"就自行停药或加药**——情绪低落时最容易想"药没用"，但心境稳定剂的作用恰恰是预防转躁，需遵医嘱规律服用。

> 安全提示：首次出现剧烈胸痛、意识异常等躯体急症，请先拨打 120 排除躯体疾病，不要把身体问题误当情绪问题硬扛。
