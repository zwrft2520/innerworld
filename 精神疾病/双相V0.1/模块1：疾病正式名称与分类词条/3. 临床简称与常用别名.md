# 3. 临床简称与常用别名

> 在医院、科普文章、网络论坛和家人嘴里，这个病会被说成各种各样的名字——"双相""躁郁症""躁狂抑郁症"" bipolar……"。本页把**正式名 ↔ 俗称/旧称/英文缩写**一一对应起来，帮你听懂别人在说什么，也避免把"情绪有点起伏"误当成一个诊断。

## 3.1 正式名 ↔ 临床常用简称/别名对照表

| 正式名称（ICD-11 / 临床规范） | 临床简称 / 英文缩写 | 常见俗称 / 旧称 | 备注 |
|---|---|---|---|
| **双相 I 型障碍** | BP-I、BD-I | 躁郁症（传统说法多涵盖 I 型） | 有过完整躁狂发作 |
| **双相 II 型障碍** | BP-II、BD-II | 常被误当"抑郁症" | 轻躁狂 + 抑郁，从无躁狂 |
| **环性心境障碍** | Cyclo、Cyclothymia | "情绪化""脾气起伏大" | 长期轻性波动，易被当性格 |
| **双相及相关障碍（总称）** | **BD**（Bipolar Disorder）、**BPAD**（Bipolar Affective Disorder） | **双相、双相障碍、双相情感障碍** | 国内病历最常用"双相情感障碍" |
| 双相障碍（泛称） | Manic-depressive illness | **躁狂抑郁症、躁狂抑郁性精神病、躁郁症** | 旧称，欧美 20 世纪常用 |
| 发作相描述 | —— | **躁狂相、抑郁相、混合相** | 指同一次病程中的某一阶段 |

## 3.2 几个特别容易误解的名字

### ① "双相""双相障碍""双相情感障碍"——哪个才对？

【临床共识】这三个指的是同一个东西，只是完整度不同：

- **双相**：最口语的简称，朋友间、病友群里这么说没问题；
- **双相障碍**：书面简称，病历、科普标题常用；
- **双相情感障碍**：国内医院病历上**最完整、最正式**的写法（对应 ICD-11 的"双相及相关障碍"这一大类）。

听到哪个都不必纠结——它们说的都是"情绪会在高涨和低落两极之间病理性摆动"这组病。

### ② "躁郁症""躁狂抑郁症"——老一辈病历上的旧名字

这是**最有历史感的一个俗称**。在 Kraepelin 时代（19 世纪末）一直到 20 世纪中后期，这个病在欧美和我国都叫"躁狂抑郁症（manic-depressive illness）"，再往后又被加上"精神病"三个字叫"躁狂抑郁性精神病"。

【临床共识】这个名字今天**已经不再作为正式诊断名使用**，但你会在以下地方反复听到：父母辈的老病历、老医生口中、港台和民间口语里、以及英文科普（"manic depression"）。**它和今天的"双相障碍"是同一大类病**，不是两种病；只是"精神病"三个字带有强烈的病耻感，现代命名特意把它拿掉了。

【研究结论】从"躁狂抑郁性精神病"改为"双相（情感）障碍"，不是简单的文字游戏：精神医学命名研究普遍认为，去掉"精神病""疯狂"等污名化字眼，能显著降低患者的病耻感、提高就医意愿和治疗依从性——这也是近几十年各国诊断体系共同的去污名化趋势。

### ③ "双相"里的"相"是什么意思？

"相"在这里是**"阶段/相位"**的意思，不是"照相"也不是"相互"。情绪高涨的阶段叫"躁狂相"，情绪低落的阶段叫"抑郁相"，两者搅在一起叫"混合相"。所以：

- **"双相"= 有两个相（躁狂相 + 抑郁相）交替出现**；
- 不是"一个人有两个人格"——这是最常见的误解，下一篇《4. 易混淆名词区分》会专门拆。

【个人体验】我第一次在病历上看到"双相"两个字时完全不懂，回家还跟家里人吵了一架——他们一直说我这是"躁郁症""想太多"，我才反应过来，原来医生写的"双相情感障碍"，和我爸妈嘴里那个老名字，说的根本就是同一回事。

### ④ 英文都怎么写？

| 英文写法/缩写 | 全称 | 使用场合 |
|---|---|---|
| **bipolar (disorder)** | bipolar disorder | 国际通用，最常见 |
| **BD** | Bipolar Disorder | 病历、病友群缩写 |
| **BPAD** | Bipolar Affective Disorder | 英国、部分英联邦国家病历写法 |
| **manic-depressive illness/psychosis** | 躁狂抑郁症 | 历史名称、文学作品、老文献 |
| **BP-I / BP-II** | Bipolar I / II | 区分一型二型 |
| **hypomania / mania** | 轻躁狂 / 躁狂 | 描述发作相时用 |

## 3.3 不是诊断名、但常被当成病名的词

下面这些说法在日常中很常见，**它们描述的是一种状态或阶段，不是一个独立的精神科诊断**：

| 说法 | 到底是什么 | 是不是诊断 |
|---|---|---|
| **情绪高涨/情绪低落** | 正常人也有，事出有因、事过能回 | ❌ 不是诊断 |
| **"我最近有点躁"** | 可能只是兴奋、熬夜后状态飘，也可能是轻躁狂早期 | ❌ 口头说法，要医生判断 |
| **躁狂发作 / 轻躁狂发作 / 抑郁发作** | 双相病程中的"一段"，不是独立病名 | ⚠️ 是病程段落，依附于双相诊断 |
| **"周期性精神病"** | 我国 CCMD 时代用过的旧条目，约相当于快速循环型双相 | ❌ 旧称，今天归入双相谱系 |
| **"情绪病""情感病"** | 民间对心境障碍的笼统说法 | ❌ 不是规范诊断 |
| **"天才病""达芬奇综合征"** | 把双相浪漫化、天才化的网络说法 | ❌ 完全不是诊断，详见模块2《3. 误区辟谣》 |

【临床共识】"我最近情绪起伏大"和"我得了双相"是**两件事**。前者人人都有，后者是要满足"发作时长、功能损害、不能用其他原因解释"等一整套门槛的疾病状态。判断权在医生，不在这张表。

## 3.4 医院病历上可能出现的其他名字

- **"双相障碍，目前为躁狂发作/抑郁发作/混合发作，部分缓解/完全缓解"**：说明分型 + 你现在处于哪一段；
- **"双相 II 型，反复发作"**：说明有过多次发作；
- **"环性心境障碍"**：那几年起起伏伏但没大发作过；
- **"双相障碍（待分型）"**：初诊还没定型，先观察；
- **"伴快速循环特征""伴混合特征"**：见上一篇 2.3。
