# 05 常见名词释义

本文用精确、通俗的方式解释精神分裂症科普与诊疗中常见的核心术语，并附表格汇总，便于速查。

## 一、核心症状术语

### 阳性症状（Positive Symptoms）
【临床共识】指**正常心理功能中出现、不应存在的异常体验**，是精神分裂症最具辨识度的表现：
- **幻觉**：无外界刺激却感知到（如评论性幻听、命令性幻听）；
- **妄想**：坚信不疑的错误信念（如被害妄想、关系妄想、被控制感）；
- **思维紊乱**：言语破碎、联想松弛、逻辑离题。

### 阴性症状（Negative Symptoms）
【临床共识】指**正常心理功能的减弱或缺失**：情感淡漠（面无表情、少语）、意志减退（无目标、懒散）、社交退缩、快感缺失、言语贫乏。阴性症状常更隐匿、更致残，且对抗精神病药反应较差。

### 认知症状（Cognitive Symptoms）
【临床共识】注意力、工作记忆、执行功能、信息处理速度等方面的损害。可存在于前驱期并贯穿全程，是预测社会功能预后的重要因素。

### 情感症状
部分患者在精神病性症状之外伴发抑郁、焦虑或情绪波动（【研究结论】约相当比例患者共病抑郁，需关注自杀风险）。

### 紧张症（Catatonia）
【临床共识】表现为运动减少或增多、木僵、蜡样屈曲、缄默等，属需紧急识别的严重状态。

## 二、病程与状态术语

| 术语 | 精确定义 | 举例 / 说明 |
| --- | --- | --- |
| 前驱期（Prodrome） | 疾病明显发作前数月至数年，出现非特异的功能下降与轻微症状 | 成绩下滑、社交退缩、多疑、睡眠紊乱、注意力下降 |
| 发作期 / 急性期 | 典型精神病性症状（幻觉妄想等）明显、功能急剧恶化的阶段 | 出现持续评论性幻听、被害妄想，需积极药物干预 |
| 缓解期 | 经治疗症状减轻或基本消失，功能部分恢复 | 幻听消失、妄想动摇，可回归工作学习 |
| 残留状态（Residual） | 急性期后残留阴性症状或轻微阳性症状，无显著发作 | 情感淡漠、言语少但无活跃妄想 |
| 复发（Relapse） | 缓解后症状再度显著加重 | 停药后再次出现幻听妄想 |
| 慢性化 / 衰退 | 长期未愈，功能持续低下 | 长期社会隔离、生活不能自理 |

---

## 三、相关概念

- **共病（Comorbidity）**：同时患其他障碍，如物质使用障碍、抑郁、焦虑、代谢综合征（抗精神病药相关）。【临床共识】共病常见，需综合管理。
- **精神分裂症谱系（Spectrum）**：ICD-11/DSM-5 将精神分裂症与其他精神病性障碍（如分裂情感性障碍、妄想性障碍、短暂精神病性障碍）并列于同一谱系，强调症状连续分布。
- **病前适应（Premorbid adjustment）**：发病前的社会功能与发育水平，是预后参考因素之一。
- **自知力（Insight）**：患者对自身疾病的认识程度；缺乏自知力常影响服药依从性。

## 五、小结

掌握这些术语有助于准确理解疾病进程与医患沟通。重点记住三组症状（阳性/阴性/认知）与三个阶段（前驱—急性—缓解/残留），是理解精神分裂症的基础框架。
