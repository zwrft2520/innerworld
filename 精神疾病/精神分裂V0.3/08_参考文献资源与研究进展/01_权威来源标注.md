# 权威来源标注

本文说明本「精神分裂症资料库」应当引用的权威信息来源类别，并提供参考来源模板与引用规范示例，以保障内容的科学性与可追溯性。本资料仅作科普、知识学习用途，不能替代临床诊断、用药方案与面诊治疗。

> **免责声明**：本资料库仅作科普、知识学习用途，绝对不能替代临床诊断、用药方案、面诊治疗；严禁用于自行判断病情、调整药物。诊断权仅限精神科执业医师。

---

## 一、应引用的权威来源类别

### 1. 中国权威指南与技术规范
- 《中国精神分裂症防治指南》（最新版）——中华医学会精神医学分会等发布。
- 国家卫生健康委员会发布的精神卫生相关技术规范、诊疗方案。
- 各省市卫健委转发或制定的精神卫生服务规范（以当地最新为准）。

### 2. 国际疾病分类与诊断标准原文
- **ICD-11**（《国际疾病分类》第十一版，WHO 世界卫生组织）。
- **DSM-5**（《精神障碍诊断与统计手册》第五版，美国精神医学学会 APA）。
> 提示：ICD-11 与 DSM-5 为诊断分类参考，具体诊断须由精神科执业医师结合临床作出。

### 3. 权威医学期刊（研究证据来源）
- 国际期刊：*The Lancet*、*The Lancet Psychiatry*、*JAMA Psychiatry*、*American Journal of Psychiatry*、*Schizophrenia Bulletin*、*Schizophrenia Research*、*Molecular Psychiatry* 等。
- 国内期刊：《中华精神科杂志》《中国心理卫生杂志》《临床精神医学杂志》等。
- 系统综述/Meta 分析、随机对照试验（RCT）优先作为强证据来源。

### 4. 国内精神医学学会/协会资料
- 中华医学会精神医学分会（CSP）。
- 中国神经科学学会精神病学基础与临床分会等学术团体发布的专家共识、指南。
- 各省级精神医学/心理卫生相关学会资料。

### 5. 世界卫生组织（WHO）资料
- WHO 精神卫生主题页、MiNDbank 政策与立法数据库。
- WHO 发布的心理健康、精神卫生服务相关报告与工具（如 mhGAP）。
> 提示：WHO 资料为全球框架性参考，具体落地以本国/本地规定为准。

## 二、参考来源模板

建议在每条关键结论后，以如下格式标注来源：

```
【观点分级】来源名称（发布机构，年份）。如：指南第 X 章 / 文献 DOI / 网页链接。
```

### 模板示例
- 指南类：
  ```
  【临床共识】引自《中国精神分裂症防治指南》（中华医学会精神医学分会，最新版），第 X 章。
  ```
- 期刊文献类：
  ```
  【研究结论】作者. 题名[J]. 期刊名, 年份, 卷(期): 页码. DOI: xxxx
  ```
- 国际标准类：
  ```
  【临床共识】引自 ICD-11（WHO, 2019），章节编码 6A20。
  ```
- 网络权威资料类：
  ```
  【研究结论】WHO. 文件/报告名[EB/OL]. (发布年). https://...
  ```

## 三、引用规范示例

### 示例 1：临床共识标注
> 精神分裂症是一种以感知、思维、情感、行为等多维障碍为特征的重性精神障碍。【临床共识】引自《中国精神分裂症防治指南》（中华医学会精神医学分会，最新版）。

### 示例 2：研究结论标注
> 综合研究显示，精神分裂症患者总体暴力风险并不显著高于普通人群，仅在急性发作受妄想或命令性幻听支配时短暂升高。【研究结论】参见相关荟萃分析文献（*JAMA Psychiatry* 等，具体以检索到的原始文献为准）。

### 示例 3：国际标准标注
> 诊断分类参照 ICD-11 精神分裂症谱系障碍编码 6A20。【临床共识】引自 ICD-11（WHO, 2019）。

### 示例 4：争议/未定论标注
> 关于某机制是否为核心病因，目前存在学术争议。【争议观点】尚在研究，未用于常规临床。来源：相关综述（*Schizophrenia Bulletin*, 年份）。

## 四、引用注意事项

1. **可追溯**：尽量提供具体出处（指南章节、文献标题/DOI、官方链接），避免"据说""有研究表明"式模糊引用。
2. **分级标注**：每条关键结论配【临床共识】【研究结论】【争议观点】标签。
3. **时效性**：优先引用近 5 年内文献与最新版指南；旧指南注明版本年份。
4. **原文优先**：诊断标准、法律条款尽量引用原文或官方译文，不二次转述失真。
5. **去除商业倾向**：避免引用来源不明、带营销性质的材料。

---

## 五、小结

规范标注来源是资料库可信度的基石。所有撰写者应使用统一的标签与模板，确保读者能区分"已被广泛认可的结论"与"仍在探索的观点"。
