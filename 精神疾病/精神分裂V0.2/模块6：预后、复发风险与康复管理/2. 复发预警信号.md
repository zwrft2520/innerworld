# 2. 复发预警信号

> **核心结论：复发很常见，但大多数复发前数天到数周会出现"预警信号"，且这些信号是可以被本人和家属提前识别、并通过及时干预（联系医生、调整治疗）阻断的。** 关键不是"等发作了再送医院"，而是在信号刚出现时就行动。每个患者的信号都不一样，需要共同整理一份"个人预警计划"。

## 一、为什么要重视预警信号

【研究结论】【临床共识】

- 精神分裂症复发率高：研究显示**停药/不规律服药会显著推高复发**，首发后数年内累计复发比例不低。
- 多数复发并非突然发生，而是有一段**前驱期（prodrome）**：睡眠、情绪、社交、想法的细微改变先于明显幻觉妄想出现。
- **在这一窗口期及时联系医生、恢复/调整治疗，常能避免一次住院**——这是性价比最高的康复动作。

## 二、常见预警信号清单

以下信号**单看一条都不特异**（失眠也可能只是熬夜），但如果**多条同时出现、且与本人平时状态明显不同**，就值得警惕。【临床共识】

| 类别 | 常见信号 | 说明 |
|---|---|---|
| 睡眠 | 入睡困难、早醒、睡眠明显变少或紊乱 | 往往是最早、最敏感的信号之一 |
| 想法 | 多疑加重、旧的妄想/被害念头复现、对人对事过度敏感 | "又开始觉得别人针对自己" |
| 感知 | 旧的幻觉（尤其幻听）重新出现或变响变频繁 | 可能先于妄想出现 |
| 社交 | 主动回避家人朋友、不愿出门、退缩加重 | 与平时"安静"不同的退缩 |
| 情绪 | 莫名烦躁、易怒、焦虑、情绪低落、哭笑无常 | 易激惹常被误当"脾气差" |
| 注意力/规律 | 注意力涣散、生活节奏被打乱、工作学习效率骤降 | 作息、饮食、个人卫生变差 |
| 言行 | 言语变得古怪、离题，行为出现旁人觉得奇怪的举动 | 家人/同事最先察觉 |
| 治疗行为 | **自行减药、停药、藏药、说"我好了不用吃了"** | 极高复发危险信号 |
| 物质 | 重新开始喝酒、吸大麻或其他物质 | 强诱发因素 |

## 三、信号是"个人化"的

- 每个人的"复发长相"不同：有人先失眠，有人先多疑，有人先停药。【个人经验】临床上反复复发的患者，其复发前驱表现往往**高度相似**。
- 因此最重要的是：在病情**稳定的时候**，回顾过去几次发作"之前都发生了什么"，整理出**本人特有的信号和出现顺序**。
- **不要凭单一条信号就恐慌**（连续两晚失眠不等于复发），要看趋势和组合。

## 四、共同制定"复发预警计划 / 预先指示"

在病情稳定、本人愿意参与时，由患者 + 家属 + 医生共同写下一份书面计划（最好一式几份），内容包括：【临床共识】

1. **个人基线与预警信号**：我平时是什么状态？哪些是我专属的复发早期信号、按出现顺序列出；
2. **有效的应对方式**：过去哪些做法能让我稳下来（散步、规律作息、找某人聊聊、暂时减少刺激）；
3. **支持网络**：第一联系人（家属/朋友）、主治医生/门诊电话、就近精神卫生中心地址；
4. **陪同人**：谁负责在信号出现时陪诊、谁能拿到病史与用药清单；
5. **急诊安排**：去哪家医院、带什么、紧急情况下的授权（预先指示可写明本人希望如何被处置）；
6. **定期更新**：每数月或每次复诊回顾一次，调整信号清单。

> 书面计划的意义：复发时本人往往自知力差、无法决策，家属需要一份"提前说好"的依据，避免临时争执或犹豫。

## 五、家属沟通话术示例（非指责、就事论事）

预警信号出现时，沟通方式直接影响患者愿不愿配合：

- **不好的说法**（易激起对抗）：
  - "你又发病了！""你是不是又没吃药？""你怎么整天在家躺着。"
- **推荐的说法**（关注具体行为、表达关心、给出选项）：
  - "我注意到你这几天睡得很少，是不是有点不舒服？我们要不要给医生打个电话问问？"
  - "你最近好像不太想见人，我有点担心你。想不想周末一起出去走走，顺便去复诊看看？"
  - "药要是有哪里吃得不舒服，跟我说，我们一起去跟医生调，别自己停。"

原则：**描述具体观察到的变化 → 表达担心而非评判 → 提供具体帮助/选项**。不要在患者多疑、激越时当面争辩"你那是妄想"。

## 六、什么时候联系门诊、什么时候直接急诊

**尽快联系门诊/主治医生（通常可在数天内处理）**：
- 多条预警信号同时出现、持续数天；
- 睡眠明显恶化、情绪或多疑开始波动；
- 出现自行减停药的念头或行为。

**直接急诊 / 拨打 120（甚至 110）的红线**（见模块6"风险内容"）：
- 出现明确自伤、自杀念头或计划；
- 命令性幻听指使伤人/自伤；
- 严重兴奋冲动、无法控制、有伤人危险；
- 木僵、拒食拒饮、不能照顾基本需要；
- 意识混乱、高热伴肌肉僵硬（警惕恶性综合征）。

## 七、记录与隐私

- 家属可记录"日期 + 观察到的具体变化 + 当天睡眠/服药情况"，复诊时给医生看，比口头回忆更准确。
- 记录应**保护隐私**：存放得当、不外传；患者本人也应有参与感和知情权，而不是被"偷偷监控"。

> **一句话记住**：预警信号出现的窗口期，是"花小钱办大事"的时间——一通电话、一次复诊，常常就能挡住一次住院。
