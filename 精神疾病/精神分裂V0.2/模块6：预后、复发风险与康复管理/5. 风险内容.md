# 5. 风险内容

> **核心结论：风险是可以评估、可以管理的，既不能恐慌（"患者都是危险分子"是污名），也不能侥幸（"不会有事"而不做任何准备）。** 精神分裂症患者**绝大多数是暴力的受害者而非施加者**；但在特定急性状态下，自伤、伤人、拒食拒药等风险确实会升高，家属需要知道：看什么信号、怎么应对、什么时候打 120 / 110。

## 一、先纠正两个极端

- **误区一（恐慌）**：得了精神分裂症就一定会打人、会被关起来。**事实**：总体而言，精神分裂症患者的暴力风险**并不高于普通人群**；风险升高主要集中在**急性发作期伴被害妄想、命令性幻听、物质使用**等特定情形。【研究结论】
- **误区二（侥幸）**："我家人肯定不会出事""问问就行不用送医"。**事实**：风险信号被忽视、求助延迟，是悲剧最常见的原因。

> 态度：**在病情稳定期按长期康复管，在风险信号出现时果断按危机处理**。

## 二、自伤 / 自杀风险

【研究结论】精神分裂症患者的自杀风险**高于普通人群**，是早亡的重要原因之一。

**高危时期与情形**：
- 发病早期、对诊断还难以接受时；
- **住院后不久、或刚出院后**（研究提示这一阶段风险并不低）；
- 伴随**明显抑郁、绝望**；
- 出现**命令性幻听**（"让你伤害自己"）；
- 合并物质使用；
- **自知力恢复、意识到患病后果，伴强烈绝望**时。

**预警信号**：
- 表达"活着没意思""是家人的负担"；
- 突然安排后事、赠送心爱物品、写告别内容；
- 情绪从极度痛苦突然"平静下来"（可能已下定决心）；
- 收集、接触危险物品；
- 既往有自伤/自杀行为。

**评估与防范**：
- **直接、平静地问**："你现在有没有想伤害自己？有没有计划？"——询问不会诱发自杀，回避才危险。
- **危险品管理**：在高风险期，把刀具、药品、绳索、高处、阳台等危险来源收管或加装防护（在本人同意和尊严范围内）。
- **保持陪伴**，不让其独处；
- 有明确计划或准备行为时，**立即送精神科急诊 / 拨打 120**，不要"在家观察几天"。

## 三、伤人 / 冲动风险

【研究结论】【临床共识】

- 总体暴力风险不高于普通人群；**升高主要见于**：急性发作期、**被害妄想**（"先下手为强"）、**命令性幻听**、**物质（酒/毒品）使用**、既往有冲动或暴力史。

**预警信号**：
- 多疑、被害妄想加重，指向某个具体的人；
- 情绪激越、语速快、踱步、骂人、拍东西；
- 幻听内容变成指使性的；
- 饮酒/吸毒后明显失控；
- 曾有威胁性言语或砸东西行为。

**应对原则（现场）**：
1. **不正面争辩、不戳穿妄想**："你觉得有人害你，我们先一起想想办法"——当面对抗只会激怒；
2. **保持安全距离、留好出口**：站在能撤离的位置，不要堵在门口；
3. **移除可见的武器/硬物**（在确保自身安全前提下）；
4. **不要独自强行控制、不要围拢围观**；
5. **及时求助**：现实人身安全威胁下拨打 **110**；需要医疗处置时拨打 **120**；尽快联系主治医生/精神科急诊。

## 四、拒食拒药 / 木僵的躯体风险

- **紧张性木僵、缄默、拒食拒饮**：看似"安静"，实则可能迅速出现**脱水、营养不良、压疮、躯体衰竭**，是需要尽快医疗干预的急症。【临床共识】
- **拒药、藏药**：不仅导致复发，还可能在急性状态下完全失控；需耐心沟通、必要时由医生评估是否改用长效针剂或住院。
- **持续高热、严重肌肉僵硬、意识改变**：警惕**恶性综合征（NMS）**，立即急诊。

## 五、走失风险

- 自知力差、定向障碍或受幻听妄想支配时，患者可能离家走失。
- 应对：随身放置**写有联系人电话的卡片/手环**；了解其常去地点；走失后尽快报警（不必等"24 小时"的旧观念，老人/患者走失应立即求助）并告知警方病情。

## 六、危机处理原则与流程

**总原则：安全第一 > 医疗处置 > 事后复盘。**

1. **先判断安全**：现场是否有刀、有人身危险？有没有人受伤？
2. **该打哪个电话**：
   - **120**：自伤/伤人已受伤、昏迷、木僵拒食、高热僵硬、需要医疗；
   - **110**：现场有现实暴力威胁、持械、患者不听劝阻且有伤人可能、走失；
   - **精神科急诊 / 主治医生**：风险上升但尚未到立即危险，尽快评估。
3. **送医准备（提前备好一个"就医包"）**：
   - 身份证 / 医保卡、既往病历与出院小结；
   - **正在服用的药物清单**（药盒拍照也可）；
   - 近期症状与行为变化的简要记录；
   - 换洗衣物、水杯等。
4. **陪伴与沟通**：简短、平静，减少刺激和围观；不要许诺"不送医院"，也不要用吓唬的话。
5. **事后复盘**：危机平息后，和医生一起分析"为什么会这样、哪个信号被漏了"，**更新预警计划**（见 2. 复发预警信号），而不是互相指责。

## 七、家属自身的安全

- 家属不是"全天候保镖"，**不要把自己置于持续危险中**；
- 激越、暴力风险上升时，**优先撤离并求助**，不要独自硬扛；
- 长期照护压力巨大，家属自己也需要喘息、支持和（必要时）心理帮助；
- 了解本地**强制医疗/非自愿住院**的法律边界：严重危害自身或他人安全时，依法送医是保护，不是"不仁"。

## 八、风险情形与即时处置速查表

| 风险情形 | 关键信号 | 即时处置 |
|---|---|---|
| 自杀/自伤 | 绝望言语、安排后事、收集危险品、命令性幻听 | 移除危险品、陪伴、直接询问、立即急诊/120 |
| 伤人冲动 | 被害妄想指向某人、激越、持物、酒/毒后失控 | 不对抗、留出口、移武器、求助 110/120 |
| 木僵拒食 | 不语不动、拒食拒饮、日渐衰弱 | 尽快送医，防脱水衰竭 |
| 恶性综合征 | 高热、肌肉僵硬、意识改变、大汗 | **立即急诊**（危重） |
| 走失 | 离家未归、定向差 | 报警求助、提供病情、随身联系卡 |
| 药物相关急症 | 严重过敏、昏厥、严重便秘腹痛、黄疸 | 停药相关不适立即就医 |

> **一句话记住**：稳定期好好康复，信号期果断就医；现场先保安全、再打对电话、备好病史药物——风险可管理，不必恐慌，也不能侥幸。
