# 资料库备注栏

> 本页是资料库"管理员"的工作台：说明版本、使用规则、更新机制和常见易错点。普通读者可跳过；负责整理、补充内容的人请仔细看。

## 一、本资料库的定位与使用说明

【免责声明再述】

- 本资料库为**科普、知识整理**用途，**不能替代临床诊断、用药方案或面诊治疗**。
- **诊断权仅限精神科执业医师**；任何人（包括患者本人、家属、本资料库）都不能据此自我诊断。
- **严禁自行调药、停药、加量**。任何药物调整都必须由精神科医生评估。
- 患者不等于暴力者；疾病不是鬼神附身、不是单纯心理问题、不等于终身丧失劳动能力。

使用建议：

- 按模块顺序阅读，先建立正确的基本概念（模块1–4），再看治疗与康复（模块5–6），最后看社会议题与资源（模块7–8）。
- 拿不准的具体数字、法条、热线，**一律以官方最新来源为准**，不要死记本库旧表述。

## 三、未定论研究的统一标注

所有尚不成熟、未进入常规临床的研究，统一标注：

> **【尚在研究，未用于常规临床】**

适用范围举例：具体基因诊断、神经炎症靶向治疗、肠道微生物组干预、数字疗法自动诊断、候选生物标志物预测疗效等。哪怕网上文章写得很轰动，只要没有权威指南推荐用于常规诊疗，就这么标。

## 四、内容更新机制

- 指南类（如NICE CG178、中国防治指南、国家诊疗规范）**每隔数年更新一次**；本库引用时须注明版本年份，并在新版发布后核对、更新。
- 法规类（精神卫生法、民法典、医保/助残政策）可能修订或出台地方细则；引用时标注"以现行法规和当地最新政策为准"。
- 热线、机构联系方式会变动；每年至少复核一次。
- 新增内容尽量**写清发布日期和来源链接**，避免"陈旧信息被当成新结论"。

## 五、常见易错点备忘（整理时自查）

- **药物名称**：区分**通用名**（如"利培酮""奥氮平"）和**商品名**（如"维思通""再普乐"）；本库以通用名为主，避免不同商品名造成混淆。
- **编码/诊断**：ICD-11、DSM-5 的表述不同，引用时写明用的是哪一套；不要把"人格分裂/解离"与精神分裂症混为一谈。
- **法条**：不编造具体条款编号；拿不准时只写制度名称，引导读者查国家法律法规数据库。
- **热线号码**：12356、12320、120、110、12348、12345 用途不同，不要写错；北京心理危机热线等具体号码须核实后再写。
- **数据**：患病率、复发率等数字要标来源和年份，不同研究口径会有差异。
- **立场**：不渲染暴力、不神化或妖魔化药物、不鼓励替代疗法。

## 六、如何给本库补充内容（模板）

新增或修订一条内容时，按下面格式写：

```
### 条目标题
- 结论：（一句话说清）
- 证据标签：【临床共识 / 研究结论 / 初步证据 / 研究假说 / 个人经验】
- 来源：（机构 + 文件/文章名 + 版本/年份 + 链接）
- 适用范围与局限：（对谁适用、有什么前提）
- 更新日期：YYYY-MM-DD
- 整理者：（签名/代号）
```

## 七、资料整理者自查清单

发布任何一页之前，逐项打勾：

- [ ] 是否写清了免责声明，没有越界提供诊断/用药结论？
- [ ] 关键结论是否都有可追溯的权威来源？
- [ ] 是否区分了【临床共识/研究结论/初步证据/假说/个人经验】？
- [ ] 未定论研究是否标注了"尚在研究，未用于常规临床"？
- [ ] 法律、医保、助残内容是否注明"以当地最新政策为准"？
- [ ] 电话号码、机构名称是否核实过最新有效性？
- [ ] 是否避免了污名化语言和暴力渲染？
- [ ] 个人叙事是否显著标注"个人体验、不代表全部患者"？
- [ ] 是否有至少一个表格、结构清晰可读？
