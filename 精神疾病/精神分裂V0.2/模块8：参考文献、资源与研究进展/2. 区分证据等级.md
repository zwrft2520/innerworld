# 区分证据等级

> 同一句"研究显示……"背后，证据强度可能天差地别。本页教你把精神分裂症领域的常见论断按证据强度归类，避免把"前沿假说"当成"临床定论"，也避免把"强证据"当成可有可无的建议。

## 一、为什么要区分证据等级

【临床共识】循证医学的核心思想是：**不同研究设计能回答的问题不同，证据强度也不同**。治疗有没有效、病因是不是某基因、一个量表准不准，不能用同一标准评判。同一条结论，来源是高质量系统评价，还是一篇小样本个案，可信度完全不同。读者既要看到"结论是什么"，也要看"这个结论有多硬"。

## 二、常见研究设计与证据强度（从高到低）

| 证据层级 | 研究类型 | 能说明什么 / 局限 |
| --- | --- | --- |
| 最高 | **系统评价 / Meta分析** | 综合多项研究，结论最稳；但纳入研究若质量差或存在发表偏倚，结论也会被拉低 |
| 高 | **随机对照试验（RCT）** | 评估干预（药物、心理治疗）效果的金标准；但样本、入组条件、随访时长可能限制对真实患者的推广 |
| 中 | **队列研究、病例对照研究** | 研究风险因素、长期预后，能看关联；混杂因素多，通常**不能单独证明因果** |
| 较低 | **横断面调查、病例系列** | 描述现象、患病率；不能推因果 |
| 低 | **个案报告、专家意见、机制/动物实验** | 提供线索、形成假说；不能当普遍疗效或风险证据 |

- **指南推荐强度**：权威指南（如NICE CG178）会对每条建议标注"强推荐"或"弱推荐"，前者是证据充分、收益明确的做法，后者是证据有限、需个体化权衡。

## 三、GRADE 方法简介

【临床共识】国际通用的 GRADE 系统把证据质量分为**高、中、低、极低**四级，从研究设计出发，再根据以下因素升降级：

- **降级因素**：研究有缺陷、结果不一致、样本间接（人群/干预对不上）、结果不精确、存在发表偏倚。
- **升级因素**：效应量极大、存在剂量反应关系、所有混杂因素都偏向"无效"却仍显示有效。

对读者而言，关键不是背 GRADE 细节，而是养成习惯：看到结论先问一句——"这是强推荐，还是初步发现？"

## 四、把精神分裂症常见论断按证据强度归类

### （一）强证据（指南强推荐，可作为常规临床依据）

| 论断 | 证据说明 |
| --- | --- |
| **抗精神病药是急性期和预防复发的核心治疗** | 大量RCT与系统评价一致支持；停药/漏服显著升高复发率 |
| **长效针剂（LAI）能降低漏服、减少复发** | 对依从性差者优势明显，有较多证据支持 |
| **氯氮平用于难治性精神分裂症** | 对多种药物无效者仍有效的证据较充分，但需监测血常规（粒细胞缺乏风险） |
| **家庭心理社会干预能降低复发率** | 多项研究支持"低情感表达"家庭干预的复发保护作用 |
| **大麻使用是发病的明确危险因素** | 前瞻性研究一致显示大麻（尤其高纯度、青少年期使用）升高风险 |

### （二）中等 / 初步证据（有一定支持，但仍在完善）

| 论断 | 证据说明 |
| --- | --- |
| **认知行为治疗（CBTp）辅助改善症状与应对** | 对部分症状有效，但效果量和适用人群仍在讨论 |
| **规律运动改善阴性症状、情绪和代谢** | 有较多阳性研究，但标准化方案未定 |
| **抗炎、辅助抗氧化等作为辅助治疗** | 初步探索，证据尚不一致，**未成为常规** |
| **某些生物标志物辅助诊断/预测疗效** | 候选指标多，可重复性不足，尚不能用于常规临床 |

### （三）假说 / 待验证（尚在研究，未用于常规临床）

| 方向 | 现状 |
| --- | --- |
| **通过基因检测直接诊断或预测个体发病** | 大型全基因组研究找到大量风险位点，但属群体关联，**不能预测某个人会不会发病** |
| **"神经炎症"靶向治疗** | 机制假说活跃，临床试验结果不一，未常规应用 |
| **肠道微生物组与精神分裂症** | 关联研究阶段，远未到临床干预 |
| **可穿戴/手机数字工具自动诊断** | 探索中，准确性、隐私、偏差待评估 |

> 截至本资料库整理时，**没有任何单一脑扫描、基因或血液检测可以确诊精神分裂症**，也没有可靠方法预测个体病程。任何声称"抽个血/做个基因就能确诊"的说法都应高度警惕。

## 五、如何看懂"研究显示……"这类标题

【研究结论】看到媒体标题党时，用下面六问快速判断：

1. **研究问的是什么问题？** 设计是否适合这个问题（治效用RCT，病因用队列）？
2. **样本量多大、代表谁？** 几十人的小样本和几千人的研究分量完全不同。
3. **有没有独立重复？** 一项研究的惊人结果，要等其他团队重复出来才可信。
4. **是相关、预测，还是因果？** "喝咖啡的人更长寿"常常只是相关（健康人更爱喝），不等于咖啡让人长寿。
5. **效果有多大？** 统计学显著 ≠ 临床上有意义；要看效果量和置信区间。
6. **谁资助、有没有利益冲突？** 药企资助的研究要更谨慎解读。

- **预印本要特别小心**：未经同行评审就上线的预印本（如某些平台），常常结论夸张、错误率高，不能当成定论。

## 六、本资料库的标签约定

- **【临床共识】**：权威指南/学界普遍认可，可作常规依据。
- **【研究结论】**：有较一致的研究证据支持，但个体效果仍可能不同。
- **【初步证据】**：初步/前沿发现，标注样本和重复验证的局限。
- **【研究假说】**：尚未证实，**不用于个体诊断和常规治疗**。
- **【个人经验】**：个人叙述，不代表全部患者。
