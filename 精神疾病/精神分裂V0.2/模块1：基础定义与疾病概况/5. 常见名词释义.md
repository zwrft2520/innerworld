# 5. 常见名词释义

> **核心结论：**本页把阅读精神分裂症相关资料时最常遇到的术语集中解释一遍。需要强调：**这些词是用来描述现象和病程阶段的工具，不是贴在患者身上的标签**；量表、分期、副作用术语都不能代替精神科医生的完整评估。

## 5.1 核心症状术语对照表

【临床共识】下表是最常被混淆的一组词：

| 术语 | 简明释义 | 容易误解的地方 |
| --- | --- | --- |
| **阳性症状** | 相对于正常心理体验"多出来"的异常内容，如幻觉、妄想、思维紊乱、行为紊乱 | "阳性"不是"好"，只是"出现了不该有的体验" |
| **阴性症状** | 正常心理功能"减退或缺失"，如情感淡漠、意志减退、言语贫乏、社交退缩、快感缺失 | "阴性"不是"消极"，而是"原本有的能力减弱了"；常被家人误以为"懒、不上进" |
| **认知症状** | 注意力、工作记忆、信息处理速度、执行功能（计划/判断/抑制）等信息加工能力下降 | 常不被外人察觉，却是影响学业、职业的核心原因 |
| **精神病性症状** | 一组"现实检验能力受损"的症状总称，包括幻觉、妄想、明显思维紊乱、行为紊乱 | 不是只有精神分裂症才有；双相躁狂、重度抑郁、毒品中毒也可出现 |
| **现实检验能力** | 一个人区分"内心主观体验"和"外部客观现实"的能力 | 急性期受损时，患者真心相信幻听是真的、妄想是铁一般的事实，并非故意说谎 |
| **自知力（洞察力）** | 患者对自己疾病的认识和判断能力——是否承认自己病了、是否认识到症状是病态的 | 自知力缺乏是急性期常见表现，不等于"故意对抗"；随治疗好转可逐步恢复 |
| **依从性（遵医嘱性）** | 患者按医嘱服药、复诊、配合治疗的程度 | 依从性差常与副作用、病耻感、对疾病不认可有关，不能简单归因于"不听话" |

## 5.2 幻觉与妄想：阳性症状的两大支柱

【临床共识】

- **幻觉**：在没有相应客观刺激时出现的类似感知体验。最常见的是**幻听**（听到声音），也可有幻视、幻嗅、幻味、幻触。精神分裂症的幻听常为**评论性幻听**（声音在评论患者的一举一动）或**命令性幻听**（命令患者做某事）——后者涉及安全风险，需认真对待。
- **妄想**：在客观证据充分相反的情况下，患者仍坚信不疑、且与其文化/宗教背景不符的错误信念。常见主题：
  - **被害妄想**：坚信被跟踪、监视、下毒、迫害；
  - **关系妄想**：把电视、新闻、路人的言行都觉得是针对自己；
  - **夸大妄想**：坚信自己有超凡能力、特殊身份；
  - **钟情妄想**：坚信某名人深深爱着自己；
  - **被控制感 / 思维插入 / 思维被广播**：感到自己的思想、行为被外力控制。
- **注意**：不能因为一个信念听起来"奇怪"就断定是妄想，必须结合文化背景、证据强度和患者是否能被说服来判断。

## 5.3 病程分期术语

【临床共识】医生和家属沟通时，常按疾病进程把时间线分成几段：

| 阶段 | 大致时间窗 | 主要特征 | 处理重点 |
| --- | --- | --- | --- |
| **前驱期** | 首次明显发作前数月至数年 | 睡眠变差、社交退缩、学习/工作效率下降、敏感多疑、情绪波动；表现很不特异 | 早期识别、专业评估；但**不能仅凭自我观察贴"前驱期"标签** |
| **急性期 / 发作期** | 首次或再次症状明显加重 | 幻觉、妄想、行为紊乱突出，现实检验能力受损，自知力常缺失 | 尽快就医、药物控制、必要时住院 |
| **巩固期** | 急性症状控制后约 3–6 个月 | 症状逐步减轻，但仍可能残留；易波动 | 继续治疗、密切随访、防复发 |
| **维持期** | 症状稳定后长期 | 阳性症状基本消失，可能仍有阴性症状和认知损害 | 坚持服药、康复训练、回归社会 |
| **缓解期** | 部分或大部分症状在一段时间内减轻 | 症状减轻 ≠ 完全痊愈；不代表可以自行停药 | 与医生共同讨论是否调整治疗 |
| **残留状态** | 急性发作缓解后仍残留部分症状 | 旧版分类用语，指残留的轻度阴性症状或不典型阳性症状 | 描述临床状态，不意味着"没希望" |

【临床共识】分期是为了指导治疗节奏，不是机械的时间表；个体之间差异很大。

## 5.4 治疗相关术语

【临床共识】家属和患者最常听到的一组治疗名词：

| 术语 | 简明释义 |
| --- | --- |
| **抗精神病药** | 治疗精神病性症状的核心药物，分第一代（典型，如氯丙嗪、氟哌啶醇）和第二代（非典型，如利培酮、奥氮平、喹硫平、阿立哌唑等，目前作为一线选择） |
| **锥体外系反应（EPS）** | 抗精神病药（尤其第一代）常见的神经系统副作用：震颤、肌肉僵硬、静坐不能（坐不住）、急性肌张力障碍（脖子歪、眼睛上翻）；长期可出现迟发性运动障碍（不自主咂嘴、吐舌） |
| **泌乳素升高** | 部分第二代药（如利培酮、帕利哌酮）可升高泌乳素，导致女性月经紊乱、泌乳，男性乳房发育、性功能下降 |
| **代谢副作用** | 奥氮平、氯氮平等可引起体重增加、血糖升高、血脂异常，是长期管理的重点 |
| **长效针剂（LAI）** | 每月或每数月注射一次的抗精神病药制剂，血药浓度平稳，**特别适合漏服、依从性差的患者**，可显著降低复发率 |
| **MECT（无抽搐电休克治疗）** | 在麻醉和肌松下，通过短暂诱发脑放电来快速控制严重精神病性症状、抑郁木僵、强烈自杀意念；不是"电刑"，是现代麻醉下的安全治疗 |
| **CBTp** | 针对精神病性症状的认知行为治疗，作为药物之外的辅助康复手段，**不能替代药物治愈急性发作** |

## 5.5 其他高频术语

| 术语 | 简明释义 |
| --- | --- |
| **病耻感（Stigma）** | 社会对精神疾病患者的偏见、歧视和回避，也包括患者内化的羞耻感；它比疾病本身更阻碍就医和回归社会 |
| **高情感表达（EE）** | 家庭环境中过高的批评、敌意、过度情感卷入；高 EE 环境与较高复发率相关，是家庭干预的重要靶点 |
| **社会功能** | 一个人完成自我照料、家庭生活、学习、工作、人际交往和社会参与的能力；是比"症状是否消失"更重要的长期预后指标 |
| **复发预警信号** | 再次发作前常先出现的细微变化：睡眠变差、多疑加重、社交退缩、情绪反常、旧症状复现等；早识别可早干预 |
| **DALY** | 伤残调整生命年，衡量疾病负担的国际通用指标，等于"早亡损失的健康年数 + 带病生存损失的健康年数" |
