# 1. 疾病正式名称

> 本页用于说明"精神分裂症"在现行诊断分类系统中的正式名称、编码、历史由来，以及大众容易混淆的叫法。**核心提醒：名称里的"分裂"指的是心理功能之间的联系紊乱，绝不是"一个人身体里住着好几个灵魂"。** 诊断权仅限精神科执业医师，本页仅作名词科普，不能用于自我诊断。

## 1.1 现行正式名称与编码

| 项目 | 内容 |
| --- | --- |
| 中文正式名称 | 精神分裂症 |
| 英文正式名称 | Schizophrenia |
| ICD-11 分类章节 | "精神、行为或神经发育障碍"（Mental, behavioural or neurodevelopmental disorders） |
| ICD-11 类别代码 | **6A20**（Schizophrenia） |
| DSM-5 / DSM-5-TR 名称 | Schizophrenia（DSM-5 于 2013 年发布，DSM-5-TR 于 2022 年修订，名称沿用未变） |

【临床共识】ICD（国际疾病分类）由世界卫生组织维护，全球用于健康信息记录、医保结算与统计；DSM（《精神障碍诊断与统计手册》）由美国精神医学学会（APA）编制，主要用于临床描述与研究。两套系统的条目、诊断病程要求和编码用途并不完全相同，例如 ICD-11 允许在诊断后附加发作次数、病程模式和症状特征的描述性标注，而 DSM-5 使用严重程度标注与亚型/标注符体系。各国采用 ICD 版本有时间差（ICD-11 于 2018 年由世界卫生大会通过，成员国陆续实施），因此不能仅凭一个国际编码推断当地病历、医保或行政事务实际使用的编码。

## 1.2 名称的历史：从"早发性痴呆"到"精神分裂症"

**【研究结论】** 现代意义上对这组疾病的系统描述，通常追溯到 19 世纪末德国精神科医生 **Emil Kraepelin（克雷丕林）**。他把一组多在青少年晚期至成年早期起病、病程迁延、逐渐出现社会功能衰退的患者归为一类，命名为 **Dementia praecox**，拉丁文意为"早发性痴呆"（premature dementia）。需要强调：这里的"痴呆"是 19 世纪的历史术语，描述的是"心智功能较早地走向衰退"，**完全不等于今天所说的阿尔茨海默病等老年期神经认知障碍**，也不意味着患者智力必然低下。

20 世纪初，瑞士精神科医生 **Eugen Bleuler（布鲁勒）** 认为 Kraepelin 描述的范围偏窄、且"痴呆"一词过于悲观。他于 1908 年前后提出 **Schizophrenia**（德文 Schizophrenie）一词，词源来自希腊语 *schizein*（分裂）+ *phren*（精神、心智）。Bleuler 用这个词想表达的是：患者的**思维、情感、感知、意志等心理功能之间原本协调统一的"联结"出现了断裂**——比如内心没有相应情绪体验，却在不该哭的时候哭、不该笑的时候笑；想到亲人去世却毫无波澜。

**【临床共识】** Bleuler 本人在提出这个词时就反复澄清："分裂"是指心理功能内部的脱联结，**不是指一个人具有多个彼此独立的人格**。这一原意与后世大众望文生义产生的"人格分裂"想象相去甚远。由于"精神分裂症"这个中文译名中"分裂"二字极具误导性，它客观上加剧了公众误解和病耻感。

## 1.3 简称、俗称与不推荐使用的称呼

| 称呼 | 性质 | 说明 |
| --- | --- | --- |
| 分裂症 | 非正式简称 | 偶见于口语或潦草病历，不宜替代完整诊断名称 |
| 精神病 / 发神经 | 范围过宽 | "精神病"可泛指一切精神病性状态或多种重性精神障碍，不是精神分裂症的同义词 |
| 疯子 / 癫子 | 贬损、污名 | 非医学诊断，带有歧视色彩，不应用于称呼患者 |
| 神经病 | 含义混乱 | 日常中文里既可被理解为神经系统疾病（如中风、神经炎），又被当作骂人的话，医学上极不推荐 |
| 人格分裂 / 双重人格 / 多重人格 | 错误对应 | 对应的是"解离性身份障碍"，与精神分裂症是完全不同的两种疾病（详见 1.4） |

【临床共识】使用中性、准确的语言（如"精神分裂症患者""一位康复中的朋友"）既是对患者的尊重，也是减少污名的第一步。

## 1.4 容易混淆、但并非同一诊断的名称

| 诊断名称 | 与精神分裂症的关系 | 关键区别 |
| --- | --- | --- |
| 分裂样障碍（Schizophreniform disorder） | 同属精神病性障碍谱系 | 症状可与精神分裂症相似，但病程时长要求不同（DSM-5 要求症状持续 1–6 个月；精神分裂症要求 ≥6 个月），并非"轻型精神分裂症" |
| 分裂情感性障碍（Schizoaffective disorder） | 与之相邻、需重点鉴别 | 既有显著的心境（躁狂/抑郁）发作，又有精神病性症状；关键在于精神病性症状是否在没有心境发作时仍持续存在 ≥2 周 |
| 解离性身份障碍（Dissociative identity disorder, DID） | **最常被误当成"精神分裂症"** | 核心是存在两个或更多彼此分离的身份状态、伴随记忆断层；旧称"多重人格障碍"。它与思维、感知紊乱为主的精神分裂症不是一回事 |
| 妄想障碍（Delusional disorder） | 另一独立诊断 | 以持续、固定的妄想为核心，缺乏精神分裂症典型的思维破裂、幻觉（尤其评论性幻听）和明显功能衰退 |
| 短暂精神病性障碍 | 病程更短 | 精神病性发作持续 1 天至 1 个月内可完全缓解 |

【临床共识】**名称相近 ≠ 疾病相同。** 这些诊断之间的界限，需要精神科医生结合完整病史、症状组合、持续时间、功能损害和病程演变来判断，患者和家属不能仅凭"症状有点像"自行对号入座。

## 1.5 台湾地区译名"思觉失调症"

【研究结论】由于"精神分裂症"这一名称长期被公众误解为"人格分裂""精神已经裂开"，并带来强烈病耻感，台湾地区于 2014 年由台湾精神医学会倡议，将 Schizophrenia 的中文译名调整为 **"思觉失调症"**，取"思考、知觉等心智功能失调"之意，希望弱化"分裂"二字带来的恐怖联想。香港部分专业文献也采用类似立场。

【临床共识】中国大陆目前仍沿用"精神分裂症"作为规范诊断名称。面向大陆读者写作时，本资料库统一使用"精神分裂症"，但会主动说明它**不等于解离性身份障碍（多重人格）**，以减少误解。这是一个译名与科普策略问题，不是疾病本身发生了变化。

## 1.6 一句话澄清最重要的误区

> **精神分裂症的"分裂"，是指一个人自己的思维、情绪、感知之间协调关系的断裂；而不是一个人身体里住着两个或更多轮流掌权的人格。** "多重人格"在医学上叫解离性身份障碍，是另一种病。把两者混为一谈，既不利于精神分裂症患者，也不利于解离障碍患者。
