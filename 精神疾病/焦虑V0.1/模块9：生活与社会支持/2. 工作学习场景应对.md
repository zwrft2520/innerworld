# 2. 工作学习场景应对

> **焦虑不会因为你坐在办公室/教室里就停下来——恰恰相反，开会、汇报、考试、宿舍社交，都是它高发的场景。这一页给你一套"要不要说、怎么说、发作了怎么办、怎么设边界"的实操方案。**
>
> 本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断。涉及具体劳动权益与学籍政策，以你所在单位/学校和当地法规为准。

## 一、要不要告诉单位 / 学校

这是一个**隐私选择**，不是义务。判断原则：

| 告诉的好处 | 不告诉的理由 |
|---|---|
| 可以申请弹性时间、减少高压任务、考试安排调整 | 担心被贴标签、影响晋升/评优 |
| 发作时有人知道怎么帮你 | 病情尚未稳定、自己还没准备好 |
| 定期复诊需要请假，有合理理由 | 病情已经很稳定、不影响工作学习 |

**常见做法是"有限披露"**：告诉直接相关的一两个人（你的直属领导、一个信任的同事/辅导员），而不是全公司/全班公开。

### 告诉谁、怎么说

**对领导 / HR（按需）：**
> "我最近因为健康原因在接受治疗，需要定期去医院复诊。工作上我会尽量安排好，不影响交付。如果某些时候状态不好，我可能需要临时调整一下节奏，谢谢你的理解。"
>
> 不必说具体诊断名称；你有权只说"健康原因"。

**对辅导员 / 班主任：**
> "我最近在医院诊断出焦虑相关的问题，在治疗中。可能需要偶尔请假复诊，考试期间如果状态不好，希望学校能有合理的安排。"

> 【临床共识】**病历和就诊记录受隐私保护**。单位/学校无权要求你出示诊断证明；但如果你要申请病假、考试缓考、岗位调整，通常需要医院开具的病假建议书——这是你自愿提供的，不是被要求的。

## 二、合理调整请求：具体怎么提

模糊的"我状态不好"很难被批准，**具体、可操作、不影响核心工作**的请求更容易被接受：

| 场景 | 可提的具体请求 |
|---|---|
| 复诊 | "每周三下午我固定请假 2 小时去医院，工作我提前交接。" |
| 弹性时间 | "能否允许我偶尔晚到 1 小时/在家办公半天，我会保证交付。" |
| 减少高压任务 | "近期我状态不太适合带大型对外汇报，能否先做支持性工作？" |
| 出差 | "这两个月能否不安排长途出差，我在本地远程支持。" |
| 考试 | 凭医生病假建议申请缓考、延长考试时间、单独考场等 |
| 宿舍 | 申请调宿舍、减少夜间集体活动（学生） |

> 提请求时，**带上医生的建议**（病假条、就诊记录），比"我觉得"有说服力得多。

## 三、职场焦虑高发场景的具体应对

【临床共识】职场里的焦虑触发点非常集中。下面是高频场景和应对：

| 触发场景 | 发作时的即时应对 | 长期练习 |
|---|---|---|
| **开会发言 / 汇报** | 提前写好提纲；发言前做 3 次缓慢呼吸；手抖就拿笔；告诉自己"说错也没关系" | 从短发言开始逐级暴露（先在小会说 1 分钟 → 大会 → 汇报） |
| **绩效 / 年终评估** | 提前把成果列成清单，不要凭感觉；评估后给自己留一段"恢复期" | 把"被评价"拆成具体反馈，而不是"我整个人被否定" |
| **社交饭局 / 团建** | 提前和一个信得过的同事约好"我们坐一起"；允许自己提前离席；不必喝酒 | 逐步延长在场时间，从 30 分钟开始 |
| **被领导突然叫去** | 去之前先做一次深呼吸；路上允许自己"腿软"，腿软不代表不能走路 | 事后记录"我担心的最坏结果发生了吗"——大多没有 |
| **deadline 高压** | 把任务拆到半天粒度；每完成一小块就休息 5 分钟 | 识别"灾难化想法"："做不完=被开除"通常不成立 |

## 四、学生场景：课堂、考试、宿舍

| 场景 | 应对 |
|---|---|
| **课堂被点名发言** | 提前和老师说"我紧张的时候可能说不完整，请允许我坐下继续说"；紧张时允许自己慢一点 |
| **考试焦虑** | 考前一周规律作息、不要突击咖啡；进考场前做 4-7-8 呼吸；手抖就先写名字、先做会做的题 |
| **考试发挥失常后** | 焦虑会扭曲记忆——考完觉得"全砸了"，往往比真实结果差。先别做重大决定，等成绩出来 |
| **宿舍社交压力** | 不必强迫自己融入所有夜聊；戴耳机、去图书馆是合理的自我保护；必要时申请调宿舍 |
| **和同学冲突后** | 急性焦虑期不要发长消息解释、不要做"以后再也不理谁"的决定；睡一觉再说 |

> 【个人体验】学生时期最伤人的是"我是不是只有我这样"。其实教室里至少三分之一的人都在偷偷心慌，只是没人说。

## 五、惊恐发作在公司 / 学校突发怎么办

这是很多人最怕的场景。提前准备好，真发作时就不慌：

1. **识别**：心跳快、胸闷、手麻、"我要晕倒了"——你认得出这是惊恐发作，就已经赢了一半。
2. **离场**：跟身边人说一句"我去下洗手间/接个电话"，走到安静、通风的地方（楼梯间、空会议室、操场边）。
3. **呼吸**：4-7-8 呼吸（吸 4 秒、屏 7 秒、呼 8 秒）做 3–5 轮；或 5-4-3-2-1 接地法（说 5 个看到的、4 个摸到的、3 个听到的）。
4. **告诉自己**："这是惊恐发作，不会死，10 分钟内会过去。"
5. **如果半小时还没过去、或这是第一次这么重**：让信任的同事/同学陪你去校医院/附近急诊排查一次。

> 【临床共识】惊恐发作本身**不会直接致命**，但**首次出现、或伴随胸痛放射/冷汗时，必须先去急诊排除心脏问题**——这是规则，不是吓自己。

## 六、病休 / 复学 / 复工：节奏与权益提示

- **不要硬撑到崩溃才休**：医生会根据你的状态开病假建议；早期短期调整，往往比拖到必须长休便宜。
- **复工/复学不要一步到位**：和医生、单位/学校商量，从半天、少量任务开始，逐步恢复全职。
- **权益底线**：根据《精神卫生法》《劳动合同法》及地方规定，精神疾病患者在医疗期内享有相应保护；单位不能仅凭"你有精神疾病"就直接辞退。具体条款拿不准，可以打 **12333**（人社咨询）或 **12348**（法律援助）问。
- **不要把病历主动广而告之**：病假条只给需要审批的人，不给八卦的同事。

> 本节只做方向性提示，不展开法律细节。真正遇到纠纷，找专业法律渠道。

## 七、设置边界与减少刺激的实操

| 日常边界 | 怎么做 |
|---|---|
| **咖啡因** | 焦虑明显时，咖啡/浓茶/能量饮料减到每天 1 杯以内，下午 2 点后不喝 |
| **酒精** | 不要用喝酒缓解焦虑——它短期放松，长期加重焦虑和失眠 |
| **屏幕时间** | 睡前 1 小时不刷短视频/工作群；工作群设置"免打扰时段" |
| **社交负荷** | 一周只安排 2–3 个社交活动，其余留给自己恢复 |
| **信息输入** | 少刷"焦虑测试""抑郁症清单"类内容——越对号入座越焦虑 |
| **身体底线** | 每天尽量同一时间睡、同一时间起；每周 3 次 30 分钟中等强度运动 |
| **拒绝权** | 练习说"这次我不参加了"，不必每次都给长理由 |

---

> **最后，请记住：** 你不是在"带病混日子"，你是在一边治疗一边生活。允许自己慢一点、允许自己申请调整、允许自己在必要时离场——这不是软弱，是长期主义。
