# 1. 就诊触发信号

> 最常见的两个错误：一是"忍忍就过去了"，拖到严重影响生活才来；二是一心慌就以为是心脏病，反复跑急诊。这一篇帮你判断：**什么时候该预约门诊，什么时候必须立刻去急诊**。
> 本资料仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。

## 一、什么时候该预约门诊（不必急诊）

出现以下情况，建议尽快挂精神科/心理科普通门诊：

| 信号 | 说明 |
|---|---|
| 担心、紧张持续存在 | 广泛性焦虑通常要≥6个月才够诊断标准，但**不必自己死卡时间**——影响生活就该看 |
| 明显影响生活功能 | 上班/上学效率明显下降、不敢出门、回避社交、与家人频繁争吵 |
| 躯体不适反复查不出原因 | 心慌、胸闷、头晕、肠胃不适，心内科/消化科查了一圈没大事 |
| 惊恐发作之后 | 经历过一次强烈发作，开始害怕再次发作、不敢独处、不敢出门 |
| 自我调节无效 | 自己试了运动、放松、休假，一两个月仍不见好 |
| 睡眠长期紊乱 | 入睡困难、早醒、睡不解乏，持续数周 |
| 出现酒精/药物滥用倾向 | 开始靠喝酒、吃药才能放松入睡 |

【临床共识】就诊不必等到"完全受不了"。早期干预疗程更短、恢复更好；拖到慢性化，治疗难度反而上升。

【个人体验】很多康复者后悔的是同一句话："早知道这么容易说清楚，我不该自己扛两年。"

## 二、【重要】出现这些身体信号，先急诊/心内科，不要先假设是焦虑

这是本篇最关键的提醒：**首次剧烈胸痛、胸闷、心悸、晕厥、呼吸困难，先按急症处理，排除心脏问题，再谈焦虑。**

| 必须先排查躯体急症的情况 |
|---|
| 突发剧烈胸痛/胸闷，尤其向左肩、左臂、下颌、背部放射 |
| 伴冷汗、濒死感、面色苍白、呼吸困难 |
| 晕厥、眼前发黑、失去意识 |
| 既往有心脏病、高血压、糖尿病、吸烟史、中年以上 |
| 心跳又快又乱、持续不缓解，或血压明显异常 |

【临床共识】惊恐发作和心脏急症在症状上非常像（都心慌、胸闷、濒死感），**第一次发作尤其不能自行断定"只是焦虑"**。先做心电图、查心肌酶，把危险排除掉，既安心，也让后面的焦虑诊断更干净。

【个人体验】一位患者描述："那次半夜胸口压得喘不上气，打120到急诊，心电图、抽血都正常。医生说'你这是惊恐发作，去看看心理科'——那一刻反而踏实了，因为终于有人告诉我它是什么。"

## 三、分流表：挂急诊 / 预约门诊 / 先自我观察

| 你的情况 | 建议行动 |
|---|---|
| 首次剧烈胸痛胸闷、放射痛、冷汗、晕厥、既往心脏病 | **立即急诊 / 拨打120** |
| 有明确自伤、自杀念头或计划 | **立即急诊或联系危机热线** |
| 惊恐反复发作，不敢独处不敢出门 | 尽快预约精神科/心理门诊 |
| 持续担心紧张≥数周，影响睡眠工作 | 预约普通门诊 |
| 身体不适反复查无器质性原因 | 门诊+必要时转诊心身医学科 |
| 偶尔紧张、压力大，休假后能恢复 | 先自我调节+观察1～2周 |

## 四、诊断标准里的"时间"，不用自己硬套

【临床共识】以广泛性焦虑障碍为例，诊断标准要求"过度的焦虑和担忧"持续**至少6个月**。但这是医生对照标准用的，**你不需要先在家掐着日历算日子**。症状明显、难受、影响生活，就值得来看；时间长短由医生面诊时综合判断。

## 五、自我调节多久没效，就该看医生

| 尝试过的方法 | 建议观察期 |
|---|---|
| 运动、作息调整、减少咖啡因、找人倾诉 | 2～4 周 |
| 仍无改善，或越来越重 | 就诊 |
| 期间出现惊恐发作、失眠加重、回避行为 | 不必等时间，直接就诊 |

## 六、一句话记住

**第一次剧烈胸痛胸闷，先救命、先查心脏；排除之后，反复出现的心慌担心、查不出原因的不舒服、影响生活的紧张——才轮到焦虑科来看。**
