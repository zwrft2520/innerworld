# 焦虑障碍（面向患者）资料库 · Markdown 模块框架
> 说明：面向患者科普，语言尽量通俗，避免过度学术化；**免责提示放最前面**：本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。
> 收录范围：焦虑障碍大类（广泛性焦虑、惊恐障碍、社交焦虑、特定恐怖症、场所恐怖等），不是单一“焦虑情绪”

## 模块1：疾病正式名称与分类词条
适合你资料库统一规范命名的部分，和之前抑郁、精神分裂条目保持格式一致
1. 标准学名（ICD-11 / DSM-5）
2. 子类型/子条目：广泛性焦虑障碍、惊恐障碍、社交焦虑障碍、特定恐怖症、场所恐惧障碍、分离性焦虑障碍等
3. 临床简称、常用别名
4. 易混淆名词区分：正常焦虑情绪 vs 病理性焦虑；焦虑障碍≠神经衰弱、焦虑≠抑郁（共病说明）
5. 历史名称（可选）

## 模块2：基础认知【患者最优先看懂】
1. 什么是焦虑障碍：区分**正常的焦虑情绪**和达到疾病程度的焦虑
2. 发病简单原理（通俗版）：大脑预警系统过度激活，神经递质、遗传、压力等，避免专业晦涩术语
3. 误区辟谣：
    - 误区：就是想太多、性格胆小、意志力差
    - 误区：吃药会上瘾，尽量不吃
    - 误区：只要调整心态就能完全好
4. 患病特点：可治疗、可康复，不是性格缺陷

## 模块3：症状表现（分躯体、情绪、思维、行为）
> 患者自查参考，**标注：有这些症状≠确诊**
1. 情绪症状：持续紧张不安、莫名恐惧、预感灾难、容易烦躁易怒
2. 躯体症状（很多患者最先感受到）：心慌胸闷、气短、手抖、出汗、头晕、肠胃不适、肌肉紧绷、失眠、疲惫
3. 思维症状：反复担忧、灾难化想法、难以控制胡思乱想、注意力难集中
4. 行为症状：回避场景、反复确认、拖延、坐立不安
5. 各亚型典型症状区分（比如惊恐发作的急性特征）

## 模块4：诱因与高危因素
1. 生物学因素：遗传、大脑神经调节、睡眠紊乱
2. 心理因素：长期压力、思维习惯、创伤经历
3. 环境因素：长期高压事件、重大变故、慢性疾病刺激
4. 保护因素：社会支持、稳定作息、及时求助

## 模块5：就医 & 诊断指南（患者实操向）
1. 什么时候应该去看医生（就诊触发信号）
2. 该挂什么科室：精神科 / 临床心理科，区分心理咨询师和精神科医生
3. 就诊前准备清单：要记录的症状、持续时间、既往病史、用药史
4. 诊断流程：问诊、评估量表（说明量表只是辅助，不能单独确诊）
5. 常见共病：焦虑合并抑郁、失眠、躯体形式问题

## 模块6：治疗方案（患者视角，客观介绍）
1. 药物治疗
    - 常用药物类别、作用原理通俗解释
    - 起效时间、常见短期副作用
    - 重要提醒：不可自行停药、减药；撤药反应风险；遵医嘱
2. 心理治疗：CBT认知行为疗法（一线推荐）、正念、暴露疗法等，简单讲适合哪类焦虑
3. 物理治疗（可选）：如重复经颅磁刺激等适用情况
4. 治疗预期：不是立刻根治，目标减轻症状、恢复生活功能

## 模块7：自我调节与日常康复实操【重点，患者高频使用】
> 强调：是辅助，**不能替代正规治疗**
1. 急性焦虑/惊恐发作应急方法（落地技巧：478呼吸、接地技术54321法）
2. 长期日常管理：睡眠、运动、咖啡因/酒精管控、压力减负
3. 思维调整练习：识别灾难化想法、担忧记录
4. 渐进式暴露练习（简单介绍，重度建议在治疗师指导下做）
5. 适合的放松练习

## 模块8：危机识别与求助资源
1. 需要紧急就医的危险信号：强烈濒死感无法缓解、伴随自伤想法、严重无法进食睡眠
2. 国内心理危机热线信息
3. 什么时候联系主治医生复诊

## 模块9：生活与社会支持
1. 和家人亲友沟通：怎么解释自己的焦虑，减少误解
2. 工作/学习场景应对方法（减少刺激、边界设置）
3. 康复路上常见困境：反复发作、病耻感

## 模块10：常见Q&A
收集患者高频疑问，例如：
- 焦虑能不能完全治好？
- 焦虑会变成精神病吗？
- 长期焦虑会不会把身体器官弄坏？
- 心理咨询一般多久见效？
