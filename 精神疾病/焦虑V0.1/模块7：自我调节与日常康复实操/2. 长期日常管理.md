# 2. 长期日常管理

> **先摆正位置：自我调节是辅助，不能替代正规治疗。** 本页讲的是在药物/心理治疗之上，帮你把复发风险降下来、把日子过稳的"生活基本功"。它不是靠意志力自愈，而是给正规治疗搭脚手架。本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。

## 一、睡眠：焦虑最好的盟友和敌人

焦虑和睡眠常常互为因果：睡不好→第二天更敏感→更焦虑→更睡不着。

**睡眠卫生清单**：

- **固定起床时间**：比"几点睡"更重要。每天同一时间起来，哪怕前一晚没睡好。
- **早上接触自然光**：起床后拉开窗帘、出门走走，帮生物钟校准。
- **睡前1小时减速**：放下手机、调暗灯光，做一点放松的事。
- **床只用来睡觉**：不要在床上工作、刷手机、翻来覆去地焦虑，让大脑把"床=睡觉"重新连起来。
- **睡不着别硬逼自己**：越努力想睡越清醒。躺约20分钟还睡不着，就起来做点安静的事，有困意再回床。
- **慎用酒精助眠**：酒精让人昏沉，但会破坏后半夜睡眠、加重焦虑反跳。

【个人体验】很多康复者发现，把"起床时间固定"这一件小事做到，整个人的节律和情绪就慢慢稳了。

## 二、有氧运动：被低估的"天然抗焦虑药"

【研究结论】规律的**有氧运动**（快走、慢跑、骑车、游泳等）对轻中度焦虑有明确的辅助改善作用，长期坚持还能降低复发风险。它通过调节神经递质、降低基础警觉水平、改善睡眠来起效。

**怎么开始（循证又安全）**：

- **频率强度**：循序渐进地，目标是每周累计约150分钟中等强度有氧（微微出汗、能说话但不能唱歌的程度），分多次完成即可；
- **从极小目标开始**：比如"今天出门走10分钟"，而不是一上来定"每天跑5公里"；
- **不要搞"运动打卡羞耻"**：今天没做到不是失败，明天继续；
- **哪怕出门站一站也算数**：动力最低的时候，"穿上鞋下楼"这一个动作就值得肯定；
- 有心脏问题、关节问题或正在服药者，开始新运动计划前先问医生。

## 三、咖啡因、尼古丁、酒精：三个容易被忽略的"焦虑放大器"

| 物质 | 为什么影响焦虑 | 建议 |
|---|---|---|
| **咖啡因**（咖啡、浓茶、能量饮料、可乐） | 它的半衰期约3–5小时，下午一杯可能影响晚上睡眠；它会直接刺激交感神经，放大心慌、手抖这些"焦虑的躯体信号" | 【临床共识】焦虑者建议**显著减少**咖啡因，尤其下午以后；敏感者可改低因或无因。不用追求"完全戒断"，但要留意它和你发作的关系 |
| **尼古丁**（吸烟/电子烟） | 短暂放松后会反跳性升高警觉，且干扰睡眠 | 戒烟对焦虑和整体健康都是净收益；戒烟过程中的情绪波动可请医生帮助 |
| **酒精** | **"假放松"**：酒精短期让人昏沉放松，但会破坏睡眠、停药/醒后焦虑反跳更重，还会与苯二氮䓬类等药物叠加抑制中枢 | 不应用酒精抗焦虑；服药期间尤其避免 |

【个人体验】很多人惊恐发作前其实喝了不少咖啡或熬了夜，只是没把这两件事联系起来。记几周日记后，这个规律会自己浮出来。

## 四、饮食与血糖

- **规律进餐**：焦虑常让人饥一顿饱一顿，低血糖本身就会引起心慌、手抖，和焦虑的躯体感觉几乎一样。
- **稳住血糖**：少用高糖饮料、精制零食让血糖大起大落，对情绪稳定有帮助。
- **不过度迷信保健品**：没有单一食物或保健品能治疗焦虑，补剂不能替代药物与治疗。

## 五、压力减负：把"警报源"一个个拆掉

焦虑的人常常不是"事太多"，而是"每件事都被当成天大的事"。方法：

- **任务拆解**：把一个大任务切到"小到不可能失败"。不要想"做完整个项目"，只想"打开文档写第一句"。
- **学会说不**：焦虑者常因怕冲突而过度承诺，结果把自己压垮。温和而清楚地拒绝，是在保护治疗。
- **信息节食**：睡前少刷手机新闻、少反复看让你焦虑的信息；固定时间处理消息，而不是全天候被它追着跑。
- **设边界**：区分"我能控制的"和"我控制不了的"，把精力只投向前者。

## 六、"担忧时间"（Worry Time）：一个被验证的小技术

这是 CBT 里专门对付广泛性焦虑"整天胡思乱想"的技术：

**操作步骤**：
1. 每天**固定一个时段**（比如傍晚 5:00–5:15），作为专属的"担忧时间"；
2. 在一天其他时间里，一旦发现自己开始担忧，就**对自己说"先记下来，留到担忧时间再想"**；
3. 到了担忧时间，拿出来**认真地、有期限地**想这些事：这件事我能做什么？不能做的部分怎么办？
4. 时间一到就停，转入下一件事。

【个人体验】它的妙处在于：你不是"不许担心"（那只会更担心），而是给担心**划定一个笼子**。练几周后，你会发现一天中"自动翻来覆去想同一件事"的时间明显变少了。

## 七、症状日记：让焦虑变得可观察、可管理

每天花2分钟记一笔：

| 日期 | 焦虑强度(0–10) | 发生了什么 | 身体感觉 | 咖啡因/睡眠情况 | 我做了什么应对 | 今天一件小事 |
|---|---|---|---|---|---|---|
| 例：10/19 | 6 | 下班路上心慌 | 胸口发紧、手抖 | 昨晚睡5h，下午一杯咖啡 | 走慢一点、深呼吸 | 便利店的热饮很好喝 |
| | | | | | | |
| | | | | | | |

坚持几周，你会看出自己的"发作规律"和"有效应对"。
