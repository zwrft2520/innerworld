# 3. 思维调整练习

> **先摆正位置：这些是 CBT 的自助工具，辅助正规治疗，不能替代。** 它们帮你识别和松动那些把小事放大成灾难的思维习惯；但如果你现在症状很重、被念头卷得无法工作生活，请在治疗师带领下做，不要独自硬扛。本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行确诊。

## 一、焦虑的脑子长什么样

【临床共识】焦虑障碍患者的大脑，像一个过于敏感的烟雾报警器——没着火也狂响。它有一套固定的"思维偏差"，识别它们是第一步。

## 二、常见认知偏差（配焦虑患者的真实例句）

| 认知偏差 | 是什么 | 焦虑患者的例句 |
|---|---|---|
| **灾难化** | 把小小的不适直接想到最坏结局 | "我心跳快了一下——我是不是要猝死了。" |
| **高估概率** | 把"有可能"当成"几乎一定会" | "明天要开会发言——我肯定会出大丑。"（其实概率很低） |
| **低估自己应对** | 事情真发生时，觉得自己一定扛不住 | "万一我在地铁上惊恐发作，我就完了、没人能救我。" |
| **非黑即白** | 要么完美要么完蛋，没有中间 | "我今天状态不好，说明这个治疗全失败了。" |
| **"应该"句式** | 用一堆"我应该/我必须"逼自己 | "我应该完全不焦虑才对。""别人都不怕，就我怕，我真没用。" |
| **情绪化推理** | 把"我感觉"当成"事实" | "我感觉要出事，那就一定要出事。" |
| **反复求确认** | 总想找人保证"没事"，但保证完很快又慌 | 反复查症状、反复问家人"我心脏到底有没有事" |

【个人体验】你不需要一次全认出它们。先挑一个你最常犯的（很多人是"灾难化"），盯它一周。

## 三、思维记录表（核心工具）

这是 CBT 最经典的自助练习。**它不是让你"往好处想"，而是让你像科学家一样，给那个自动想法找证据。**

### 空白模板（可复制到备忘录）

| 栏目 | 填什么 |
|---|---|
| ① 情境 | 发生了什么？在哪？和谁？ |
| ② 自动想法 | 脑子里瞬间冒出来的那句念头是什么？ |
| ③ 情绪强度(0–100) | 当时焦虑/恐惧有几分？ |
| ④ 支持这个想法的证据 | 有什么事实真的支持它？ |
| ⑤ 反对这个想法的证据 | 有什么事实不支持它？ |
| ⑥ 替代想法 | 更平衡、更符合证据的说法是什么？ |
| ⑦ 重新评分 | 现在焦虑还剩几分(0–100)？ |

### 一个填好的示例

| 栏目 | 内容 |
|---|---|
| ① 情境 | 下午开会前，我突然心跳快、胸口发紧。 |
| ② 自动想法 | "我马上要在会上惊恐发作、当众晕倒，出大丑。" |
| ③ 情绪强度 | 90 |
| ④ 支持证据 | 我确实心跳快、胸口紧；以前有过惊恐。 |
| ⑤ 反对证据 | 我被医生诊断过惊恐障碍，这种发作几十分钟会退；上次同样的感觉我并没有真的晕倒；我可以先出去喝口水、做慢呼吸；同事也有过紧张不适，没人觉得天塌了。 |
| ⑥ 替代想法 | "这是惊恐的躯体信号，不是心脏病。它会过去，我可以坐下、慢呼吸、必要时出去一下，不需要立刻在所有人面前出丑。" |
| ⑦ 重新评分 | 40 |

【个人体验】你会发现：做完这张表，情绪往往不是降到0，而是从90降到40——这就够了。**目标不是消灭焦虑，而是把它从"被淹没"降到"能应对"。**

## 四、苏格拉底式提问清单

当一个灾难化念头冒出来，像个律师一样问自己这几句：

1. **支持这个想法的证据是什么？反对的证据是什么？**
2. **这件事真正发生的概率有多大？**（不是"有没有可能"，是"百分之几"）
3. **就算它真的发生了，我具体能怎么办？**我以前有没有熬过类似的事？
4. **如果我的朋友遇到这件事、这么想，我会怎么劝他？**
5. **我是在"知道事实"，还是在"感觉要出事"？感觉不等于事实。**
6. **我现在最糟会怎样？最好会怎样？最可能发生的又是哪个？**

## 五、去灾难化练习：三个版本

针对一个你最担心的场景，把下面三栏都写出来：

| 版本 | 内容（示例：怕在地铁上惊恐发作） |
|---|---|
| **最坏会怎样** | 我可能心慌、难受、想下车。但既往经验是它几十分钟会退，我不会真的死掉。 |
| **最好会怎样** | 可能根本不发作，或者只是轻微紧张，坐几站就到了。 |
| **最可能发生的** | 我可能会有点紧张，做几次慢呼吸，到了就好了——这是最现实的。 |
| **如果最坏真发生，我能怎么办** | 下车、找座位坐下、做接地和慢呼吸、必要时联系家人；我以前做到过。 |

【临床共识】这个练习的关键是最后一行——**它把"我无法应对"的信念，替换成"我有具体的应对步骤"**，这正是焦虑最怕的事。

## 六、使用提醒

- **不必追求"完全不焦虑"**：目标是把焦虑调回到可应对的程度，不是变成一个没情绪的人。
- **重度时需要治疗师带**：如果念头强烈到你根本没法坐下来填表、或已经影响到进食睡眠，请回到医生/治疗师那里。
- **它是练出来的**：前几次填表会很别扭、很慢，这很正常。就像健身，练多了大脑会自动开始这么干。

---

> **再强调一次**：这些工具是 CBT 的自助版本，是正规治疗的辅助，不能替代药物和专业心理治疗。配合《模块7》的暴露练习和放松练习一起用，效果更好。
