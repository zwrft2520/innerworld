# 3. 复诊时机与联系医生

> **很多治疗失败不是因为药不对，而是因为"该复诊的时候没去、该说的症状没说、不该停的药自己停了"。这一页帮你把复诊节奏、必须联系医生的情况、和医生高效沟通的方法讲清楚。**
>
> 本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。所有用药与剂量调整，请遵你的主治医生医嘱。

## 一、固定复诊节奏：不同阶段不一样

【临床共识】精神科治疗的复诊频率，是跟着"稳不稳"走的——越早期、越调整期，看得越勤；越稳定，间隔越长。下面是常见节奏，**具体以你的医生安排为准**：

| 阶段 | 常见复诊间隔 | 这个阶段医生在看什么 |
|---|---|---|
| **治疗初期**（刚开始用药/心理治疗前 1–4 周） | 1–2 周一次 | 药物耐受、早期副作用、症状变化趋势 |
| **调药期**（加减药、换方案） | 2–4 周一次 | 疗效是否出现、副作用能否耐受、剂量是否合适 |
| **稳定期**（症状明显好转、方案固定） | 1–3 个月一次 | 维持疗效、预防复发、评估能否减量 |
| **巩固/减药期**（连续稳定数月后讨论停药） | 4–8 周一次，逐步拉长 | 撤药反应、复发迹象、社会功能恢复 |

> 【个人体验】很多人觉得"我好得差不多了，就不去了"。恰恰相反——**稳定期的复诊是为了不让你重新掉回去**，它比你想象的便宜、也比复发一次便宜得多。

## 二、必须提前/临时联系医生的情况

以下情况**不要等到预约的复诊日**，应该主动联系医生（门诊加号、电话/线上问诊、必要时急诊）：

| 情况 | 为什么不能等 |
|---|---|
| **出现新的明显副作用**：皮疹、严重恶心呕吐、手抖影响生活、持续头晕、性功能明显受影响、明显发胖 | 副作用可能需要调整剂量或换药，硬扛只会让你自行停药 |
| **症状明显加重**：焦虑比上周重、惊恐发作变频繁、开始睡不着 | 可能需要提前调整方案，而不是等复发 |
| **睡眠急剧恶化**：连续多日几乎无法入睡 | 失眠是焦虑复发和其他问题的早期信号 |
| **出现自伤/自杀念头**，哪怕一闪而过 | 这是最高优先级，不要等，见《需要紧急就医的危险信号》 |
| **出现"睡很少却特别精神、话多、冲动消费"** | 警惕转躁，需医生评估是否双相谱系 |
| **遇到重大生活事件**：亲人离世、分手、失业、搬家、家庭冲突 | 应激是复发常见诱因，医生可能要预防性调整 |
| **误服/漏服大量药物**、怀疑药物相互作用（新加了别的科的药） | 可能需要紧急处理 |
| **打算怀孕/备孕** | 药物需要提前个体化评估，不要自己突然停 |

> 【临床共识】**任何让你"心里不踏实"的变化，都值得打一个电话问医生。** 医生宁愿你多问，也不愿你自己猜。

## 三、如何与医生高效沟通：带上这三样

精神科门诊通常只有 10–20 分钟。**谁准备得充分，谁就能在有限时间里拿到更准的判断。** 建议每次复诊前准备好下面三样：

### 1. 症状日记（手机备忘录即可）

不用写长文，按天记关键词：

```
日期：10/15
睡眠：昨晚 2 点才睡，醒 2 次
惊恐：1 次（下午开会时，约 10 分钟）
情绪：上午烦躁，下午平稳
服药：早上忘吃一次，晚上补了
副作用：白天有点犯困
```

### 2. 量表分数（如果医生让你做）

很多医院会用 GAD-7（焦虑 7 项）、PHQ-9（抑郁 9 项）、PSQI（睡眠）等量表。**自己在家每 1–2 周做一次，把分数变化带给医生**，比"我感觉好点了"具体得多。

> 量表只是辅助，不能单独用来诊断或调药——但它是医生判断趋势的好工具。

### 3. 用药反应记录

- 现在每天吃哪几种、各多少剂量、几点吃；
- 吃了多久；
- 哪个症状先好转、哪个没变化；
- 出现了哪些副作用、从第几天开始。

**一张表能省掉医生大量回忆时间。**

## 四、复诊时可以直接问医生的问题清单

不知道说什么时，照着问：

- "我现在这个症状变化，算正常波动还是需要调方案？"
- "这个药大概还要吃多久？"
- "如果我出现 XX 副作用，是该减量、换药还是忍一忍？"
- "我大概什么时候可以讨论减量？"
- "我最近遇到 XX 事，需要预防性调整吗？"
- "如果我出差/回老家，药怎么带、复诊怎么衔接？"
- "我可以做心理咨询吗？和药物怎么配合？"

> 你有权让医生把"下一步计划"说清楚。如果医生说"先这样，下次再说"，你可以追问一句："那下次复诊我主要观察什么？"

## 五、春节 / 出差 / 异地：用药与复诊怎么衔接

这是很多人断药、复发的高发场景。提前规划：

| 场景 | 提前要做的事 |
|---|---|
| **春节回老家** | 回老家前多开 2–4 周药量（复诊时主动跟医生说"过年要回老家"）；带上药盒/处方，不要把药分装到小药盒里就觉得没事，万一要补药有凭证 |
| **长期出差** | 算好天数，多备 1 周缓冲；查好出差城市有精神科的医院；保留主治医生的联系方式/线上问诊渠道 |
| **搬家/异地长期居住** | 带上既往病历、用药记录、出院小结；到新城市后 1–2 周内挂上当地精神科，**不要凭老处方自己一直买药吃** |
| **断药几天了** | 不要自己"加倍补回来"，立刻联系医生问怎么恢复 |

> 【个人体验】药盒上的药名、剂量、服用时间，拍张照存在手机里；病历本拍照备份。这些小动作在异地补药时能救命。

## 六、停药 / 减量：必须经医生

【临床共识】这是焦虑障碍治疗中最容易踩的坑：

- **症状刚好转就自行停药** → 复发率显著升高，且下次治疗更难。
- **想减量时突然停** → 可能出现撤药反应（头晕、电击感、失眠、焦虑反弹），被误认为"病更重了"。
- **要不要停、怎么停、停多久**，必须由医生根据你的病程、稳定时间、复发风险个体化决定。

> 你可以跟医生讨论减量，但**不要自己先减量再告诉医生**。

## 七、医生联系不上时的替代路径

打医生电话没接、线上问诊没人回、预约号挂满了——不要就此放弃，按下面顺序找替代：

1. **医院门诊/导诊台**：说明"正在服用精神科药物，有副作用/症状变化，需要加号"，很多医院有加号通道。
2. **药师门诊 / 用药咨询窗口**：药物相互作用、漏服、副作用这类问题，药师可以先给你应急建议。
3. **同科室其他医生**：主治医生不在时，同科室值班医生也能看你的病历。
4. **12356 心理援助热线**：先聊一聊，让接线员帮你判断紧急程度、推荐本地资源。
5. **急诊**：如果出现自伤念头、严重失眠进食困难、药物严重不良反应，不要等预约号——直接去有精神科急诊的医院。

> 联系不上医生 ≠ 没人管你。医院、热线、急诊，都是你的后路。

## 八、给自己建一份"就诊档案"

建议在手机里建一个备忘录文件夹，长期保存：

- [ ] 确诊名称（ICD/DSM 名称，问医生要）
- [ ] 主治医院、科室、医生姓名、出诊时间、联系方式
- [ ] 正在用的药名、剂量、服药时间、开始日期
- [ ] 既往用过但停掉的药、停药原因
- [ ] 做过的检查（心电图、甲功、血常规等）日期和结果
- [ ] 量表分数趋势
- [ ] 紧急联系人、12356、120、110

> 换医院、换医生、急诊时，这一份档案能让新医生在 5 分钟内了解你半年的病程。

---

> **最后，请记住：** 复诊不是"证明你好了"，而是"让医生帮你一直好下去"。主动联系医生不代表你脆弱，恰恰说明你在认真管理自己的健康。
