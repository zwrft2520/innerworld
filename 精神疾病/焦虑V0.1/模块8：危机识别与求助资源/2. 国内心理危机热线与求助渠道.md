# 2. 国内心理危机热线与求助渠道

> **不知道打给谁、不知道哪个渠道靠谱，是很多人在最难的时候卡住的原因。这一页把国内能用的求助渠道按"首选—补充—线上—医院"整理好，存进手机备忘录，希望你永远用不上，但一定要有。**
>
> 本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。
>
> **核实日期：2026-10-19。热线号码可能随时间调整，拨打前以当地官方公布为准。**

## 一、首选：全国统一心理援助热线 12356

【临床共识】**12356 是目前国内最优先、最该存的心理援助号码。**

| 项目 | 内容 |
|---|---|
| 号码 | **12356** |
| 服务时间 | **24 小时** |
| 费用 | **免费**（按市话/套餐计费，无额外服务费） |
| 开通时间 | **2025 年 5 月 1 日起**全国统一使用 |
| 主办 | 国家卫生健康委员会统一部署，各地精神卫生中心/定点机构承接 |
| 能解决什么 | 情绪困扰倾诉、心理危机干预、就医指导、转介建议 |

> 号码里没有"4"，寓意"要爱我了"，是国家层面设计的暖心号码。
>
> 【核实依据】2025 年 5 月起，全国原有的各地心理援助热线逐步统一并入 12356；国家卫健委 2025 年多次新闻发布会介绍过该热线运行情况。

**什么时候打 12356：**
- 你情绪很难受，想找人说说话，又不想惊动身边人；
- 你出现了"活着没意思""不想撑了"之类的念头，想先聊一聊评估风险；
- 你不知道自己的情况该挂什么科、要不要去急诊；
- 你是家属，不知道怎么回应身边人的危机。

> 你不需要"够严重"才配打这个电话。任何让你不安的状态，都值得一个电话。

## 二、紧急：医疗急救 120、报警 110

| 渠道 | 号码 | 什么时候用 |
|---|---|---|
| 医疗急救 | **120** | 胸痛、晕厥、呼吸困难、自伤行为发生、药物严重不良反应、意识不清 |
| 报警 | **110** | 现场有现实人身安全威胁、需要警力到场、当事人有伤害他人风险 |

打 120 时，调度员通常会问：地址、发生了什么、患者现在的状态、年龄性别、既往病史。**照实说就好，不要因为"不确定是不是小题大做"而不打。**

## 三、对口机构：当地精神卫生中心 / 精神专科医院急诊

心理危机最对口的线下去处，是**当地精神卫生中心（或精神专科医院）的急诊/门诊**，以及开设精神科的三甲综合医院。

**怎么找：**
1. 打开手机地图（高德/百度/腾讯地图），搜索"**精神卫生中心**""**精神科急诊**""**心理危机干预**"；
2. 看导航里有没有标注"24 小时急诊"；
3. 去之前先打医院公开电话确认急诊是否开放、是否需要预约。

> 【个人体验】很多城市的精神卫生中心同时就是 12356 的本地承接单位，接线员如果判断你需要线下就诊，会直接建议你去对口机构。

| 项目 | 号码 |
|---|---|
| 手机 / IP / 分机用户拨打 | **010-82951332** |
| 固定电话（座机）拨打 | **800-810-1117** |

## 五、其他补充渠道（需注意性质）

| 渠道 | 说明 | 注意 |
|---|---|---|
| 希望 24 热线等民间公益热线 | 由民间心理机构运营，24 小时接听 | **民间性质**，接线质量和排班可能变动；拨打前先在官网核实当期号码 |
| 各地"市长热线"12345 | 可咨询本地精神卫生资源、就医政策 | 非直接危机干预，适合问资源 |
| 人社咨询 12333 / 法律援助 12348 | 涉及病休、复工、劳动权益时咨询 | 非心理热线 |

> 【争议观点】网上还能搜到大量"心理疏导""情感挽回"类商业热线/APP。**它们不是危机干预资源**，很多以盈利为目的，甚至可能诱导付费。真遇到危机，优先打上面列的公立/公益号码。

## 六、线上渠道：去哪里查靠谱信息

- **国家心理健康和精神卫生防治中心**：https://ncmhc.org.cn/ （原国家精神卫生项目办）——发布全国精神卫生政策、科普、本地资源。
- **国家卫生健康委员会官网**：http://www.nhc.gov.cn/ ——查 12356 相关通知、本地精神卫生中心名录。
- **北京市心理援助热线 / 北京心理危机研究与干预中心**：https://www.crisis.org.cn/ ——科普文章质量较高。
- 你所在**省/市卫生健康委官网**、本地三甲医院精神科公众号。

**怎么判断一个渠道靠不靠谱：**

| ✅ 优先选 | ❌ 谨慎/避开 |
|---|---|
| 公立医院、政府卫生部门主办 | 个人自媒体、商业培训机构 |
| 有明确主办单位、地址、电话 | 只留微信号、"加老师咨询" |
| 内容是科普、就医指导 | 内容是"七天根治焦虑""停药不复发" |
| 不主动诱导你买课/买药 | 反复劝你买课、买产品、加付费群 |

## 七、打热线会发生什么：流程与保密原则

第一次打心理热线的人，常常紧张得不知道说什么。了解一下流程就不慌了：

1. **接通**：接线员自报家门，比如"您好，这里是 12356 心理援助热线"。
2. **倾听与评估**：你说，接线员听；他们会问几个简单问题——你现在在哪里、身边有没有人、有没有伤害自己的计划——用来判断风险。
3. **一起想办法**：根据你的状态，接线员会建议你：先做几次呼吸、联系家人、马上去急诊、或转介到本地精神卫生资源。
4. **结束**：你可以随时挂电话；如果是危机状态，接线员可能会多聊一会儿、确认你安全后再结束。

**关于保密：**
- 心理热线通常**遵守保密原则**，不会把你的话告诉单位、家人。
- **例外**：当接线员判断你（或身边人）有即刻生命危险时，他们会按规范联系紧急救援——这不是"告密"，是救命。提前知道这一点，到时候不会觉得被背叛。

**你可以说什么：**
- 不用组织语言，想到哪说到哪；
- 可以哭、可以沉默、可以说"我也不知道怎么说"；
- 不必报真实姓名。

## 八、紧急情况下的行动清单（可截图保存）

**身体突发急症（胸痛/晕厥/呼吸困难）：**
1. 停下手里的事，坐下或半躺；
2. 拨 **120**，说清地址和症状；
3. 通知一位家人/朋友尽快到你身边；
4. 不要自行开车、不要临时吞别人的药。

**心理危机（撑不住/有自伤念头）：**
1. 不要独处——立刻给信任的人发消息；
2. 拨 **12356** 先聊；念头很具体就拨 **120** 或直接去精神卫生中心急诊；
3. 不要饮酒、不要自行加药/停药；
4. 在专业人员指导下，让信任的人帮忙移除眼前危险物品。

## 九、家属 / 旁观者：该做与不该做

| ✅ 该做 | ❌ 不该做 |
|---|---|
| 平静、直接地问："你是不是有过不想活的念头？有没有计划？" | 回避不谈、假装没事 |
| 胸痛晕厥时立刻帮他拨 120 | 说"你就是焦虑，别吓唬人" |
| 陪着他，不离开他独自待着 | 让他一个人"静静" |
| 帮他拨 12356 / 联系医生 / 去急诊 | 承诺"我替你保密"（安全比保密重要） |
| 认真倾听，不评判、不说教 | 指责、羞辱、比较"别人比你惨" |
| 告诉他"你的安全对我很重要，我们一起找办法" | 轻视、说"这点小事至于吗" |

> 你不需要"会心理辅导"。**在场、稳定、不评判、帮他联系人、该叫救护车时立刻叫**——就已经是极大的帮助。
