# 1. 药物治疗

> 焦虑障碍是一种有生物学基础的疾病，药物能帮你把过度激活的"警报系统"调回正常，但它不是"快乐药"，也不是吃了立刻见效的开关。本页只介绍药物类别、起效规律、常见反应与用药原则，**不涉及任何具体剂量、疗程天数与换药方案**——你吃哪种、吃多少、怎么停，必须由精神科医生根据你的情况决定。本资料库仅作健康知识参考，不能替代精神科医生面诊与诊断，不用于自行调药、确诊。

## 一、先建立几个正确预期

【临床共识】焦虑障碍（广泛性焦虑、惊恐障碍、社交焦虑、场所恐惧等）有其生物学基础：大脑的威胁检测系统（涉及 5-羟色胺、去甲肾上腺素、γ-氨基丁酸等神经递质）过度敏感，长期处于"拉响警报"的状态。药物针对的是这个**失调的系统**，而不是你的性格。

- 药物不是"给你灌快乐"，而是**把焦虑强度降下来**，让你有精力去做心理治疗、调整生活。
- 多数人需要的是"药物 + 心理治疗 + 生活调整"的组合拳，单用或联合由医生评估。
- 【研究结论】规范治疗下，多数焦虑障碍患者的症状会明显改善、生活功能恢复。即使第一种药效果不理想，也有换用、联合等多条路，不要因为一次效果不好就认定"药对我没用"。

【个人体验】很多人第一次拿到药盒时会紧张："我是不是一辈子都要吃药了？""会不会上瘾？"——后面"用药常见顾虑"一节会专门客观回答。

## 二、常见抗焦虑/抗抑郁药物类别与代表通用名

下面只列**类别和通用名**，帮助你看懂医生处方和药品说明书，不代表你应该自行选用。

| 类别 | 代表通用名 | 大致特点与提示 |
|---|---|---|
| SSRI（选择性5-羟色胺再摄取抑制剂） | 艾司西酞普兰、舍曲林、帕罗西汀、氟西汀、氟伏沙明、西酞普兰 | **一线首选**，对广泛性焦虑、惊恐、社交焦虑、场所恐惧均有效；起效需数周；不同人对其中某一种反应差异较大，常需试选 |
| SNRI（5-羟色胺与去甲肾上腺素再摄取抑制剂） | 文拉法辛、度洛西汀 | **一线选择**，对伴躯体不适、疼痛、乏力的焦虑有时更合适；文拉法辛部分人血压会轻度升高 |
| 5-HT1A 部分激动剂 | 丁螺环酮、坦度螺酮 | 专门用于广泛性焦虑，不成瘾、镇静轻，但起效慢、对惊恐效果有限 |
| 苯二氮䓬类 | 阿普唑仑、劳拉西泮、氯硝西泮、地西泮等 | **起效快**，能快速镇静；但长期使用可产生依赖与耐受，有嗜睡、跌倒风险，不可与酒精同用，**不可自行突然停用**。医生通常短期、按需、有限使用（详见后文） |
| 非苯二氮䓬类催眠药 | 唑吡坦等 | 主要用于短期助眠，不是抗焦虑主药，同样不宜自行长期连续使用 |
| 三环类等老一代抗抑郁药 | 氯米帕明、阿米替林、多塞平等 | 疗效确切，但副作用（口干、便秘、心慌、体位性头晕）较多、过量危险，现多作为二线或特定情况使用 |
| β受体阻滞剂 | 普萘洛尔等 | 不治疗"心里的焦虑"，但能减轻**躯体性表现**（心跳过快、手抖、声音发颤），常用于演讲、临场表演前的"表现焦虑"，是否适合需医生评估 |
| 其他 | 曲唑酮（常利用其镇静助眠）、米氮平等 | 多根据失眠、食欲等伴随症状选择 |

【临床共识】**不推荐你自行使用**抗组胺药（如某些"安神"西药）、中成药、保健品来"治焦虑"。NICE 等指南明确指出，镇静类抗组胺药不应用于惊恐障碍的长期治疗；中成药、保健品成分复杂，可能与处方药发生相互作用，想用必须先告诉医生。

【争议观点】"是药三分毒，能不吃就不吃"是很多人的本能。但客观看：中重度焦虑长期不治疗，本身会损害睡眠、工作、人际关系，并增加共病抑郁的风险；在医生指导下规范用药的收益，通常大于可控的副作用。

## 三、起效规律：最容易让人半途而废的一关

这是本页最重要的一节，请耐心读完。

| 时间窗 | 通常发生的变化 | 你的正确做法 |
|---|---|---|
| 服药最初几天～1周 | 几乎感觉不到焦虑下降；反而可能出现恶心、头晕、犯困，或短暂的焦虑/坐立不安加重 | **不要急着停药**。这是身体在适应，尤其 SSRI/SNRI 初期可能短暂"闹一下" |
| 约2–4周 | 紧张、心慌、入睡困难等可能先开始松动；情绪的改善往往滞后 | 坚持按医嘱服药，记录身体反应 |
| 约6–8周 | 多数人在此阶段才能较充分地评估这一种药是否对症 | 复诊，由医生判断疗效与是否需要调整 |

【临床共识】SSRI/SNRI **不是吃了立刻平静的药**。它通常在数周内逐步起效。"吃了一两周没感觉就停"是最常见、也最可惜的做法——往往在药快要起效时被停掉。苯二氮䓬类则相反，起效以"分钟~小时"计，但正因如此才要警惕依赖，不能把它当长期主力。

## 四、副作用：短期不适 vs 必须尽快告诉医生

副作用个体差异很大，**多数早期不适会在1–2周内自行减轻**，不要因轻微反应就自行停药。但你要能分清"忍一忍会过去"和"必须马上说"。

### A. 短期常见不适（多在1–2周内逐渐减轻）

- 轻度恶心（通常随餐或饭后服用可缓解）
- 头痛、轻微头晕
- 口干、轻度腹泻或便秘
- 嗜睡（苯二氮䓬类尤其明显），或相反的轻度失眠
- 服药初期短暂的焦虑、坐立不安感
- 苯二氮䓬类：乏力、反应变慢、走路不稳

### B. 需要在复诊时主动告诉医生（不一定停药，但要被记录和处理）

| 反应 | 说明 |
|---|---|
| 性功能方面的变化（性欲、高潮困难等） | 较常见，尤其 SSRI；很多人不好意思说，但**这是可以和医生讨论、调整的**，不必默默忍受 |
| 体重或食欲明显变化 | 部分药较明显；可结合饮食运动一起管理 |
| 异常多汗 | 部分人会出现 |
| 持续便秘、排尿不畅 | 需医生评估 |
| 血压变化（尤其用文拉法辛者） | 可自我监测，复诊告知 |
| 白天过度嗜睡、走路不稳（尤其老年人） | 与苯二氮䓬类相关，需医生调整，防跌倒 |

### C. 危险信号：出现以下任何一条，尽快联系医生或急诊

| 危险反应 | 典型表现 | 行动 |
|---|---|---|
| **5-羟色胺综合征** | 高热、意识混乱、明显激越、肌肉僵硬或不自主抽动、大汗淋漓、心跳很快 | **立即急诊**，这是急症；常发生在叠加其他升高5-羟色胺的药/物质时 |
| 诱发躁狂/轻躁狂 | 突然异常兴奋、话多、睡眠需要明显减少、冲动消费、觉得自己特别厉害 | **立即复诊**——这提示可能是双相情感障碍，治疗方向会改变 |
| 异常出血/瘀斑 | 无故牙龈出血、黑便、皮肤大片瘀斑 | 尽快就医 |
| 低钠血症 | 老年人体位性头晕、乏力、意识模糊、抽筋 | 尽快就医 |
| 皮疹、过敏 | 服药后新发皮疹，尤其伴发热 | 停药并就医 |
| 心悸、晕厥感 | 尤其用药后新发 | 告知医生，必要时查心电图 |

【临床共识】**5-羟色胺综合征**是焦虑/抑郁用药中最需要警惕的急症之一：如果你在服用 SSRI/SNRI 的同时，自行叠加了圣约翰草（贯叶连翘）、某些感冒药/止痛药、其他抗抑郁药，或短期内加量，出现高热+意识混乱+肌肉僵硬，不要犹豫，立即急诊。

## 五、苯二氮䓬类：把"上瘾"这件事说清楚

这是焦虑患者最常纠结的一类药，单独拿出来客观讲。

- **它的优点**：起效快（分钟到小时级），能快速压下一次严重的惊恐或急性焦虑，让你先"缓过来"。
- **它的代价**：连续使用数周以上，身体会**耐受**（同样效果需要更大剂量）和**依赖**（不吃就难受、睡不着、反跳性焦虑更重）；长期用还可能影响记忆、增加跌倒风险（尤其老年人）。
- **它的铁律**：
  1. **不可与酒精同用**——两者叠加会过度抑制呼吸和中枢，有致命风险；
  2. **不可自行突然停用**——长期用后骤停可能诱发严重戒断（抽搐、剧烈焦虑、失眠）；
  3. 医生通常只让你**短期、按需、有限度**地用它来"救急"，而不是天天长期吃。

【临床共识】所以正确的用法是：苯二氮䓬类像"创可贴"，用来度过急性发作的头几周；真正长期治本靠的是 SSRI/SNRI 这类不成瘾的药，加上心理治疗。等你的长效药起效了，医生会帮你慢慢把苯二氮䓬类减下来。

## 六、用药总原则：足量、足疗程、不擅自停

### 1. 为什么要"足疗程"

焦虑障碍治疗通常分三个阶段（具体时长由医生根据你的发作次数和严重程度决定）：

| 阶段 | 大致目标 | 你需要知道的 |
|---|---|---|
| 急性期 | 控制症状，达到临床缓解 | 通常需要数周～数月，药要吃够、吃对 |
| 巩固期 | 防止症状刚好转就反弹 | 症状消失后**仍需继续服药一段时间**，因为"感觉好了"不等于"病好了" |
| 维持期 | 降低复发风险 | 反复发作、有家族史者，维持治疗更重要 |

【临床共识】很多人"一感觉好转就自己停药"，结果在数月内复发，而每复发一次，未来复发的风险就升高一截。**过早自行停药是复发最常见的人为原因之一。**

### 2. 为什么不能突然停药

抗焦虑/抗抑郁药（尤其 SSRI/SNRI，以及苯二氮䓬类）突然停掉，可能出现：

- **撤药反应**：头晕、像被电击一下的感觉、恶心、类似感冒的不适、烦躁、失眠、情绪波动；
- **反跳**：原来的焦虑、惊恐在停药后比之前更猛烈地回来。

撤药反应本身通常会逐渐过去，但它容易被误读为"我又病了"而慌乱；更重要的是，**突然停药会显著升高复发风险**。

【临床共识】停药必须在医生指导下**缓慢、逐步减量**，给身体适应的时间。哪怕你已经决定要停，也要先和医生约好节奏。

### 3. 漏服了怎么办

- **不要下次自己加倍补吃**，那会增加副作用风险。
- 想起来时若离下次服药还久，按医嘱补服一次即可；若已接近下次服药时间，跳过这次、按原计划继续。
- 记不清、拿不准时，问开药医生或药师，而不是凭感觉加倍。

## 七、相互作用与特殊情况

- **酒精不能代替药物**：酒精让人短暂昏沉，但会破坏睡眠、加重焦虑反跳、与苯二氮䓬类/镇静药叠加抑制中枢，是焦虑康复中的"假放松"。
- **不得自行叠加圣约翰草（贯叶连翘）等保健品**：它会与很多药物相互作用，甚至诱发5-羟色胺综合征。正在服用、打算开始服用任何其他药物、保健品、中成药，都要告诉医生。
- **妊娠、备孕、哺乳**：这是需要医生与孕妇共同权衡的决策——不治疗的中重度焦虑本身对母亲和胎儿也有风险。**如果你在备孕或已怀孕，不要自行停药**，尽快告知医生。
- **老年人**：更易出现低钠、体位性低血压、跌倒，苯二氮䓬类尤其要慎用，起始剂量常更小。
- **合并躯体疾病**（心脏病、高血压、肝肾疾病等）：药物选择需医生个体化权衡，复诊时务必带上完整用药清单。

## 八、用药常见顾虑答疑

| 你的担心 | 客观说明 |
|---|---|
| "会不会上瘾、一辈子戒不掉？" | SSRI/SNRI、丁螺环酮**不属于成瘾性物质**，不会越吃越想要。"需要长期吃"是因为疾病本身容易复发，就像降压药需要长期吃一样，不是成瘾。**苯二氮䓬类才是有成瘾风险的那一类**，所以医生会短期、有限使用。 |
| "吃了会不会变傻、反应变慢？" | 少数人初期会有犯困、思维略钝，多在适应后缓解；焦虑本身才是让人注意力、记忆力下降的原因。规范治疗后，很多人反而觉得脑子更清楚。 |
| "好了不就可以停了吗？" | 恰恰相反——"感觉好转"是治疗起效的信号，但巩固和维持期是用来**防止反弹**的。自行过早停药，是复发最常见的原因。 |
| "我靠自己扛行不行？" | 轻度可尝试心理治疗和生活调整；但中重度焦虑时，"硬扛"常常错过最佳干预期，药物能帮你恢复到有能力做心理治疗和自我调节的状态。 |
| "网上说这药副作用特别吓人？" | 【争议观点】网上把药说得极可怕或极无害都不真实：它确实有副作用和需要监测的风险，但在医生指导下规范使用是安全、成熟的治疗手段。 |

## 九、一张表看懂用药全过程

| 阶段 | 时间感 | 重点任务 | 复诊节奏 |
|---|---|---|---|
| 启动期 | 第1–2周 | 适应副作用、监测初期情绪变化、不漏服 | 按医嘱，有危险信号随时就医 |
| 起效期 | 第2–6周 | 观察紧张/心慌/睡眠变化，记录反应 | 复诊评估 |
| 充分评估期 | 第6–8周 | 判断疗效，决定是否继续/调整 | 复诊 |
| 巩固期 | 症状消失后数月 | 不擅自减停，配合心理治疗与生活重建 | 规律复诊 |
| 维持期 | 反复发作人群 | 长期管理，与医生商定维持时长 | 定期复诊 |

## 十、你可以现在就做的三件事

1. 把正在吃/准备吃的药名（通用名）记在手机里，复诊时主动告诉医生你的身体反应。
2. 告诉一位你信任的家人/朋友你在治疗中，让他在你"想自行停药"时提醒你先问医生。
3. 把开药医生/医院的联系方式存好，尤其是出现危险反应时知道找谁。
