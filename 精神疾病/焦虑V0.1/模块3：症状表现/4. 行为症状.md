# 4. 行为症状

> 焦虑不只是"心里想""身体难受"，它还会**改变你做事情的方式**——回避某些场景、反复确认、拖延、坐立不安、做一些"安全行为"。这一页讲清楚这些行为是什么、为什么它们短期舒服却长期加重焦虑，以及你可以怎么一点点松动它们。本资料库不替代面诊。

## 4.1 最常见的行为表现

### ① 回避行为（avoidance）

【个人体验】最典型的表现：**能不去就不去、能躲开就躲开**。

- 怕惊恐发作 → 不敢一个人出门、不敢坐地铁、不敢去人多的地方；
- 怕当众出丑 → 不发言、不参加聚餐、不接陌生电话；
- 怕高/怕飞虫/怕血 → 绕路、换工作、取消旅行；
- 怕"万一身体出问题" → 不运动、不喝咖啡、不看任何健康信息。

【临床共识】**回避是焦虑障碍最核心、最需要被干预的行为。** 它短期让你安全，但长期让你越来越觉得"那个地方/那件事真的很危险"——因为你从来没机会验证"其实我去了也没事"。

### ② 反复确认 / 求保证（reassurance-seeking）

【个人体验】反复去医院做检查、反复问家人"你说我是不是没事""孩子到家了吗回个微信"、反复查手机、反复量血压心率、反复锁门、反复检查煤气。

【个人体验】有患者描述："我明知道刚量过血压，但过 10 分钟不量，心就慌。"

【临床共识】这种行为短期能缓解不安，但**每一次确认都在悄悄告诉大脑"你不确认就不行"**，让下一次的焦虑来得更快。

### ③ 安全行为（safety behaviors）

为了"万一发作时能撑住"，你发展出一些**必须随身携带、必须有人陪、必须坐固定位置**的习惯：

- 出门必须带药、带水、带手机满电；
- 去人多的地方必须有人陪；
- 坐车必须坐靠窗/靠门的位置；
- 不喝任何含咖啡因的东西；
- 旅行必须离医院近。

这些行为本身不是坏事，但**当你觉得"没有它我就一定不行"时，它就成了焦虑的拐杖**——你越依赖，越觉得自己走不了路。

### ④ 拖延（procrastination）

【个人体验】不是懒，是**一想到那件事就心慌**，所以拖到最后一刻：不回邮件、不预约体检、不和领导谈加薪、不处理那个一直绕着你的问题。拖延短期避开了焦虑，但事情一直在那儿，焦虑也一直在。

### ⑤ 坐立不安（psychomotor agitation）

【个人体验】抖腿、转笔、来回走、不停刷手机、咬指甲、扯头发、坐不住。身体在焦虑时需要"放电"，这些小动作是无意识的释放。

### ⑥ 其他可观察的行为变化

- 说话变快、声音发紧、不敢对视；
- 突然结束对话、匆忙离开；
- 失眠导致的白天嗜睡、工作效率下降；
- 饮酒、吸烟、暴食（用物质缓解焦虑，短期有效，长期加重）。

## 4.2 为什么"回避 + 安全行为"是个恶性循环

【临床共识】这是理解焦虑障碍最重要的一个模型，请认真看：

```
遇到害怕的场景（如地铁）
   ↓
焦虑升起："万一我发作了怎么办？"
   ↓
做出回避/安全行为：逃出来 / 让朋友陪 / 反复确认
   ↓
焦虑暂时下降（短期奖励）
   ↓
大脑学到："刚才要是没逃/没人陪，我就完了"
   ↓
下次遇到同样场景，焦虑**更强**，回避更坚决
   ↓
活动范围越来越小，功能越来越受限
```

【个人体验】很多场所恐惧的患者回头看："我一开始只是不敢坐地铁，半年后不敢一个人逛超市，一年后不敢独自下楼取快递。**不是我越来越胆小，是我每一次逃避都在教我的大脑'那个地方真的很危险'。**"

打破这个循环的方法，就是心理治疗里说的**"暴露"**——在安全、可控的前提下，一点点面对你怕的场景，**不回避、不做安全行为**，让大脑自己发现："其实我去了也没事，我当时担心的那件事没发生。"

## 4.3 行为症状自查清单（可打印）

> 用法：最近 1 个月，你有过下面哪些行为？勾选后，在右边写下"它短期让我舒服了，但长期让我____"。

| 行为 | 我有没有（打勾） | 长期让我…… |
|---|---|---|
| 回避某些场景（地铁、人多、发言、出门） | □ | 活动范围越来越小 |
| 必须有人陪才敢做某事 | □ | 越来越依赖别人 |
| 反复去医院/反复做检查 | □ | 不查就慌 |
| 反复问家人"我没事吧/孩子没事吧" | □ | 别人也累，我也没真安心 |
| 必须带某样东西（药、水、手机）才敢出门 | □ | 没带就觉得完了 |
| 不喝任何咖啡/浓茶/能量饮料 | □ | 稍微喝一点就惊恐 |
| 拖延重要事情（体检、谈话、决定） | □ | 事情一直悬着，焦虑一直没走 |
| 抖腿、转笔、来回走、坐不住 | □ | 别人看出来，我更紧张 |
| 靠喝酒/吸烟/吃东西缓解紧张 | □ | 短期放松，长期更糟 |
| 不敢看新闻/不敢聊疾病话题 | □ | 世界在我眼里越来越危险 |

## 4.4 改变行为的第一步：不是"硬扛"，是"分级"

【临床共识】改变回避行为**不是让你立刻一个人坐地铁去市中心**——那会让你更怕。专业的做法是**"分级暴露"**：

1. 列出你回避的所有场景，按 0–100 分打分（0 = 完全不害怕，100 = 想到就惊恐）；
2. 从**分数最低的那件事**开始练习（比如"独自下楼取快递"）；
3. 在治疗师指导下，反复做、不做安全行为，直到焦虑自然下降；
4. 再升级到下一档（"独自走到小区门口""独自坐一站地铁"……）。

这个过程在模块7《渐进式暴露练习》里会展开讲。**重度、伴场所恐惧的患者，强烈建议在 CBT 治疗师指导下做，不要自己硬扛。**

## 4.5 给你的一句话

> **你不是"胆小"，你是被大脑训练成了"遇到危险就逃"的模式。** 这个模式曾经在原始草原上救过人类，但在今天的地铁、会议室、超市里，它过时了。好消息是：**行为是可以被重新训练的**——通过一点点、可控的暴露，你的大脑会重新学到"其实外面没那么危险，我也能应付"。
