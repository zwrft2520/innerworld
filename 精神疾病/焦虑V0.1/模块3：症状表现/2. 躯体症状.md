# 2. 躯体症状

> 这是**绝大多数患者最先感受到、也最容易被吓住**的一组症状。心慌、胸闷、气短、手抖、出汗、头晕、肠胃不舒服、肌肉紧绷、失眠、疲惫、尿频……它们像真的得了心脏病、胃病、甲亢一样，但跑到心内科、消化科查了一圈，结果都"基本正常"。
>
> 这一页要做两件事：①把焦虑引起的躯体不适系统列出来，让你知道"原来这些都是焦虑的表现"；②**划一条安全红线**——第一次出现剧烈胸痛、胸闷、心悸、晕厥、呼吸困难，尤其伴放射痛、冷汗、既往心脏病史，**必须先急诊或心内科排查躯体疾病**，不能一律自我归因为焦虑。本资料库不替代面诊。

## 2.1 为什么焦虑会引起这么多躯体不适？

【临床共识】焦虑时大脑启动"战或逃反应"，肾上腺素、去甲肾上腺素大量分泌，全身的血管、肌肉、呼吸、消化、汗腺全部被调动起来。**这些反应在原始人遇到老虎时救他们的命；但在你只是坐在办公室、躺在床上时启动，就变成了让人难受的躯体症状。**

关键的一点是：**这些症状是真实的生理反应，不是"装的"**。你心跳真的快了、手真的抖了、胃真的拧着——只是它们的来源是过度敏感的神经系统，而不是器官本身坏了。

## 2.2 焦虑最常见的躯体症状清单（按系统分类）

### ① 心血管系统（患者最常跑急诊的一组）

| 症状 | 患者典型描述 |
|---|---|
| 心慌、心悸 | "心跳像要从嗓子里蹦出来""能感觉到自己的心在胸口砰砰跳" |
| 心跳重、漏跳感 | "心脏好像停了一拍""重重地撞一下"（多为早搏感） |
| 胸闷、胸口压迫感 | "胸口像压了块石头""喘不上气" |
| 胸痛（位置常游走、尖锐） | "左胸下方刺痛一下""说不上来哪儿疼，就是不对劲" |
| 血压短暂升高 | 焦虑发作时自测血压偏高，缓解后回落 |

### ② 呼吸系统

| 症状 | 患者典型描述 |
|---|---|
| 气短、窒息感 | "像被人捂住嘴""总觉得吸不够气" |
| 过度换气 | 呼吸又快又浅，接着手脚发麻、嘴唇发麻（呼碱） |
| 喉咙哽噎感 | "喉咙像堵了个东西，咽不下去"（常被当成咽炎/梅核气） |

### ③ 神经与运动系统

| 症状 | 患者典型描述 |
|---|---|
| 手抖、嘴唇抖 | "端杯子、签字时手控制不住地抖" |
| 出汗（手心、全身） | "手心一直湿的""半夜醒来一身冷汗" |
| 头晕、头重脚轻 | "脑袋发飘""像踩在棉花上""要晕倒但从没真晕过去" |
| 头皮发紧、头痛 | "头上像箍了个紧箍咒"（紧张性头痛） |
| 肌肉紧绷、酸痛 | "肩颈硬得像石头""后背一直紧着" |
| 不真实感（depersonalization） | "像在看电影""感觉自己不像自己" |

### ④ 消化系统

| 症状 | 患者典型描述 |
|---|---|
| 口干 | "嘴里一直干，喝水也不解渴" |
| 吞咽困难 | "咽东西总觉得卡一下" |
| 胃部不适、恶心 | "胃里拧着""一紧张就想吐" |
| 腹胀、肠鸣、腹泻 | "一要出门就想上厕所"（肠易激常见） |
| 食欲下降 | "心里一发紧，饭就吃不下" |

### ⑤ 泌尿生殖系统

| 症状 | 患者典型描述 |
|---|---|
| 尿频 | "越紧张越想上厕所""刚出来又想进去" |
| 月经紊乱（女性） | 焦虑期月经提前、推后、痛经加重 |
| 性功能下降 | 紧张导致性欲降低、勃起/高潮困难 |

### ⑥ 睡眠与精力

| 症状 | 患者典型描述 |
|---|---|
| 入睡困难 | "躺下脑子就开始放电影，两小时睡不着" |
| 易醒、早醒 | "凌晨三四点醒了，再也睡不着，开始想事" |
| 多梦、噩梦 | "一宿都在跑、被追、赶不上车" |
| 疲惫、没力气 | "睡了跟没睡一样，早上起来更累" |
| 易惊醒 | "一点声音就跳起来" |

## 2.3 【安全红线】这些躯体症状必须先排除躯体疾病

【临床共识】**焦虑会引起真实的躯体不适，但躯体疾病也会伪装成焦虑。** 第一次出现下列情况，请**先急诊或相应内科排查**，不能直接归因为"我就是焦虑"：

| 你的症状 | 需要排查的躯体疾病 | 建议挂的科 |
|---|---|---|
| 突发剧烈胸痛、压榨感、放射到左肩/下颌/后背，伴冷汗、濒死感 | **急性冠脉综合征、心肌梗死** | **急诊、心内科** |
| 心慌、心跳极快（>120次/分）、不规则、持续不缓解 | **心律失常、房颤、室上速** | 急诊、心内科 |
| 胸闷、气短、咳粉红痰、不能平卧 | **心衰、肺栓塞** | 急诊 |
| 头晕、晕厥、说话含糊、一侧肢体无力 | **脑卒中（中风）** | **急诊（120）** |
| 体重明显下降、心慌、怕热、手抖、凸眼 | **甲状腺功能亢进** | 内分泌科 |
| 头晕、站起来眼前发黑、乏力、面色苍白 | **贫血、低血压** | 内科、血液科 |
| 反复发作的位置性头晕（翻身、起床时天旋地转） | **耳石症、梅尼埃病** | 耳鼻喉科、神经内科 |
| 慢性咳嗽、气短、运动耐量下降 | **哮喘、慢阻肺** | 呼吸科 |
| 低血糖、糖尿病前期（心慌、手抖、出汗、饿） | **血糖异常** | 内分泌科 |
| 持续头痛、晨起加重、伴呕吐、视力变化 | **颅内占位、高血压急症** | 神经内科、急诊 |

【临床共识】**特别强调**：如果你是第一次发生"剧烈胸痛 + 濒死感 + 持续不缓解"，**请立刻打 120 或去急诊**，不要按"惊恐发作"自己扛。等医生做完心电图、心肌酶、必要时影像检查，**排除了心脏急症**之后，再考虑焦虑的诊断——这才是对自己负责。

但反过来：**一旦医生已经系统排查过、明确告诉你心脏没问题，以后再发作时你就知道"这是焦虑，不是猝死"**——这种"被排除过"的确定感，本身就能大幅降低发作时的恐惧。

## 2.4 焦虑 vs 需要排查的躯体疾病——快速对照

| 维度 | 焦虑引起的躯体不适 | 真正的躯体疾病 |
|---|---|---|
| 发作诱因 | 常在安静、睡前、压力大时出现；也可毫无预兆 | 常与运动、情绪激动、特定体位相关 |
| 持续时间 | 数分钟到数十分钟自行缓解；或持续"隐隐不舒服" | 不处理通常不自行缓解 |
| 对检查的反应 | 心电图、心肌酶、甲功、影像**基本正常** | 检查有异常（心电图改变、甲功升高、贫血等） |
| 伴随 | 同时有手抖、出汗、喉咙紧、濒死感、怕再发作 | 症状更"单一"、有疾病特征（如放射痛、咳血） |
| 体位/呼吸影响 | 过度换气时手脚发麻；缓慢呼吸可缓解 | 体位变化不改变，缓解药（硝酸甘油）有效 |

【个人体验】很多患者跑了两三年急诊、做了一堆检查，最后被急诊医生建议"去精神心理科看看"。那种感觉一开始是抵触的——"我明明是心脏疼，为什么让我去看心理？"但当他们真的被诊断为惊恐障碍、开始规范治疗后，回头才发现：**原来这两三年反复检查出来的"基本正常"，本身就是答案。**

## 2.5 患者最常问的几个问题

**Q1：我心慌得这么厉害，会不会猝死？**
【临床共识】**单纯惊恐发作本身不会直接致命**。它是神经系统的过度放电，不是心脏的器质性故障。但前提是——**你已经由医生排除了心脏疾病**。没排除之前，请先去查。

**Q2：焦虑会不会把我的心脏/胃/脑子"弄坏"？**
焦虑本身不直接损伤器官。但**长期未治的慢性焦虑**会通过持续升高的皮质醇、血压、睡眠紊乱，间接增加心血管、消化问题的风险。所以治疗的意义不仅是舒服，也是保护长期健康。

**Q3：我这些症状是不是"装"的？**
**不是。** 你的心跳、出汗、手抖、胃肠反应都是真实的生理反应。只是它们的"总开关"（杏仁核-前额叶环路）出了故障，而不是某个器官坏了。

**Q4：为什么我查了一圈都正常，但就是难受？**
这恰恰是焦虑障碍（尤其躯体症状突出的 GAD 和惊恐障碍）的典型表现。医生需要排除所有"会装成焦虑"的躯体疾病后，才能下诊断。多跑几次内科不是浪费，是必要的鉴别过程。

## 2.6 给你的一句话

> **你的身体在诚实地向你报告"我太累了"。** 心慌、胸闷、失眠、肠胃拧着，不是你在装病，也不是器官在坏——是那套保护你的系统，太想保护你了。先让医生帮你把"真的病"排除掉，剩下的，我们一起学怎么让它安静下来。
