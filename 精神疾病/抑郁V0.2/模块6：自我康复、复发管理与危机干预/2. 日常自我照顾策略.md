# 2. 日常自我照顾策略

> 这一页讲的是康复期的"自我照顾"，但请先摆正位置：**它是专业治疗的辅助，不是"靠意志力自愈"的替代。** 如果你正处在严重发作期——连吃饭、起床都困难——请先就医，而不是逼自己"按这页做"。自我照顾的目标，是帮你在治疗之上一点点恢复生活的节奏。

## 一、睡眠管理

抑郁和睡眠常常互为因果：睡不好，情绪更糟；情绪糟，更睡不着。

- **固定起床时间**：比"几点睡"更重要。每天同一时间起来，哪怕前一晚没睡好。
- **早上接触自然光**：起床后拉开窗帘、出门走走，帮生物钟校准。
- **睡前1小时减速**：放下手机、调暗灯光，做一点放松的事。
- **床只用来睡觉**：不要在床上工作、刷手机、焦虑，让大脑把"床=睡觉"重新连起来。
- **睡不着别硬逼自己**：越努力想睡越清醒。躺20分钟还睡不着，就起来做点安静的事，有困意再回床。
- **慎用酒精助眠**：酒精让人昏沉，但会破坏后半夜睡眠，还会加重抑郁、干扰药效。

【个人体验】很多康复者发现，把"起床时间固定"这一件小事做到，整个人的节律就慢慢回来了。

## 二、运动

【研究结论】规律的**有氧运动**（快走、慢跑、骑车等）对轻中度抑郁有明确的辅助改善作用，效果可与一些基础干预相比，长期坚持还能降低复发。

但请注意执行方式：

- **从极小目标开始**：比如"今天出门走10分钟"，而不是一上来定"每天跑5公里"。
- **不要搞"运动打卡羞耻"**：今天没做到，不是失败，明天继续就好。运动是为了照顾自己，不是给自己加一个新的考核。
- **哪怕出门站一站也算数**：动力最低的时候，"穿上鞋下楼"这一个动作就值得肯定。

## 三、饮食

- **规律进餐**：抑郁常让人饥一顿饱一顿，先把"一日三餐"的节奏稳住。
- **血糖稳定**：少吃高糖饮料、精制零食大起大落的刺激，对情绪有帮助。
- **【研究结论】地中海饮食模式**（多蔬果、全谷、鱼类、橄榄油，少加工食品）与较好的情绪状态相关，但这是一种整体饮食结构，**不是某一种"抗抑郁食物"的奇迹**。
- **不过度迷信保健品**：没有单一食物或保健品能治疗抑郁，补剂不能替代药物与治疗。

## 四、社交：最低剂量维持

抑郁时最怕的就是"越退缩越孤独，越孤独越抑郁"。

- **"最低剂量社交"**：不需要强撑着聚会，哪怕每天和一个人说一句话、回一条消息，也是在维持连接。
- **每天一个微小联结**：给朋友发个表情、和邻居点个头、在家人群里冒个泡。
- **不必为"没力气见人"愧疚**：先做到"最低剂量"就够了。

## 五、压力减负与任务拆解

抑郁状态下，一个普通任务都像一座山。方法是把任务切到"小到不可能失败"：

- 不要想"打扫房间"，只想"把这桌上的两个杯子洗掉"。
- 不要想"写完报告"，只想"打开文档写第一句话"。
- **降低决策负担**：穿什么、吃什么这种小事，提前定好、减少反复纠结。
- **允许降低期待**：康复期把标准从"做到最好"调成"做一点就行"，是智慧，不是偷懒。

## 六、正念与呼吸（简单版）

- **3分钟呼吸空间**：停下手里的事——①先觉察此刻的想法和感受；②把注意力集中到呼吸上；③再把觉察扩展到全身。一天做几次即可。
- **身体扫描**：躺着，把注意力从脚到头慢慢移过身体，不评价、只观察。这是 MBCT 的基础练习。

【个人体验】正念不是"让脑子放空"（那根本做不到），而是学会"注意到自己走神了，再轻轻拉回来"——这个动作本身就是在练"不被念头卷走"。

## 七、情绪日记模板

每天花2分钟记一笔，情绪会变得可观察、可管理。

| 日期 | 情绪(0–10) | 发生了什么事 | 身体感觉 | 我做了什么 | 今天一件小事 |
|---|---|---|---|---|---|
| 例：10/11 | 4 | 早上被领导说方案要改 | 胸口发紧、肩酸 | 出门走了10分钟 | 楼下的猫蹭了我 |
| | | | | | |
| | | | | | |

## 八、行为激活：愉快事件与成就事件清单

抑郁让人什么都不想做。下面两张表用来"主动安排"，而不是等情绪好了才去做——**往往是先做了，情绪才跟着好起来**。

**愉快事件清单**（做了会让我稍微舒服一点的小事）：
- 例：晒太阳、听某首歌、泡一杯热茶、和朋友聊两句、洗澡、整理桌面……

**成就事件清单**（哪怕很小、但我完成了的事）：
- 例：今天按时起床了、吃了饭、回复了那条一直拖着的消息、出门走了走……

> 做法：每周从"愉快清单"里挑1–2件排进日程，做完在"成就清单"里记一笔。这是行为激活（BA）的自助版。

## 九、防复发生活节律表（参考）

| 时段 | 安排 |
|---|---|
| 起床后 | 固定时间起、见光、喝水、按时服药 |
| 上午 | 做当天最重要的一件"小任务" |
| 午后 | 一次出门活动/运动（哪怕10分钟） |
| 傍晚 | 最低剂量社交：联系一个人 |
| 睡前1小时 | 放下手机、放松、准备睡觉 |
| 每天 | 记一笔情绪日记 |

## 十、给"完全没力气的日子"的最低生存清单

有些日子连"自我照顾"都嫌重。这种时候，只需要做到这五件事，就算胜利：

1. **吃一点东西**（哪怕几口）；
2. **喝够水**；
3. **洗把脸/简单洗漱**；
4. **吃该吃的药**；
5. **联系一个人**（哪怕只发一句"我今天不太好"）。

【个人体验】度过那种日子的诀窍，就是把目标降到"只要活着、基本维持"就好，不要求自己积极、不要求自己进步。熬过去，就是进步。

---

> **再强调一次**：这些方法是帮你康复的"脚手架"，不能替代药物和心理治疗。如果你按这页做了很久仍持续下滑，请回到医生和治疗师那里，而不是独自硬扛。
