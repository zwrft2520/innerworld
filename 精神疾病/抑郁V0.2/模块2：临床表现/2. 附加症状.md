# 2. 附加症状

> 上一页讲了两条核心症状。这一页讲的是"除此之外，抑郁还会怎么折腾你"——它们分成认知、躯体、行为三组。很多患者是**先注意到身体或脑子出了问题**，很久以后才意识到"哦，原来是抑郁"。

## 2.1 认知症状：脑子像灌了浆糊

【个人体验】
- **注意力下降**：开会、看一页书，眼睛在看，脑子像隔着一层雾，读了三行不知道自己读了啥。
- **记忆力变差**：刚说过的话、刚放的钥匙，转头就忘；工作中开始出错，自己都吓一跳。
- **决策困难**：中午吃什么、回不回这条微信，都要纠结半小时——不是选择多，是**做决定的力气没了**。
- **自责自罪 / 无价值感**："都是我的错""我是家里的负担""我什么都做不好"——这些念头根本停不下来，哪怕客观上你做得还行。
- **悲观**：看什么都先想到最坏的结果，觉得"未来不会好了"。
- **思维迟缓**：别人问话，你要缓好几秒才能组织出一句完整的话。
- **反复想到死亡**：不是立刻要做什么，而是"活着到底有什么意思"这类念头反复冒出来。

【临床共识】这些认知症状不是你"变笨了"，而是前额叶功能下降、反刍思维过度活跃的表现——**治疗起效后，它们通常是最先改善的一组**。

## 2.2 躯体症状：它真的会让身体疼

【个人体验】抑郁最容易被忽视的一面，就是它**披着身体的外衣**：

| 躯体症状 | 典型感受 |
|---|---|
| **睡眠紊乱** | 最常见是**早醒**（比平时早醒 2 小时以上，且再也睡不着）；也有人反过来整天嗜睡 |
| **食欲改变** | 明显下降（吃不下）或明显上升（尤其想吃甜食、碳水） |
| **体重变化** | 一个月内体重变化超过 5%（非刻意减肥/增重） |
| **乏力疲惫** | 睡了 10 小时还是累，像"被抽走了电" |
| **不明原因疼痛** | 头痛、颈肩痛、背痛、全身游走性疼痛，检查无器质性问题 |
| **肠胃不适** | 胃胀、便秘、腹泻、食欲差 |
| **性欲下降** | 明显减退 |
| **女性月经紊乱** | 周期、经量改变 |

【临床共识】**早醒**是抑郁非常有特征性的睡眠信号；而"查不出毛病的躯体不适"是中国患者最先跑到综合医院各科室的原因——消化科、心内科、中医科、神经内科跑一圈，最后才被建议到精神心理科。

## 2.3 行为症状：你能看出来的那些"不对劲"

【个人体验】
- **行动 / 言语变慢**：走路、说话、回消息都慢半拍；家属可能觉得"他最近怎么木木的"。
- 也有人反过来表现为**激越**：坐不住、来回踱步、手抖、无法安静。
- **回避社交**：以前爱聚会，现在推掉所有邀约，"不想见人，怕被问东问西"。
- **拖延**：一件小事拖一周，不是懒，是启动不了。
- **自我封闭**：把自己关在房间里，窗帘都不想拉开。
- **个人卫生变差**：不洗澡、不换衣服、胡子好几天不刮——不是邋遢，是**连照顾自己的力气都没有了**。

【个人体验】这一段特别想对家属说：**别把这些行为理解成"他就是不想好""他懒""他针对我们"**。这是病在消耗他的能量。

## 2.5 一个重要的提醒

【个人体验】如果你的主诉是"我就是睡不好、胃不舒服、头疼"，跑了几个科都没查出问题——**请认真考虑去精神心理科聊一次**。这不是说你"想多了"，而是抑郁的躯体化在中国患者身上太常见了，早识别就能少走很多弯路。
