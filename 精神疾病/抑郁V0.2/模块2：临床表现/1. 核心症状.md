# 1. 核心症状

> 这一页写给"正在经历的人"。抑郁的核心症状只有两条，但它们会以非常不同的样子出现在每个人身上。读它不是为了让你给自己确诊，而是帮你把"我说不清楚到底怎么了"那种感觉，翻译成可以被医生听懂的话。

## 1.1 两条核心症状（诊断标准里最关键的两条）

### ① 持续的情绪低落、悲伤、空虚或麻木

【个人体验】不是偶尔难过一下，而是**像穿了一件湿棉袄**——沉、冷、脱不下来。有人会哭，有人反而哭不出来，只是觉得心里"空了一块""麻麻的"。还有人（尤其是男性）不表现为悲伤，而是**易怒**：一点小事就烦、看谁都不顺眼、对家人没耐心。

> "我不是懒，也不是故意摆脸色。我就是连起床、刷牙、回一条微信，都要在心里给自己做半小时动员。"——这是很多患者的真实独白。

### ② 快感缺失 / 兴趣减退（Anhedonia）

【个人体验】最有代表性的一句话是：**"我理智上知道以前我喜欢这个，但现在……感觉不到了。"** 以前追的剧、爱吃的东西、想见的朋友、喜欢的游戏，全都变成"哦"。不是不想开心，是"开心"这个按钮好像被拔掉了。

【临床共识】这两条是诊断抑郁发作的**必要条件**：DSM-5 要求在**至少连续 2 周**里，几乎每天的大部分时间都存在其中至少一条（临床实践中通常要求同时有这两条，或其中一条加明显的功能损害），并且造成显著的痛苦或社会功能受损。

## 1.2 为什么"外表看着没事"不能排除抑郁

【个人体验】很多患者是"微笑型"的——白天能上班、能打招呼、甚至能开玩笑，回家却瘫在沙发上连饭都不想吃。身边人说"你看着挺好的啊"，但只有你知道，那层壳下面有多累。

【临床共识】抑郁不是靠"脸上有没有笑"来诊断的。**能演出来的正常，和真实的内在状态，是两回事。** 外表正常恰恰是很多患者延迟求助的原因之一。

## 1.3 核心症状自查对照表（可打印、可记录）

> 用法：最近两周，每天在心里打个勾。如果某一项"几乎每天大部分时间"都成立，并且已经持续 ≥ 2 周，请认真考虑就医。

| 核心症状 | 我的感受举例（可替换成自己的话） | 最近 2 周是否几乎每天 | 开始日期 |
|---|---|---|---|
| 情绪低落 / 悲伤 / 空虚 | "心里像压着石头""说不上来为什么，就是高兴不起来" | □ 是　□ 否 | ______ |
| 麻木 / 没感觉 | "以前能让我开心的事，现在像隔着一层玻璃" | □ 是　□ 否 | ______ |
| 易激惹 / 没耐心 | "一点小事就想发火，看谁都不顺眼"（尤其男性） | □ 是　□ 否 | ______ |
| 兴趣减退 | "以前喜欢的事，现在连碰都不想碰" | □ 是　□ 否 | ______ |
| 快感缺失 | "吃到以前最爱吃的东西，也没什么味道" | □ 是　□ 否 | ______ |
| 功能受损 | "上班 / 上学 / 做家务 / 照顾自己变得很吃力" | □ 是　□ 否 | ______ |

【个人体验】不必每条都中。哪怕只有"情绪低落"和"兴趣减退"这两条都持续了两周以上，并且已经让你觉得"撑得很辛苦"，就值得去精神科或心理科谈一次——**不必等到"严重到撑不下去"才求助**。

## 1.4 持续时间与"什么时候该去看医生"

【临床共识】一个相对可操作的参考：
- 上述核心症状 **持续 ≥ 2 周**；
- 并且**已经影响**到工作、学习、人际或日常生活；
- 且不能用最近的明确丧失事件（如刚失去亲人）完全解释。

→ 满足这些，建议尽快就诊。

## 1.5 一个必须单独说的红灯：自伤 / 自杀念头

【个人体验】有些患者在低落最重的时候，脑子里会冒出"如果我不在了，是不是大家都轻松""活着没什么意思"这种念头。这是**抑郁这个病本身的症状**，不是你这个人"坏"或者"对不起谁"。

【临床共识】**一旦你出现具体的自伤或自杀计划、或者觉得自己可能控制不住——请立刻行动：**
- 告诉身边一个可信任的人，不要独自待着；
- 拨打全国心理援助热线 **12356**（2025 年起由国家卫生健康委推出的统一心理援助热线），或当地精神卫生中心急诊；
- 情况紧急时直接拨打 120 或前往最近医院急诊。

详细的危机识别与急救步骤，见本资料库模块6"危机识别与急救"专题。
