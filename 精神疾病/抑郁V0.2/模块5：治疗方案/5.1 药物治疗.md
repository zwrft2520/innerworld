# 5.1 药物治疗

> 抗抑郁药是治疗中度至重度抑郁障碍的重要手段之一，但它不是"快乐药"，也不是一次性根治的钥匙。它的作用是逐步把大脑调节情绪的能力拉回正轨，给心理康复和生活重建腾出空间。本页只介绍类别、起效规律、常见反应与用药原则，**不涉及具体剂量与个体化方案**——你吃哪种、吃多少、怎么停，必须由精神科医生根据你的情况决定。

## 一、先建立几个正确预期

【临床共识】抑郁障碍是一种有生物学基础的疾病，不是"想不开""意志力差"。就像高血压需要药物把血压稳住，抑郁也常需要药物帮助神经递质系统（尤其是 5-羟色胺、去甲肾上腺素等）恢复平衡。

- 药物针对的是**疾病本身**，而不是你这个人的性格。
- 多数人需要的是"药物 + 心理治疗 + 生活调整"的组合，单用或联合由医生评估。
- 【研究结论】约三分之二的患者在规范治疗后症状会明显改善；即使第一种药效果不理想，也有换用、联合、增效等多条路可走，不要因为一次效果不好就认定"药对我没用"。

## 二、常见抗抑郁药类别与代表药（通用名）

下面只列**类别和通用名**，帮助你看懂医生处方和药品说明书，不代表你应该自行选用。

| 类别 | 代表通用名 | 大致特点与提示 |
|---|---|---|
| SSRI（选择性5-羟色胺再摄取抑制剂） | 氟西汀、舍曲林、帕罗西汀、氟伏沙明、西酞普兰、艾司西酞普兰 | 目前最常用的一线选择，耐受性较好；不同人对其中某一种反应差异较大，常需试选 |
| SNRI（5-羟色胺与去甲肾上腺素再摄取抑制剂） | 文拉法辛、度洛西汀 | 作用更广，对伴疼痛、乏力的抑郁有时更合适；文拉法辛部分人血压会轻度升高 |
| NaSSA（去甲肾上腺素能与特异性5-羟色胺能抗抑郁药） | 米氮平 | 镇静、食欲增加作用较明显，适合伴失眠、消瘦者；有人会体重增加、白天嗜睡 |
| 三环类/四环类（老一代） | 阿米替林、马普替林、氯米帕明等 | 疗效确切但副作用（口干、便秘、心慌、体位性头晕）较多，过量危险，现多作为二线或特定情况使用 |
| MAOI（单胺氧化酶抑制剂） | 吗氯贝胺等 | 因与食物和药物相互作用多，现已很少常规使用 |
| 新型多靶点药 | 伏硫西汀、维拉佐酮 | 对认知症状、情绪有不同作用谱，性功能影响相对小，价格通常较高 |
| 褪黑素能受体激动剂 | 阿戈美拉汀 | 对睡眠节律紊乱者较友好，需定期监测肝功能 |
| 其他 | 曲唑酮 | 常利用其镇静作用改善睡眠，低剂量时多用于助眠 |
| 植物药 | 圣约翰草提取物（贯叶连翘） | **不是"天然就安全"**：与很多药物（抗抑郁药、避孕药、抗凝药等）相互作用强，可能影响肝脏代谢；若正在服用或打算服用，必须告知医生，切勿与处方抗抑郁药自行叠加 |

【个人体验】很多人第一次拿到药盒时会紧张，担心"一旦开始吃就停不下来"。后面"用药常见顾虑"会专门解释。

## 三、起效规律：最容易让人半途而废的一关

这是本页最重要的一节，请耐心读完。

| 时间窗 | 通常发生的变化 | 你的正确做法 |
|---|---|---|
| 服药最初几天～1周 | 几乎感觉不到情绪变好；反而可能出现恶心、头晕、犯困或焦虑加重 | **不要急着停药**。这是身体在适应 |
| 约2–4周 | 睡眠、食欲、紧张感可能先开始松动；情绪的改善往往滞后 | 坚持按医嘱服药，记录身体反应 |
| 约6–8周 | 多数人在此阶段才能较充分地评估这一种药是否对症 | 复诊，由医生判断疗效与是否需要调整 |

【临床共识】抗抑郁药**不是吃了立刻开心的药**。它通常在数周内逐步起效，而且常常先改善睡眠和焦虑，再改善情绪。"吃了一两周没感觉就停"是最常见、也最可惜的做法——往往在药快要起效时被停掉。

### 治疗初期的自杀风险监测（尤其要重视）

【临床共识】在用药最初的1–2周（以及加量阶段），部分患者——尤其是25岁以下青少年和年轻成人——可能出现一过性的焦虑、激越或自杀念头增多。这不是"药让你更糟"，而是需要被严密观察的窗口期。

- 如果服药后出现"以前没有过的、强烈的想结束自己的念头"，**立即联系医生或复诊**，不要等下次预约。
- 家属在此期间应多留意情绪和行为变化。
- 医生会权衡利弊后决定继续观察、调整剂量或换药。

## 四、副作用：短期不适 vs 必须尽快告诉医生

副作用个体差异很大，**多数早期不适会在1–2周内自行减轻**，不要因轻微反应就自行停药。但你要能分清"忍一忍会过去"和"必须马上说"。

### A. 短期常见不适（多在1–2周内逐渐减轻）

- 轻度恶心（通常随餐或饭后服用可缓解）
- 头痛、轻微头晕
- 口干、轻度腹泻或便秘
- 嗜睡，或相反的轻度失眠
- 服药初期短暂的焦虑、坐立不安感

### B. 需要在复诊时主动告诉医生（不一定停药，但要被记录和处理）

| 反应 | 说明 |
|---|---|
| 性功能方面的变化（性欲、高潮困难等） | 较常见，尤其 SSRI；很多人不好意思说，但**这是可以和医生讨论、调整的**，不必默默忍受 |
| 体重或食欲明显变化 | 米氮平等较明显；可结合饮食运动一起管理 |
| 异常多汗 | 部分人会出现 |
| 持续便秘、排尿不畅 | 需医生评估 |
| 血压变化（尤其用文拉法辛者） | 可自我监测，复诊告知 |

### C. 危险信号：出现以下任何一条，尽快联系医生或急诊

| 危险反应 | 典型表现 | 行动 |
|---|---|---|
| 5-羟色胺综合征 | 高热、意识混乱、明显激越、肌肉僵硬或不自主抽动、大汗淋漓、心跳很快 | **立即急诊**，这是急症 |
| 诱发躁狂/轻躁狂 | 突然异常兴奋、话多、睡眠需要明显减少、冲动消费、觉得自己特别厉害 | **立即复诊**——这提示可能是双相情感障碍，治疗方向会改变 |
| 异常出血/瘀斑 | 无故牙龈出血、黑便、皮肤大片瘀斑 | 尽快就医 |
| 低钠血症 | 老年人体位性头晕、乏力、意识模糊、抽筋 | 尽快就医 |
| 皮疹、过敏 | 服药后新发皮疹，尤其伴发热 | 停药并就医 |
| QT间期延长相关 | 心悸、晕厥感 | 告知医生，必要时查心电图 |

【争议观点】网上常有人把抗抑郁药描述得非常可怕，也有人把它说得毫无副作用。两种极端都不真实：它确实有副作用和需要监测的风险，但在医生指导下规范使用是安全、成熟的治疗手段。

## 五、用药总原则：足量、足疗程、不擅自停

### 1. 为什么要"足疗程"

抑郁治疗通常分三个阶段，时间概念如下（具体时长由医生根据你的发作次数和严重程度决定）：

| 阶段 | 大致目标 | 你需要知道的 |
|---|---|---|
| 急性期 | 控制症状，达到临床缓解 | 通常需要数周～数月，药要吃够、吃对 |
| 巩固期 | 防止症状刚好转就反弹 | 症状消失后**仍需继续服药一段时间**，因为"感觉好了"不等于"病好了" |
| 维持期 | 降低复发风险 | 反复发作、有家族史者，维持治疗更重要 |

【临床共识】很多人"一感觉好转就自己停药"，结果在数月内复发，而每复发一次，未来复发的风险就升高一截。**过早自行停药是复发最常见的人为原因之一。**

### 2. 为什么不能突然停药

抗抑郁药（尤其 SSRI/SNRI）突然停掉，可能出现"撤药反应"：

- 头晕、像被电击一下的感觉
- 恶心、类似感冒的不适
- 烦躁、失眠、情绪波动、易激惹

撤药反应本身通常会逐渐过去，但它容易被误读为"我又抑郁了"而慌乱；更重要的是，**突然停药会显著升高复发风险**。

【临床共识】停药必须在医生指导下**缓慢、逐步减量**，给身体适应的时间。哪怕你已经决定要停，也要先和医生约好节奏。

### 3. 漏服了怎么办

- **不要下次自己加倍补吃**，那会增加副作用风险。
- 想起来时若离下次服药还久，按医嘱补服一次即可；若已接近下次服药时间，跳过这次、按原计划继续。
- 记不清、拿不准时，问开药医生或药师，而不是凭感觉加倍。

## 六、换药、联合用药与增效治疗

如果第一种药效果不好，并不意味着"没救了"。医生可能会考虑：

- **换用另一种不同类别的抗抑郁药**；
- **联合用药**：两种作用机制互补的药搭配；
- **增效治疗**：在抗抑郁药基础上加用小剂量非典型抗精神病药、锂盐等，用于难治性抑郁。

这些决策都涉及相互作用和安全性，**必须由医生评估和实施**，切勿自行叠加网上看到的"组合"。

## 七、相互作用与特殊情况

- **MAOI 与其他抗抑郁药之间换药**，需要一段"清洗期"，否则可能引发5-羟色胺综合征——这也是为什么换药一定要听医生的。
- 避免同时使用其他会升高5-羟色胺的药物/物质（部分感冒药、止痛药、圣约翰草等），用药前先问医生或药师。
- **酒精、违禁物质**会加重抑郁、干扰药效、增加镇静风险，应尽量避免。
- 正在服用、打算开始服用任何其他药物、保健品、中成药，都要告诉医生。

### 妊娠、备孕、哺乳

这是一个需要**医生与孕妇共同权衡**的决策，不能简单说"一定不能吃"或"随便吃"：

- 不治疗的中重度抑郁本身，对母亲和胎儿也有风险（孕期情绪、产后照护能力等）。
- 某些药物在孕期相对更常用，但具体选择必须由精神科 + 产科医生共同评估。
- **如果你在备孕或已怀孕，不要自行停药**，尽快告知医生，一起制定方案。

### 老年、肝肾功能疾病

老年人更易出现低钠、体位性低血压，起始剂量常更小；肝肾功能不全者药物代谢不同。这些都需要医生个体化调整。

## 八、用药常见顾虑答疑

| 你的担心 | 客观说明 |
|---|---|
| "会不会上瘾、一辈子戒不掉？" | 抗抑郁药**不属于成瘾性物质**，不会像安眠药/酒精那样越吃越想要、不吃就 craving。"需要长期吃"是因为疾病本身容易复发，就像降压药需要长期吃一样，不是成瘾。 |
| "吃了会不会变傻、反应变慢？" | 少数人初期会有犯困、思维略钝，多在适应后缓解；抑郁本身才是让人注意力、记忆力下降的原因。规范治疗后，很多人反而觉得脑子更清楚。 |
| "会不会发胖？" | 不同药差异大（米氮平等较易增重）。体重可通过饮食、运动管理，且这一顾虑可以在选药时就和医生沟通。 |
| "好了不就可以停了吗？" | 恰恰相反——"感觉好转"是治疗起效的信号，但巩固和维持期是用来**防止反弹**的。自行过早停药，是复发最常见的原因。 |
| "我靠自己扛行不行？" | 轻度可尝试心理治疗和生活调整；但中重度抑郁时，"硬扛"常常错过最佳干预期，药物能帮你恢复到有能力做心理治疗和自我调节的状态。 |

## 九、一张表看懂用药全过程

| 阶段 | 时间感 | 重点任务 | 复诊节奏 |
|---|---|---|---|
| 启动期 | 第1–2周 | 适应副作用、监测初期情绪变化、不漏服 | 按医嘱，有危险信号随时就医 |
| 起效期 | 第2–6周 | 观察睡眠/焦虑/情绪变化，记录反应 | 复诊评估 |
| 充分评估期 | 第6–8周 | 判断疗效，决定是否继续/换药 | 复诊 |
| 巩固期 | 症状消失后数月 | 不擅自减停，配合心理治疗与生活重建 | 规律复诊 |
| 维持期 | 反复发作人群 | 长期管理，与医生商定维持时长 | 定期复诊 |

## 十、你可以现在就做的三件事

1. 把正在吃/准备吃的药名（通用名）记在手机里，复诊时主动告诉医生你的身体反应。
2. 告诉一位你信任的家人/朋友你在治疗中，让他在你"想自行停药"时提醒你先问医生。
3. 把开药医生/医院的联系方式存好，尤其是出现危险反应时知道找谁。
