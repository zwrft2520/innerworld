# B 参考文献与指南版本

这一页列出本资料库主要依据的指南、机构文件与量表原始文献，说明每条来源的用途、年份和证据分量，也说明版本记录和“怎么判断信息过时”。
它写给想追根问底的患者和家属，也写给需要核对引用是否可靠的同道。
读完之后，你应该能判断：**某一条说法是“指南明确推荐”，还是“临床常见做法”，还是“还在研究阶段”。**

## 这份清单怎么用

本资料库不是论文，不在每句话后面挂引用。做法是：**正文用方括号标签标出信息的分量，来源集中列在每篇末尾和这一页。** 所以你看到一条说法时，可以按三步核对：

1. 看标签：是【指南】【研究】【临床经验】【待验证】还是【个人体验】。
2. 回到这一页，找对应的来源，看它的年份和用途是否覆盖这条说法。
3. 如果标签和来源不匹配（比如标了【指南】却找不到对应指南），**按更低的分量看待它**，并向维护者反馈。

这样做的好处是正文可读，坏处是个别句子没有精确到页码。**对精确性要求高的场合（写论文、做患教材料、医疗决策），请直接查阅原始指南，不要以本资料库为最终依据。**

## 逐条说明

**NICE CG113。** 这是本资料库在“成人广泛性焦虑与惊恐障碍”上最主要的指南依据。它按病情严重程度给出分层路径：轻度优先心理治疗（尤其是 CBT）、中重度考虑药物与心理治疗联合、苯二氮䓬类只建议短期使用，对抗精神病药用于焦虑也持保留态度，不列为常规一线。【指南】

**NICE CG159。** 社交焦虑障碍的专门指南，核心推荐是结构化的 CBT（含暴露与注意力训练），药物方面推荐 SSRI（尤其是舍曲林、艾司西酞普兰一类），并建议不要用苯二氮䓬类长期治疗社交焦虑。【指南】

**《中国焦虑障碍防治指南（第二版）》（2023）。** 国内临床实践最主要的参考，覆盖评估、药物治疗、心理治疗、特殊人群和长期管理，用药习惯与国内可及性比 NICE 更贴近实际。引用时注意：**指南版本会影响推荐，第二版与第一版之间已有变化，不要混用。** 具体分级方法见该书方法学章节。

**NICE NG222。** 本资料库只在“焦虑合并抑郁”的语境下引用它，因为抑郁与焦虑常同时出现，治疗顺序和药物选择会互相影响。**它不是焦虑障碍指南，不能拿它替代 CG113。**

**WHO 与 NIMH。** 两者都是面向公众的机构材料，适合用来说明“焦虑障碍常见、可治疗”这类总体判断，**不适合用来支撑具体用药方案**。它们的页面会随网站改版更新，引用时应记录访问日期。

**DSM-5-TR 与 ICD-11。** 两套国际诊断分类，条目和阈值不完全一致。DSM-5-TR 是 2022 年的文本修订版，ICD-11 在 2019 年世界卫生大会通过、2022 年生效。**本资料库的描述以临床常见表述为主，不逐条复述诊断标准**；需要精确对照时请查原书。

**《中华人民共和国精神卫生法》。** 只用于说明原则：住院治疗以自愿为原则、隐私与人格尊严受保护、不得歧视、心理咨询人员不得从事精神障碍的诊断和治疗。**本资料库不提供法律意见**，条文会修订，具体问题以现行法律文本和当地主管部门答复为准。

**12356。** 国家卫生健康委统一部署的心理援助热线，2025 年起在全国推行。它能提供心理支持、危机干预和转介，**但不是急救系统**，不能派车、不能保证定位。地方还有各自的热线，**号码与服务时间以当地卫健委公布为准**。

**量表原始文献。** GAD-7（Spitzer 等，2006）、PDSS（Shear 等，1997）、LSAS（Liebowitz，1987）、SPIN（Connor 等，2000）、SCARED（Birmaher 等，1997）。本资料库只引用量表名称与作者年份，不复刻完整条目，**也不建议读者自行用这些量表下诊断**。

## 证据等级怎么读

“证据等级”不是一个统一的标尺，不同机构的分法不一样。读的时候抓住两件事：**证据质量**（这个结论有多可靠）和**推荐强度**（值不值得照着做）。

| 层级 | 大致含义 | 在本资料库中的标签 |
|---|---|---|
| 指南推荐 | 系统检索证据后形成的规范建议，通常标注推荐强度 | 【指南】 |
| 系统综述与 Meta 分析 | 把多个研究合起来算，结论比单项研究稳 | 【研究】 |
| 随机对照试验 | 能说明“因果”，但受人群、疗程、实施质量限制 | 【研究】 |
| 观察性研究 | 能说明“相关”，不能直接说明“因果” | 【研究】或【待验证】 |
| 专家意见与临床常规 | 有经验基础，缺少高质量对照研究 | 【临床经验】 |
| 机制推测与小样本研究 | 提示方向，尚不足以指导决策 | 【待验证】 |

几点提醒：

- **指南之间会不一致。** NICE 更强调成本效果和分级路径，国内指南更贴近本地用药习惯与可及性。不一致时，不要把两边的话混着用。
- **“有研究支持”不等于“指南推荐”。** 很多干预有小型试验支持，但还没进入指南，这类信息只适合作为和医生讨论的素材。
- **推荐强度弱，不等于没道理。** 它往往意味着“证据还不够硬，或者要看个体情况”。
- **GRADE 只是方法之一。** NICE 在方法学上借鉴 GRADE 思路，区分证据质量与推荐强度；国内指南多采用自己的分级体系。**具体分级以各指南的方法学章节为准，本页只做通俗说明，不复述具体分级表。**

## 怎么判断信息过时

网上关于焦虑的内容，最大的问题不是错，而是“曾经对”。用下面这份清单快速判断：

- [ ] **看年份。** 超过 5 年的治疗推荐要谨慎；药物适应证和安全信息以最新说明书为准。
- [ ] **看它有没有说来源。** 只写“国外最新研究”而不给期刊、作者、年份的，基本无法核对。
- [ ] **看它有没有把话说死。** “根治”“永不复发”“保证有效”“三天见效”——出现这类词，直接降低可信度。
- [ ] **看它是否在卖东西。** 带课程、保健品、仪器购买链接的“科普”，结论往往服务于销售。
- [ ] **看它是否忽略禁忌。** 不谈孕妇、老人、肝肾功能、合并用药的内容，通常不完整。
- [ ] **看指南是否已更新。** 旧版指南的推荐可能已被推翻，比如某些药的一线地位变化、某些联合用药的风险提示。
- [ ] **看诊断分类是否过时。** ICD-10 与 ICD-11、DSM-IV 与 DSM-5-TR 之间，诊断名称和阈值都有变化。
- [ ] **热线与政策类信息要现查。** 号码、医保政策、报销流程都可能调整，**以当地卫健委、医保局最新公布为准**。

## 本资料库刻意不写的内容

为了守住安全边界，以下内容本资料库一律不写：

- **具体剂量方案**：起始剂量、加量速度、减量速度、血药浓度目标。这些必须由医生结合诊断、年龄、体重、肝肾功能、合并用药和既往反应决定。
- **“某药最好”式的推荐**：只比较类别特点，并注明“个体差异大，以处方为准”。
- **自行停药、换药、加量的方法**：包括“怎么自己减苯二氮䓬”这类看似贴心的内容。
- **用保健品、草本、仪器替代规范治疗的建议**。
- **具体报销比例、具体病假天数、具体法律结论**：这些属于地方政策和法律范畴，本资料库只讲原则和办理路径。
- **未经核实的统计数据**：宁可写“目前证据有限”“研究结果不一致”，也不编造数字。

## 免责声明

本资料库是科普材料，**不能替代精神科医生面诊、诊断与处方**。不可依据它判断病情、自行选药、增减或停用药物，也不可依据它处理法律、保险、劳动争议。

所引指南与机构文件的**中文表述为编写者的转述，不是原文翻译**；如与原文冲突，以原文为准。链接可能失效，**失效时请以机构官网的现行版本为准**，并在维护记录里标注“待核”。

如果本资料库的内容与你的面诊医生判断不一致，**以医生的个体化判断为准**，并把差异告诉医生——这往往是一次有价值的沟通。

> **什么时候需要联系医生 / 去急诊**
> 核对资料后发现自己的治疗方案与指南差距较大，想调整用药——**先联系医生**，不要自行更改。
> 出现自杀念头、自伤行为、意识障碍、高热、抽搐、严重过敏、胸痛、晕厥——**立即拨打 120 或去急诊**，这类情况不需要先查资料。
> 情绪上撑不住又暂时约不到医生——可拨打 **12356** 心理援助热线；有立即危险时，120 优先。
