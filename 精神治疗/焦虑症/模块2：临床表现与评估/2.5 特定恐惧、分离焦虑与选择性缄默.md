# 2.5 特定恐惧、分离焦虑与选择性缄默

怕打针怕到晕过去、怕坐飞机怕到取消行程、孩子上学抱着妈妈不撒手、在家里话很多一到学校就一个字不说——这些表现看起来差别很大，但都属于焦虑障碍谱系里“怕得很具体、躲得很明显”的一类。这一页讲三种情况：特定恐惧、分离焦虑、选择性缄默，重点是怎么识别、什么时候该就医，以及为什么“逼一逼就适应了”往往适得其反。

## 一、特定恐惧：怕的对象很明确

特定恐惧是指对某个特定对象或情境产生明显、持续的恐惧，一遇到就几乎立刻紧张，能躲就躲，而且这种恐惧与实际危险不成比例，通常持续6个月以上并影响生活【指南】。

常见的有五类：

| 类型 | 例子 | 特点 |
|---|---|---|
| 动物型 | 狗、蛇、蜘蛛、昆虫 | 常起病于童年，怕被咬、怕突然出现 |
| 自然环境型 | 高处、雷雨、水、黑暗 | 怕失控、怕坠落、怕被困 |
| 血液-注射-损伤型 | 打针、抽血、看到伤口、牙科 | 常出现头晕、恶心、面色苍白，可能晕倒 |
| 情境型 | 飞机、电梯、隧道、开车、幽闭空间 | 怕逃不掉、怕发作、怕出事 |
| 其他 | 呕吐、窒息、生病、玩偶、气球 | 怕特定身体反应或物体 |

**血液-注射-损伤型需要单独说一句**：它和其他类型不同，很多人不是心跳加快，而是先心跳加快、随后血压下降，出现头晕、眼前发黑甚至晕厥。这解释了为什么有人“一打针就晕”。这种情况有专门的应对方法（如应用肌肉紧张法），可以在就诊时请医生或心理治疗师指导，不要靠“硬扛”。

特定恐惧的特点是“知道不合理，但控制不住”。很多人一辈子绕着它走：不坐飞机、不体检、不洗牙、不住高层。只要不影响生活，未必要治疗；但一旦影响健康（比如因为怕针而不去抽血、因为怕电梯而不去复诊），就值得处理。

## 二、分离焦虑：不只是小孩子的事

分离焦虑的核心，是**与依恋对象（通常是父母，也可能是伴侣、孩子）分离时产生过度、持续的痛苦和担忧**。

在儿童身上，常见表现是：

- 离开家、离开父母就哭闹、发脾气、身体不舒服；
- 反复担心父母会出事、会离开自己；
- 拒绝独自睡觉、拒绝去学校、拒绝去朋友家；
- 做与分离有关的噩梦；
- 分离前就表现腹痛、头痛、恶心，甚至呕吐；
- 紧跟、黏人，父母上厕所都要跟着。

要区分“正常的发展阶段”和“障碍”。幼儿在特定年龄出现分离哭闹是正常的，通常会随年龄缓解。判断要看四点：**是否与年龄不相称、是否持续（儿童青少年通常至少4周）、是否造成明显痛苦、是否影响上学和日常生活**【指南】。

分离焦虑也不只发生在儿童。成人也会有，表现为过度担心伴侣出事、不敢出差、不敢独居、孩子上学后坐立不安。成人诊断通常要求持续6个月以上。

## 三、选择性缄默：不是“不想说”，是“说不出来”

选择性缄默是指：孩子在**某些场合能正常说话**（通常是在家里、和最亲近的人），但在**另一些需要说话的场合**（学校、陌生人面前）持续地不说话。注意几个关键词：

- **选择性**：不是完全不会说，而是分场合；
- **持续**：通常至少一个月；入园/入学初期要观察是否持续存在，不能把最初几天的适应困难直接当成选择性缄默；
- **影响**：已经影响学习、社交或日常交流；
- **不是不会**：孩子具备相应的语言能力，也不是故意对抗。

选择性缄默常被误认为“胆小”“没礼貌”“故意不理人”，甚至被老师批评。实际上，它和社交焦虑关系密切，很多孩子同时有社交焦虑的表现，比如回避眼神、僵硬、躲藏、在需要说话时脸红或发抖。它也可能和语言发育、双语环境、入学适应等因素交织在一起。

**最关键的一句话：不要强迫孩子说话。** 被点名、被追问、被承诺“说了就奖励”、被当众比较，往往会让孩子更紧张，把“说话”和“威胁”绑得更紧。有效的做法通常是：先降低压力、建立安全感，再从“能发出声音”“能耳语”“能和一个人说”这样的小步骤开始，由专业人员指导逐步扩展。

## 四、什么时候该就医

| 情况 | 建议 |
|---|---|
| 怕打针、怕狗，但能绕开，不影响生活 | 可以先观察，不必急于治疗 |
| 因为怕而回避必要的医疗（抽血、体检、牙科） | 建议就诊，处理恐惧本身 |
| 孩子分离哭闹，但能上学、能睡觉，几周内缓解 | 多数是发展性，可先支持、观察 |
| 分离焦虑持续一个月以上，拒绝上学、不敢独睡、频繁躯体不适 | 建议儿童精神科或心理科评估 |
| 孩子在某些场合完全不说话，持续一个月以上，影响课堂 | 建议尽快评估，越早干预越好 |
| 成人因分离焦虑无法工作、无法独处 | 建议精神科或心理科评估 |
| 出现晕厥、摔倒受伤、拒食拒水、自伤 | 尽快就医或急诊 |

## 五、不要强迫暴露，以及什么时候该求助

### 为什么“推一把”常常失败

“把他扔进泳池就会游了”“多上台几次就不怕了”“不说话就别回家”——这类做法在短期内可能“逼”出一次行为，但代价往往是更高的恐惧、更强的回避，甚至对帮助者失去信任。

对这三类问题，更稳妥的原则是：

- **分级**：从最不害怕的一小步开始，而不是从最怕的开始；
- **允许退出**：事先说好“难受可以说停”，而不是“必须撑住”；
- **不欺骗**：不偷偷离开、不骗孩子“妈妈在门口”然后走掉，这会破坏安全感；
- **奖励靠近，不只奖励结果**：孩子愿意走到校门口、愿意小声说一个字，都值得肯定；
- **不羞辱**：不说“这么大了还怕”“你看别人都不怕”；
- **专业指导**：暴露不是“硬闯”，具体节奏需要评估后制定。

对选择性缄默，尤其要避免“当众要求说话”。可以先从非言语互动、平行游戏、一对一、短时分离开始，让孩子在安全关系里一点点“出声”。这部分的具体方法属于专业治疗范畴，本页只讲原则。

### 什么时候需要联系医生或去急诊

> **出现以下情况，请立即拨打120或去急诊：**
> - 因恐惧导致晕厥、摔倒、受伤；
> - 孩子长时间拒食、拒水，出现脱水、精神萎靡；
> - 出现自伤行为或自杀念头；
> - 分离时出现剧烈攻击、破坏、走失风险；
> - 服药后出现高热、意识改变、肌肉僵硬。

> **建议尽快到儿童精神科、精神科或心理科门诊：**
> - 孩子持续一个月以上在特定场合完全不说话；
> - 分离焦虑导致长期拒绝上学、无法独睡、频繁腹痛头痛；
> - 成人因害怕分离无法正常工作、无法独处；
> - 特定恐惧已经妨碍必要的医疗、出行或工作；
> - 家长已经尝试多种办法，越劝越糟，亲子冲突加剧。

对儿童问题，**家长先就诊往往比“等孩子愿意”更有效**。医生可以先和家长工作，再安排适合孩子的评估方式。

### 给家长和成人的观察清单

- [ ] 害怕的对象/场合是否明确、是否每次都触发？
- [ ] 是否已经到了“能躲就躲”的程度？躲开了多少生活？
- [ ] 这种害怕持续多久了？有没有超过半年（儿童分离焦虑超过一个月）？
- [ ] 是否出现身体反应：腹痛、头痛、恶心、晕倒、发抖？
- [ ] 孩子在不同场合的说话表现，差别有多大？
- [ ] 家里是否有人长期用“逼”“激”“比”的方式处理？
- [ ] 学校是否了解情况，是否愿意配合调整？
- [ ] 有没有因为这个问题，错过疫苗、体检、上学、旅行？

## 六、常见问题与容易踩的坑

**“孩子就是胆小，长大就好了。”**
有一部分会缓解，但持续回避、拒绝上学、完全不说话，很少靠“等”解决。越早干预，越省力。

**“选择性缄默是不是自闭症？”**
不是一回事，但两者可能同时存在，也可能被混淆。自闭症的核心是社交沟通的持续困难、兴趣狭窄和重复行为；选择性缄默是“分场合不说话”，孩子在其他场合语言正常。判断需要专业评估，不要自行贴标签。

**“分离焦虑是不是家长太宠了？”**
不是简单的“宠”造成的。气质、遗传、生活变动（搬家、转学、二胎、疾病）、养育方式都可能有关。把责任推给家长，通常只会让家庭更不敢求助。

**“特定恐惧必须做暴露吗？”**
不是所有人都需要治疗。影响生活时，暴露是有效方法之一，但要在专业指导下分级进行；血液-注射-损伤型还需要针对晕厥的特殊处理。
