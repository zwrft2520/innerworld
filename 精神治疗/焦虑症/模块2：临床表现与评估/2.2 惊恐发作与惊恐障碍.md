# 2.2 惊恐发作与惊恐障碍

很多人第一次惊恐发作是在地铁上、在开会时、在半夜醒来时：心突然狂跳，胸口像被压住，气吸不进来，手脚发麻，脑子里冒出一个念头——“我要死了”“我要疯了”。几分钟后慢慢缓过来，但那种恐惧会一直留着。这一页讲惊恐发作时身体到底发生了什么、发作的规律、为什么有人会发展成惊恐障碍，以及最要紧的一件事：**怎么区分“又一次惊恐”和“真的躯体急症”**。读完你应该知道发作时能做什么、什么时候必须去医院，以及下一步怎么治。

## 一、惊恐发作是什么：一次“假警报”，但身体反应是真的

惊恐发作是一阵突然出现的强烈恐惧或不适，在几分钟内达到高峰，同时出现一组身体和想法上的症状【指南】。医学上常提到的症状包括：

- **心脏和呼吸**：心悸、心跳很快、胸闷、胸痛、气短、觉得透不过气、哽住感。
- **神经和肌肉**：出汗、发抖、手脚或嘴唇发麻、刺痛、头晕、站不稳、发冷或发热。
- **胃肠**：恶心、腹部不适。
- **感受和想法**：周围不真实、觉得自己不真实、害怕失控或“发疯”、害怕死掉。

一次发作通常至少要有其中四项，才算典型的惊恐发作。但**症状数量不是重点**，重点是那种“突然、猛烈、我控制不了”的体验。

要理解的是：这是身体警报系统的一次误触发。肾上腺素一下子升高，心跳加快、呼吸变快、肌肉绷紧，这些都是真实的生理变化，不是“想出来的”，也不是“矫情”。**身体没有坏，是警报器太敏感了。** 这句话对很多人是有用的，因为它把“我是不是得了绝症”换成了“我的警报系统出了问题，而这是可以治的”。

## 二、一次发作的时间表

知道发作有“形状”，本身就能减轻恐惧。典型的经过大致是这样：

| 阶段 | 大致表现 | 通常持续 |
|---|---|---|
| 前兆 | 一点心慌、胸口发紧、头晕，或完全没有预兆 | 几秒到几分钟 |
| 上升 | 心跳猛地加快，呼吸变浅变快，恐惧迅速升高 | 几十秒到几分钟 |
| 高峰 | 最强烈的恐惧，常伴濒死感、失控感 | 数分钟 |
| 回落 | 症状逐渐减轻，人很累、发抖、想哭 | 十几分钟到半小时 |
| 后遗 | 疲惫、肌肉酸痛、害怕再来一次 | 数小时到数天 |

多数发作在10分钟内达到高峰，通常在数分钟到半小时内缓解，超过1小时还没有缓解的并不常见【临床经验】。夜间发作也常见，人从睡梦中惊醒，心跳剧烈，更容易被误认为心脏病。

**但“通常会缓解”不等于“这次也一定没事”。** 时间表是用来理解发作的，不是用来自我诊断的。

## 三、从一次发作到惊恐障碍

偶尔一次惊恐发作并不等于有病。很多人在一生中经历过一两次，尤其在压力大、睡眠差、咖啡因摄入多的时候。

惊恐障碍的诊断要点是两条【指南】：

1. **反复出现、出乎意料的惊恐发作**（不是只在特定场合才发作）；
2. 发作后至少一个月里，持续担心再次发作、担心发作的后果（比如“是不是心脏病”“会不会死”），或者因为发作而明显改变行为（不敢坐地铁、不敢独自出门、不敢运动）。

注意第二条。**真正把人困住的，往往不是发作本身，而是发作之后开始的“防着它”。** 有人开始随身带药、带水、查最近的医院；有人不敢喝咖啡、不敢运动、不敢一个人待着；有人反复做心电图。这些行为短期能降低恐惧，长期却让大脑更确信“这件事很危险”。

惊恐障碍常和广场恐惧、抑郁、其他焦虑障碍一起出现，也常被误认为心脏病而反复就诊。它通常在青少年后期到成年早期起病，女性更常见，病程容易波动、慢性化。

### 对再次发作的恐惧，和随之而来的回避

惊恐障碍有一个很典型的循环：

1. 一次发作，留下强烈记忆；
2. 开始过度关注身体：数心跳、量血压、注意每一次胸闷；
3. 一点点不适被解释成“要发作了”；
4. 于是回避可能触发的场景：地铁、电梯、超市、电影院、运动、独处；
5. 回避让恐惧暂时下降，但“我其实能应付”的经验再也没有机会出现；
6. 恐惧泛化，生活半径缩小。

这个循环里，**“安全行为”**很关键。安全行为是指那些“觉得不这样做就会出事”的小动作：必须带着药才敢出门、必须坐在靠门的位置、必须有人陪、必须一直喝水、必须查手机信号。它们看起来无害，实际上在告诉大脑：“你一个人确实不行。”

治疗的重点之一，就是逐步减少这些安全行为，让身体重新学到“这些感觉虽然难受，但不会要命”。这部分的具体做法在[5.4 惊恐障碍的CBT与内感受暴露](<../模块5：心理治疗/5.4 惊恐障碍的CBT与内感受暴露.md>)，本页不展开。

## 四、惊恐发作和心脏病，边界在哪里

这是最需要说清楚的一节。**惊恐发作本身通常不致命，但这不能成为忽视胸痛、气短、晕厥的理由。** 下面这张表可以帮助理解两者的典型差别，但它**不能用来给自己排除心脏病**。

| 线索 | 更像惊恐发作 | 更需要警惕心脏问题 |
|---|---|---|
| 诱因 | 常在静息、睡眠中、情绪波动时出现 | 常在活动、劳累、寒冷、情绪激动时出现 |
| 胸痛性质 | 针刺样、位置会变、几秒到几分钟 | 压榨样、闷痛、像被石头压住，持续不缓解 |
| 放射 | 少见 | 可放射到左臂、后背、下颌、上腹 |
| 伴随 | 麻木、过度换气、濒死感、手脚发凉 | 大汗淋漓、恶心、面色苍白、濒死感 |
| 缓解 | 十来分钟到半小时自行缓解 | 休息可缓解，或持续加重 |
| 既往 | 有焦虑史、类似发作史 | 有高血压、糖尿病、吸烟、心脏病家族史 |

问题在于，两者的重叠比想象中大：惊恐发作也会有胸痛、出汗、濒死感；心肌缺血也可能表现为心慌、气短而没有典型胸痛。**所以真正的判断不能靠感觉，要靠风险因素、体格检查、心电图和必要时的化验。**

以下情况，第一次出现就必须按急症处理：

- 首次发作，尤其是40岁以后第一次出现；
- 胸痛剧烈、持续不缓解，或伴大汗、恶心、面色苍白；
- 气短明显，休息也不缓解，或嘴唇发紫；
- 晕倒，或差点晕倒；
- 心跳极快且伴胸痛、头晕、黑朦；
- 有已知心脏病、高血压、糖尿病、吸烟史，或家族早发心脏病史。

## 五、发作时怎么做，什么时候必须就医

### 第一次发作时，可以照着做

- [ ] 先停下来，找个安全的地方坐下或靠墙，不要开车、不要登高。
- [ ] 看一下时间，记住发作从什么时候开始。
- [ ] 如果胸痛剧烈、气短明显、快要晕倒，或这是第一次发作——**直接拨打120**，不要等它自己过去。
- [ ] 如果已经有过多次类似发作、医生也评估过，可以告诉自己：“这是惊恐发作，它会在十几分钟内下去。”
- [ ] 把呼吸放慢，重点是**呼气变长**，不要拼命大口吸气。
- [ ] 把注意力放到外界：说出眼前看到的五样东西、听到的三种声音。
- [ ] 不要做的事：反复量血压、反复查手机、立刻吃别人的药、喝酒压惊。
- [ ] 发作后记一笔：时间、地点、当时在做什么、第一个感觉、持续多久、怎么缓解。

### 什么时候需要联系医生或去急诊

> **出现以下任一情况，请立即拨打120或去最近的急诊，不要先按“焦虑”处理：**
> - 突发剧烈胸痛、胸闷、压榨感，持续不缓解，或放射到手臂、后背、下颌；
> - 突然严重气短、喘不上气、口唇发紫；
> - 晕倒、意识丧失，或差点晕倒伴冷汗；
> - 心跳极快且伴胸痛、头晕、眼前发黑；
> - 第一次出现这样的发作，尤其是中老年人；
> - 发作超过1小时仍不缓解，或一次接一次没有间歇；
> - 出现自杀念头或自伤行为。

> **建议尽快到精神科或心理科门诊：**
> - 反复发作，且发作后一直担心再来一次；
> - 因为害怕发作而回避地铁、电梯、商场、独处、运动；
> - 反复检查心脏，结果正常仍不放心；
> - 随身带药、带水、查医院，生活被“防发作”占满；
> - 合并情绪低落、失眠、喝酒增多。

不确定时，先打 **12356** 心理援助热线，或去急诊做基本检查。**先排除危险，再谈焦虑，顺序不能反。**

## 六、常见问题与容易踩的坑

**“我是不是心脏有问题，只是没查出来？”**
这个担心很常见，也值得认真对待。如果已经做过心电图、心脏超声、动态心电图，医生也结合风险因素判断过，那么“反复检查”本身可能已经成了焦虑的一部分。可以和医生明确问一句：“以我的风险因素，还需要查什么？查完之后，如果结果正常，我们怎么处理这个担心？”

**“发作时我会不会死？”**
惊恐发作本身通常不会造成心脏骤停或死亡【指南】。但这句话不能用来安慰一个第一次发作、有胸痛或晕厥的人——那种情况必须先排除急症。

**“深呼吸是不是一定有用？”**
不一定。对一部分人，刻意大口深呼吸反而会加重头晕和麻木，因为它改变了血液中的二氧化碳水平。更稳妥的是**放慢呼吸、延长呼气**，而不是用力吸气。具体方法在[7.1 呼吸训练与放松训练](<../模块7：物理与辅助治疗/7.1 呼吸训练与放松训练.md>)。

**“是不是不能运动了？”**
不是。运动时心跳加快，容易被误认为“要发作了”，于是有人彻底不动。长期不动会让体能下降，稍微一动就心慌，反而更怕。建议在医生评估心脏没问题后，从低强度开始，逐步恢复。具体见[7.3 运动处方](<../模块7：物理与辅助治疗/7.3 运动处方.md>)。

**“要不要随身带药？”**
有些人短期需要“救命药”带来的安全感，这可以和医生讨论。但长期依赖“必须带着药才敢出门”，会变成安全行为，阻碍康复。用药与停药必须由医生决定，不要自行加减。
