# 6.4 苯二氮䓬类：短期救火与依赖风险

苯二氮䓬类是常说的「安定」类药，吃下去几十分钟就能让人松下来，对急性焦虑、失眠、惊恐发作的即时控制确实有效。但它的代价也很明确：耐受、依赖、戒断、跌倒、认知影响和呼吸抑制。这一页想讲清两件事——它什么时候该用、为什么几乎不该长期用，以及为什么绝对不能自己突然停。适合正在吃这类药、家人长期吃、或者医生刚开了几天的人读。

## 它为什么起效这么快

大脑里有一种叫 GABA 的抑制性信号，作用是「踩刹车」。苯二氮䓬类不直接踩刹车，而是让刹车更好使：它结合到 GABA 受体的特定位点，让同样的抑制信号效果更强。结果是神经系统整体活动下降——紧张感减轻、肌肉放松、困意上来。

正因为作用直接，它见效快，通常几十分钟内就有感觉。也正因为作用广泛，它不只影响「焦虑的那部分脑区」，而是让整个中枢神经系统都慢下来，于是注意力、反应速度、记忆形成、平衡都会受影响。

这一点决定了它的定位：**适合当消防员，不适合当日常供电。**

### 什么时候可以短期用

苯二氮䓬类不是「坏药」，用对了能帮人渡过难关。指南里认可的场景大致是这些。【指南】

- **急性期开路**：焦虑非常重、睡不着、吃不下、无法工作时，先用几天到几周把状态压下来，同时开始用 SSRI 或 SNRI，等后者起效。
- **惊恐发作的临时应对**：在医生指导下按需使用，而不是每天固定吃。
- **躯体疾病或检查操作前**：如影像检查、牙科操作、内镜检查前的镇静。
- **严重失眠的短期处理**：尤其是急性应激导致的失眠，但通常不超过几周。
- **药物调整的过渡期**：换药、加量初期症状波动时短期搭桥。

| 场景 | 是否适合 | 关键限制 |
|---|---|---|
| 急性焦虑、无法入睡的几天 | 适合短期 | 同时启动长期方案，不单独依赖 |
| 惊恐发作按需使用 | 可以，需医生指导 | 频率上升是要警惕的信号 |
| 长期每日服用超过数月 | 一般不建议 | 疗效可能下降，依赖风险上升 |
| 老年人长期助眠 | 尽量避免 | 跌倒、意识混乱、记忆影响 |
| 与酒或阿片类同用 | 避免 | 呼吸抑制风险叠加 |
| 驾驶、操作机器前 | 避免 | 反应速度和判断力下降 |

判断「短期」没有统一数字，但临床上普遍的原则是：**能按需就不每天，能用几天就不拖成几周，能不长期就不长期。** 如果发现自己离不开、减一点就难受，说明已经进入需要处理的阶段。【临床经验】

## 四个容易混淆的概念

很多人把「依赖」「成瘾」「耐受」「戒断」当成一回事，其实不同。

| 概念 | 说的是什么 | 典型表现 |
|---|---|---|
| 耐受 | 同样剂量效果变弱 | 原来半片就够，后来要加量才有效 |
| 依赖 | 身体适应了有药的状态 | 停药或减量就出现不适，渴望继续吃 |
| 成瘾 | 失控性使用、明知有害仍继续 | 自行加量、囤药、多渠道找药、影响生活 |
| 戒断 | 减停后出现的生理反应 | 焦虑反跳、失眠、手抖、出汗、心慌 |

【指南】【临床经验】

依赖不等于成瘾。很多长期服药的人并没有「失控使用」，只是身体适应了，停不下来。但依赖本身也值得认真对待，因为它意味着减药会有难度，需要计划。

还有一个临床上很重要的信号：**两次服药之间出现焦虑、心慌、手抖，吃药后很快缓解。** 这叫「间歇性戒断」，说明身体已经在依赖药物维持，而不是焦虑本身在波动。出现这种情况要主动告诉医生。

## 长期使用的代价

**疗效可能不如从前。** 耐受会让同样剂量越来越不够用，于是有人自行加量，形成「越吃越多、效果越来越差」的循环。

**戒断反应。** 突然减量或停药后，可能出现焦虑反跳（比原来更焦虑）、失眠、易怒、出汗、心慌、手抖、肌肉抽动、感官过敏（声音变响、光线变刺眼）、注意力涣散。**严重时会出现抽搐、意识混乱、幻觉、高热，这是医疗急症，可能危及生命。** 所以苯二氮䓬类不能自行突然停药，这条没有例外。

**跌倒和骨折。** 这类药影响平衡和反应速度，老年人尤其明显。夜间起床上厕所是高风险时刻。髋部骨折对老年人来说后果严重，这是限制长期使用的重要理由。【指南】

**认知影响。** 注意力、工作记忆、学习新东西的能力可能下降，长期使用者的研究结果不完全一致，但「吃药期间脑子发木」是常见的主诉。多数在减停后可以改善，但需要时间。

**呼吸抑制。** 这类药会降低呼吸中枢对二氧化碳的敏感性。对睡眠呼吸暂停、慢性阻塞性肺病、肥胖低通气的人，风险更高。与酒精、阿片类止痛药、其他镇静药同用时，风险成倍上升，严重时可以致命。

**情绪钝化。** 有些人会觉得「不焦虑了，但也没什么感觉」，像隔着一层玻璃。这不等于抑郁，但需要如实告诉医生。

**驾驶与操作风险。** 服药初期、加量后、以及和酒同用时，反应速度和判断力下降明显。这不是「小心一点就行」的问题，而是实实在在地增加事故风险。

## 减停：只能慢慢来

如果你已经吃了几个月甚至几年，想停下来，正确的路径是：

1. **先和医生谈**，说明为什么想停、以前停过没有、停的时候什么感觉。
2. **制定减量计划**，通常是把总量分成若干小步，逐步减少，越到后面越慢。
3. **可能换成作用时间更长的同类药**，让血药浓度更平稳，减少戒断波动。这一步必须由医生做。
4. **配合心理治疗**，尤其是惊恐障碍和广泛性焦虑，CBT 能显著降低停药后的复发。
5. **记录反应**，出现明显不适时联系医生调整节奏，而不是自己恢复原量或硬扛。

减量的速度没有通用答案，取决于用了多久、剂量多大、哪种药、之前有没有戒断史。任何「几周减完」的通用说法都不适合套在自己身上。

### 关于酒精：两个方向的陷阱

- **一起吃**：镇静叠加，呼吸抑制、跌倒、判断力下降的风险明显上升，严重时可致命。
- **用酒缓解戒断**：有些人停药后难受，就用酒来压，结果形成「镇静药加酒精」的双重依赖，戒断风险更高。

如果你正在长期大量饮酒，或者同时用苯二氮䓬类，**不要自己硬戒**。酒精和镇静药的戒断都可能危及生命，需要在医疗监护下进行。

## 清单：正在吃这类药的人可以对照

- [ ] 知道自己吃的是哪一类、为什么吃、计划吃多久
- [ ] 不自行加量，哪怕觉得「今天特别难受」
- [ ] 不自行突然停药，减量前一定先问医生
- [ ] 不与其他镇静药、止痛药、酒同用
- [ ] 服药后不开车、不操作机器
- [ ] 夜间起床先坐一会儿，开灯，慢起身
- [ ] 把药放在固定地方，避免重复服用
- [ ] 复诊时主动说「我最近有没有出现两次服药之间难受」

## 什么时候需要联系医生 / 去急诊

> **尽快联系医生（当天）**
>
> - 需要不断加量才有原来的效果；
> - 两次服药之间出现明显焦虑、心慌、手抖；
> - 白天嗜睡、走路不稳、记忆力明显下降；
> - 情绪变得很平，对什么都提不起兴趣；
> - 计划怀孕或已经怀孕。
>
> **立即去急诊或拨打 120**
>
> - 突然停药或减量后出现抽搐、意识混乱、幻觉、高热、大汗；
> - 服药后呼吸变慢、叫不醒、嘴唇发紫；
> - 与酒或止痛药同用后出现意识障碍；
> - 跌倒后头部受伤、意识改变；
> - 有自杀念头或已经伤害自己。
>
> 戒断引起的抽搐和意识障碍可能危及生命，不要在家「扛一扛」。

### 常见问题

**「吃了几年了，是不是戒不掉了？」** 不是。缓慢减量在多数人身上可以完成，只是需要时间和计划。失败常见的原因是减得太快，而不是「戒不掉」。

**「医生说短期吃，可我吃了半年了怎么办？」** 不要慌，也不要自己停。把这个情况告诉医生，重新评估是否还需要、能不能开始减量。

**「能不能只在特别难受的时候吃？」** 对某些人（如惊恐发作）按需使用是合理的，但频率上升说明需要重新评估整体方案。

**「中药或褪黑素能不能替代？」** 没有可靠证据支持它们能替代苯二氮䓬类的急性作用。突然用保健品替换处方药，可能出现戒断反应。
