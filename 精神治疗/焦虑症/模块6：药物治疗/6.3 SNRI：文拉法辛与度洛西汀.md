# 6.3 SNRI：文拉法辛与度洛西汀

SNRI 是「5-羟色胺和去甲肾上腺素再摄取抑制剂」的缩写。和 SSRI 相比，它多作用了一个系统——去甲肾上腺素，因此除了抗焦虑、抗抑郁，还可能影响疼痛感受、疲劳感和注意力。这一页讲清这类药适合什么人、文拉法辛和度洛西汀有什么不同、要盯住哪些指标、以及为什么不能突然停。文中不写剂量，具体用哪种、用多少，要由医生结合你的血压、心脏、肝肾功能和既往反应来定。

## 这类药在做什么

神经细胞之间靠化学信号传递信息，5-羟色胺和去甲肾上腺素是其中两种。SSRI 主要让 5-羟色胺在突触间隙停留更久；SNRI 同时让这两种递质都停留更久一些。

多出来的这一份去甲肾上腺素作用，带来了两个后果：

- **好处**：对慢性疼痛、疲劳、注意力涣散、动力不足可能更有帮助。去甲肾上腺素参与身体对疼痛信号的「下行抑制」，也就是大脑主动把疼痛调小的能力。
- **代价**：去甲肾上腺素会让心跳加快、血管收缩，所以血压和心率可能上升；也会带来出汗、口干、便秘、排尿不畅。

这也是为什么医生开这类药时，常常会量血压、问心率，而开 SSRI 时不一定会。

### 什么情况下医生会考虑 SNRI

SNRI 也是一线药物，在广泛性焦虑、惊恐障碍、社交焦虑中都有证据，和 SSRI 并列。【指南】实际选择时，下面这些情况更容易倾向 SNRI：

- **焦虑合并慢性疼痛**：如纤维肌痛、糖尿病周围神经痛、慢性腰背痛、紧张性头痛。这是 SNRI 相对 SSRI 最有优势的场景。【指南】
- **焦虑合并抑郁，且疲劳、兴趣减退、动力不足突出**：去甲肾上腺素作用可能对「没劲」有帮助。
- **用 SSRI 效果不充分或耐受不了**：换到 SNRI 是常见策略。【指南】
- **焦虑伴明显躯体症状**：心慌、肌肉紧张、出汗，有些人反应较好，但个体差异大。【临床经验】

反过来，有明显高血压且控制不好、心动过速、心律失常、癫痫、闭角型青光眼、排尿困难（如前列腺增生）的人，医生会更谨慎，或者干脆选别的类别。

| 考量点 | SSRI | SNRI |
|---|---|---|
| 焦虑疗效 | 一线，证据充分 | 一线，证据充分 |
| 慢性疼痛 | 作用有限 | 更有优势 |
| 疲劳、动力不足 | 因人而异 | 可能更有帮助 |
| 血压心率 | 通常影响小 | 可能升高，需要监测 |
| 撤药反应 | 有，程度不一 | 通常更明显，文拉法辛尤甚 |
| 出血风险 | 有轻度增加 | 也可能增加，个体与药物差异大；合并抗凝药或 NSAIDs 时需警惕 |

## 文拉法辛和度洛西汀：同类别，不同脾气

**文拉法辛**的特点是「剂量越高，去甲肾上腺素作用越明显」。低剂量时它更像 SSRI，剂量上去以后才逐渐体现 SNRI 的特点。这解释了为什么有些人加量后感觉「不一样了」，也解释了为什么它的副作用常常和剂量相关。它的半衰期较短，**漏服或突然停药时撤药反应比较明显**，这一点在临床上很受重视。【指南】【临床经验】

**度洛西汀**的作用相对均衡，在慢性疼痛方面的研究较多，常被用于焦虑合并疼痛的情况。它同样可能升高血压，也可能引起恶心、口干、便秘、出汗。对肝功能有一定要求，有肝病或大量饮酒的人需要特别评估。

两者的共同点是：都需要几周才见效；都可能引起撤药反应；都不建议和酒同用；都可能与某些其他药物发生相互作用（尤其是影响肝药酶的药物）。

## 血压、心率和其他常见副作用

去甲肾上腺素作用会让部分人的血压上升、心率加快。特点是：

- 多数人升幅不大，但少数人明显；
- 与剂量相关，加量后更需要注意；
- 治疗前有高血压的人风险更高；
- 通常需要在治疗前量一次血压，治疗中定期复测。

如果本身有高血压，不代表不能用，但需要先把血压控制稳定，并在用药过程中监测。家庭血压计在这个时候很有用：固定时间、安静坐五分钟、量两次取平均，记录下来带给医生看。【指南】

需要警惕的情况：持续头痛（尤其是后枕部）、视力模糊、胸闷、心跳明显加快、鼻出血。这些可能提示血压升高，要尽快测量并联系医生。

### 其他常见副作用

| 副作用 | 表现 | 应对思路 |
|---|---|---|
| 恶心 | 早期明显，饭后可减轻 | 多在几周内缓解，持续不缓解要报告 |
| 出汗 | 夜间或紧张时明显 | 注意补水，勤换衣物 |
| 口干、便秘 | 持续性 | 多喝水、增加膳食纤维，必要时和医生讨论 |
| 头晕 | 起身时明显 | 放慢动作，避免突然站起 |
| 失眠或嗜睡 | 因人而异 | 和医生讨论服药时间 |
| 食欲下降、体重变化 | 早期常见 | 记录体重，明显下降要报告 |
| 排尿困难 | 尿线变细、排尿费力 | 需要报告，尤其老年男性 |

【临床经验】

## 撤药反应、疼痛共病与特殊人群

### 撤药反应：最需要认真对待的问题

SNRI 的撤药反应通常比 SSRI 更明显，文拉法辛尤其如此。原因是它的半衰期短，血药浓度下降得快，身体来不及适应。

典型表现：头晕、恶心、乏力、出汗、焦虑反跳、情绪低落、失眠、多梦、像「触电感」或「脑内电流」的感觉、走路不稳。通常在停药后一两天内出现，程度可能相当难受。

因此有几条原则：

1. **不要突然停**。哪怕觉得「已经好了」，也要和医生商量减量计划。
2. **漏服要尽快补，但不要一次吃双份**。具体怎么处理，按医生或药师的交代。
3. **减量要慢，越到后面越慢**。有些人在最后一段减量时反应最明显。
4. **撤药反应不等于复发**，但两者可以同时发生，判断交给医生。

### 和疼痛共病：这类药的一个实际优势

焦虑和慢性疼痛常常一起出现：长期紧张让肌肉持续收缩，睡不好让疼痛阈值下降，疼痛又反过来加重焦虑。SNRI 在这类「焦虑加疼痛」的组合里有实际价值，因为一种药可以同时照顾两头。【指南】

但要建立合理预期：这类药对疼痛的作用通常是「减轻一部分」，不是「完全不痛」。它也不是止痛药，不会像布洛芬那样半小时见效。通常需要几周，且需要配合运动、睡眠、物理治疗等综合管理。

如果疼痛是新出现的、位置固定、夜间加重、伴随体重下降或发热，要先查清楚原因，不要默认「是焦虑引起的」。

### 特殊人群的提醒

- **老年人**：血压波动、跌倒、低钠的风险更高，起始和调整更保守。
- **心血管疾病**：未控制的高血压、近期心梗、明显心律失常的人，需要先和医生充分讨论。
- **肝脏疾病或长期大量饮酒**：部分药物对肝脏有负担，需要评估。
- **闭角型青光眼、前列腺增生**：可能加重排尿困难或眼压问题，要提前告知医生。
- **双相障碍**：抗抑郁药可能诱发转躁，必须先评估。
- **孕产期**：需要精神科与产科共同权衡，不能自行决定停或继续。
- **青少年**：治疗初期需要密切观察情绪和冲动变化。

## 清单：吃 SNRI 期间可以做的事

- [ ] 治疗前量一次血压和心率，记下来
- [ ] 买一个家用血压计，每周固定时间测一两次
- [ ] 记录漏服情况，不要自行补双份
- [ ] 不突然停药，减量前先联系医生
- [ ] 手术、拔牙、做检查前，说明自己在吃这类药
- [ ] 避免和酒同用
- [ ] 出现持续头痛、胸闷、心跳很快，当天测量血压并联系医生

## 什么时候需要联系医生 / 去急诊

> **尽快联系医生（当天或一两天内）**
>
> - 血压明显升高，或持续头痛、视物模糊；
> - 心跳持续偏快、胸闷、活动后气短；
> - 恶心呕吐持续不止，吃不下东西；
> - 排尿困难、尿不出来；
> - 情绪明显恶化，出现自伤念头；
> - 皮疹、瘙痒。
>
> **立即去急诊或拨打 120**
>
> - 剧烈胸痛、晕厥、抽搐；
> - 高热、大汗、肌肉僵硬或抽动、意识模糊（可能是血清素综合征）；
> - 面部肿胀、呼吸困难、皮疹迅速蔓延；
> - 有明确的自杀计划或已经伤害自己。
>
> 血压高到多少算危险、要不要调药，由医生判断，不要自己加服降压药或停抗焦虑药。

### 常见问题

**「文拉法辛是不是比度洛西汀强？」** 没有这种排序。选择看的是你的症状组合、血压、肝功能、既往反应和耐受情况。

**「吃了以后出汗很厉害，正常吗？」** 常见，多数会随时间减轻。如果伴随心慌、体重明显下降、手抖，需要查甲状腺功能。

**「能不能用来助眠？」** 不合适。这类药可能让人犯困，也可能让人睡不着，且不适合当作安眠药使用。

**「漏服了一次怎么办？」** 想起来就补，但如果已经接近下一次服药时间，跳过即可，不要吃双份。具体按医嘱。
