# 6.1 药物总览：什么情况用药、用什么、用多久

这一页想解决三个最常被问到的问题：什么情况下需要吃药、抗焦虑药大致分几类各站在什么位置、以及药通常要吃多久。它适合刚被建议服药、正在犹豫要不要开始、或者已经拿到处方却看不懂每种药是干什么的人。读完之后，你应该能和医生讨论「为什么选这一类、大概多久见效、计划用多久」，但这里不会给出具体药名和剂量，也不会替你决定该吃哪一种。

## 先纠正一个印象：抗焦虑药不是「镇静剂」

很多人一听要吃药，脑子里出现的是「吃了就迷糊、反应变慢、离不开」。这个印象主要来自苯二氮䓬类，也就是常说的「安定」类。它们确实起效快，也确实有依赖和戒断风险，但只是抗焦虑药里的一类，不是全部。

目前最常用的一线药物是 SSRI 和 SNRI。它们不是当场把情绪压下去，而是通过长期调节 5-羟色胺、去甲肾上腺素等信号分子的传递，让过度活跃的威胁检测回路慢慢降下来。所以它们起效慢，常常要几周，但不会让人立刻「上头」，也不产生苯二氮䓬那种典型的依赖。【指南】

这一点很重要：**「起效慢」不等于「没用」，「吃了没感觉」也不等于「药不对」。** 不少人吃到第二周觉得毫无变化就停了，恰好停在最需要坚持的位置。

### 什么情况该考虑药物

不是所有焦虑都需要吃药。轻度焦虑、有明确诱因、工作生活基本能维持的人，心理治疗（尤其是认知行为治疗）往往是首选，单用心理治疗就够了。【指南】

下面这些情况，医生更可能把药物纳入方案：

- 症状达到中度以上，明显影响工作、学习、睡眠或社交；
- 已经开始回避，生活范围在缩小，比如不敢坐地铁、不敢开会；
- 心理治疗资源排不上、费用难以承担，或认真做过一段时间效果有限；
- 合并抑郁、失眠，或躯体症状特别突出；
- 需要较快控制症状，先恢复基本功能，再补心理干预；
- 以前发作过、有明确复发史，医生判断需要维持治疗。

也有几种情况需要先「等一等」或换个思路：诊断还不清楚；症状可能是甲亢、心律失常、低血糖引起的；每天大量咖啡、酒精或某些药物在维持焦虑；正在备孕或已经怀孕；合并双相障碍（抗抑郁药可能诱发转躁）；以及本人对吃药有强烈顾虑、还没和医生充分谈过。这些都不是「绝对不能用药」，而是「先把前提弄清楚」。【指南】【临床经验】

| 情况 | 首先考虑 | 说明 |
|---|---|---|
| 轻度、功能基本正常 | 心理治疗、生活方式调整 | 单用非药物手段常常已经足够 |
| 中度、功能受影响 | 心理治疗联合药物 | 联合治疗通常优于单用其中一种 |
| 重度、明显受损 | 以药物为主，尽快联合心理治疗 | 先恢复功能，再补心理干预 |
| 合并抑郁或失眠 | 能兼顾两者的药物 | 避免多种镇静类药物叠加 |

## 抗焦虑药物的大类：一张表看清位置

下表只做类别层面的对比，帮助你看懂处方里「这一种是干什么的」。同一类里不同药物差别也不小，具体用哪一种由医生决定。

| 类别 | 主要用途 | 起效速度 | 主要顾虑 |
|---|---|---|---|
| SSRI | 广泛性焦虑、惊恐、社交焦虑的一线 | 数周 | 早期恶心、性功能影响、出汗；停药需缓慢 |
| SNRI | 焦虑合并慢性疼痛、共病抑郁 | 数周 | 血压和心率升高、出汗、撤药反应 |
| 苯二氮䓬类 | 急性期短期救火、检查或操作前 | 数十分钟到数小时 | 依赖、耐受、戒断、跌倒、认知影响 |
| 丁螺环酮、坦度螺酮 | 广泛性焦虑的替代选择 | 一到两周起，数周才充分 | 起效偏慢，对惊恐和表演焦虑证据较弱 |
| 普瑞巴林 | 广泛性焦虑（部分地区获批）、神经痛 | 相对较快 | 镇静、水肿、滥用风险 |
| β受体阻滞剂 | 表演焦虑的躯体症状，按需使用 | 服药后较短时间 | 低血压、心动过缓、哮喘患者不宜 |
| 抗组胺药 | 短期助眠、急性焦虑的辅助 | 较快 | 嗜睡、口干、老年人意识混乱 |
| 曲唑酮 | 助眠、辅助治疗 | 当晚 | 镇静、体位性低血压、心律风险 |
| 三环类 | 二线选择、特定类型 | 数周 | 口干便秘、心脏毒性、过量危险 |
| MAOI | 难治性焦虑、特殊类型 | 数周 | 饮食与药物禁忌多，管理要求高 |

【指南】【临床经验】

看这张表时留意两件事。第一，起效快慢和「好不好」不是一回事：起效最快的苯二氮䓬类，恰恰是最不适合长期用的。第二，副作用一栏写的是「需要留意」，不是「一定会发生」，多数人只会遇到其中一两项，而且常常在几周内减轻。

### 「一线」「二线」这两个词，容易被误读

一线指的是：在多数病人身上，疗效证据最充分、长期使用安全性数据相对多、适用范围最广。它不等于「效果最强」，也不等于「别人吃了好你也一定合适」。

二线也不等于「差」。二线往往是三种情况之一：疗效证据稍弱；只对某类亚型更合适；或者有效但需要更多监测（比如三环类的心电图监测、MAOI 的饮食限制）。有些人在一线药物上反应不好或耐受不了，二线反而是对的那一个。【指南】

## 急性期、巩固期、维持期：药要用多久

「吃到什么时候」是比「吃不吃」更容易被低估的问题。一般把用药分成几个阶段：

| 阶段 | 主要目标 | 大致时间 |
|---|---|---|
| 急性期 | 控制症状、恢复基本功能 | 数周到两三个月 |
| 巩固期 | 把疗效稳住，防止刚好转就反弹 | 症状缓解后数月 |
| 维持期 | 预防复发 | 通常半年到一年以上，部分人更久 |
| 减停期 | 缓慢减量、观察反复信号 | 数周到数月 |

具体多久，看焦虑类型、严重程度、既往复发次数、有没有残留症状、生活压力是否还在。惊恐障碍和广泛性焦虑的维持时间不完全一样，合并抑郁的往往需要更长。【指南】把这张表理解成「大致地图」而不是「合同期限」比较合适。

需要提醒的是：症状好转不等于病程结束。焦虑障碍的复发并不少见，过早停药是常见原因之一。这方面可以配合阅读停药与维持相关的篇目，不要自己掐着日子停。

## 心理治疗和药物，不是二选一

把两者对立起来，是常见的误解，也是很多人吃亏的地方。

- 心理治疗擅长教技能：识别灾难化想法、停止回避、耐受躯体感觉、面对不确定性。这些技能学会了可以带走，停药后仍然有用。
- 药物擅长改状态：在症状很重、睡不着、无法出门、无法工作的阶段，先把状态降下来，人才有力气做心理治疗。
- 联合治疗在中重度焦虑里通常效果更好，这一点在指南里有明确推荐。【指南】

所以真正的问题不是「吃药还是做心理治疗」，而是「现在这个阶段，哪一头更急」。急性期症状压不住，先用药开路；症状稳定了，心理治疗决定能走多远。

### 四条红线：不要自行选药、加量、换药、停药

这四条不是客套话，每一条背后都有具体风险。

1. **自行选药**：别人吃某药效果好，不代表适合你。诊断类型、共病、年龄、肝肾功能、合并用药、既往反应，都会改变选择。
2. **自行加量**：抗焦虑药大多不是「多吃一片好得快」。加量过快会放大副作用，苯二氮䓬类还可能带来过度镇静和呼吸抑制。
3. **自行换药**：不同药物之间怎么换、要不要交叉递减，是有讲究的。直接换可能引起撤药反应或血清素综合征。
4. **自行停药**：抗抑郁药和苯二氮䓬类突然停都可能出现明显不适，苯二氮䓬类突然停还有抽搐风险。必须由医生给减量计划。

## 清单：第一次拿到抗焦虑药处方，可以问这几句

- [ ] 这个药是治什么的，属于哪一类？
- [ ] 大概多久能感觉到变化，早期可能出现哪些副作用？
- [ ] 如果漏服一次，应该怎么处理？
- [ ] 计划用多久，什么时候评估效果？
- [ ] 不能和哪些药、酒、保健品一起用？
- [ ] 出现什么情况要立刻联系您，什么情况要直接去急诊？
- [ ] 如果我以后想停药，应该怎么和您商量？

把答案记在手机备忘录里。复诊时如果换了药，重新问一遍。

## 什么时候需要联系医生 / 去急诊

> **尽快联系医生（当天或一两天内）**
>
> - 服药后出现皮疹、瘙痒、面部或嘴唇肿胀；
> - 明显心慌、坐立不安、出汗发抖，且越来越重；
> - 情绪突然变得很糟，出现自伤念头；
> - 持续呕吐腹泻、吃不下东西，担心脱水；
> - 怀疑自己漏服或重复服药。
>
> **立即去急诊或拨打 120**
>
> - 高热、大汗、肌肉僵硬或抽动、意识模糊、心跳很快（可能是血清素综合征）；
> - 呼吸困难、面唇肿胀、皮疹迅速蔓延（可能是严重过敏）；
> - 晕厥、抽搐、剧烈胸痛；
> - 有自杀念头或已经做出伤害自己的行为。
>
> 如果拿不准算不算严重，按严重处理，宁可白跑一趟。

### 几个常见的坑

**「症状好了就可以停」**：好转通常说明药在起作用，不说明病已经走完。停药时机要单独讨论。

**「西药伤肝伤肾，能不吃就不吃」**：长期不治疗的中重度焦虑同样消耗身体和生活。药物有风险，医生的工作是把风险控制在可监测的范围内。

**「先吃点安眠药顶一顶」**：镇静类药物短期有效，长期会带来耐受和依赖，尤其是老年人。

**「中药或保健品更安全，可以替代」**：目前没有可靠证据支持任何保健品能替代规范治疗，混用还可能增加相互作用。
