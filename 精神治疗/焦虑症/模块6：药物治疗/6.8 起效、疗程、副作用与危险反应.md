# 6.8 起效、疗程、副作用与危险反应

吃上药之后，最折磨人的往往不是副作用本身，而是「不知道现在这样算正常还是异常」。这一页给出一条可对照的时间线：前两周会发生什么、四周该看什么、八周该评估什么；然后讲清哪些副作用可以观察、哪些必须报告、哪些是必须立刻去急诊的危险反应。它适合刚开始服药、正在加量、或者吃药后出现不适不知道要不要停药的人。

## 一条大致的时间线

不同药物起效速度不同，但抗抑郁类抗焦虑药（SSRI、SNRI 等）的节奏大体相似。下面这张表是「大致地图」，不是精确时刻表。

| 时间 | 常见发生的事 | 你该做什么 |
|---|---|---|
| 第 1–3 天 | 恶心、头晕、口干、困或睡不着 | 观察、记录，不急着下结论 |
| 第 1–2 周 | 副作用最明显，焦虑可能短暂加重 | 不自行停药，难受就联系医生 |
| 第 2–4 周 | 睡眠、食欲先有变化，焦虑开始松动 | 继续按医嘱，记录变化 |
| 第 4–8 周 | 疗效逐渐显现，可判断是否有效 | 复诊评估，讨论是否调整 |
| 第 8–12 周 | 多数人达到缓解 | 进入巩固期，不急着减药 |
| 数月到一年以上 | 维持治疗、预防复发 | 和医生一起决定维持多久 |

【指南】

需要强调：**「两周没感觉」是常见现象，不是失败。** 但「两周后越来越糟」也不是正常现象，需要报告。

### 怎么判断「有没有效」

不要只凭「今天心情好不好」下判断。更可靠的做法是看三个层面：

1. **症状强度**：担心是否还那么频繁？惊恐发作次数有没有减少？入睡时间有没有缩短？
2. **功能**：能不能上班、上学、出门、社交？回避的范围有没有缩小？
3. **主观痛苦**：同样的事情发生时，难受的程度有没有下降？

可以用 GAD-7 之类的量表每隔两三周自评一次，看趋势而不是看单次分数。分数下降几分不代表「好了」，分数没变也不代表「没用」，要结合功能一起看。

临床上常说的「有效」，通常指症状明显减轻（比如减轻一半左右）、功能恢复；「缓解」指症状基本消失、功能基本正常。这两个词不一样，治疗目标也不一样。

## 常见副作用：哪些可以观察，哪些要报告

| 副作用 | 常见程度 | 处理方向 |
|---|---|---|
| 恶心、腹泻、胃口差 | 很常见，早期明显 | 饭后服药，多数几周内减轻 |
| 头痛、头晕 | 常见 | 慢起身、多喝水，观察 |
| 口干、便秘 | 常见 | 补水、增加纤维，持续则报告 |
| 出汗增多 | 常见 | 注意补水，多数可耐受 |
| 困倦或失眠 | 常见，因人而异 | 和医生讨论服药时间 |
| 性功能影响 | 常见但少被提及 | 主动报告，有处理办法 |
| 体重变化 | 因人而异 | 记录体重，明显变化要报告 |
| 情绪变平 | 少数 | 如实报告，不要自己忍 |
| 坐立不安、手抖 | 需要留意 | 报告医生，可能需要调整加量速度 |
| 淤青、牙龈出血 | 需要留意 | 报告医生，尤其合并抗凝药时 |

【临床经验】

一个实用原则：**能忍、在减轻、不影响生活 → 观察；不能忍、在加重、影响生活 → 报告。** 但有三类例外，无论轻重都要报告：皮疹、情绪恶化、以及任何自伤念头。

## 需要立刻处理的危险反应

### 血清素综合征

这是 5-羟色胺过度活跃引起的药物不良反应，可能发生在加量、换药、合并其他 serotonergic 药物（包括曲马多、右美沙芬、圣约翰草、某些止吐药）时。

典型表现是三组症状同时或先后出现：

- **精神状态改变**：躁动、意识模糊、坐立不安；
- **自主神经不稳定**：高热、大汗、心跳快、血压波动；
- **神经肌肉异常**：肌肉僵硬、震颤、抽动、反射亢进。

**这是急症，需要立即停药并急诊处理。** 不要在家「观察一晚」。

### 严重过敏

- 皮疹迅速蔓延、瘙痒剧烈；
- 面部、嘴唇、舌头肿胀；
- 呼吸困难、喉咙发紧。

这些可能是严重过敏反应，立即呼叫 120。另外，有些药物会引起更隐蔽的过敏反应（如发热、淋巴结肿大、肝功能异常、大面积皮疹），出现「吃药后莫名其妙发烧、全身不舒服」也要报告。

### QT 间期延长与心律失常

表现为心悸、头晕、晕厥、心跳不规则。有心脏病、电解质紊乱、同时在用其他延长 QT 药物的人风险更高。出现晕厥必须急诊。

### 低钠血症

多见于老年人、用利尿剂的人、大量饮水的人。表现：乏力、头痛、恶心、注意力不集中、走路不稳、意识模糊，严重时抽搐。需要查血钠。

### 出血

SSRI/SNRI 会让血小板聚集能力略降。合并抗凝药、抗血小板药、非甾体抗炎药时风险上升。表现：不明原因淤青、鼻血、牙龈出血、黑便、血尿。

### 转躁

如果既往有双相障碍，抗抑郁药可能诱发躁狂或轻躁狂：睡眠需求明显减少、话多、想法飞快、冲动消费、易怒。出现这些要立即联系医生。

### 自杀风险

治疗初期、加量期、以及情绪突然「变好」（有时是下定决心）时，风险可能上升。任何自伤念头都要认真对待，不要独自承受。

### 一张「危险信号」对照表

| 表现 | 可能是什么 | 该怎么办 |
|---|---|---|
| 高热、大汗、肌肉僵硬、意识模糊 | 血清素综合征 | 立即急诊，拨打 120 |
| 皮疹快速扩散、面唇肿胀、呼吸困难 | 严重过敏 | 立即急诊，拨打 120 |
| 晕厥、心跳不规则 | 心律失常、QT 延长 | 立即急诊 |
| 抽搐 | 低钠、戒断、癫痫 | 立即急诊 |
| 黑便、血尿、大片淤青 | 出血 | 当天就医 |
| 睡眠骤减、话多、冲动 | 转躁 | 尽快联系医生 |
| 自伤念头、计划 | 自杀风险 | 不要独处，急诊或 120 |

## 清单：用药期间的自我记录

- [ ] 每天一句：今天最难受的是什么、大概几点
- [ ] 每周一次：睡眠时长、焦虑对生活的影响（0–10 分）
- [ ] 每两周一次：GAD-7 自评，记录分数
- [ ] 记录漏服、补服、加量、换药的时间
- [ ] 记录同时吃的其他药、保健品、酒
- [ ] 记录出现的副作用和持续时间
- [ ] 复诊前把记录整理成一页纸

## 什么时候需要联系医生 / 去急诊

> **尽快联系医生（当天或一两天内）**
>
> - 副作用明显加重，影响到吃饭、睡觉、上班；
> - 焦虑或抑郁在用药后反而恶化；
> - 皮疹、瘙痒、不明原因发热；
> - 淤青、鼻血、牙龈出血变多；
> - 持续呕吐腹泻、吃不下东西；
> - 计划怀孕或发现怀孕。
>
> **立即去急诊或拨打 120**
>
> - 高热、大汗、肌肉僵硬或抽动、意识模糊、心跳很快；
> - 面部或喉咙肿胀、呼吸困难、皮疹迅速蔓延；
> - 晕厥、抽搐、剧烈胸痛、心跳极快或不规则；
> - 有自杀念头、计划或已经伤害自己。
>
> 不确定时按严重处理。**不要为了「等复诊」而耽误急症。**

### 常见问题

**「副作用这么大，是不是药不对？」** 不一定。早期副作用常见，多数会减轻。是否换药，要等医生评估，不要自己停。

**「吃了两个月，好了一半，算有效吗？」** 算部分有效，值得继续。要不要加量、联合心理治疗，由医生判断。

**「症状消失了，能不能马上停？」** 不能。症状消失通常意味着进入巩固期，过早停药复发风险高。

**「能不能自己加一点，好得快些？」** 不能。加量需要在医生指导下进行，尤其是三环类、苯二氮䓬类和普瑞巴林。
