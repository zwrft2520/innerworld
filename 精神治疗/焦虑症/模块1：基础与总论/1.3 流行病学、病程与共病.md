# 1.3 流行病学、病程与共病

焦虑障碍是最常见的一类精神障碍，但“常见”两个字经常被误读成“轻”。很多人因此拖了很多年才就诊，回头一看，最难受的那几年本来是可以处理的。

这一页讲三件事：谁更容易在什么年龄遇上它；如果不处理，它通常怎么走；以及它为什么经常和别的病一起来。文中不给具体百分比——不同研究的口径差别很大，数字给错方向，比不给更糟。

## 谁更容易遇上：年龄、性别与起病时间

焦虑障碍在人群中相当常见【指南】。它不分城市农村、不分学历收入，但分布并不均匀。

**性别。** 女性被诊断为焦虑障碍的比例普遍高于男性，尤其是广泛性焦虑、惊恐障碍、广场恐惧和特定恐惧；社交焦虑的性别差别相对小一些。这里有真实的生物学差异，也有求助行为的差异：男性更少因为“心里难受”去看医生，更常用喝酒、发火、硬扛来处理，所以统计上的数字可能低估了男性患者。家属如果觉得“男人不会得这个”，容易把问题拖过去。

**起病年龄。** 不同类型的起点不一样，这一点对识别很有用。

| 类型 | 常见起病年龄 | 常见走向 |
|---|---|---|
| 特定恐惧症 | 儿童期多见 | 很稳定，很少自行消失 |
| 分离焦虑障碍 | 儿童期，也可成年起病 | 儿童期治疗后多能缓解 |
| 选择性缄默 | 多在学龄前 | 越早干预越好 |
| 社交焦虑障碍 | 青少年期多见 | 常持续多年，起病越早越易慢性 |
| 惊恐障碍 | 青少年后期到三十多岁 | 可间歇发作，也可长期波动 |
| 广泛性焦虑障碍 | 成年早期多见，也可中老年首发 | 常呈波动性、慢性病程 |

**两个特别要提醒的情况。**

一是老年首次出现明显焦虑。这时候不能默认“人老了就爱担心”，要优先排查躯体疾病（甲状腺、心脏、呼吸、疼痛）、药物副作用（某些激素、支气管扩张剂、兴奋类药物）、抑郁、认知功能下降，以及酒精和镇静药的戒断。

二是儿童青少年的焦虑常不以“我担心”说出来，而是肚子痛、头痛、不想上学、发脾气、黏人。只按“纪律问题”处理，往往越处理越僵。

**文化因素。** 在中文语境里，很多人描述焦虑时说的是“胸闷”“胃不舒服”“脖子发紧”“睡不着”，而不是“我焦虑”。这不代表他们不焦虑，只是表达通道不同。医生问躯体症状，不是绕开心理，而是从你熟悉的入口进去。

## 病程：为什么它容易拖成慢性

焦虑障碍的一个特点是“会自己长大”。不处理的情况下，常见几种走向：

- 波动性慢性：好一阵、坏一阵，遇到压力就加重，几年下来一直在低水平运转。广泛性焦虑常是这种。
- 发作性：一段时间密集发作，之后平静几个月甚至几年，再被某件事点燃。惊恐障碍常见。
- 持续稳定：症状强度变化不大，但一直存在，社交焦虑和特定恐惧常如此。
- 缓解：确实有一部分人不治疗也好转了，尤其在应激源消失、生活条件改善之后。但不能把“有人会好”当成“我可以等”。

影响走向的因素，临床上反复看到这么几条【临床经验】：起病越早、病程越长，越容易慢性；回避范围越广，越难好转；共病越多（尤其合并抑郁、物质使用、人格问题），治疗越复杂；持续的现实压力（照顾重病家人、长期加班、经济困难、家庭冲突）会不断给症状加油；社会支持越弱，恢复越慢。

还有一个常被低估的因素：**延迟就诊**。很多人从第一次明显症状到第一次看精神科，中间隔了好几年。这几年里，回避在扩大，酒量在增加，身体被反复检查，工作机会在流失。焦虑本身不会因为拖延而变成绝症，但拖延会让它更难治。

需要说清楚的是：治疗能改变轨迹。规范治疗后，相当一部分人可以达到缓解，也就是症状基本消失、功能恢复；也有一部分人是明显减轻但仍有残留。焦虑障碍的病程常常是波动的，好转之后遇到压力再次出现，不等于前功尽弃，而是提醒该复查和调整维持方案。关于疗程，可以看 [11.1 为什么要足疗程](<../模块11：疗程、复发与停药/11.1 为什么要足疗程.md>)。

## 功能损害：不只是“心情不好”

焦虑障碍真正消耗人的地方，往往不是那阵心慌，而是它悄悄改掉了你的生活半径。

- **学业与职业**：注意力下降、效率变低、反复检查、拖延、频繁请假、放弃晋升或考试。
- **经济**：收入减少、医疗支出增加、反复做检查、因回避失去机会。
- **人际**：推掉聚会、不敢发言、不敢谈恋爱、怕麻烦别人、逐渐与朋友断联。
- **家庭**：需要家人反复保证、因回避引发争吵、育儿时过度保护。
- **健康服务**：反复就诊、多次急诊、重复检查，既花钱也可能带来不必要的风险。
- **共病风险**：长期焦虑会增加抑郁、失眠、物质使用和心血管问题的风险。

功能损害有一个讨厌的特点：**它很隐蔽，而且会被自己合理化**。“我不太喜欢热闹”“那个会我让别人去”“我开车容易紧张”——每一句都讲得通，加起来就是生活越来越小。

所以在评估严重程度时，功能损害比“症状有几条”更好用。可以问自己三个问题：这半年我放弃了什么？我为了绕开焦虑多花了多少时间和钱？如果我完全不焦虑，我的生活会有什么不同？

## 共病：焦虑很少单独出现

临床上，单纯只有焦虑、别的什么都没有的人并不多。共病不是“病得更多”，而是同一个人的不同问题互相喂养。

| 共病 | 相互影响 | 治疗上要注意什么 |
|---|---|---|
| 抑郁 | 最常见；焦虑久了容易低落，低落又会加重无望和回避 | 需要一起评估，尤其要问自杀念头 |
| 其他焦虑障碍 | 一个人可能同时符合两三种 | 治疗要抓最影响功能的那一条 |
| 酒精与镇静药 | 短期像在帮忙，长期加重焦虑并产生依赖 | 必须如实告诉医生用量，不能自行硬戒 |
| 失眠 | 睡不好会放大第二天的焦虑和躯体感觉 | 睡眠问题要单独处理，不只靠加药 |
| 慢性疼痛、胃肠不适 | 焦虑放大疼痛和腹部症状，症状又加重焦虑 | 需要躯体科与精神科一起看 |
| 心血管、呼吸疾病 | 心慌气短既可能是焦虑也可能是病情变化 | 新发或变化的症状要先排查器质性原因 |
| 孤独症谱系、ADHD | 焦虑表现常被当成“行为问题”或“不专心” | 识别不足，需要专门评估 |
| 双相障碍 | 抗抑郁药可能诱发转躁 | 用抗抑郁药前要筛查既往躁狂或轻躁狂 |
| 创伤后应激、强迫症 | 症状重叠，容易互相掩盖 | 治疗顺序和重点不同，需要区分 |

还有一类共病容易被漏掉：**睡眠呼吸暂停**。打鼾严重、白天困倦、夜里憋醒的人，焦虑和疲劳可能有一部分来自缺氧，而不是单纯的心理问题。

### 初诊时值得主动交代的线索

- [ ] 最近三个月喝过多少酒，有没有为了助眠喝
- [ ] 有没有长期吃安眠药、镇静药、止痛药
- [ ] 每天咖啡、浓茶、功能饮料大概多少
- [ ] 有没有甲状腺、心脏、血糖、贫血方面的病史或检查异常
- [ ] 有没有一段时期特别兴奋、话多、睡得少但精力旺盛
- [ ] 有没有经历过重大创伤，或者反复闪回
- [ ] 有没有反复检查、计数、清洗这类仪式动作
- [ ] 家里有没有人得过焦虑、抑郁、双相或精神分裂症

### 什么时候需要联系医生 / 去急诊

> **立即拨打 120 或去急诊**：首次突发的剧烈胸痛、严重气短、晕厥；意识模糊、抽搐、高热；单侧肢体无力或说话不清；出现自杀念头、自伤行为或“不想活了”的具体计划；酒精或镇静药突然停用后出现发抖、大汗、心跳极快、幻觉。
>
> **尽快联系医生**：焦虑持续加重并影响工作生活；新出现体重明显下降、持续发热、心悸伴消瘦；情绪低落超过两周；饮酒或镇静药用量明显增加；准备自行减药或停药。

### 容易踩的坑

- 用“发病率高”安慰自己，也用它吓自己。群体数字说明这件事常见，不说明你的情况轻或重。
- 把共病当成“治不好了”。共病需要的是更完整的评估，不是更悲观的结论。
- 只治焦虑，不处理失眠和饮酒。这两件事不处理，焦虑很难稳定。
- 相信“过了这个阶段就好”。有些阶段确实会过去，但持续半年以上的功能损害，值得主动处理。
