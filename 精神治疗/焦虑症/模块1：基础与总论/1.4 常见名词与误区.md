# 1.4 常见名词与误区

焦虑这件事，被说错的次数比被说对的次数多。“你就是想太多”“深呼吸就好了”“社恐不就是内向”“惊恐发作会死人”——这些话有的出于关心，有的出于误解，共同点是都会让人错过该做的事。

这一页把最容易混的几组词、最常见的十来种说法，一条条摊开说清楚。它不是让你去跟人辩论，而是让你在自己心里有个准星：哪些话可以听，哪些话听过就算。

## 先把几个词分开

- **焦虑**：一种情绪，指向“还没发生、可能会发生”的威胁。人人都有。
- **焦虑症状**：焦虑在身体和心理上的具体表现，比如心慌、肌肉紧张、反复担心。
- **焦虑障碍**：一组有诊断标准的疾病，要求症状持续、难以控制、造成功能损害，并且不能用其他疾病或物质更好解释。
- **惊恐发作**：一次急性的、在很短时间内冲到顶点的强烈恐惧，伴随心悸、气短、头晕、手麻、濒死感或失控感。它是一种症状事件，不是诊断。
- **惊恐障碍**：反复出现意外性惊恐发作，并且持续担心再发或因此明显改变行为，才构成诊断。
- **恐惧**：通常指向眼前具体的对象或情境，比如蛇、高处、打针。
- **强迫**：反复出现的想法（强迫思维）加上用来抵消它的动作（仪式）。在 DSM-5 之后，它已经从焦虑障碍里独立出去。
- **回避**：为了减少焦虑而不去做某件事、不去某个地方。短期有效，长期让恐惧更牢。
- **安全行为**：必须带着某个东西、或必须有某个人陪着，才敢面对某个场景。比如出门必须带药、开会必须坐门口。

这几个词经常被混着用，但混用会带来实际后果：把惊恐发作当成心脏病，会反复跑急诊；把焦虑障碍当成“想太多”，会拖到慢性；把强迫当成焦虑，会用错方法。

## 十组最容易混淆的说法

| 说法 | 常见的误解 | 更准确的理解 |
|---|---|---|
| 焦虑症就是焦虑 | 把情绪当病，或把病当情绪 | 焦虑是普遍情绪；焦虑障碍要求持续、难控、有功能损害，并排除其他原因 |
| 惊恐发作等于心脏病 | 发作时以为要心梗，或反过来把心梗当惊恐 | 两者症状高度重叠；首次发作、有心脏病史、症状不典型，必须先排查心脏和肺部 |
| 社恐就是内向 | 以为只是性格，不用处理 | 内向的人独处舒服；社交焦虑是怕被评价、主动回避、事后反复回想，很痛苦 |
| 强迫症就是焦虑症 | 按焦虑的路子治，漏掉核心症状 | 强迫症已独立成章，核心是强迫思维与仪式，治疗重点是暴露与反应阻止 |
| 放松训练能替代治疗 | 只练呼吸，不去面对 | 放松是辅助手段，能降低唤醒；中重度焦虑需要心理治疗和/或药物 |
| 焦虑是想太多 | 把责任推给性格 | 涉及遗传气质、神经回路、应激激素和学习性条件反射，不是“想不想”的问题 |
| 吃药就是软弱 | 病耻感，拒绝有效治疗 | 药物调节的是神经递质和回路，性质接近眼镜和降压药，不是意志力比赛 |
| 焦虑久了会变成精神病 | 怕自己“疯了” | 焦虑障碍不会转成精神分裂症；惊恐时的“我要疯了”是发作体验，不是事实 |
| 焦虑症一辈子好不了 | 绝望，放弃治疗 | 多数人经规范治疗可以缓解；复发可以预防，波动不等于失败 |
| 量表分数高就是有病 | 拿筛查工具给自己确诊 | 量表只提示“值得评估”，诊断要靠面诊、病史和排除其他原因 |

## 就诊时你会听到的词

| 术语 | 大白话 |
|---|---|
| 广泛性焦虑障碍（GAD） | 长期、对很多事担心，停不下来 |
| 惊恐发作 | 十几分钟内冲到顶的强烈恐惧，伴心慌气短 |
| 惊恐障碍 | 反复发作，并且一直怕再发作 |
| 广场恐惧 | 怕人多、怕被困住、怕逃不掉、怕没人帮 |
| 社交焦虑障碍 | 怕被看、怕被评价、怕当众出丑 |
| 特定恐惧症 | 怕某个具体的东西或场景 |
| 回避 | 为了不难受而躲开 |
| 安全行为 | 靠某个人或某样东西才敢面对 |
| 内感受暴露 | 主动体验心慌、头晕这类感觉，练到不怕 |
| 认知行为治疗（CBT） | 一类结构化的心理治疗，改想法也改行为 |
| SSRI | 一类常用抗抑郁药，也用于治疗焦虑障碍 |
| 共病 | 同时存在两种或以上的问题 |

## 自查：这些话你对自己说过吗

- [ ] “再忍忍就过去了，不用看医生”
- [ ] “别人都能扛，就我不行”
- [ ] “我是不是太矫情了”
- [ ] “等这阵忙完就不焦虑了”
- [ ] “我不能让别人知道我在吃药”
- [ ] “查了都没事，那肯定是我瞎想”
- [ ] “我不能去那个地方，去了肯定出事”
- [ ] “只要不发作，我就不算有病”

勾中三条以上，说明你已经在用某套解释安抚自己。这些解释不必被批判，但值得拿出来和医生对一遍。

## 什么时候需要联系医生 / 去急诊

> **立即拨打 120 或去急诊**：首次突发的剧烈胸痛、压榨样疼痛或放射到手臂下颌的疼痛；突然严重气短、咯血；晕厥或差点晕倒；心跳极快伴眼前发黑；单侧肢体无力、口角歪斜、说话不清；抽搐、意识模糊、高热；严重过敏表现；出现自杀念头或自伤行为。
>
> **尽快联系医生**：症状持续数周不缓解；回避的场景越来越多；开始靠喝酒或吃安眠药应付；体重明显下降、持续发热、心悸伴消瘦；情绪低落超过两周。

### 容易踩的坑

- 把“我查过，没事”当成“我不用治”。检查排除的是器质性疾病，不排除焦虑障碍。
- 把“我能上班”当成“我还好”。功能损害是渐进的，很多人撑到撑不住才来。
- 用某一个名词解释全部问题。焦虑、抑郁、失眠、饮酒常常是一起来的。
- 拿网络段子当科普。“社恐”“强迫症”“抑郁了”这些词在网络上被用得很轻，容易让人低估真正的病。
