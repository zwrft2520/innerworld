# 9.3 焦虑合并PTSD与OCD

有些“焦虑”治了很久不见好，因为方向从一开始就偏了：一个人反复闪回多年前的事，被当成广泛性焦虑；一个人反复检查门锁、反复求保证，被当成“太紧张”。创伤后应激障碍（PTSD）和强迫症（OCD）在外表上都像焦虑，但治疗的核心动作完全不同。这一页写给治疗效果不理想、或怀疑自己有创伤史、强迫症状的人，也写给想帮忙的家属。

## 一、三者不是一回事：先分清，再找创伤

三者都让人紧张、回避、睡不好，但维持问题的机制不一样，因此“什么起作用”也不一样：

| | 焦虑障碍 | PTSD | OCD |
|---|---|---|---|
| 核心 | 对未来的威胁过度预估 | 创伤记忆未被整合，反复侵入 | 强迫思维加仪式行为 |
| 触发 | 广泛的情境、身体感觉 | 与创伤相关的线索 | 特定的念头、图像、冲动 |
| 维持因素 | 回避、安全行为 | 回避创伤线索、麻木、警觉 | 仪式、求保证、回避触发 |
| 一线治疗 | CBT、暴露 | 创伤聚焦心理治疗 | ERP 加药物 |

【指南】把三者混为一谈，最常见的后果是：只做放松、只做支持性谈话，症状短期舒服、长期不动。

PTSD 的核心不是“想起往事难过”，而是四组症状同时存在：

1. **再体验**：闪回、噩梦、突然觉得事情又发生了一遍、看到画面、闻到气味就回到现场；
2. **回避**：躲开地点、人、话题、新闻、声音，甚至回避自己的感受；
3. **负性认知与情绪**：觉得自己坏了、脏了、该负责；对世界失去信任；持续恐惧、愤怒、羞耻、麻木；
4. **警觉与反应性改变**：易惊、易怒、睡不着、注意力差、过度警惕、自伤或冒险行为。

诊断意义上的“创伤事件”有明确界定，通常指实际或威胁的死亡、严重伤害、性暴力。但临床上也会关注长期忽视、欺凌、医疗创伤、反复羞辱等经历——它们不一定满足诊断门槛，却同样值得被谈。【指南】

**不问，就找不到。** 很多人不会主动说，因为羞耻、怕被评判、怕“说出来会更糟”，或者根本不认为那算创伤。医生需要主动问，而且问得具体：“有没有经历过让你至今想起来还很难受、会躲开的事？”患者可以做的：第一次就诊时就告诉医生“我有一段不想提的经历”，不必一次说完细节；如果医生没问，可以主动说。**治疗不需要你一次讲完所有细节，稳定和安全永远排在前面。** 量表方面，PCL-5 和 PC-PTSD 常用于筛查，但分数只是提示，不能替代访谈。

## 二、OCD 与焦虑的区别

强迫症有两个部件：**强迫思维**，是反复出现的念头、图像或冲动，令人痛苦，常常与自己的意愿相反（比如怕伤害孩子、怕被污染、怕自己不是好人）；**强迫行为**，是为了减轻痛苦而做的重复动作或心理仪式——洗手、检查、计数、默念、反复求保证、反复回忆确认。

关键区别在这里：

| | 焦虑的担心 | 强迫 |
|---|---|---|
| 内容 | 现实问题：工作、健康、家人安全 | 往往不合理、违背意愿、令人羞耻 |
| 行为 | 回避、反复求证 | 重复仪式、反复求保证、反复检查 |
| 感受 | 紧张、担心 | 厌恶、羞耻、“必须做，不做就受不了” |
| 治疗 | CBT、暴露 | ERP 加药物 |

焦虑的担心通常是“现实的担忧被放大了”；强迫是“我知道不合理，但停不下来”。自知力也会波动：状态差的时候，有些人会越来越相信“不检查真的会出事”。

**最容易踩的坑是“求保证”。** 家属一遍遍说“门锁了”“你没病”“你不会伤害孩子”，当下很舒服，但下一次焦虑来得更快、更强。求保证是强迫循环的燃料，不是解药。

## 三、ERP 与创伤聚焦治疗：为什么“放松”不够

**暴露与反应预防（ERP）** 是强迫症的核心心理治疗：主动面对触发（暴露），同时不做原来的仪式（反应预防），让大脑学到“不做也不会出事”。它起作用的机制不是“习惯了就不怕”，而是**预期被打破**：你预计不做仪式会灾难临头，结果没有；一次次重复，这个新的学习慢慢盖过旧的恐惧。

为什么“放松”不够：

- 对 OCD，放松能降低紧张，但不做反应预防，强迫循环还在；甚至一边放松一边继续求保证，等于在加固症状。
- 对 PTSD，放松能缓解警觉，但不能加工创伤记忆；创伤聚焦治疗（如延长暴露、认知加工治疗、EMDR）才是针对核心的。【指南】
- 对焦虑障碍，放松是辅助，核心仍是面对回避的情境。

需要提醒的是：**ERP 和创伤暴露都要在专业指导下做。** 自己硬闯、一次做太猛，可能造成创伤重演或症状加重。好的治疗会有分级、有准备、有退出机制、有复盘。

药物方面，SSRI 类对 PTSD 和 OCD 都有效；OCD 通常需要更长的疗程才能判断效果，PTSD 的一线仍是心理治疗，药物更多用于共病抑郁或症状严重时的辅助。苯二氮䓬类在 PTSD 中一般不作常规推荐，因为它可能干扰暴露治疗、增加依赖，也可能让“回避”更牢固。【指南】

## 四、治疗顺序与就诊准备

同时有焦虑、PTSD、OCD 时，没有一套对所有人都适用的顺序。常用的判断原则是：

1. **安全与稳定优先。** 自杀风险、自伤、物质过量、现实中的危险（家暴、欺凌）要先处理。不稳定的时候做创伤暴露，可能适得其反。
2. **谁最影响功能，谁先治。** 如果强迫仪式每天耗掉几个小时、无法出门，先做 ERP；如果闪回导致完全无法工作、无法睡觉，先做创伤聚焦治疗。
3. **能整合就整合，不要无限期拖延。** 过去有一种做法是“先戒酒/先稳定，再治创伤”，一等几年。现在更倾向整合或并行治疗，尤其当物质使用是为了应对创伤症状时。【研究】
4. **一次不要开太多战线。** 同时做创伤暴露、ERP、社交焦虑暴露，容易过载。和医生商量一个主线，其他先做支持性处理。

就诊前可以准备：

- [ ] 写下最困扰你的三个症状，各举一个具体例子；
- [ ] 列出你的“回避清单”：不去的地方、不做的事、不谈的话题；
- [ ] 列出你的“仪式清单”：洗手、检查、计数、求保证、反复确认；
- [ ] 记录一次症状发作的完整过程：什么触发、想法是什么、做了什么、多久缓解；
- [ ] 告诉医生有没有创伤史，不必一次讲完；
- [ ] 家属记录：一周内你被问了几次“门锁了吗”，每次持续多久；
- [ ] 睡眠、酒精、咖啡因的量；
- [ ] 目前的药和保健品清单。

## 五、什么时候需要联系医生 / 去急诊

> **立即拨打 120 或去急诊：**
> - 自杀念头伴计划，或已经自伤；
> - 闪回、解离导致失控、走失、伤害自己或他人；
> - 过量服药、酗酒后的意识障碍；
> - 出现幻觉、妄想、极度混乱；
> - 正处于现实危险中（家暴、性侵、被跟踪）。

> **24–48 小时内联系医生：**
> - 创伤画面频繁侵入，连续几天几乎不能睡；
> - 强迫行为每天耗掉数小时，无法上班上学；
> - 开始 ERP 或创伤治疗后症状骤增，难以承受；
> - 新药后出现明显激活、皮疹、发热。

> **尽快预约门诊：**
> - 焦虑治疗 8 周以上没有改善；
> - 反复求保证、反复检查已经影响家人关系；
> - 一直回避某段经历，一提起就强烈不适。

## 六、常见问题与容易踩的坑

**“放松一下就好了。”** 放松是辅助。PTSD 需要加工创伤记忆，OCD 需要反应预防，单靠放松通常不够。

**“过去的事想开点就过去了。”** 想开不是开关。创伤记忆需要以安全、可控、专业的方式被重新处理。

**“强迫症就是爱干净、太仔细。”** 强迫症的核心是痛苦和失控，不是整洁。很多人洗手洗到破皮，并不觉得干净。

**“暴露就是硬扛、越狠越有效。”** 不是。有效的暴露是分级的、可承受的、可复盘的。硬闯可能造成创伤重演。

**“多保证几次，他安心了就好了。”** 短期有效，长期加固。更好的做法是温和地说“我知道你现在很不安，我们说好不做这个确认”，然后一起做别的事。

**“PTSD 不能提创伤，提了会更糟。”** 在专业治疗框架下，创伤聚焦治疗是有效的；关键是谁来提、什么时候提、怎么提。无限期回避，症状往往更顽固。

**“一次把创伤全讲完才算治。”** 不是。分段、可控、有准备地接近，比一次倾倒更安全，也更有效。
