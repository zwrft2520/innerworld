# 13.1 焦虑日记与惊恐记录

焦虑有一个很难对付的特点：它在回忆里会变形。发作的时候觉得“天天都这样、越来越重”，其实一周只有两次；好转的时候又觉得“好像也没什么”，于是提前停了药。日记的作用，就是给这种变形装一个参照物。

这一页给的是可以直接照抄的模板：每天记什么、惊恐发作怎么记、担忧和回避怎么记，以及最重要的——怎么用这些记录看趋势，而不是被某一天的分数牵着走。全部记下来每天大约花五到十分钟。

> 记录是工具，不是作业。它服务于你和医生的判断，不是给你打分的考卷。漏记一天不需要补，也不需要自责。

## 先想清楚：记是为了什么

如果不知道为什么要记，记录很快就会变成新的负担。它至少有三个用处。

**第一，给医生提供可比较的信息。** “最近特别焦虑”和“过去四周，每周发作两三次，最长一次四十分钟，因为这个推掉了两次出差”，后者能让医生做出更准确的判断。

**第二，让你看见模式。** 很多人的焦虑不是均匀分布的：周一早上最重、开会前最重、经期前一周最重、喝完咖啡的下午最重。看见模式，才有调整的入口。

**第三，把“我很糟”拆成具体的事。** 焦虑发作时，人的注意力会全部收进身体内部，感觉是“整个天都塌了”。写下来以后，它变成“心跳快、手麻、持续了二十分钟、后来坐下喝了水就好了”——具体的东西，比一团模糊的恐惧更容易处理。

需要先说清楚记录**不能**做什么：它不能替代诊断，不能证明你“病得多重”，也不能靠“记录做得好”来换好转。它只是一个观察工具。

## 每天三到五行：日常记录

不需要长篇大论。每天固定一个时间（建议睡前，或者第二天早上补），写五行就够。

| 字段 | 填什么 | 例子 |
|---|---|---|
| 睡眠 | 入睡大约几点、醒几次、总时长 | 1 点睡，醒 2 次，共 5 小时 |
| 焦虑分数 | 当天最高分与大致平均分（0 到 10） | 最高 7，平均 4 |
| 触发 | 时间、地点、当时在做什么、之前发生了什么 | 上午开会前，被点名汇报 |
| 身体与念头 | 两三个身体感觉，加上当时脑子里冒出的第一句话 | 心慌、手抖；“我会说不出话” |
| 应对 | 面对了、部分回避、完全回避；做了什么有用 | 部分回避，让别人先说；喝水有用 |

几个填写要点：

- **分数只写整数**，不要纠结 6.5 还是 7。分数是给自己做比较用的，不是精确测量。
- **“触发”写事实，不写评价。** 写“开会前被点名”，不写“我又不行了”。
- **“念头”写原话。** 脑子里那句“我要晕倒了”比“我有点担心”有用得多，因为后面要针对的正是这句话。
- **“应对”要区分面对和回避。** 这是全表最重要的一栏，因为它直接对应治疗目标。

如果某天什么都没发生，就写“平稳，最高 2 分”。空白的一天也是信息，别让它空着。

## 惊恐发作记录表（可照抄）

惊恐发作和日常焦虑要分开记，因为它的时间短、强度高、细节容易忘。建议在发作结束后半小时内填，趁记忆还清楚。

| 项目 | 填写内容 |
|---|---|
| 日期与时间 | 例如 10 月 8 日 21:40 |
| 地点与情境 | 例如 地铁 2 号线，人多，刚下班 |
| 从开始到顶峰 | 大约几分钟 |
| 总持续时间 | 大约多少分钟 |
| 峰值强度 | 0 到 10 分 |
| 身体感觉 | 圈出：心悸／胸闷／气短／出汗／发抖／头晕／手麻／恶心／发冷发热／喉咙堵 |
| 脑子里的第一句话 | 原话，例如“我要心梗了”“我要疯了” |
| 我做了什么 | 例如 下车、坐下、给家人打电话、含了药 |
| 多久恢复 | 例如 二十分钟后基本平复，一小时后完全正常 |
| 之后回避了什么 | 例如 第二天改打车上班 |

填写时注意三件事：

1. **不要在现场填。** 发作时注意力应该放在“度过它”，不是“记录它”。事后补记完全够用。
2. **“身体感觉”只圈真实的，不要凑数。** 列出来的项目是为了方便，不是为了让你对号入座。
3. **“之后回避了什么”这一栏千万别省。** 发作本身会过去，但回避会留下来，而回避才是让惊恐障碍维持下去的关键。

### 一个提醒：第一次发作要特殊对待

如果这是你人生第一次出现突发的剧烈胸痛、严重气短、晕厥或濒死感，**先按躯体急症处理，不要先填表**。先去急诊做心电图和相关检查，排除心脏、肺部、低血糖等问题。惊恐发作本身多数不致命，但“多数”不等于“这一次”。

## 担忧记录与回避清单

日常焦虑和惊恐之外，还有两样东西值得单独记：反复出现的担忧，和悄悄扩大的回避。

**担忧记录**适合广泛性焦虑。核心不是“别担心”，而是把担忧从脑子里搬到纸上，看它经不经得起检验。

| 日期 | 担心的事（一句话） | 我估的可能性 | 一周后回看：实际发生了吗 |
|---|---|---|---|
| 10.09 | 汇报时会被当场质疑，然后被辞退 | 80% | 没发生，被问了一个问题，答上来了 |
| 10.11 | 妈妈晚归半小时，可能出事了 | 60% | 没发生，手机没电 |

“一周后回看”是这张表的关键。它不靠讲道理说服你，而是靠你自己积累的证据。几周之后，你通常会看到一种模式：担心的事绝大多数没有发生，或者发生了但没有你想的那么糟。

**回避清单**适合所有类型的焦虑，也最容易被忽略。

| 我躲开的事 | 躲开的代价 | 能拆出的最小一步 |
|---|---|---|
| 坐地铁 | 每天多花一小时打车，费用增加 | 先坐一站，有人陪 |
| 公司聚餐 | 和同事越来越疏远 | 先去半小时，坐靠门位置 |
| 独自在家 | 必须有人陪，家人无法出差 | 先独自待一小时，手机开着 |

“最小一步”这一栏现在不用做到，写下来就行。它是给后面做暴露练习时用的，具体方法见 [5.3 暴露疗法：分级、重复与停止回避](<../模块5：心理治疗/5.3 暴露疗法：分级、重复与停止回避.md>)。

## 看趋势，不要盯单次；也别记成负担

**先说怎么看趋势。** 一周挑一个固定时间（比如周日晚上），只花三分钟，看四个数：

1. 这一周惊恐发作了几次，最长一次多久。
2. 焦虑平均分大概是多少（把七天的平均分粗算一下）。
3. 回避清单上多了几项、少了几项。
4. 功能：这周上了几天班／出了几次门／睡了几个好觉。

只看这四项的**四周走向**，不看某一天的起伏。焦虑本来就是波动的，一次发作回到 8 分，不代表前面的努力作废。真正有意义的变化往往是这样的：发作次数没怎么变，但恢复得快了；分数没怎么降，但敢去的地方多了；还是会紧张，但不再事后反复回想三个小时。

**再说别记成负担。** 下面这些信号出现时，说明记录本身变成了新的焦虑源，该减量了：

- 每天花在记录上的时间超过十五分钟
- 反复翻看旧记录，越看越难受
- 为了“数据好看”而改变行为，比如硬撑着不去回避，就为了让那一栏好看
- 漏记一天就烦躁、想补记
- 记录内容越来越长，变成情绪宣泄

出现这些情况，把记录简化成“每天一行：分数＋有没有回避”。等状态稳一点再恢复。记录是为了帮你，不是为了考核你。

### 每周复盘清单

- [ ] 这周发作几次，最长多久
- [ ] 焦虑平均分大概几分，比上周高还是低
- [ ] 新增了哪些回避，减少了哪些回避
- [ ] 有没有出现新的身体症状（体重下降、持续发热、心悸伴消瘦）
- [ ] 酒、咖啡、安眠药的用量有没有变化
- [ ] 睡眠大概几点睡、醒几次
- [ ] 有没有出现“活着没意思”的念头
- [ ] 下周复诊要重点说哪两件事

### 什么时候需要联系医生 / 去急诊

> **立即拨打 120 或去急诊**：首次突发的剧烈胸痛、严重气短、晕厥或濒临晕倒；意识模糊、抽搐、高热；单侧肢体无力、说话不清；出现自杀念头、自伤行为，或已经在做伤害自己的准备。
>
> **尽快联系医生**：记录显示发作频率持续上升；回避项目一周比一周多；开始靠喝酒或加量吃镇静药来应付；出现明显的情绪低落、兴趣丧失；记录里反复出现“撑不下去了”这类想法。
>
> 如果记录中出现自杀相关的念头，不要只写在日记里。把它告诉医生、告诉一个能立刻到你身边的人，或者拨打 12356 心理援助热线。
