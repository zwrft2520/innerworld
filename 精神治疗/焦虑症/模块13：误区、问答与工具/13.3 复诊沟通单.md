# 13.3 复诊沟通单

精神科门诊的一个现实是：你准备了很久，坐下以后可能只有十几分钟。医生要在这十几分钟里判断病情变化、调整方案，而你常常一紧张就忘了最要紧的那句。

这一页是一张可以打印、可以存进手机备忘录的沟通单。它把复诊拆成三段：诊前三分钟准备、诊中必须说和必须问、诊后确认。照着走一遍，信息就不会漏在诊室门外。

## 十几分钟的复诊，最怕什么都说了又什么都没说清

复诊和初诊不一样。初诊是“从头讲一遍”，复诊是“讲变化”。医生最想知道的不是“我很难受”，而是三件事：比上次好了还是差了、差在哪里、有没有新出现的问题。

而患者最常给出的信息是模糊的：“还行吧”“就那样”“有时候好点”。这不是不配合，是因为焦虑本身就是一团没有边界的感受，很难自动整理成句子。

所以准备的重点不是“想清楚该说什么”，而是**提前写下来**。写下来的东西不会因为紧张而消失，也不会因为医生说“我们时间不多”而被压缩掉。

一个可用的时间分配：出门前花三分钟填单子，进诊室先递单子再说两句话，把剩下的时间留给提问。

## 诊前 3 分钟：把纸填好

不需要写作文，填六个空就够。

**第一个空：这四周的整体走向。** 用一个词概括——明显好转、略有好转、差不多、略差、明显变差。再补一句为什么。

**第二个空：发作或难受的次数。** 一周几次，最长一次多久，最重的时候 0 到 10 分是几分。不要写“经常”，写数字。

**第三个空：最影响生活的一件事。** 只写一件。比如“不敢坐地铁，改打车，每月多花八百”“开会不敢发言，已经推掉两次汇报”。

**第四个空：药。** 现在吃的每一种，药名、怎么吃、有没有漏服、有没有不舒服。副作用要写清三件事：什么时候开始的、持续多久、影响到什么程度（能不能上班、能不能睡）。

**第五个空：酒、咖啡、烟、其他药。** 包括中药、保健品、朋友给的“助眠药”。这一栏最容易被省略，也最容易出问题。

**第六个空：情绪和安全。** 有没有持续低落、兴趣丧失、觉得活着没意思、有过伤害自己的念头。这一栏必须主动说，不要等医生问。

## 诊中：必须说清的八件事、必须问的六个问题

### 必须说清的八件事

1. **走向**：这四周是好转、持平还是变差。
2. **频率与强度**：发作几次、每次多久、峰值几分。
3. **诱因**：什么情境下最容易出现，有没有新的诱因。
4. **回避**：这阵子多躲开了什么，有没有因此影响工作、上学、出门。
5. **睡眠**：几点睡、醒几次、白天困不困。
6. **药物**：怎么吃的、漏没漏、有没有副作用、有没有自己减过。
7. **物质**：酒、咖啡、烟、其他药和保健品。
8. **安全**：有没有低落、绝望、自杀或自伤的念头。这一条不丢人，也不能省。

### 必须问的六个问题

1. 我现在的诊断依据是什么，有没有需要再排除的其他原因？
2. 现在的治疗大概多久能看到变化，用什么标准判断有没有效？
3. 出现哪些副作用需要立刻联系你，哪些可以再观察？
4. 我需要同时做心理治疗吗，去哪里找靠谱的？
5. 下次复诊前，我需要记录什么、注意什么？
6. 什么情况下要提前来，或者直接去急诊？

如果时间实在不够，就挑三个问：诊断依据、疗效判断、危险信号。这三个问题的答案，决定了你接下来几个月怎么走。

### 怎么把模糊的话说具体

| 项目 | 模糊的说法 | 医生能用的说法 |
|---|---|---|
| 频率 | 最近老是发作 | 这周发作三次，周二、周四、周日，都在晚上 |
| 强度 | 特别难受 | 峰值 8 分，最难受的时候觉得要晕过去 |
| 时长 | 好久才缓过来 | 从开始到平复大约四十分钟，之后一小时还发虚 |
| 诱因 | 没什么原因 | 三次里有两次是在地铁上，一次是在开会前 |
| 回避 | 我不太出门 | 一个月没坐地铁，超市只在人少时去，聚会全推了 |
| 副作用 | 吃药后不舒服 | 加药第三天开始恶心，早饭后明显，持续两周，没影响上班 |
| 情绪 | 心情不好 | 近三周每天大部分时间低落，原来喜欢的球赛也不想看 |

## 诊后：用自己的话复述一遍

离开诊室前，用三十秒做一次复述。这一步能挡掉大量“回家才发现没听懂”的情况。

复述四句话：

- “我的诊断是……”
- “药我打算这样吃……”（说清时间、和饭的关系、漏了怎么办）
- “下次复诊是……”
- “如果出现……我就联系你或者去急诊”

如果这四句里有任何一句说不出来，当场问清楚。医生不会因为你多问一句而不耐烦，真正麻烦的是三个月后才发现一直吃错了。

几个实操建议：

- **带家属或朋友一起去。** 两个人在场，一个负责说，一个负责记，比一个人硬撑好。
- **录音。** 先征得医生同意。焦虑状态下，人对信息的接收会明显变差，录音能补上。
- **核对处方。** 拿药后把处方和医生的口头说明对一遍，不一致就打电话问。
- **别改口头约定。** 医生说“先这样吃四周”，就不要两周后自己觉得好了而停掉。
- **记下医生的原话。** 尤其是“什么情况必须回来”这一句。

### 出门前检查清单

- [ ] 沟通单填好了，字迹自己能看懂
- [ ] 医保卡、就诊卡、身份证
- [ ] 正在吃的药，或者药盒照片
- [ ] 最近的检查单、化验单
- [ ] 上次的处方和病历
- [ ] 手机电量够，能录音
- [ ] 家属或朋友同行（如果需要）
- [ ] 想好的三个问题写在最上面

### 什么时候需要提前联系医生 / 去急诊

> **立即拨打 120 或去急诊**：首次突发的剧烈胸痛、严重气短、晕厥；意识模糊、抽搐、高热；单侧肢体无力、说话不清；出现自杀念头、自伤行为或具体计划；严重过敏表现（面唇肿胀、呼吸困难）；突然停用镇静药后出现发抖、大汗、心跳极快、幻觉。
>
> **在下次复诊之前就联系医生**：症状明显加重、无法工作或出门；出现新的副作用且影响生活；漏服或误服药物；饮酒量明显增加；情绪持续低落两周以上；对治疗方案有疑问、想调整。

### 容易踩的坑

- **报喜不报忧。** 怕被说“不配合”，就把漏服、喝酒、加量的事藏起来。医生按不完整的信息调整方案，风险由你承担。
- **只讲感受，不讲事实。** “我很焦虑”很难处理，“每周三次、都在地铁上”可以直接变成治疗目标。
- **把问题留到下次。** 三个问题这次没问，下次可能就问别的了。
- **不核对处方。** 药名相近、规格不同的事故，多半发生在“没多看一眼”的时候。
- **自行调整后再告诉医生。** 已经调了，也要如实说，不要因为怕批评而隐瞒。
