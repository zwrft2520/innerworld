# 10.4 血清素综合征、跌倒与驾驶风险

> 抗焦虑药大多数时候是安全的，但有几类风险需要提前知道：血清素综合征、心电图上的 QT 间期延长、血钠偏低、跌倒，以及服药后开车和操作机器的风险。这一页不吓人，也不轻描淡写，而是把“什么情况要立刻就医、什么情况要冲急诊、什么情况只是需要调整”分开讲清楚。读完你应该能和医生一起，把这些风险提前排掉。

## 血清素综合征：少见，但可以很重

血清素综合征是血清素（5-羟色胺）在体内过多引起的一组药物不良反应。它通常不是“吃一种药吃久了慢慢出现”，而是发生在几个特定时点：刚开始一种血清素能药物、加量、同时用两种以上这类药、过量服药，或者换药时间隔不够。【指南】

常见的组合包括：SSRI 或 SNRI 与曲马多（一种止痛药）、曲坦类（偏头痛药）、MAOI、圣约翰草、锂盐、亚甲蓝、部分止吐药合用；也包括可卡因、安非他命、摇头丸等娱乐性药物。有些抗生素（如利奈唑胺）也有血清素能作用。很多人不知道中成药、减肥药、感冒药里也可能含有相关成分，所以就诊时要把所有正在吃的东西都告诉医生。

它不是“血清素越高越健康”那种养生说法。血清素过多会让神经系统的兴奋性失控，轻的手抖、出汗、腹泻，重的会出现高热、肌肉强直、意识改变，甚至危及生命。

## 怎么认：三类症状一起看

血清素综合征的典型表现可以归成三组。三组同时出现，尤其是最近刚加药或加了新药，要高度怀疑。

| 三类表现 | 具体可能看到什么 |
|---|---|
| 精神状态改变 | 焦虑激越、坐立不安、话多、意识模糊、谵妄 |
| 自主神经不稳定 | 发热、大汗、心跳快、血压高、瞳孔散大、腹泻、恶心 |
| 神经肌肉异常 | 震颤、肌肉僵硬、反射亢进、阵挛、眼球震颤 |

“阵挛”是指肌肉一阵一阵地抽动，比如脚踝被快速向上扳时，脚背出现几次节律性的抽动。它是比较有特征的表现，但普通人不必自己查体，怀疑就应该去医院。

| 程度 | 表现 | 该怎么做 |
|---|---|---|
| 轻 | 震颤、腹泻、出汗、瞳孔偏大、反射活跃，人还清醒 | 暂停下一次服药，尽快联系医生或去急诊 |
| 中 | 明显激越、眼球阵挛、反射亢进、心跳快、发热 | 立即去急诊，不要在家观察 |
| 重 | 谵妄、肌肉强直、高热、休克、抽搐、横纹肌溶解 | 立即拨打 120 |

症状通常在开始用药或加量后二十四小时内出现，多数在几小时内进展。这一点很关键：如果刚换了药、刚加了量，随后出现发热、大汗、抖动、意识不对，不要等“明天看看”。

### 和什么区分：别把所有发抖都当成血清素综合征

血清素综合征容易被和几种情况混淆：

- **恶性高热**：与麻醉药有关，通常发生在手术中或术后，普通人日常用药不会遇到
- **抗精神病药恶性综合征**：进展较慢，以肌肉强直、意识改变、发热为主，和抗精神病药相关
- **抗胆碱能中毒**：皮肤干、不出汗、瞳孔大、尿潴留、口干明显
- **感染或败血症**：有感染灶、畏寒寒战、白细胞升高等
- **惊恐发作**：会心慌、出汗、发抖，但不会出现高热、肌肉强直、阵挛和意识改变

普通人不需要自己鉴别。要记住的是一条：**发热 + 肌肉僵硬或抽动 + 意识改变，同时最近动过药，就是急诊信号。**

## QT 间期延长与低钠：两个“查血查心电图”才能看见的风险

QT 间期是心电图上的一段，代表心脏电活动“复位”的时间。某些药物会让它变长，增加一种叫尖端扭转型室速的严重心律失常风险，可能引起晕厥，极少数情况下猝死。风险不高，但可以提前识别。

可能延长 QT 的药物包括：西酞普兰和艾司西酞普兰（与剂量相关）、文拉法辛、三环类抗抑郁药、部分抗精神病药、美沙酮、昂丹司琼、部分大环内酯类和喹诺酮类抗生素、唑类抗真菌药等。风险在以下情况更高：先天性长 QT、心脏病、心跳过慢、低钾或低镁、女性、高龄、同时用多种延长 QT 的药、肝肾功能不全、进食障碍或反复呕吐。

需要警惕的症状是心悸、头晕、眼前发黑、晕厥、抽搐。**晕厥一次就要去急诊**，不要只说“我可能是低血糖”。有心脏病、晕厥史、家族中有人年轻猝死、或需要合并多种药的人，医生可能会安排心电图和电解质检查，这是常规的风险管理，不是“过度检查”。

低钠血症是另一件容易被忽略的事。SSRI 和 SNRI 可能导致抗利尿激素分泌过多，血钠被稀释，出现低钠。它更容易发生在治疗开始后的前几周、加量后、老年人、体重偏低的人、同时用利尿剂的人身上。

低钠的表现不特异：乏力、头痛、恶心、食欲差、注意力下降、走路不稳、意识模糊，严重时会抽搐、昏迷。家里有老人刚开始吃抗抑郁药，如果两三周内变得“没精神、反应慢、走路发飘”，不要只当成“年纪大了”，要查血钠。【指南】

## 跌倒与驾驶：每天都要面对的风险

跌倒看起来不如血清素综合征“吓人”，却是抗焦虑药最常见的实际伤害，尤其在老年人身上。苯二氮䓬类、Z 药（唑吡坦等）、抗组胺药、曲唑酮、部分镇静性抗抑郁药，都会让人嗜睡、反应变慢、平衡变差、血压偏低。夜里起夜、浴室地滑、地面有杂物、视力不好、同时吃多种药，都会把风险放大。跌倒导致的髋部骨折，对老年人可能是一次生活能力的断崖。

家里可以这样做：

- [ ] 床边放夜灯，走道不要堆杂物
- [ ] 浴室铺防滑垫，装扶手
- [ ] 起夜时先在床边坐半分钟，再站起来
- [ ] 穿合脚、防滑的鞋，不穿拖鞋走远路
- [ ] 常用物品放在伸手可及的高度，不爬凳子
- [ ] 把正在吃的所有药列一张清单，复诊时请医生看有没有重复的镇静药
- [ ] 如果最近摔过，或走路开始不稳，尽快告诉医生

驾驶和操作机器的风险来自三处：药物带来的嗜睡和反应变慢、焦虑本身占用的注意力、以及惊恐发作时突然的头晕和视线模糊。开始用一种新药、加量、换药后的头几天，风险最高；即使“吃久了习惯了”，也不代表完全没有影响。

- [ ] 开始新药或加量后，先观察自己的反应，必要时几天内不开车
- [ ] 感到困倦、头晕、反应慢、视物模糊时，不开车
- [ ] 不酒后驾车，也不用酒精去“压”药物的副作用
- [ ] 长途、夜间、恶劣天气更谨慎，必要时休息
- [ ] 职业司机、操作重型机械或高空作业的人，提前告诉医生
- [ ] 开车时如果惊恐发作，打转向灯靠边停，开双闪，等缓解再走
- [ ] 不隐瞒用药情况；具体限制以当地法规和医生意见为准

## 高危人群与几个常见疑问

| 人群 | 主要风险 | 要点 |
|---|---|---|
| 65 岁以上 | 跌倒、低钠、QT、多重用药 | 低剂量起始、加量慢、复查电解质、尽量少用镇静药 |
| 孕产期 | 用药与不治疗的权衡 | 不自行停换药，和产科、精神科一起讨论 |
| 青少年 | 血清素综合征、冲动、自伤 | 家长保管药物，留意合并用药和网络购药 |
| 肝肾功能不全 | 药物蓄积、QT、低钠 | 就诊时主动告知，按医生安排监测 |
| 心脏病或长 QT | QT 延长、晕厥 | 查心电图，避免自行合用延长 QT 的药 |
| 进食障碍、反复呕吐、用利尿剂 | 低钾低镁，放大 QT 风险 | 纠正电解质，别自行补钾 |
| 有物质使用 | 血清素综合征、呼吸抑制 | 如实告诉医生，不要隐瞒 |

### 几个常见疑问

**“吃 SSRI 是不是都会得血清素综合征？”**
不会。它总体少见，多数与合并用药、过量、换药间隔不足有关。按医嘱服药、不自行加药、不随便加用止痛药和保健品，是最有效的预防。

**“我感觉好多了，能不能自己加一点量？”**
不能。加量要由医生决定，尤其是西酞普兰这类与 QT 相关的药。

**“吃抗焦虑药能不能喝酒？”**
不推荐。酒精会加重嗜睡和判断力下降，也会加重焦虑反跳。

**“开车前吃一片抗焦虑药可以吗？”**
如果吃了让人困倦的药，就不要开。需要长期开车的人，提前和医生讨论用药时间。

## 什么时候需要联系医生 / 去急诊

> **立即拨打 120 或去急诊：**
>
> - 高热，同时肌肉僵硬、抽动、意识改变，且最近加过药或换过药
> - 抽搐、晕厥、意识不清
> - 心跳极快且不规则，伴头晕、胸闷
> - 严重过敏：皮疹迅速扩散、面唇肿胀、呼吸困难
> - 跌倒后不能站起、髋部疼痛、头部受伤后呕吐或嗜睡
>
> **当天联系医生：**
>
> - 新加药后出现发热、大汗、抖动、腹泻
> - 老年人加药后乏力、反应慢、走路不稳、意识模糊
> - 心悸、头晕、眼前发黑，但还没有晕倒
> - 准备开车、操作机器，或职业需要，想确认用药影响
>
> **拨打 12356 心理援助热线：**
>
> - 因为担心副作用而不敢吃药，或想自行停药
> - 吃药后情绪明显变差，出现伤害自己的想法
