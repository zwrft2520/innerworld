# 10.2 自杀风险与安全计划

> 这一页谈一个很难开口的话题。焦虑本身不一定带来自杀风险，但焦虑合并抑郁、长期失眠、酒精使用或强烈绝望时，风险会明显升高。它教家属怎么直接问、怎么判断紧急程度、怎么把安全计划和手段限制落到具体动作上，也说明为什么“你保证不自杀”不能代替专业评估。

## 焦虑合并抑郁时，风险为什么会升高

焦虑和抑郁经常一起出现。抑郁带来绝望、兴趣丧失、精力下降，焦虑带来失眠、坐立不安、灾难化的想法，两者叠加，人会觉得自己被困住了：既没有力气改变，也停不下来地担心。

惊恐发作时的濒死感和失控感，也会被误解成“我撑不下去了”。长期失眠会削弱判断力和情绪调节能力，酒精则先让人放松、再把人推向更深的低落和冲动。焦虑障碍本身也与自杀意念、自杀尝试的风险升高有关，即使排除了抑郁的影响，这种关联仍然存在。【研究】

需要强调：绝大多数有自杀念头的人并不是真的想结束生命，而是想让痛苦停下来。这个区分很重要，它决定了我们该做什么——不是讲道理劝“想开点”，而是降低痛苦、争取时间、把危险手段拿远。

| 风险升高的信号 | 保护因素 |
|---|---|
| 既往自杀未遂（最强的预测因素之一） | 有稳定的家人、朋友或伴侣 |
| 家族中有自杀史 | 有明确的生活责任，如孩子、老人、宠物 |
| 强烈的绝望感、“没有出路” | 愿意求助，愿意把念头说出来 |
| 合并抑郁、双相、PTSD、物质使用 | 正在接受治疗，规律复诊 |
| 长期失眠、冲动、极度激越 | 有宗教信仰或坚定的价值信念 |
| 独居、近期丧亲、失业、经济压力 | 手段不容易获得 |
| 能轻易拿到药物、农药、利器 | 与医生之间有信任关系 |
| 男性、高龄、近期出院 | 有孩子或其他需要他照顾的人 |

## 怎么直接问：问不会“教坏”对方

很多家属不敢问，怕“本来没想到，被我一问就想起来了”。现有的研究和临床经验都提示：平静、直接地询问自杀念头，不会增加风险，反而常常让人松一口气——终于有人愿意听，而且没有被吓跑。【研究】

旁敲侧击反而更危险。“你不会想不开吧”“你别吓我”这类问法，暗示这是禁忌，对方最容易回答“没有”。直接问，是把话题从暗处拿到明处。

| 不要这样问 | 可以这样问 |
|---|---|
| “你不会想不开吧？” | “最近有没有想过不想活了？” |
| “你别吓我，你不会做傻事吧？” | “有没有想过具体怎么做？” |
| “你怎么能这么想，你考虑过我们吗？” | “是什么让你觉得撑不下去？” |
| “你答应我，绝对不做傻事。” | “如果那个念头变强，我们可以找谁？” |
| “想开点，大家都很难。” | “你现在最需要我做什么？” |

问的时候，注意几件事：

- 找安静、不被打断的时间，坐下来问，不要一边做别的一边问
- 语气平静、直接，不惊讶、不评判、不急着安慰
- 顺着一条线问完整：有没有念头 → 有没有计划 → 有没有准备 → 有没有尝试过 → 现在打算怎么办
- 给对方时间，允许沉默，不逼着“马上说清楚”
- 不要承诺绝对保密。涉及生命安全时，保密有例外，这一点要提前说清楚
- 问完要接住：谢谢你告诉我，我们一起想办法

一个可以照着说的版本：“我注意到你最近很累，也很少说话。我想直接问你一个问题，因为我在乎你：你有没有想过不想活了？不管答案是什么，我都不会责怪你，也不会转身就走。”

## 风险分级：从念头到计划到准备

自杀风险不是一个“有或没有”的开关，而是一条从模糊念头到具体行动的线。下面这张表帮助家属判断紧急程度，但它不是诊断，判断不了就按更高一级处理。

| 级别 | 常见表现 | 该做什么 |
|---|---|---|
| 低 | 偶发念头，没有计划，没有准备，能说出原因，有支持 | 尽快预约精神科或心理治疗；做安全计划；家属保持联系；移除手段 |
| 中 | 念头频繁，有模糊计划，没有具体准备，情绪激动或绝望 | 当天联系医生或去精神科急诊；不要独处；做手段限制；缩短复诊间隔 |
| 高 | 有具体计划、时间、地点、方法，或已准备工具、写过告别的话 | 立即拨打 120 或去急诊，全程陪同，不让其独处，移除手段，必要时请 110 协助 |
| 极高 | 正在实施，或已经服药、割伤、站在高处、溺水 | 立即拨打 120，现场急救，保持气道通畅，不要让其独处 |

还有一种情况要特别警惕：一个极度绝望的人突然变得异常平静，开始交代后事、送东西、道歉、说“以后你们要好好的”。这不一定是“想通了”，也可能是已经下定决心。此时要提高警惕，直接问，并尽快就医。

## 安全计划与手段限制

安全计划不是一张保证书，而是一份“当念头变强时，我具体做什么”的预案。它通常包含六步，可以和医生、心理治疗师一起写，也可以由家属陪着填。

- [ ] 第一步：写下我的预警信号（例如连续三晚睡不着、开始查“怎么死”、把自己关起来）
- [ ] 第二步：写下我自己能做的三件事（例如冲冷水脸、出门快走十分钟、听固定的歌单）
- [ ] 第三步：写下能让我分心的人和地方（例如去客厅找家人、去楼下便利店、给朋友发消息）
- [ ] 第四步：写下我可以联系的两个人，附上电话号码
- [ ] 第五步：写下专业资源：主治医生、就近医院急诊、12356、120
- [ ] 第六步：写下环境安全措施：哪些东西要收起来、由谁保管

手段限制是安全计划里最具体、也最容易被跳过的一步。它的逻辑不是“监视”，而是“在风险最高的这段时间，把决定推迟”。

- 药物：由家人保管，只留当天需要的那一份；不要放在床头、包里或卫生间
- 利器：刀具、剪刀、剃须刀片收进锁柜
- 绳索、农药、百草枯等：农村家庭要特别检查储藏间和仓库
- 高处：锁好通往天台、阳台的门窗，移走可以攀爬的凳子
- 车钥匙：由家人保管
- 酒精：家里暂时不存酒，也不要在风险期劝酒
- 让信任的人知道，但不要到处宣扬；知情范围控制在“能帮忙的人”

为什么“保证不自杀”不能代替评估？因为承诺不能预测行为，也挡不住冲动。更糟的是，当家属反复要求“你保证”，患者为了不让家人担心，会学会说“我保证”，然后把真实念头藏起来。真正有用的是四件事：可执行的计划、能随时找到的人、被移走的手段、被治疗的症状。

家属可以说：“我不需要你保证永远不自杀，那太重了。我需要你答应我一件事：念头变强的时候，先告诉我，或者先打这个电话，给自己十分钟。”

## 家属常犯的错与需要特别注意的人

常见的坑：

- 把自杀话题当禁忌，觉得“不提就不会发生”
- 相信“说了就不会做”，或者相信“真想做的人不会说”，这两种说法都不对
- 用道德绑架：“你要是有个三长两短，我们怎么办”
- 二十四小时盯着人，却不带去治疗
- 患者说“我没事”，家属就真的放心了；直觉不对时，要相信直觉并找医生
- 把自伤说成“博关注”。自伤是痛苦的表现，也是后续风险的重要信号
- 家属自己硬扛，不求助；照顾者也需要支持

几类人需要额外留意：

- **青少年**：直接问，不要用“你就是叛逆”堵回去。注意自伤、校园霸凌、网络上的自杀相关内容、家庭冲突。家长要保管好药物，并和学校沟通。
- **老年人**：老年男性的自杀死亡比例较高，求助意愿却常较低。表现可能不是“我不想活”，而是“没意思”“活着拖累你们”“身体到处不舒服”。独居、丧偶、多重用药都要留意。
- **产后**：产后焦虑和抑郁常同时出现。要问“有没有想过伤害自己，或者伤害孩子”。产后精神病（幻觉、妄想、极度混乱）是急症，立即去急诊。
- **双相障碍**：抑郁期和混合期风险高，抗抑郁药可能诱发转躁。不要只按抑郁或焦虑治，需要精神科评估。

## 什么时候需要联系医生 / 去急诊

> **立即拨打 120 或去最近医院急诊：**
>
> - 已经有自杀计划、准备了工具、写好了告别的话
> - 正在实施自杀行为，或已经服药、割伤、溺水、从高处坠落
> - 出现幻觉、妄想、极度混乱，或听到命令自己去死的声音
>
> **立即拨打 110 请求协助：**
>
> - 当事人拒绝就医、正在离开、或你无法保证其安全
>
> **当天联系医生或去精神科急诊：**
>
> - 自杀念头频繁出现，或明显比之前强烈
> - 情绪突然“平静”得反常，开始交代后事
> - 严重失眠、激越、无法进食，或酒精使用明显增加
>
> **拨打 12356 心理援助热线：**
>
> - 你需要有人陪着梳理思路，或不知道该找谁
> - 当事人愿意谈，但还不想去医院
