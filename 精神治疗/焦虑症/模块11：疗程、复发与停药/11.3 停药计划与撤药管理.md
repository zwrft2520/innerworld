# 11.3 停药计划与撤药管理

> 这一页讲停药。停药不是“不想吃了就不吃”，也不是“吃够时间就必须停”，而是一次需要计划的调整：什么时候可以考虑、先做哪些准备、怎么慢减、怎么区分撤药反应和复发、停药后怎么监测。读完你能和医生一起做一份属于自己的停药计划，而不是靠感觉硬扛。

## 什么时候可以考虑停药

停药的前提不是“我受够了”，而是“病情稳住了，而且稳得够久”。医生通常会一起看这几条：

- 症状缓解已经持续足够久，不是刚好了两三个星期
- 工作、学习、社交、睡眠等基本功能恢复，生活能正常运转
- 近期没有可预见的大变动，比如考试、搬家、换工作、丧亲
- 残留症状很轻，或者已经处理过
- 你对停药后的监测和复诊有准备，愿意放慢速度
- 这个决定是你和医生一起做的，不是因为怕依赖、别人劝、或者药快吃完了

有些时候，还不适合谈停药：刚缓解不久、最近刚经历重大压力、复发过多次、残留症状明显、合并抑郁或物质使用还没控制、怀孕计划还没和医生讨论过。这些情况下，先稳住，比“尽快停掉”更重要。【指南】

也要说清楚：停药不是必须完成的任务。有些人需要在医生指导下长期维持，这是合理的治疗选择，不是“失败”。

## 停药前要做的准备

停药能不能顺利，很大程度取决于开始之前的准备。

| 准备 | 为什么 | 怎么做 |
|---|---|---|
| 选时间 | 压力期减量更容易失败 | 避开考试、搬家、换工作、丧亲、手术 |
| 告诉家人 | 需要有人观察和支持 | 让至少一个人知道你的计划和预警信号 |
| 记录基线 | 以后才能分清撤药和复发 | 停药前两周记录睡眠、焦虑、躯体症状 |
| 约好复诊 | 减量期需要更密的监测 | 提前预约，不要等出问题才找医生 |
| 心理治疗衔接 | 提供技能支持 | 继续暴露和认知练习，必要时加几次巩固 |
| 了解自己的药 | 半衰期、剂型、能否掰开 | 问医生或药师，不要自己处理 |

还有一件常被忽略的事：把家里的药量算清楚。减量期间如果药不够、临时换品牌、或者出差断了药，很容易被迫“硬停”。提前确认复诊时间和取药方式，比事后补救有用。

## 怎么慢减：原则，不是速度

减量的核心是“慢”和“稳”，但具体多慢，必须由医生根据你的药、剂量、用药时间、半衰期、既往戒断史、年龄、肝肾功能和焦虑严重度来定。本页不给具体数字，也不建议你照着别人的方案减。

可以期待医生做的是：

- 制定分阶段的计划，以周或月为单位推进，最后阶段通常更慢
- 必要时换成长半衰期的药，让血药浓度更平稳
- 一次只改一件事，不同时换药、减量、停另一种药
- 告诉你哪些反应可以观察，哪些要立刻报告
- 在减量后段安排更密的复诊

你可以做的是：

- [ ] 按医生给的节奏走，不因为“今天感觉不错”就多减一点
- [ ] 不隔天吃。隔天吃会让血药浓度忽高忽低，反跳更明显
- [ ] 不自己掰药或换剂型，有些药不能掰，有些剂型需要医生选
- [ ] 记录每天的用量、睡眠、焦虑评分和身体反应
- [ ] 出现明显不适时先联系医生，不自行加回或加快
- [ ] 减量期不大量喝酒、不熬夜、不接高强度新任务
- [ ] 把“减量”告诉一个信任的人，让他帮你观察

如果减到某一步特别难受，医生可能会让你在这一步多停留一段时间，或者暂时回调一点。这不是失败，是调整。硬撑着往下减，往往换来更严重的反弹。

## 撤药反应和复发，怎么分

这是停药期最容易被搞混的一件事。两者都可能表现为心慌、失眠、焦虑，但时间线和性质不一样。

| 对比 | 撤药反应 | 复发 |
|---|---|---|
| 出现时间 | 减量或停药后数天内 | 数周内逐渐出现 |
| 持续时间 | 通常数天到数周，逐渐减轻 | 持续存在，甚至加重 |
| 症状性质 | 头晕、电击感、恶心、出汗、流感样、易怒、失眠、感觉异常 | 原来的焦虑或抑郁症状回来：担忧、回避、惊恐 |
| 对重新服药的反应 | 恢复原有剂量后较快减轻 | 需要重新治疗一段时间才见效 |
| 处理方式 | 暂缓减量、回调、对症处理 | 恢复治疗、重新评估方案 |

“电击感”是撤药反应里比较有特点的一种：像头部突然被电了一下，或者眼前闪一下。它让人害怕，但通常不危险，会随着时间减轻。

两者也可能重叠：撤药反应把人弄得很焦虑，焦虑又触发复发。所以不要自己下判断，把时间线记下来，和医生一起看。

## 停药后监测、复发应对与常见问题

停药不是终点，后面还有一段需要看着的日子。

- [ ] 停药后第一周：睡眠、头晕、情绪、焦虑，每天记一笔
- [ ] 第二到第四周：撤药反应的高峰期，也是复发早期信号出现的窗口
- [ ] 第二到第三个月：功能恢复情况、回避有没有回来、按时复诊
- [ ] 第六到第十二个月：遇到生活事件时，回头看预警清单
- [ ] 每次复诊带上记录，不要只说“还行”
- [ ] 知道自己该找谁：主治医生、12356、就近医院急诊

### 如果复发了怎么办

先不要自责。复发是疾病的一部分，不是意志失败，也不代表之前的治疗白做了。

- 尽快联系医生，不要自己把原来的剂量加回去，也不要翻出以前的药自己吃
- 把停药的时间线、减量过程、最近的生活事件告诉医生
- 可能需要恢复治疗一段时间，起效同样需要时间
- 复盘这次停药：是不是太早、太快、减量期压力太大、残留症状没处理
- 下一次可以更慢、维持更久，这不丢人

### 特殊人群要更谨慎

- **孕产期**：不要因为发现怀孕就自行停药。突然停药可能引起撤药和复发，对母婴都不利；要和产科、精神科一起讨论。
- **老年人**：代谢慢、跌倒和低钠风险高，减量通常更慢，复诊更密。
- **青少年**：需要家长参与，学校配合，注意情绪波动和自伤信号。
- **肝肾功能不全**：药物可能蓄积，减量方案要结合检查结果。
- **合并酒精或其他镇静药**：先处理酒精和镇静药问题，再谈减量，否则风险叠加。

### 容易踩的坑

**“我自己先减一半。”**
减太快可能诱发严重撤药，甚至抽搐。把想法告诉医生。

**“隔天吃就能停。”**
血药浓度波动，反跳更明显，不是科学的减法。

**“用保健品或中药替代。”**
目前没有可靠证据支持它们可以替代规范的减量管理，自行替换可能两头落空。

**“怕依赖，所以硬停。”**
硬停不会让你更快自由，只会让戒断更重、复发更快。依赖是可以被管理的，见 [10.3 苯二氮䓬依赖、戒断与酒精](<../模块10：风险管理/10.3 苯二氮䓬依赖、戒断与酒精.md>)。

**“停药后喝酒助眠。”**
酒精会加重反跳性焦虑和失眠，还可能和残留药物叠加。

**“停了就再也不吃了。”**
如果复发，重新治疗是合理选择，不是前功尽弃。

## 什么时候需要联系医生 / 去急诊

> **立即拨打 120 或去急诊：**
>
> - 停药或减量后出现抽搐、意识混乱、高热、极度激越
> - 出现自杀念头、自伤行为，或已经做了计划
> - 严重过敏、晕厥、剧烈胸痛
>
> **当天联系医生：**
>
> - 撤药反应明显，影响进食、睡眠或出门
> - 情绪持续低落、绝望，或焦虑明显加重
> - 失眠连续多天，白天无法工作
> - 想加快减量，或已经自行减量
>
> **拨打 12356 心理援助热线：**
>
> - 停药期焦虑难忍，需要有人先听你说
> - 复发后羞于联系医生，不知道怎么开口
