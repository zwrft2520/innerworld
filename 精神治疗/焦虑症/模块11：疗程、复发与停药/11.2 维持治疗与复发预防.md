# 11.2 维持治疗与复发预防

> 焦虑治疗里最容易松劲的一段，是“已经好得差不多了”的时候。症状退了，日子忙起来，复诊一拖再拖，药也慢慢停了——然后某天发现，心慌、失眠、担忧又回来了。这一页讲维持治疗到底在维持什么、哪些人需要更久、复发有哪些早期信号，以及怎么把药物、心理治疗和生活方式接成一张网。

## 维持治疗在维持什么

维持治疗不是“多吃一段时间”，也不是医生保守。它做的是三件事：把已经获得的缓解固定下来、让大脑的应激系统有时间恢复稳定、把因为生病而缩小的生活重新撑开。

焦虑障碍的病程常常是波动的。生活里的事件——换工作、考试、搬家、亲人去世、生病、怀孕——都会让焦虑回升。维持期的治疗像一层缓冲：同样的压力落下，有治疗撑着的人更不容易被推回诊断标准，即使回升，也更容易早发现、早处理。【指南】

还有一点常被忽略：维持期是练习期。药物把症状压下去以后，人才有力气去做暴露、去重建社交、去恢复工作。如果这时候把治疗全部撤掉，练习也往往跟着停。

## 维持多久：一般原则与需要更长的人

没有一个适用于所有人的天数。医生通常会看四件事：这是第几次发作、缓解得彻不彻底、有没有残留症状、生活是否稳定。下面是一张粗略的参考表，不是处方。

| 情况 | 维持时间的大致方向 | 理由 |
|---|---|---|
| 首次发作、缓解彻底、功能恢复好 | 缓解后六到十二个月 | 复发风险相对低，但仍需度过高风险期 |
| 反复发作两次以上 | 数年，甚至更久 | 每次复发都会增加下一次的风险 |
| 有残留症状（睡眠差、易紧张、回避） | 更长，先处理残留 | 残留症状是复发的预测因素 |
| 合并抑郁、物质使用、失眠 | 更长，且分别治疗 | 共病会互相维持 |
| 家族史明显、起病早、病程长 | 更长 | 生物学易感性更高 |
| 生活压力大、支持少 | 更长，同时加强心理治疗 | 环境负荷高 |
| 老年人、孕产期 | 个体化 | 代谢、用药安全、激素变化都不同 |

“维持”不等于“终身吃药”。很多人可以在医生指导下，经过足够长的稳定期后缓慢减停；也有人需要更长期的治疗。这两者都是合理的，取决于病情，不取决于“意志力”。【指南】

## 复发的早期预警信号

复发很少是某天突然发生的，它通常先派几个“先遣部队”。越早认出来，处理越轻。

- [ ] 睡眠变浅、早醒、入睡困难，持续超过几天
- [ ] 担忧的时间变长，停不下来，开始影响工作
- [ ] 开始回避以前能做的事：地铁、超市、会议、聚会
- [ ] 心慌、胸闷、手抖、头晕等躯体症状回来
- [ ] 易怒、坐立不安、注意力下降
- [ ] 咖啡因、酒精、尼古丁的用量增加
- [ ] 反复查身体、反复查资料，越查越怕
- [ ] 出现“我是不是又要犯了”的念头，并因此更焦虑
- [ ] 不想复诊，想自己减药或停药
- [ ] 情绪低落、兴趣下降、觉得拖累别人

如果同时出现两三项，并持续一周以上，建议提前复诊，不要等“严重了再说”。这时候调整治疗，往往比复发后再治容易得多。

## 复发预防的四根柱子

| 支柱 | 具体做什么 | 谁来做 |
|---|---|---|
| 药物维持 | 按医嘱服药、不漏服、不自行减量 | 患者与医生 |
| 心理治疗与技能 | 继续暴露、认知练习、做复发预防计划 | 患者与治疗师 |
| 生活方式 | 睡眠、运动、咖啡因、酒精、压力管理 | 患者 |
| 支持与监测 | 家人、规律复诊、量表、预警清单 | 患者、家属与医生 |

四根柱子缺一根，房子未必立刻倒，但抗压能力会下降。最常见的情况是：药吃了，心理治疗停了；或者心理治疗做完了，生活方式一团糟；或者什么都做了，但不再复诊，直到复发才回来。

心理治疗的衔接尤其重要。CBT 结束前，通常会和治疗师一起做一份“复发预防计划”：列出预警信号、写一张应对卡、保留暴露练习清单、约定结束后几个月怎么自查。治疗结束后，可以在第一个月、第三个月、第六个月、第十二个月各回顾一次。遇到可预见的压力事件（比如换工作、考试、手术），提前把练习加回来，而不是等发作了再补救。

## 生活方式与一份自己的复发预防计划

生活方式不是治疗的配角。睡眠不足会直接放大焦虑，咖啡因会模拟心慌，酒精先压后弹，久坐和缺乏运动让压力更难代谢。这些因素单独看都很小，叠在一起足以把一个人推过阈值。

可以落地的几件事：

- 固定起床时间，比固定入睡时间更容易做到
- 每周规律运动，从快走开始，不追求强度
- 下午以后少喝咖啡、浓茶、能量饮料
- 不用酒助眠、不用酒压焦虑
- 戒烟可以安排在病情稳定期，必要时和医生讨论
- 保持固定的人际接触，哪怕只是每周一次散步
- 留出“什么都不做”的时间，而不是把日程排满

下面是一份可以自己填的复发预防计划，建议写下来，放在随手能拿到的地方：

- 我的预警信号是：______
- 我第一时间会联系的人：______（姓名、电话）
- 我自己能做的三件事：______
- 我的医生和下次复诊时间：______
- 我正在吃的药和过敏史：______
- 复发时要避免的事：喝酒、熬夜、自行加药、独自硬扛
- 如果出现自杀念头，我的安全计划是：见 [10.2 自杀风险与安全计划](<../模块10：风险管理/10.2 自杀风险与安全计划.md>)

### 容易踩的坑

**“好了就停。”**
“好了”通常只是症状缓解，不是风险结束。停药要按计划来，见 [11.3 停药计划与撤药管理](<../模块11：疗程、复发与停药/11.3 停药计划与撤药管理.md>)。

**“我怕一辈子吃药。”**
维持治疗不等于终身。很多人能在足够稳定后减停；也有人需要长期低强度维持。把担心说出来，和医生讨论，而不是自己停。

**“复发就是前功尽弃。”**
复发不是回到原点。你已经有的技能、对症状的理解、和医生的关系都还在，处理起来通常比第一次快。

**“上次的药这次自己买。”**
不建议。复发时的身体状况、合并用药、副作用风险都要重新评估。

**“心理治疗做完了，就万事大吉。”**
技能不用会退化。把暴露和认知练习当成像刷牙一样的事，定期做。

## 什么时候需要联系医生 / 去急诊

> **立即拨打 120 或去急诊：**
>
> - 出现自杀念头、自伤行为，或已经做了计划
> - 自行停药后出现抽搐、意识混乱、高热
> - 严重过敏、晕厥、剧烈胸痛
>
> **尽快联系医生（当天或次日）：**
>
> - 复发预警信号同时出现两三项，持续一周以上
> - 症状明显加重，回避范围扩大
> - 想减药或停药，或已经自行减量
> - 生活里发生重大变化（丧亲、失业、离婚、重病）
>
> **拨打 12356 心理援助热线：**
>
> - 复发后自责、羞耻，不敢联系医生
> - 夜里焦虑难忍，需要有人先说说话
