# 4.2 初诊准备与症状时间线

很多人第一次走进精神科诊室，坐下就卡住了：从哪儿说起？说“我焦虑”够不够？医生问“什么时候开始的”，只记得“好像很久了”；问“发作几次”，答不上来；明明有一堆检查单，却翻不出来。结果十分钟过去，最重要的信息没说清。这一页给你一套可直接照抄的准备方法：带什么、怎么讲、时间线怎么画、家属怎么补充，以及哪些事必须主动说。

## 一、医生最想知道的六件事

不管医生问得多细，核心就是六块。你可以按这个顺序准备：

1. **起病**：第一次是什么时候？当时发生了什么？是突然出现，还是慢慢加重？
2. **症状**：身体上、想法上、行为上分别有什么？最难受的是哪一项？
3. **频率与规律**：多久一次？一天几次？和什么情境有关（早上、晚上、开会、独处、月经前后）？
4. **影响**：工作、学习、睡眠、社交、家庭受到了什么影响？有没有请假、回避、放弃机会？
5. **既往治疗**：看过哪些科、做过什么检查、吃过什么药、效果如何、有没有副作用。
6. **背景**：睡眠、咖啡因、酒精、吸烟、躯体疾病、家族史、重大生活事件、性格与应对方式。

这六块讲清楚，比“我很焦虑”重复十遍有用得多。

## 二、画一条症状时间线

时间线不用精确到天，关键是“顺序”和“变化”。可以按下面的格式写：

> 2024年3月：换工作，开始睡不好，早上心慌。
> 2024年6月：第一次在地铁上突然心跳很快、胸闷、手麻，持续约十几分钟，去急诊查心电图正常。
> 2024年7–9月：又发作三四次，开始不敢坐地铁，改坐公交，出门要人陪。
> 2024年10月：看心内科，动态心电图正常；医生建议看心理科，没去。
> 2025年1月：担心加重，几乎每天下午心慌，开始失眠，喝酒助眠。
> 2025年3月：第一次来看精神科。

这条线里有起病、有转机、有回避、有检查、有酒精使用，医生一眼就能看出“发作—恐惧—回避—功能下降”的链条。**时间线不需要文采，需要顺序和具体。**【临床经验】

## 三、怎么描述一次发作

用“五问”把一次发作讲清楚：

| 问题 | 可以怎么说 |
|---|---|
| 什么时候、在哪里、在做什么？ | “上周二早上8点，地铁2号线，站着，没吃早饭。” |
| 第一个感觉是什么？ | “先是胸口发紧，然后心跳突然很快，像要跳出来。” |
| 最难受的时候什么样？ | “手麻、头晕、觉得要晕倒，怕自己死在车上。” |
| 持续多久？怎么缓解？ | “大概十几分钟，到站下车坐下，慢慢缓过来。” |
| 之后发生了什么？ | “当天不敢再坐地铁，第二天请假，之后改坐公交。” |

注意最后两问。**“之后发生了什么”往往比发作本身更重要**，因为它暴露了回避和安全行为，而这两样正是维持焦虑的关键。

## 四、带什么去，以及一张纸模板

### 带什么去

- [ ] 身份证、医保卡、就诊卡。
- [ ] 既往检查报告：血常规、甲状腺功能、心电图、动态心电图、心脏超声、影像等（按时间排序）。
- [ ] 正在吃的药：药盒、处方、药名和用法（包括中药、保健品、减肥药、感冒药）。
- [ ] 自己记的症状日记或量表（GAD-7、PHQ-9 等），标好日期。
- [ ] 一张写好的时间线和问题清单（见下一节模板）。
- [ ] 家属或知情朋友（如果愿意，且医生允许陪同）。
- [ ] 笔和纸，或手机备忘录，记医生的关键交代。

如果检查单太多，挑**最近的、异常的、和这次症状相关的**，其余拍照存手机。医生不一定有时间全部翻完，但你有准备，问诊会顺很多。

### 一张纸模板

把下面这张表打印出来，或照着手写在纸上，初诊时递给医生。

| 项目 | 我的情况 |
|---|---|
| 主要困扰（一句话） | 例如：反复心慌、胸闷，不敢坐地铁，怕自己猝死 |
| 第一次出现 | 年月、当时情境 |
| 到现在多久 | 例如：1年3个月 |
| 发作频率 | 例如：近1个月每周2–3次 |
| 最难受的症状（按顺序） | 心悸、胸闷、手麻、头晕、濒死感 |
| 什么情况容易诱发 | 独处、封闭空间、咖啡、熬夜、月经前 |
| 因为怕而回避的事 | 地铁、电梯、独自出门、运动 |
| 对生活的影响 | 请假、推掉出差、夫妻争吵 |
| 睡眠 | 入睡难、易醒、每晚睡几小时 |
| 咖啡因/酒精/吸烟 | 每天几杯咖啡、是否喝酒助眠 |
| 正在吃的药/保健品 | 名称、开始时间、效果、副作用 |
| 既往检查 | 做过什么、结果如何 |
| 既往治疗 | 心理治疗、药物、效果 |
| 希望医生帮我什么 | 例如：明确诊断、是否需要用药、怎么处理发作 |

这张纸的价值在于：**它把“我很痛苦”翻译成医生能快速处理的信息**，也避免你一紧张就忘。

## 五、必须主动说的事，家属怎么补充

### 这些事必须主动说

有些信息难以启齿，但对诊断和安全至关重要：

- **酒精**：喝多少、多久、是否用酒助眠或壮胆、有没有停酒后手抖出汗。
- **镇静药/安眠药**：是否自行加量、是否从别人那里拿药、是否想停。
- **咖啡因**：咖啡、浓茶、能量饮料、含咖啡因的感冒药或止痛药。
- **其他药物**：减肥药、激素、支气管扩张剂、含麻黄碱的制剂、保健品。
- **躁狂/轻躁狂史**：有没有过一段时间“精力特别好、睡得少也不困、话多、花钱大手大脚、冲动”。
- **创伤史**：有没有经历过事故、暴力、性侵、长期忽视。
- **自杀念头**：有没有想过死、有没有计划、有没有准备。
- **家族史**：直系亲属有没有焦虑、抑郁、双相、自杀、酒精问题。

这些不是“查户口”，而是直接影响诊断和用药安全。**你不需要一次说完，但不要说谎或省略。**

### 家属怎么补充

家属的观察常常比患者本人更客观，尤其是“变化”和“回避”。

- **说具体行为，不说评价**：“他这三个月没坐过地铁”“她每天晚上要检查门锁五六次”，比“他太焦虑了”有用。
- **说时间线**：“去年10月以后开始请假”，比“很久了”有用。
- **说功能变化**：“以前每周打球，现在不去了”“最近三个月瘦了十斤”。
- **说用药和饮酒**：有没有自行加量、有没有偷偷喝酒。
- **说风险**：有没有提到不想活、有没有自伤、有没有把东西送人。
- **不打断、不替患者回答**：医生问患者时，先让患者说，需要时再补充。
- **不当场指责**：诊室里说“他就是懒”，会让患者更难开口，也影响医生判断。

如果患者不愿意家属陪同，可以事先写一张纸条交给医生，或单独和医生沟通。

## 六、就医提示与常见问题

### 什么时候需要联系医生或去急诊

> **立即拨打120或去急诊：**
> - 胸痛、气短、晕厥、抽搐、意识障碍；
> - 自杀念头强烈、有具体计划，或已经自伤；
> - 酒精、镇静药突然停用后出现手抖、大汗、幻觉、意识混乱；
> - 服药后高热、大汗、肌肉僵硬、意识改变。

> **尽快联系医生：**
> - 初诊后症状没有按预期变化，或明显加重；
> - 服药后出现新的不适、过敏、心慌加重；
> - 出现情绪低落、失眠加重、坐立不安；
> - 想自行减药或停药（先问，不要自己动手）；
> - 准备怀孕、已经怀孕或哺乳。

### 常见问题

**“我说不清楚，会不会影响诊断？”**
不会。医生受过训练，会用提问帮你梳理。你带着时间线和检查单，已经比大多数初诊患者准备得好。

**“要不要把以前的诊断告诉医生？”**
要。包括别人给过的诊断、吃过的药、效果和副作用。误诊、改诊断在精神科并不罕见，信息越全，判断越准。

**“家属能不能进诊室？”**
多数医院允许，但医生可能会先单独问患者，再请家属补充。提前问一句“需要家属一起吗”更稳妥。

**“一次没说完，下次还要重新讲吗？”**
不用。初诊记录会留存，复诊时补充“这段时间的变化”即可。可以带一个固定的小本子，每次记三件事：变化、副作用、想问的问题。
