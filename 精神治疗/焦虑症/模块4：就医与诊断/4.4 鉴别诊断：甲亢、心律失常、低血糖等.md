# 4.4 鉴别诊断：甲亢、心律失常、低血糖等

心慌、手抖、出汗、气短、头晕——这些症状既可能是焦虑，也可能是甲状腺、心脏、血糖、呼吸或前庭系统出了问题。把所有的“心悸”都归为焦虑，会漏掉真正需要处理的疾病；反过来，把所有的“心悸”都当成心脏病，又会让人陷入反复检查、越查越怕的循环。这一页讲哪些病容易和焦虑混淆、各自的线索是什么、哪些症状必须查，以及怎么和医生一起把边界划清楚。

## 一、为什么不能把所有心悸都归为焦虑

心悸是一种主观感受，可能来自心跳太快、太重、太乱，也可能来自对正常心跳的过度注意。焦虑会让人心跳加快、对心跳更敏感，所以“焦虑→心悸”这条路是成立的。

但反过来，“心悸→焦虑”不成立。甲状腺功能亢进、心律失常、贫血、低血糖、嗜铬细胞瘤、药物副作用，都可以直接引起心悸、手抖、出汗，而这些症状又会让人紧张，形成“病→怕→更难受”的叠加。**这时候只治焦虑，等于只处理了回声，没有处理声源。**

一个实用的原则：**首次出现、症状剧烈、有躯体危险因素、伴随“不像焦虑”的特征时，先查躯体原因。**【指南】

## 二、常见需要鉴别的疾病

| 疾病 | 典型线索 | 常做的检查 |
|---|---|---|
| 甲状腺功能亢进 | 怕热、多汗、手抖、体重下降、食欲增加、腹泻、月经紊乱、甲状腺肿大、突眼 | 甲状腺功能（TSH、FT4） |
| 心律失常 | 心跳“漏一拍”、突发突止、活动时加重、伴头晕或晕厥 | 心电图、动态心电图、心脏超声 |
| 二尖瓣脱垂 | 心悸、胸闷、乏力，部分人有胸痛 | 心脏超声 |
| 低血糖 | 出汗、手抖、心慌、饥饿感、意识模糊，进食后缓解 | 血糖（发作时测最有价值） |
| 嗜铬细胞瘤 | 阵发性血压骤升、剧烈头痛、大汗、心悸 | 血/尿儿茶酚胺代谢物、影像 |
| 哮喘/慢阻肺 | 气短、喘鸣、咳嗽、夜间憋醒、活动后加重 | 肺功能、峰流速 |
| 贫血 | 乏力、面色苍白、活动后心慌气短 | 血常规 |
| 前庭疾病 | 天旋地转、耳鸣、听力下降、体位改变诱发 | 前庭功能检查、听力检查 |
| 药物/咖啡因/酒精 | 心慌、手抖、失眠，和摄入时间相关 | 详细用药与饮酒史 |
| 戒断反应 | 停酒或停镇静药后手抖、大汗、心跳快、幻觉、抽搐 | 病史为主，必要时急诊处理 |

下面挑几个最常被混淆的说细一点。

### 甲状腺功能亢进

甲亢是“披着焦虑外衣”的典型。患者会心慌、手抖、出汗、睡不好、容易发脾气、注意力下降，和广泛性焦虑几乎一模一样。区别常在这些地方：

- **怕热、多汗**，而不是怕冷；
- **吃得多却瘦**，体重明显下降；
- **腹泻、大便次数增多**；
- **月经量减少或紊乱**；
- **脖子粗、眼睛突出**（不是每个人都有）；
- **心率持续偏快**，安静时也快。

如果你有以上任何一项，尤其是体重下降和怕热，值得先查甲状腺功能。甲亢不处理，焦虑治疗也很难见效。

### 心律失常与二尖瓣脱垂

心律失常的表现差别很大。有人是“突然一阵心跳飞快，几分钟后突然停”，有人是“心脏漏一拍、咯噔一下”，有人是持续的心跳乱。**突发突止、活动时诱发、伴头晕或晕厥**，更提示需要心脏评估。

二尖瓣脱垂是一种相对常见的心脏结构问题，多数人没有严重问题，但可能有心悸、胸闷、乏力。需要说明的是：**过去曾把二尖瓣脱垂和惊恐障碍紧密联系，后来的研究并不支持“二尖瓣脱垂导致惊恐障碍”这种简单因果关系**。两者可能同时存在，但处理上要分别评估，不能互相替代。【研究】

心电图正常不代表没有心律失常——普通心电图只记录几十秒。如果症状是阵发性的，医生可能安排动态心电图（佩戴24小时或更久）、事件记录器或运动负荷试验。具体做什么，由心内科医生根据症状频率和风险决定。

### 低血糖

低血糖的典型表现是出汗、手抖、心慌、饥饿、焦虑、注意力不集中，严重时意识模糊、行为异常。它和焦虑的区分点在于：

- 和**进食时间**有关，空腹或漏餐后出现，吃东西后缓解；
- 糖尿病患者使用降糖药或胰岛素时尤其要警惕；
- 发作时测血糖最有价值，事后测可能已经正常；
- 严重低血糖可能危及生命，不能只当焦虑处理。

如果你反复出现“手抖、出汗、心慌、必须马上吃东西才好”，建议和医生讨论是否需要查血糖，尤其是正在用降糖药的人。

### 嗜铬细胞瘤

这是一种少见的肾上腺肿瘤，会阵发性释放肾上腺素，引起**血压骤升、剧烈头痛、大汗、心悸**，发作时非常像惊恐发作。它罕见，但危险，漏诊后果严重。

提示点：发作时血压明显升高（而不是正常或偏低）、头痛剧烈、大汗淋漓、发作持续十几分钟到一小时；可能有家族史。医生如果怀疑，会查血或尿的儿茶酚胺代谢物，必要时做影像。**不要因为“我查过肾上腺没事”就永远排除，也不要因为“网上一查就是它”而过度恐慌**——它罕见，判断靠医生。

### 呼吸系统疾病

哮喘、慢阻肺、肺栓塞都可能表现为气短、胸闷、心慌。提示点：

- 喘鸣、咳嗽、夜间憋醒、活动后加重（哮喘、慢阻肺）；
- 突发气短伴胸痛、咳血、单侧腿肿（需警惕肺栓塞，属急症）；
- 对支气管扩张剂有反应；
- 肺功能、峰流速、血氧有帮助。

另外，治疗哮喘的支气管扩张剂本身可能引起心慌、手抖，容易被误认为“焦虑加重”。

### 药物、咖啡因、酒精与戒断

这一类的“线索”在病史里，不在化验单上：

- **咖啡因**：咖啡、浓茶、能量饮料、部分感冒药和止痛药。每天几杯、什么时候喝、停了会不会好，都值得记录。
- **减肥药、兴奋剂**：部分成分会明显加快心率、加重焦虑。
- **激素、甲状腺素、支气管扩张剂、含麻黄碱的制剂**：可能引起心慌、失眠。
- **抗抑郁药早期**：部分人开始服药时会出现焦虑、心慌、恶心，通常会随适应减轻，但需要医生评估。
- **酒精**：喝酒当下放松，代谢后反跳性焦虑、失眠、心跳快；长期大量饮酒后突然停酒，可能出现手抖、大汗、幻觉、抽搐，**这是急症，不能自行硬戒**。
- **苯二氮䓬类**：长期使用后突然减停，可能出现焦虑反跳、失眠、心慌、震颤，严重时抽搐。**必须在医生指导下缓慢减量。**

### 前庭疾病

眩晕、天旋地转、走路不稳、恶心，常被当成“焦虑发作”。区别点：

- 真正的旋转性眩晕，常伴眼震、耳鸣、听力下降；
- 体位改变诱发（如起床、翻身）提示良性阵发性位置性眩晕；
- 突然听力下降伴眩晕，需尽快耳鼻喉科就诊；
- 焦虑相关的头晕多是“头重脚轻、飘、站不稳”，较少真正的旋转。

## 三、哪些症状必须查

以下情况，不建议先按焦虑处理，应先做躯体评估：

- [ ] 首次出现的心悸、胸痛、气短，尤其年龄偏大或有心血管危险因素。
- [ ] 活动时诱发、休息缓解的胸闷胸痛。
- [ ] 晕厥或差点晕厥。
- [ ] 心跳持续过快（安静时也快）或明显不规则。
- [ ] 不明原因体重下降、怕热、多汗、手抖、腹泻。
- [ ] 阵发性血压骤升伴头痛、大汗。
- [ ] 反复低血糖样发作，尤其是糖尿病患者。
- [ ] 喘鸣、夜间憋醒、咳血、单侧腿肿。
- [ ] 旋转性眩晕伴耳鸣、听力下降。
- [ ] 长期饮酒或使用镇静药，准备减停。
- [ ] 正在服用可能引起心悸、焦虑的药物。

**“必须查”不等于“全套查”。** 查什么、查到什么程度，由医生根据病史、体征和风险因素决定。过度检查也有代价：增加焦虑、浪费资源、可能发现无意义的“小异常”而引发新的担心。

## 四、什么时候需要联系医生或去急诊

> **立即拨打120或去急诊：**
> - 突发剧烈胸痛、压榨感，持续不缓解，或放射到手臂、下颌；
> - 突然严重气短、口唇发紫、咳血；
> - 晕厥、抽搐、意识障碍；
> - 心跳极快且伴胸痛、头晕、眼前发黑；
> - 血压骤升伴剧烈头痛、大汗、呕吐；
> - 低血糖后意识模糊、行为异常，进食后不缓解；
> - 酒精或镇静药戒断出现幻觉、抽搐、高热。

> **尽快到相应专科就诊：**
> - 反复心悸、胸闷，普通心电图正常但症状频繁；
> - 体重下降、怕热、手抖、腹泻；
> - 反复低血糖样发作；
> - 喘鸣、活动后气短；
> - 旋转性眩晕、耳鸣、听力下降；
> - 正在用药，怀疑与症状有关。

## 五、常见问题与容易踩的坑

**“我查了心电图正常，是不是就说明心脏没问题？”**
普通心电图只记录几十秒，阵发性问题可能抓不到。如果症状频繁或伴晕厥，需要和医生讨论更长时间的监测。但也不意味着要无限查下去，具体由心内科判断。

**“是不是所有心悸都是焦虑？”**
不是。心悸的原因很多，焦虑只是其中之一。反过来，焦虑也确实会引起心悸。**两者可以同时存在**，所以要“边查边治”，而不是二选一。

**“我查了很多次都没事，还需要查吗？”**
如果已经做过规范评估、风险因素低、症状模式稳定，反复检查的收益会下降，反而可能强化焦虑。可以和医生明确问：“以我的情况，还需要查什么？查完之后，如果正常，我们怎么处理这个担心？”

**“甲亢查一次正常，是不是就永远没事？”**
甲状腺功能会变化。如果症状持续或出现新线索，医生可能复查。是否复查、多久复查，由医生决定。

**“我是不是应该先治焦虑，还是先查身体？”**
多数情况可以并行：先做必要的排查，同时开始焦虑的评估和干预。**急症优先，排查与治疗不冲突。**
