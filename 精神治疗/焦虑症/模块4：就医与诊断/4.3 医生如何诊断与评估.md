# 4.3 医生如何诊断与评估

“医生就问了我十几分钟，做了个量表，就说是焦虑症，靠谱吗？”这是初诊后最常见的疑问之一。有人觉得诊断太轻率，有人觉得医生问得太少。这一页讲精神科医生到底怎么做出诊断：访谈问什么、为什么要看病程和功能、量表在其中占什么位置、需要排除哪些情况，以及为什么“诊断”常常是一个随时间修正的过程。

## 一、诊断不是“做个量表”

量表是筛查和追踪工具，不是诊断工具。GAD-7 分数高，只能说明“最近两周焦虑水平偏高”；它不能区分广泛性焦虑、惊恐障碍、社交焦虑，也不能排除甲状腺问题、心律失常、药物副作用。**真正的诊断来自临床访谈：症状、病程、功能损害、排除其他原因，四块拼起来。**【指南】

可以这样理解：

- **量表**回答“有多重”；
- **访谈**回答“是什么、多久了、影响多大、还有什么”；
- **检查**回答“是不是别的病”；
- **时间**回答“治疗反应对不对、诊断要不要改”。

只做量表就下诊断，就像只看体温计就判断是肺炎还是流感——体温有用，但远远不够。

## 二、临床访谈会问什么

一次规范的精神科初诊，通常会覆盖这些方面：

| 维度 | 医生可能问什么 | 为什么重要 |
|---|---|---|
| 主诉 | 最难受的是什么？什么时候开始的？ | 确定核心问题 |
| 现病史 | 症状、频率、诱因、加重缓解因素 | 判断是否符合诊断标准 |
| 病程 | 持续多久？是持续存在还是发作性？ | 区分不同类型 |
| 功能 | 工作、学习、睡眠、社交受影响吗？ | 判断严重度与治疗强度 |
| 既往治疗 | 看过什么科、做过什么检查、用过什么药 | 避免重复、判断难治 |
| 躯体情况 | 有没有甲亢、心脏病、哮喘、糖尿病 | 排除躯体原因 |
| 物质使用 | 咖啡因、酒精、吸烟、镇静药、减肥药 | 排除物质所致 |
| 风险 | 有没有自杀念头、自伤、冲动 | 安全评估 |
| 家族史 | 直系亲属有没有焦虑、抑郁、双相 | 辅助判断 |
| 人格与应对 | 一贯的性格、遇到压力的方式 | 理解个体差异 |

访谈不是“查户口”，而是把碎片拼成一条能解释症状的线索。**一个好医生会追问细节**：不是“你焦虑吗”，而是“上次发作时，你第一个感觉到什么？当时在做什么？后来怎么处理的？”

## 三、病程和功能损害，是诊断的两根柱子

同样是“紧张、心慌”，持续三天和持续三年，意义完全不同；偶尔发作和每天发作，处理方式也不同。

**病程**帮助区分类型：

- 广泛性焦虑：长期、弥散、多数日子存在；
- 惊恐障碍：反复的意外发作，加上至少一个月担心再发或行为改变；
- 社交焦虑：特定社交情境、持续较长时间；
- 特定恐惧：特定对象、即时反应、回避；
- 分离焦虑：与依恋对象分离相关，儿童至少四周、成人至少六个月。

**功能损害**决定“算不算病”和“要不要治”。诊断标准里通常都要求“造成明显痛苦或功能损害”。功能包括：工作/学业、家庭、社交、睡眠、日常生活。**一个人还能上班，不代表没有损害**——可能是在用额外的力气硬撑。

## 四、需要排除的那些“看起来像焦虑”的情况

这是诊断中最容易被忽略、也最影响治疗的部分。

**双相障碍**：如果患者有过躁狂或轻躁狂发作（精力旺盛、睡眠需求减少、话多、思维奔逸、花钱冲动、行为鲁莽），单独用抗抑郁药可能诱发转躁或快速循环。所以医生会专门问“有没有一段时间状态特别高”。这一点必须主动说，不要因为“那段时间感觉挺好”就省略。

**抑郁障碍**：焦虑和抑郁常同时存在。抑郁以情绪低落、兴趣减退、精力下降为核心，焦虑以担忧、恐惧、紧张为核心。两者共病时，治疗顺序和药物选择会不同。

**创伤后应激障碍（PTSD）**：经历过重大创伤后，出现闪回、噩梦、回避、警觉性增高。如果只按焦虑治，不处理创伤，效果往往有限。

**强迫症（OCD）**：反复的念头（污染、伤害、对称）和重复行为（清洗、检查、计数）。强迫和焦虑有重叠，但治疗重点不同，需要区分。

**物质或药物所致**：咖啡因、酒精、尼古丁、减肥药、激素、含麻黄碱的感冒药、某些哮喘药，都可能引起心慌、手抖、失眠。酒精或镇静药戒断也会表现为焦虑。

**躯体疾病**：甲状腺功能亢进、心律失常、低血糖、嗜铬细胞瘤、哮喘、前庭疾病等。详见[4.4 鉴别诊断：甲亢、心律失常、低血糖等](<4.4 鉴别诊断：甲亢、心律失常、低血糖等.md>)。

**其他**：人格特质、孤独症谱系、注意缺陷多动障碍、痴呆早期、慢性疼痛、睡眠障碍，都可能以“焦虑”的面貌出现。

## 五、量表、检查与诊断过程

### 量表的位置：筛查、分级、追踪

常用的量表各有分工：

| 量表 | 测什么 | 主要用途 |
|---|---|---|
| GAD-7 | 广泛性焦虑的严重度 | 筛查、追踪 |
| PDSS | 惊恐障碍的严重度 | 评估发作与回避 |
| LSAS / SPIN | 社交焦虑的范围与严重度 | 筛查、追踪 |
| SCARED | 儿童青少年焦虑 | 儿童筛查 |
| PHQ-9 | 抑郁严重度 | 共病筛查 |
| 自评/他评功能量表 | 工作、社交、家庭功能 | 判断损害程度 |

量表的正确用法是：**治疗前测一次作为基线，治疗中定期复测看趋势**。单次高分不能确诊，单次低分也不能排除。量表还会受最近事件、睡眠、作答动机影响。

有些医院会做**结构化访谈**（如 SCID），由受过训练的人员逐条询问诊断标准，比自由访谈更系统，但耗时较长，不是每个门诊都做。

### 躯体检查：不是每个人都全套，但不能跳过该查的

精神科医生通常会做简单的体格检查（血压、心率、甲状腺触诊等），并根据病史安排化验。常见的有：

- 血常规、甲状腺功能、血糖、电解质、肝肾功能；
- 心电图，尤其是有心悸、胸痛、晕厥，或准备用可能影响心脏的药物时；
- 育龄女性可能需要妊娠试验；
- 有物质使用史时，可能需要尿检；
- 有晕厥、活动后气短时，可能需要动态心电图、心脏超声、肺功能。

**不是所有焦虑患者都需要全套检查**，但“该查的没查”和“查得过多”都是问题。前者漏诊，后者增加焦虑和费用。判断依据是病史、体征和风险因素。

### 诊断是一个过程，不是一次判决

精神科的诊断，更像一个**工作假设**：根据现有信息给出最可能的方向，开始治疗，观察反应，再修正。

几种常见情况：

- 一开始诊断为 GAD，治疗中发现反复的惊恐发作，诊断调整为惊恐障碍；
- 一开始只看到焦虑，后来出现明确的抑郁发作，需要同时处理；
- 治疗无效时，回头发现是双相、PTSD、OCD 或躯体疾病；
- 青少年早期诊断为社交焦虑，随发育发现同时有孤独症谱系特征。

所以复诊时医生会反复问：“这一个月怎么样？药有没有用？有没有新情况？”这不是“上次没看准”，而是精神科诊断的常态。**你可以主动提供信息，帮助医生修正判断。**

### 你可以问医生的几个问题

- [ ] 我的诊断是什么？依据是什么？
- [ ] 还需要排除哪些躯体或精神方面的问题？
- [ ] 需要做哪些检查？为什么做？
- [ ] 目前严重程度属于哪一档？对功能的影响有多大？
- [ ] 治疗选择有哪些？心理治疗、药物，还是联合？
- [ ] 起效大概要多久？怎么判断有没有效？
- [ ] 出现什么情况需要提前复诊或去急诊？
- [ ] 下次复诊前，我需要记录什么？

问这些问题不会“得罪”医生，反而能让你更清楚自己在治什么。

## 六、就医提示与常见问题

### 什么时候需要联系医生或去急诊

> **立即拨打120或去急诊：**
> - 胸痛、气短、晕厥、抽搐、意识障碍；
> - 自杀念头强烈、有具体计划，或已经自伤；
> - 服药后高热、大汗、肌肉僵硬、意识改变；
> - 酒精、镇静药突然停用后出现戒断反应。

> **尽快联系医生：**
> - 治疗数周后毫无改善，或症状明显加重；
> - 出现新的症状，尤其是情绪高涨、睡眠需求减少、冲动行为；
> - 出现药物不良反应；
> - 想调整或停止治疗，先和医生讨论。

### 常见问题与容易踩的坑

**“网上说我是焦虑症，还需要看医生吗？”**
需要。网络信息可以帮你描述问题，但不能排除躯体疾病、双相、PTSD、药物因素。自我诊断最大的风险不是“贴错标签”，而是漏掉真正需要处理的问题。

**“量表分数正常，是不是就没病？”**
不是。量表测的是最近两周的典型症状，可能漏掉回避、躯体化、发作性症状。诊断看的是整体。

**“医生只问了十分钟，是不是不认真？”**
时间长短不是唯一标准。有经验的医生会抓关键线索，配合量表、检查、既往资料。如果你觉得没说完，可以复诊时补充，或换一位医生再听一次意见。

**“诊断会不会变？”**
会，而且不罕见。诊断随信息更新而修正，是负责任的表现，不是“庸医”。
