# 12.1 急诊指征与危机资源

这一页只回答一个很具体的问题：**眼前这个情况，能不能等到明天门诊？**
它写给正在发作的人，也写给旁边那个拿着手机、不知道要不要打 120 的家属。
读完你会带走三样东西：一张“哪些症状必须先当躯体急症处理”的对照表，一套在电话里把情况说清楚的顺序，一份陪护者当场就能照着做的清单。
原则只有一句：**不确定的时候，按严重处理。宁可白跑一趟，不要赌。**

## 先分清三种“急”

焦虑相关的情况里，“急”其实有三种，处理路径完全不同，混在一起就容易耽误。

**第一种是躯体急症。** 心肌梗死、肺栓塞、主动脉夹层、严重心律失常、低血糖、哮喘急性发作，都可以表现为“突然心慌、胸闷、喘不上气、出大汗”。这些病和惊恐发作的症状高度重叠，靠感觉分不出来，只能靠检查和病史。**首次出现、性质与以往不同、或者本人有心血管危险因素时，先按躯体急症走。**

**第二种是精神科急症。** 正在实施或即将实施的自伤、自杀行为，严重兴奋躁动、伤人风险，意识混乱、谵妄，以及精神病性症状支配下的危险行为。这类情况需要急诊和精神科会诊，不是“聊一聊就好”。

**第三种是戒断急症。** 长期大量饮酒后突然停酒，或长期服用苯二氮䓬类、镇静催眠药后突然停药，可能出现抽搐、幻觉、意识障碍、高热，**可以危及生命**。这一类最容易被“我自己扛一扛”耽误。

| 类型 | 典型表现 | 第一动作 |
|---|---|---|
| 躯体急症 | 突发剧烈胸痛、压榨感、放射到手臂或下颌、大汗、真正晕倒、静息下喘不上气 | 拨打 120，不要自己开车 |
| 精神科急症 | 正在自伤、写好遗书、囤药、说“不想活了”并有计划、意识混乱 | 不要独处，拨打 120 或送急诊，同时通知可信任的人 |
| 戒断急症 | 停酒或停药后手抖、大汗、心跳很快、看见或听见不存在的东西、抽搐 | 立即急诊，并告诉医生具体用了什么、用了多久 |

【指南】焦虑障碍的规范治疗里，“排除躯体原因”是第一步，不是可选项。已经确诊焦虑障碍，也不等于以后所有胸痛都可以归给焦虑。

## 胸痛、气短、晕厥：先按躯体急症处理

惊恐发作时，心跳加快、呼吸变浅变快、胸口发紧、手脚发麻、头晕、有濒死感，这些都是真实的生理反应，不是“想出来的”。**惊恐发作本身通常不致命**，这是可以让人安心的一点【指南】。

但这句话有一个必须配套的前提：**它只适用于已经排除躯体急症、并且症状性质与以往一致的情况。** 对第一次发作的人、症状不典型的人、有心脏病史的人，先做检查再谈焦虑，是负责任的做法，不是过度医疗。

下面这些特征，更倾向于“先排除躯体急症”：

- 胸痛是压榨样、闷痛，持续十几分钟不缓解，或放射到左臂、下颌、后背。
- 伴随大汗淋漓、恶心呕吐、明显的濒死感，且与活动或情绪激动有关。
- **真正失去意识**（晕厥）。惊恐发作时头晕、腿软很常见，但真正晕倒并不常见，晕厥要单独查原因。
- 静息状态下突然喘不上气，说话只能一个字一个字往外挤，或嘴唇发紫。
- 心跳快到无法计数、伴眼前发黑，或有心脏病、高血压、糖尿病、吸烟史、早发心脏病家族史。
- 近期长期卧床、手术后、长途旅行后出现气短伴胸痛，要想到肺栓塞。
- 老年人、女性、糖尿病患者的症状可能不典型，只表现为乏力、上腹不适、气短，更容易被当成“焦虑”。

| 表现 | 更像惊恐发作 | 更需要先排除躯体急症 |
|---|---|---|
| 起病 | 常在几分钟内冲到高峰，二三十分钟后逐渐回落 | 持续加重，或超过半小时不缓解 |
| 诱因 | 常与压力、咖啡因、睡眠不足、特定情境有关 | 与活动、体位、外伤、手术后相关 |
| 意识 | 清醒，能说话，能描述“我要死了” | 真正晕倒、意识模糊、叫不醒 |
| 既往 | 有明确的惊恐发作史，本次“和以前一样” | 首次发作，或本次“从来没这么疼过” |

> **什么时候需要联系医生 / 去急诊**
> 首次出现突发剧烈胸痛、静息下呼吸困难、真正晕厥、抽搐、嘴唇发紫、大汗伴恶心——**立即拨打 120**。
> 已经确诊焦虑障碍，但本次症状与以往明显不同、持续时间明显更长、含服急救药无效——**按躯体急症处理，去急诊**。
> 拿不准的时候，先打 120。急救人员不会因为你“其实没事”而责怪你。

## 自杀念头与自伤：不要独处，也不要只靠热线

出现“不想活了”“活着没意思”“如果没有我大家会轻松些”这类念头，本身就是需要认真对待的信号，不是矫情，也不是“说说而已”。焦虑合并抑郁时，自杀风险会明显升高【指南】，这一条值得每个家属知道。

关于“要不要问”，很多人怕问了会“提示”对方。目前的共识是：**直接问不会增加风险，反而常常让人松一口气**——终于有人愿意听。可以这样问：“你最近有没有想过不想活了？”“有没有想过具体怎么做？”问完不要急着讲道理，先说“谢谢你告诉我”。

真正降低当下风险的，是几件很具体的事：

1. **不要让人独处。** 哪怕只是陪着坐在客厅，也比“你自己静一静”安全。
2. **把手段拿远。** 药物、刀具、绳索、农药，能收起来的收起来，能交给别人保管的交给别人。这一步比任何劝说都有效【指南】。
3. **陪同去急诊或精神科。** 有明确计划、已经开始准备、或已经自伤，直接去最近医院急诊，不要等预约。
4. **不要答应“绝对保密”。** 可以承诺“我只告诉能帮上忙的人”，但不能承诺一个人扛。

关于热线，需要说清楚它的位置：**心理援助热线能陪你把最难的那一个小时熬过去，但它不是急救系统。** 热线接线员通常无法定位你的位置、无法派车、无法上门。所以在“已经站在窗边”“手里已经有药”这种迫切危险里，热线不能作为唯一手段，**必须同时拨打 120，或让身边的人送你去急诊**。

| 号码 | 适合什么时候打 | 能做什么 | 不能做什么 |
|---|---|---|---|
| 120 | 胸痛、气短、晕厥、抽搐、服药过量、正在自伤、有立即生命危险 | 派救护车、途中急救处置、送到有急诊能力的医院 | 不负责长期心理治疗，不负责调解家庭矛盾 |
| 110 | 有人正在实施危险行为、走失、被困、需要现场协助、无法自行送医 | 出警到现场、维持秩序、协助送医、联系家属 | 不提供医疗判断，是否出警由接警单位按情况决定 |
| 12356 | 情绪崩溃、极度焦虑、需要有人听、需要被转介到当地资源 | 心理支持、危机干预、转介 | 不能替代急救，不能派车，不能保证即时定位 |

12356 是国家卫生健康委统一部署的心理援助热线，2025 年起在全国推行。各省市还有自己的心理援助热线，**具体号码和服务时间以当地卫健委公布为准**；同一个号码在不同地区的接通方式可能不同，打之前可以先在本地卫健委官网确认。

## 戒断：酒精、苯二氮䓬类、镇静催眠药

这一类危险最容易被低估，因为当事人往往觉得“我是在往好的方向走”。

**酒精戒断。** 长期大量饮酒的人突然停酒，可能在数小时到数天内出现手抖、出汗、心跳加快、焦虑加重、失眠，进一步可能出现幻觉（看见虫子、听见人声）、抽搐，最严重的震颤谵妄会出现意识模糊、高热、大汗，**有生命危险**。所以长期大量饮酒的人戒酒，应该在医疗机构评估和监护下进行，**不要自行硬戒**。

**苯二氮䓬类戒断。** 这类药药名多带“西泮”“唑仑”，突然减停可能出现焦虑反跳、失眠、心慌、出汗、手抖、肌肉抽动，也可能出现抽搐、意识混乱。**必须由医生制定缓慢减量计划**，不能自己掰着吃、想起来就停。

**抗抑郁药的撤药反应。** SSRI、SNRI 突然停用常出现头晕、类似触电感、恶心、烦躁、睡眠变差，通常不危及生命，但很难受，也容易被误认为“病又回来了”。同样应该由医生安排减量。

下面这些情况，请立刻去急诊，并且**主动告诉医生用药和饮酒的详细情况**：

- [ ] 停酒或停药后出现抽搐，哪怕是第一次、只有几十秒。
- [ ] 停酒或停药后看见、听见不存在的东西，或说话前言不搭后语。
- [ ] 高热、大汗、心跳持续很快、意识模糊。
- [ ] 停药后出现强烈的自伤冲动。
- [ ] 不知道自己吃了多少药，或同时喝了酒。

> 到医院后，把药盒、酒的种类和大概量、最后一次使用的时间都告诉医生。这些信息直接决定怎么处理，“怕被说”而隐瞒，风险最大。

## 电话里怎么把情况说清楚

急救调度最需要的是**位置**和**状态**，不是完整的病史。按下面的顺序说，通常一分钟内能说完：

- [ ] 先说地址：小区名、楼栋、单元、门牌号，以及门口明显的标志物。说不清就报最近的路口或商铺。
- [ ] 再说人：几个人、大概年龄、男或女、现在有没有意识、能不能说话、有没有呼吸。
- [ ] 说最要紧的症状：胸痛？喘不上气？抽搐？吃了多少药？有没有出血？
- [ ] 说正在吃的药：药名念不出来就把药盒放在门口，或者拍照。
- [ ] 说最近的变化：这几天有没有停药、减药、喝酒、发烧、熬夜。
- [ ] 留一个能接通的电话，并保持手机畅通。
- [ ] **不要先挂电话**，等对方说可以挂。调度员可能会在电话里指导你做心肺复苏或止血。

如果是给不在身边的家人求助，除了地址，还要说清楚“门能不能进去”“有没有人陪着”“有没有养狗”，这些会直接影响救援。

## 陪护者做什么、不做什么

陪护者在现场的判断，往往比患者自己更可靠。下面这张表可以直接照着做。

| 可以做 | 尽量不要做 |
|---|---|
| 留在身边，用平稳、简短的话说明“我在” | 反复争辩“你就是想太多”“这是心理作用” |
| 降低刺激：关灯、关电视、让围观的人散开 | 围着患者不停追问“你到底怎么了” |
| 帮患者放慢呼气，不强行要求“深吸一大口” | 拿塑料袋罩住口鼻，或强迫大量喝水 |
| 收起药物、刀具等危险物品，代为保管 | 承诺“我绝对不告诉任何人” |
| 记录时间线：几点开始、什么症状、吃了什么药 | 因为“上次也是焦虑”就把这次也当成焦虑 |
| 带上药盒、病历、医保卡、身份证 | 在胸痛、晕厥、抽搐时自己开车送，而不是叫救护车 |
| 到急诊后主动告诉分诊护士“有自杀念头” | 在患者面前和医生讨论“他是不是装的” |

有一句话值得所有家属记住：**陪伴不等于说服。** 你不需要在当下把道理讲通，你只需要让危险的那几个小时过去。

## 到急诊之后会发生什么

急诊的分诊台会先判断紧急程度，所以“看起来不严重”的人可能要等。这不是不重视，而是按危及生命的可能性排序。

常见的流程是：问病史和用药史 → 量血压、血氧、做心电图 → 抽血查心肌酶、血糖、电解质、甲状腺功能等 → 必要时留观或住院。**急诊里的“焦虑”是一个排除性判断**：先排除心脏、肺、代谢、药物原因，再考虑焦虑。所以医生说“心电图没事”，不等于“你没事”，而是“心脏急症暂时排除了”，后面还需要到精神科或心理科继续评估。

如果急诊评估后建议你去看精神科门诊，请尽量在几天内去，不要拖成“下次再说”。急诊解决的是“现在有没有生命危险”，不解决“接下来怎么治”。

## 常见问题与容易踩的坑

**“我每次都这样，还用去医院吗？”**
如果本次和以往完全一样、有明确的惊恐发作史、以往检查齐全，可以先按[10.1 惊恐发作的现场应对](<../模块10：风险管理/10.1 惊恐发作的现场应对.md>)处理，并尽快联系你的医生。但只要有“这次不一样”的感觉，就按躯体急症处理。

**“去了急诊说没事，是不是白花钱？”**
排除急症本身就是结果。一次心电图和心肌酶，买的是“可以安心”和“没有漏掉”。

**“半夜没有精神科门诊怎么办？”**
综合医院急诊通常可以处理急性危机并联系精神科会诊；也可以拨打 12356。有立即危险时，120 优先。

**“热线占线怎么办？”**
换一个号码，或直接去急诊。**占线不是“没人管你”的证据，只是那一刻线路满了。**

**最容易踩的坑：把“不要紧”提前用在还没检查的人身上。** 焦虑的知识是用来减少恐惧的，不是用来劝人不去医院的。
