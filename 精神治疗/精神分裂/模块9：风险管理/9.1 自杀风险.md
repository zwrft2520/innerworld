# 9.1 自杀风险

自杀是可以被问出来、被说出来、被干预的。很多人以为“不问就没事”“问了反而提醒他”，事实恰恰相反：一个被认真问过、被认真听过的人，往往更容易开口求助。这一页讲五件事：哪些因素会让风险升高、怎么直接把话问出口、风险怎么分级、安全计划怎么写、家里的危险物品怎么处理。它写给患者，也写给想知道“我该怎么接话”的家属。

## 一、先破除一个误解：问了不会“教坏”他

“直接问会不会给他一个念头？”这是家属最常有的担心。目前的证据是：**平静、直接地询问自杀想法，不会增加自杀风险，反而常常带来缓解**【研究】。因为很多人不是“不想说”，而是“不知道怎么说”“怕吓到别人”“怕被当成威胁”。

真正危险的是另一种沉默：所有人都察觉到不对劲，但没人敢开口，最后在事后说“早知道就问了”。

需要说清楚的是：问出来，不等于你能独自解决。你的任务不是“说服他别死”，而是**知道情况有多严重，然后把他带到能处理的人面前**。

## 二、风险因素：找那些“可以改”的部分

风险因素不是算命。它的用处是帮你判断“现在该多紧张”，以及哪些环节可以动手改。

| 类别 | 具体因素 |
|---|---|
| 疾病相关 | 合并抑郁、绝望感、命令性幻听、严重被害妄想、自知力差、近期复发或刚出院 |
| 既往史 | 曾经自杀未遂（尤其近期、方式致命）、家族中有自杀史 |
| 物质使用 | 大量饮酒、使用大麻或其他物质、混合使用 |
| 社会因素 | 独居、失业、经济困难、亲密关系破裂、丧亲、被歧视或霸凌、刚经历羞辱性事件 |
| 治疗相关 | 刚换药或加药、治疗中断、对治疗失望、缺乏随访 |

有几个时间点要特别留意：**出院后的头几周**、**刚被诊断时**、**复发前后**、**重要关系破裂后**、**法律或经济危机中**。这些时候风险会集中升高。

保护因素同样真实：稳定的家庭支持、还愿意看的医生、对孩子的责任感、宗教信仰、还有没完成的事、怕痛苦。它们不能“抵消”风险，但能争取时间。

## 三、怎么直接问：从轻到重，一层层往下

不要一上来就问“你是不是想自杀”，也不要问“你不会想不开吧”——后者等于给了他一个“应该否认”的台阶。

可以这样开口：

> “我注意到你最近很少说话，晚上也睡不好。我想直接问你一件事，因为我在意你：你有没有觉得，活着没什么意思？”

然后根据回答往下走，一层一层来：

1. **有没有消极念头**：“有没有想过，要是睡过去不醒就好了？”
2. **有没有自杀想法**：“有没有想过结束自己的生命？”
3. **有没有计划**：“有没有想过具体怎么做？”
4. **有没有准备**：“有没有准备东西、选地方、选时间？”
5. **有没有行动**：“最近有没有做过什么，或者开始安排后事？”

问的时候记住几点：

- **平静。** 不要惊呼、不要哭、不要立刻说教。你的表情越稳，他越敢说。
- **具体。** 问“什么时候”“用什么方式”“当时在想什么”，比问“你为什么”更有用。
- **不评判。** 不说“你怎么这么自私”“你还有孩子”“想想你爸妈”。
- **不承诺保密。** 如果涉及生命安全，你需要告诉医生和能帮忙的人。可以提前说：“如果我知道你有危险，我会告诉医生，因为我不想失去你。”
- **记录下来。** 时间、原话、当时的情境，复诊时告诉医生。

## 四、风险分级：不同级别，不同动作

分级不是为了贴标签，而是为了决定“今晚能不能回家”。

| 级别 | 大致表现 | 该做什么 |
|---|---|---|
| 低 | 偶尔有“活着没意思”的念头，没有计划，能自我调节，有支持 | 尽快看门诊，写安全计划，加密随访，处理诱因 |
| 中 | 经常有自杀想法，有模糊计划但没准备，情绪冲动 | 尽快精神科评估（当天或次日），家属陪伴，限制手段，考虑住院 |
| 高 | 有明确计划、已做准备、近期尝试过、命令性幻听让他去死、极度绝望或激越 | 立即去急诊或拨打 120，不要独处，不要让他开车 |
| 极高 | 正在实施、已服药、已割伤、已站在高处 | 立即拨打 120 和 110，现场急救，不要独自搬动 |

判断时宁可往上靠一级。**“拿不准”本身就是需要专业评估的理由。**

## 五、安全计划：写下来，比记在心里有用

安全计划不是“保证不自杀”的承诺书，而是一张“当念头来了，我按顺序做什么”的路线图。可以和他一起写，写在一张纸上，放在他看得到的地方。

- [ ] **第一步：我的预警信号**（比如连续两晚睡不着、开始送东西、反复听某个声音）
- [ ] **第二步：我自己能做的事**（洗冷水脸、出门走十分钟、听固定的歌单、写下念头）
- [ ] **第三步：能让我分心的人或地方**（朋友、便利店、公园、宗教场所）
- [ ] **第四步：我可以打电话的人**（写具体名字和号码，至少两个）
- [ ] **第五步：专业帮助**（精神科门诊电话、急诊地址、12356 心理援助热线）
- [ ] **第六步：让环境更安全**（把药、刀、绳索、农药收起来，具体做法见下面的“手段限制”）

这份计划要**定期更新**，复诊时带给医生看。人在急性期写不出来，可以等稍微稳定一点再一起补。

### 手段限制：最有效、也最容易被跳过的一步

自杀冲动往往不是持续几天，而是几分钟到几小时的“窗口期”。把致命手段挪远一点，就能把这个窗口拖过去。

- **药物**：由家属保管，按次给；家里不留大量存货；过期药及时处理。
- **刀具、剪刀、绳索、皮带**：收进上锁的抽屉。
- **农药、消毒剂、清洁剂**：锁起来，不要放在阳台或厕所。
- **高处**：窗户装限位器，阳台门加锁；不要让他独自去天台、楼顶。
- **煤气、炭**：注意通风和阀门。
- **车钥匙**：高风险期由家人保管。

这些做法可能让他觉得“被监视”“不被信任”。可以这样解释：“这不是因为我不信你，是因为我想让你在难受的那几个小时里，多一点时间。”【临床经验】

## 六、家属怎么接话：能说的和别说的

| 可以说 | 尽量别说 |
|---|---|
| “我不知道该说什么，但我在这儿。” | “你想开点就好了。” |
| “你现在很难受，我想听你多说一点。” | “你还有孩子、父母，你不能这样。” |
| “我不会因为这个看不起你。” | “你怎么这么脆弱。” |
| “我们一起去找医生，我陪你去。” | “你要是敢做，我就……” |
| “我需要告诉医生，因为我怕失去你。” | “我保证不告诉任何人。”（做不到的承诺） |

还有几句是家属自己需要听到的：

- 他自杀，不是因为你不够好。精神疾病会让人产生“没有出路”的感觉，那是症状的一部分。
- 你可以害怕、可以崩溃、可以找人帮忙。照护者也需要支持。
- 你不需要一个人扛。把亲友、社区、医生拉进来。

> **什么时候需要立即联系医生 / 去急诊**
>
> - 明确说想死，或说“我准备好了”“这是最后一次见你”
> - 有具体计划、时间、地点、方式
> - 正在做危险的事：已服药、已割伤、站在高处、开着煤气
> - 开始送东西、写遗书、交代后事、突然异常平静
> - 命令性幻听让他去死，或坚信自己该死
> - 严重失眠、极度激越、完全不吃不喝
> - 刚出院、刚失恋、刚失业后的几天内出现明显变化
>
> 出现以上任何一条：不要让他独处，不要让他开车，移除身边的危险物品，立即拨打 120 或去最近医院急诊；现场有危险时拨打 110。也可以拨打 12356 心理援助热线。

### 容易踩的坑

- 觉得“问了会提醒他”，于是谁都不问。
- 听到“我不想活了”就急着讲道理、举例子、说别人更惨。
- 答应“绝对不告诉别人”，结果自己扛不住。
- 只盯着“有没有说想死”，忽略“开始安排后事”“突然变平静”。
- 家里药箱、农药、刀具完全不设防。
- 出院后觉得“医院都治好了”，随访松懈。
