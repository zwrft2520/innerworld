# 9.2 暴力风险评估

先说结论：**大多数精神分裂症患者并不暴力，他们更常见的身份是暴力的受害者，而不是加害者。** 但也不能走到另一个极端，说“患者绝不会伤人”——在少数具体情境下，风险是真实存在的，而且往往发生在家里，受害者常常是最亲近的家属。这一页把暴力风险拆成“情境”来讲：哪些症状、哪些状态、哪些环境会让风险升高，怎么把它降下来，什么时候必须打 110 或 120。

## 一、先把事实放回原位

媒体喜欢把精神疾病和暴力绑在一起，这造成两个后果：患者被整体污名化，家属在真正遇到危险时又不敢相信自己的判断。

需要同时成立的两句话是：

- **诊断本身不是暴力预测器。** 仅仅因为一个人有精神分裂症，无法推断他会不会伤人。绝大多数患者终其一生都没有严重的暴力行为【研究】。
- **某些症状和情境确实与风险升高相关。** 命令性幻听、被害妄想、物质使用、治疗中断、急性激越，这些才是需要盯住的东西【指南】。

所以正确的说法不是“他是个危险的人”，而是“**他现在处于一个风险升高的状态**”。状态会变，治疗能改变它，环境也能改变它。这就是为什么这一页讲“风险因素与情境”，而不是给人贴标签。

## 二、风险升高的情境

下面这张表列的是临床上最需要警觉的组合。单独一条不等于会出事，但几条叠在一起，就要提高警惕。

| 情境 | 为什么风险升高 | 现场能观察到什么 |
|---|---|---|
| 命令性幻听 | 声音命令他去伤害某个具体的人，他可能认为必须服从 | 侧耳倾听、自言自语、突然盯着某人、说“我知道了” |
| 被害妄想 | 坚信某人要害自己或家人，可能“先下手为强” | 反复检查门窗、跟踪、收集“证据”、点名某个人 |
| 被控制感 | 觉得身体或想法被别人控制，反抗的冲动强 | 说“我的手不听我的”“有人在操控我” |
| 急性激越 | 情绪失控、判断力下降、一点刺激就爆 | 来回踱步、大声、摔东西、握拳、脸涨红、说话越来越快 |
| 物质使用 | 酒精、冰毒、可卡因直接降低自控、放大冲动 | 最近大量饮酒、熬夜、瞳孔变化、言语混乱 |
| 治疗中断 | 症状反弹，自知力下降，没人能劝 | 自己停药、拒诊、躲着家人 |
| 既往暴力史 | 是预测未来暴力最强的因素之一 | 过去打过人、砸过东西、被报警过 |
| 环境压力 | 拥挤、噪音、被围堵、被强迫、当众羞辱 | 多人围着、有人拍摄、有人指指点点 |
| 武器可得性 | 冲动时手边有什么，决定后果有多重 | 家里有刀、棍、工具、枪支 |

还有两个容易被忽略的点：

**风险常常发生在家里。** 同住意味着高频接触、日常摩擦、照护疲劳，也意味着对方最了解你的作息和弱点。

**风险会随治疗变化。** 同一个人，在急性期和稳定期可以是完全不同的状态。所以评估要看“最近几天”，不是看“他这个人”。

## 三、怎么把风险降下来

**先改环境，再谈说服。** 人在激越时听不进道理，讲道理往往火上浇油。

- **减少刺激**：关掉电视和音乐，让围观的人散开，把孩子和老人带到另一个房间。
- **保持距离**：至少一臂半的距离，站在门口一侧，不要堵住他的出口，也不要让他觉得被逼到墙角。
- **不要突然靠近、不要从背后接近、不要伸手去抢东西。**
- **说话方式**：低声、慢速、短句，先叫他的名字，承认他的感受——“我知道你现在很害怕，或者很生气”。
- **不争辩妄想内容。** 不说“根本没人害你”，而说“你觉得有人要害你，所以你这么紧张”。
- **给选择，给时间。** “你想先坐下喝口水，还是我陪你去阳台站一会儿？”有选择感，冲动会下降。
- **不要多人围堵。** 三四个人一起上前，几乎一定会激发挣扎，也可能伤到所有人。
- **不要用空头威胁。** “你再这样我就报警”要么别说了，要么真的准备报警。说了不做，只会让他知道威胁没有后果。
- **移除手边的危险物品**：刀、剪刀、玻璃杯、工具、热水。做这件事要在他不注意时、由两个人配合，不要当面抢夺。

长期来看，降低风险靠的是：规律服药、治疗物质使用、家庭干预、减少高情感表达、有稳定随访。这些比任何“临场话术”都管用。

### 现场降温清单

- [ ] 让无关的人离开，尤其孩子和老人
- [ ] 关掉电视、音乐，降低噪音
- [ ] 自己先深呼吸，语速放慢，音量压低
- [ ] 站在出口附近，保持一臂半的距离
- [ ] 叫他的名字，说一句承认情绪的话
- [ ] 不提“你有病”“你疯了”“你吃药了没”
- [ ] 不争辩幻听和妄想的内容
- [ ] 给两个具体、可执行的选择
- [ ] 手边危险物品已移开，或至少不在他伸手可及处
- [ ] 已经想好：如果升级，谁打电话、打给谁、从哪里撤离

## 四、什么时候打 110、什么时候打 120

| 情形 | 打哪个 | 电话里说什么 |
|---|---|---|
| 已经动手打人、持械、砸东西，或威胁要伤害具体的人 | 110 | 地址、人数、有没有武器、有没有人受伤、他现在的状态 |
| 有明确对象、明确方式，正在去找对方 | 110 | 同上，并说明他可能有精神疾病、是否在服药 |
| 已经受伤、流血、昏迷、抽搐 | 120（必要时同时 110） | 伤情、意识、呼吸、地址 |
| 自伤、服毒、高处危险 | 120（现场有危险时 110） | 物品、时间、量、意识状态 |
| 木僵、拒食、高热、肌肉僵硬 | 120 | 体温、意识、四肢僵硬、多久没吃没喝 |
| 只是言语威胁，还能对话，没有武器 | 先联系精神科医生或社区随访，同时保持警戒 | 不要独自处理，告诉医生具体说了什么 |

关于报警，有两件事需要说清楚：

1. **报警不是“毁了他”。** 警察到场可以协助控制局面、协助送医，很多地方有警医联动机制。真正危险的时候，安全优先于“家丑不可外扬”。
2. **报警时如实说明病情。** 是否在服药、最近有没有停药、有没有喝酒、以前有没有打过人。这些信息能帮助现场人员判断，而不是让他被当成“普通闹事者”。

法律上，精神障碍患者的刑事责任能力要由司法鉴定判断，不是家属或警察现场说了算。这一页不展开，具体见[11.3 精神卫生法与权益](<../模块11：危机、住院与法律/11.3 精神卫生法与权益.md>)。

## 五、事后：不羞辱、不“算账”、不装作没发生

风波过去之后，最伤人的往往不是事件本身，而是之后的处理方式。

- **不要在事后反复说“你刚才多可怕”“你差点打死我”。** 羞辱会加重病耻感，也会让他下次更隐瞒症状。
- **记录触发点**：之前发生了什么、他说了什么、有没有喝酒、有没有停药。复诊时带给医生。
- **把安全计划补上**：家里哪些东西要收、紧急时谁打电话、孩子去哪里。
- **该谈的责任要谈**：造成的损失、邻居的投诉、可能的赔偿，可以等稳定后再谈，但不能永远不谈。
- **家属自己的伤也要处理**：被推倒、被掐、被威胁，都是真实的伤害，不是“他病了所以不算”。

## 六、给家属和邻居：保护自己不是背叛

如果你正和一位有精神分裂症的家人同住，请记住：

- 你有权利保护自己的人身安全，这不叫“抛弃他”。
- 不要独自面对一个持械或明显失控的人。先撤离，再求助。
- 不要因为“他是病人”就长期忍受暴力。长期容忍会让风险累积，也会拖垮整个家庭。
- 邻居如果被卷入，不需要知道诊断细节，只需要知道“现在不安全，请帮忙报警”。

> **什么时候需要立即联系医生 / 去急诊**
>
> - 正在打人、掐人、持械、砸东西，或明确说要杀某个人
> - 命令性幻听命令他伤害自己或别人
> - 坚信家人要害他，已经开始“反击”或跟踪
> - 出现激越升级：摔东西、砸门、脸涨红、说话越来越快、无法对话
> - 合并大量饮酒或使用兴奋剂后行为失控
> - 有人受伤、流血、昏迷、抽搐
> - 木僵、拒食、高热、肌肉僵硬（可能是紧张症或恶性综合征）
>
> 现场已经失控时，先撤离到安全位置，再拨打 110；有人受伤或意识不清，同时拨打 120。不要试图独自制服一个成年人，也不要让儿童留在现场。

### 容易踩的坑

- 为了“反污名”而否认一切风险，结果家属毫无准备。
- 因为一次激越，就给患者贴上“危险分子”的标签，一辈子翻不了身。
- 围观、拍摄、激将、说“你敢吗”，把冲突推向升级。
- 用“报警”当口头威胁，却从不真的行动。
- 认为“病人打人不用负责”，于是不做任何防范。
- 事后羞辱、翻旧账，让他下一次更不敢说自己的症状。
