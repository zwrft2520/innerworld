# 13.3 复诊沟通单与用药记录

很多人复诊时的真实状态是：排队两小时，进门五分钟，出来才想起最想问的那句话没说。这不是你一个人的问题。这一页把复诊拆成“诊前准备—诊中怎么说—诊中问什么—回家记什么”四步，并给出一份可以直接打印的“一张纸”模板。照着用，至少能保证每次复诊把最重要的事说清楚。

## 一、诊前三天：把材料备齐

临时找东西最耽误时间。提前三天，把下面这些放进同一个袋子或文件夹：

- [ ] 正在吃的所有药：药盒、处方、或者一张写清药名和用法的清单
- [ ] 最近的化验单：血常规、肝肾功能、血糖血脂、心电图
- [ ] 上次的病历和量表报告
- [ ] 这半个月的症状记录或预警表
- [ ] 医保卡、就诊卡、身份证
- [ ] 一张纸，写着你这次最想问的三个问题

还有一件事容易被忽略：**把“这次最想解决的一个问题”写成一句话。** 比如“晚上幻听吵得睡不着”“吃完药手抖得拿不了筷子”“想问问能不能减药”。门诊时间有限，有一个明确的主诉，医生才能把有限的几分钟用在刀刃上。

如果本人不方便表达，家属可以陪同，但要提前商量好谁主说。两个人抢着说、互相纠正，医生反而抓不到重点。

## 二、诊中必说：五句话

医生问“最近怎么样”，回答“还行”是最常见也最亏的回答。可以按下面五句话的结构说：

| 说什么 | 为什么重要 | 可以这样说 |
|---|---|---|
| 症状的变化 | 医生需要趋势，不是印象 | 这两周幻听从每天一两次变成四五次，晚上多 |
| 对生活的影响 | 决定治疗强度 | 因为这个，我一周没去上班，白天不敢出门 |
| 服药情况 | 判断是药无效还是没吃 | 一直按时吃，只有两天忘了晚上的 |
| 副作用 | 决定要不要调方案 | 手抖，拿筷子不稳；便秘三天一次 |
| 你最担心的 | 让医生知道你的优先级 | 我怕这样下去又要住院 |

说的时候尽量具体：频率、时间、程度、和上周比是好了还是差了。避免“特别难受”“一点用都没有”这类没有刻度的描述。

如果症状涉及幻听的内容，可以直接说：“有个声音让我别出门，说外面有人等着我。”医生需要知道内容，不是因为你“说了会被抓走”，而是因为命令性幻听、被害妄想直接关系到风险评估。

## 三、诊中必问：八个问题

很多人出门才想起没问，可以把这张清单存在手机里，进诊室前看一眼。

- [ ] 这次的诊断或判断是什么？依据是什么？
- [ ] 现在这个药，主要指望它改善哪几个症状？
- [ ] 大概多久能看到变化？如果没变化，下一步怎么办？
- [ ] 有哪些副作用需要我特别留意，出现什么情况要马上联系你？
- [ ] 下次复诊前，我需要记录什么、做什么检查？
- [ ] 如果漏服了一次，应该怎么处理？
- [ ] 我能不能同时吃别的药、中药或保健品？有没有需要避开的？
- [ ] 什么情况下需要提前来，或者直接去急诊？

关于“漏服怎么处理”，一定要在诊室里问清楚，而不是上网搜。不同药物、不同服药频率的处理方式不一样，搜到的答案未必适用于你。

还有几个问题，适合在病情稳定时问，而不是等到危机时：

- [ ] 我的维持治疗大概要多久，什么情况下可以考虑减量？
- [ ] 如果需要长期治疗，对我工作、开车、怀孕分别有什么影响？
- [ ] 有没有适合我的心理社会干预或康复资源？

## 四、用药记录表

不需要每天写长篇，一张表记录“吃没吃、有没有不舒服”就够。药名和用法按处方抄，不要自己改。

| 药名（按处方抄） | 服药情况（早/中/晚） | 漏服或自减 | 不舒服的表现 |
|---|---|---|---|
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

填法：

- 在“服药情况”里按早、中、晚写“√”或“×”，自己在某个时段改过就写“减”或“加”。
- “不舒服的表现”写具体的：手抖、坐不住、口干、便秘、心慌、嗜睡、月经推迟、体重变化。
- 如果同时吃其他科的药、中药、保健品，也单独列一行，复诊时给医生看。

这张表的作用不是监督你，而是帮医生判断：症状没好转，是因为药不对，还是因为没吃进去；副作用是不是和某个药、某个时间点有关。

## 五、副作用：写具体，别写“难受”

| 模糊的说法 | 更有用的说法 |
|---|---|
| 难受 | 吃完两小时开始坐不住，必须一直走 |
| 没力气 | 早上起床要躺半小时才能起来，持续一周 |
| 手抖 | 拿筷子抖，写字歪，别人能看出来 |
| 便秘 | 三天一次，干结，需要开塞露 |
| 睡不好 | 凌晨三点醒，之后睡不着，白天困 |
| 月经不正常 | 两个月没来，上次也是吃药后开始的 |
| 体重涨了 | 三个月涨了 6 公斤，胃口明显变大 |

出现下面这些情况，不要等到复诊：

- 发热、咽痛、口腔溃疡、明显乏力（尤其服用氯氮平时）；
- 高热、肌肉僵硬、意识改变、大汗、心跳很快；
- 脖子突然转不动、眼睛往上翻、走路姿势异常；
- 坐立不安到无法静止、整夜走动；
- 吞咽困难、进食呛咳；
- 胸痛、心悸、晕厥；
- 严重便秘伴腹胀、呕吐、不排气。

## 六、氯氮平专页：血常规是处方的一部分

氯氮平对难治性精神分裂症有明确价值，但它有一个必须严肃对待的风险：**粒细胞缺乏**——一种让身体抵抗感染能力下降的血象变化。它不常见，但一旦发生可能危及生命，所以监测不是“附加项目”，而是处方本身的一部分。【指南】

需要记住的几条：

**第一，按医生安排查血常规，不能因为“感觉还好”就跳过。** 开始用药的阶段查得最密（通常每周一次，持续数月），之后按医生安排定期复查，多数方案为每月一次。具体频率以处方和当地监测要求为准。

**第二，发热、咽痛、口腔溃疡、明显乏力，要立即查血常规。** 这些是感染的常见表现，在粒细胞缺乏时可能是最早的信号。不要先吃退烧药观察两天。

**第三，不要自行停药或自行减量。** 突然停氯氮平可能引起症状反弹，也可能出现撤药相关的不适。任何调整都由医生决定。

**第四，其他需要报告的情况：** 胸闷、心悸、气短、发热（尤其用药早期，警惕心肌炎）；严重便秘、腹胀、不排气（警惕肠梗阻）；流涎严重；抽搐；尿潴留。

**第五，把血常规结果按日期存好。** 换医院、换医生时，这份记录很重要。

- [ ] 我知道下次查血常规的日期
- [ ] 我知道结果异常时该联系谁、怎么联系
- [ ] 我知道发热咽痛时要立即查血，不等到复诊
- [ ] 我知道不能自行停氯氮平
- [ ] 我的血常规结果按日期存好了

打印出来，每次复诊带同一张，按日期归档，半年后回看会很有用。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现自杀念头、自伤行为或具体计划：不要独处，拨打 120 或去最近医院急诊，也可拨打 12356 心理援助热线。
> - 服用氯氮平后发热、咽痛、口腔溃疡、明显乏力：立即查血常规，不要等复诊。
> - 出现高热、肌肉僵硬、意识改变、大汗：警惕恶性综合征，立即停药并急诊。
> - 出现木僵、拒食、缄默、长时间不动：警惕紧张症，急诊精神科评估。
> - 出现吞咽困难、进食呛咳、呼吸困难：警惕噎食，立即急诊。
> - 突然停药后出现严重失眠、激越、幻觉加重：尽快联系医生，不要自行加回原量。
