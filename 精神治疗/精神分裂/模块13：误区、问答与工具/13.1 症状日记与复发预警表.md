# 13.1 症状日记与复发预警表

出院时医生常说“注意观察，有变化就来”，可“变化”到底是什么，很多人回家就忘了。这一页给出一份可以直接照抄的记录方法：每天记五个格子，每周填一张预警表，复诊时三分钟讲清楚。它不要求你写得漂亮，也不要求天天满分，能坚持记下三四成，就已经比“全凭印象”有用得多。

## 一、为什么值得记：三个很实际的作用

**第一，对抗记忆偏差。** 人对最近两三天的感受记得最清楚，对两周前的情况只剩一个模糊的结论：“好像还行”或者“一直不好”。医生调药偏偏需要看趋势，而不是看今天的心情。

**第二，发现自己的模式。** 很多复发不是毫无征兆的。有人是先连续几天只睡三四个小时，然后开始多疑；有人是先不愿出门、话变少，过一阵才出现幻听。记上一个月，模式往往自己会浮出来。

**第三，让复诊更有效率。** 一次门诊常常只有十几分钟。带着记录去，你可以直接说“这周幻听从每天一两次变成五六次，晚上明显，睡眠从七小时掉到四小时”，医生马上能抓住重点。空手去，往往只能说出“还行吧”。

要强调的是：记录是工具，不是考核。漏了几天不用补，也不用因为“记得不好”而自责。它的目的是帮你和医生，不是给谁打分。

## 二、每天记什么：五个格子

不用写日记，五个格子就够。每个格子一两句话，或者直接打勾、写数字。

| 格子 | 记什么 | 例子 |
|---|---|---|
| 睡眠 | 几点上床、大概多久睡着、夜里醒几次、总共睡多久、白天困不困 | 23:30 上床，1 点才睡着，醒 2 次，共 5 小时，白天很困 |
| 服药 | 有没有漏、有没有自己加减、有没有不舒服 | 早上的漏了，晚上按时；吃完手有点抖 |
| 症状 | 幻听有没有、几次、说什么；有没有多疑、被针对感；情绪打几分 | 幻听 2 次，说“他们在看你”；下午觉得同事在议论我 |
| 副作用 | 手抖、僵硬、坐不住、口干、便秘、心慌、体重、月经、性功能 | 便秘第 3 天；坐不住，下午走了很久 |
| 活动 | 出门了吗、做了什么、和谁说过话 | 上午买菜，下午没出门，和妈妈说了几句话 |

几个写法上的建议：

- **能用数字就用数字。** “幻听 3 次”比“幻听很多”有用；“睡了 4 小时”比“没睡好”有用。
- **记事实，不急着解释。** 写“今天觉得邻居在敲墙针对我”，不必写“因为我不好所以被针对”。解释留给复诊时和医生一起做。
- **情绪用 0 到 10 打分。** 0 是最低，10 是最好。不用精确，凭感觉给一个数就行。
- **副作用要具体。** “难受”医生没法处理，“手抖到拿不稳筷子”“三天没排便”就能处理。

## 三、症状清单：打勾就行

如果不想写字，每天睡前花一分钟，把当天有的情况打勾。建议固定放在床头或手机备忘录里。

- [ ] 今天听到别人听不到的声音
- [ ] 声音在评论我，或命令我做什么
- [ ] 觉得有人在监视、跟踪或针对我
- [ ] 觉得别人能知道我的想法，或我的想法被拿走了
- [ ] 说话跳跃，别人说听不懂
- [ ] 什么都不想做，躺着也不觉得休息
- [ ] 对以前喜欢的事提不起兴趣
- [ ] 不想见人，回避电话和消息
- [ ] 入睡困难、早醒，或睡得明显比平时多
- [ ] 情绪低落到影响吃饭、洗漱、出门
- [ ] 特别烦躁，坐不住，容易发火
- [ ] 注意力散，记不住刚发生的事
- [ ] 手抖、肌肉僵硬、走路不稳、脖子转不动
- [ ] 口干、便秘、排尿困难、心慌
- [ ] 今天漏服或自行调整了药

勾选本身不说明病情好坏，它只是把“感觉”变成“可以数的东西”。连续几天勾选项目变多，就是值得和医生说的信号。

## 四、一周一次：复发预警表

每天记完，周末花五分钟做一次汇总。这张表比日记更能看出趋势，也最适合复诊时给医生看。

| 预警信号 | 上周 | 本周 | 变化 |
|---|---|---|---|
| 睡眠明显减少（比自己平时少很多） |  |  |  |
| 多疑、觉得被针对 |  |  |  |
| 幻听变频繁或内容变凶 |  |  |  |
| 说话变乱、别人听不懂 |  |  |  |
| 明显退缩、不出门、不说话 |  |  |  |
| 情绪异常高涨或异常低落 |  |  |  |
| 烦躁、坐立不安、容易冲突 |  |  |  |
| 漏服、自行减药或停药 |  |  |  |
| 工作学习能力突然下降 |  |  |  |
| 出现新的躯体不适 |  |  |  |

填法很简单：有就写“有”或打勾，没有就写“无”，比上周好写“↓”，比上周差写“↑”，差不多写“→”。

除了通用信号，每个人还有自己的“专属前兆”。有的人是突然特别爱整理东西，有的人是开始反复检查门锁，有的人是说话突然变得很正式。花十分钟和家人一起回想：**上一次复发前一两周，最早出现的三个变化是什么？** 写下来，贴在冰箱上。

- [ ] 我的第一个前兆：__________
- [ ] 我的第二个前兆：__________
- [ ] 我的第三个前兆：__________

【临床经验】

## 五、副作用与躯体指标：单独留一页

有些问题进展慢，不记就发现不了。建议每周固定一天（比如周日早上）测一次，记在同一张纸上。

| 项目 | 多久记一次 | 怎么记 |
|---|---|---|
| 体重 | 每周 | 同一时间、同一件衣服、同一台秤 |
| 腰围 | 每月 | 肚脐水平绕一圈 |
| 血压 | 每周 | 静坐五分钟后测 |
| 血糖、血脂 | 按医生安排 | 把化验单拍照存好 |
| 月经 | 每月 | 日期、是否规律、量多量少 |
| 性功能 | 有变化时 | 简短描述，不必详细 |
| 排便 | 每周 | 几天一次、是否干结 |
| 手抖、僵硬、坐不住 | 每周 | 轻、中、重三档即可 |

如果服用氯氮平，血常规的日期和结果要单独记，见 13.3 的用药记录页。发热、咽痛、口腔溃疡要立即查血，不能等到下周。

## 六、复诊怎么用这份记录

门诊时间有限，记录不是念给医生听，而是帮你挑重点。可以按这个顺序讲：

1. **先说变化**：“这两周幻听变多了，晚上尤其明显。”
2. **再说影响**：“因为这个，我三天没去上班，晚上只睡四小时。”
3. **再说药**：“药一直按时吃，就是吃完手抖，拿筷子不稳。”
4. **最后说担心**：“我怕是不是又要复发了。”

如果医生时间紧，直接把预警表递过去，比你组织语言更快。

- [ ] 复诊前把记录本、药盒、化验单装进同一个袋子
- [ ] 用一句话写下这次最想解决的问题
- [ ] 把最严重的三个变化圈出来
- [ ] 想好一个必须问医生的问题
- [ ] 记下医生这次的调整和下次复诊时间

## 七、可照抄的模板

下面是每天一行的简版，抄在笔记本上或做成手机表格都行。

```text
日期：
睡眠：上床___ 入睡约___分钟 夜醒___次 共___小时 白天困（无/轻/重）
服药：早（按时/漏/自减） 中（ ） 晚（ ） 不适：
症状：幻听___次，内容：______ 多疑（无/轻/中/重） 情绪__/10
副作用：______
活动：出门（是/否） 做了：______ 和人说话（是/否）
备注：
```

一周汇总时，只回答三个问题：

- 这周比上周，最明显的变化是什么？
- 有没有出现我的“专属前兆”？
- 有没有需要下次复诊一定要说的事？

> **什么时候需要联系医生 / 去急诊**
>
> - 出现自杀念头、自伤行为，或已经在准备方法：不要独处，联系信任的人陪着，拨打 120 或去最近医院急诊；也可拨打 12356 心理援助热线。
> - 出现命令性幻听，声音让你伤害自己或别人：先保证安全，远离危险物品，拨打 120，必要时 110。
> - 连续多天几乎不睡、明显兴奋话多、行为失控：尽快精神科急诊评估。
> - 出现木僵、拒食、缄默、长时间不动：警惕紧张症，立即急诊。
> - 出现高热、肌肉僵硬、意识改变、大汗：警惕恶性综合征，立即急诊。
> - 服用氯氮平期间发热、咽痛、口腔溃疡：立即查血常规。
