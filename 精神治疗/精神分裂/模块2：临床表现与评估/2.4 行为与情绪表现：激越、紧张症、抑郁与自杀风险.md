# 2.4 行为与情绪表现：激越、紧张症、抑郁与自杀风险

精神分裂症不只有幻觉妄想。有人会突然激动、砸东西、威胁人；有人一动不动、不吃不喝、叫也不应；有人在病情好转后陷入深深的低落。这一页把这些表现分开讲，重点标出哪些必须立刻去急诊。适合家属在慌乱时快速对照，也适合患者自己理解“我身上发生了什么”。读完你能分清“闹脾气”和“急症”，也知道自杀风险该怎么问、怎么陪。

## 一、激越：先保证安全，再谈原因

激越指明显升高的紧张、坐不住、易怒、喊叫、摔东西甚至攻击。它是一个“状态”，不是一个诊断，背后可能有很多原因：

- 幻觉、妄想带来的恐惧，比如觉得有人要杀自己；
- 身体不舒服：疼痛、憋尿、便秘、发热、低血糖；
- 药物副作用：静坐不能（一种坐不住、心里发慌的副作用）；
- 戒断：酒精、苯二氮䓬类药物突然停用；
- 谵妄：意识不清、注意力涣散，常见于感染、电解质紊乱。

现场处理的原则是先降刺激、再加沟通：人少一点、声音低一点、灯亮一点、给对方留出能走出去的空间；用短句说清楚“我在，你很安全”；不要围堵、不要拉扯、不要争辩症状真假。药物由医生决定，家属不要自行加药。【指南】（NICE NG10 对急性激越的处理有专门推荐。）

### 静坐不能容易被误认为“激越”

有一种副作用叫静坐不能：心里发慌、腿发软、坐不住、来回走，但患者并没有愤怒或敌意。它常在加量或换药后出现，患者会说“我就是难受，说不清”。如果误当成“病情加重”而加药，反而会更重。遇到这种情况，记录出现时间和用药变化，尽快反馈给医生。

## 二、紧张症：不是“不配合”

紧张症是一组以运动和反应异常为主的表现，可能出现在精神分裂症、双相障碍、抑郁障碍，也可能由脑炎等躯体疾病或恶性综合征引起。它的危险在于：患者看起来只是“不理人”，实际上可能已经脱水、电解质紊乱，甚至出现血栓。

| 表现 | 家属看到的样子 | 紧急程度 |
|---|---|---|
| 木僵 | 几乎不动、不反应，像“定住了” | 急症 |
| 缄默 | 完全不说话，问也不答 | 急症 |
| 拒食 | 不吃饭、不喝水，或含在嘴里不咽 | 急症 |
| 违拗 | 让他抬手偏放下，让他张嘴偏闭紧 | 急症 |
| 蜡样屈曲 | 摆成什么姿势就保持什么姿势 | 急症 |
| 装相、刻板动作 | 反复做同一个怪动作、保持怪异姿势 | 需尽快评估 |
| 凝视、模仿言语 | 长时间盯着看、重复别人的话 | 需尽快评估 |

关键点：

- 紧张症需要急诊精神科评估，不能只当“闹情绪”或“对抗”。
- 不要强行喂食。吞咽反射可能有问题，硬灌容易呛入气管，造成窒息或吸入性肺炎。
- 拒食超过一两天、尿量明显减少、口干、站起来头晕，就要走急诊，可能需要静脉补液。
- 紧张症的治疗包括苯二氮䓬类药物和电休克（ECT），具体选择由医生判断；剂量和疗程不在科普里给。

## 三、抑郁与焦虑

抑郁可以出现在精神分裂症的任何一个阶段：急性期、症状缓解后、维持期。症状缓解后出现的抑郁，有时叫“精神病后抑郁”，表现是情绪低落、自责、无望、睡不好、不想动，严重时出现自杀观念。【指南】

它和阴性症状容易混：两者都可能表现为不说话、不动、退缩。区别在于抑郁有“低落”的底色——患者会觉得痛苦、自责、觉得拖累别人；阴性症状更多是“平淡、无所谓”。当然，两者可以同时存在。

焦虑也很常见，可能来自症状本身、对复发的担心、社会歧视，也可能来自咖啡因、尼古丁戒断，或药物的副作用（比如静坐不能带来的心慌）。持续的心慌、手抖、出汗，先排除躯体原因和药物原因。

## 四、自杀风险：要问、要陪、要限制手段

精神分裂症患者的自杀风险高于一般人群，风险较高的时段包括病程早期、病情好转后、出院后不久，以及伴发抑郁、绝望、命令性幻听、物质使用、既往自杀未遂的时候。【指南】

很多人怕“问了会教坏他”，事实相反：直接问不会增加风险，反而常常让人松一口气。

可以这样问：

- “最近有没有觉得活着没意思？”
- “有没有想过不想活了？”
- “有没有想过具体怎么做？家里有没有你打算用的东西？”

如果答案是肯定的，接下来做三件事：不让他独处、把手段拿远（药物由家属保管、刀具收好、高层窗户限位）、联系医生或急诊。必要时拨打 120，或拨打 12356 心理援助热线。

安全计划可以写下来，内容包括：出现念头时先打给谁、去哪里、把什么东西交给谁保管、哪些话对自己有用。写下来比记在脑子里可靠。

## 五、哪些情况算急症

- 明确的自杀计划、自杀未遂、正在交代后事；
- 命令性幻听，或已经按命令行动；
- 明显激越伴伤人威胁、持物、堵门；
- 木僵、缄默、拒食超过一两天；
- 高热、肌肉僵硬、意识改变、大汗、心跳很快——警惕恶性综合征；
- 突然吞咽困难、进食呛咳、呼吸困难——警惕噎食；
- 意识时清时浊、抽搐、剧烈头痛、频繁呕吐。

以上任何一条，都不要等门诊，直接去急诊；无法配合时拨打 120，有伤人风险时拨打 110。

## 六、家里可以怎么做

- [ ] 提前写好一张“紧急联系卡”：主治医生、医院急诊、社区精防人员、两位能立刻到场的亲友、12356。
- [ ] 把药物、刀具、绳索、过量可能致命的物品集中管理，钥匙由家属保管。
- [ ] 学会观察三件事：睡眠、进食、情绪基调。这三样变化常早于大波动。
- [ ] 不在激动时讲道理，等平静后再谈；一次只谈一件事。
- [ ] 不用“你想开点”“别人比你更惨”来回应低落，先承认“这确实很难”。
- [ ] 记录症状和用药的时间线，复诊时带着。
- [ ] 家属轮流照看，避免一个人长期硬扛。

> **什么时候需要联系医生 / 去急诊**
>
> **立即急诊或拨打 120：** 自杀计划或行为；命令性幻听并准备执行；伤人威胁或已发生冲突；木僵、缄默、拒食；高热加肌肉僵硬加意识改变；噎食、呼吸困难、抽搐、意识不清。
>
> **尽快联系门诊：** 情绪低落持续两周以上；焦虑心慌影响睡眠；加药后坐不住、手抖；拒食一餐但能喝水、精神尚可；家属不知道该怎么应对。

### 容易踩的坑

1. **把紧张症当“赌气”。** 拖延的代价可能是脱水、电解质紊乱和血栓。
2. **强行喂饭喂水。** 呛咳和窒息风险很高。
3. **认为“问自杀不吉利”。** 不问才是真的风险。
4. **好转就放松看护。** 出院后和症状缓解初期，反而是风险较高的时段。
5. **把静坐不能当成“病情加重”。** 可能越加药越重。
6. **只靠“陪着他”而不联系医生。** 陪伴重要，但不能替代评估。
