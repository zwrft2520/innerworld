# 2.3 认知损害：注意、记忆与执行功能

很多患者和家属会发现，症状控制住了，人却还是“回不去”：记不住刚说过的话，做一顿饭步骤全乱，出门总是忘带东西。这背后常常是认知损害，而不是“不用心”。这一页讲清楚认知损害包括哪些方面、为什么它比幻觉更影响工作和独立生活，以及家里能做哪些代偿。读完你能分辨“能力下降”和“态度问题”，也不会再把所有事都推给“懒”。

## 一、认知损害不是“变笨了”，是“处理不过来”

认知损害指注意、记忆、思考速度、计划能力这些“脑力工具”的效率下降。它和智力不是一回事：很多患者在智力测验上处于正常范围，但一放到真实生活里就处处卡住——不是不懂，是同时要处理的信息太多，脑子转不过来。

患者常这样描述：“话我都听见了，但拼不起来”“想做事，脑子里一片空白”“看一页书要看三遍”。这些描述比“记忆力差”更接近实情。

认知损害在精神分裂症里非常常见，而且在首次发作时就可能存在，不一定随阳性症状缓解而完全恢复。它和功能结局的关系，往往比幻觉妄想更紧密。【指南】【研究】

## 二、五个常受影响的领域

| 领域 | 通俗解释 | 生活里的表现 |
|---|---|---|
| 工作记忆 | 脑子里临时“存”住信息并操作 | 记不住刚说的号码；边听边记就乱；算账算到一半忘了 |
| 注意与警觉 | 持续专注、过滤无关信息 | 看电视看不下去；人多就烦；别人说话听不进去 |
| 处理速度 | 反应和思考的速度 | 说话慢半拍；跟不上对话；做事比别人费时间 |
| 执行功能 | 计划、排序、切换、控制冲动 | 做饭步骤乱；不会安排一天；一件事没做完又去做别的 |
| 社会认知 | 读表情、猜意图、理解玩笑和隐喻 | 误解别人好意；把玩笑当讽刺；觉得所有人都在针对自己 |

### 每个领域大概是什么样

**工作记忆**像一块小白板。别人说“把盐、酱油、醋拿过来”，白板小的人走到厨房只记得“盐”。这不是不听指令，是信息在半路掉了。

**注意**的问题有两头：一头是撑不住，几分钟就走神；另一头是过滤不掉，背景里的电视声、走路声全都涌进来，很快就累。

**处理速度**慢最容易被误解成“反应迟钝”“不尊重人”。给对方多几秒，结果往往不一样。

**执行功能**是“总指挥”。它弱的时候，人会显得没条理、拖延、冲动，很像性格问题，其实是能力问题。

**社会认知**受损和关系妄想不是一回事，但会互相加重：读不准表情，就容易把中性的话当成敌意。

## 三、为什么它比幻觉更影响工作和独立生活

幻觉很显眼，但它可以是间歇的；认知损害却是每天都在的底色。

- **吃药**：一天几次、哪几种、饭前饭后，全靠工作记忆和计划能力。
- **做饭**：买菜、洗切、看火、算时间，是典型的多任务执行。
- **出门**：查路线、看站牌、记住在哪下车、临时改道。
- **工作**：同时接两件事、被临时打断后回到原来的任务、记住口头交代。
- **管钱**：算账、比较、抵抗“现在就想买”的冲动。
- **复诊**：记住医生说的三件事，回家还能复述。

研究普遍发现，认知损害对职业与社会功能的预测力较强，甚至强于阳性症状的严重程度。【研究】这也解释了为什么“症状好了却上不了班”，不是患者不努力，而是支持没跟上。

## 四、怎么评估

认知损害不能靠“我觉得他变笨了”来判断，也不能靠网上的自测题确诊。

- **成套测验**：如 MATRICS 共识认知成套测验（MCCB）、简短认知评估（BACS），覆盖上述几个领域，多用于研究或较完整的评估。
- **床旁筛查**：医生在门诊用连线测验、数字广度、词语回忆等简单任务做初步判断。
- **功能评估**：PSP 量表看的是实际生活能力，比分数更贴近真实处境。
- **访谈**：问“最近做饭、买东西、坐车有没有变难”，往往比测验更有信息。

要注意，分数会被很多因素拉低：没睡好、抑郁、焦虑、药物镇静、抗胆碱能作用（一类让人口干、便秘、反应慢的副作用）、饮酒、甲状腺功能异常。所以“测出来差”不等于“脑子坏了”，需要医生结合背景解释。

## 五、能做点什么

认知矫正训练（针对注意、记忆、解决问题的结构化练习）有一定证据，但效果通常是中等程度，需要和具体的生活目标绑在一起才有意义，比如“为了能自己去超市”而练，而不是为了刷分。【研究】

日常代偿往往更直接：

- [ ] 药物用分格药盒加手机闹钟，闹钟响时人必须在场。
- [ ] 一天的事写在一页纸上，只写三件，做完划掉。
- [ ] 复杂任务拆成三步，写在便利贴上，贴在做事的地方。
- [ ] 钥匙、眼镜、医保卡固定放在同一个位置。
- [ ] 家里人一次只交代一件事，说完让对方复述一遍。
- [ ] 重要决定延后一天，先写下来，第二天再看。
- [ ] 睡眠、运动、戒烟限酒，对注意和速度都有实际帮助。
- [ ] 复诊时问医生：现在的镇静程度、抗胆碱能负担、情绪问题，有没有可以调整的空间。

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊：**
>
> - 认知状态在几天内明显变差，伴发热、头痛、意识时清时浊、抽搐、走路不稳——要先排除脑部或躯体疾病。
> - 突然不认识人和地方、说胡话、昼夜颠倒，可能是谵妄，按急症处理。
> - 因为记不住吃药而反复漏服、重复服药，或出现明显过量。
>
> **尽快联系门诊医生：**
>
> - 记忆和注意力在几周内持续下降，影响到吃饭、吃药、安全。
> - 同时出现情绪低落、什么都不想做、觉得拖累家人——要评估抑郁和自杀风险。
> - 换了药或加了药以后反应明显变慢，先记录时间关系再反馈，不要自行停药。

### 容易踩的坑

1. **把认知损害当懒。** 越催越乱，越乱越不敢做。
2. **觉得“是药吃傻了”，自己停药。** 镇静和认知下降要由医生区分，突然停药的风险更大。
3. **只做“脑力训练”App。** 练了游戏分数，不一定迁移到做饭和上班。
4. **拿病前水平要求。** 目标应该是“能完成”，不是“和以前一样快”。
5. **一次交代五件事。** 结果往往一件都没完成，双方都受挫。
6. **忽视抑郁。** 抑郁造成的“假性痴呆”可以改善，漏诊代价很大。
