# 2.5 疾病分期：前驱期、急性期、巩固期、维持期

同一句“他病了”，在不同阶段要做的事完全不同：早期是“要不要就诊”，急性期是“怎么保证安全”，缓解后是“怎么不复发、怎么回到生活”。这一页按前驱期、急性期、巩固期、维持期四个阶段讲目标与家属的位置，适合刚接触这个病、想弄明白“现在算哪一步”的人。读完你会知道分期是医生用来决定治疗强度的工具，而不是给自己贴标签的尺子。

## 一、分期是为了决定“现在该做什么”

精神分裂症的病程差异很大：有人一次发作后长期稳定，有人反复波动，有人以阴性症状和功能下降为主。分期不是给病程画一条直线，而是帮助医生判断三件事——现在的主要矛盾是控制症状、防止复发，还是恢复功能。

需要提前说明：分期主要由医生根据症状、病程、功能、治疗反应来综合判断，患者和家属很难自己“对号入座”。把分期当成理解治疗逻辑的框架可以，当成自我诊断的依据不行。

## 二、前驱期：模糊、非特异、不能据此下诊断

前驱期指正式发病前的一段变化期，可能持续数月到数年。常见表现是“整个人慢慢不对了”：

- 成绩或工作表现下降，注意力不集中；
- 变得孤僻，不愿见人，和家人说话变少；
- 情绪不稳、易怒、焦虑、睡眠差；
- 变得多疑，觉得别人在议论自己；
- 说话开始绕、难懂，或内容变得奇怪；
- 偶尔出现很轻的幻觉，比如听到叫自己名字，但很快过去；
- 个人卫生变差，兴趣减少。

这些表现单独看都很普通，青春期、抑郁、压力大、熬夜都可能出现。所以前驱期不能靠“对症状”来确诊。

研究显示，被列为“临床高危”的人里，多数并不会发展为精神病；一部分会，一部分会缓解，还有一部分会走向其他精神障碍。【研究】这也是为什么对高危状态的处理以“减少应激、治疗共病、定期随访、避免大麻等物质”为主，而不是急着长期用药。

需要提醒的是：如果家里有青少年出现上述变化，还伴随成绩断崖式下降、说话让人听不懂、明显疑心，值得尽快看精神科，而不是等到“确定是精神病”再去。

## 三、急性期：目标是控制症状、保证安全

急性期的典型表现是阳性症状突出：幻觉、妄想、思维紊乱、行为紊乱，常伴睡眠差、进食差、情绪激动。这个阶段的主要目标很明确：

1. **保证安全**：自杀、伤人、拒食、走失、意外。
2. **控制症状**：以抗精神病药为主，医生通常从低剂量开始、逐步调整，具体方案个体差异很大，以处方为准。
3. **处理诱因和共病**：物质使用、感染、睡眠剥夺、躯体疾病。
4. **建立治疗关系**：让患者和家属理解“为什么要治、治多久”。

急性期通常需要数周才能看到明显改善，不要期待吃几天药就“恢复正常”。部分患者需要住院：有明显自伤伤人风险、拒食、木僵、门诊调整无效、需要排除躯体病因时，住院是更安全的选择。是否住院、自愿还是非自愿，按精神卫生法和医生评估决定。

## 四、巩固期与维持期：目标是防复发、恢复功能

症状缓解不等于病好了。急性期之后，症状可能残留，复发的风险也仍然存在。

**巩固期**的目标是“稳住”：在症状明显缓解后继续原有治疗一段时间，避免过早减量导致反弹；同时开始处理阴性症状、认知损害和情绪问题。这个阶段最容易出现两种偏差：家属觉得“好了可以停了”，患者觉得“我没病了为什么还吃”。两种情况都需要在复诊时摊开来谈。

**维持期**的目标是“长期不复发 + 回到生活”：继续维持治疗、定期随访、识别复发前兆、恢复学习工作与社交。维持多久没有适用于所有人的答案，指南普遍建议在缓解后继续较长时间的维持治疗，具体由医生根据发作次数、既往停药后复发的历史、症状残留、副作用耐受性和患者意愿来决定。【指南】

一个常被低估的事实：停药后复发的风险很高，而且每次复发都可能带来功能上的倒退。所以减量、停药必须是医生的计划，不能自己决定。突然停药还可能出现失眠、激越、幻觉加重等反应。

## 五、四个阶段的目标对照

| 阶段 | 主要目标 | 家属能做什么 |
|---|---|---|
| 前驱期 | 识别变化、减少应激、治疗共病、定期随访 | 记录变化时间线；不贴标签；督促睡眠与就诊 |
| 急性期 | 控制症状、保证安全、排除躯体病因 | 陪同就诊；管理危险物品；如实提供病史；不争辩症状 |
| 巩固期 | 稳住疗效、处理残留症状、重建作息 | 提醒服药；观察副作用；不因“看起来好了”就自行减药 |
| 维持期 | 预防复发、恢复功能、提高生活质量 | 识别复发前兆；支持上学上班；维持随访；准备危机预案 |

### 每个阶段都可以做的一张小清单

- [ ] 这周睡眠大约几点到几点，有没有连续几天明显减少。
- [ ] 药有没有漏，有没有自己加减。
- [ ] 情绪是往“烦躁、话多”走，还是往“低落、沉默”走。
- [ ] 有没有新的疑心、新的声音、新的奇怪说法。
- [ ] 吃饭、洗漱、出门这三件事，比上个月是多了还是少了。
- [ ] 下次复诊是哪天，要问的三个问题写好了没有。
- [ ] 家里的危险物品和紧急联系电话，是不是还在原处。

### 不同阶段，家里说话的方式也不一样

急性期，少讲道理，多给安全感：“我在，我们去看医生。”巩固期，重点在稳定：“这周过得怎么样，药有没有漏？”维持期，重点在生活：“你想先试着做哪一件？”同一句话放在不同阶段，效果可能完全相反。

### 不要用分期给自己或家人“分期诊断”

- 分期是回顾性判断。当下很难说“我在前驱期还是急性期”，医生也要看一段时间的变化。
- “前驱期”这个标签会带来焦虑和歧视。孩子只是最近成绩差、不爱说话，不等于要发病。
- 症状波动不等于“进入新阶段”。睡不好、压力大、漏服药都会让症状暂时变重，先找原因。
- 不同医院的记录可能用不同说法，复诊时直接问：“现在这个阶段，治疗重点是什么？”

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊或拨打 120：**
>
> - 出现自杀念头、自杀计划或自伤行为；
> - 命令性幻听，或已经按命令行动；
> - 木僵、缄默、拒食超过一两天，或明显脱水；
> - 高热、肌肉僵硬、意识改变、大汗；
> - 明显激越伴伤人威胁；
> - 首次出现精神病性症状，同时有发热、头痛、抽搐、意识波动。
>
> **尽快联系门诊医生：**
>
> - 睡眠连续几天明显减少，疑心变重，说话又开始绕；
> - 患者提出想减药或停药；
> - 出现明显的情绪低落、焦虑、坐立不安；
> - 服药后有让人难以忍受的副作用；
> - 学校或单位反馈“状态不对”，而家里说不清哪里不对。

### 容易踩的坑

1. **“好了就不用吃药了”。** 症状消失是治疗起效，不是疾病消失。
2. **把前驱期当命运。** 高危不等于发病，多数人不会发展成精神病。
3. **用分期互相指责。** “你就是不肯好”这类话，会把人推得更远。
4. **只盯症状，不管功能。** 能上学、能做饭、能和人说话，和症状分数一样重要。
5. **复发后自己把药加回去。** 剂量和方案要医生定，自行加量可能带来副作用。
6. **忽略躯体原因。** 首次发作、非典型表现，都要排除脑部和躯体疾病。
