# 2.1 阳性症状：幻觉与妄想

精神分裂症最容易被外人注意到的，是“多出来的”体验：听到别人听不到的声音，坚信自己被监视、被控制，说话跳来跳去接不上。这一页把这些体验拆开讲清楚，适合刚出现异常体验的人、被吓到的家属，以及想弄明白“他到底在经历什么”的读者。读完你能分清普通的多疑和妄想、知道命令性幻听为什么要当急症处理，也知道家属怎么观察和记录，而不是靠争辩。

## 一、“阳性症状”指的是“多出来的东西”

精神科把症状粗略分成三类。阳性症状是正常功能里多出来的部分：幻觉、妄想、思维形式紊乱、明显紊乱或激越的行为。阴性症状是正常功能里少了的部分：情感表达变少、话变少、没劲、不愿社交。认知损害则是注意、记忆、计划能力下降。三类常常同时存在。【指南】

“阳性”没有任何褒贬，只是在描述“加出来的症状”。这类症状通常对药物治疗反应相对明显，也常在复发早期最先冒头：睡眠变差、疑心变重、声音又出现了。所以它们既是治疗目标，也是复发预警信号。【指南】【临床经验】

需要先说明一句：出现幻觉或妄想，并不等于精神分裂症。严重抑郁、双相障碍、物质使用、某些躯体疾病和药物都可能引起类似体验，这正是需要医生鉴别的理由。

## 二、幻觉：没有外界刺激，却有真实感受

幻觉是在没有相应外界刺激时出现的真实知觉：没有人说话却听到声音，没有人在却看到人影，没有气味却闻到异味。它和错觉不同，错觉是“有东西但看错了”，比如把衣架看成一个人。幻觉也不等于想象，患者不是“假装听到”，他的体验往往和真实听到一样清楚。

五种感官都可能出现幻觉，其中听幻觉最常见，也最影响诊断和治疗。【指南】

### 听幻觉的几种样子

- 简单的声音：嗡嗡声、敲门声、一段音乐。
- 说话声：一个或多个“人”在讲话，可能是熟人，也可能是陌生人。
- 评论性幻听：声音像旁白一样评论患者正在做的事，比如“他又在发呆了”。
- 对话性幻听：两个或多个声音在争论、商量，甚至议论患者。
- 命令性幻听：声音直接下指令，“别吃了”“跳下去”“去打他”。
- 思维鸣响：自己的想法刚出现，就同时被一个声音念出来。

患者对声音来源的判断常常很确定：“就在门外”“在墙里”“是邻居装的设备”。这时争辩“根本没有声音”通常无效，还会让他觉得你也在骗他。

### 命令性幻听：按急症对待

命令性幻听是自伤和暴力风险的重要风险因素之一，但不是“一定会执行”。风险高低与这些情况有关：命令内容是否具体、患者是否相信那个声音无所不能、是否同时有被害妄想、是否饮酒或使用兴奋剂、是否刚停药、身边有没有可用的危险物品。绝大多数患者不会照着声音去做，但少数情况确实危险，不能赌。【指南】【临床经验】

只要出现下面任何一种，不要等门诊，直接去精神科急诊；患者拒绝就医或已经准备行动时，拨打 120，有伤人风险时拨打 110：

- 声音命令伤害自己或他人；
- 患者开始按命令做准备，比如囤药、找刀、写告别信、反复站到窗边；
- 患者说“不照做就会被惩罚”，表现出明显恐惧；
- 同时有被害妄想，坚信某人要伤害自己，并打算“先下手”。

## 三、妄想：改不掉的错误信念

妄想是一种与现实不符、与所处文化背景也不相符的坚定信念。它不因相反证据而改变，也不是靠讲道理能说通的。判断时要考虑文化背景：某些信念在特定宗教或民俗语境里并不算妄想。

| 类型 | 患者可能怎么说 | 家属看到的样子 |
|---|---|---|
| 被害妄想 | “有人在饭里下毒”“他们在跟踪我” | 反复锁门、检查食物、不敢出门、偷偷录音 |
| 关系妄想 | “电视里那句话是在说我”“路人都在议论我” | 觉得陌生人都在针对自己，回避公共场所 |
| 被控制妄想 | “我的脑子被机器控制了”“身体不由我做主” | 说想法、动作被外力操纵，可能因此攻击“操控者” |
| 夸大妄想 | “我是重要人物，有特殊使命” | 说话夸张、要做大事、拒绝常规治疗 |
| 嫉妒妄想 | “伴侣一定出轨了” | 反复查手机、跟踪、质问，冲突不断升级 |
| 躯体妄想 | “我身体里长了东西、烂掉了” | 反复就医、要求手术，检查正常也不相信 |

### 被害妄想与关系妄想

被害妄想是最常见的一类。患者不是在“演戏”，而是真的感到威胁，所以可能锁门、拉窗帘、囤积食物、拒绝吃喝别人给的东西。关系妄想则是把外界中性的事件读成针对自己：广告牌、新闻、同事的笑声。两者常一起出现，情绪底色是恐惧和警觉。

家属最容易犯的错是“举证式辟谣”：拿出监控、找人作证、逼患者承认自己错了。证据越硬，患者越可能把家属也算进“他们”里。更稳的做法是先接住情绪：“你现在很害怕，我先陪着你”，再把具体的安全安排交给医生。

### 被控制感

被控制感指患者觉得自己的想法、情绪或动作被外部力量操纵，比如“脑子里被植入了芯片”“手自己动起来”。这种体验非常可怕，也容易引发针对“操控者”的冲动行为。它属于需要尽快药物干预的症状，不适合只做心理疏导。

### 和“多疑”“固执”的区别

普通人也会多疑，但通常能被解释松动，也会随着情境变化。妄想的几个特点是：坚信程度极高、不因反证改变、内容离奇或与背景明显不搭、明显影响生活。是否“离奇”要由医生结合文化背景判断，家属不必自己下结论。

## 四、思维形式障碍：想法“接不上”

思维形式指“怎么组织想法”，思维内容指“想的是什么”。妄想是内容出了问题，思维形式障碍是结构出了问题。

- 思维松弛：句子之间失去逻辑连接，听着像各说各的。
- 思维破裂：严重时句子内部也断裂，词和词拼不起来。
- 答非所问、思维中断：说着说着停住，说“有人把想法拿走了”。
- 语词新作：自造词，只有他自己懂。
- 病理性赘述：绕一大圈说不到重点。
- 思维贫乏：内容空、话少，更偏阴性症状。

家属常把这些概括成“胡言乱语”，但医生需要的是原话。用手机记几句、或者事后照抄，比“他说话没逻辑”有用得多。

## 五、家属怎么观察和记录

- [ ] 记下第一次出现的时间，当时有没有熬夜、饮酒、使用大麻或兴奋剂、刚停药。
- [ ] 尽量记原话，不改写、不概括成“他说胡话”。
- [ ] 记录频率和持续时间：一天几次、每次多久、最近是变多还是变少。
- [ ] 记录伴随情况：睡眠、吃饭、上班上学、愿不愿出门。
- [ ] 记录安全相关内容：有没有命令、有没有提到具体的人或地点、家里有没有刀和大量药物。
- [ ] 记录服药情况：吃没吃、有没有自己减量、有没有副作用。
- [ ] 观察情绪：害怕、愤怒、低落、麻木，各持续多久。
- [ ] 复诊时按时间顺序讲，不要一次抛十个问题。

不要偷偷录音录像后到处传播，也不要在患者不知情时把他的原话发到亲戚群。这类做法一旦被发现，会严重破坏信任，也会让后续治疗更难进行。

## 六、什么时候需要联系医生 / 去急诊

> **出现以下情况，立即去精神科急诊；患者拒绝或无法配合时拨打 120，有伤人风险时拨打 110：**
>
> - 命令性幻听，或患者已经开始按命令行动。
> - 被害妄想伴随明确的“自卫”准备，或已经发生推搡、持物威胁。
> - 幻觉、妄想突然加重，伴整夜不睡、不进食、到处乱走。
> - 新出现的幻觉妄想伴发热、头痛、意识时清时浊、抽搐、走路不稳——要排除脑部或躯体疾病，走急诊而不是门诊。
> - 出现自伤、自杀的言语或行为。
>
> **可以先联系门诊医生、调整复诊时间的情况：**
>
> - 症状比上周多一些，但能正常吃饭睡觉，没有伤害自己或他人的想法。
> - 药物副作用让人难受，比如手抖、坐不住、发胖。
> - 家属不知道怎么应对，需要有人教具体的说法。

### 容易踩的坑

1. **和声音争辩。** “根本没有声音”会让患者觉得你不信他。先接住情绪：“那个声音在骂你，一定很难受。”
2. **顺着妄想一起演。** 为了安抚而一起“对付邻居”，会让妄想更牢固。可以说“我不确定，但我相信你现在很害怕”。
3. **把妄想当成故意找茬。** 患者不是想控制你，他是真的相信。
4. **只盯幻觉，不看功能。** 声音还在但能上班、能吃饭，和声音没了却整天躺着，处理重点完全不同。
5. **用“中邪”“想太多”拖延。** 首次出现精神病性症状越早评估越好，拖延会拉长未治疗的时间。
6. **自行加药或停药。** 突然停药可能引起失眠、激越、幻觉加重和复发。
