# 6.3 CBTp：针对精神病性症状的认知行为治疗

CBTp 是“针对精神病性症状的认知行为治疗”的缩写（Cognitive Behavioural Therapy for psychosis）。它常被误会成“劝人承认自己有病的谈话”，其实方向相反：它从这个人正在经历的痛苦出发，一起看这些体验是怎么被解释、怎么影响生活的，再找出能松动的地方。这一页讲它做什么、不做什么、适合谁、大概要做多久，以及证据到底有多硬。

## CBTp 做什么、不做什么

### 做什么

**第一，做个案概念化。** 治疗师会和患者一起，把症状放回生活里理解：这些体验是什么时候开始的，什么情况下加重，睡眠、压力、冲突、孤独起了什么作用，哪些应对方式短期缓解、长期却让问题更大（比如因为怕被监视而整天拉窗帘，结果越不出门越确信）。概念化不是找谁的错，也不是挖童年，而是画一张“问题怎么维持下去”的地图。地图清楚了，才知道从哪里下手。

**第二，正常化。** 治疗师会说明：在极度缺觉、长期压力、创伤或药物作用下，人也可能出现听见声音、觉得被针对的体验。正常化的意思不是“你没病”，而是“这种体验有它可以理解的部分”，这能降低羞耻感，也让人更愿意谈细节。

**第三，合作检验想法。** 不是辩论“你的妄想是错的”，而是一起看：支持这个想法的证据有哪些，有没有别的解释，如果换一种解释，生活会不会好过一点。常用方法是行为实验：把一个“如果……就说明我被监视”的预测，变成一次可以观察的小尝试，再一起看结果。

**第四，处理幻听带来的痛苦。** 包括记录声音出现的时间、内容、当时的情绪；讨论“这个声音有多大权力”；准备应对卡（听音乐、找人说话、专注做事、离开某个环境）；也包括直接和声音“对话”的练习，前提是患者愿意。

**第五，减少回避。** 很多痛苦不是症状本身，而是为了躲症状付出的代价：不出门、不上班、不见人、反复检查。CBTp 会把这些回避拆成小步骤，一步步加回来。

**第六，谈药物。** 不是劝“你必须吃”，而是把吃药放进目标里谈：你想减少复发、想能上班，药在这件事里起什么作用，副作用怎么和医生谈。最终决定权在患者和医生。

### 不做什么

- **不试图说服患者承认“我有精神病”。** 承认诊断不是治疗的前提。很多有效的 CBTp 会谈里，双方对“这是不是病”意见不同，但仍然能合作处理失眠、回避和痛苦。
- **不和妄想正面辩论。** “你说邻居监视你，证据呢？”“这不可能！”这类对话只会让人更防备。CBTp 问的是“还有没有别的可能”，不是“你错了”。
- **不劝停药、不劝减药。** CBTp 不替代药物，也不能把复发风险降到可以停药的程度。
- **不是“想开点”“积极思维”。** 它要求具体、可观察、可验证，不靠打气。
- **不是一次谈话就见效。** 它是一段有结构、有作业、有回顾的治疗。
- **不是所有人都要谈创伤。** 创伤知情是态度，不等于每个人都必须做创伤加工。

## 适合谁、什么时候要等一等

| 情况 | 是否适合 | 怎么调整 |
|---|---|---|
| 幻觉妄想还在，但能对话、能出门 | 适合 | 以痛苦和回避为目标，不必先消除症状 |
| 不认同诊断，但愿意谈困扰 | 适合 | 不谈病名，谈睡眠、害怕、吵架 |
| 同时有抑郁、焦虑、社交恐惧 | 适合 | 可整合处理，先处理最影响生活的一项 |
| 急性兴奋、思维极度散乱 | 暂缓 | 先药物稳定，改为支持性接触 |
| 严重认知损害、注意力维持很短 | 需调整 | 缩短会谈、多用图卡、家属参与 |
| 正在大量使用大麻或兴奋剂 | 先处理 | 物质使用会让会谈效果打折扣 |
| 有明确自杀计划 | 先保安全 | 先做安全计划与急诊评估，再谈症状 |
| 极度偏执、无法建立基本信任 | 先建关系 | 从具体事务入手，不急于谈信念 |

一个常被忽略的适合人群：症状已经不太重，但一直不敢坐公交、不敢去超市、不敢接电话的人。CBTp 对这类“症状后遗的回避”往往比对新发幻觉更有效。

## 一次会谈大概发生什么

以“觉得邻居在监视自己、不敢开窗”为例，一次会谈可能这样走：

1. **回顾上周。** 哪天最难受，当时在做什么，身体什么反应，后来怎么应对。
2. **选一个具体情境。** 不是笼统谈“被监视”，而是“周三晚上七点，楼下有人说话，你觉得他们在说你”。
3. **记录想法与情绪。** 当时的念头是什么（“他们在记录我”），情绪多强（十分里几分），做了什么（关窗、拉帘、不出声）。
4. **看证据，两栏写。** 支持的一栏、不支持的一栏，都写具体事实，不写“我就是知道”。
5. **找替代解释。** 不必接受，只要能“暂时并列”：也可能是邻居在聊家常，也可能是自己最近睡太少更敏感。
6. **设计一个小实验。** 比如“开窗五分钟，站在离窗两米的地方，记录焦虑从几分降到几分，以及有没有出现‘被记录’的实际后果”。实验要小到能做成，不做“证明你错了”的大测试。
7. **复盘。** 重点不是“你看没人监视你”，而是“即使不完全确定，开窗这件事能不能做到一点”“焦虑有没有从八分降到六分”。
8. **布置作业。** 一周两次，记录表带回来。

一次会谈通常四十五到六十分钟。有效的不只是谈话内容，还有稳定的关系：同一个人、同一时间、不评判，本身就有作用。

## 疗程与证据

**形式与长度。** 通常是一对一，每周一次，至少十六次，持续数月；也可以做团体形式。次数不是硬指标，症状持续多年、目标较多的人往往需要更长。【指南】

**证据。** 多项随机对照试验和系统综述显示，CBTp 对持续存在的阳性症状有小的到中等程度的改善，对症状带来的痛苦、回避和部分功能有帮助；对阴性症状和认知损害的证据较弱；对“减少住院”的结果不一致。【研究】效果通常在治疗结束后一段时间内部分保留，但不是永久。

**指南态度。** NICE 的成人精神病与精神分裂症指南推荐把 CBTp 作为可用干预，同时指出总体效应量有限，2020 年更新后的措辞比早期版本更谨慎，更强调针对持续症状和个体需要。【指南】这不等于“没用”，而是说：它不是万能钥匙，也不该被当成必须完成的打卡项目。

**期待怎么定。** 合理的期待是：更能理解自己的体验、少一点害怕、多做成几件事、和家人的冲突少一点。不合理的期待是：做完就听不到声音、可以停药、从此不再复发。

**怎么配合。** 患者可以做的：把作业当成治疗的一部分，记录具体情境而不是笼统感受；会谈中觉得被冒犯就直接说；对目标有不同意见就提出来。家属可以做的：不追问会谈内容（隐私归患者），帮忙留出固定时间，不在会谈前后争论“你到底有没有病”。【临床经验】

### 开始之前，可以准备的清单

- [ ] 写下三个“想改善的具体场景”，比如坐公交、去超市、接电话。
- [ ] 和医生确认：现在的状态能不能坐下来谈四十五分钟。
- [ ] 想清楚哪些事暂时不想说，提前告诉治疗师。
- [ ] 问清楚大概做多少次、什么时候评估有没有效。
- [ ] 准备一个本子，只记情境、想法、情绪强度、做了什么。
- [ ] 和家属说好：会谈内容不追问，时间不被打断。
- [ ] 约定症状加重时找谁、什么情况下暂停会谈。

### 常见问题

**CBTp 会不会给我洗脑？** 不会。它的前提是你有权不同意治疗师的解释，治疗师的工作是提供另一种看法，不是替换你的看法。如果一次会谈让你觉得被强迫承认什么，可以直接说出来，也可以换治疗师。

**谈了会不会让症状更重？** 聚焦症状的谈话在少数人身上会短期升高焦虑，正规做法会控制节奏、先建立稳定感，并在症状急性加重时暂停。如果谈完连续几天失眠、猜疑明显加重，应告诉治疗师和医生。

**找不到会做 CBTp 的医生怎么办？** 国内受过系统训练的治疗师仍不多。可先问精神科门诊、日间病房、大学心理中心或当地精神卫生中心；也可以先用心理教育、家庭干预、职业支持打底。CBTp 不是康复的必经门槛。

## 什么时候需要联系医生 / 去急诊

> CBTp 进行中，出现以下情况要先停下治疗，处理安全。
>
> - 出现自杀念头、自伤行为或具体计划：不要独处，呼叫 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 命令性幻听让你去做危险的事，或坚信有人要伤害你而准备“先下手”：远离冲突现场，呼叫 **120**，必要时 **110**。
> - 连续几天几乎不睡、极度兴奋、话停不下来：尽快精神科就诊。
> - 出现木僵、缄默、拒食、违拗、长时间保持怪异姿势：可能是紧张症，立即急诊。
> - 服药后高热、肌肉僵硬、意识改变、大汗：可能是恶性综合征，立即停药并急诊。
> - 自行停药后失眠、激越、幻觉明显加重：尽快联系医生，不要自行加回原量。
> - 会谈后症状持续加重超过一周，或出现新的自伤冲动：联系治疗师与处方医生，评估是否暂停。
