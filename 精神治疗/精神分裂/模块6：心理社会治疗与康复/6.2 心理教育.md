# 6.2 心理教育

心理教育是心理社会干预里最基础的一项：把疾病、治疗、复发和权利讲清楚，让患者和家属能听懂、能提问、能参与决定。它听起来简单，做起来却常变成单向说教，或者变成“你到底认不认自己有病”的试探。这一页讲清楚该讲什么、怎么讲、怎么用它提高依从性而不让人反感。

## 心理教育不是“上课”，也不是“查忠诚”

心理教育（psychoeducation）指的是：用普通人听得懂的话，系统讲解疾病知识、治疗原理、副作用监测、复发信号、应对方法和社会资源。它有四个目标：理解自己的状态、参与治疗决定、更早识别复发、减少自责和病耻感。【指南】

它不是这四件事：

- 不是说服患者承认“我有精神病”。承认诊断不是配合治疗的前提，很多人一边不认同诊断，一边愿意吃药、愿意复诊，这同样可以工作。
- 不是考试。记不住药名、说不清受体，不影响治疗效果。
- 不是只给家属上课。患者本人有知情权，被排除在信息之外，容易产生“你们合起来骗我”的感觉。
- 不是一次性告知。刚被诊断时，人的注意力大概只够记住两三句话，剩下的信息要分次、重复地给。

判断一次心理教育有没有用，不看讲了多少，看对方有没有多问出一个问题、有没有多知道一件可以做的事。它也不能替代药物和复诊：心理教育提高的是理解和参与，不是疗效本身。

## 该讲什么：一份可以照着讲的内容清单

| 主题 | 要讲到的点 | 常见误解 |
|---|---|---|
| 诊断与症状 | 阳性、阴性、认知症状分别是什么；诊断是当前状态的归纳，不是判决 | “精神分裂就是人格分裂” |
| 病程 | 多数人需要长期治疗；复发常见；个体差异很大 | “吃几个月就能断根” |
| 药物 | 药物降低复发风险、改善哪些症状；起效需要时间 | “药是毒，会吃坏脑子” |
| 副作用 | 常见副作用、哪些需要报告、怎么监测体重血糖 | “忍忍就过去了，不用说” |
| 复发信号 | 睡眠变少、猜疑变多、幻听变频繁、突然停药 | “复发了再治也一样” |
| 应激与物质 | 熬夜、冲突、大麻与兴奋剂的风险 | “大麻能放松，没关系” |
| 功能与目标 | 复学、复工、社交、独立生活可以分步来 | “这辈子不能工作了” |
| 权利与保密 | 知情同意、隐私、非自愿住院的条件 | “住院就出不来了” |
| 危机应对 | 谁打电话、去哪家急诊、药放在哪 | “到时候再说” |

这张表不必一次讲完。急性期先讲三件事：这是什么病、药为什么现在不能停、出现什么要马上找医生。其余内容放在复诊和家属会谈里，一次一个主题。

讲副作用时有个平衡要把握：只讲“可能很严重”会让人不敢吃药，只讲“没事”会让人在出现问题时不知所措。可行的说法是：这类药常见的反应是哪些，我们怎么监测，出现哪一种要打电话，出现哪一种要立刻去急诊。把“监测方案”一起给出去，恐惧才会变成可控。

## 怎么讲才听得进去

**先问，再讲。** 开口前先问一句：“关于这个病，你目前最想搞清楚的是什么？”对方关心的往往不是发病率，而是“我还能不能上班”“药会不会让我变傻”“会不会遗传给孩子”。从他的问题进入，比从教科书第一章进入有效得多。

**用他的词，不用术语。** 说“脑子里有声音在评论你”，比说“评论性幻听”更容易接住；说“觉得别人都在针对你”，比说“关系妄想”更接近体验。术语可以后置，作为“医生记录里会写成某某”的补充。

**请对方复述。** 讲完一段，问“如果我讲得太绕，你用自己的话说一遍，我听听有没有说错”。这叫回述法，能立刻暴露误解，也不会让人感到被考。对方复述错了，先认可他抓住的部分，再补差别。

**允许不认同。** “我不觉得自己有病”这句话，可以接：“你可以不同意这个诊断，我们先不谈诊断，谈你想解决的问题——比如晚上睡不着、白天没劲。这些能不能一起想办法？”不和信念硬碰，治疗照样能推进。

**分开谈，再合谈。** 患者在场时，家属常常抢着补充，患者容易闭嘴。可以先和家属谈一次（讲照护和危机预案），再和患者单独谈一次（讲自主和目标），最后一起谈（讲分工）。三次各二十分钟，比一次讲两小时有用。

**给书面材料，并且重复。** 人走出诊室就会忘。一页纸的要点、复诊时再问一遍、家属手机里存一份，比一次讲透更可靠。

### 一次十分钟的对话示例

患者：“我没病，是你们逼我吃药。”

家属常接：“你怎么没病？医生都说了！”——这句话之后，谈话基本结束。

可以换成三段：

1. 接住情绪：“你觉得被逼着吃药，很不舒服，我理解。”
2. 绕开诊断，谈目标：“那我们先不谈病名。你最近睡得怎么样？白天是不是很累？这两件事你想不想改善？”
3. 给出选择：“医生说药对睡眠和紧张有帮助，也可能有副作用。我们可以先试两周，你把不舒服记下来，复诊时我们一起跟医生提。如果完全没帮助，也可以跟医生讨论换方案。”

这不是骗人，也不是承认“没病”。它把“承认诊断”这个高门槛，换成了“愿不愿意试一个可能有用的小步骤”。前提是说法要和医生的解释对得上：可以说“这个药对睡眠和紧张有帮助”，不能编造“这不是治精神病的药”。

## 提高依从性，而不是“管住他”

依从性差很少是“不听话”，通常有具体原因。找原因，比加监督有效。

| 常见原因 | 表现 | 可以做什么 |
|---|---|---|
| 副作用难受 | 手抖、发胖、嗜睡、坐立不安 | 记录具体症状和时间，复诊时提出；由医生调整，不自行减量 |
| 觉得自己好了 | “我已经正常了，不用吃了” | 讲清维持治疗与复发的关系；把停药决定交给医生评估 |
| 病耻感 | 怕同事看见、怕被叫精神病 | 换包装、固定私密服药时间；讨论是否披露 |
| 忘记 | 作息乱、药多、出门在外 | 和刷牙、早饭绑定；分装盒、手机提醒；家属只提醒不催逼 |
| 费用与取药不便 | 异地、挂号难、自费压力 | 问社区随访、门诊慢病政策、长效针剂是否减少取药次数 |
| 不信任 | 觉得医生敷衍、被强制过 | 换一位能沟通的医生；带上问题清单；家属陪同 |
| 认知困难 | 记不住用法、分不清药盒 | 简化方案（由医生做）、贴标签、家属代管但保留知情 |
| 家庭冲突 | 吃药变成权力斗争 | 把“吃不吃”从亲子对抗里拿出来，交给医生和患者谈 |

真正有效的做法通常是组合：医生做共享决策，患者知道自己在吃什么、为什么吃，家属提供提醒而非监工，复诊时固定检查副作用。单靠“盯着咽下去”，很难撑过一年。

### 复诊前花五分钟的依从性自查

- [ ] 这一周有没有漏服？漏了几次，当时在做什么？
- [ ] 有没有出现新的不舒服：手抖、发胖、嗜睡、坐立不安、月经变化？
- [ ] 有没有因为“感觉自己好了”而自行减量？
- [ ] 药还够吃到下次复诊吗？
- [ ] 有没有人劝你停药、换药，或者推荐保健品替代？
- [ ] 下一次复诊是哪天，谁陪你去？
- [ ] 如果出现急症，打哪个电话、去哪家医院？

### 关于“把药藏进饭里”

有些家属会把药磨碎混进食物。这不推荐，原因很具体：患者不知情，等于剥夺知情同意；一旦发现，信任很难修复，之后可能连必要的药也拒绝；剂量和相互作用不可控；有的药味道苦、刺激性强，混在热食里可能影响吸收；还有呛咳和噎食风险。

如果患者持续拒药，且症状加重、有伤人毁物或拒食风险，正确路径是联系医生评估，必要时急诊或住院处理，而不是家庭内部私自给药。紧急情况下怎么做得由医生判断。【指南】

## 常见问题

**要不要告诉患者诊断？** 多数情况下要，但可以分次、用他能接受的说法。完全不说的风险是：他自己上网查、从亲戚口中听到、或者从药盒上看到，反而更崩。说的时候带上“这个诊断意味着什么、不意味着什么”。

**他一直否认有病，心理教育还有用吗？** 有用，但目标要改。不追求“承认诊断”，追求“愿意为解决具体问题尝试治疗”。这两件事在临床上可以分开。

**讲副作用会不会吓得他不敢吃药？** 会，如果只讲风险不讲监测。把“出现什么、找谁、多久查一次”一起讲，多数人反而更安心。

**家属自己听不懂怎么办？** 每次复诊准备三个问题，写在纸上：现在吃的是什么、为什么吃、出现什么要打电话。医生通常愿意回答具体问题，不愿意回答“你说该怎么办”这种开放式提问。

**心理教育能代替心理咨询吗？** 不能。心理教育是知识和决策层面的工作；CBTp 处理的是症状带来的痛苦和应对方式；家庭干预处理的是互动模式。三者目标不同，可以叠加。

## 什么时候需要联系医生 / 去急诊

> 心理教育过程中，如果出现以下情况，停止讲解，先处理安全。
>
> - 患者表达自杀念头、自伤计划，或说“活着没意思”：不要独处，呼叫 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 出现命令性幻听、坚信被追杀、明显激越或伤人风险：不要争辩和围堵，先保证安全，呼叫 **120**，必要时 **110**。
> - 出现木僵、缄默、拒食、违拗、保持固定姿势：可能是紧张症，立即急诊精神科评估。
> - 服药后高热、肌肉僵硬、意识改变、大汗、心跳很快：可能是恶性综合征，立即停药并急诊。
> - 服用氯氮平期间发热、咽痛、口腔溃疡、乏力：立即查血常规。
> - 进食呛咳、吞咽困难、呼吸困难：警惕噎食，立即急诊。
> - 患者自行突然停药后出现严重失眠、激越、幻觉加重：尽快联系医生，不要自行加回原量。
