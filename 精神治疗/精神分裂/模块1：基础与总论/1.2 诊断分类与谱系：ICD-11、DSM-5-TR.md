# 1.2 诊断分类与谱系：ICD-11、DSM-5-TR

拿到诊断时，你可能会遇到好几个名字：精神分裂症、分裂情感性障碍、短暂精神病性障碍、妄想障碍，还有“物质所致”“躯体疾病所致”。在不同的医院，甚至同一个人不同时间，诊断也可能不一样。这一页讲清两套最常用的分类系统怎么用、谱系里几个“邻居”差在哪里、为什么诊断会变。读完你能看懂病历上的诊断名称，也知道该向医生追问什么。

## 一、诊断是“排除”出来的，不是“对上一个症状”

很多人的想象是：医生问几个问题，对照一张症状表，对上就打勾。实际流程更接近“排查”。

医生通常要做四件事：

1. **看症状**：有没有幻觉、妄想、言语紊乱、阴性症状，出现多久，怎么变化。
2. **看病程**：是几天、几周，还是几个月、几年。病程长短直接决定落在哪个诊断上。
3. **看功能**：学习、工作、自理、人际受影响到什么程度。
4. **排除其他原因**：情绪障碍、物质或药物、躯体疾病、发育问题。

第四步最容易被忽略，却最关键。需要排除的包括：双相障碍的躁狂期、抑郁伴精神病性症状、大麻或兴奋剂所致的精神病性症状、酒精戒断、甲状腺功能异常、癫痫、自身免疫性脑炎、谵妄、某些维生素缺乏、听力或视力障碍带来的误解等。老年人第一次出现精神病性症状，尤其要先查躯体原因。

信息来自三个方向：本人怎么讲、家属怎么补充、既往病历和检查结果。缺了哪一块，诊断都容易偏。所以初诊常需要一次以上面谈，这不是医生拖，而是在收集够用的信息。【指南】

## 二、两套常用分类：ICD-11 与 DSM-5-TR

国际上最常被引用的是世界卫生组织的 ICD-11 和美国精神医学学会的 DSM-5-TR。中国临床和医保、残疾评定更多参照 ICD 体系，研究论文里则两套都常见。

| 对比项 | ICD-11 | DSM-5-TR |
|---|---|---|
| 发布机构 | 世界卫生组织（WHO） | 美国精神医学学会（APA） |
| 使用场景 | 国际疾病分类，中国临床与行政常用 | 北美临床与研究常用，国际研究广泛引用 |
| 精神分裂症要点 | 核心症状至少两项、持续约一个月，功能受影响 | 核心症状至少两项（其中至少一项是妄想、幻觉或言语紊乱），总病程至少六个月，功能下降 |
| 对“亚型”的处理 | 取消偏执型、青春型等经典亚型，改用症状维度描述 | 同样取消经典亚型，紧张症作为独立标注 |
| 共同点 | 都要排除物质、药物与躯体疾病所致；都强调病程与功能 | 同左 |

两套系统的大方向一致，细节门槛不同，所以同一个人在两套标准下可能落到不同名称上。这不代表谁“诊错了”，而是分类系统本来就是人为划定的工具。具体条款以最新版原文和医生的解释为准。【指南】

ICD-11 的一个变化值得知道：它不再把人分成“偏执型”“青春型”，而是描述这个人以哪类症状为主——阳性症状明显、阴性症状明显、抑郁、躁狂、精神运动异常、认知受损。这种描述更贴近临床，因为同一个人的症状构成会随时间变化。

## 三、谱系里的几个“邻居”

“精神分裂症谱系”不是一种病，而是一组在症状上有重叠、在病程和结局上不同的障碍。分清它们，直接影响治疗选择。

| 名称 | 核心特点 | 病程 | 与精神分裂症的关键区别 |
|---|---|---|---|
| 精神分裂症 | 妄想、幻觉、言语紊乱、阴性症状等组合 | 至少一个月（DSM-5-TR 要求总病程六个月以上） | 症状更全面、功能受影响更明显 |
| 分裂情感性障碍 | 精神病性症状与心境发作同时存在 | 心境症状占据病程大部分时间 | 情绪发作是核心部分，不是“附带” |
| 短暂精神病性障碍 | 急性起病的精神病性症状 | 至少一天、不足一个月，之后完全恢复 | 时间短，功能可回到病前 |
| 妄想障碍 | 以持续的妄想为主 | 至少一个月 | 除妄想相关外，行为与功能相对保留 |
| 物质/药物所致 | 使用或停用某物质后出现 | 与物质作用时间吻合 | 停用后多可改善，需尿检等佐证 |
| 躯体疾病所致 | 由甲亢、癫痫、脑炎等引起 | 随原发病波动 | 治原发病为主，精神症状常随之缓解 |

**分裂情感性障碍。** 要点是：精神病性症状和一次完整的心境发作（抑郁或躁狂）重叠出现，心境症状占据病程的大部分时间；同时，病程中有一段时间只有精神病性症状、没有明显心境症状。它既不是“精分加抑郁”，也不是“双相加幻觉”，治疗上常需要抗精神病药与心境稳定剂或抗抑郁药配合，具体由医生判断。

**短暂精神病性障碍。** 起病往往很急，可能在前几天还有明显应激。症状持续至少一天但不到一个月，之后完全恢复到病前水平。名字里的“短暂”容易让人松劲，但急性期的风险（自伤、冲动、走失）一样真实，而且需要随访确认没有转为更长的病程。

**妄想障碍。** 以妄想为核心，内容常涉及被害、嫉妒、躯体或“某个人爱上我”。除了与妄想直接相关的部分，言谈和行为可以相当正常，工作生活也可能维持得不错。这带来一个现实问题：本人往往不觉得需要治疗，家属也很难劝。建立信任比争论内容更有效。

**物质或药物所致的精神病性障碍。** 大麻、兴奋剂、酒精戒断、某些激素和药物都可能引起幻觉或妄想。判断线索是时间关系：症状在物质使用期间或戒断期间出现，停用后减轻。尿检、用药史、家属观察都很重要。把这类情况当成精分来长期用药，会错过真正该做的事。

**躯体疾病所致的精神病性障碍。** 甲状腺功能异常、癫痫、自身免疫性脑炎、谵妄、严重感染、营养缺乏都可能表现为“像精分”。这类情况的处理核心是原发病。若只按精分治，既延误病情，也可能让躯体问题恶化。

## 四、边界为什么重要：诊断会改，治疗也不同

不同诊断对应不同的治疗重心：

- 双相障碍的精神病性症状，重点是心境稳定，单用抗精神病药可能不够；
- 物质所致的精神病性症状，第一步是停用与戒断管理；
- 躯体疾病所致，先治原发病；
- 短暂精神病性障碍，需要短期治疗并密切随访，而不是直接按终身病来安排。

误诊的代价不是抽象的：可能吃错药、错过治疗窗口、背上不必要的标签，也可能漏掉真正危险的躯体问题。

也要接受一件事：**诊断会变**。随着信息增加（症状演变、对治疗的反应、检查结果），医生修正诊断是正常的临床过程，不是“水平不行”。有一类情况叫“诊断漂移”，在病程早期尤其常见，因为那时候证据本来就不够。

## 五、分类不是贴标签

诊断有用：它让医生之间能沟通，让治疗有依据，让医保和残疾评定有标准，让研究能比较不同人群。这些都是真实的好处。

诊断也有局限：

- 同一个诊断的人，症状组合、功能水平、治疗反应可能差别极大；
- 诊断描述的是“现在符合哪一组标准”，不预测某一个人的具体结局；
- 标签一旦写进档案，可能带来就业、保险、婚恋上的歧视；
- 诊断不能定义一个人是谁，也不能解释全部行为。

所以更合适的用法是：把诊断当成“当前最合理的解释和沟通工具”，而不是“关于你这个人的最终结论”。

下次复诊时，可以带着这几个问题去问：

- [ ] 我是否知道自己的完整诊断名称，以及医生依据的是哪几条？
- [ ] 有没有做过排除物质、躯体原因的检查？结果在哪里？
- [ ] 医生预计多久复评一次诊断？
- [ ] 如果症状变化，什么情况下需要重新评估诊断？
- [ ] 诊断信息会出现在哪些材料里，谁可以看到？

## 六、常见问题

**两家医院诊断不一样，听谁的？** 不必急着选边。把两份病历都带给现在的医生，说明各自的依据和时间。诊断不一致本身是有价值的信息，通常说明某些关键信息还不确定。

**会不会过几年变成双相？** 有可能，尤其在早期。心境发作出现后，诊断需要重新评估。这不是坏消息，而是治疗可能因此更对症。

**需要做基因检测或脑影像吗？** 目前这些检查不用于个体确诊精神分裂症。脑影像主要用于排除肿瘤、卒中、脑炎等结构性或炎症性问题；基因检测在少数情况（如遗传咨询）有帮助，但不是常规诊断工具。【待验证】

> **什么时候需要联系医生 / 去急诊**
>
> - 症状突然加重，出现命令性幻听或明确的伤人、自伤念头：不要独处，拨打 120，必要时 110。
> - 急性起病、意识模糊、发热、抽搐：先按躯体急症处理，立即急诊，不要只当成“精神病发作”。
> - 老年人首次出现幻觉、妄想，或伴有记忆明显下降：尽快就诊，需要排除谵妄、脑卒中、感染等。
> - 使用大麻、兴奋剂后出现持续幻觉、极度兴奋或胸痛、心悸：立即急诊。
> - 出现木僵、拒食、缄默、长时间不动：警惕紧张症，急诊精神科评估。
