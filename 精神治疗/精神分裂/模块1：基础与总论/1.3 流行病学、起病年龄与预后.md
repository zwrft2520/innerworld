# 1.3 流行病学、起病年龄与预后

“这病常见吗？”“为什么是他？”“以后会怎么样？”这三个问题，几乎是每个家庭在确诊后都会问的。这一页讲三件事：精神分裂症在人群中的分布、起病年龄与性别差异、以及哪些因素和更好的预后有关。数字部分会尽量谨慎，因为精确的统计数字在不同研究之间差别很大，而“预后”从来不是一个写好的结局。

## 一、有多少人会得：一个谨慎的说法

精神分裂症不算罕见病，但也远没有到“身边到处都是”的程度。国际上常用的粗略估计是：**终生患病风险低于百分之一**。不同研究报告的数字并不一致，从千分之几到百分之一上下都有，差异来自诊断标准、随访年限、年龄结构和地区人群的不同。【研究】

这里要区分两个词：

- **患病率**：某个时间点上，人群中符合诊断的人占多少。
- **发病率**：一段时间内，新发病人占多少。

大众常说的“发病率”往往是患病率。两者不能混着比。

另外，统计数字受“诊断口径”影响很大。用宽的标准，数字会高；用严的标准，数字会低。所以看到“某地精神病患者激增”这类说法，先问一句：是病人真的变多了，还是诊断标准、就诊率、登记制度变了？

还有一点值得说：精神分裂症在全世界各个文化、各个国家都能见到，不是某个地区或某种生活方式特有的病。城市化、移民、社会经济地位较低的人群中报告的发病率偏高，但这些是风险因素层面的观察，不能推到一个具体的人身上。【研究】

## 二、起病年龄：两个高峰

起病年龄是精神分裂症最重要的特征之一，也是它和很多其他精神障碍不同的地方：**它主要攻击年轻人**。

| 阶段 | 大致年龄 | 特点与注意点 |
|---|---|---|
| 儿童青少年期 | 十几岁以前 | 少见，诊断更谨慎，需排除发育、孤独症、创伤等因素 |
| 青年早期 | 十几岁末到二十岁出头 | 男性更常见，起病常较隐匿，前驱期长 |
| 青年后期到三十岁出头 | 二十几岁 | 女性更常见，情感症状可能更突出 |
| 中年以后 | 四十岁以后 | 首次发病需认真排除躯体、物质、情绪障碍 |
| 老年期 | 六十岁以后 | 极少见，必须排除痴呆、谵妄、脑卒中、感染、药物 |

男性起病通常更早，很多在二十岁前后；女性的起病年龄分布更宽，二十几岁是一个高峰，绝经前后还会出现一个小高峰。总体终生风险男女大体接近，差别更多体现在起病时间、症状构成和病程走向上。【研究】

**为什么起病年龄重要？** 因为它正好撞上人生几个关键节点：高考、上大学、第一份工作、开始独立生活、建立亲密关系。疾病在这些节点上打断的不只是身体，还有身份和计划。这也是为什么“早识别、早治疗”在精神分裂症里被反复强调——不是为了抢时间，而是为了少丢东西。【指南】

**晚发不等于轻。** 四五十岁以后第一次出现精神病性症状，首先要做的不是急着贴精分标签，而是查清楚：有没有甲状腺问题、自身免疫性疾病、神经系统疾病、听力视力下降带来的误解、长期物质使用、抑郁或双相。老年人还要特别警惕谵妄——它起病急、波动大、伴意识不清，是急症。

## 三、性别差异：不是“谁更严重”，而是“哪里不同”

把男女差异讲成“男性更重、女性更轻”是不准确的。更贴近临床的说法是：

| 方面 | 男性常见 | 女性常见 |
|---|---|---|
| 起病年龄 | 更早，多在二十岁前后 | 更晚，分布更宽，绝经前后有小高峰 |
| 症状构成 | 阴性症状、认知损害更突出 | 情感症状、抑郁焦虑更突出 |
| 物质使用 | 合并酒精、大麻等比例较高 | 相对较低，但并非少见 |
| 社会功能 | 病前功能较差者较多，就业受影响明显 | 病前功能相对较好，但照护责任更重 |
| 特殊风险 | 就医晚、隐瞒症状 | 孕产期复发、产后精神病、催乳素相关月经问题 |

这些是群体层面的倾向，不能拿来判断某一个人。一个具体的人，可能完全不符合上面任何一条。

对女性来说，有几个时间点需要提前和医生讨论：备孕、怀孕、产后、哺乳、围绝经期。产后是复发和产后精神病风险明显升高的时期，需要提前安排随访，而不是等出事再处理。对男性来说，更常见的问题是拖到很晚才就诊、用酒精或大麻自我“治疗”、以及不愿意承认需要帮助。

## 四、病程的几种走向：异质性有多大

精神分裂症最被低估的一点，是它的**异质性**——同样一个诊断，不同人的走向可以差得很远。

| 走向 | 大致表现 | 在人群中 |
|---|---|---|
| 单次发作后长期稳定 | 一次急性期后症状缓解，功能基本恢复，停药后也未再发 | 少数 |
| 复发—缓解型 | 有发作，治疗后缓解，间隔数月到数年再发 | 较常见 |
| 持续症状伴部分功能 | 阳性症状时轻时重，阴性症状和认知损害持续，需要长期支持 | 相当一部分 |
| 慢性化、功能受损明显 | 症状持续，自理和社交长期受限，需要较多照护 | 少数，但最耗资源 |

要提醒的是：这些“比例”在不同研究里差别很大，随访时间越长，越多人出现复发；而“康复”的定义不同，结论也会不同。所以不要拿某一篇研究里的百分比往自己身上套。

可以确定的是：**最坏的结局不是默认结局**。多数人处在中间地带——有症状，也有生活；需要治疗，也能做点事。把“要么痊愈、要么废掉”这种二选一扔掉，才看得见中间那条路。

## 五、影响预后的因素

研究者反复找到一些和结局相关的因素。它们不是命运，但值得知道，因为其中一部分是可以改变的。

| 有利因素 | 不利因素 |
|---|---|
| 起病较急、有明显诱因 | 起病隐匿、前驱期长 |
| 病前社会功能、学业工作表现较好 | 病前已有明显回避、学业倒退 |
| 首次治疗及时，未治疗期短 | 从出现症状到开始治疗拖了很久 |
| 阳性症状为主，对药物反应好 | 阴性症状、认知损害突出 |
| 家庭支持稳定、不过度批评或包办 | 家庭冲突高、缺乏支持 |
| 能规律服药、定期复诊 | 反复自行停药、失访 |
| 不合并物质使用 | 长期大量使用大麻、酒精、兴奋剂 |
| 没有明显共病（抑郁、躯体病） | 共病多、躯体健康差 |
| 有工作、学习或社会角色 | 长期隔离、无事可做 |

【指南】【研究】

有几条值得展开：

**未治疗的精神病期（DUP）。** 从出现明显精神病性症状到开始规范治疗之间的时间，越长，预后通常越差。这是“早发现早治疗”最硬的证据基础之一。但也要避免另一种极端：为了抢时间而随便找个地方开药，不如尽早找到能系统评估的精神科。【研究】

**阴性症状和认知损害。** 这两块对长期功能的影响，往往比幻听妄想更大。它们对药物反应有限，更需要康复训练、结构化活动和环境支持。【研究】

**依从性。** 停药是复发最强的预测因素之一。很多人停药不是因为“不想好”，而是因为副作用难受、觉得好了、没人解释清楚、或者经济压力。这些都可以摊开来和医生谈。【指南】

**家庭情绪氛围。** 高情感表达（频繁批评、敌意、过度介入）与更高的复发率相关。这不是说家属“做错了”，而是提醒：少一点指责、多一点稳定的支持，是有意义的。【研究】

**病耻感。** 怕被贴标签而不敢就医、不敢复工、不敢社交，会通过“回避”这条路，慢慢把功能耗掉。病耻感是可以被讨论和处理的。

## 六、预后不是判决

“预后”在医学上是一个概率判断：在相似条件下，一群人里大概会有多少种走向。它不能告诉你某一个具体的人会怎样。

有几件事，是个人和家庭可以主动做的，也是这份资料库反复强调的：

- [ ] 尽早接受系统评估，别在“是不是中邪”“是不是青春期”上耗太久
- [ ] 把药吃对、吃够时间，副作用及时说，而不是自己减停
- [ ] 学会识别自己的复发早期信号，写下来，和家人共享
- [ ] 保持基本的生活结构：睡眠、吃饭、出门、有事做
- [ ] 处理物质使用问题，不把酒精和大麻当“自我治疗”
- [ ] 让家庭沟通从“管教”转向“合作”，减少高频批评
- [ ] 给自己设定小而具体的目标：先恢复作息，再谈复学复工
- [ ] 定期体检，关注体重、血糖、血脂、心电图

预后不是一个等着被宣布的结果，而是一条被很多小决定慢慢推着走的路。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现自杀念头、自伤行为或具体计划：不要独处，拨打 120 或去最近医院急诊，也可拨打 12356 心理援助热线。
> - 起病急、伴发热、意识模糊、抽搐：先按躯体急症处理，立即急诊。
> - 老年人首次出现幻觉、妄想，或记忆、定向力突然变差：尽快就诊，排除谵妄与神经系统疾病。
> - 孕产期症状加重或出现伤害自己或婴儿的念头：立即联系产科与精神科，必要时急诊。
> - 出现木僵、拒食、缄默、长时间不动：警惕紧张症，急诊精神科评估。
