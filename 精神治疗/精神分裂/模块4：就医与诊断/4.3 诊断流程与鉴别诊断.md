# 4.3 诊断流程与鉴别诊断

“医生凭什么说我是精神分裂症？”这个问题值得认真回答。精神分裂症没有一滴血能验出来，诊断靠的是一套结构化的推理：症状是什么、持续多久、功能掉了多少、有没有别的解释。这一页讲清诊断的四个支点、需要排除的常见情况，以及为什么第一次诊断有时会改。读完你能理解医生的思路，也能判断自己该追问什么。

## 一、诊断不是一次谈话就定

在门诊，医生做的第一件事往往不是“下诊断”，而是“收集证据”。同一种幻觉，可能来自精神分裂症，也可能来自双相障碍、严重抑郁、大麻、甲状腺功能亢进、脑炎或某些药物。这些情况的治疗完全不同，把可逆的原因漏掉，代价很大。

所以规范的流程通常是：详细病史、精神检查、必要的量表、化验和影像、初步诊断、随访修正。首诊给出的常常是“考虑某病”或“待观察”，这不是医生不负责，而是诊断本身需要时间。

## 二、诊断的四个支点

| 支点 | 具体要求（简化表述） | 医生怎么获取 |
|---|---|---|
| 症状 | 妄想、幻觉、思维紊乱、明显紊乱或紧张症行为、阴性症状中至少两项，且至少一项是妄想、幻觉或思维紊乱 | 精神检查、家属补充、量表 |
| 病程 | 症状持续一段时间；不同诊断体系要求不同，通常需要至少一个月的活跃期症状，并结合更长的总体病程 | 病史时间线、既往记录 |
| 功能损害 | 工作、学习、人际、自理能力明显下降 | 患者叙述、家属观察、功能量表 |
| 排除 | 不能用物质、药物、躯体疾病、心境障碍更好解释 | 化验、影像、既往史、随访 |

需要说明：国际上两套主要分类体系对“病程多久”“功能损害怎么算”的具体表述和阈值略有差异。ICD-11 通常要求活跃期症状至少一个月，DSM-5-TR 要求总病程至少六个月；两者都重视功能损害，但条款细节不完全相同。中国临床实践中两者都会参考，具体标准以医生使用的版本为准。【指南】

### 单一症状不足以诊断

“听到声音”本身不是精神分裂症。诊断看的是症状组合、持续时间、功能变化和排除结果。这也是为什么不能靠一篇科普或一份自评量表给自己下结论。

## 三、需要鉴别的几类情况

| 需要排除 | 常见线索 | 医生通常会怎么做 |
|---|---|---|
| 双相障碍伴精神病性症状 | 有过明显躁狂或轻躁狂：精力旺盛、话多、睡得少也不累、花钱大手大脚；症状呈发作性 | 追问既往发作史、家族史；抗抑郁药诱发躁狂要特别追问 |
| 抑郁障碍伴精神病性症状 | 严重抑郁在前或与妄想同时出现，妄想内容与抑郁主题一致（罪恶、贫穷、躯体腐烂） | 评估心境症状的时间关系、严重度 |
| 物质或药物所致 | 大麻、冰毒、致幻剂、酒精戒断；激素、某些感冒药、免疫抑制剂 | 尿毒物筛查、详细用药史、停药观察 |
| 器质性疾病 | 癫痫、脑肿瘤、卒中、甲状腺疾病、维生素 B12 缺乏、梅毒、HIV、自身免疫性脑炎 | 化验、脑影像、脑电图，必要时腰穿 |
| 分裂情感性障碍 | 心境发作与精神病性症状长期并存，且心境症状占病程的大部分 | 纵向梳理时间线，常需随访 |
| 妄想障碍 | 妄想突出但功能相对保留，幻觉不明显，行为不至于明显紊乱 | 评估妄想以外的症状 |
| 短暂精神病性障碍 | 起病急、持续时间短、常伴明显应激 | 随访观察是否缓解 |
| 孤独症谱系、强迫症、创伤后应激 | 社交沟通从小就有困难；有反复的强迫观念；有创伤史和闪回 | 发育史、创伤史、症状性质区分 |

### 关于自身免疫性脑炎

这一类需要单独提醒。抗 NMDAR 脑炎等自身免疫性脑炎可以以精神症状起病：年轻患者突然出现幻觉、易激惹、言语紊乱，随后出现癫痫、记忆下降、意识波动、口面部不自主运动、自主神经不稳。它容易被当成“首发精神分裂症”，但也有相当一部分患者最初确实只看精神科。【研究】【临床经验】

所以出现以下组合时，要尽快到急诊或神经科评估，而不是按普通精神科门诊慢慢调药：急性起病（几天到几周）、精神症状加癫痫、记忆明显下降、意识时清时浊、动作怪异、发热、通气不足。是否需要腰穿、查抗体，由神经科医生判断，不是所有首次发作都要做。

## 四、会做哪些检查

不是每个患者都要全套做，医生会按情况选：

- **化验**：血常规、肝肾功能、电解质、血糖、血脂、甲状腺功能、维生素 B12、感染筛查（如梅毒、HIV，按风险）。
- **尿毒物筛查**：怀疑物质使用时。
- **心电图**：用药前基线，尤其是有心脏病史或需要特定药物时。
- **脑影像**：首次发作、非典型表现、有神经系统体征、治疗反应差、老年首发的患者，更需要。
- **脑电图**：怀疑癫痫、意识波动时。
- **腰穿**：怀疑中枢神经系统感染或自身免疫性脑炎时，由专科医生决定。
- **量表**：PANSS、BPRS、PSP 等，用于评估严重度和追踪变化。

### 看诊前可以自己先核对

- [ ] 症状是什么时候开始的，最早出现的是哪一项。
- [ ] 有没有一段时间完全正常，最长多久。
- [ ] 有没有发热、头痛、抽搐、意识不清、走路不稳这些“不像精神科”的表现。
- [ ] 有没有饮酒、大麻、冰毒，或最近换过其他科的药。
- [ ] 家族里有没有人患精神病、住过院、自杀过。
- [ ] 有没有既往的出院小结，上面写的是什么诊断。
- [ ] 现在最想解决的一个问题是什么。

检查正常，并不能“证明”就是精神分裂症；检查异常，也不一定排除它。两者要合起来看。

## 五、诊断会变，随访比一次结论更重要

以下几种情况，诊断被修改是常见的：

- 随访中出现明确的躁狂发作，诊断可能改为双相障碍；
- 停药后症状持续多年不再出现，可能考虑其他诊断；
- 发现物质使用是主因；
- 查出躯体疾病；
- 儿童青少年期诊断本身就不稳定，需要反复评估。

诊断改变不代表之前“被骗了”，而是信息变多了。对患者来说，重要的是治疗有没有效、功能有没有恢复，而不是标签本身。复诊时可以主动问：“现在的诊断依据是什么？有没有需要重新评估的地方？”

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊或拨打 120：**
>
> - 首次出现精神病性症状，同时有发热、剧烈头痛、颈项僵硬、抽搐、意识时清时浊；
> - 精神症状加癫痫发作、记忆骤降、口面部不自主运动——警惕自身免疫性脑炎等器质性原因；
> - 自杀计划或自伤行为；
> - 命令性幻听并准备执行；
> - 木僵、缄默、拒食；高热加肌肉僵硬加意识改变。
>
> **尽快联系门诊：**
>
> - 诊断不明确，想请第二意见（带上全部资料，不要重新开始）；
> - 服药后出现新的神经系统症状；
> - 症状在几周内明显变化，或出现新的发作形式；
> - 对诊断有疑问，但不确定该问什么。

### 容易踩的坑

1. **把“检查都正常”当成“没病”。** 精神分裂症本来就没有特异性化验指标。
2. **把“一次诊断”当成终审判决。** 诊断会随随访修正。
3. **只做心理测评就下结论。** 量表是辅助，不是诊断。
4. **隐瞒物质使用。** 这会直接改变诊断方向。
5. **频繁换医院重复检查。** 资料不连贯，反而更难判断。
6. **拒绝随访。** 很多鉴别诊断只有在时间里才能看清。
