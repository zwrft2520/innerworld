# 4.2 初诊准备与病史采集

精神科门诊的时间常常只有十几分钟，说漏一句关键信息，可能就影响判断。这一页告诉你初诊该带什么、症状时间线怎么写、哪些内容必须如实说，以及家属补充信息的边界在哪里。适合第一次带家人就诊、或者自己要去看精神科但不知道从哪说起的人。读完你手上会有一张可以直接照着准备的清单。

## 一、带什么

把东西装进一个文件袋，出门前对着清单勾一遍：

- [ ] 身份证、医保卡／就诊卡。
- [ ] 既往病历、出院小结、门诊记录（尤其是精神科的）。
- [ ] 正在吃的所有药：药盒、药单或处方照片，包括中药、保健品、减肥药、避孕药。
- [ ] 最近的化验单、心电图、脑电图、影像报告。
- [ ] 过敏史清单（药名和反应）。
- [ ] 家族史信息：父母、兄弟姐妹、子女里有没有精神疾病、自杀、住院、长期服药的情况。
- [ ] 女性的月经史、末次月经、是否可能怀孕、是否在哺乳。
- [ ] 一页纸的症状时间线（下面有模板）。
- [ ] 想重点问医生的三个问题。

| 常被漏掉的东西 | 为什么重要 |
|---|---|
| 保健品和中药 | 可能影响肝肾功能、与精神科药物相互作用 |
| 减肥药、激素、感冒药 | 某些成分可能引起兴奋、失眠、幻觉 |
| 以前的出院小结 | 能看出既往用药反应、复发模式 |
| 饮酒和吸烟情况 | 影响药物代谢和剂量判断 |
| 睡眠和月经记录 | 常是复发和副作用的最早信号 |

## 二、写一条症状时间线

医生最想知道的是“变化的过程”，而不是“现在有多糟”。按时间顺序写，一条一行，不用修饰。

### 时间线模板

- 什么时候第一次觉得“不对劲”：
- 最早出现的三个变化（睡眠、情绪、说话、社交、成绩／工作）：
- 什么时候出现幻觉／妄想／行为异常：
- 中间有没有好转过，怎么好转的：
- 有没有诱因（熬夜、考试、失恋、失业、搬家、饮酒、使用大麻或冰毒、停药）：
- 用过哪些药，吃了多久，有没有效果，有没有副作用：
- 有没有住过院、有没有自伤自杀行为：
- 现在最影响生活的是什么：

### 一个写好的例子（示意，非真实个案）

> 去年九月开始睡不好，说班里有人针对他，不愿去上学。十一月起听到有人骂他，说是同学在楼道里装的喇叭。十二月开始不出门，一天只吃一顿。今年一月在门诊看过一次，开了药，吃了两周觉得“没事了”就停了。二月症状加重，说有人要杀他，晚上把门反锁，拿菜刀放在床边。没有饮酒，去年夏天和朋友抽过几次大麻。舅舅年轻时住过精神病院。

这样一段，医生能很快抓到：起病时间、症状演变、治疗史、停药、物质使用、家族史、当前风险。比“他最近很不正常，医生你看看”有用得多。

## 三、用药与物质使用要如实说

这不是“审问”，而是安全底线。

**要说清楚的：**

- 现在吃的每一种药，包括精神科药、降压药、降糖药、抗癫痫药、激素、中药、保健品。
- 吃了多久、有没有自己加过减过、有没有漏服。
- 吃了以后有没有效果，有没有手抖、坐不住、发胖、月经紊乱、溢乳、口干、便秘、心慌。
- 有没有对某种药过敏，出现过什么反应。
- 饮酒：多久一次、大概多少、最近有没有停酒。
- 吸烟：每天大概多少支。吸烟会影响部分药物的代谢，医生需要知道。
- 其他物质：大麻、冰毒、摇头丸、笑气、镇静催眠药，用过多长时间、最近一次是什么时候。

**为什么必须说：**

物质使用可以单独引起精神病性症状，也会加重病情、影响药效、增加复发和暴力风险。隐瞒会让医生把“物质所致”当成“精神分裂症”，或者反过来。医生关心的是怎么治，不是评判你。

如果实在不方便当面说，可以写在纸上递给医生，或者让家属单独说。

## 四、家族史、孕产史、发育史、躯体史

**家族史**：直系亲属里有没有精神分裂症、双相障碍、抑郁症、自杀、住院、长期服精神科药物。有也不代表一定会得，只是风险因素之一。

**孕产史**：对女性很重要。是否怀孕、是否计划怀孕、是否哺乳，直接关系到用药选择。不要因为怕医生“劝停药”就不说，医生需要在“停药复发”和“药物风险”之间做权衡，信息不全就没法权衡。

**发育史**（儿童青少年尤其重要）：什么时候会说话走路、学习成绩变化、有没有被霸凌、有没有长时间把自己关在房间里、有没有自伤。

**躯体史**：甲状腺疾病、癫痫、肝病、肾病、心脏病、糖尿病、高血压、头部外伤、感染（包括 HIV、梅毒）、自身免疫疾病。这些都可能是精神症状的原因，也会影响用药。

## 五、家属补充的边界

家属的信息非常关键，尤其是患者自己不觉得有问题的时候。但补充有边界，越界会让患者从此不再开口。

| 适合说 | 不适合说 |
|---|---|
| 具体的行为和原话：“他这周有三个晚上没睡，说门外有人” | 评价和标签：“他就是懒、就是装的” |
| 时间、频率、变化 | 翻旧账：“他从小就不听话” |
| 用药、饮酒、就医经过 | 替患者回答所有问题 |
| 安全相关信息：自杀念头、藏药、持刀 | 当着患者面讨论“要不要送走他” |
| 家庭实际困难：没人照看、经济压力 | 把家庭矛盾当病因控诉 |

几条实操建议：

- **先说事实，再说担心。** “我怕他晚上出事”比“你们得管管他”更容易被听进去。
- **当着患者的面说。** 除非涉及安全，尽量不搞“背后告状”。可以事先和患者对好：“哪些我可以讲？”
- **留出患者自己说的空间。** 医生问患者时，家属先别抢答，等患者说完再补充。
- **敏感内容写下来。** 自杀念头、藏药、被家暴、性行为，写在纸上比当面说更容易。
- **不隐瞒危险信息。** 这一点没有商量余地：隐瞒可能直接导致评估失误。

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊或拨打 120：**
>
> - 出现自杀计划、自伤行为，或已经吞药、割伤；
> - 命令性幻听，或已经按命令行动；
> - 明确伤人威胁，或家里已经发生冲突；
> - 木僵、缄默、拒食超过一两天；
> - 高热、肌肉僵硬、意识改变；
> - 首次出现精神症状伴发热、头痛、抽搐、意识波动。
>
> **就诊前需要先打电话确认的情况：**
>
> - 患者极度抗拒、有暴力风险——先联系医院急诊或社区精防，不要独自强行带人；
> - 正在发热或患急性躯体病——先看急诊或内科，精神科评估可以稍后；
> - 涉及未成年人、孕产妇——提前问清楚医院是否有相应门诊。

### 容易踩的坑

1. **替患者编病史。** 为了“让他住院”夸大，或为了“别留记录”缩小，都会误导治疗。
2. **只说最近一周。** 病程是诊断的核心，几个月甚至几年的变化都要提。
3. **隐瞒停药。** 医生会按“一直在吃药”来判断疗效，结论可能完全相反。
4. **把保健品当“不算药”。** 相互作用是真实存在的。
5. **家属全程代答。** 医生需要观察患者本人的语言和思维。
6. **不带药盒。** 说不清药名，等于让医生猜。
