# 4.4 共病筛查与躯体检查

精神分裂症很少“单独出现”。同一个人身上常有抑郁、焦虑、物质使用，也常有体重、血糖、血脂、甲状腺、牙齿的问题。这些共病不但影响生活质量，还直接影响用药安全。这一页讲该筛查什么、抗精神病药治疗前要做哪些基线检查、复查看什么。适合刚确诊、准备开始服药的人，也适合已经吃药多年却从没查过血脂血糖的人。

## 一、为什么共病要专门筛查

三个原因。

**第一，共病很常见，但常被主病掩盖。** 一个人话少、不动，可能是阴性症状，也可能是抑郁；心慌手抖，可能是焦虑，也可能是药物副作用或甲亢。不主动筛查，很容易一直归因于“病本身”。

**第二，共病影响预后。** 抑郁增加自杀风险，物质使用增加复发和暴力风险，睡眠呼吸暂停加重认知损害，代谢问题则慢慢侵蚀心血管健康。

**第三，共病影响用药安全。** 肝功能、肾功能、心电图、电解质，都会改变医生对药物的选择。抗精神病药本身也可能带来体重、血糖、血脂、催乳素和心脏传导方面的影响，所以基线数据非常关键——没有“用药前”的数字，就判断不了“用药后”的变化。

研究一致显示，精神分裂症患者的预期寿命比一般人群短，心血管疾病是主要原因之一，而这一部分恰恰是可以筛查、可以干预的。【指南】【研究】

## 二、精神科共病

| 共病 | 常见线索 | 处理方向 |
|---|---|---|
| 抑郁 | 持续低落、自责、无望、早醒、食欲下降、自杀观念 | 评估自杀风险；区分阴性症状与药物镇静；由医生调整方案 |
| 焦虑 | 持续紧张、心慌、出汗、回避、反复担心 | 排除甲亢、咖啡因、静坐不能；心理干预与药物由医生决定 |
| 创伤后应激 | 闪回、噩梦、回避、过度警觉、创伤史 | 建立安全感；创伤聚焦治疗需在稳定期进行 |
| 强迫症 | 反复出现闯入性的念头、反复检查或洗涤，自己知道不合理 | 与妄想区分：强迫观念通常被体验为“自己的、不对的” |
| 物质使用 | 大麻、冰毒、酒精、镇静药；戒断时加重症状 | 整合治疗；不指责；注意戒断风险 |
| 人格问题／孤独症谱系 | 长期的人际模式异常、从小社交沟通困难 | 需要发育史；影响治疗关系与沟通方式 |
| 睡眠障碍 | 入睡难、早醒、昼夜颠倒、打鼾憋气 | 睡眠卫生；筛查睡眠呼吸暂停；避免长期自行用安眠药 |

### 物质使用为什么必须单独问

大麻和兴奋剂可以诱发精神病性症状，也会加重原有病情、增加复发和冲动行为。反过来，很多患者用物质来缓解焦虑、失眠或药物副作用。这件事需要在不评判的气氛里问，问法可以是：“有没有用什么让自己好受一点？”

突然停酒或停镇静药可能出现戒断，严重时会抽搐、意识混乱，不能在家硬扛，需要医疗处理。

## 三、躯体共病

- **代谢**：体重、腰围、BMI、血糖、糖化血红蛋白、血脂、血压。抗精神病药相关的体重增加和代谢异常很常见。
- **心血管**：心电图（QT 间期）、心率、血压、有无晕厥史。
- **内分泌**：甲状腺功能、催乳素（月经紊乱、溢乳、性欲下降时可查）。
- **感染**：按风险筛查乙肝、丙肝、梅毒、HIV；是否加做结核筛查，由医生按用药和流行病学情况决定。
- **神经系统**：癫痫史、头部外伤、锥体外系反应的基线（手抖、僵硬、动作慢）。
- **口腔**：龋齿、牙周病、口干导致的龋齿风险；口腔问题会影响进食和自信。
- **眼科**：部分药物可能影响视力调节；青光眼患者用药需特别说明。
- **消化**：便秘很常见，严重时可致肠梗阻，需要主动报告。
- **睡眠**：打鼾、憋气、白天嗜睡，要筛查睡眠呼吸暂停。

## 四、开始抗精神病药前的基线检查

- [ ] 身高、体重、BMI、腰围。
- [ ] 血压、心率。
- [ ] 空腹血糖或糖化血红蛋白。
- [ ] 血脂四项。
- [ ] 肝功能、肾功能、电解质。
- [ ] 心电图（尤其有心脏病史、家族猝死史、正在用其他影响心电图的药）。
- [ ] 血常规（如计划使用氯氮平，这是必须项）。
- [ ] 催乳素（有月经紊乱、溢乳、性功能问题时）。
- [ ] 育龄女性的妊娠试验与避孕计划。
- [ ] 既往用药、过敏史、物质使用。
- [ ] 神经系统检查与锥体外系反应基线。
- [ ] 家族史：糖尿病、高血脂、心脏病、猝死。

**氯氮平要单独强调：** 血常规监测是处方的一部分，不是“额外要求”。用药前要查，之后按医生安排定期复查。出现发热、咽痛、口腔溃疡、乏力，要立即查血常规，不能等下次复诊。感觉“还好”不是跳过监测的理由。

## 五、治疗中复查什么

| 项目 | 为什么复查 | 大致节奏（以医生安排为准） |
|---|---|---|
| 体重、腰围、血压 | 早期变化最快，便于及时干预 | 用药初期较密，稳定后定期 |
| 血糖、血脂 | 代谢异常常无症状 | 用药后数月复查，之后定期 |
| 心电图 | QT 延长、心律失常风险 | 有心脏病史或联合用药时更需 |
| 催乳素 | 月经、性功能、骨密度 | 有症状时查，不必人人常规 |
| 肝肾功能 | 药物代谢、合并用药 | 按药物和躯体情况 |
| 锥体外系反应 | 手抖、僵硬、坐不住、迟发性运动障碍 | 每次复诊都看 |
| 血常规（氯氮平） | 粒细胞缺乏可致命 | 严格按处方要求，不能自行拉长 |
| 口腔与便秘 | 影响进食与安全 | 每次复诊问一句 |

具体频率由医生根据药物、年龄、体重变化、合并疾病和当地随访安排决定，不要拿别人的复查节奏套自己。

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊或拨打 120：**
>
> - 服用氯氮平后出现发热、咽痛、口腔溃疡、极度乏力（可能粒细胞缺乏）；
> - 高热、肌肉僵硬、意识改变、大汗、心跳很快（可能恶性综合征）；
> - 剧烈腹痛、腹胀、停止排便排气（可能肠梗阻）；
> - 胸痛、心悸伴晕厥、呼吸困难；
> - 抽搐、意识不清；
> - 吞咽困难、进食呛咳。
>
> **尽快联系门诊：**
>
> - 体重在短期内明显增加，或腰围变大；
> - 月经紊乱、溢乳、性功能下降；
> - 手抖、走路变慢、坐立不安、舌头或嘴唇不自主动作；
> - 便秘超过三天、口干严重；
> - 打鼾伴白天嗜睡。

### 容易踩的坑

1. **只查精神科，不查身体。** 代谢和心血管问题往往没有感觉。
2. **觉得“查过就一劳永逸”。** 体重和血糖会变，复查才有意义。
3. **因为怕加药而隐瞒副作用。** 副作用是调整方案的依据，不是“不听话”的证据。
4. **用保健品代替复查。** 没有任何保健品能替代血糖血脂和血常规。
5. **氯氮平“感觉好”就跳过血常规。** 粒细胞缺乏早期可以毫无症状。
6. **便秘硬扛。** 抗精神病药相关的便秘可以很严重。
