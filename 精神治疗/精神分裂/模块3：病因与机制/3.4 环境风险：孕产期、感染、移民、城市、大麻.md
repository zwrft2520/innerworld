# 3.4 环境风险：孕产期、感染、移民、城市、大麻

读到“环境风险”这四个字，很多家属会紧张：是不是我怀孕时感冒了？是不是我们搬到大城市？是不是他大学时抽过几次大麻？这一页把常见环境风险一个个拆开讲：哪些有证据、证据有多硬、哪些是可以改变的，以及为什么“有风险因素”不等于“找到病因”。读完希望你能明白一件事：风险因素是概率的推手，不是某个人、某件事的罪证。

## 一、先弄清“风险因素”是什么意思

流行病学里的“风险因素”，指的是**与发病概率升高相关**的因素，它不承诺因果，也不指向某一个具体的人。吸烟与肺癌的关系已经算很硬了，但仍有长期吸烟者不得肺癌，也有从不吸烟的人得肺癌。精神分裂症的环境风险更是如此，每个因素的效应都不大。

这里有两个容易混淆的概念。**相对风险**是“暴露组比未暴露组高多少”；**绝对风险**是“一个人一生中实际发生的可能性”。一个因素可以把相对风险提高不少，但如果基线风险本来就不高，绝对风险的增加可能很小。媒体常报道“某某因素让风险翻倍”，读者容易听成“我有一半概率会得”，这是两回事。

目前比较被接受的整体图景是“多重打击”：遗传易感性打底，加上孕期、围产期、童年、青春期的一连串风险，累积到某个阈值才发病。没有任何单一因素能解释大多数病例。也正因如此，**无法通过回溯找到“你的病因”**——医生能做的是评估整体风险，而不是给每个患者开一张归因清单。

## 二、产前与围产期：证据较多，但效应温和

这是环境风险里研究最扎实的一块。比较一致的方向包括：母体在孕期感染（尤其是流感类呼吸道感染）、孕期营养不良、妊娠高血压与妊娠糖尿病、早产与低出生体重、分娩时缺氧、产伤等，与子代后来患精神分裂症的风险升高相关。【研究】

其中“营养不良”的证据来自历史事件的自然实验：战时饥荒期间受孕或孕早期经历严重饥饿的人群，子代患病率有所升高。这类研究设计巧妙，但也受限于当时的诊断标准和记录质量。

父亲生育年龄偏高也与风险升高相关，机制可能涉及新生突触突变累积，目前仍属【待验证】。

需要非常小心的一件事：这些发现**不是用来指责母亲的**。“孕期感冒”是极常见的事，绝大多数孕期感染并不会导致孩子患病；把病因归到某一次感冒、某一次没休息好，既不符合证据，也会给家庭增加不必要的内疚。

## 三、感染与免疫：有关联，但还不能当因果

除了孕期感染，早年中枢神经系统感染（如脑炎、脑膜炎）与后来的精神病性障碍相关；部分自身免疫病（如狼疮、自身免疫性甲状腺病）患者的精神病性症状发生率较高；弓形虫感染也被反复讨论，但结果不一致，且很难排除社会经济状况、宠物接触、饮食习惯等混杂因素。【待验证】

这类研究的价值在于提示“免疫系统可能参与”，但它离“感染导致精神分裂症”还很远。绝大多数感染过的人不会患病，绝大多数患者也没有明确的感染史。具体到免疫机制与抗炎治疗的可能性，详见 [3.3 脑结构、神经发育与炎症](<3.3 脑结构、神经发育与炎症.md>)。

## 四、移民与城市生活：更像是社会处境的问题

移民与少数族裔群体中，精神分裂症的发病率在多项研究中高于当地多数族群。这个发现一度被误读为“某些种族的基因问题”，但后续研究并不支持这种解释：风险升高在不同原籍国、不同族群的移民中都出现，而且与移民第二代、社会歧视体验、失业、住房不稳定、社会支持缺乏关系更密切。【研究】

目前比较主流的解释是“社会挫败”与长期压力：持续的歧视、边缘化、身份被否定，会改变人的应激反应、睡眠和社会连接，进而影响易感个体的发病风险。这也解释了为什么“移民比例高的社区里，少数族群占比越低，风险越高”这类看似奇怪的现象会出现。

城市生活与发病风险之间也有统计关联，且呈现“城市化程度越高、风险略高”的趋势，但效应很小，远不足以解释城市里大多数人的健康状况。城市里同时聚集了更多的人口流动、社会孤立、物质使用和压力事件，这些才是更值得关注的中介因素。

与此相关的一个经典争论是“社会因果”与“社会漂移”：是贫困与压力导致发病，还是发病导致人往下流动、失去工作与住所？两种过程很可能同时存在。对家庭来说，这个争论的实际含义是：**不要把患者的社会处境当成他“不努力”的证据**。

## 五、大麻与兴奋剂：目前最值得重视的可改变因素

在所有环境因素里，物质使用是少数“证据较硬、又确实可以改变”的一项。

关于大麻，比较一致的发现是：使用越早、频率越高、THC（大麻中主要的精神活性成分）浓度越高，精神病性症状与精神分裂症的风险越高；在遗传易感人群中，这种关联更强。【研究】合成大麻素（俗称“香料”“K2”等）风险更高，因为它们对受体的作用强度远超天然大麻。

但因果推断并不轻松。使用大麻的人可能同时吸烟、饮酒、睡眠紊乱、社会压力更大，这些都可能是混杂因素；也可能存在“反向因果”——已经出现早期症状的人更倾向于用大麻缓解不适。即便如此，考虑到大麻使用的普遍性和可改变性，“减少或停止使用”仍是目前最值得做的事之一。【指南】

兴奋剂类物质（苯丙胺、甲基苯丙胺、可卡因等）能直接诱发类似精神分裂症的精神病性状态，常被称为“苯丙胺精神病”，表现为被害妄想、听幻觉、激越。多数人在停用后数天到数周内缓解，但有一部分人会持续更久，甚至发展为独立于物质使用的病程。判断“这是物质所致还是精神分裂症”，需要医生结合使用史、停药后的病程和随访来判断，不能自己下结论。

这里要避免一种污名化：使用物质的人不是“自甘堕落”，物质使用障碍本身是需要治疗的健康问题。把“他抽大麻所以活该”挂在嘴边，只会让人隐瞒使用情况，耽误评估。

## 六、把这些风险放在一起看

| 风险因素 | 证据强度 | 能否改变 |
|---|---|---|
| 孕期感染、营养不良、产科并发症 | 中等，方向一致 | 部分可改变（产检、营养、戒烟酒） |
| 童年期中枢感染、自身免疫病 | 较弱，结果不一致 | 部分可治疗 |
| 移民、少数族群处境、歧视 | 中等，机制偏向社会因素 | 社会层面可改善，个人层面有限 |
| 城市生活 | 弱，效应小 | 有限 |
| 大麻（尤其高效力、早期、频繁） | 中等偏强 | **可以改变** |
| 兴奋剂类物质 | 较强（急性精神病性症状） | **可以改变** |

这张表最实用的读法是看最后一列。遗传、孕期、童年经历都已经过去，无法重来；而物质使用、睡眠、社会支持、是否及时就医，是现在还能动的部分。把注意力放在这里，比反复追问“到底是哪件事造成的”更有帮助。

### 家属可以做的事

- 不翻旧账式追问“是不是我怀孕时……”，这类自责对治疗没有帮助；
- 了解家族里是否有精神疾病、住院、自杀的情况，就诊时主动告诉医生；
- 青少年期避免大麻和其他成瘾物质，家里不存放、不默许；
- 出现持续猜疑、听见声音、成绩骤降、社交退缩，尽早就诊，不要等“确诊了再说”；
- 如果家人已经在使用大麻，先谈“减少伤害”（不空腹、不独自、不用合成大麻素、不驾车），再谈戒断，必要时找成瘾专科；
- 关注睡眠：长期昼夜颠倒、通宵打游戏往往是复发的前奏，而不只是“生活习惯问题”；
- 保持社会连接：一份工作、一个固定活动、几个能说话的人，都是实打实的保护因素；
- 不把“环境风险”当成指责患者的理由，风险因素不等于个人选择。

### 常见问题

**“孕期感冒过一次，是不是我害了孩子？”** 不是。孕期感染很常见，绝大多数并不会导致子代患病。把病因锁定在某一次感冒上，既没有证据支持，也会让家庭背上不该背的负担。

**“搬到大城市生活，是不是风险很高？”** 城市生活与发病的统计关联很弱，远不足以成为搬不搬家的决策依据。相比之下，睡眠、物质使用、社会支持这些具体因素更值得关注。

**“偶尔抽一次大麻，会不会就得病？”** 单次使用导致精神分裂症的可能性很低，但风险随频率、效力、开始年龄上升，在易感人群中更明显。对已经有精神病性体验或家族史的人，最稳妥的选择是不用。

**“疫苗会不会导致精神分裂症？”** 目前没有可靠证据支持这种说法。相反，孕期严重的感染性疾病本身才是需要防范的风险，按医嘱接种推荐的疫苗属于常规产检的一部分。

> **出现以下情况，请当天联系医生或尽快复诊：**
>
> - 孕期或备孕期间正在服抗精神病药，想讨论用药调整——挂精神科与产科联合门诊，不要自行停药
> - 使用大麻或兴奋剂后出现幻觉、被害感、激越、行为失控——立即停止使用并尽快就医
>
> **出现以下情况，立即去急诊或拨打 120：**
>
> - 出现自杀念头、自伤行为，或命令性幻听让自己做危险的事——不要独处，必要时拨打 110
> - 出现高热、肌肉僵硬、意识改变、大汗、心跳很快（警惕恶性综合征或物质中毒）
> - 出现抽搐、意识丧失、剧烈头痛、胸痛、呼吸困难
> - 出现木僵、缄默、拒食、保持固定姿势不动（警惕紧张症）
