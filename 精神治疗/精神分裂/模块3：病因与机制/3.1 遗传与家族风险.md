# 3.1 遗传与家族风险

很多人第一次听到“精神分裂症有遗传倾向”，心里会立刻冒出两个问题：是不是我传给了孩子？我家里明明没有病人，为什么偏偏是我？这一页想把这两团乱麻理清楚：家族聚集到底说明了什么，遗传度这个常被引用的数字被误读成了什么，以及“有遗传风险”为什么不等于“一定会发病”。读完希望你能带走三句话——遗传是重要的风险因素，但不是命运；不存在一个叫“精神分裂症基因”的东西；有家族史的人真正能做的，是减少其他风险、早点识别、早点求助。

## 一、家族聚集：一个被观察了很久的事实

精神分裂症在家族中有聚集现象，这是精神医学里最早被确认的线索之一。早在上世纪初，医生就注意到：一个家庭里出现一位患者后，其亲属患病的可能性比一般人群高。此后一百年里，家系调查、双生子研究、寄养子研究反复验证了这一点，方向相当一致。【研究】

但“聚集”这个词需要拆开看。家族成员之间共享的不只是基因，还有居住环境、经济状况、饮食习惯、教养方式、甚至同一场灾难或同一种歧视经历。家族聚集只能说明“这个家庭里出现精神分裂症的概率高于平均水平”，不能直接说明“原因是基因”。

下表把常见亲属关系的风险相对水平排了一下。这里刻意不写具体百分比，因为不同研究给出的数字差别不小，而且任何数字放到某一个具体的人身上，都会失真。

| 亲属关系 | 风险相对水平 | 可以怎么理解 |
|---|---|---|
| 一般人群（无近亲患病） | 基线 | 绝大多数人一生不会发病 |
| 父母一方患病 | 高于基线 | 风险升高，但多数子女并不发病 |
| 父母双方均患病 | 进一步升高 | 仍然不是“必然发病” |
| 兄弟姐妹患病 | 高于基线 | 共享基因，也共享家庭环境 |
| 同卵双生子一方患病 | 各类亲属中最高 | 共享全部基因，仍有相当一部分同卵双生子不发病 |
| 二级亲属（祖父母、叔伯姑舅、侄甥） | 轻度升高 | 血缘越远，风险越接近基线 |
| 三级亲属（表亲等） | 接近基线 | 在个体层面几乎无法据此判断什么 |

这张表最容易被读错的地方，是把“相对水平”读成“命中率”。同卵双生子共享全部基因，同病率在各类亲属中最高，但仍有相当一部分同卵双生子并不发病——这一件事本身就说明，基因不是全部。反过来说，绝大多数精神分裂症患者并没有一位患精神分裂症的直系亲属。家族史阴性，一点也不奇怪。【研究】

## 二、遗传度：最容易被误读的一个词

“遗传度”是行为遗传学里的一个统计量，描述的是：在某个特定人群中，人与人之间的差异有多大比例可以归因于基因差异。它回答的是群体问题，不是个人问题。

这个区别听起来学究气，实际影响很大。假设某地成年人的身高差异大部分可以归因于遗传，这不意味着你的身高也大部分“由基因决定”、剩下一小部分“靠后天努力”。它只意味着：在那个群体里，人与人身高不同的原因，大部分与基因差异有关。营养、疾病、睡眠同样影响身高，只是在这个群体里它们造成的差异相对小一些。精神分裂症的遗传度也是同样的逻辑。它是一个群体指标，不能拆开来分配给某一个人。【研究】

遗传度高，也不等于“环境不重要”。遗传度是在特定环境范围内估算的，环境一旦大幅改变，遗传度的估计也会变。更重要的是，遗传度高不等于“不可改变”。遗传度高的疾病里，照样有大量可以通过环境干预降低风险的部分——这一点在后面几节会展开。

还有一层常被忽略：遗传度不是“某个基因的作用大小”。精神分裂症不是单基因病，不存在“携带就发病、不携带就安全”的位点。

## 三、多基因风险：没有“精神分裂症基因”

过去十几年，全基因组关联研究（把成千上万人的基因位点与疾病做统计比对）带来的核心结论是：精神分裂症与很多很多个常见基因变异有关，每一个的作用都很小。把它们的作用加总起来，形成一个“多基因风险评分”，在群体层面能区分出风险高低。【研究】

但多基因风险评分目前仍是研究工具，不是临床检查。它不能告诉你“你一定会得”，也不能告诉你“你一定不会得”。原因很直接：这些变异单个效应太微弱，评分只在人群统计上有意义，落到个人身上预测力很有限。目前没有任何一家正规医疗机构会用基因检测来诊断或预测精神分裂症。

另一类变异效应较大，比如 22q11.2 缺失综合征（一小段染色体缺失），携带者患精神病性障碍的风险明显升高。但这类拷贝数变异只解释极少数病例，而且大多在儿童期就因其他躯体问题被识别。它重要，但它不是精神分裂症的主要解释。【研究】

所以更准确的说法是：精神分裂症是“多基因易感性 + 环境风险 + 发育过程”共同作用的结果，而不是某个基因打开了一个开关。

## 四、遗传不是命运：同卵双生子为什么不一起发病

如果基因决定一切，同卵双生子应该总是一起发病。事实不是这样。这是理解“遗传不是命运”最直观的入口。

差异来自哪里？目前能想到的至少有四类。第一，基因表达会被环境调控，同样一套基因在不同经历下“打开”的程度不同，这类机制常被归到表观遗传，具体到精神分裂症仍属【待验证】。第二，双生子在子宫里的位置、胎盘供血、出生体重可能不同，早年的营养与缺氧暴露也不同。第三，成长过程中的感染、压力、物质使用、社会处境各自不同。第四，随机性——大脑发育本身带有随机成分，不是一段写死的程序。【待验证】

还有“基因与环境的互动”。同样携带较高易感性的人，在一个支持充足、没有大麻、睡眠规律、压力可控的环境里，可能一辈子不发病；换一个环境，可能就被推过阈值。这就是为什么预防工作有意义：你改不了基因，但能改其中一部分环境侧的风险。

对家族史阳性的人来说，可行的做法不是“定期筛查基因”，而是照着下面这份清单做：

- 了解并记录家族中精神疾病、住院、自杀的情况，就诊时主动告诉医生；
- 避免大麻等物质，尤其是青少年期和成年早期；
- 保持规律睡眠，减少长期昼夜颠倒；
- 学会识别早期信号：持续猜疑、听见别人听不到的声音、成绩或工作能力明显下滑、社交退缩、情绪变得平淡；
- 出现上述信号时尽早看精神科，而不是等“严重了再说”；
- 不因为“家里有这个病”就放弃学业、工作或生育计划。

## 五、生育、家族史与家属的自责

“我是患者，能不能要孩子？”这是门诊里最常见、也最难用一句话回答的问题。可以谈，而且应该谈，但它不是一道“能或不能”的判断题。合适的做法是找精神科医生做一次孕前咨询，把几件事摆到桌面上：目前病情稳定多久、正在用什么药、停药或换药的风险、孕期随访条件、家庭支持情况。遗传风险是其中一项，不是全部。【指南】

需要说清楚的是：目前没有任何产前检查能预测一个孩子将来会不会得精神分裂症。它不是唐氏综合征那样的染色体问题，无法通过羊水穿刺或基因芯片给出“是或否”。任何声称能“孕前基因筛查精神分裂症”的商业服务，都应该高度警惕。

另一半常被忽略的是家属的自责。有些父母在得知诊断后反复回想：是不是我当年太严厉？是不是我孕期感冒了？是不是我遗传给了他？关于“父母造成精神分裂症”的旧观点，资料库在 [3.5 心理社会因素、研究局限与“致病家庭”误区](<3.5 心理社会因素、研究局限与“致病家庭”误区.md>) 里有专门澄清。这里只说一句：把病因归到父母的人格或教养上，既不符合现在的证据，也帮不到任何人。遗传风险是概率，不是某个人的过错。

## 六、常见问题与容易踩的坑

**“家里没人得过，我是不是特别倒霉？”** 不是倒霉，也不罕见。大多数患者没有患精神分裂症的直系亲属，这符合疾病本身的分布规律。

**“亲属患病，我要不要提前吃点药预防？”** 不需要。目前没有用于“预防精神分裂症”的药物，健康人服用抗精神病药反而要承担副作用风险。真正有效的预防是识别高危状态、处理共病、减少物质使用，并在症状出现时尽早治疗。【指南】

**“基因检测能不能告诉我孩子会不会得？”** 不能。多基因风险评分目前只在研究中使用，个体预测力有限；宣传“一测就知道”的机构不可信。

**“遗传度高，是不是说明治疗没用？”** 不是。遗传度描述的是群体差异的来源，不描述治疗反应。抗精神病药、心理社会干预、家庭支持的作用与遗传度是两回事。

> **出现以下情况，请当天联系医生或尽快复诊：**
>
> - 想做孕前咨询、遗传咨询，或对家族史有疑问——挂精神科或遗传咨询门诊，不要靠网络自测下结论
> - 服用抗精神病药后自行停药，出现失眠、激越、幻觉加重——尽快联系医生，不要自行加回原量或硬扛
>
> **出现以下情况，立即去急诊或拨打 120：**
>
> - 坚信被监视、被针对，听见别人听不到的声音，说话变得跳跃难懂，且持续两周以上
> - 出现自杀念头、自伤行为，或已经写好了计划——不要独处，立即联系信任的人陪同，必要时拨打 110
> - 出现木僵、缄默、拒食、保持一个姿势不动（警惕紧张症）
> - 出现高热、肌肉僵硬、意识改变、大汗、心跳很快（警惕恶性综合征）
