# 3.5 心理社会因素、研究局限与“致病家庭”误区

几乎每一位家属都在某个深夜想过同一个问题：是不是我们哪里做错了？是不是我太严厉、太冷漠、太忙，才让他变成这样？这个念头不是凭空来的——上世纪中叶，精神医学界真的流行过“父母造成精神分裂症”的说法，它影响了几代人。这一页做三件事：讲清楚心理社会因素在精神分裂症里到底扮演什么角色；把“致病家庭”这段历史错误摊开说明；以及教你怎样判断一条“新研究说”的结论值不值得信。

## 一、应激—易感模型：压力常常是扳机，不是子弹

目前最被广泛接受的框架叫“应激—易感模型”。它说的是：一个人先有生物学上的易感性（遗传、神经发育），在遇到足够强的应激时，才可能跨过发病的阈值。易感性像火药，应激像火星；没有火药，火星点不着；没有火星，火药也可能一直不响。

这个模型能解释几个临床现象。第一，同样的压力事件，有人发病，有人没事。第二，很多患者在发病前确实经历了明显的生活事件：高考失利、失恋、被辞退、亲人去世、搬迁、长期失眠。第三，发病之后，压力仍然会影响复发——这也是为什么家庭沟通、工作节奏、睡眠管理在康复期那么重要。

但要小心因果方向。生活事件与发病在时间上接近，不等于事件导致了疾病。有时候是疾病的前驱期已经开始，人的状态在变化，才导致了失恋、失业、冲突——也就是说，**症状可能是“原因”而不是“结果”**。这类“反向因果”在横断面研究里几乎无法排除。

## 二、哪些心理社会因素有证据

心理社会因素对精神分裂症的作用，可以粗略分成两类：对“起病”的作用，和对“复发与结局”的作用。后者的证据通常更硬。

| 因素 | 证据强度 | 主要作用在哪个环节 |
|---|---|---|
| 童年期虐待、忽视、霸凌 | 中等，与精神病性体验相关 | 起病风险与症状严重度 |
| 社会孤立、缺乏支持 | 中等 | 起病风险、复发、结局 |
| 重大生活事件、长期压力 | 中等（复发证据更硬） | 复发 |
| 移民、歧视、少数族群压力 | 中等 | 起病风险 |
| 家庭高情感表达 | 较强（复发） | 复发 |
| 就业、稳定住所、社会资本 | 中等 | 结局与功能 |

关于童年创伤，需要说清楚：它与精神病性体验的关联在多项研究中重复出现，但“关联”不等于“必然”。大多数经历过创伤的人并不会得精神分裂症；而且创伤的影响往往是跨诊断的，与抑郁、焦虑、人格问题都相关。【研究】

关于社会孤立，因果方向同样纠缠：是社会孤立导致发病，还是发病导致社会孤立？很可能两者互为因果，形成越孤立越难走出、越难走出越孤立的循环。这也意味着干预可以从任何一端切入——恢复一点点社会连接，就可能打断循环。

## 三、高情感表达：一个有用的临床概念，不是给家属定罪

“高情感表达”（英文缩写 EE）是研究复发时常用的一个概念，指的是家属在言语和态度中表现出的三类特征：**批评**（频繁指出对方的错）、**敌意**（带有攻击性、否定对方人格）、**情感过度卷入**（过度介入、替对方做所有决定、把自己的情绪完全绑在对方身上）。

研究反复发现：高情感表达的家庭环境与更高的复发率相关；而结构化的家庭干预（心理教育、沟通训练、问题解决训练）能降低复发风险。这一点写进了多部指南。【指南】

但这里有几个必须同时讲的限定。

第一，情感表达是**互动模式**，不是家属的人格缺陷。一个人长期照顾患病的亲人、睡眠不足、经济压力大、被邻居指指点点，说话变得急躁、批评变多，是完全可以理解的反应。把它当成“你有问题”，既不准确也不公平。

第二，情感表达有**文化差异**。在一些文化里，家人高度参与、表达强烈，是关心的常态；研究工具原本是在西方家庭里发展出来的，直接套用可能失真。

第三，**降低情感表达不等于冷漠疏远**。有些家属听到这个概念后，变得不敢说话、不敢关心，这其实是误解。目标不是“少爱一点”，而是“换一种方式”。

| 容易变成高情感表达的说法 | 可以替换的说法 |
|---|---|
| “你又胡思乱想了，跟你说多少遍是假的！” | “我知道你听到的声音对你来说很真实，我们一起看看怎么应对。” |
| “你要是不吃药，我就当没你这个儿子。” | “不吃药会让我们都很担心，能不能一起跟医生谈谈你的顾虑？” |
| “我这辈子都被你毁了。” | “我最近很累，需要找人搭把手，我们看看社区有没有支持。” |
| 替他决定所有事，不允许他自己出门 | 一起制定一个双方都能接受的安全计划，逐步放回自主权 |

## 四、“致病家庭”：一段必须澄清的历史错误

上世纪四十到五十年代，精神分析在精神医学里占主导，一种说法流行起来：精神分裂症是早年母婴关系出了问题造成的。代表人物提出了“精神分裂症源性母亲”这个概念，媒体把它简化成“冰箱母亲”——母亲冷漠、控制、缺乏温情，孩子因此发病。

另一个相关的理论叫“双重束缚”：父母同时发出互相矛盾的指令，孩子无论怎么做都错，长期下来就“疯”了。

这些说法为什么当时能流行？因为那时没有脑影像、没有遗传学、没有可靠的药物，理论只能从访谈和临床印象里生长；而照护者主要是母亲，观察者看到的“母子互动问题”，自然被归因到母亲身上。这里面还夹着明显的性别偏见。

它们为什么是错的？主要有四点。第一，研究方法是回顾性的：先知道谁患病，再回头审视他的家庭，很容易把疾病造成的结果当成原因。第二，没有对照：没有人去比较“健康孩子的母亲”是不是也有同样的行为。第三，无法解释为什么同一家庭里有的孩子发病、有的不发病，也无法解释为什么不同文化、不同家庭结构下都有精神分裂症。第四，后来的双生子、寄养子、遗传与神经发育研究，都把解释重心移到了生物学与发育过程上。

这段历史造成的伤害是真实的。几代母亲在毫无根据的指责中生活，很多家庭因此隐瞒病情、拒绝就医、彼此怨恨。今天必须说清楚：**家庭不是精神分裂症的病因。** 家庭可以是压力源，也可以是保护因素，但它不在病因的位置上。

## 五、研究局限：为什么“新研究说”要打折听

理解研究怎么做，能帮你少被标题党带走。心理社会研究尤其容易出问题，常见的有以下几类。

**横断面研究**：只在一个时间点测量，无法判断先后。看到“孤独的人更容易得精神病”，你不知道是孤独导致发病，还是发病导致孤独。

**样本小**：几十人的研究很容易出现偶然结果。样本越小，结论越不稳定。

**效应量小**：统计上“显著”不等于“重要”。当效应量很小时，一点点混杂因素就能把结果推翻。

**混杂与反向因果**：贫困、歧视、物质使用、睡眠紊乱常常同时出现，很难拆开谁的作用更大。

**回忆偏倚**：让患者回忆童年，记忆本身会被当前的情绪和疾病状态影响。

**发表偏倚与可重复性**：阳性结果更容易被发表，阴性结果常被搁置。心理学与精神病学近年来经历了“可重复性危机”，一些曾被广泛引用的效应在更大样本中消失了。

**样本文化偏差**：大量研究来自欧美样本，结论能否套用到中国家庭，需要谨慎。

所以，看到一条研究结论时，可以先问四个问题：样本多大？有没有对照组？是相关还是因果？有没有被独立重复？如果四个问题都答不上来，就先别拿它指导自己的治疗。

## 六、风险因素不等于责任

这是这一页最想说的一句话。

**风险因素**是统计学上的概率推手，它不指向某个人的过错。一个人有童年创伤，不代表他“注定”发病；一位母亲脾气急，不代表她“造成”了孩子的病；一个家庭经济困难，也不代表他们“没做好”。

把这三件事分开看，会轻松很多：**因果**（是什么导致了疾病）、**责任**（谁该为疾病负责）、**可控性**（现在还能做什么）。科学能回答一部分因果，但几乎回答不了责任；而可控性，是每天都能动的。

家属可以做的，往往很具体：

- 学习疾病知识，知道哪些是症状、哪些是药物副作用；
- 保持规律的探视、陪伴与服药提醒，但不代替他做所有决定；
- 用“我担心……”代替“你又……”；
- 减少当面的指责与争吵，有分歧留到情绪平稳时再谈；
- 给照护者自己找支持：家属团体、心理咨询、亲友轮班；
- 与医生保持联系，复发早期就调整，而不是等到住院；
- 不隐瞒病情，也不把病情当成家庭的羞耻。

### 常见问题

**“我脾气急，是不是我把孩子逼病的？”** 不是。家庭氛围会影响复发与康复，但不在病因的位置上。脾气、沟通方式是可以调整的，调整的目的是让康复更顺，而不是赎罪。

**“那家庭因素到底还要不要管？”** 要管，但管的是“现在”。减少争吵、稳定作息、及早就医、家属自己寻求支持，这些都会影响复发风险和结局。

**“我看了一篇说‘童年创伤导致精神分裂症’的文章，可信吗？”** 童年创伤与精神病性体验有关联，但关联不是宿命，也不是单一病因。判断这类文章，先看样本量、有无对照、是相关还是因果、有没有被重复。

**“家属是不是应该少见面、少说话，免得‘情感表达’太高？”** 不是。目标是减少批评、敌意和过度控制，不是减少关心。稳定的陪伴本身就是保护因素。

> **出现以下情况，请当天联系医生或尽快复诊：**
>
> - 照护者自己出现持续失眠、情绪崩溃、无力照顾的感觉——去精神科或心理门诊求助
> - 家庭冲突反复升级、沟通完全无法进行——联系医生讨论家庭干预
>
> **出现以下情况，立即去急诊或拨打 120：**
>
> - 出现自杀念头、自伤行为，或已经做出计划——不要独处，联系信任的人陪同，必要时拨打 110
> - 出现命令性幻听让自己做危险的事、坚信被追杀而准备“自卫”——避免争辩与围堵，必要时报警
> - 家庭冲突升级到肢体冲突、打砸、威胁——先离开现场，保证人身安全，不要试图单独制服
> - 出现木僵、缄默、拒食、保持固定姿势不动（警惕紧张症）
> - 出现高热、肌肉僵硬、意识改变、大汗（警惕恶性综合征）
