# 3.3 脑结构、神经发育与炎症

做过核磁的患者常拿着报告问：上面写着“脑室略大”“皮层萎缩”，是不是脑子坏掉了？也有人反过来问：既然说是脑子的病，为什么医生不给我做一个脑扫描确诊？这一页讲三件事：影像研究在群体层面发现了什么，神经发育与免疫炎症这两条解释线走到哪一步，以及为什么这些发现不能拿来给任何一个人下诊断。读完之后，希望你对“脑影像异常”这件事少一点恐慌，也少一点不切实际的期待。

## 一、脑影像看到了什么：差异是真的，但只在群体里

过去几十年，结构核磁研究反复报告了一些平均差异：与健康对照相比，精神分裂症患者组的侧脑室平均更大，颞上回、海马、前额叶等区域的灰质体积平均更小，白质纤维束的完整性指标平均更低。【研究】

这些发现是真实的统计差异，不是编出来的。但它们有几个必须同时说清的性质。

第一，差异是“组的平均”。把两组人的数值画成两条分布曲线，中间大部分是重叠的。很多患者在这些指标上完全落在健康人范围内，也有很多健康人的数值落在患者那一侧。用一个人的扫描结果去判断他有没有精神分裂症，准确率并不比抛硬币好多少。

第二，效应量只能算中等。所谓效应量，可以理解为“两组差距相对于人群自然波动的幅度”。中等效应意味着差异看得见，但远不足以作为个体层面的标签。

第三，混杂因素很多。病程长短、是否用药、用药种类与年限、吸烟、体重、饮酒、社会处境，都会影响脑结构。有些研究提示抗精神病药可能影响灰质体积变化，这类问题在伦理上很难做严格的对照试验，所以因果方向至今没有定论。【待验证】

| 常见发现 | 主要研究方法 | 群体层面的含义 |
|---|---|---|
| 侧脑室平均扩大 | 结构核磁 | 提示部分患者存在脑脊液腔隙增大，机制不明 |
| 颞上回、海马、前额叶灰质体积平均减少 | 结构核磁、纵向随访 | 可能与症状严重度、认知表现相关，个体差异大 |
| 白质完整性指标下降 | 弥散张量成像 | 提示部分纤维束连接受影响，解释力有限 |
| 皮层厚度或表面积差异 | 结构核磁 | 结果不一致，受年龄、用药、扫描参数影响 |

## 二、神经发育假说：一条从孕期就开始的线

为什么一个十八九岁的人会突然发病，而大脑的“问题”却可能更早？神经发育假说给了一个思路：风险在生命很早就埋下，症状只是在特定发育阶段才显现。

支持这条线的证据大致有三类。第一类是产科与围产期因素：母体感染、营养不良、妊娠高血压、早产、低出生体重、分娩缺氧等，在流行病学上与后来的精神分裂症相关。第二类是童年期的细微异常：部分后来发病的孩子，在儿童期就有动作协调、注意力、社交理解上的轻微落后，只是往往不足以引起重视。第三类是前驱期的变化：在正式发病前的几个月到几年，常出现成绩下滑、社交退缩、猜疑、言语变得空泛等。【研究】

一个被广泛讨论的机制是“突触修剪”。青春期大脑会主动修剪用得不多的神经连接，让网络更高效。有假说认为，部分人的修剪过程过度或失调，导致关键环路连接不足。这个假说能解释“为什么起病年龄集中在青春期到成年早期”，但目前仍属于【待验证】，还无法直接指导治疗。

还有“神经退行”与“神经发育”的争论：病后的功能下降，是持续退化，还是一次发育性偏离之后的稳定状态？纵向影像研究的结果并不统一，部分患者病程中确有更明显的灰质变化，但很难与用药、生活方式、反复发作区分开。目前比较稳妥的说法是：两者可能都参与，比例因人而异。【待验证】

需要强调的是，这条线不等于“小时候就注定了”。神经发育风险是概率性的，绝大多数有产科并发症的孩子并不会得精神分裂症；反过来，很多患者并没有明显的早年风险。

## 三、炎症与免疫：从“相关”到“因果”还有很长的路

免疫这条线近几年很热，值得认真讲，也值得认真泼一点冷水。

支持性的观察包括：母体在孕期感染某些病原体，与子代患病风险升高相关；部分患者存在自身免疫病共病；一些研究发现患者血液中某些细胞因子（免疫系统用来传递信号的蛋白）水平与健康对照不同；尸检研究提示部分患者脑内微胶质细胞（大脑里的免疫细胞）活化标志物增加。【研究】

但“相关”不等于“因果”。细胞因子升高可能来自睡眠紊乱、吸烟、体重、应激、感染，也可能是疾病过程的结果而不是原因。更关键的是，免疫指标在个体之间波动很大，目前没有任何一个血液炎症指标可以用来诊断精神分裂症。

治疗转化同样谨慎。塞来考昔、米诺环素、N-乙酰半胱氨酸等抗炎或抗氧化辅助治疗的试验，结果不一致：有的小样本显示对部分症状有帮助，较大的试验却没能重复。因此这类做法目前只能算研究性尝试，标为【待验证】，不能作为常规推荐，更不应该自行购买服用。【待验证】

这里有一个必须说清的安全点：**不要因为“炎症假说”就自行服用抗生素、激素或大剂量消炎药。** 这些药有明确的副作用和相互作用风险，没有医生评估的自行使用可能造成伤害。

## 四、为什么这些发现不能用于个体诊断

精神分裂症至今仍是临床诊断：靠症状、病程、功能损害和排除其他原因，不靠任何一项检查。脑影像在精神科的主要用途是**排除**——排除肿瘤、脑卒中、脑炎、多发性硬化、颞叶癫痫等可能引起精神病性症状的器质性疾病，而不是“确认”精神分裂症。

那么什么时候医生会建议做影像？通常是有一些“不像单纯精神科问题”的线索时：首次发作、年龄偏大或偏小、有局灶性神经体征（比如一侧肢体无力、视野缺损）、新发癫痫、意识障碍、头痛呕吐、症状在短时间内快速进展、有肿瘤病史或免疫抑制状态。这些情况下做影像，是为了不漏掉可以治疗的躯体疾病。【指南】

对已经确诊、病情稳定的患者，反复做核磁并不会带来治疗上的好处，反而增加花费和焦虑。这也是为什么医生常常不做——不是不重视，而是这项检查对诊断没有帮助。

同样重要的是，别把影像报告上的“脑室扩大”“轻度萎缩”当成判决书。第一，放射科报告的措辞常常是描述性的，很多“轻度”改变在健康人里也能见到；第二，大脑有可塑性，功能结局更多取决于症状控制、康复、社会支持，而不是某一张片子上的一条线；第三，报告需要结合年龄、病史来读，脱离上下文解读容易吓到自己。

## 五、听到“脑子有变化”之后，可以做的事

如果你或家人刚拿到一份让人不安的影像报告，下面这份清单可以带去门诊：

- 问清楚：这个发现是“排除性检查的正常描述”，还是需要随访的异常？
- 问清楚：以目前的症状和病程，这个发现会改变治疗方案吗？
- 问清楚：需要复查吗？多久复查？复查要解决什么问题？
- 问清楚：这个发现和年龄、用药、吸烟、体重有没有关系？
- 主动提供：完整用药史、物质使用史、既往头部外伤与癫痫史；
- 主动询问：有没有可能影响影像解读的其他疾病，比如甲状腺问题、自身免疫病、感染；
- 不要自行购买“补脑”“修复神经元”的保健品，也不要用它替代药物；
- 如果报告里出现“占位”“出血”“梗死”“脑炎可能”等字样，尽快找医生当面解读，不要等。

## 六、常见问题与容易踩的坑

**“脑室扩大是不是说明脑子萎缩了、没救了？”** 脑室扩大常被通俗地称为“脑萎缩”，但在精神分裂症研究中，它更多是一个群体层面的统计差异，幅度有限，不能用来预测某个人的结局。功能结局与治疗、康复、支持的关系，比与影像的关系更直接。

**“炎症假说是不是说明要吃消炎药？”** 不是。目前的抗炎辅助治疗证据不一致，属于研究性尝试。自行服用抗生素或激素有实际风险。

**“能不能用影像预测我会不会发病、吃哪种药有效？”** 目前不能。影像标志物还停留在研究阶段，没有进入常规临床决策。

**“那我做这些检查是不是白做了？”** 不白做。排除器质性疾病是诊断流程的一部分，只是它的意义在于“排除”，不在于“确诊”。

> **出现以下情况，请当天联系医生或尽快复诊：**
>
> - 对影像报告有疑问、被“脑萎缩”吓到、想讨论复查计划——挂精神科门诊，带上片子和报告当面问
> - 出现口唇、舌头、下颌或四肢的不自主动作——尽快复诊，不要自行停药
>
> **出现以下情况，立即去急诊或拨打 120：**
>
> - 新发剧烈头痛、呕吐、视物模糊、一侧肢体无力、说话不清、抽搐——这是神经系统急症，不能按“精神病症状”处理
> - 发热、颈项强直、意识模糊、行为紊乱且进展很快——警惕脑炎等中枢感染
> - 高热、肌肉僵硬、意识改变、大汗——警惕恶性综合征，立即停药并急诊
> - 出现木僵、缄默、拒食、保持固定姿势不动（警惕紧张症）
> - 出现自杀念头、自伤行为，或命令性幻听让自己做危险的事——不要独处，必要时拨打 110
