# 5.2 首发、复发与难治性：如何选药

同样是精神分裂症，第一次发病、第二次复发、吃药两年仍不见好，处理思路完全不同。很多患者和家属的困惑也集中在这里：首发是不是要用“最好的药”？复发了一次是不是说明之前的药白吃了？换了两种药都没效，是不是就没希望了？这一页按这三个情境分别讲选药逻辑，并说明“难治性”这个标签到底该在什么时候用。本页不写具体剂量，也不推荐某一种药。

## 一、首发：先站稳，再谈走远

第一次发病的治疗，是整个病程里最值得认真对待的一次机会。原因很实际：初治阶段对药物的反应通常较好，而这一阶段形成的用药习惯、对治疗的态度、家庭的支持方式，会影响后面很多年。

首发选药通常遵循几条原则。【指南】

**单一用药。** 先用一种药，而不是一上来就联合。联合用药会让副作用难以归因，也会让后续调整失去参照。

**从低剂量开始，缓慢调整。** 初治患者对锥体外系反应、镇静、体位性低血压往往更敏感，尤其是年轻、体重偏低的人。起效需要时间，追求“几天内彻底好转”往往换来的是副作用和抵触。

**把耐受性放在很靠前的位置。** 首发患者大多要长期用药，如果第一段治疗体验是“手抖、发胖、整天昏沉”，后面很难建立信任。医生在疗效相近的药之间，通常会优先考虑患者更能长期接受的方案。这不是“保守”，而是现实。

**同步安排心理社会干预。** 药物控制症状，心理教育、家庭干预、复原计划帮助人回到生活。首发阶段做这些，比复发多年后再补要容易得多。【指南】

**不要过早停药。** 症状消失不等于病程结束。首发后过早减停，复发风险明显上升；维持治疗要持续多久，取决于症状缓解程度、既往复发次数、家庭支持与应激水平，由医生判断。

关于长效针剂，首发患者的使用近年有增加趋势，部分研究显示对预防早期复发有帮助，但指南的推荐仍是“有条件考虑”，不是人人适用。【研究】

| 首发选药的考虑因素 | 为什么重要 |
|---|---|
| 症状以阳性为主，还是阴性、认知问题突出 | 决定对哪一类药物特点更看重 |
| 年龄、体重、代谢指标、心电图 | 决定代谢与心脏风险的可接受范围 |
| 是否能坚持每天服药、有无监督者 | 影响是否考虑长效针剂 |
| 既往用药史与家族用药反应 | 只能作为参考，不能照搬 |
| 学习、工作、哺乳、怀孕计划 | 影响镇静、催乳素、致畸性等方面的权衡 |
| 经济条件与医保 | 长期治疗必须考虑可持续性 |

## 二、复发：先找原因，再谈换药

复发在精神分裂症里并不少见，它不是“意志薄弱”的证据，也不是“这个人没救了”的判决。但复发之后最忌讳的做法，是立刻换药——因为复发的原因常常不在药本身。

复发前最常见的原因有这几类：**自行减量或停药**（包括“感觉好了就停”“怕副作用就停”）、**漏服**、**物质使用**（大麻、酒精、兴奋剂）、**重大生活事件**（丧亲、失业、搬迁、感情破裂）、**睡眠长期紊乱**、**剂量不足或吸收问题**、**合并用药影响了血药浓度**（比如某些抗癫痫药、抗结核药、吸烟量的剧烈变化）、以及**诊断需要重新评估**。

所以合理的顺序是：先核对依从性，再复核诊断，再评估物质使用与躯体状况，然后才是调整方案。如果原来的方案曾经有效、这次是因为停药而复发，恢复原方案往往比换一种新药更合理。

有一个现象值得家属知道：**复发的次数越多，恢复到病前水平的难度往往越大**。这不是吓唬人，而是提醒——把功夫花在预防上，比反复“救火”划算。

## 三、难治性：一个必须严格定义的标签

“难治性”不是“吃了药还没好”的日常抱怨，它有相对严格的定义。通常要同时满足：**经过两种不同抗精神病药的足量、足疗程治疗，依从性得到确认，症状仍然没有达到可接受的缓解**；同时要有明确的症状严重度与功能损害依据。不同指南在细节上略有差别，但核心是这三条：两种药、足量足疗程、依从。【指南】

在贴这个标签之前，必须先排除“假性难治”。临床上相当一部分“怎么治都不好”的病例，原因是可以纠正的。

| 排查方向 | 具体要看什么 |
|---|---|
| 诊断是否正确 | 双相障碍、分裂情感性障碍、抑郁伴精神病性症状、创伤后应激、孤独症谱系、人格障碍、物质所致、器质性疾病 |
| 依从性 | 是否真的每天吃、有没有藏药、家属是否确认、血药浓度是否支持 |
| 药物代谢 | 吸烟量变化、合并用药、肝功能、胃肠道吸收、是否呕吐或腹泻 |
| 剂量与疗程 | 是否真的达到治疗剂量、是否用够时间、是否过早判定无效 |
| 物质使用 | 大麻、酒精、兴奋剂、镇静催眠药 |
| 心理社会因素 | 持续的家庭冲突、居住不稳定、被霸凌、经济崩溃 |
| 共病 | 抑郁、焦虑、强迫、睡眠障碍、甲状腺问题、慢性疼痛 |

这张表说明一件事：**在考虑“难治”之前，先把可以纠正的问题纠正掉。** 很多患者在这个阶段被重新评估后，发现只是剂量不足、依从性不佳，或者诊断需要修正。

## 四、氯氮平：难治性治疗里位置最特殊的一种药

如果确实排除了假性难治，接下来最关键的决策通常是一个：**是否使用氯氮平**。

氯氮平是唯一在难治性精神分裂症中被反复证实有优势的抗精神病药，多个指南把它列为这一情境下的推荐选项。它对部分“其他药都没反应”的患者能带来明显改善，包括阳性症状、攻击行为，以及部分患者的整体功能。【指南】

但氯氮平不是“更强的药”，它是一种需要认真管理的药。使用它意味着：

- **血常规监测是处方的一部分**，不是可选项。监测频率由医生根据阶段安排；不能因为“感觉还好”就跳过。
- **发热、咽痛、口腔溃疡、乏力要立即查血常规**，警惕粒细胞缺乏。这是可能危及生命的，不能等下次复诊。
- **早期要警惕心肌炎**，出现胸闷、心悸、气促、发热要尽快就医。
- **癫痫、严重便秘、流涎、镇静、体重与代谢影响**都需要管理。便秘看似小事，严重时可导致肠梗阻。
- **不能自行停药**。突然停用氯氮平可能引起反跳性精神病性症状，还可能出现撤药样不适；任何减量都要医生计划。

为什么这么好的药用得不多？原因很现实：监测麻烦、副作用让人害怕、医生经验不足、患者听说“要抽血”就拒绝。这些顾虑都合理，但它们应该被讨论，而不是让一个可能有效的选项被默默排除。如果医生建议氯氮平，值得认真听完理由；如果医生没提，而你已经换过两种药仍无效，也可以主动问一句：“我这种情况，是否符合氯氮平的适应条件？”【临床经验】

如果氯氮平无效或不耐受，还有别的路：联合另一种药物、合并电休克治疗（对紧张症、严重拒食、高自杀风险尤其有价值）、以及更密集的康复支持。这些都需要在专科医生评估后进行。

## 五、去门诊前，把这几件事准备好

- 目前吃的药名、剂量、吃了多久、有没有漏服（带药盒或拍照）；
- 最近一次复发前，生活里发生了什么变化；
- 有没有使用大麻、酒精、兴奋剂、镇静药；
- 最近有没有换过其他科的药（抗癫痫药、抗结核药、抗生素、避孕药）；
- 吸烟量有没有明显变化；
- 睡眠、体重、月经、性功能、便秘的情况；
- 之前试过哪些药、各自吃了多久、为什么停；
- 家属观察到的变化，按时间顺序写下来。

## 六、常见问题

**“首发是不是要用最强的新药？”** 不是。首发的重点是有效、可耐受、能长期坚持。新不等于更适合。

**“复发一次，是不是以后都治不好了？”** 不是。多数复发是可以治疗的，但反复复发会让恢复变难。重点是把复发次数降下来。

**“两种药都没效，是不是没救了？”** 先确认是不是“足量足疗程”和“真的吃了”。排除假性难治后，氯氮平等选项仍然存在。

**“氯氮平是不是最后的药，用了就没退路？”** 不是“最后”，而是“证据最硬的一个选项”。用了之后仍可调整，只是需要更规范的监测。

> **出现以下情况，请当天联系医生或尽快复诊：**
>
> - 服用氯氮平后出现发热、咽痛、口腔溃疡、乏力——立即查血常规，不能等下次复诊
> - 服用氯氮平后出现胸闷、心悸、气促、发热——警惕心肌炎，尽快就医
> - 准备自行减药或停药——先联系医生，突然停药可能导致复发或撤药样症状
>
> **出现以下情况，立即去急诊或拨打 120：**
>
> - 出现高热、肌肉僵硬、意识改变、大汗、心跳很快（警惕恶性综合征）
> - 出现严重便秘、腹胀、呕吐、停止排便排气（警惕肠梗阻）
> - 出现木僵、缄默、拒食、保持固定姿势不动（警惕紧张症）
> - 出现自杀念头、自伤行为，或命令性幻听让自己做危险的事——不要独处，必要时拨打 110
