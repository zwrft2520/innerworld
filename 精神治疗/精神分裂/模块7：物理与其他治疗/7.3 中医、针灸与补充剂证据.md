# 7.3 中医、针灸与补充剂证据

在精神科门诊，最常被问到的几个问题是：“能不能吃中药调理？”“针灸对幻听有用吗？”“omega-3 能不能代替药？”这些方法有人确实在用，也有人因此停了西药、耽误了治疗。这一页不站队，只把证据、风险和边界讲清楚：什么可以辅助、什么不能替代、哪些信号提示肝损伤或药物相互作用。

## 先说结论

第一，中医、针灸和多数补充剂目前都**不能替代抗精神病药**。它们可能对某些症状或副作用有辅助作用，但没有足够证据支持单独用来治疗精神分裂症。

第二，这类干预的最大风险不是“没用”，而是“用了以后把有效的治疗停了”，以及肝损伤、肾损伤、掺入西药、与处方药相互作用。

第三，任何要尝试的东西，都值得告诉主治医生。隐瞒不会让它更安全，只会让医生在出现问题时少一条线索。

## 中医：能做什么，不能做什么

中医看精神分裂症，通常按“癫”“狂”“郁”等范畴辨证，用清热化痰、活血化瘀、安神定志等思路组方，也可能使用中成药或针灸。部分患者在规范西药治疗的基础上，报告睡眠、便秘、口干、情绪紧张有所改善。【临床经验】

从研究角度看，问题在于证据质量。多数中药治疗精神分裂症的试验样本小、疗程短、盲法不严、结局指标不统一，难以得出“某方某药有效”的可靠结论。系统综述的总体结论是：某些中药作为辅助可能对症状或副作用有有限益处，但证据等级低，不能支持替代抗精神病药。【研究】

中医真正有价值的地方，可能在于整体关注睡眠、饮食、排便、情绪和体质，这些恰恰是西药治疗中容易被忽略的部分。但它不能替代抗精神病药对阳性症状和复发预防的作用，这一点必须说清楚。

## 针灸：证据与安全

针灸治疗精神分裂症的研究主要集中在幻听、阴性症状、焦虑、失眠和抗精神病药引起的便秘、流口水。一些小样本试验报告了辅助改善，但样本量小、对照组设置不一，重复性有限，目前只能算“可能有益、证据不足”。【研究】

安全性方面，由受过训练、使用一次性无菌针具的医师操作，针灸总体是安全的。常见不适是针刺处酸胀、轻微出血或淤青、头晕。需要警惕的少见风险包括：气胸（胸背部深刺）、感染、断针、晕针、神经损伤。服用抗凝药、血小板低、针刺部位有感染或皮损、装有心脏起搏器（做电针时）的人，需要提前告知医生。

针灸不能用于控制急性兴奋、拒食、木僵或自杀风险。这些情况需要急诊和精神科处理，不能靠“扎几次看看”。

## Omega-3 与其他补充剂

| 补充剂 | 研究证据 | 需要注意 |
|---|---|---|
| Omega-3（EPA/DHA） | 辅助治疗研究结果不一致，对阴性症状可能有小幅益处，早期精神病预防的大型试验未显示明确效果 | 鱼腥味、腹泻；与抗凝药同用可能增加出血风险 |
| N-乙酰半胱氨酸（NAC） | 小样本研究，结果混合，部分显示对症状或副作用有帮助 | 胃肠不适；缺乏长期数据 |
| 肌氨酸（sarcosine）等氨基酸类 | 小样本，个别显示对阴性症状有益 | 证据有限，不作为常规推荐 |
| 维生素 B 族、叶酸 | 缺乏时补充有意义；不缺乏时额外补充无明确益处 | 过量并非无害，尤其脂溶性维生素 |
| 大麻二酚（CBD） | 处于研究阶段，未获批用于治疗精神分裂症 | 肝酶影响、药物相互作用、产品质量参差 |
| 各类“安神”“排毒”中成药 | 证据弱，成分复杂 | 肝损伤、掺西药、重金属、与处方药相互作用 |

需要特别提醒：omega-3 常被宣传成“天然的抗精神病药”，这是夸大。它在辅助治疗中的证据不稳定，不能替代药物，也不能因为“吃了鱼油”就减少复诊。购买时选择正规渠道、看清成分和剂量标识，不要买“三无”产品。

## 肝损伤、相互作用与不能替代抗精神病药

**肝损伤**是中药和补充剂最需要警惕的问题之一。何首乌、土三七（含吡咯里西啶生物碱）、雷公藤、某些“减肥茶”“排毒茶”都有肝损伤报告；朱砂（含汞）、雄黄（含砷）等矿物药有重金属风险。早期表现不典型：乏力、食欲差、恶心、尿色变深、皮肤或眼白发黄。出现这些要立即停用并查肝功能，不要当成“上火”。

**相互作用**同样重要。部分中药和补充剂会影响肝脏代谢酶的活性，从而改变抗精神病药的血药浓度；有的本身可能延长 QT 间期；与抗凝药、降糖药、抗癫痫药同用也可能出问题。你以为在“调理”，实际可能让血药浓度忽高忽低。

**为什么不能替代抗精神病药**，理由有四条：一是现有证据不足以支持单用；二是急性期的幻觉、妄想、激越需要快速控制，中药起效速度跟不上；三是停药后复发风险很高，一次复发可能让之前几年的努力归零；四是“替代”往往意味着延误，而延误本身就会造成伤害。

### 如果要尝试，怎么做相对安全

- [ ] 先告诉主治医生，包括方名、成分、剂量、开始时间
- [ ] 选择正规医院的中医科或有资质的医师，不使用来源不明的“偏方”“秘方”
- [ ] 不同时服用多种成分重叠的中成药，避免重复用药
- [ ] 开始后按医生建议复查肝功能，出现乏力、尿黄、黄疸立即停用
- [ ] 不减少、不停用抗精神病药；不减量“试试看”
- [ ] 记录睡眠、排便、情绪、症状变化，复诊时带上
- [ ] 出现皮疹、发热、呼吸困难，立即停药并就医
- [ ] 不购买宣称“根治精神分裂症”“替代西药”的产品

## 什么时候联系医生 / 去急诊

> **立即去急诊或拨打 120：**
>
> - 皮肤或眼白发黄、尿色像浓茶、呕吐、右上腹剧痛（警惕肝损伤）
> - 意识模糊、嗜睡、行为异常、手抖加重（警惕代谢性脑病或药物相互作用）
> - 皮疹伴面唇肿胀、呼吸困难（警惕严重过敏）
> - 呕血、黑便、剧烈腹痛
> - 心悸、晕厥、抽搐
>
> **尽快联系医生：**
>
> - 乏力、食欲明显下降、恶心持续几天
> - 发热、皮疹、淋巴结肿大
> - 加用中药或补充剂后，精神症状明显波动
> - 睡眠、排便、月经出现新的变化
>
> **不要做：** 不要自行停抗精神病药“给中药让路”；不要用“护肝片”抵消可能的肝损伤；不要相信“纯天然所以无毒”。

### 容易踩的坑

**“中药没有副作用。”** 中药有明确的肝损伤、肾损伤和过敏风险，矿物药还可能有重金属问题。“天然”不等于“安全”。

**“西药伤肝，中药护肝。”** 抗精神病药确实需要监测肝功能，但不少中药同样伤肝。正确做法是定期查肝功能，而不是用一种药去抵消另一种药的风险。

**“针灸能根治幻听。”** 目前证据只支持可能的辅助作用，不能替代药物，也不能用于急性期。

**“omega-3 是天然的抗精神病药。”** 研究结果不一致，不能替代治疗。把它当成可能的辅助，而不是“天然替代品”。

**“别人吃这个方子好了，我也试试。”** 中医讲究辨证，同一个方不适合所有人；别人的“有效”也可能是安慰剂、自然波动或同时进行的其他治疗。
