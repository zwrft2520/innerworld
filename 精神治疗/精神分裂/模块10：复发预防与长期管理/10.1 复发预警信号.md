# 10.1 复发预警信号

复发很少是“某天早上突然就变了一个人”。在幻觉和妄想明显回来之前，多数人已经有一段时间睡得越来越少、越来越防备，或者悄悄把药停了。这一页讲怎么认出这些前兆，怎么把它整理成一份属于自己的预警清单，以及家属在边上能观察到什么、第一句话该怎么说。读完可以带走一张能贴在冰箱门上的表。

## 一、复发多半有“前奏”

先解释三个词。**缓解**指症状轻到基本不影响生活，并且维持了一段时间；**复发**指缓解之后症状又回到需要治疗的程度；**前驱症状**指复发真正发生之前那段“不太对劲”的时期。

前驱期通常持续几天到几周，表现往往不典型：睡不好、烦躁、觉得别人在议论自己、不想出门。它不像幻觉那样一眼能认出来，所以最容易被当成“最近压力大”“脾气变差”“人变懒了”。但对治疗来说，这恰恰是最有价值的窗口——这时候核对服药情况、加密随访、处理生活里的应激，有可能把一次住院挡在门外【指南】。

需要说清的是：有前驱症状不等于一定复发，没有前驱症状也不等于不会复发。它是一个提示你去核对、去联系医生的信号，不是一个可以自己下结论的诊断。

## 二、六类最值得盯住的信号

| 类别 | 具体表现（举例） | 为什么值得注意 |
|---|---|---|
| 睡眠 | 入睡困难、凌晨醒来睡不着、总睡眠明显缩短却不困、昼夜颠倒 | 往往出现得最早，比幻觉早好几天 |
| 情绪 | 无故紧张害怕、坐立不安、易怒、突然低落哭泣 | 焦虑和抑郁常与复发同时出现 |
| 感知 | 声音变大变清楚、余光看到人影、觉得周围不真实 | “将信将疑”阶段比明确幻听更好沟通 |
| 猜疑与思维 | 觉得被针对、被议论、被监视；说话跳跃、别人听不懂 | 常先表现为对家人的盘问和防备 |
| 社交与功能 | 不出门、不接电话、卫生变差、工作学习明显掉 | 与阴性症状、药物副作用容易混淆 |
| 服药与复诊 | 自行减量、藏药、说“我好了不用吃”、拒绝复诊 | 停药是最强的复发预测因素之一 |

**睡眠**是最值得盯的一项。不是“睡得少”本身，而是“睡得少还不觉得困”。家属常描述为“他这几天精神特别好，半夜还在收拾东西”。这种状态如果持续两三个晚上，就该联系医生，而不是等它自己过去。

**情绪**的变化有两个方向。一个是往上走：紧张、烦躁、一点就着、坐不住。另一个是往下走：突然沉默、哭泣、说“活着没意思”。后者更危险，因为抑郁和自杀风险常常同时升高。

**感知**的早期变化很轻微：声音好像变大了，或者开始能“听出”是哪个熟人在说；眼角扫到人影；觉得世界像隔了一层玻璃。这些体验本人往往也半信半疑，这时候问“你最近有没有听到什么”，比等他开始跟声音对话要容易得多。

**猜疑**常从具体的人开始：邻居在议论、同事在针对、家里被装了东西。表现是反复检查门窗、盘问家人行踪、把窗帘拉上。争辩“没人议论你”通常无效，甚至会让对方把你也算进“他们”里。

**社交与功能**的退步需要和阴性症状、药物镇静区分。判断的办法是看“变化速度”：几周内明显下滑，更像复发前驱；长期稳定地不爱说话、表情少，更像阴性症状。

**服药与复诊**的变化最直接。藏药、吐药、把药换成保健品、频繁换医生、拒绝查血，都是明确的警报。尤其是“我感觉好了，不用吃了”这句话——它常常出现在复发前的几周。

## 三、做一份属于自己的预警清单

每个人的前驱表现相对固定，第二次、第三次复发往往沿着相似的路径走。所以清单要个人化，不能照抄别人的。

做法可以分五步：

1. **回忆上一次复发前两到四周**。问家属、翻聊天记录、看就诊记录，把当时发生的具体事情写下来。
2. **只留五条**。选最具体、最容易被外人观察到的，不要写“情绪不稳”这种谁也说不清的话。
3. **写成行为句**。不写“睡眠变差”，写“连续两晚只睡三小时，白天还在擦地板”。
4. **分三级**：黄色是出现了但还能上班上学；橙色是已经影响日常、持续三天以上；红色是出现危险信号。
5. **每条配一个动作和一个联系人**，然后拿给医生看，请医生补充和修正。

| 级别 | 大致表现 | 当天该做什么 |
|---|---|---|
| 黄色 | 睡眠或情绪有变化，日常基本维持 | 记录、核对服药、减少熬夜和应酬，下次复诊时提出来 |
| 橙色 | 持续三天以上，明显影响工作学习，开始回避人 | 一天内联系医生，商量是否提前复诊或调整随访 |
| 红色 | 命令性幻听、明确的自伤伤人念头、拒食、失联、打砸 | 立即急诊或拨打 120，有即时危险时拨打 110 |

可以照着勾选：

- [ ] 我写下了自己最常见的五个早期信号
- [ ] 每个信号都配了具体动作，而不是“注意观察”
- [ ] 清单上有医生、社区精防医生、一位家属的电话
- [ ] 家里有一个固定放清单的地方，家里人都知道
- [ ] 我和至少一个人对过这份清单，确认写得看得懂
- [ ] 我知道红色信号出现时去哪个医院、走哪条路
- [ ] 清单每半年和医生一起更新一次

## 四、家属能观察什么、怎么开口

观察的原则是：**描述行为，不评价人格；提供信息，不下诊断。** “他今天把窗帘拉了一天”是信息，“他又犯病了”是判决。前者医生能用，后者只会让对话结束。

值得记的几项很具体：几点睡、几点起、夜里有没有起来；吃了几顿；出门几次；有没有洗漱；手机用到几点；有没有自言自语或无故发笑；有没有反复检查门窗；药盒里还剩几粒。

记录不用复杂，手机备忘录一天一行就够。复诊时给医生看五行字，比“他最近不太好”有用得多。

开口的句式可以练：

- “我注意到你这三天都是凌晨四点还亮着灯，是睡不着，还是心里有事？”
- “你最近好像不太想接电话。是懒得说话，还是他们说的话让你不舒服？”
- “我不跟你争那个声音是不是真的。我只想知道，它有没有让你想去做伤害自己的事？”

三件最好别做：

- **不偷看手机、不翻抽屉当侦探。** 被抓到一次，之后他就什么都不跟你说了。
- **不说“你又犯病了”“你就是不吃药”。** 这两句话会把对方推到防守位置。
- **不在情绪最高的时候讲道理。** 等半小时，效果常常比讲一小时好。

## 五、容易踩的坑

**把阴性症状当成懒。** 不想动、不说话、面无表情，可能是阴性症状，也可能是药物镇静。骂一顿通常只会让退缩更严重，正确做法是记下来告诉医生。

**只盯幻觉，忽略睡眠。** 睡眠变浅变短，往往比幻听早出现好几天，而且更容易被家属发现。

**把副作用当成复发。** 静坐不能（坐着也停不下来、来回踱步）、手抖、嗜睡、坐立不安，可能是药物反应，需要医生调整，不是病情加重。两者的处理方向完全相反。

**一次复发就换医生、换医院、换药。** 复发后最需要的是稳定评估和足量足疗程，频繁更换会让医生看不到完整病程，也容易在换药空档里出问题。

**家属自己扛。** 长期盯着一个人，先垮的往往是照护者。轮班、找人替手、自己去看医生，都不是自私。

**把“能上班”当成没事。** 很多人是硬撑着上班，回家才崩。功能维持是好事，但不能替代睡眠、服药和复诊这三项硬指标。

> **什么时候需要联系医生 / 去急诊**
>
> - 连续两三个晚上几乎不睡，白天仍然兴奋、话多、停不下来。
> - 出现命令性幻听（声音叫他去做危险的事），或明确说“有人要我死”。
> - 出现自杀念头、自伤行为、写遗书、把东西送人、突然交代后事。
> - 拒绝进食饮水超过一天，或出现木僵、缄默、蜡样屈曲（肢体被摆成什么姿势就保持什么姿势）。
> - 打砸、威胁他人、携带刀具，或已经离家失联。
> - 服药后出现高热、肌肉僵硬、意识改变、大汗、心跳很快——按恶性综合征处理，立即急诊。
>
> 以上情况不要等下次复诊。拨打 **120**；有即时人身危险时拨打 **110**；也可以拨打 **12356** 心理援助热线。
