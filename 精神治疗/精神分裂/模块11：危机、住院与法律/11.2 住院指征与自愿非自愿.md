# 11.2 住院指征与自愿非自愿

住院是精神分裂症治疗里最让人紧张的一件事。有人担心“进去就出不来”，有人拖到出事才送。这一页讲什么情况需要住院、自愿和非自愿在法律上分别是什么条件、病房里大概会发生什么、出院前要准备什么。法律部分只讲原则，具体个案以现行法律和当地规定为准。

## 一、什么情况需要住院

住院不是“病重到某个分数”就自动触发，而是看**门诊能不能保证安全、能不能完成必要的治疗**。下面这些情形，通常是医生建议住院的理由。

| 情形 | 为什么门诊难以替代 | 常见处理 |
|---|---|---|
| 自杀念头明确、有计划或已有自伤行为 | 门诊无法做到全天看护 | 住院评估、环境安全管理、调整治疗 |
| 明确威胁他人、持械、打砸，或命令性幻听 | 需要安全环境和快速起效的处理 | 住院，必要时联合公安送诊 |
| 拒食拒水、木僵、缄默、蜡样屈曲 | 可能是紧张症，有脱水、衰竭风险 | 急诊评估，常需住院甚至物理治疗 |
| 严重药物不良反应 | 需要停药、观察、处理合并问题 | 住院监测 |
| 诊断不明确、需要连续观察 | 门诊每次只有十几分钟 | 住院观察、完善检查 |
| 合并严重躯体疾病或外伤 | 需要多科协作 | 综合医院或专科病房 |
| 门诊调整多次仍反复恶化 | 需要结构化治疗与护理 | 住院重新评估方案 |
| 家中无人照护、环境本身有风险 | 出院后无法保证服药与安全 | 住院同时联系社区资源 |

反过来说，也有一些情况**不一定需要住院**：症状存在但能配合门诊、有家属陪同、没有自伤伤人风险、调整方案可以在门诊完成。住院本身也有代价——脱离工作和社交、环境陌生、可能带来病耻感，这些都要一起权衡。

## 二、住院能做什么、不能做什么

**能做的：**

- 提供相对安全的环境，把刀具、窗户、危险物品管理起来。
- 24 小时护理观察，及时发现问题。
- 系统评估：精神检查、病史、体格检查、化验、心电图、必要的影像。
- 在可控条件下调整治疗，观察反应和副作用。
- 处理合并的躯体问题、物质戒断、拒食脱水。
- 让家属喘一口气，同时接受心理教育和沟通训练。
- 为出院后的社区随访、康复、复学复工做准备。

**不能做的：**

- 不能“关起来就没事”。住院只是把风险暂时降下来，真正的长期管理在出院之后。
- 不能保证“一次治好”。住院的目标是度过急性期、把方案稳定下来，不是根治。
- 不能替代知情同意。多数治疗仍然需要患者理解和同意，非自愿住院也不等于所有治疗都可以强制。
- 不能消除病耻感。住院记录属于敏感信息，隐私保护是另一个要单独处理的问题。

## 三、自愿住院

中国精神障碍的住院治疗实行**自愿原则**。也就是说，默认情况下，住院需要患者本人同意。

自愿住院的人，通常是自己觉得需要帮助，或者在家属劝说下同意。住院期间，患者提出出院，医疗机构应当按规定办理；如果医生评估认为病情仍需要继续住院，且符合法律规定的非自愿条件，需要走相应的法定程序，不能靠“拖着不办”或者“口头劝住”来解决。反过来，也不能因为家属不同意就强行留住一个不符合条件的患者。

自愿住院有一个常被忽略的好处：患者对治疗的参与度更高，出院后更容易接着吃药、接着复诊。所以如果能在自愿的前提下入院，通常比拖到非自愿要好。

## 四、非自愿住院：法律上的两类情形

非自愿住院是例外，不是常规。按照《中华人民共和国精神卫生法》的原则，对严重精神障碍患者实施非自愿住院，需要同时满足“诊断结论和病情评估表明需要住院”，并且属于法律规定的两类情形之一：

**第一类：已经发生伤害自身的行为，或者有伤害自身的危险。** 比如自杀未遂、明确的自伤计划、拒食到危及生命。

**第二类：已经发生危害他人安全的行为，或者有危害他人安全的危险。** 比如打伤他人、持械威胁、纵火。

几个要点需要说清楚：

- **前提是“严重精神障碍患者”**，并且经过诊断和病情评估。不是家属觉得“该住院”就能住院，也不是医院单方面决定。
- **诊断结论由精神科执业医师作出。** 疑似患者被送诊时，医疗机构不得拒绝为其作出诊断。
- **送诊的主体**通常包括近亲属、所在单位、公安机关等。出现正在发生的伤害行为时，公安机关会介入制止并协助送医。
- **患者和监护人有救济权利。** 对需要住院治疗的诊断结论有异议、不同意住院的，可以要求再次诊断和鉴定；再次诊断或鉴定认为不需要住院的，医疗机构不得对其实施住院治疗。
- **非自愿住院不是处罚。** 它不设“刑期”，住多久取决于病情评估和治疗需要，而不是“关够多少天”。
- **非自愿住院不等于强制一切治疗。** 用药、检查等仍然要按知情同意和诊疗规范处理；紧急情况下如何处置，法律和诊疗规范有具体规定。

还要提醒：非自愿住院的决定权在医疗机构和法定程序，不在家属。家属能做的是提供病史、表达观察、配合送诊，而不是“签字把人送进去”。反过来说，如果家属认为患者被不当收治，也有投诉和申请再次诊断的渠道，具体见[11.3 精神卫生法与权益](<11.3 精神卫生法与权益.md>)。

## 五、病房流程与出院计划

**入院当天**通常会做这些事：医生问病史、做精神检查；护士做安全检查和物品登记；测体温、血压、体重；抽血、做心电图；告知病房制度、探视时间、通讯方式。

**随身物品**有讲究。刀具、打火机、火柴、玻璃器皿、绳子、皮带、大量现金、可能被用来伤害自己的物品，通常由病房代为保管。手机、充电器、眼镜、换洗衣物一般可以带，具体按病房规定。不同医院差别很大，入院前问清楚，比到了门口争执要好。

**住院期间**，治疗由医生、护士、心理治疗师、社工、康复师共同参与。家属可以做的是：按探视时间去、带对方习惯的东西、听护士说注意事项、参加家属课堂、把家里的情况如实告诉医生。

**出院不是“办个手续”。** 比较理想的出院准备，在出院前一两周就开始：

- [ ] 出院后的药名、用法、复诊时间已经写清楚
- [ ] 已经预约到具体的复诊号，而不是“回头再挂”
- [ ] 社区精防人员已知情，转介材料已提交
- [ ] 家里已经收好危险物品，窗户、阳台有防护
- [ ] 家属知道复发预警信号和危机时的联系电话
- [ ] 有书面的危机预案，家里人手一份
- [ ] 病假、复学、复工的手续已经开始办
- [ ] 知道出现什么情况要立刻回医院
- [ ] 出院后头两周由谁陪着，已经安排好

出院后的头几个月是复发的高峰期。药物、复诊、社区随访、家庭支持这四件事，任何一件掉链子，都可能把住院的成果还回去。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现自杀念头、自伤行为，或明确说“不想活了”。
> - 出现命令性幻听，或坚信有人要伤害自己或家人。
> - 拒食拒水超过一天、木僵不动、缄默不语。
> - 打人、砸东西、持械、纵火，或离家失联。
> - 高热、肌肉僵硬、意识改变、大汗——立即急诊。
> - 出院后药物断了、复诊没约上、社区联系不上——尽快联系医生，不要拖到下次。
>
> 拨打 **120**；有即时人身危险时拨打 **110**；也可拨打 **12356** 心理援助热线。
