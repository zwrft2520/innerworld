# 11.1 急性兴奋激越的现场处理

家里有人突然大声喊叫、砸东西、来回走、说有人要害他，那几分钟往往决定后面几周怎么过。这一页讲的是现场能做什么：先保证安全、怎么减少刺激、第一句话怎么说、什么时候该打 120 或 110、以及哪些做法看起来有用其实很危险。它不鼓励任何形式的强行制服。

## 一、先保证安全，再谈别的

**激越**（agitation）是一个描述性说法，指明显的坐立不安、情绪高涨、言语增多、动作不断，可能伴随威胁、打砸或攻击。它不是一种诊断，背后可能是幻觉或妄想的驱动，可能是极度恐惧，可能是疼痛、感染、低血糖等躯体问题，也可能是药物副作用（比如静坐不能）或酒精、兴奋剂的作用。

现场第一件事不是讲道理，是判断“现在有没有人可能受伤”。

几个具体动作，越快做越好：

- **拉开距离。** 保持大约两臂的距离，不要贴脸说话，不要站在对方正前方堵住去路。
- **站在出口一侧。** 让自己有一条退路，也让对方知道“你可以走”。堵住门会显著增加恐慌。
- **清掉危险物。** 刀具、剪刀、玻璃杯、热水壶、打火机、酒瓶、可投掷的重物，能拿走就拿走；拿不走就把人引开。药盒和农药、清洁剂也要注意。
- **减少在场的人。** 围观的人越多，越容易被理解成“他们要对付我”。指定一个人主谈，其他人退到另一个房间。
- **让孩子离开。** 不管孩子多大，都不要让他在现场“帮忙劝”。
- **关掉刺激源。** 电视、音响、刺眼的灯、一直响的手机。

如果对方已经持械、正在打人、或者把门反锁，不要试图自己解决，直接进入下面“什么时候打 110”的部分。

## 二、减少刺激：环境、距离、姿态

激越的人对外界刺激非常敏感。声音、光线、人数、目光，都会被放大。

**声音**：说话音量降到比平时低一点，速度放慢。不要几个人同时说，也不要隔着房间喊。安静本身就有降温作用。

**光线**：把大灯调暗或关掉一部分，但不要全黑——黑暗会加重不安和猜疑。

**距离与姿态**：侧身站，不要正面对峙；手放在看得见的地方，不要插兜、不要背手；不要俯视，能坐下就坐下，让双方视线高度接近。

**时间感**：给对方留出回应的空档。问完一句，等十秒。急于填满沉默，会让人觉得被逼。

**身体接触**：除非对方正在伤害自己或别人，否则不要主动触碰。突然的接触是激越现场最常见的升级点。

还有一点常被忽略：**先处理身体需求。** 渴、饿、憋尿、疼痛、太热、失眠好几天，都会让情绪更容易爆。递一杯水、问一句“要不要先去趟厕所”，有时比任何劝说都有效。

## 三、怎么说话

说话的目标不是“让他承认自己有病”，而是**让他感到安全一点点，愿意接受帮助**。这两件事差别很大。

| 不建议说 | 为什么 | 可以换成 |
|---|---|---|
| “你冷静点” | 否定了他此刻真实的恐惧 | “我在这儿，我们不着急，慢慢说。” |
| “没人害你，那是假的” | 直接争辩妄想，会把你也划进“他们” | “你觉得有人要害你，这一定很害怕。” |
| “你再这样我就报警” | 威胁会加速升级 | “我需要保证大家都安全，所以我们先坐下来。” |
| “你是不是又没吃药” | 一开口就审问，容易触发对抗 | “这几天是不是没睡好？” |
| “我是为你好” | 把决定权拿走 | “你想先做什么？喝水，还是坐一会儿？” |

几条通用的做法：

- **自我介绍，叫名字。** “我是你姐，我在。”比“你听我说”有效。
- **说清楚你要做什么。** “我想把电视关了，太吵了。”提前说，不要突然动手。
- **短句，一次一个信息。** 激越时处理长句的能力会下降。
- **给两个选项，不给开放题。** “去客厅坐，还是去阳台站一会儿？”
- **承认情绪，不确认内容。** 可以承认“你很害怕”“你很生气”，不必承认“他们真的在监视你”。
- **重复。** 同一句话平静地说三遍，比换三种说法更稳。
- **允许沉默。** 不说话不等于失败。

如果对方开始能对话，可以慢慢转向具体的事：“要不要我陪你走一圈”“我们先吃饭，别的事待会儿说”。不要在这个时候讨论“你到底有没有病”，那是之后门诊的事。

## 四、什么时候打 120、什么时候打 110

这两个号码的分工，很多人搞不清。简单说：**120 管医疗，110 管人身安全和制止危害行为。** 很多时候两个都要打。

| 情况 | 打哪个 | 说明 |
|---|---|---|
| 意识不清、抽搐、高热、大汗、肌肉僵硬 | 120 | 可能是恶性综合征、感染、脑部问题 |
| 胸痛、呼吸困难、严重外伤、出血 | 120 | 先救命，精神问题随后处理 |
| 疑似服药过量、饮酒后昏迷、低血糖 | 120 | 带上药盒和空瓶，告诉急救人员吃了什么 |
| 木僵、缄默、拒食拒水超过一天 | 120 或急诊 | 可能是紧张症，需要精神科急诊评估 |
| 正在打人、砸东西、持械、纵火 | 110，同时 120 | 先制止危害，再送医 |
| 把自己反锁、站在窗台或楼顶 | 110，同时 120 | 不要自己冲上去拉 |
| 离家失联、可能自伤 | 110 | 报失联，提供照片、衣着、常去地点 |

打 110 时说清楚四件事：**具体地址（门牌、楼层、单元）、现场有几个人、有没有武器、有没有人受伤。** 不要只说“我家人情绪失控了”，这会让出警的人无法判断该带什么、该不该带约束工具。

打 120 时除了地址，还要说：**现在是不是清醒、有没有呼吸问题、有没有吃药、吃的什么药、有没有喝酒。** 把药盒、病历、医保卡放在门口，急救人员到了直接拿。

还要提醒一句：**报警不是“把家人送进派出所”。** 在多数情况下，110 的角色是制止正在发生的危险行为、协助送医，后续的评估和治疗仍然由医疗机构完成。提前把这句话跟家人说清楚，可以减少“被背叛”的感觉。

## 五、不要做什么

**不要强行制服。** 几个人一起按倒、压住胸口和背部，是现场最危险的动作。体位性窒息、横纹肌溶解、骨折、吸入呕吐物，都可能在这几分钟里发生。已经在用抗精神病药的人，体温调节和运动系统本来就可能不稳定，剧烈挣扎加高温，是恶性综合征的诱因之一。

**不要自行捆绑。** 用绳子、胶带、床单固定四肢，可能导致神经压迫、血液循环障碍、皮肤损伤，也可能被认定为非法限制人身自由。约束是在医疗机构里、没有其他替代办法时、由受过训练的人按规范实施的保护性医疗措施，需要记录和观察，不是家属可以自行采取的“土办法”。

**不要围堵。** 把人围在墙角、堵住门、几个人同时逼近，只会让“被攻击”的预期变成现实。

**不要抢东西、不要突然从背后靠近。** 除非对方正要伤害自己或他人。

**不要灌药、不要往水里加药。** 呛咳、误吸、剂量不可控，都可能致命。

**不要激将。** “你打啊”“你敢吗”这类话，在激越现场是把火往上浇。

**不要拍照录像发群。** 事后传播会造成二次伤害，也可能涉及隐私侵权。

**不要用“精神病”“疯子”当骂人的词。** 尤其是当着本人的面。

**不要在孩子面前复盘细节。** 孩子需要的是“现在安全了”，不是全过程。

如果情况已经超出能力范围，正确的选择是退出来、锁好门、打 120 和 110，而不是“再试一次”。退出来不丢人。

现场平息之后，还有几件事要做。激越过后，家属常常会抖、会哭、会自责，这些都需要被看见，也需要被处理。

- [ ] 检查所有人有没有受伤，包括自己
- [ ] 把经过和时间点简单写下来，越具体越好
- [ ] 当天或第二天联系医生，说明这次发作
- [ ] 更新危机预案里的电话、医院和步骤
- [ ] 把危险物品收好，药交给一个人统一保管
- [ ] 让参与的人先睡一觉，复盘可以放到明天

> **什么时候需要联系医生 / 去急诊**
>
> - 出现意识不清、抽搐、高热、大汗、肌肉僵硬、心跳很快。
> - 出现胸痛、呼吸困难、严重外伤或出血。
> - 木僵不动、缄默不语、拒绝进食饮水超过一天。
> - 明确说“有人要我死”，或出现命令性幻听。
> - 已经发生打人、砸东西、持械、纵火，或站在高处、反锁房间。
> - 疑似服药过量、饮酒后昏迷。
>
> 立即拨打 **120**；有即时人身危险时拨打 **110**；也可拨打 **12356** 心理援助热线。不要等“他自己冷静下来”。
