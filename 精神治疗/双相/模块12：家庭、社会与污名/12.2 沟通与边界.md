# 12.2 沟通与边界

家里有人处于躁狂或抑郁时，最伤人的往往不是病本身，而是彼此说话的方式。这一页讲三件事：躁狂时怎么说不激化，边界怎么设才不变成控制，怎样避免“高情感表达”把家变成压力源。它适合每天和患者打交道的家属，也适合想改善关系的患者本人。文中有可以直接照着说的话，也有可以打印出来贴在冰箱上的约定。

## 躁狂时，争辩通常没有用

躁狂或轻躁狂时，人的判断力、风险感和对他人感受的觉察都会下降。【指南】这不是“故意气人”，而是状态的一部分。此时跟他逐条辩论“这个投资不靠谱”“你没病”，通常只会升级冲突：他越被否定，越要证明自己；家属越说越急，最后两败俱伤。

急性期沟通的目标不是“说服”，而是“降速、保安全、把人带到医生面前”。可以记住四句话：句子短、内容具体、态度稳、给台阶。

- 句子短：一次只说一件事，不超过两句话。
- 内容具体：说看到的行为，不说人格评价。“你这三天只睡了两小时”比“你太不正常了”更容易被听进去。
- 态度稳：音量放低，语速放慢，不追着说。
- 给台阶：给一个不丢面子的选择。“先吃点东西，再去医院看看，行不行？”

还要选时机。人在高速运转时听不进长解释，等他从外面回来、坐下来、吃了点东西，再谈下一步。不要在电梯里、饭桌上、亲戚面前谈病情，也不要在深夜他正兴奋时讲道理。减少刺激本身就是在帮忙：关掉吵人的电视、把客厅灯调暗、一次只来一个人说话。

## 话术对照：把“指责”换成“我担心”

| 场景 | 容易出口的话 | 可以试着说 |
|---|---|---|
| 连续不睡 | “你就是玩手机玩的” | “我注意到你这几天睡得很少，我有点担心，我们一起给医生打个电话。” |
| 大额投资 | “你疯了，绝对不行” | “这个决定很大，我们等两天，把账算清楚再定，好吗？” |
| 发脾气、指责 | “你怎么这么没良心” | “你现在很烦，我先出去十分钟，等你缓一缓我们再谈。” |
| 拒绝吃药 | “不吃药你就完了” | “你不想吃，是副作用难受，还是觉得没必要？我们跟医生说说。” |
| 说“我没病” | “你病得不轻” | “你觉得现在挺好，我听到了。但睡眠和花钱的变化让我担心，我们去做一次复诊，让医生判断。” |
| 抑郁时说“没意思” | “想开点，比你惨的人多了” | “我在这儿。你不用马上好起来，要不要我陪你坐一会儿？” |
| 提到自杀 | “你别吓我” | “你这么说我很重视。你现在有具体的想法吗？我们一起联系医生。” |

表里的句子不是万能钥匙。对方拒绝时，不要追着重复，可以换成“那我先不说了，你需要的时候叫我”，然后去联系医生、调整环境、找其他家人接力。沟通的目标是把人留在求助的通道里，不是赢下这一场对话。

关于自杀的问法，很多家属怕“问了会提醒他”。目前的证据不支持“直接询问会增加自杀风险”这种担心；相反，直接、平静地问，往往能让对方说出真实想法。【研究】问的时候不要带评判，也不要急着保证“一切都会好”，先听他把话说完。

## 边界：不纵容，也不把人推开

不争辩是沟通技术，不是放弃原则。急性躁狂期，可以先把分歧挂起，等状态稳定再讨论；但涉及安全的事，比如动手、酒驾、把家里钱转走、带孩子做危险行为，需要当场设限。

设限时尽量做到三点：

1. 说自己的行为，不说对方的品格。“如果你动手，我会离开房间并拨打 110”，这是边界；“你就是个暴力狂”，这是攻击。
2. 提前说、平静说、说到做到。边界只有在稳定执行时才有意义，反复威胁又反复退让，会让对方学会“闹一闹就没事”。
3. 全家口径一致。父母一个唱红脸一个唱白脸，边界会立刻失效。

家属常出于心疼替患者兜底：替他还冲动消费的账、替他向单位撒谎、替他隐瞒停药。短期看是息事宁人，长期看会让后果全部由家人承担，患者反而缺少面对问题的机会。

可以帮的：陪诊、提醒、做饭、接送、在医生面前补充观察。不宜帮的：替躁狂期的大额借贷签字、帮忙圆“没生病”的谎、把停药说成“医生同意”、用“他病了”解释所有伤人的行为。

不纵容也不等于冷处理。比较稳妥的说法是：“这件事我不会替你处理，但我可以陪你去面对。”既守住边界，也不把人推开。边界不是惩罚，它的作用是让双方都知道什么可以商量、什么不能。

## 高情感表达：家庭气氛可以被调整

家庭研究里有一个概念叫“高情感表达”，主要指三样东西：频繁的批评、明显的敌意、过度卷入和保护。【研究】多项研究提示，高情感表达与复发风险升高有关，但这不是说“家属说错话才害他生病”。更准确的理解是：家庭气氛是复发的一个环境因素，可以被调整，而不该被用来追责。

降低高情感表达，不是让家属憋着。可以试试：

- 减少“你总是”“你从来”这类概括性批评，改成具体事件加具体请求。
- 把“你怎么又这样”换成“这次我们怎么处理”。
- 给彼此留空间，不追问每一个细节，不翻旧账。
- 家属自己找出口：朋友、支持团体、心理咨询，而不是把全部情绪倒回家里。
- 开家庭会议，一次只解决一个问题，有结论就写下来。

下面这些约定，可以在状态稳定时一家人坐下来逐条谈，谈成几条算几条：

- [ ] 急性期不讨论宏大计划，只谈今天和明天的具体安排
- [ ] 一次只处理一个问题，不翻旧账
- [ ] 不使用侮辱性称呼，不拿病当武器
- [ ] 不动手、不砸东西、不限制人身自由
- [ ] 大额支出延迟决定，全家提前约定
- [ ] 每周固定一次家庭会议，控制在半小时内
- [ ] 家属轮流休息，不把照护压给一个人
- [ ] 有分歧时先暂停，等情绪降下来再谈
- [ ] 危机联系人和就医路线贴在冰箱上
- [ ] 复诊后一起对一下医生说了什么

## 抑郁期与自杀话题：少讲道理，多问一句

抑郁期的患者常被“鼓励”压得更累。“你要坚强”“你要走出来”这类话，听在耳朵里像“你连这个都做不到”。【临床经验】更有效的是具体、低负担的陪伴：一起吃顿饭、下楼走十分钟、把窗帘拉开、帮忙预约复诊。不要催他“快点好”，也不要拿别人比较。

也不要因为怕刺激而回避自杀话题。可以直接问：“最近有没有觉得活着没意思，有没有想过伤害自己？”如果对方说有，接着问有没有计划、有没有手段，并尽快联系医生；情况紧急时拨打 120 或 110，或拨打 12356。把家里的过量药物、刀具、绳索收好，是具体的安全措施，不是不信任。

容易踩的坑：

- 在躁狂高峰期讲道理，越讲越僵。
- 边界说得很狠，执行时每次都退。
- 用“他有病”合理化所有伤害，包括暴力和财务风险。
- 把家庭气氛当成唯一病因，全家陷入自责。
- 只盯患者，没人管家属的情绪。
- 把“不争辩”理解成“什么都答应”。

## 什么时候需要联系医生 / 去急诊

> **出现以下情况，沟通先放一边，优先处理安全：**
>
> - 躁狂加重：连续多日几乎不睡、话多停不下、出现幻觉或被害感。
> - 有伤人威胁、已经动手、持械、堵门不让走。
> - 明确说想死、有计划，或已经开始准备。
> - 拒绝进食饮水、意识模糊、高热、肌肉僵硬。
> - 酒后驾车、带着孩子做危险行为、失联。
>
> 立即拨打 120，必要时拨打 110；也可拨打 12356 心理援助热线。不要在这类情况下继续讲道理或刺激对方。
