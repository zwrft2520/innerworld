# 8.2 老年双相障碍

> 这一页写给 60 岁以上确诊双相障碍的人，也写给他们的子女和主要照护者。老年双相不是把成年人的方案照搬过来就行：晚发的人要先查有没有别的躯体原因，共病多、吃的药多、跌倒和记性变差的风险都更高，锂盐的安全窗口也更窄。读完这一页，你会知道晚发和早发有什么不同、复诊要带什么、家里怎么防跌倒，以及哪些变化必须立刻去医院。

## 一、晚发还是早发：两条不同的路

同样是双相，六七十岁第一次发病，和二十岁发病一直治到老，背后的东西差别很大。

**早发、进入老年的人**，通常已经有多年病程：可能发作过很多次，工作、婚姻、经济都受影响，长期在吃药。到了老年，发作的形态可能变：躁狂变少、抑郁变多，或者情绪高低切换得更频繁；也可能因为退休、丧偶、身体变差而复发。这类人的重点往往是“维持治疗 + 减少药物负担 + 处理共病”。

**晚发的人**，一般指中老年以后第一次出现躁狂或轻躁狂。这时第一件事不是加心境稳定剂，而是先排除“别的原因”。【指南】

需要排查的方向包括：

- **脑血管病**：卒中、小血管病变可以引起类似躁狂的表现，常伴执行功能下降、走路不稳、情绪控制变差。【待验证】有研究提出“血管性躁狂”的说法，但目前还不能当成一个独立诊断。
- **痴呆早期**：额颞叶痴呆、路易体痴呆早期可能出现情绪失控、冲动、幻觉，容易被当成双相。
- **甲状腺功能异常**：甲亢可以表现得像躁狂，甲减可以表现得像抑郁。
- **药物或物质**：激素、某些抗抑郁药、左旋多巴、感冒药里的成分、酒精、镇静催眠药过量或戒断。
- **感染、疼痛、便秘、脱水、睡眠剥夺**：在老年人身上，这些都能把情绪推乱。
- **谵妄**：一种急性的意识混乱，注意力集中不了、话前言不搭后语、白天晚上颠倒、时好时坏。谵妄是急症，不是“老了就这样”。

所以，老年人第一次出现躁狂，值得做一次完整的躯体与神经系统评估，包括必要的化验和影像。**晚发不等于“就是双相”，早发也不等于“老了会自己好”。**

## 二、共病与多重用药：一张必须自己维护的清单

老年人身上很少只有一个病。双相之外，常见高血压、糖尿病、冠心病、慢性肾病、甲状腺病、骨质疏松、白内障、前列腺增生、认知障碍。病多，药就多；药多，相互作用和副作用就多。

| 共病 | 对双相治疗的影响 | 平时要盯什么 |
|---|---|---|
| 高血压、冠心病、心衰 | 抗精神病药可能引起体位性低血压、心率变化；部分药影响心电图 QT 间期 | 起身慢一点、量血压、必要时查心电图 |
| 慢性肾病 | 锂盐靠肾排出，肾功能下降时血锂更容易升高 | 肾功能、血锂、尿量、饮水 |
| 糖尿病 | 部分抗精神病药增加体重和血糖；感染会诱发谵妄 | 血糖、体重、足部皮肤 |
| 甲状腺疾病 | 锂盐可引起甲状腺功能减退或甲状腺肿 | 促甲状腺激素（TSH）定期查 |
| 认知障碍 | 与双相互相混淆；抗胆碱能作用强的药可能加重糊涂 | 记性、注意力、走失风险 |
| 帕金森病、手抖 | 手抖可能来自病本身、锂盐或抗精神病药，来源不同处理不同 | 手抖是粗大还是细小、是否伴走路不稳 |
| 青光眼、前列腺增生 | 部分药有抗胆碱能作用，可能诱发眼压升高、排尿困难 | 眼痛眼胀、排尿 |
| 骨质疏松、跌倒史 | 镇静、低血压、低钠都会增加跌倒和骨折 | 步态、夜起、家里地面 |

**关于多重用药**，有五件事值得做：

1. **维护一张用药清单**：药名、剂量、为什么吃、谁开的、吃了多久。包括中药、保健品、外用药、偶尔吃的止痛药和感冒药。
2. **尽量固定一个主要开药医生**，或者请药师做一次用药审核。不同专科各开各的，是重复用药和相互作用的温床。
3. **警惕“处方瀑布”**：用一种药去治另一种药的副作用，结果药越加越多。比如用镇静药治失眠，失眠又来自另一个药的副作用。
4. **不要自行加保健品和中草药**。有些会影响凝血、血压、肝酶，甚至干扰血锂。
5. **每次复诊都更新清单**，把停掉的药划掉，别让旧清单一直流传。

## 三、跌倒、认知和日常生活

**跌倒**是老年双相最容易被低估的风险。原因往往是叠加的：镇静药让人反应慢，降压药和抗精神病药让起身时血压掉下去，锂盐让手抖、走路不稳，夜尿多、视力差、地面滑，任何一条都足以让人摔一跤。跌倒的后果不只是骨折，还有硬膜下血肿——老年人摔到头以后，可能过几天才出现头痛、嗜睡、呕吐、意识变化，这时候要立刻查CT，不能等。

家里可以做的事：

- [ ] 卧室到卫生间装夜灯，走廊不留杂物，地面防滑
- [ ] 卫生间装扶手，马桶旁、淋浴区都要有
- [ ] 床边放便器，减少夜里摸黑走远路
- [ ] 起身分三步：先坐起来，坐一会儿，再站，站稳再走
- [ ] 鞋子合脚、防滑，不穿拖鞋走远路
- [ ] 视力、听力该配的配，听不清会加重猜疑和冲突
- [ ] 每年复核一次“让人犯困、让人站起来发晕”的药
- [ ] 手机设紧急联系人，独居者考虑佩戴呼叫设备

**认知**方面，双相本身和注意力、记忆、执行功能下降有关，老年期又要和痴呆鉴别。区分点包括：波动性（双相更随情绪波动）、起病方式、是否伴人格改变、影像和量表结果。锂盐可能让一些人觉得反应变慢、记忆变差，这需要和医生讨论，而不是自己停药。电休克在老年严重躁狂、抑郁、紧张症里仍然有效，但要做心血管和认知评估，短期内可能影响记忆，这些都要在知情同意里谈清楚。【指南】

**日常生活**还有几件事值得提前安排：驾驶是否还安全、大额理财谁把关、独居时谁每天联系、家里燃气电器谁检查、紧急情况下谁有权做医疗决定。这些不是“咒老人出事”，而是把不确定变成约定。

## 四、锂盐在老年身上：窗口更窄

锂盐是双相维持治疗的重要药物，但在老年人身上，安全范围更窄。【指南】

原因很直接：肾功能随年龄下降，锂排出变慢，同样的剂量可能得到更高的血锂；老年人口渴感减退、饮水少；很多人同时在吃利尿剂、降压药、止痛药。

**会让血锂升高的常见情况**：

- 发热、腹泻、呕吐、大汗、夏天高温
- 吃得太淡、刻意低盐饮食、减肥
- 噻嗪类利尿剂、部分降压药、某些止痛药（如非甾体抗炎药）、部分抗生素
- 肾功能下降、脱水、手术前后
- 不小心吃多了

**要警惕的表现**：手抖比平时明显变粗、走路不稳、反复呕吐或腹泻、嗜睡、说话含糊、意识模糊、抽搐。在老年人身上，“这两天有点糊涂”可能就是中毒的开始，不要当成“年纪大了”。

家属能做的是：把“喝水、吃盐正常、别自行加药”这三件事当成日常；发热、拉肚子、吃不下饭时，当天联系医生问要不要调整；按医生安排复查血锂和肾功能，不要因为“最近挺好”就不查。**任何减量、停药都由医生决定，自行停锂盐的复发风险很高。**

## 五、照护：家属能做的具体事

照护老年双相的人，最累的往往不是病情本身，而是“什么都要管”。

- **用药**：用分药盒，按天分好；每次换药后重新核对；不“帮忙减半片”。发现漏服，不要一次补两倍，联系医生问怎么处理。
- **记录**：睡眠、情绪、步态、便秘、饮水、有没有说“活着没意思”。一页纸、一周一行就够，复诊时非常有用。
- **陪诊**：带上用药清单、最近的化验单、记录本；进诊室前把最想问的三个问题写下来；经医生和老人同意可以录音，回家再听。
- **预先计划**：万一病情急转，谁陪同、去哪家医院、老人自己希望怎么治，提前聊一次，比在急诊走廊里吵要好。
- **照护者自己**：轮流值守、申请社区居家服务、参加家属团体。照护者倒下，老人往往跟着出问题。

> **什么时候需要联系医生 / 去急诊**
>
> - 突然变得糊涂、注意力散、白天晚上颠倒、时好时坏——警惕谵妄，**立即就医**。
> - 跌倒撞到头，之后出现头痛、嗜睡、呕吐、走路不稳、意识变化——**立即急诊查头颅CT**。
> - 呕吐、腹泻、吃不下、发热、尿量明显减少，同时在吃锂盐——**当天联系医生，必要时急诊查血锂**。
> - 手抖明显加重、走路不稳、说话含糊、嗜睡、抽搐——**立即拨打 120**。
> - 说“不想活了”、拒绝进食饮水、把东西送人、写遗书——**不要独处，立即联系医生；有明确计划时拨打 120，必要时 110**。
> - 出现幻觉、坚信有人害自己、半夜往外走、走失——尽快精神科急诊评估，走失时拨打 110。
> - 胸痛、胸闷、心跳很快或很乱、晕倒——**立即拨打 120**。
>
> 判断不了的时候，按严重处理。也可拨打 **12356** 心理援助热线咨询。

## 六、容易踩的坑

- **把晚发躁狂当“老糊涂”或“脾气变坏”**：第一次躁狂在老年出现，必须查躯体原因。
- **把老年抑郁当“正常衰老”**：不想动、不吃、说没意思，不是“人老了都这样”，可能是可治的抑郁。
- **药越多越安心**：没人统管的多种用药，本身就是风险。
- **怕伤肾就自己停锂盐**：停药后的复发和自杀风险，往往比监测下的用药更大。
- **只管情绪不管步态**：跌倒在老年人身上是可以致命的。
- **忽略听力和视力**：听不清会加重猜疑、争吵和不配合。
- **只盯着老人，不看照护者**：照护者耗竭时，最先被牺牲的往往是规律服药和复诊。
