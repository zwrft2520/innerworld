# 8.4 躯体疾病与物质使用共病

> 这一页写给同时患有心血管病、肾病、肝病、甲状腺疾病，或者有酒精、兴奋剂、大麻使用问题的双相障碍患者和家属。躯体病和物质使用会让双相的药更难用、风险更高，也最容易被“心内科管心、精神科管情绪”切成两半。读完这一页，你会知道为什么要有一个医生统筹、哪些组合要特别小心、物质使用为什么不能只靠“下决心”，以及哪些情况必须立刻去急诊。

## 一、为什么共病会让治疗变复杂

双相障碍很少单独出现。临床上常见的是“双相 + 高血压 + 脂肪肝 + 失眠药 + 偶尔喝酒”这样的组合。共病让治疗变复杂，主要有四条路径：

1. **药物代谢相互影响**。肝酶被诱导或被抑制，会让另一种药的血药浓度忽高忽低。卡马西平是典型的“诱导剂”，会让很多药变得不够用；丙戊酸盐会抑制别人的代谢，让别人的浓度升上去。
2. **药物可能加重躯体病**。锂盐靠肾排，肾功能不好时容易蓄积；丙戊酸盐有肝毒性和高氨血症风险；部分抗精神病药影响体重、血糖、血脂和心电图 QT 间期。
3. **躯体病会模拟或诱发情绪发作**。甲亢可以像躁狂，甲减可以像抑郁，感染、疼痛、激素、睡眠剥夺都能把情绪推乱。
4. **物质使用同时踩好几脚**。它诱发发作、破坏睡眠、降低服药依从性、和药物直接相互作用，戒断本身还可能是急症。

面对共病，原则不是“先治哪个”，而是**先处理当下最危险的那个问题，同时不让另一边失控**。因为“有肝病”就停掉所有精神科药，和“只治情绪”不管心肝肾功能，同样会出事。

## 二、四个躯体系统：心脏、肾脏、肝脏、甲状腺

双相的治疗方案要跟着躯体情况走。下面四个系统的问题，最常在复诊时被漏掉，值得逐个过一遍。

### 心血管：先看心电图和血压

心脏问题和双相治疗的交集，主要在三点：心律、血压、代谢。

- **QT 间期延长**。心电图上的 QT 间期反映心脏复极时间，部分抗精神病药和卡马西平可能让它变长；低钾、低镁、同时用其他延长 QT 的药、先天性长 QT，都会放大风险。开始这类药前做一次心电图，之后按医生安排复查，是常规做法。【指南】出现心悸、头晕、眼前发黑、晕倒，要立刻就医。
- **体位性低血压**。起身时血压骤降，眼前发黑、站不稳，老年人、脱水、同时吃降压药的人更明显。对策很朴素：起身分三步、别空腹洗热水澡、告诉医生你站起来会晕。
- **锂盐与心电图**。锂盐可能引起 T 波改变、窦性心律不齐，多数是良性的，但需要基线心电图和定期复查。
- **抗凝与抗血小板**。卡马西平会加快华法林代谢，让抗凝效果打折；换药、停药时凝血指标会波动，必须让开抗凝药的医生知道。
- **心衰、冠心病**。部分药引起水钠潴留、体重增加，会加重心脏负担；反过来，心功能差时用药要更保守。

| 心血管问题 | 需要特别留意的方向 | 平时盯什么 |
|---|---|---|
| 心律失常、长 QT | 部分抗精神病药、卡马西平 | 心电图、血钾血镁、有没有晕厥 |
| 高血压 | 体重增加、水钠潴留、镇静 | 家庭血压、体重腰围 |
| 冠心病、心衰 | 体位性低血压、心率 | 胸闷气短、下肢水肿、夜间憋醒 |
| 用抗凝药 | 卡马西平等诱导肝酶 | 凝血指标、牙龈出血、黑便 |

### 肾脏：锂盐的主战场

锂盐几乎全部经肾排出，所以肾功能是锂盐治疗的“基础设施”。

- **肾功能下降时**，锂排出变慢，同样的剂量会产生更高的血锂。老年人、糖尿病肾病、高血压肾损害的人尤其要小心。
- **长期用锂盐**可能影响肾小管的浓缩功能，表现为多尿、口渴、夜尿增多；少数人会出现肾性尿崩症，也就是肾脏“关不住水”。【研究】这些变化需要定期查肾功能、尿常规，并和医生讨论。
- **会让血锂升高的常见药**：噻嗪类利尿剂、部分降压药、非甾体抗炎药（很多止痛药和感冒药里都有）、部分抗生素。加任何新药前，告诉医生你在吃锂盐。
- **脱水是加速器**：发热、腹泻、呕吐、大汗、夏天户外工作、刻意低盐饮食，都会让血锂上去。
- **透析的人**：锂会被透析清除，用药和监测需要肾内科与精神科一起安排，不能按普通人的节奏来。

### 肝脏：丙戊酸盐要特别小心

肝脏负责代谢很多精神科药物，肝病会改变药物在体内的浓度和毒性。

- **丙戊酸盐**有明确的肝毒性风险，尤其在儿童、有代谢病或线粒体病的人身上；它还可能引起高氨血症——血里氨升高，表现为呕吐、乏力、意识模糊、手抖加重，严重时昏迷。用丙戊酸盐的人出现“莫名其妙的糊涂和呕吐”，要查血氨。【指南】
- **卡马西平**也可能引起肝损伤，并且是强肝酶诱导剂，会让口服避孕药、抗凝药、部分抗癫痫药失效。
- **脂肪肝、酒精性肝病**在双相患者里并不少见，会让代谢更乱、药物负担更重。
- **严重肝病**时，蛋白合成下降、凝血变差，用药要更保守，必要时调整方案。
- 出现**黄疸（眼白和皮肤发黄）、深色尿、右上腹持续疼痛、皮肤瘙痒、容易出血**，不要等复诊，直接就医。

## 五、甲状腺：一个常被漏掉的方向

甲状腺和情绪的关系非常直接：甲亢可以表现得像躁狂——心跳快、怕热、手抖、话多、睡不着、体重下降；甲减可以表现得像抑郁——乏力、怕冷、反应慢、记性差、情绪低。

- **锂盐**可能引起甲状腺功能减退、甲状腺肿，少数人出现甲亢。所以用锂盐的人要定期查促甲状腺激素（TSH）。【指南】
- 甲状腺功能异常被纠正后，情绪常常跟着改善；反过来，情绪长期不稳的人，值得查一次甲状腺。
- **胺碘酮**含碘量高，可能引起甲亢或甲减，也会影响锂盐的浓度，用这类药的人要更勤地复查。
- 怀孕和产后甲状腺功能会波动，这段时期的监测见[8.3 孕产期双相障碍](<8.3 孕产期双相障碍.md>)。

## 六、物质使用：酒精、兴奋剂、大麻

双相和物质使用常常同时出现，而且互相加重：情绪发作时用酒或药“自救”，物质又让发作更频繁、更难治。【指南】

**酒精**是最常见的一种。它会让抑郁加重、睡眠变浅、判断力下降，长期喝伤肝、伤胃、伤神经；和镇静类药物一起用，可能抑制呼吸。更危险的是**戒断**：长期大量饮酒的人突然停酒，可能出现手抖、出汗、心跳快、幻觉，严重时癫痫发作或震颤谵妄——这是可以致命的急症，**不能在家硬扛，需要医疗监护下戒断**。

**兴奋剂**（冰毒、可卡因、部分来路不明的“减肥药”“提神药”）能直接诱发躁狂、幻觉、冲动和心血管事件。它和双相的症状可以长得一模一样，医生有时需要先按物质所致来处理，观察一段时间才能分清。

**大麻**的问题更微妙。有人用它助眠、缓解焦虑，但大麻可能加重焦虑、诱发精神病性症状，长期使用还与动机下降、注意力变差有关；证据并不一致，但“用大麻治双相”没有依据。【待验证】尤其是有过幻觉、妄想的人，风险更高。

**尼古丁和咖啡因**也值得说一句：吸烟会诱导肝酶，突然戒烟时某些药的血药浓度会上升；咖啡因过量会加重失眠、心悸和焦虑。

面对物质使用，有几条比“讲道理”更有用：

1. **别指望一次戒断**。复发是这个过程的一部分，不是道德失败。
2. **减少伤害**：先减少量、减少频率、不混用、不空腹喝、家里不放酒、把药和酒分开管理。
3. **整合治疗**：精神科和成瘾治疗在同一个团队里做，比“先戒了再来治情绪”有效。分开治，往往两边都掉。
4. **动机访谈**比训话有效：问“你觉得它给你带来了什么、又拿走了什么”，比“你再喝就完了”更能让人动。
5. **戒断要安全**：酒精和镇静催眠药的戒断需要医疗监护，不要自己在家突然硬停。

## 七、把治疗整合起来：就诊前准备

共病最怕的是“没人看全局”。可以做的事：

- [ ] 一张完整的用药清单：药名、剂量、谁开的、吃了多久，包括中药、保健品、外用药
- [ ] 一张躯体病清单：诊断、目前控制情况、最近一次化验日期
- [ ] 每次看新科室，主动说“我在吃精神科药，这是清单”
- [ ] 固定一个主要开药医生，或请药师做一次用药审核
- [ ] 化验单按时间归档，复诊时带上
- [ ] 如实告诉医生喝了多少酒、用了什么物质，不要因为怕被说而隐瞒
- [ ] 家里备一个血压计，必要时备血糖仪

> **什么时候需要联系医生 / 去急诊**
>
> - 胸痛、胸闷持续不缓解、心跳极快或很乱、晕倒——**立即拨打 120**。
> - 眼白或皮肤发黄、深色尿、右上腹剧痛、呕血、黑便——**立即急诊**。
> - 尿量明显减少甚至无尿、下肢明显水肿、气短——**立即急诊**。
> - 呕吐、乏力、意识模糊、手抖加重（尤其在用丙戊酸盐）——**立即就医查血氨和肝功能**。
> - 发热、腹泻、呕吐、吃不下，同时在用锂盐——**当天联系医生，必要时急诊查血锂**。
> - 突然停酒或停镇静药后出现手抖、大汗、心跳快、幻觉、抽搐——**立即拨打 120**，这是戒断急症。
> - 使用兴奋剂后出现极度兴奋、幻觉、胸痛、高热——**立即急诊**。
> - 说“不想活了”、自伤、冲动到可能出事——**不要独处，立即联系医生；有计划时拨打 120，必要时 110**。
>
> 判断不了时按严重处理。可拨打 **12356** 心理援助热线。

## 八、容易踩的坑

- **隐瞒喝酒或用物质**：医生按“没喝”来开药，风险就落到你身上。
- **怕伤肝伤肾就自行停精神科药**：突然停药的复发风险往往更大，调整要由医生做。
- **用酒或大麻“自我治疗”失眠和焦虑**：短期像有效，长期把睡眠和情绪一起拖坏。
- **各科各开各的药，没人核对**：重复用药和相互作用就是这样来的。
- **把戒断当意志力问题**：酒精和镇静药戒断是医学问题，可能需要住院。
- **只查情绪不查甲状腺**：一个简单的化验，可能改变整个方案。
- **认为“躯体病太重，精神科先放一放”**：没有被控制的躁狂或抑郁，会让躯体病更难管。
