# 8.1 儿童青少年双相障碍

> 这一页写给刚被诊断为双相障碍的孩子家长，也写给已经确诊、想弄明白“为什么这么难判断”的青少年本人。孩子身上的双相，样子常常和成人不一样：发作界限模糊、易激惹比兴高采烈更常见，还容易和 ADHD、孤独症、创伤反应、抑郁搅在一起。读完这一页，你会知道为什么要找儿童精神科评估、家庭和学校能做什么、吃药要盯哪些指标，以及哪些情况一分钟都不能等。

## 一、先弄懂几个词，再看孩子

儿童青少年双相障碍的讨论里，最容易吵起来的就是“这到底算不算双相”。先把词说清楚，后面的判断才有落点。

- **躁狂与轻躁狂**：一段时间里情绪异常高涨，或者异常易怒，同时出现睡得少却不困、话比平时多、脑子转得飞快、觉得自己特别有本事、做事不计后果。轻躁狂程度轻一些，身边人看得出“像换了个人”，但还没到完全失控。
- **易激惹**：一点小事就炸，摔东西、骂人、动手。很多人以为躁狂就是开心，其实孩子身上更常见的是“一点就着”。
- **混合特征**：抑郁的绝望和躁狂的激越同时在场。比如一边说“活着没意思”，一边坐不住、整夜不睡、冲动发火。这种状态最危险，自杀和冲动风险都高。【指南】
- **快速循环**：情绪在高涨和低落之间频繁切换，中间恢复得不充分。孩子身上比成人多见。【研究】
- **发作性**：症状是一段一段出现的，有起点、有终点，而不是天天都这样。这一点是区分双相和很多其他问题的关键。

孩子身上的双相有几个特点，值得家长先放在心里：

1. **界限不清**。成人常常能说出“从哪天开始不对”，孩子往往是慢慢变糟，家长回想起来只能说“这个学期一直不对劲”。
2. **混合和快速循环多**。同一天里又绝望又亢奋，或者一周里高高低低好几轮，容易被当成“青春期情绪化”。
3. **易激惹打头**。发脾气、砸门、和老师对着干，比“兴奋得睡不着”更早被注意到。
4. **和发育阶段缠在一起**。青春期本来就睡得晚、爱冒险、和父母顶嘴，判断“是不是症状”需要看变化幅度、持续时间和功能受损。
5. **诊断争议大**。低龄儿童诊断双相在学界一直有争论，很多指南主张非常谨慎，尤其是学龄前儿童。【指南】这也意味着：孩子被下这个诊断时，值得找儿童青少年精神科医生复核，而不是在普通门诊一锤定音。

起病越早，复发和功能受损往往越明显，诊断被延迟也很常见。延迟的原因不神秘：孩子不会描述“心境高涨”，家长更关注成绩和打架，医生在有限的门诊时间里很难拼出完整病程。

## 二、先分清：是双相，还是别的

儿童青少年期，好几件事看起来都像双相。弄错方向的代价不小：把双相当成 ADHD 只用兴奋剂，可能让情绪更不稳定；把创伤反应当成双相长期用药，可能错过真正需要的心理治疗。

| 容易被当成双相的情况 | 关键区别 | 下一步 |
|---|---|---|
| ADHD（注意缺陷多动障碍） | 注意困难、多动、冲动是长期底色，从小就有，不是一段一段发作；没有明显的“心境高涨期” | 由专科判断是否共病、治疗先后顺序 |
| 孤独症谱系（ASD） | 情绪爆发常由感官过载、常规被打破触发；社交沟通困难、兴趣狭窄是长期特征 | 发育行为评估，调整环境与沟通方式 |
| 创伤后应激（PTSD） | 有明确的创伤或长期忽视史；闯入性回忆、回避、过度警觉；情绪爆发多与触发线索有关 | 创伤知情评估，心理治疗为主 |
| 单相抑郁 | 只有低落，没有过持续几天的高涨或易激惹；抗抑郁药后突然“变了一个人”要高度警惕 | 主动追问轻躁狂史，重新评估 |
| 破坏性心境失调障碍（DMDD） | 慢性、几乎天天易激惹，发脾气频繁，但不符合发作性的高涨 | 儿童精神科鉴别，治疗路径不同 |
| 物质或药物所致 | 近期使用大麻、兴奋剂、激素、某些感冒药或减肥药；停药后好转 | 如实告诉医生所有在用物质 |
| 躯体疾病 | 甲状腺功能异常、癫痫、睡眠严重不足、感染后状态 | 查体与必要的化验 |

这张表不是让人自己对号入座，而是提醒：**“像双相”不等于“就是双相”**，需要把病程、触发因素、家族史、发育史放在一起看。【指南】

有两个坑特别常见。

第一个坑是**共病**。ADHD 和双相可以同时存在，不是二选一。合并 ADHD 时是否用兴奋剂、什么时候用、怎么监测情绪，必须由儿童精神科医生决定，家长不要自行找药或自行停。

第二个坑是**只问家长，不问孩子**。青少年可能瞒着自伤、幻听、用药，也可能在家长面前表现得“没事”。单独给孩子说话的时间，往往才是信息的入口。

## 三、评估：为什么一定要找儿童精神科

儿童青少年双相的评估，比成人更依赖“多方拼图”，一次门诊很难完成。【指南】

- **多来源信息**：孩子本人、父母（最好两位）、班主任或心理老师。同一件事在三方眼里的样子常常不同，差异本身就是信息。
- **纵向病程**：什么时候开始、持续多久、之间有没有完全正常的时期、有没有诱发事件（转学、被欺凌、亲人去世、熬夜备考）。
- **发育与学校史**：发育里程碑、成绩变化、同伴关系、被欺凌史、旷课。
- **家族史**：父母双方三代内的双相、抑郁、自杀、物质使用、精神分裂症。家族史不是命运，但会影响评估。
- **躯体与化验**：身高体重、血压、甲状腺功能，必要时药物筛查。不要跳过躯体检查。
- **量表只是辅助**：YMRS 有儿童版本，HAMD、MDQ 也有相应使用场景，但它们不能代替面诊，更不能自测确诊。【指南】
- **用药史要细**：用过什么、用了多久、有没有“吃完更兴奋”、有没有皮疹、有没有突然停药。

### 第一次就诊可以带上这些

- [ ] 孩子最近三个月的睡眠记录（几点睡、几点醒、夜里醒几次）
- [ ] 情绪与行为的简单日记（哪天特别高涨、哪天特别低落、持续几天）
- [ ] 学校表现与老师反馈（成绩、纪律、同伴冲突、旷课）
- [ ] 既往诊断、用药清单、化验单、心理测评报告
- [ ] 家族史清单（三代内精神疾病、自杀、物质使用）
- [ ] 孩子自己写的一段话：最近最难受的是什么、有没有不想活的时候
- [ ] 家长想问的三个问题，写在纸上，避免进诊室就忘

## 四、家庭和学校能做什么

药物稳定情绪，环境和关系决定孩子能不能把稳定维持下去。

**家庭这边**，最有用的不是讲道理，而是四件事：

1. **把病和惩罚分开**。发作期的冲动、顶撞、乱花钱是症状的一部分，事后算总账、羞辱、断生活费，通常只会让下一次隐瞒得更彻底。边界仍然要有，但要提前约定、平静执行。
2. **降低高情感表达**。家里长期高压、频繁指责、过度卷入，和复发风险升高有关。【研究】具体做法是：说具体行为，不贴人格标签；少用“你总是”“你就是”；冲突升级时先离开十分钟。
3. **守住作息**。睡眠是双相的开关之一。熬夜打游戏、通宵刷题、周末补觉到中午，都可能把节律推乱。固定起床时间比固定入睡时间更可行。【指南】
4. **家长自己要有支持**。照护是长期消耗，父母一方崩溃，孩子往往最先受影响。找家长互助团体、心理咨询、轮流值守，都不是矫情。

**学校这边**，可以谈的合理便利包括：座位调整、考试分段或延时、作业量弹性、允许在情绪失控时去安静的地方缓一缓、心理老师定期跟进、复学时的渐进安排。这些不是“特殊照顾”，而是让孩子能留在学校里的具体条件。同时要留意校园欺凌，被欺凌既可能是诱因，也可能是复发的维持因素。

## 五、药物与监测：孩子不是“缩小版成人”

儿童青少年用药有几个必须知道的原则，具体用哪种药、用多少，只能由医生定。

- **很多药属于超说明书使用**。也就是说，药品说明书上没有写这个年龄段，但临床证据和指南支持使用。这不等于“拿孩子做实验”，但医生有义务把理由、预期收益、已知风险讲清楚，家长有权利问明白。【指南】
- **从低剂量开始，缓慢调整**。加量速度由医生安排，家长不要因为“看起来没好”自行加，也不要因为“看起来好了”自行减。
- **要盯的指标比成人多**：身高、体重、腰围、血压、血糖血脂、泌乳素、甲状腺功能、肝功能；用锂盐还要查血锂、肾功能；用抗精神病药要观察手抖、走路僵、坐不住、眼球上翻等锥体外系反应。
- **发育与认知要长期看**。药物对发育中大脑的长期影响，目前证据有限，不能拍胸脯说“完全没影响”，也不能因此拒绝必要的治疗。【待验证】可行的做法是每半年到一年评估一次学习能力、社交和身高体重曲线。
- **心理社会治疗不是可选项**。心理教育、家庭聚焦治疗、CBT、人际与社会节律治疗（IPSRT），在青少年里都有应用；药物解决症状，心理社会干预解决识别信号、沟通和节律。【指南】
- **依从性要靠合作，不靠搜查**。青少年藏药、吐药，常常是因为“不想被当成病人”“吃了变胖”“同学会问”。把选择权还给他一部分（比如自己设提醒、自己选服药时间），比翻书包有效。

> **什么时候需要联系医生 / 去急诊**
>
> - 说“不想活了”、写遗书、把心爱的东西送人、突然异常平静地道别——**不要独处，立即联系医生；有明确计划或已动手，拨打 120，必要时 110**。
> - 出现自伤（划手臂、撞头、掐自己），即使伤口不深，也要当天联系医生。
> - 连续几天几乎不睡、话停不下来、冲动乱花钱、攻击家人或同学——尽快精神科急诊评估；有伤人威胁时拨打 110。
> - 说听到别人听不到的声音、坚信有人要害自己、行为明显紊乱——立即急诊。
> - 服药后出现皮疹，尤其伴发热、口腔溃疡、眼睛红、皮肤起疱或脱皮——**立即停药并急诊**。
> - 出现高热、肌肉僵硬、意识不清、大汗、心跳很快——**立即拨打 120**。
> - 手抖明显加重、走路不稳、反复呕吐、意识模糊（用锂盐的孩子）——立即急诊查血锂。
> - 拒绝吃喝、尿量明显减少、抽搐、意识不清——立即急诊。
>
> 拿不准算不算严重时，按严重处理。也可以拨打 **12356** 心理援助热线先问清楚。

## 六、容易踩的坑

- **把青春期当双相**：熬夜、叛逆、追星、和父母吵架，本身不是病。看的是持续时间、功能受损和发作性。
- **把双相当叛逆**：反复的彻夜不睡、夸大、冲动消费、突然的成绩崩塌，不该只用“管教”解决。
- **只治孩子，不治环境**：家庭冲突、校园欺凌、长期睡眠不足不改变，药效会打折扣。
- **自行停药**：觉得“好两个月了”就停，复发风险很高；停药要在医生安排下缓慢进行。
- **隐瞒发作**：怕住院、怕被贴标签而少说，医生拿不到真实病程，方案就会偏。
- **忽略孩子自己的叙述**：孩子说“那种感觉又来了”，往往比量表更早。
- **一次门诊定终身**：儿童青少年诊断会随发育和病程修正，定期复核是正常的，不是医生不靠谱。
