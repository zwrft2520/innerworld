# 3.4 环境与生活事件：睡眠剥夺、季节、物质

这一页讲那些“看得见、摸得着”的诱因：睡眠剥夺、跨时区与倒班、季节变化、重大生活事件，以及酒精、兴奋剂和大麻。它适合反复发作、想弄明白“这次到底为什么又犯了”的读者，也适合被家人质问“是不是你自己作出来的”的人。读完你会知道：**这些是风险因素和触发器，不是单一病因；把能改的部分管好，能降低发作概率，但不能替代治疗，也不该成为责怪谁的理由。**

## 一、睡眠剥夺：证据最硬的一个触发器

在各种环境因素里，睡眠与双相发作的关系是最扎实的。临床上反复看到同一条时间线：先有几晚睡不好或干脆没睡，接着情绪抬升、话变多、计划变多，然后发作。【研究】

这条线不只在观察中被记录，也被实验研究支持过——在易感者中，睡眠剥夺可以诱发轻躁狂或躁狂样表现。反过来，抑郁期常见的是睡眠增多、白天嗜睡。也就是说，**睡眠改变既可能是前兆，也可能是发作的一部分**。

要把两个容易混淆的现象分开：

| 现象 | 具体表现 | 意味着什么 |
|---|---|---|
| 失眠 | 想睡睡不着，躺很久，白天疲惫、注意力差 | 常见于焦虑、抑郁、药物副作用，也可能是发作前兆 |
| 睡眠需求减少 | 只睡三四个小时仍精力充沛，不觉得困，脑子转得快 | 躁狂或轻躁狂的典型信号，不是“状态好” |
| 睡眠节律紊乱 | 入睡和起床时间每天差很多，白天补觉，夜间活动 | 节律不稳，是复发风险因素 |
| 嗜睡 | 睡很久仍起不来，白天大部分时间在床上 | 常见于抑郁相，也可能是药物镇静 |

产后是一个特殊的窗口：夜间反复被叫醒、睡眠被切成碎片，与产后精神病性症状相关。家里有新生儿、又有人有双相病史时，安排夜间轮班照护不是“娇气”，而是风险管理。【指南】

## 二、跨时区、倒班与光照

生物钟靠光照校准，也靠固定的社会时间表（吃饭、上班、社交）稳定。当外界时间表突然改变，节律要花几天到两周去适应。

- **向东飞行**通常比向西更难适应，因为需要把生物钟往前拨，而人体天然倾向于往后延。
- **倒班**，尤其是频繁轮换的夜班，会让“白天该清醒、夜里该睡”的信号反复错位。
- **夏令时切换**这类一小时的改变，对多数人影响有限，但对节律脆弱的人可能是触发点。
- **夜间强光**（手机、电脑、加班灯）会推迟节律；白天户外光照不足则让节律“抓不住”锚点。

实践上的原则很简单：**固定起床时间优先于固定入睡时间**，因为起床时间更容易人为控制，而它又能反过来拉动入睡时间。出差或旅行时，尽量按目的地时间安排第一天的起床与早餐，白天多到户外见光。

光照治疗在双相抑郁中有一定证据，但也有诱发转躁的风险，必须在医生指导下进行，不能自己买灯照。【研究】

## 三、季节与重大生活事件

**季节模式**：部分患者的发作有明显季节性，春季躁狂、秋冬抑郁的报告较多，但不是每个人都有。如果你连续几年都在同一季节出现波动，值得写进病史告诉医生。【研究】

**生活事件**：丧失亲友、失业、离婚、经济压力、搬迁、考试、官司——这些都可能成为触发点。有一个被广泛讨论的框架叫“点燃”（kindling）：早期发作往往需要明显的应激，随着发作次数增加，后来可能不需要那么大的刺激也能发作。【待验证】这个假说解释了一部分临床现象，但证据并不统一，不要把它理解成“发作会自己越来越容易，所以没救了”。

**童年逆境**：研究较一致地报告，童年期遭受忽视、虐待、家庭功能严重紊乱的人，起病更早、共病更多、病程更差。【研究】这里要特别强调：**这是风险因素，不是指责父母的证据，更不是“你小时候的事造成了这一切”的单一因果。** 讨论它的意义在于：这类经历值得被治疗（心理治疗有明确作用），而不是被拿来追责。

还有一个常被忽略的中介：**生活事件往往通过打乱睡眠来起作用。** 熬夜赶工、守夜、失眠，才是那条把压力转化成发作的常见通路。所以应对压力的具体动作，常常就是“先把睡觉保住”。

## 四、酒精、兴奋剂与大麻

**酒精**是最容易被低估的一个。它看似助眠，实际上破坏后半夜的睡眠结构，导致早醒和睡眠碎片化；它本身是中枢抑制剂，却可能加重抑郁、增加冲动和自杀风险；它还与多数精神药物相互作用，影响肝代谢和镇静程度。【指南】“喝一点好睡觉”是双相患者最常踩的坑之一。

**兴奋剂**包括处方药（如治疗注意缺陷多动障碍的药物）和非法兴奋剂（冰毒、可卡因等）。它们能提高多巴胺活性，可能诱发躁狂、混合状态甚至精神病性症状。处方兴奋剂不是绝对禁忌，但需要医生在双相诊断明确、心境稳定方案到位的前提下权衡。【指南】

**大麻**：研究较一致地报告，使用大麻与更早发病、发作更频繁、结局更差相关；高效价产品（THC 含量高）风险更大。它不是“天然就安全”，也可能诱发焦虑、偏执和精神病性症状。【研究】

**咖啡因与能量饮料**：半衰期长，下午之后摄入容易推迟入睡；能量饮料常含大剂量咖啡因加糖，对睡眠和代谢都不友好。

面对物质使用，有用的态度不是道德审判，而是把它当成治疗的一部分：**如实告诉医生用了什么、多久一次、多少量**。隐瞒的代价是医生按“没在用”来调药，风险由患者承担。

## 五、风险因素叠加，不是单一病因

写到这里，最需要说清的一句话是：**没有哪一件事“害了你”。**

目前的理解是“多因素叠加”：遗传给了易感性，神经发育和节律系统决定了脆弱点，环境因素在特定时间点把风险推过阈值。同一个人在不同时期，可能因为不同原因发作；同一次发作，也可能同时有几条线索在起作用。

这也意味着两件事：**第一，不必找“罪魁祸首”**，包括不必怪自己、怪父母、怪某次熬夜；**第二，不必因为找不到原因就放弃管理**，因为可干预的因素确实存在。

- [ ] 连续两周记录：上床时间、起床时间、夜间醒几次、饮酒量、咖啡因量、白天活动量。
- [ ] 出差、旅行、考试、换班前，先把作息方案写下来，而不是到了当地再说。
- [ ] 把“这次发作前三个月发生了什么”写成一页纸，复诊时带给医生，找个人化的规律。
- [ ] 减少夜间饮酒，不用酒精助眠；需要助眠时与医生讨论。
- [ ] 下午之后不喝咖啡、浓茶、能量饮料。
- [ ] 不隐瞒物质使用，包括“偶尔抽一点”“周末喝几杯”。
- [ ] 春节、长假、婚礼、考试季这类作息容易崩的时段，提前和家里人约定“几点必须睡”。
- [ ] 若已经形成依赖，不要自行硬戒，尤其是酒精——突然停酒可能引起震颤、幻觉、抽搐，需要医疗支持。

### 容易踩的坑

- **“这次是因为跟人吵架，所以不用吃药。”** 触发因素和疾病本身是两回事，去掉诱因不等于不需要治疗。
- **“我熬夜没事，说明我好了。”** 熬夜后感觉良好，可能正是轻躁狂的开始。
- **“大麻是天然的，比药安全。”** 天然不等于无害，尤其对双相病程。
- **“只要作息规律，就能不吃药。”** 规律作息降低风险，但不能替代维持治疗。

> **什么时候需要联系医生 / 去急诊**
>
> - 连续数日几乎不睡，同时话多、冲动消费、危险驾驶、性行为失控或出现伤人威胁：尽快精神科急诊评估，必要时拨打 **120** 或 **110**。
> - 饮酒后出现自杀念头、自伤行为或具体计划：不要独处，立即拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 减少或停止长期大量饮酒后出现手抖、大汗、心慌、幻觉、抽搐：警惕酒精戒断，可能危及生命，立即急诊。
> - 使用兴奋剂或大麻后出现幻觉、被害感、极度兴奋伴失眠：立即就医，不要独自观察。
