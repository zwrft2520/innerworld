# 3.2 神经生物学：单胺、昼夜节律与线粒体

这一页解释三个最常被提到的机制：单胺（多巴胺、5-羟色胺、去甲肾上腺素）、生物钟与睡眠—觉醒节律、线粒体与能量代谢。它适合想弄明白“药为什么起效”“为什么一熬夜就容易发作”的读者，也适合被人用“你就是血清素低了”一句话打发过的人。读完你会知道：**机制解释是研究工具，不是化验单；它能帮你理解治疗方向，但不能拿来给自己下诊断，也不能当成“补一补就好”的理由。**

## 一、单胺假说：从“化学失衡”说起

“抑郁症是大脑里血清素不够”——这句话流传极广，也极其简化。它的源头大致有两条线索：一是早期抗抑郁药能提高突触间隙的单胺浓度，情绪随之改善；二是耗竭单胺的药物（例如老式的降压药利血平）在部分人身上会引起抑郁。【研究】

多巴胺这条线在双相里更显眼：阻断多巴胺受体的抗精神病药能控制躁狂；反过来，用于帕金森病的多巴胺激动剂、以及某些增强多巴胺的药物，可能诱发躁狂或类似躁狂的表现。【研究】这组“正反两面”的观察，是“多巴胺参与躁狂”最直观的证据。

但“血清素低”这个说法有三处不严谨。

第一，**活人的突触间隙递质浓度没法稳定测量**。我们测的是血液、尿液里的代谢产物，或者是脑脊液，这些和外显行为之间隔着好几层，不能直接换算成“你缺多少”。

第二，**药物立刻改变递质，情绪却要等几周**。如果病因只是“浓度不够”，补上就该立刻好转。这个时间差提示：真正起作用的，可能是递质下游的受体适应、信号通路和神经可塑性变化，而不只是“水位”。

第三，**双相不是单向的“低”**。躁狂期的表现更像“系统被踩了油门”：睡眠需求减少、活动增多、奖赏敏感。用一个“缺乏”模型去解释两极，往往讲不通。

| 机制假说 | 支持它的观察 | 它解释不了什么 |
|---|---|---|
| 单胺（5-羟色胺、去甲肾上腺素） | 抗抑郁药提高单胺、耗竭单胺可致抑郁 | 起效延迟；为什么同一套系统既管抑郁又管躁狂 |
| 多巴胺与奖赏系统 | 抗精神病药控躁狂；多巴胺激动剂可诱发躁狂 | 为什么有些人终生只有抑郁相 |
| 谷氨酸与 GABA 平衡 | 部分抗惊厥药有效；磁共振波谱有异常报告 | 具体到个人无法测量，无法指导选药 |
| 神经可塑性下降 | 神经营养因子、海马体积研究报告 | 因果方向不明，多为横断面观察 |

对患者的意义在于：**你的病不是“意志薄弱”，也不是“补点血清素就好”。** 药物作用于这些系统，但它们不是维生素，不能按“缺多少补多少”来用。

## 二、生物钟与睡眠—觉醒节律

人体内部有一套约二十四小时的计时系统。主时钟位于下丘脑的视交叉上核，靠光照校准；它再通过体温、皮质醇、褪黑素等信号，把“现在几点”通知全身。研究还发现一组“时钟基因”参与这套节律的分子机制。【研究】

双相障碍和这套系统的关系，是机制研究里相对扎实的一块：

- **相位偏移常见**：不少患者入睡与起床时间偏晚，节律与外界时间表对不上。
- **节律不稳**：睡眠时长、起床时间、日间活动量波动大，社会节律（吃饭、上班、社交的固定时间点）容易被打乱。
- **睡眠剥夺能诱发发作**：这不是民间说法。临床观察和实验研究都报告，通宵或连续熬夜后，易感者可能在数天内出现轻躁狂甚至躁狂。【研究】
- **产后是高风险窗口**：夜间反复被叫醒、睡眠被切碎，与产后精神病性症状相关。【指南】

这也解释了一个常被误解的现象：**“睡眠需求减少”和“失眠”不是一回事。** 失眠是想睡睡不着、白天疲惫；睡眠需求减少是睡三四个小时仍然精力充沛、脑子转得快、不觉得困。后者常常是躁狂或轻躁狂的早期信号，而不是“最近状态好”。

反过来，光照也是杠杆。强光、蓝光在夜间会推迟节律；白天到户外见光、固定起床时间，则有助于把节律往前拉。光照治疗对双相抑郁有一定证据，但也存在诱发转躁的风险，必须在医生安排下进行。【研究】

## 三、线粒体与能量代谢

神经元是全身最耗能的细胞之一。线粒体负责生产能量分子（ATP）、缓冲细胞内钙离子、调节氧化应激。如果能量供应或质量控制出问题，神经元的兴奋性和存活都会受影响。

这条线索在双相研究里出现得越来越多：

- **磁共振波谱研究**报告患者脑内乳酸、pH、含磷代谢物与健康人存在平均差异，提示能量代谢可能改变。【待验证】
- **外周血与尸检研究**报告线粒体复合体活性、氧化应激标志物的变化，但样本通常不大，结果不完全一致。【待验证】
- **锂的作用**被一些研究认为与线粒体功能、神经营养因子有关，这为“锂为什么不止稳定情绪”提供了可能的解释。【待验证】

必须说清楚边界：这些都是群体层面的平均差异，效应量不大，研究之间也有矛盾。**它们不能用来诊断，更不能推出“吃某种线粒体营养素就能治双相”的结论。** 市面上打着“修复线粒体”“给大脑供能”旗号的补剂，多数没有在双相患者中做过像样的试验。把钱花在规律睡眠、按时复诊和必要的心理治疗上，性价比高得多。

## 四、机制解释的局限

理解机制的价值，和机制的局限，值得一起讲。

**第一，相关不等于因果。** 研究发现患者组某项指标偏高，可能是疾病造成的，也可能是药物、睡眠不足、吸烟、体重增加造成的。横断面研究（在同一时间点比较两组人）没法分辨先后。

**第二，药物是最强的混杂因素。** 大多数患者的脑影像和血液指标，是在服药状态下采集的。想把“疾病效应”和“药物效应”分开，需要从未用药的首发患者入手，而这样的样本很难找、往往很小。

**第三，双相障碍异质性很大。** 双相 I 型、II 型、快速循环、以混合发作为主的人，可能对应不同的生物学通路。把所有患者放在一起求平均，容易把彼此相反的变化互相抵消。

**第四，机制很少立刻改变处方。** 从“发现某个通路异常”到“开发出可用靶点”，中间要经过很多年。真正指导今天用药的，仍然是发作类型、既往反应、身体状况和指南推荐。【指南】

所以，看到“科学家发现双相障碍的新机制”这类新闻，合理的反应是：“有意思，但它会不会改变我现在的治疗？”多数时候答案是不会。这不算坏消息——说明现有的治疗框架虽然粗糙，但确实抓住了某些关键环节。

## 五、把机制变成日常能做的事

机制讲完，落到可操作的部分其实不多，但每一条都不难：

- [ ] **固定起床时间**，比固定入睡时间更容易做到；周末与工作日的差距尽量控制在一小时左右。
- [ ] **记录睡眠**：上床时间、入睡大概用时、夜间醒几次、起床时间、白天是否困。复诊时带上，比“最近睡得还行”有用得多。
- [ ] **跨时区或倒班前先和医生商量**，尽量按目的地时间作息，白天多到户外见光，夜间减少强光。
- [ ] **不把通宵当常态**，尤其是赶工、打游戏、追剧这类“主动熬夜”。
- [ ] **不自行用褪黑素、补剂或酒精来“调睡眠”**；需要助眠时和医生讨论。
- [ ] **区分“累”和“不困”**：连续几天睡得很少却越来越有劲，是要警惕的方向，不是好转。
- [ ] **把“最近一次发作前两周的睡眠”写下来**，很多人会发现规律。

### 常见问题

**问：既然机制还没搞清楚，吃药是不是在“试”？**
一定程度上是。精神科用药目前仍以临床评估和试错调整为主，这也是为什么需要复诊、需要记录反应。但“机制未完全清楚”不等于“无效”；很多有效治疗的作用机制，是在使用之后才逐步被理解的。

**问：是不是把睡眠调好就能减药？**
不能这样类推。规律作息能降低复发风险，是治疗的一部分，但不等于可以替代药物。减药、停药必须由医生评估，自行减量后的复发往往来得更快。

**问：家里人说“你就是想太多，脑子里的化学物质乱了”？**
前半句是误解，后半句是过度简化。双相障碍有生物学基础，但不是“某种物质低了”这么简单，也不是靠“别想太多”能解决的。

> **什么时候需要联系医生 / 去急诊**
>
> - 连续数日几乎不睡，同时话明显变多、精力异常旺盛、冲动消费或冒险行为：尽快精神科就诊，必要时急诊。
> - 出现自杀念头、自伤行为或具体计划：不要独处，立即拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 服用抗精神病药后出现高热、肌肉僵硬、意识改变、大汗、心跳很快：警惕恶性综合征，立即急诊。
> - 突然出现剧烈头痛、肢体无力、说话含糊、抽搐：立即拨打 **120**，不要在家观察。
