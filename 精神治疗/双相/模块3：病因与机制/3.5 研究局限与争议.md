# 3.5 研究局限与争议

这一页不教你新的医学知识，而是给你一把尺子：看到“科学家发现双相障碍的病因”“某种营养素能修复大脑”“基因检测可提前十年预警”这类标题时，怎么判断它值不值得信。它适合想读懂研究新闻、又不想被带节奏的读者和家属。读完你会知道：**遗传、影像、炎症三类研究各自卡在哪里，以及判断一条研究含金量的几个硬指标。**

## 一、遗传研究：从候选基因到全基因组

遗传研究的路线换过好几代，每一代都有各自的坑。

**第一代是“候选基因”研究。** 研究者先认定某个基因（比如与 5-羟色胺转运体、多巴胺受体有关的基因）在生物学上说得通，然后比较患者与健康人的基因型。这类研究在本世纪初大量发表，但样本往往只有几十到几百人，重复性差；后来的大样本研究多数没能复制出稳定结果。【待验证】当年的“抑郁基因”“双相基因”新闻，大多出自这一批。

**第二代是全基因组关联研究（GWAS）。** 它不再预设哪个基因重要，而是把全基因组的常见变异都扫一遍，需要数万人的样本才能在统计上站住。它确实找到了一批在不同人群中反复出现的位点，效应也都很小。【研究】

GWAS 的局限同样明显：

- **效应小**：单个位点对风险的贡献极小，单独拿出来几乎没有解释力。
- **样本代表性**：绝大多数研究的参与者是欧洲血统，结果迁移到东亚人群时，位点和效应都可能不同。
- **只覆盖常见变异**：罕见变异、结构变异、非编码区的调控变化，很多没被覆盖。
- **统计显著不等于临床有用**：一篇论文能发表，不代表它能进医院。

**第三代是“多基因风险评分”。** 把成千上万个微小效应加成一个分数。它在研究中有价值——可以看人群层面的分层、可以做因果推断的工具——但对个人的预测力很弱。两个分数相近的人，可能一个患病一个不患病；患者与健康人的分数分布也大面积重叠。把它当算命，会同时制造虚假的安心和虚假的绝望。【待验证】

| 你看到的标题 | 研究实际说了什么 | 该怎么读 |
|---|---|---|
| “发现双相障碍的致病基因” | 找到一个统计学关联位点，效应极小 | 离“致病”和“检测”都很远 |
| “基因检测可预测患病风险” | 多基因评分在群体中有信号，个体预测力弱 | 目前不用于临床，不建议自费购买 |
| “家族史阳性者风险高数倍” | 相对风险升高，但绝对风险仍有限 | 相对风险不等于“一定会得” |
| “表观遗传解释了为什么同卵双生子不同” | 机制假说，人体证据有限 | 有意思，但还不能用 |

## 二、影像研究：小样本、混杂与发表偏倚

影像研究好看、好传播，也最容易过度解读。它的问题集中在三处。

**第一，样本小。** 单中心研究常常只有几十人。在样本这么小的情况下，个别极端值就能把平均值拉偏。近年来国际协作（把多中心数据合并）改善了这一状况，但多数仍是横断面设计——只拍一次，无法回答“谁先谁后”。

**第二，混杂因素太多。** 患者组与健康组在用药、体重、吸烟、饮酒、睡眠、共病上往往系统性地不同。药物对脑结构和功能有实实在在的影响，而这些影响很难从“疾病效应”里剥离出来。理想的设计是招募从未用药的首发患者，但这样的样本稀少，随访脱落率也高。

**第三，发表偏倚。** 阳性结果更容易被发表，阴性结果常躺在抽屉里。这意味着你读到的文献整体上“效果”被高估了。再加上媒体偏好“突破”，一个效应量很小的研究，标题可以写成“改写教科书”。

结果是：**我们能说“双相障碍与某些脑区和连接的群体平均差异相关”，但不能说“某个影像指标可以诊断双相”。** 后者需要敏感度、特异度、阳性预测值都过关，目前没有候选指标达到这个门槛。【指南】

## 三、炎症研究：相关不等于因果

炎症与精神症状的关联，是近十年最热的方向之一。研究者在部分患者身上看到炎症指标升高、脑内小胶质细胞激活的迹象，也看到某些免疫性疾病患者的精神症状发生率较高。【待验证】

但这条线索的因果链条还没接上：

- **方向不明**：是炎症促成发作，还是发作、失眠、酗酒、体重增加导致炎症升高？横断面研究回答不了。
- **混杂太多**：脂肪组织本身分泌炎症因子；吸烟、感染、压力、药物都能改变指标。
- **指标不稳**：同一个人的 C 反应蛋白可以因一次感冒大幅波动，单次抽血的意义有限。
- **干预试验结果不一**：抗炎药作为辅助治疗的试验，有的报阳性，有的报阴性，样本普遍不大，还不足以支持常规使用。【研究】
- **可能的亚组**：真正受益的也许是某个特定亚群（比如伴自身免疫问题的人），把所有患者一起治，效果就被稀释了。

所以，“炎症假说”值得研究，但**不值得你现在去吃抗炎药、抗生素或大剂量保健品**。这类自行尝试有真实的肝肾功能风险。

## 四、怎么判断一条“新研究”的含金量

下面这张表可以直接拿去对照新闻标题。

| 层次 | 常见形式 | 能说明什么 | 分量 |
|---|---|---|---|
| 个案与专家观点 | 一位医生的经验、一个病例 | 提供假设 | 最低 |
| 动物与细胞实验 | 小鼠、培养皿 | 提示机制，不能直接推人 | 低 |
| 小样本横断面 | 几十人，只测一次 | 发现关联，不能定因果 | 偏低 |
| 大样本队列 | 数千人，随访多年 | 关联更可靠，仍非因果 | 中 |
| 随机对照试验 | 随机分组、设对照 | 能支持因果与疗效 | 高 |
| 系统综述与 meta 分析 | 汇总多项试验 | 估计总体效应 | 高 |
| 指南推荐 | NICE、CANMAT/ISBD、中国指南 | 已经过专家评估与整合 | 最高 |

具体到阅读时，可以按这几个问题过一遍：

1. **样本多大、是什么人？** 二十个人的研究，和两万人的研究，能说的话完全不同。
2. **有没有对照？** 没有对照，就无法排除时间、安慰剂、回归均值的影响。
3. **有没有被重复？** 一项孤立的发现，尤其在小样本领域，很可能是偶然。
4. **效应有多大？** 统计显著（p 值小）不等于效应大；临床上有意义的差别才重要。
5. **测的是“替代指标”还是“真实结局”？** 炎症指标下降、脑区体积变化，不等于复发减少、生活质量改善。
6. **发表在哪、谁出钱？** 同行评议的期刊、声明清楚的资助方，比“某机构内部报告”可靠。
7. **是预印本吗？** 预印本没经过同行评议，可以看，但别当定论。
8. **作者有没有过度承诺？** 论文里写“未来可能”，新闻里变成“已经证实”，这是最常见的失真。

## 五、几条实用的怀疑与行动清单

- [ ] 先找原始论文，而不是二手转述；找不到原文的“研究”基本可以跳过。
- [ ] 看摘要里的样本量、对照设置、随访时间，再看结论。
- [ ] 记住一句口诀：**动物实验不等于人体证据，相关不等于因果，统计显著不等于临床有用。**
- [ ] 对“突破”“根治”“改写指南”“科学界震惊”这类词保持警惕。
- [ ] 看到“某补剂或某仪器改善双相症状”，先问有没有随机对照试验、有没有独立重复。
- [ ] 把感兴趣的研究带给医生讨论，**不要据此自行加药、减药或停药**。
- [ ] 关注指南更新（NICE CG185、CANMAT/ISBD、中国双相障碍防治指南），而不是单篇论文。
- [ ] 允许“目前不知道”这个答案存在；医学里很多问题的正确答案就是“证据不足”。

### 容易踩的坑

- **把“机制合理”当成“治疗有效”。** 一个药在理论上应该管用，和它在试验中真的管用，是两件事。
- **把“没有证据”当成“证明无效”。** 这两者不同；有些问题只是还没人好好研究。
- **把“专家说”当成“指南推荐”。** 指南是系统评估后的共识，专家观点是个体经验。
- **把“国外最新”当成“更适合你”。** 人群、医疗体系、药物可及性都不同。

> **什么时候需要联系医生 / 去急诊**
>
> - 因为看到某篇研究而想停药、减药、换药：先联系开药的医生，**不要自行调整**。突然停药可能诱发躁狂、混合状态或抑郁加重。
> - 已经自行停药后出现睡眠明显减少、情绪高涨、冲动行为：尽快精神科就诊，必要时急诊。
> - 出现自杀念头、自伤行为或具体计划：不要独处，立即拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 自行服用来源不明的“补剂”“排毒方案”后出现黄疸、尿色加深、乏力、恶心：立即停用并急诊查肝功能。
