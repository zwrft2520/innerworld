# 3.1 遗传与家族风险

这一页讲三件事：双相障碍为什么在有些家族里更常见，“遗传度”这个常被引用的数字究竟在说什么，以及家里已经有人患病时，自己和孩子该怎么理解这份风险。它适合刚被诊断、正在担心“是不是我传给了孩子”的读者，也适合想弄懂家族史意义的家属。读完你大概能带走一句话：**遗传抬高的是概率，不是写好的结局；目前也没有哪种基因检测能用来预测或确诊双相障碍。**

## 一、医生问家族史，问的是什么

精神科初诊几乎一定会问一句：“家里有没有人得过类似的病？”这不是例行公事。家族研究反复看到同一个现象：双相障碍在一级亲属（父母、子女、亲兄弟姐妹）中比在一般人群中更常见，血缘越近，风险越高。【研究】收养研究提供了另一块拼图——被收养的孩子，患病风险更接近亲生父母一方，而不是养父母一方，说明家族聚集不只是“一起生活、一起吃饭”造成的。

但这句话有三层容易被忽略的意思。

**第一层，“更常见”不等于“一定会”。** 绝大多数有家族史的亲属，终身并不会发展成双相障碍。风险升高是统计层面的事；落到某一个人身上，仍然是“有可能”和“多半不会”并存。把家族史听成“迟早要发作”，既不准确，也会让人过早放弃努力。

**第二层，家族史阴性非常常见。** 相当多的患者是家里第一个得病的人。原因可能是上一辈的症状被当成“脾气差”“更年期”“酒喝多了”，也可能是因为在这些家庭里，环境与偶然因素占了更大比重。所以“家里没人得过”既不能排除双相障碍，也不该让人怀疑“我是不是想多了、在装病”。

**第三层，家族史是诊断线索，不是判决书。** 医生问它，是为了在“单相抑郁还是双相”“要不要考虑环性心境”之间多一个参考；它不能替代病史、病程和现症检查。【指南】

| 你可能听到的说法 | 更准确的理解 |
|---|---|
| “这病会遗传，孩子肯定跑不掉” | 亲属中风险确实升高，但多数亲属并不患病；遗传给的是概率 |
| “家里没人得过，就跟遗传无关” | 家族史阴性很常见，首次发病可以完全没有家族史 |
| “抽个血查基因，就知道会不会得” | 目前没有用于预测或确诊双相障碍的临床基因检测 |
| “孩子变成这样，是家里没教育好” | 养育方式不是双相障碍的病因；家庭氛围影响的是复发与康复 |

## 二、遗传度：一个经常被读错的数字

讨论遗传时绕不开一个词：遗传度。它来自双生子研究——同卵双生子共享几乎全部基因，异卵双生子平均共享一半。研究发现，同卵双生子中“两人都患病”的比例明显高于异卵双生子，这支持遗传对双相障碍有实质贡献。但同卵双生子也常常一个患病、一个不患病，说明基因不是全部。遗传度就是在这个背景下被估算出来的一个数。【研究】

这里有三处极容易读错的地方。

**第一，遗传度是群体指标，不是个人归因。** 它描述的是“在某个特定人群中，患病差异有多少可以归因于基因差异”，而不是“你的病有多少比例来自基因”。把“遗传度很高”翻译成“我这个病是基因决定的”，是典型的概念偷换。同一个疾病，在不同国家、不同年代、不同环境暴露下估出来的遗传度都可能不同——因为环境变了，能被基因解释的那部分比例也就变了。

**第二，遗传度高，不等于不可改变。** 近视的遗传度很高，但我们照样用眼镜矫正它。遗传度描述的是“差异从哪来”，不是“能不能干预”。双相障碍的遗传研究再深入，也不会改变一个事实：治疗有效，而且越早规范治疗，长期结局通常越好。

**第三，遗传度不等于“宿命论”，也不等于“治疗无用”。** 这两件事常被混在一起：有人听到“遗传”就觉得自己没救了，有人听到“遗传”就觉得“那治也没用”。前者忽略了环境与治疗的作用，后者把“病因”和“可治疗性”混为一谈。

理解遗传度的正确姿势是：它告诉你“这个病有明确的生物学基础，不是你不够坚强”，同时提醒你“基因只是剧本的一部分，怎么演还取决于别的条件”。

## 三、多基因：很多小效应叠加，而不是一个“双相基因”

十几年前，媒体常把某个基因说成“抑郁基因”“双相基因”。这类说法大多没有站住。早期候选基因研究样本小、重复性差，很多结果在后来的大样本中没能复制。【待验证】

现在的主流图景是“多基因”：成百上千个常见的基因变异，每一个对风险的作用都极其微小，叠加起来才形成倾向。全基因组关联研究（把大量患者的基因组与健康人比对，寻找统计学上的差异位点）确实找到了一些在不同人群中反复出现的位点，例如与钙通道、神经元结构蛋白相关的基因。【研究】这些发现帮助我们理解“神经元的兴奋性、突触怎么连接”可能参与其中，但距离“解释病因”还有很长的路。

这里要特别提醒两件事。

第一，**位点不等于病因**。找到统计学关联，只说明“这个位置附近可能有点关系”，不说明它怎么致病，更不说明能拿它做治疗靶点。

第二，**多基因风险评分目前不能用于个人**。研究者可以把成千上万个微小效应加成一个分数，在人群层面看到“高分组的患病比例更高”；但这个分数对单个人的区分能力很弱，患者与健康人的分数大量重叠。把它当成“算命”，会同时制造虚假的安心和虚假的绝望。市面上宣称能测“双相基因”的商业检测，多数缺乏临床验证，不建议购买。【待验证】

## 四、遗传不是命运：基因、环境与时机

最有力的一个观察还是来自双生子：基因几乎完全相同，两人却不一定同时患病。这说明基因之外，还有别的东西在决定“发不发病、什么时候发病”。

目前常用的框架是“素质—应激”：遗传给了易感性，环境决定这种易感性在什么时候、以什么形式被“点燃”。常见的触发因素包括睡眠剥夺、跨时区旅行与倒班、重大生活事件、酒精与兴奋剂、产后睡眠碎片化。这些内容在 3.4 有专门展开。

也有研究关注“表观遗传”——基因的序列没变，但基因的表达被环境、应激、睡眠和药物修饰。【待验证】这条线索很有意思，但目前还停留在研究阶段，不能拿来做检测或指导用药。

对患者和家属来说，这套说法有几个实际含义：

- **不必自责，也不必宿命。** 发病不是你“想不开”，也不是“家族诅咒”。
- **能改的部分值得改。** 睡眠、酒精、压力应对、规律复诊，是少数你能直接影响的因素。
- **早识别、早治疗有意义。** 反复发作与延误治疗和更差的长期结局相关；这不是“治不治都一样”。【指南】
- **生育决定可以讨论，不必独自扛。** 有家族史不构成“不能要孩子”的理由，但值得在孕前做一次专业评估。

## 五、给家人和自己的实用清单

- [ ] 复诊时主动说明三代以内的家族史，包括抑郁、自杀、酒精使用、明显情绪高涨的时期，而不只是“确诊过双相”的人。
- [ ] 不把家族史当成“注定”的证据，也不拿它当“反正治不好、不用治”的理由。
- [ ] 计划要孩子之前，安排一次孕前或遗传咨询，把药物、睡眠、产后照护一起谈。
- [ ] 孕期与产后优先保证连续睡眠，安排夜间轮班照护，识别早期信号。
- [ ] 家里有人出现连续多日睡眠需求明显减少、话多停不下来、行为突变，尽早精神科评估，不要等“自己缓过来”。
- [ ] 不购买宣称“测双相基因”“预测孩子天赋”的商业检测，也不据此调整药物。
- [ ] 把“家族里谁有过什么表现”写成几行字带去门诊，比临场回忆可靠。

### 容易踩的坑

- **把“遗传”当成“家教问题”的替身。** 有些家庭为了否认遗传，转而责怪父母管教；这两件事都不是病因解释。
- **把“没有家族史”当成“不用长期治疗”。** 是否需要维持治疗，看的是发作次数、严重度、既往停药后的复发情况，不是家族史。
- **把“基因检测”当成“确诊工具”。** 双相障碍的诊断仍然依靠病史与精神检查，依据 DSM-5-TR 或 ICD-11 的标准。【指南】

> **什么时候需要联系医生 / 去急诊**
>
> - 出现自杀念头、自伤行为，或已经在做计划、交代后事：不要独处，让信任的人陪着，立即拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
> - 家人出现连续数日几乎不睡、话多停不下来、冲动消费或投资、危险驾驶、伤人威胁：尽快精神科急诊评估，必要时拨打 **120** 或 **110**。
> - 产后出现严重失眠、幻觉、妄想、行为紊乱或伤害婴儿的念头：按急症处理，立即急诊。
> - 正在服药期间出现严重手抖、走路不稳、反复呕吐、意识模糊：立即急诊，并带上药盒。
