# 2.3 双相抑郁

这一页讲双相障碍的抑郁相：它和单相抑郁有什么不同，为什么容易被误诊，哪些信号提示需要重新评估。它适合反复抑郁、治疗效果不理想的患者，也适合被告知“只是抑郁症”但心里不踏实的家属。读完后，你应当能整理出有价值的病史线索，并知道抗抑郁药出现异常反应时该怎么处理。

## 一、双相抑郁不只是“心情不好”

双相抑郁的核心是一次重性抑郁发作：持续至少两周，几乎每天大部分时间情绪低落，或对原本喜欢的事失去兴趣，并伴随睡眠、食欲、精力、注意力、自我评价、动作迟缓或坐立不安等变化。【指南】严重时会出现无价值感、反复想到死亡、自杀计划，甚至精神病性症状。

双相抑郁和单相抑郁在症状上有大量重叠，单靠“当下这一刻”很难区分。真正的区别往往藏在**过去**：有没有过轻躁狂或躁狂发作，抑郁是第一次出现在什么年龄，发作是否频繁，家族里有没有双相障碍，产后是否出现过严重情绪问题，吃抗抑郁药后有没有异常兴奋或转躁。

这也意味着，医生需要问的不只是“你现在有多难受”，还要问“你以前有没有过一段完全不同的时期”。很多患者会因为羞耻、遗忘，或认为那段“兴奋期”不是病，而漏掉关键信息。

## 二、双相抑郁常见的“非典型”特征

所谓非典型特征，是指与“典型抑郁”的入睡困难、食欲下降、早醒不完全一样的表现。双相抑郁中较常见的有：

- 睡得很多，仍然起不来，白天嗜睡。
- 食欲增加，尤其想吃甜食或碳水化合物，体重上升。
- 四肢沉重，像灌了铅，想做事情但身体动不了。
- 对拒绝、批评特别敏感，人际关系中小事也会引发强烈反应。
- 情绪反应性保留：遇到好事能短暂开心，但很快又掉下去。
- 抑郁与烦躁、思维加速、活动增多同时出现，形成混合状态。

需要强调的是：**非典型特征提示“要想到双相”，但不能单凭它确诊。** 单相抑郁也可能出现嗜睡或食欲增加；反过来，双相抑郁也可能表现得很“典型”。【研究】这些特征的价值，是提醒医生多问一句，而不是给患者贴标签。

## 三、差别、误诊与抗抑郁药

| 线索 | 更偏向单相抑郁 | 更偏向双相抑郁 |
|---|---|---|
| 起病年龄 | 各年龄段均可 | 较早起病更需警惕 |
| 发作史 | 以抑郁发作为主 | 曾有轻躁狂或躁狂 |
| 睡眠 | 入睡难、早醒常见 | 嗜睡、睡不醒也常见 |
| 发作频率 | 相对稳定 | 反复、频繁，甚至快速循环 |
| 家族史 | 抑郁家族史 | 双相、躁狂、自杀家族史 |
| 治疗反应 | 抗抑郁药相对平稳 | 抗抑郁药后转躁、混合或波动 |
| 产后 | 产后抑郁可能 | 产后精神病或严重情绪波动需警惕 |

这张表只能帮助整理线索，不能代替诊断。最关键的一列其实是“有没有过另一极的发作”。如果从来没有被系统询问过，建议主动补充。

### 误诊的代价

把双相抑郁当成单相抑郁处理，最大的风险不是“药没效”，而是可能让病程更不稳定。双相抑郁患者单用抗抑郁药，可能出现转躁、混合状态、烦躁加剧、睡眠减少或快速循环。【指南】这并不是说抗抑郁药绝对不能用于双相障碍，而是说它需要在明确诊断、联合心境稳定剂、密切监测的前提下由医生决定。

误诊还会带来其他代价：反复换药、反复住院、工作与关系受损、被误解为“想太多”“不配合治疗”。有些患者多年只被当作“难治性抑郁”，直到某次轻躁狂被家属看见，才拼出完整图像。误诊的代价，往往是时间。

### 抗抑郁药转躁：需要知道什么

转躁不是“性格变了”，也不是“药把人吃坏了”这么简单。它是指使用抗抑郁药后，出现持续的情绪高涨、易激惹、睡眠需求减少、话多、活动增多、冲动等躁狂或轻躁狂表现，有时还会出现抑郁与兴奋并存的混合状态。

需要记住三点：

1. **不要自行停药或减药。** 突然停药可能引起撤药反应或情绪波动，应由医生评估后调整。
2. **尽快记录并复诊。** 记录从哪天开始、睡了多久、话和活动是否增多、有没有冲动行为，这些信息对医生判断很重要。
3. **出现精神病性症状或自杀风险时按急症处理。** 不要等到下次预约。

## 四、自杀风险：双相抑郁最需要正视的部分

双相障碍的自杀风险高于一般人群，抑郁相和混合状态尤其需要警惕。【指南】危险信号包括：反复说“活着没意思”“没有我大家会更好”，把重要东西送人，突然安排后事，购买或囤积危险物品，从极度痛苦突然变得异常平静，以及抑郁同时伴随烦躁、冲动、失眠。

家属常担心“直接问自杀会不会提醒他”。现有证据并不支持这种担心；温和、直接地询问反而可能让患者感到被理解。【研究】可以这样问：“你最近有没有想过不想活了？有没有想过怎么做？”如果对方承认有计划或已经准备工具，不要让其独处，立即联系医生或急救。

> **什么时候需要联系医生 / 去急诊**
>
> - 反复出现自杀念头，或已经有具体计划、准备手段。
> - 抑郁同时伴随明显烦躁、坐立不安、失眠、冲动，像“混合状态”。
> - 服用抗抑郁药后突然话多、兴奋、睡得少、脾气变大，或出现幻觉、妄想。
> - 拒绝进食饮水、木僵、意识模糊，或身体状况迅速变差。
> - 有即时自伤、自杀或伤人风险时，立即呼叫 **120**，必要时 **110**；不要让患者独处，移开利器、药物等危险物品。

## 五、就诊准备与常见误区

### 就诊前可以准备的清单

- [ ] 第一次抑郁发作大约在什么年龄，当时持续多久。
- [ ] 有没有过连续几天睡得少却特别有精神、话多、计划多的时期。
- [ ] 有没有人说过你“像变了一个人”“最近太亢奋”。
- [ ] 每次发作前有没有睡眠减少、跨时区、饮酒、停药等诱因。
- [ ] 用过哪些抗抑郁药，用后有没有转躁、烦躁、失眠或冲动。
- [ ] 家族中是否有人得过双相、躁狂、抑郁或自杀。
- [ ] 产后、青春期、更年期前后有没有明显情绪波动。
- [ ] 目前是否有自杀念头、计划，或自伤行为。

### 容易踩的坑

**坑一：只治抑郁，不问另一极。** 这是双相抑郁最常见的漏诊路径。就诊时主动提“有没有过特别兴奋的时期”。

**坑二：把抗抑郁药后的兴奋当成“终于好了”。** 睡眠减少、话多、花钱变多，是需要复诊的信号，不是康复的证据。

**坑三：因为怕转躁就拒绝所有抗抑郁药。** 是否使用、如何使用，需要医生根据发作史、严重度、既往反应决定，不能自行一刀切。

**坑四：把自杀话题当成禁忌。** 直接询问不会“教坏”患者，反而能争取时间。

**坑五：症状一好就停药。** 双相抑郁缓解后仍需维持治疗和复发监测，具体方案由医生决定。
