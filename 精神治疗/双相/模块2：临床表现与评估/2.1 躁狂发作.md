# 2.1 躁狂发作

这一页讲清楚躁狂发作到底是什么样、和“心情特别好”有什么区别、哪些表现提示危险。它适合刚被诊断的患者、正在观察家人的家属，也适合想分清“躁狂”和“轻躁狂”的读者。读完后，你应当能识别躁狂的核心症状，知道什么时候必须联系医生，什么时候要立刻去急诊。

## 一、先看整体：一次躁狂发作的轮廓

躁狂发作不是简单的“情绪高涨”，而是一段时间内情绪、精力、思维、睡眠和行为同时发生明显改变。按 DSM-5-TR 的描述，这种改变通常持续至少一周，几乎每天大部分时间都存在；如果严重到需要住院，则不论是否满一周都可以成立。【指南】

判断的关键不是“他最近很开心”，而是这种状态和本人平时的样子相比，是否出现了**持续、成组、失控**的变化。比如平时谨慎的人突然大量投资，平时话少的人连续几个小时不停地讲，平时睡七小时的人只睡两三个小时仍觉得精力充沛。单个症状可能有其他解释，一组症状同时出现、持续数天，就需要精神科评估。

躁狂的严重度可以很不一样。有的人还能勉强上班，只是明显反常；有的人已经出现幻觉、妄想，无法照顾自己，甚至做出危及生命的行为。**躁狂本身是一种需要医疗处理的状态，不是靠意志力“压一压”就能过去。**【指南】

## 二、七个常见症状群

### 1. 情绪高涨或明显易激惹

情绪高涨表现为异常兴奋、自信、愉快，甚至觉得“什么都难不倒我”。另一种常见表现是易激惹：一点小事就发火，和家人争吵，觉得别人故意针对自己。躁狂并不总是“开心”，愤怒、烦躁、敌意同样可以是核心表现。

### 2. 睡眠需求减少

这里说的是**睡眠需求减少**，不是睡不着。患者可能只睡很少，第二天仍然精力旺盛，不觉得困，也不认为有问题。家属常听到“我根本不累”“睡觉是浪费时间”。如果连续几天几乎不睡，同时话多、活动增多，风险会明显上升。

### 3. 话多、语速快、停不下来

说话比平时多得多，语速快，声音大，别人很难插话。话题可能不断跳转，从工作跳到投资，再跳到童年往事，听者勉强能跟上，患者自己却觉得“思路特别清楚”。严重时会出现“思维奔逸”，即念头一个接一个，语言变得破碎，旁人难以理解。

### 4. 夸大、自我评价过高

患者可能坚信自己能力非凡、马上要发大财、有特殊使命，甚至认为自己拥有超自然能力。轻一些时表现为过度自信、贬低他人、计划宏大；重一些时可能发展为夸大妄想。此时讲道理、摆事实通常无效，争论只会让关系更紧张。

### 5. 活动增多、目标导向行为增加

突然同时启动很多项目，熬夜工作、频繁社交、到处旅行、整理房间到凌晨。活动看似“有目标”，但往往虎头蛇尾，计划不断升级，身体却在被透支。也可能表现为坐立不安、来回走动、无法安静。

### 6. 冲动与冒险行为

这是最需要家属警惕的一组表现：超出承受能力的消费或投资、赌博、危险驾驶、轻率发生性行为、突然辞职、与人冲突、独自远行。患者当下可能觉得“这很正常”“我承担得起”，事后才发现后果严重。冲动行为可能在很短时间内造成难以挽回的损失。

### 7. 精神病性症状

严重躁狂可能出现幻觉或妄想，例如听到有人议论自己、坚信被监视、认为自己有特殊身份。精神病性症状提示病情更重，通常需要住院评估。此时患者可能因为害怕或兴奋而拒绝帮助，家属不要单独与其对抗，应联系医生或急救人员。

| 症状群 | 患者可能怎么说 | 家属可能观察到什么 |
|---|---|---|
| 情绪 | “我状态特别好”“别管我” | 异常兴奋、易怒、哭笑无常 |
| 睡眠 | “我不需要睡” | 连续少睡仍精力旺盛 |
| 言语思维 | “我脑子转得飞快” | 话多、抢话、话题跳跃 |
| 自我评价 | “我马上要干大事” | 夸大计划、听不进劝 |
| 活动 | “我有很多事要做” | 同时开很多项目、坐不住 |
| 冲动 | “这点钱不算什么” | 乱花钱、冒险驾驶、轻率性行为 |
| 精神病性 | “他们在监视我” | 对空说话、极度警觉、坚信被害 |

## 三、严重度：从“需要调药”到“必须急诊”

躁狂的严重度不是只看“高不高兴”，而要看**现实检验、冲动控制、自理能力和安全风险**。下面的分级只是帮助理解，不能替代医生的判断。

| 严重度 | 常见表现 | 建议处理 |
|---|---|---|
| 轻度至中度 | 睡眠减少、话多、计划增多，但仍能部分工作，听劝 | 尽快联系精神科医生，调整评估与治疗 |
| 明显影响功能 | 无法工作、家庭冲突升级、明显乱花钱、驾车冒险 | 当日或尽快就诊，必要时家属陪同 |
| 重度 | 妄想、幻觉、极度激越、拒绝进食饮水、无法自理 | 立即急诊，必要时呼叫 120 |
| 危急 | 伤人风险、自杀风险、危险行为、走失、衰竭 | 立即呼叫 120，必要时 110 |

需要特别说明：**“还能上班”不等于“不严重”。** 有些患者靠意志力维持表面正常，回家后却完全失控。家属描述“他最近像变了一个人”，往往比患者自己的判断更接近真实情况。

## 四、家属能做什么，不能做什么

家属最重要的任务不是说服患者“你有病”，而是**降低刺激、减少伤害、把患者带到专业帮助面前**。在躁狂急性期，讲道理、翻旧账、强行辩论通常会火上浇油。

- [ ] 减少环境刺激：避免大型聚会、长时间争论、多人同时劝说。
- [ ] 保管好银行卡、现金、车钥匙、证件和危险物品，必要时设置支付限额。
- [ ] 不嘲笑、不刺激、不激怒，也不轻易承诺无法兑现的事。
- [ ] 用简短、具体的句子表达关心，例如“我很担心你，今晚我陪你去医院”。
- [ ] 记录睡眠、言语、花费、活动和冲动行为，就诊时交给医生。
- [ ] 联系患者信任的医生，询问是否需要提前复诊或急诊评估。
- [ ] 如果患者愿意，可由一两位熟悉的家属陪同，避免多人围堵。
- [ ] 家属也要轮换休息，长期照护需要备用方案。

不要做的事同样重要：不要自行给患者加药、减药或停药；不要用“你再这样我就走”反复威胁；不要在患者持械、极度激动或明确威胁伤人时独自上前；不要因为“家丑不可外扬”而拖延就医。

> **什么时候需要联系医生 / 去急诊**
>
> - 连续几天几乎不睡，仍异常兴奋、话多、活动不停。
> - 出现幻觉、妄想、坚信被监视或迫害，无法正常交流。
> - 有伤人、自杀、危险驾驶、纵火、跳楼等风险。
> - 乱花钱到严重影响家庭生活，或准备做出不可逆的重大决定。
> - 拒绝进食饮水、极度衰竭、意识模糊、高热、肌肉僵硬。
> - 以上情况不要等待“自己冷静下来”，立即联系精神科急诊；有即时危险时呼叫 **120**，必要时 **110**。

## 五、容易踩的坑

**坑一：把躁狂当成“状态好”。** 真正的躁狂往往伴随睡眠需求减少、冲动和功能受损。只是心情好、效率高，不足以诊断躁狂。

**坑二：只盯着“高兴”，忽略易激惹。** 不少躁狂发作以愤怒、争吵、攻击性为主，家属容易误以为“脾气变差”。

**坑三：等“这阵子过去”。** 躁狂可能持续数周，越拖越难处理。冲动行为的代价往往发生在等待期间。

**坑四：用争吵证明患者有病。** 急性期争论只会增加敌意。把目标从“说服他”改成“保证安全、尽快就医”。

**坑五：症状缓解后立刻停药。** 躁狂缓解不等于疾病消失，维持治疗和复发预防需要与医生共同决定。
