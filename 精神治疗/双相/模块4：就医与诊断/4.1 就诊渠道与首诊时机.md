# 4.1 就诊渠道与首诊时机

这一页讲怀疑双相障碍时该去哪里看、什么情况要立即去急诊、如何选择适合自己的医生。它适合第一次求助、不知道该挂精神科还是心理科的患者，也适合面对家人情绪失控却不知道往哪送的家属。读完后，你应当能根据紧急程度选对渠道，少走弯路，也不把急症拖成门诊问题。

## 一、先判断：这是门诊问题，还是急症

双相障碍的求助场景大致分三类：**需要立即处理的安全风险、需要尽快评估的明显症状、需要长期随访的稳定期管理。** 三类对应的渠道不同，先判断紧急程度，比先纠结“挂哪个专家”更重要。

如果患者有明确的自杀计划、正在自伤、威胁伤人、持械、纵火、跳楼跳桥、极度兴奋到无法控制、出现幻觉妄想并因此恐惧或攻击、连续多日不睡不食、意识模糊或高热肌肉僵硬，这些都不是“等明天门诊”的情况。应立即呼叫 **120**，必要时拨打 **110**，或由家属陪同前往最近医院的急诊。【指南】

如果没有即时危险，但已经出现持续数天的睡眠减少、话多、冲动消费、易怒、抑郁加重或功能明显下降，应尽快看精神科，而不是先观察几周。双相障碍越早识别、越早规范评估，越有可能减少发作带来的功能损害。

## 二、不同渠道分别能做什么

| 场景 | 更适合的渠道 | 大致时机 |
|---|---|---|
| 自杀计划、伤人风险、严重兴奋或木僵 | 医院急诊、120/110 | 立即 |
| 首次出现疑似躁狂/轻躁狂 | 精神科门诊 | 尽快，数日内 |
| 抑郁反复、治疗不理想 | 精神科门诊 | 尽快预约 |
| 病情稳定、需要开药和随访 | 精神科门诊、社区精防 | 按医嘱 |
| 只有情绪困扰、无诊断需求 | 心理咨询/心理治疗 | 可预约，但不能替代诊断 |
| 想先了解资源、情绪支持 | 12356 心理援助热线 | 随时 |

**精神科门诊**是双相障碍诊断和处方的主要入口。精神科医生有诊断权和处方权，能安排必要的化验、心电图和量表评估，也能判断是否需要住院。第一次就诊不一定要找“最有名的专家”，能挂上号、能把病史讲清楚、能持续随访，往往更重要。

**急诊**处理的是即时安全风险。急诊医生会先保证生命安全、控制严重激越或精神病性症状，再决定是否留观或转精神科病房。不要因为“怕被贴标签”而拒绝急诊；也不要指望急诊一次就完成完整的双相诊断，急诊的首要任务是稳住危险。

**社区精神卫生服务**在部分地区承担随访、服药管理、康复指导和危机转介。各地资源差异很大，具体能提供什么，以当地社区卫生服务中心或精防机构公布的信息为准。社区医生不一定做首次诊断，但可以成为长期管理的支点。

**心理咨询/心理治疗**适合处理压力、关系、情绪调节和康复适应，但心理咨询师通常不能做医学诊断，也不能开药。如果咨询中发现明显的躁狂、精神病性症状或自杀风险，应转介精神科。把心理咨询当作“替代精神科”的路径，可能耽误诊断。

**12356 心理援助热线**可以提供情绪支持、危机干预和资源指引，但不能替代面诊、诊断和处方。适合在不知道该去哪、夜间情绪崩溃、需要有人听你说时使用；有即时身体危险时，仍应拨打 120。

## 三、什么情况要立即就诊

以下情况建议当日或尽快就诊，不要等“自己好起来”：

- 睡眠需求明显减少，连续数天仍精力旺盛，话多、活动增多。
- 突然大额消费、投资、赌博、危险驾驶、轻率性行为。
- 情绪异常高涨或易怒，与家人同事冲突明显升级。
- 抑郁加重，出现“活着没意思”、安排后事、赠送物品。
- 出现幻觉、妄想、坚信被监视或迫害。
- 服药后出现严重皮疹、高热、肌肉僵硬、意识改变、走路不稳。
- 饮酒或使用兴奋剂后情绪、睡眠、行为明显失控。

## 四、如何选择医生

选择医生时，可以看以下几个实际因素，而不是只看头衔：

1. **是否有精神科执业资质。** 双相障碍的诊断和处方需要精神科医生，不是所有“心理专家”都可以。
2. **是否有心境障碍诊疗经验。** 可以问“您平时看双相障碍多吗”，不必觉得冒犯。
3. **是否能持续随访。** 双相障碍需要长期观察，固定医生比每次换人更容易看清病程。
4. **沟通是否让你能说清楚。** 好医生会追问睡眠、冲动、发作史，也会解释为什么问这些。
5. **是否愿意纳入家属信息。** 在患者同意的前提下，家属的观察对诊断很重要。
6. **就诊是否方便。** 长期复诊的可行性，比一次“名医”更重要。

如果对诊断有疑问，可以寻求第二意见。第二意见不是“不信任医生”，而是对复杂疾病负责。带上既往病历、用药记录和家属观察，比只凭一次谈话更容易得到有价值的意见。

## 五、首诊前可以准备的清单

- [ ] 证件、医保卡、既往就诊卡和病历。
- [ ] 正在服用的药物清单，包括剂量、开始时间和副作用。
- [ ] 最近两周的睡眠、情绪、活动、花钱记录。
- [ ] 第一次发作的大致时间、持续多久、当时的表现。
- [ ] 家族中是否有双相、抑郁、自杀或精神疾病史。
- [ ] 饮酒、吸烟、咖啡因和其他物质使用情况。
- [ ] 一位了解情况的家属或朋友，必要时陪同。
- [ ] 想问医生的问题，写在纸上，避免当场忘记。

> **什么时候需要联系医生 / 去急诊**
>
> - 有自杀计划、正在自伤，或已经准备好危险物品。
> - 威胁伤人、持械、纵火、跳楼跳桥，或严重失控。
> - 出现幻觉、妄想并因此极度恐惧、拒食、拒水。
> - 连续多日几乎不睡，伴衰竭、意识模糊、高热或肌肉僵硬。
> - 以上情况立即呼叫 **120**，必要时 **110**；不要独自运送有暴力风险的人。

## 六、容易踩的坑

**坑一：只找心理咨询，不做精神科评估。** 咨询可以帮助你，但不能替代诊断和处方，尤其是出现躁狂或精神病性症状时。

**坑二：认为“不严重就不用看”。** 轻躁狂也可能带来难以挽回的财务、法律和关系后果，早评估更划算。

**坑三：频繁换医生。** 双相障碍需要纵向观察，频繁更换会让每个人只看到片段。

**坑四：因为病耻感拖到急诊。** 越早求助，越可能在后果发生前把风险降下来。

**坑五：把 12356 当成急诊。** 热线能提供支持，但不能替代 120 和医院急诊。
