# 4.2 初诊准备与病史采集

这一页讲第一次看精神科前可以准备什么，以及医生问睡眠、花钱、冲动、性行为、家族史时到底在了解什么。它适合即将初诊的患者，也适合要陪家人就诊的照顾者。读完后，你应当能整理出一份具体、可用的病史时间线，而不是只带着一句“我最近情绪不好”走进诊室。

## 一、初诊不是考试，准备是为了少漏信息

精神科初诊通常时间有限，医生要在较短时间里了解现在的症状、过去的发作、功能变化、用药和风险。患者常因为紧张、羞耻或不知道什么重要，只讲了最近几天；家属则容易把多年积怨一股脑倒出来。两种都不理想。

更好的做法是提前写一份“病史摘要”：按时间顺序列出几次关键发作，每次持续多久、以什么表现为主、有没有诱因、有没有造成后果、用过什么治疗。不需要写成作文，几行字、一张表就可以。医生会根据它继续追问，而不是指望你一次说全。

## 二、带什么去

- 身份证件、医保卡、既往就诊卡。
- 既往病历、出院小结、检查报告、心理测评结果。
- 正在服用的所有药物：药名、剂量、每天怎么吃、从什么时候开始。
- 保健品、中草药、助眠药、减肥药，也要列出来。
- 最近两周的睡眠、情绪、活动、花钱记录。
- 一位了解你情况的家属或朋友，必要时陪同。
- 你想问的问题清单。
- 如果是复诊或转诊，带上前一位医生的诊断和用药调整记录。

如果记不清药名，可以拍药盒照片；如果记不清时间，可以查手机支付记录、聊天记录、就诊记录来帮助回忆。具体到“哪天开始睡不好”“哪个月刷了多少信用卡”，比“最近一直不好”有用得多。

## 三、医生会问什么，为什么问

| 问题 | 医生想了解什么 | 可以怎么准备 |
|---|---|---|
| 第一次不对劲是什么时候 | 起病年龄、早期表现 | 问家人、翻旧照片和记录 |
| 有没有特别兴奋的时期 | 轻躁狂/躁狂史 | 回忆睡眠、话多、花钱、冲动 |
| 每次持续多久 | 发作持续时间与诊断阈值 | 按时间线列出大致天数 |
| 有没有诱因 | 睡眠、应激、产后、药物 | 记录发作前一周的变化 |
| 平时功能怎么样 | 工作、学习、关系、自理 | 用具体事例说明变化 |
| 有没有自杀或伤人念头 | 风险评估 | 如实说，医生会评估安全 |
| 用过什么药，反应如何 | 治疗史、转躁史、副作用 | 带药盒、处方、病历 |
| 家族里有没有类似情况 | 遗传与家族聚集 | 问父母、长辈，不猜测 |

关于睡眠，医生不只会问“睡几个小时”，还会问“睡了以后是否觉得恢复”“是否比平时明显少睡仍精力旺盛”。关于花钱，不只是问“有没有乱花钱”，还会问是否超出承受能力、是否隐瞒、是否造成债务。关于性行为，医生问的是冲动、风险和保护措施，不是评判道德。关于物质使用，酒精、大麻、兴奋剂、镇静催眠药都可能影响情绪和诊断，需要如实说。

## 四、把发作讲成一条时间线

可以按下面的结构整理：

1. **起点**：第一次明显异常大约在什么年龄、什么阶段（上学、工作、产后、换城市）。
2. **表现**：那一阵子睡眠、情绪、话量、活动、花钱、脾气、性行为、社交有什么变化。
3. **持续时间**：几天、几周还是几个月；是否几乎每天都有。
4. **功能**：还能不能上班上学，有没有请假、休学、辞职、住院。
5. **后果**：有没有债务、冲突、违法、伤害自己或别人。
6. **间隔**：两次发作之间是完全正常，还是有残留的疲劳、注意力差、情绪脆弱。
7. **治疗**：看过谁、吃过什么、有没有转躁、有没有停药。

如果只能记住一件事，就记住：**具体行为、持续时间、与平时的差别、造成的后果。** 例如“去年五月连续五天只睡两小时，讲话停不下来，刷信用卡买了两台电脑，和家人大吵，后来自己好了”比“去年有过一段亢奋”信息量大得多。

## 五、家属怎么补充，才不变成控诉

家属的观察对诊断很重要，尤其是患者自己不记得或不愿说的轻躁狂。补充时尽量说事实，不说人格评价：

- 把“他就是自私”换成“他以前很节省，这半年开始频繁请客，还借了钱”。
- 把“她疯了”换成“她连续三晚不睡，说要完成一个大项目，讲话比平时快很多”。
- 把“他不听话”换成“他拒绝复诊，说自己没病，我们不知道该怎么办”。

家属也可以带自己的记录：睡眠时间、消费记录、聊天截图、请假记录、既往住院材料。不要在诊室里翻旧账、互相指责，这会让患者更防御。可以提前和患者约定：“今天只讲事实，不吵架，目的是把病看清楚。”

如果患者不愿意让家属旁听，医生通常会先单独询问患者，再在患者同意的情况下获取家属信息。保密和安全需要平衡；如果存在明确的自杀或伤人风险，医生会按专业和法律要求处理。

## 六、初诊提问与常见误区

### 初诊时可以问医生的问题

- [ ] 目前最可能的诊断是什么？还有哪些可能？
- [ ] 需要做哪些检查来排除躯体原因？
- [ ] 这次是躁狂、轻躁狂、抑郁还是混合状态？
- [ ] 有没有自杀或冲动风险，需要怎么防范？
- [ ] 目前建议的治疗包括哪些部分？
- [ ] 药物可能有哪些副作用，出现什么情况要联系你？
- [ ] 下次复诊什么时候，期间出现什么情况要提前来？
- [ ] 家属可以怎样配合，哪些做法会帮倒忙？

> **什么时候需要联系医生 / 去急诊**
>
> - 初诊前或等待就诊期间出现自杀念头、计划或自伤行为。
> - 出现幻觉、妄想、严重激越、伤人威胁，或无法照顾自己。
> - 连续多日几乎不睡，伴话多、冲动、行为失控。
> - 服药后出现高热、肌肉僵硬、意识改变、严重皮疹或走路不稳。
> - 有即时危险时立即呼叫 **120**，必要时 **110**；不要为了“等初诊”而拖延。

### 容易踩的坑

**坑一：只讲最近几天。** 双相障碍的诊断依赖纵向病程，过去的轻躁狂往往是关键。

**坑二：因为羞耻隐瞒性行为、物质使用或自杀念头。** 这些信息直接影响诊断和安全评估，医生需要的是事实，不是道德评判。

**坑三：家属在诊室里争吵。** 这会让患者更防御，也让医生难以获取信息。提前分工，一人主诉、一人补充。

**坑四：带着“必须确诊双相”的目标去。** 诊断需要排除其他可能，带着预设答案可能误导信息收集。

**坑五：忘记带药盒和病历。** 药物名称、剂量和既往反应是治疗决策的重要依据。
