# 7.2 rTMS与tDCS

在药物和电休克之外，还有两类“用物理方式调节大脑”的治疗：重复经颅磁刺激（rTMS）和经颅直流电刺激（tDCS）。它们不需要麻醉，不用住院，听起来比 ECT “温和”，因此常被寄予很高期待。但温和不等于适合所有人，也不等于可以替代药物。这一页讲清它们是什么、对双相抑郁的证据到哪一步、转躁风险有多大，以及为什么现在还不是常规首选。读完你能判断：医生提到这两种治疗时，是在什么位置上考虑它们。

## 一、rTMS 是什么：不用麻醉的“磁刺激”

rTMS 的做法是：把一个磁线圈放在头皮特定位置，通过快速变化的磁场在大脑皮层诱发微弱电流，从而调节局部神经活动。治疗时人是清醒的，坐在治疗椅上，不需要麻醉，也不需要肌肉松弛。治疗结束后可以正常活动，通常不需要人陪。

它和 ECT 的区别很关键：ECT 是诱发一次全面癫痫样放电，需要麻醉，起效快，对严重躁狂、紧张症、高自杀风险有明确地位；rTMS 是局部、清醒、温和的皮层调节，起效通常以周计，对急性危险状态没有 ECT 那样的快速作用。**把 rTMS 当成“更安全的 ECT”是误解，它们的适应证和强度不在一个层级。**

tDCS 则是用很弱的直流电，通过头皮电极改变神经细胞的兴奋性。它更简单、更便宜，但证据也更少，目前主要用于研究场景，临床上远不如 rTMS 成熟。

## 二、证据到哪一步：有效信号，但不是常规首选

rTMS 在单相抑郁中的证据相对多，在双相抑郁中的研究则少得多：样本量小、设计不完全一致、随访时间短。已有的一些随机对照试验和荟萃分析提示，rTMS 对双相抑郁可能有效，尤其是作为药物的辅助治疗；但结果并不一致，也不是所有指南都把它列为一线。【研究】

CANMAT/ISBD 2018 把 rTMS 列为双相抑郁在药物治疗效果不佳时可以考虑的选项之一，位置在 ECT 之后、常规药物之前或之间，取决于具体病情。【指南】换句话说：**它不是起点，也不是“没药可吃才用”，而是介于两者之间的一个备选。** 对不能耐受药物副作用、或药物效果不理想但又不至于做 ECT 的人，它可能有用。

还有几点现实限制：rTMS 通常需要连续多天到诊所治疗，前后数周；效果不是立竿见影，常在第 2 到 4 周才逐渐显现；停止治疗后，如果不继续药物维持，复发并不少见；不同医院设备、方案和经验差别较大；费用和可及性因地区而异。

## 三、转躁风险：低，但不是零

这是双相患者最该问的问题。rTMS 确实可能诱发轻躁狂或躁狂，文献中有个案报告，也有人群研究提示风险存在但不高。【研究】机制上可以理解：它和抗抑郁药一样，是在“往上托”情绪，双相的大脑可能被推过头。

所以做 rTMS 时，监测和用抗抑郁药时一样重要：睡眠时长、话量、活动量、花钱、易怒、冲动，都要记录。如果治疗期间出现“睡得少但精力好、话变多、停不下来”，要立刻告诉治疗团队，而不是觉得“治疗起效了，我终于有精神了”。

风险高低和几个因素有关：双相 I 型、既往有药物诱发转躁史、混合特征、快速循环、没有同时使用心境稳定剂。**做 rTMS 不等于可以停掉心境稳定剂**，这一点常被忽略。多数研究里，rTMS 是加在原有治疗之上的，而不是替代。

## 四、谁适合、谁要慎重

| 情况 | 是否适合考虑 rTMS | 说明 |
|---|---|---|
| 双相抑郁，药物效果不佳 | 可以考虑 | 通常作为辅助，不是单打独斗【指南】 |
| 不能耐受药物副作用 | 可以考虑 | 仍需评估转躁风险 |
| 严重抑郁伴精神病性症状 | 不作为首选 | ECT 更合适 |
| 急性躁狂 | 证据不足 | 不用 rTMS 控制躁狂 |
| 高自杀风险、需要快速起效 | 不作为首选 | 起效以周计，来不及 |
| 有癫痫史、颅内金属植入物 | 需严格评估 | 可能不适合，由医生判断 |
| 孕期 | 谨慎 | 数据有限，需多学科评估 |
| 混合状态、快速循环 | 谨慎 | 转躁和病情波动风险更高 |

绝对禁忌和相对禁忌由医生根据设备说明和个人情况判断。植入式心脏起搏器、耳蜗植入、颅内电极、近期脑卒中或心肌梗死、未控制的癫痫、严重头痛病史，都需要提前说明。治疗时通常要戴耳塞，因为磁线圈工作时会发出较响的敲击声，长时间暴露可能影响听力。

## 五、tDCS：证据更少，别急着买家用设备

tDCS 的原理是用很弱的电流改变皮层兴奋性，设备便宜、操作简单，因此网上出现了大量“家用抑郁治疗仪”。这里需要非常明确地说：**目前 tDCS 对双相抑郁的证据很有限，不足以支持自行购买、自行使用。**

已发表的研究多为小样本、短疗程，结果不一致；对双相的专门研究更少；刺激位置、电流强度、疗程都缺乏统一标准；长期效果和转躁风险也没有足够数据。家用设备还带来额外风险：电极放置不当可能造成皮肤灼伤，电流不稳定可能引发不适，使用者往往同时吃药却不告诉医生，出了问题也难以追溯。【待验证】

如果医生在正规医疗机构建议 tDCS，通常是在研究或特定临床条件下，有明确的评估和随访。除此之外，不建议自己买设备“试试看”。省下的钱和避免的风险，比“可能有用”的期待更实在。

## 六、流程、花费、急诊边界与常见问题

rTMS 的典型流程是：精神科评估 → 确认适应证和禁忌 → 签知情同意 → 连续多天到院治疗 → 定期评估情绪、睡眠、认知和副作用 → 疗程结束后进入维持方案。治疗本身不痛，但会有敲击感、头皮发麻，部分人治疗后头痛或头皮不适。

可以照做的清单：

- [ ] 治疗前把所有的药、植入物、癫痫史、偏头痛史、怀孕可能告诉医生。
- [ ] 确认治疗期间继续原有的心境稳定剂，不自行减停。
- [ ] 每次治疗前后记录睡眠时长和情绪，尤其是睡眠需求减少。
- [ ] 治疗期间避免熬夜、跨时区旅行、大量咖啡因和酒精。
- [ ] 出现头痛、耳鸣、头晕、记忆变差，及时告诉治疗团队。
- [ ] 不因为“做了 rTMS”就放松复诊和药物管理。
- [ ] 对家用 tDCS 设备保持警惕，不自行购买使用。

> **需要立即联系医生或去急诊：**
> - 治疗中或治疗后出现抽搐、意识丧失；
> - 剧烈头痛、呕吐、视物模糊、一侧肢体无力；
> - 治疗后情绪突然异常高涨、整夜不睡、冲动消费或行为失控；
> - 出现自杀念头、自伤行为；
> - 头皮灼伤、水疱、持续疼痛；
> - 心悸、胸痛、晕厥。
>
> **尽快联系治疗团队：**
> - 头痛、头皮不适持续超过一天；
> - 耳鸣或听力变化；
> - 记忆、注意力明显下降；
> - 情绪低落加重，或出现混合症状；
> - 治疗费用、疗程安排与预期不符，想调整方案。

### 常见问题

**“rTMS 能替代药物吗？”** 多数情况下不能。它常作为辅助治疗，原有药物通常要继续。适不适合减药，要由医生在疗程结束后评估。

**“rTMS 比 ECT 安全，是不是应该先做 rTMS？”** 取决于病情。高自杀风险、紧张症、严重躁狂需要快速起效时，ECT 更合适；病情相对稳定、药物效果不佳时，rTMS 可以作为备选。安全性和有效性要一起看。

**“做一次就能好吗？”** 不能。rTMS 通常需要连续多次，效果逐渐累积，停止后还可能复发。把它当成一个疗程，而不是一次性的“修理”。

**“tDCS 家用仪靠谱吗？”** 目前证据不足，不建议自行购买使用。正规研究中的 tDCS 有严格参数和监测，和网上卖的家用设备不是一回事。
