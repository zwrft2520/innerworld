# 7.3 光照治疗、睡眠剥夺与补充剂证据

在药物和心理治疗之外，光照治疗、睡眠剥夺和各类补充剂是患者最常自己尝试的三类方法。它们有一个共同点：听起来“自然、无害、可以自己来”，但对双相障碍的人来说，恰恰可能因为“自己来”而诱发转躁。这一页讲清每种方法的证据到什么程度、可能带来什么好处、风险在哪，以及为什么它们都不能替代药物。读完你能分辨：哪些值得和医生讨论，哪些应该直接放弃。

## 一、为什么它们只能“辅助”

双相障碍的核心治疗是心境稳定剂、抗精神病药和心理社会干预。光照、睡眠调整、营养补充之所以被归为“辅助”，不是因为它们没用，而是因为：**证据强度不足以单独撑起治疗，作用幅度通常中等，而且对双相患者有特殊的“转躁”风险。**

这一点和单相抑郁不同。单相抑郁的人做光照治疗、熬一夜，最坏的结果是没效果；双相障碍的人做同样的事，可能把情绪推向轻躁狂甚至躁狂。睡眠减少本身就是躁狂的早期信号，也是诱因之一。所以这类方法在双相里必须“有人看着做”，而不是“网上看到就试”。

还有一层现实：补充剂市场几乎没有监管，标签上的成分和实际含量可能不符，和处方药的相互作用也常被忽略。**“天然”不等于“安全”，更不等于“可以和药一起吃”。**

## 二、光照治疗：证据、做法与转躁

光照治疗的原理是模拟自然光，通过眼睛影响生物钟和情绪调节系统。它在季节性情感障碍中的证据比较充分，在非季节性的双相抑郁中也有一些研究支持，常作为药物的辅助。【研究】部分指南把它列为双相抑郁的辅助选项，但证据质量参差，研究样本通常不大。【指南】

做法上，通常是在早晨使用专门的光疗设备，坐着接受一段时间的光照，期间可以看书、吃早饭，但不要直视光源。具体设备、时长和时段由医生指导，不建议自己买一台“看着亮”的灯就用。设备应当带紫外线过滤，避免晒伤和眼损伤；不要用普通台灯、浴霸或太阳光凑合。

| 方面 | 说明 |
|---|---|
| 可能获益 | 改善抑郁情绪、睡眠节律和精力，尤其对季节性加重的人 |
| 证据强度 | 中等，研究质量不一，双相专门研究较少【研究】 |
| 主要风险 | 诱发轻躁狂或躁狂、眼疲劳、头痛、皮肤光敏反应 |
| 不适合的人 | 视网膜疾病、光敏性疾病、正在用光敏药物的人 |

转躁是光照治疗最需要警惕的问题。研究里确实有诱发轻躁狂的报告，尤其在双相 I 型、没有同时使用心境稳定剂、或光照时间安排在傍晚的人身上。【研究】所以治疗期间要记录睡眠和情绪，一旦出现“睡得少但精力好、话变多、停不下来”，要立刻告诉医生。**不要因为“这是自然疗法”就放松监测。**

光敏风险也常被忽略。某些药物（如部分抗生素、利尿剂、维 A 酸类、某些抗精神病药和抗抑郁药）会让皮肤和眼睛对光更敏感；红斑狼疮、卟啉病等疾病也属于光敏性疾病。开始前把这些情况告诉医生。

## 三、睡眠剥夺：起效快，也最容易“翻车”

睡眠剥夺（也叫觉醒治疗）是指有意减少或取消一晚睡眠，用来快速改善抑郁。它的特点是**起效极快**：有些人一夜不睡，第二天抑郁就明显减轻，效果在几小时内出现，比任何抗抑郁药都快。【研究】

但它的缺点同样突出：**效果短暂**，补一觉后往往回落；**转躁风险高**，尤其在双相障碍中，睡眠剥夺本身就是诱发躁狂的经典因素；**操作不当有害**，连续多日不睡可能导致极度疲劳、注意力下降、判断力受损，甚至诱发精神病性症状。

因此，睡眠剥夺在双相抑郁里绝不是“自己在家熬一晚”的方法。正规做法通常是在医院或严密随访下进行，配合心境稳定剂、随后安排睡眠相位前移（把入睡和起床时间整体提前），并密切监测转躁。即便如此，它的证据仍有限，不属于常规一线治疗。【待验证】

需要特别提醒：**如果已经连续几天睡得很少、却越来精神，那不是“治疗起效”，而可能是转躁的开始。** 这时要做的是联系医生，而不是继续“保持这个状态”。

## 四、Omega-3 与其他补充剂

Omega-3 脂肪酸（尤其是 EPA）是研究最多的补充剂之一。一些随机对照试验和荟萃分析提示，它可能对抑郁症状有轻度改善，作为辅助治疗时作用不大但相对安全；也有研究没有发现明显效果，结果并不一致。【研究】它**不能替代心境稳定剂**，对躁狂没有治疗作用，也不能用来“预防复发”。

其他常见补充剂的证据更弱：

| 补充剂 | 证据强度 | 可能的获益 | 主要风险 |
|---|---|---|---|
| Omega-3（EPA 为主） | 中等偏弱，结果不一致 | 辅助改善抑郁症状 | 高剂量可能增加出血风险，与抗凝药同用需谨慎 |
| N-乙酰半胱氨酸 | 弱，初步研究 | 辅助改善抑郁、冲动 | 胃肠道不适，长期安全性数据不足 |
| 维生素 D | 取决于是否缺乏 | 缺乏者补充有益骨骼和整体健康 | 过量可致高钙血症 |
| 叶酸 | 弱，缺乏者有意义 | 缺乏者辅助改善情绪 | 一般安全，需注意与某些药物相互作用 |
| 圣约翰草 | 不推荐 | 无 | 诱导肝酶、降低多种药物浓度、血清素综合征、诱发转躁 |
| SAMe | 不推荐自行使用 | 研究集中在单相抑郁 | 可能诱发躁狂，与抗抑郁药合用风险更高 |

圣约翰草（贯叶连翘）值得单独说：它是很强的肝酶诱导剂，会让避孕药、抗凝药、部分抗精神病药和免疫抑制剂的效果下降；和 SSRI 类抗抑郁药合用可能引起血清素综合征；本身也可能诱发转躁。**在双相障碍里，它不是一个“温和的草药”，而是一个需要避开的相互作用源。**

褪黑素常被用来调整睡眠时相，对倒时差可能有帮助，但对双相复发预防的证据不足，且可能与部分药物相互作用。想用的话，先问医生。

## 五、怎么安全尝试：清单

- [ ] 先和医生说明想尝试什么、为什么想试、期望是什么。
- [ ] 确认它不会和正在吃的药相互作用（包括避孕药、抗凝药）。
- [ ] 确认自己目前不是混合状态、快速循环期，或近期有转躁。
- [ ] 从低强度、短时间开始，不追求“越强越好”。
- [ ] 同时坚持原有药物，不因为“加了新方法”就减药。
- [ ] 每天记录睡眠时长、情绪、精力、话量和冲动。
- [ ] 设定停止规则：出现转躁信号、睡眠明显减少、情绪异常高涨，立即停并联系医生。
- [ ] 不购买来源不明、宣称“根治双相”的产品。
- [ ] 孕期、哺乳期、肝肾功能不全、正在抗凝治疗，先咨询医生。

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊或拨打 120：**
> - 光照或睡眠剥夺后出现整夜不睡、话多、冲动消费、行为失控（转躁）；
> - 出现自杀念头、自伤行为；
> - 高热、大汗、肌肉抽动、意识改变（警惕血清素综合征，尤其合用圣约翰草或多种抗抑郁药）；
> - 剧烈眼痛、视力突然下降、皮肤大面积红肿水疱（光损伤或光敏反应）；
> - 心悸、胸痛、晕厥。
>
> **尽快联系医生：**
> - 情绪明显转向兴奋、易怒，睡眠需求减少；
> - 抑郁加重，或出现混合症状；
> - 头痛、眼疲劳、皮肤发红持续不缓解；
> - 准备开始或停止任何补充剂；
> - 正在服用抗凝药、避孕药、抗癫痫药，想加补充剂；
> - 计划怀孕、已怀孕或哺乳。

### 常见问题

**“光照治疗能代替抗抑郁药吗？”** 不能。它是辅助手段，证据强度不足以单独治疗双相抑郁，也不能替代心境稳定剂。

**“熬一夜真的能治抑郁吗？”** 有些人会短暂好转，但效果通常只维持到下一次睡眠，而且转躁风险高。不要把“不睡”当成自助疗法。

**“Omega-3 是不是多吃点更好？”** 不是。研究用的剂量不等于“越多越好”，高剂量可能增加出血风险，与抗凝药同用尤其要小心。

**“保健品是天然的，应该比药安全吧？”** 不一定。天然不等于无害，圣约翰草就是典型例子：它会改变多种药物的浓度，还可能诱发转躁。

**“我能不能只靠光照和运动，不吃药？”** 对少数轻症、稳定期的人，医生可能会讨论减少药物负担，但这必须建立在充分评估和随访之上。自行停药的风险通常远大于收益。
