# 9.3 锂中毒

> 这一页写给所有正在吃锂盐的人，和帮他们管药的家属。锂盐是双相维持治疗里很重要的药，但它有一个特点：**有效和中毒之间的距离比较近**。发烧、拉肚子、吃得太淡、加了别的药，都可能让血里的锂升上去。读完这一页，你会知道哪些情况会让血锂升高、轻中重度中毒各长什么样、出现什么必须立刻查血锂、在到急诊之前能做什么和绝对不能做什么，以及平时怎么防。

## 一、为什么锂盐容易中毒

锂盐和很多药不一样，它在体内的“安全走廊”比较窄。医生给你定的目标血锂范围，是靠定期抽血维持的，不是一个固定不变的数。

几个基本事实：

- **锂几乎全部由肾排出**。肾功能好，锂排得快；肾功能差、脱水，锂就积在体内。
- **身体缺钠时，肾会把锂留下来**。因为锂和钠在肾小管里“走同一条路”，身体以为缺盐，就会回收钠，顺手把锂也回收了。所以吃得太淡、出汗太多、拉肚子，都可能让血锂升高。
- **很多常见药会影响锂的排出**，包括一些利尿剂、部分降压药、某些止痛药和抗生素。
- **老年人风险更高**：肾功能随年龄下降，体重轻、喝水少、口渴感迟钝。
- **中毒不一定和血锂数字完全对应**。有的人血锂在“正常范围”里已经有症状，尤其是长期服药的人和老年人。所以**症状比数字更要紧**。

## 二、哪些情况会让血锂升高

| 类别 | 具体情况 |
|---|---|
| 丢水丢盐 | 发烧、大量出汗、腹泻、呕吐、吃不下饭、夏天高温、户外作业、桑拿 |
| 吃得太淡 | 刻意低盐饮食、减肥、只吃水煮菜、大量喝白开水不补充电解质 |
| 合并用药 | 噻嗪类利尿剂、部分降压药、非甾体抗炎药（布洛芬、双氯芬酸等止痛药）、部分抗生素、部分抗癫痫药 |
| 肾功能 | 肾功能下降、脱水、手术前后、造影检查前后 |
| 剂量问题 | 自行加量、误服、一次吞服大量（可能是自杀行为） |

这里有一条临床上的做法，叫“病日规则”：**发烧、呕吐、腹泻、吃不下饭的时候，不要照常吃锂盐，当天联系医生，问要不要暂停、要不要查血锂。** 具体怎么处理必须由医生说，但“照常吃、等复诊”是危险的。【临床经验】

还有几个容易被忽略的细节：

- 感冒发烧时吃的退烧止痛药，很多属于非甾体抗炎药，会让血锂升高。
- 中草药、保健品、减肥茶，成分不明，也可能影响水盐平衡。
- 夏天运动大量出汗，只喝白开水不补盐，反而可能把血锂推上去。
- 腹泻两天以上、吃不下东西，是常见的入院诱因。

## 三、中毒长什么样：从轻到重

锂中毒的症状是渐进的，早期很容易被当成“累了”“上火了”“年纪大了”。

| 程度 | 常见表现 | 该做什么 |
|---|---|---|
| 轻度 | 手抖比平时明显、恶心、拉肚子、没力气、特别渴、尿多、不想吃饭 | 当天联系医生，尽快查血锂 |
| 中度 | 手抖变成粗大（端杯子会洒）、走路不稳像喝醉、反复呕吐、说话含糊、嗜睡、意识模糊、肌肉抽动 | **立即急诊**，不要等 |
| 重度 | 抽搐、昏迷、心跳很乱、血压不稳、尿很少甚至没尿、高热 | **立即拨打 120**，这是可以致命的 |

三个最值得记住的“红灯”：

1. **手抖从细变粗**。平时只是写字有点抖，现在端碗、端杯子会洒出来。
2. **走路不稳**。像喝醉酒一样，脚底下发飘，走不直。
3. **意识改变**。反应变慢、说话含糊、叫不太应、白天也迷迷糊糊。

这三个出现任何一个，都不要再观察，直接去急诊查血锂。

还要注意**慢性中毒**：不是一下子发生的，而是几天到几周里慢慢变得手抖、走路差、记性差、人变糊涂。家里人常常以为是“老了”或者“抑郁加重”，一查血锂才发现高了。老年人尤其容易这样。

## 四、怀疑中毒时：立刻做什么

**第一步：停掉下一次锂盐，然后立刻就医。** 这是急症情况下的例外——怀疑锂中毒时，先不要再吃下一次，同时马上联系医生或去急诊；之后是否恢复、怎么恢复，由医生决定。不要自己“减半片试试”，也不要“先停几天看看”。

**第二步：不要做这些事。**

- 不要催吐。
- 不要大量灌白开水或盐水“冲淡”。
- 不要自己吃利尿剂“排出去”。
- 不要等到明天门诊。
- 不要自己开车去医院（意识可能突然变差）。

**第三步：带上这些东西。**

- 药盒或药瓶（医生要知道你吃的是哪种锂盐、每片多少）。
- 最近的化验单（血锂、肾功能、电解质）。
- 一张纸，写清楚：从哪天开始不舒服、有没有发烧腹泻、这几天吃了什么药、最后一次吃锂盐是什么时候。

**第四步：到医院后会发生什么。** 医生通常会急查血锂、肾功能、电解质、心电图，评估意识状态。轻度可能只需停药、补液、观察；中重度需要住院补液，极重度可能需要血液透析把锂清出去。**透析是有效的，但前提是来得够快。**

## 五、平时怎么防

- [ ] 正常喝水，不刻意少喝，也不狂灌白开水
- [ ] 正常吃盐，不搞无盐饮食、不长期只吃水煮菜
- [ ] 发烧、呕吐、腹泻、吃不下饭，**当天**联系医生，不要照常吃药硬扛
- [ ] 新增任何药之前问一句“我在吃锂盐，这个能一起用吗”，包括止痛药、感冒药、中药、保健品
- [ ] 按医生安排查血锂、肾功能、甲状腺，不因为“最近挺好”就跳过
- [ ] 不自行加量、减量、停药
- [ ] 夏天、运动、桑拿、长途旅行，注意补水和电解质
- [ ] 家里锂盐单独存放、上锁，防止老人误服、孩子误拿
- [ ] 家属知道“手抖变粗、走路不稳、人变糊涂”这三个红灯
- [ ] 把“最后一次吃药时间”和“最近的化验值”记在手机里

## 六、常见问题

**“血锂在正常范围，是不是就没事？”**
不一定。症状比数字重要，尤其是老年人、长期服药的人、慢性中毒的人。有症状就要告诉医生，必要时复查。

**“多喝水是不是能解毒？”**
不能。大量喝白水可能进一步稀释血钠，反而让情况复杂。正确做法是就医，由医生决定补什么、补多少。

**“手抖是吃锂盐的正常反应吧？”**
轻微手抖确实常见，但**加重、变粗、影响端杯子**，就不是“正常”了，要查血锂。

**“我拉肚子两天，药还照吃吗？”**
不要自己决定。当天联系医生，把腹泻次数、能不能进食、有没有发烧说清楚。

**“夏天出汗多，我多喝点水就行了吧？”**
出汗丢的不只是水，还有盐。只灌白水、吃得很淡，反而可能让血锂升高。正常饮食、适当补充电解质，有不适及时问医生。

**“我自己减半片，是不是就不容易中毒？”**
自行减量会让情绪不稳、复发风险上升，而且血锂波动更难判断。任何调整都让医生来做。

**“中药和保健品没关系吧？”**
不一定。成分不明的东西可能影响水盐代谢或肝肾功能，用之前告诉医生。

> **什么时候需要联系医生 / 去急诊**
>
> - 手抖明显加重、端杯子会洒、走路不稳、说话含糊——**立即急诊查血锂**。
> - 反复呕吐、腹泻、吃不下饭，同时在吃锂盐——**当天联系医生；出现意识变化立即急诊**。
> - 嗜睡、叫不太应、反应明显变慢、白天也迷糊——**立即拨打 120**。
> - 抽搐、昏迷、心跳很乱、尿量明显减少——**立即拨打 120**。
> - 发烧、大汗、脱水后出现上述任何症状——**立即急诊**，不要等。
> - 误服或一次吞服大量锂盐（包括自杀行为）——**立即拨打 120**，带上药瓶。
> - 老年人“突然变糊涂”，而家里有人在吃锂盐——**查血锂**，不要只当成“老了”。
>
> 拿不准时按严重处理。**宁可白跑一趟急诊，也不要在家观察一夜。**
