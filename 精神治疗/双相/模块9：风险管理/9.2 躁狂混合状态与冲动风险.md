# 9.2 躁狂混合状态与冲动风险

> 这一页写给正在躁狂或混合状态里的人，也写给被卷进这场风暴的家属。躁狂期的冲动不是“性格问题”，而是判断力和刹车同时失灵：钱、车、性、脾气，哪一样都可能在一周内出大事。读完这一页，你会知道混合状态为什么最危险、四类冲动风险现场怎么处理、哪些话现在说没用、哪些事现在做有用，以及什么时候必须打 120、什么时候必须打 110。

## 一、混合状态：最容易被看错的高危状态

先说清楚混合状态是什么：**抑郁的绝望和躁狂的激越同时在场**。不是“心情不好”，也不是“有点兴奋”，而是两套症状叠在一起。【指南】

典型的样子：

- 一边说“活着没意思、我是累赘”，一边整夜不睡、坐不住、话停不下来。
- 一边哭，一边疯狂做计划、打电话、下单、约人。
- 一边极度自责，一边暴怒、砸东西、觉得所有人都对不起自己。
- 思维奔逸，但想的内容全是绝望的；精力恢复了一点，恰好够用来实施计划。

**为什么它最危险？** 因为抑郁提供“想死”的念头，躁狂提供“能做”的能量和冲动。这两样加在一起，自杀和冲动行为的风险都比单纯的抑郁或单纯的躁狂更高。【指南】而它最常被误判成“抑郁加重”，于是加抗抑郁药——这可能让混合和快速循环更糟。【指南】

还有一个容易被忽略的点：**躁狂期的冲动，是症状，不是人品。** 大脑的抑制控制在那段时间是打折的，当事人事后常常自己也说不清“当时怎么会那样”。理解这一点，不是替他免责，而是让家属知道：**讲道理、算后果、羞辱，在这个阶段基本无效**，有效的是把环境和手段先管住。

## 二、四类冲动风险：钱、车、性、伤人

躁狂和混合状态下的冲动，通常集中在四个方向。它们的现场处理有共同点，也有各自的门道。

### 钱：冲动消费、投资与借贷

这是最常见的“事后才发现”的损失。表现包括：大额转账、突然要创业、炒币炒股加杠杆、网络赌博、网贷、买一堆用不上的东西、请客摆阔、相信“稳赚不赔”的项目、被诈骗分子盯上。

家属在现场常常做错一件事：**跟他辩论“这个项目不靠谱”**。在躁狂状态下，他的自信是病理性升高的，辩论只会变成争吵，然后他换个渠道继续。

更有效的做法：

- **先冷却，不签字**。任何合同、转账、借款、担保，一律拖 24 到 48 小时；就说“我们家规矩是大额支出隔天再定”，不评价对错。
- **临时保管关键物品**：身份证、银行卡、U 盾、支付密码、股票账户。做之前说清楚：“这是临时的安全措施，等你稳定了我们再一起管。”这不是没收，是代管。
- **联系银行**：设转账限额、关闭大额免密、必要时临时冻结。可以说明家里有病人、需要防诈骗。
- **保留证据**：聊天记录、转账记录、合同。被骗了打 110 报案，越早越好。
- **不要“以贷养贷”**，也不要替他向亲友借钱填坑，那会把一个人拖成一家人的债务。

有一点要提前知道：**躁狂期签下的合同、做出的处分，事后可能涉及民事行为能力的问题**，但这需要法律程序认定，不是家属一句话就能作废。所以“事前拦住”永远比“事后追回”划算。相关法律问题见[11.3 精神卫生法与权益](<../模块11：危机、住院与法律/11.3 精神卫生法与权益.md>)。

### 车与身体：危险驾驶和冒险行为

躁狂期的人常觉得自己“反应快、技术好、不会出事”。真实情况是：注意力涣散、冲动、低估风险、可能还喝了酒。

需要盯的行为：超速、闯红灯、逆行、疲劳驾驶、酒后驾驶、深夜独自开车出门、突然去玩极限运动、独自远行、在工地或高处逞能。

家属能做的很具体：

- **车钥匙由家人保管**，不要放在玄关、包里、外套口袋。
- **不争论“我开车没问题”**，改成“这段时间我接送你，等复诊后再说”。
- **把出行的替代方案准备好**：打车、公交、家人送。
- **提醒法律后果**：酒驾、肇事逃逸都是要担责的，病情不是免责理由。
- **如果他坚持出门**，至少确认有没有人陪、去哪里、什么时候回；失联及时报警。

### 性行为：不羞辱，但要讲安全

躁狂期的性冲动升高，可能表现为：主动约陌生人、多性伴、不使用保护措施、在网上发露骨内容、大额打赏、被别有用心的人利用。

这件事家属最难开口，但回避的代价更大：意外妊娠、性传播感染、被敲诈、被性侵，都可能在几周内发生。

可以这样说：不说“你怎么这么不要脸”，而是“我担心的是安全，不是评判你”。具体能做的：

- 提供避孕套、陪同做性传播感染筛查和妊娠检测。
- 提醒“现在你的判断可能不可靠”，把决定往后拖。
- 如果遭遇性侵或被利用，**保留证据、不要洗澡换衣、立即报警 110 并就医**。
- 网络上的露骨内容、转账打赏，尽量截图留存，必要时联系平台。

## 五、伤人风险：先保人，再讲病

躁狂或混合状态下的伤人风险，通常有几个信号：极度易激惹、偏执（坚信有人害自己）、听到命令自己攻击的声音、喝酒、有过暴力史。

现场要快速判断三件事：**有没有具体对象、有没有计划或武器、是不是已经动过手**。有其中两样，就不要试图自己“制服”，直接打 110。

| 冲动类型 | 现场能做什么 | 什么时候报警或急诊 |
|---|---|---|
| 乱花钱、投资、借贷 | 冷却 24–48 小时、代管证件、联系银行 | 已被诈骗、被威胁、签下大额合同 → 报警 110 |
| 危险驾驶 | 保管车钥匙、安排接送 | 已酒驾、已出事故、坚持上路 → 报警 110 |
| 高风险性行为 | 讲安全、提供保护、陪同筛查 | 被性侵、被敲诈 → 报警 110 并就医 |
| 伤人威胁 | 保持距离、减少刺激、转移老人小孩 | 有具体对象或武器、已动手 → 110；受伤 → 120 |
| 自伤、自杀 | 不独处、移走危险物品 | 有计划或已实施 → 120，必要时 110 |

## 六、现场降风险：说话的方式比内容重要

躁狂状态下，人的注意力窄、易被激惹、对刺激敏感。现场原则是**降刺激、给空间、少说话、给选择**。

可以做的：

- [ ] 减少人数，只留一两个他信任的人
- [ ] 关掉电视、音乐，调暗灯光，把场面安静下来
- [ ] 说话短、慢、低声：一次一句，不超过十个字
- [ ] 给两个选项，而不是命令：“先坐下，还是先喝口水？”
- [ ] 满足基本需求：水、食物、烟、上厕所、躺一会儿
- [ ] 保持一臂以上的距离，站在靠近门口的位置，不背对
- [ ] 把老人、孩子先带到别的房间或邻居家
- [ ] 记录时间线：几天没睡、吃了什么药、喝了多少酒、说了什么
- [ ] 一旦开始砸东西、找武器、锁门，立刻退出并报警

不要做的：

- 不要争辩、嘲笑、激将（“你敢动我试试”）
- 不要围堵、按住、抢夺（除非有人正在受伤）
- 不要当众羞辱、翻旧账、叫一群人来看
- 不要承诺“我不告诉你爸妈/医生”，事后做不到会彻底失去信任
- 不要在孩子面前动手或对骂

## 七、什么时候必须急诊或住院

以下情况不是“再观察一晚”的范围：

- 有具体的伤人威胁，或已经动手、持械。
- 有明确的自杀计划，或已经自伤。
- 出现幻觉、妄想、行为完全紊乱，无法沟通。
- 极度激越，家人已经无法保证安全。
- 连续多日几乎不睡、不吃不喝，出现脱水、意识模糊。
- 混合状态，一边绝望一边冲动。
- 合并高热、外伤、酒精或药物中毒。

**120 和 110 的分工**：有人受伤、意识不清、需要医疗处置，打 120；有人身危险、持械、需要现场控制，打 110。两者可以同时打。不要因为“怕留记录”“怕邻居知道”而拖着不送医——急性期的及时处理，恰恰是减少长期损害的办法。

关于非自愿住院的条件和流程，见[11.2 住院指征与自愿非自愿](<../模块11：危机、住院与法律/11.2 住院指征与自愿非自愿.md>)。

## 八、事后：修复比追责有用

急性期过去后，家里最容易发生的是一场“清算”：翻账单、骂一顿、逼着道歉。这往往让当事人更羞耻、更隐瞒，下一次发作来得更隐蔽。

更有用的顺序是：

1. **先处理实际问题**：债务、报案、退单、法律咨询、性传播感染筛查。
2. **再做一次不带审判的复盘**：那几天最早出现的信号是什么？睡眠？话多？花钱？把它写进复发预警表。
3. **调整治疗**：复诊、按医嘱用药，不自行停；把这次发作告诉医生，剂量和方案由医生改。
4. **补上环境防线**：账户限额、车钥匙、家中药物保管、紧急联系人。
5. **照顾家属**：经历一次躁狂发作，家人也会耗竭、愤怒、内疚，这些都需要出口。

> **什么时候需要联系医生 / 去急诊**
>
> - 有具体的伤人威胁、已经动手、手持器械——**立即拨打 110**；有人受伤同时拨打 **120**。
> - 有明确自杀计划、正在自伤——**立即拨打 120**，不要独处。
> - 连续几天几乎不睡、完全无法沟通、行为紊乱——**立即精神科急诊**。
> - 出现幻觉、坚信有人要害自己——**立即急诊**。
> - 大额转账正在进行、被诈骗、被敲诈——**立即拨打 110**，同时联系银行止付。
> - 酒后驾车、坚持危险驾驶——**立即拨打 110**。
> - 高热、外伤、意识不清、抽搐——**立即拨打 120**。
> - 自己拿不准是否到了急诊程度——按严重处理，先联系医生或拨打 **12356**。
>
> 记住：这一页说的所有“现场处理”，都是为了争取时间送到医生手里，不是替代就医。
