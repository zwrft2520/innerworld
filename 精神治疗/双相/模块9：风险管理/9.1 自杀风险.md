# 9.1 自杀风险

> 这一页写给有自杀念头的双相障碍患者，也写给发现家人状态不对、却不知道怎么开口的家属。自杀不是“想不开”或“意志薄弱”，在双相里它常常和抑郁、混合状态、冲动、失眠、停药绑在一起，是可以提前识别、提前布防的。读完这一页，你会知道哪些信号要当回事、怎么直接问而不伤人、风险怎么分层、安全计划怎么写、家里怎么限制手段，以及那一刻该说什么、不该说什么。

## 一、先把几个误解拆掉

**误解一：问“你有没有想过自杀”会把人问出病来。** 现有研究不支持这种担心：直接、平静地询问，不会增加自杀念头，反而常常让人松一口气——终于有人愿意听。【研究】

**误解二：说“我想死”的人只是想要关注。** 说出来可能是求助，也可能是在试探有没有人拦；无论哪种，都值得认真对待。真正的危险有时恰恰是“什么都不说”。

**误解三：看起来好起来就安全了。** 有两段时间要特别小心：一是**刚出院的一两周**，环境变了、支持变少、动力恢复但问题还在；二是**突然变得异常平静**，尤其之前一直很痛苦的人，这种平静可能是已经做了决定，而不是好了。

**误解四：自杀是“他自己的选择”，别人做不了什么。** 手段是否容易拿到、身边有没有人、能不能及时看上医生，都会改变结局。这些是可以改变的。

还要说清楚：**双相的自杀风险不只在抑郁期。** 混合状态（抑郁的绝望 + 躁狂的激越和冲动）往往是最危险的组合，因为人既有想死的念头，又有行动的能量。【指南】躁狂期的冲动、冒险、精神病性症状，同样可能带来致命后果。

## 二、风险因素：哪些情况要认真布防

风险因素不是“判决书”，而是提示“这一段要多上心”。

| 类别 | 具体内容 |
|---|---|
| 最重要的既往因素 | 以前有过自杀未遂（尤其近期、多次、方式较危险）；家族中有人自杀 |
| 临床状态 | 抑郁发作、混合特征、明显激越、绝望感、严重失眠、精神病性症状（尤其听到命令自己去死的声音）、共病焦虑、物质使用、创伤、边缘型人格特征 |
| 治疗相关 | 刚停药或自行减药；抗抑郁药单用后转躁或混合；刚出院；换医生、治疗中断 |
| 心理与性格 | 冲动、攻击性、完美主义、觉得自己是别人的负担、问题解决能力下降 |
| 社会处境 | 独居、丧偶或分手、失业、债务、被羞辱或被欺凌、缺乏支持、家中容易拿到危险物品 |
| 时间窗口 | 深夜、酒后、节假日、纪念日、季节变化、月经前 |

**保护因素**同样重要：稳定的家人朋友、对子女或宠物的责任感、愿意看医生、有活下去的理由、信仰、还能工作或学习、过去遇到难事能扛过来。评估风险时，保护因素不是“抵消”，而是“可以加固的地方”。

## 三、怎么直接问：问句是可以准备的

很多人卡在“怕问错”。其实不需要说得漂亮，需要的是**直接、平静、不评判**。

可以按这个顺序往下问，一层一层来：

1. **打开话题**：“最近有没有觉得活着太累、不想撑了？”
2. **确认念头**：“有没有想过不想活了？大概多久一次？”
3. **问到计划**：“有没有想过具体怎么做？”
4. **问到准备**：“有没有准备东西，或者查过方法？”
5. **问到既往**：“以前有没有做过？那次是怎么回事？”
6. **问到控制力**：“现在这种念头来的时候，你觉得自己能控制住吗？”
7. **问到身边**：“如果今晚特别难受，你会找谁？”

几个技巧：

- **不要用“你不会想不开吧”这种带答案的问法**，对方顺着说“不会”就过去了。
- **不要在同一次对话里又问又劝**。先问完、听完，再谈怎么办。
- **对方沉默不等于否认**。可以补一句：“你不用现在回答，我等你想说的时候。”
- **问完要接住**：“谢谢你告诉我，这需要很大的力气。”
- **不承诺保密**。生命有危险时，保密要让位；可以提前说：“如果你有危险，我会联系医生，这不是出卖你。”

对青少年也一样要直接问。孩子不会因为被问就“学会”自杀，反而常常因为被认真对待而愿意说。

## 四、风险分级：不同情况，不同动作

分级不是为了贴标签，而是为了决定“现在要不要立刻行动”。

| 风险等级 | 常见表现 | 该做什么 |
|---|---|---|
| 低 | 偶尔有“活着没意思”的念头，没有计划，能正常生活，有支持 | 尽快看门诊，做安全计划，缩短复诊间隔，家属保持联系 |
| 中 | 经常有念头，有模糊计划但没有准备，或冲动上来时难控制 | **当天**联系医生；不独处；移除家中危险物品；48 小时内面诊评估 |
| 高 | 有明确计划、有准备（攒药、看地点、写告别信）、有意图，或近期有过尝试 | **立即急诊**，必要时住院；全程有人陪；拨打 120，必要时 110 |
| 极高 | 正在实施，或已经服药、受伤 | **立即拨打 120**，必要时 110；现场急救，不要让其独处 |

判断时看三件事：**有没有计划、有没有准备、能不能控制冲动**。三条里中两条，就按高风险管理。拿不准时，按更严重的一级处理——宁可白跑一趟急诊，不要赌。

## 五、安全计划：一张可以照着做的纸

安全计划不是“保证不自杀”的承诺书。承诺书（让对方签“我保证不自杀”）没有可靠证据支持，还可能让家属误以为安全了。【研究】真正有用的是**具体到“难受时做什么、找谁”的计划**。

可以按六步写，写在一张纸上，复印一份给家属，复诊时带给医生：

- [ ] **第一步：我的预警信号**（比如连续两晚睡不着、开始觉得“我是累赘”、把自己关起来）
- [ ] **第二步：我自己能做的事**（洗热水澡、出门走十分钟、听固定的歌单、写下来但不发出去）
- [ ] **第三步：能让我分心的地方和人**（便利店、朋友家、家人房间，不要求对方会安慰）
- [ ] **第四步：我可以找的人**（两个名字 + 电话，提前说好“我难受时可能半夜打给你”）
- [ ] **第五步：专业资源**（精神科医生、最近医院急诊、**12356** 心理援助热线、120）
- [ ] **第六步：让环境变安全**（药由家人保管、家里不留危险物品、酒锁起来）
- [ ] **第七步：我活下去的理由**（孩子、父母、宠物、没看完的剧、想去的城市，越具体越好）

写完之后，和家人对一遍：真到了那一步，谁负责陪着、谁负责打电话、去哪里。**计划要练过，才在慌乱时用得上。**

### 手段限制：最具体、也最有效的一环

想自杀的那一刻，人往往冲动而短视。**让危险物品“拿不到”，就是给冲动留出冷却时间。** 这一点在指南里被认为很重要。【指南】

家里可以做的：

- **药物**：由家属保管，按次发放；不在床头、抽屉、包里囤药；复诊时和医生商量处方量；过期的药及时处理。
- **酒精**：锁起来或家里不放。酒后冲动控制下降，是常见的引爆点。
- **刀具、绳索、农药、燃气**：收进上锁的柜子；农村家庭尤其注意农药存放。
- **高处**：检查窗户、阳台、天台的可及性，必要时加装限位。
- **车辆**：病情不稳时由家人保管钥匙。
- **网络**：退出鼓励自杀的群组和账号，算法会不断推送同类内容。

做这些事时，最好**提前说清楚**：“这不是监视你，是我们一起把危险的东西挪远一点，等这段过去。”如果偷偷做又被发现，容易变成“你们不信任我”的争吵。同时，家属不必为此道歉——保护生命比面子重要。

## 六、家属怎么接话：说与不说

那一刻，家属最常犯的错不是“说错话”，而是**急着解决问题**。对方需要的是先被听见。

| 容易伤人的说法 | 可以换成 |
|---|---|
| “你想太多了”“别矫情” | “你现在很难受，我听得出来” |
| “你想想你爸妈，你这么做对得起谁” | “我很怕失去你，所以我在这儿陪着你” |
| “别人比你惨多了” | “我不知道你有多痛，但我想知道” |
| “你要敢做我就……” | “我们一起想办法，先保证今晚安全” |
| “你答应我绝对不做” | “难受的时候，我们能做点什么让你撑过去” |
| “这是威胁我吗” | “你说这些，是不是已经到了很难撑的时候” |

几句可以直接用的话：

- “谢谢你告诉我，这很不容易。”
- “你现在安全吗？身边有没有会伤到自己的东西？”
- “今晚我不走，我们一起待到明天，明天去联系医生。”
- “我不评判你，也不会到处说，但如果你有危险，我会联系医生。”

还要注意：**不争辩“活着有没有意义”**，那是一场赢不了的辩论；**不追问细节到像审讯**；**不表现出手足无措的惊恐**——你可以害怕，但先把声音放慢。家属自己也需要支持，长期绷着的人撑不到最后。

### 长期看：把防线放在平时

- **按医嘱服药、不自行停药**：停药后复发和自杀风险都会上升。
- **守住睡眠**：连续失眠是重要的预警信号，比情绪更早。
- **戒酒**：酒精是最常见的“最后一步”催化剂。
- **出院后两周内加强陪护**，复诊不要拖。
- **把资源贴在冰箱上**：医生电话、最近医院急诊、**12356**、120。
- **每年更新一次安全计划**，因为人会变、处境会变。

> **什么时候需要联系医生 / 去急诊**
>
> - 说“不想活了”“想解脱”，或反复说“活着没意思”——**当天联系医生**，不要独处。
> - 已经在做计划：攒药、看地方、写告别信、把东西送人、突然异常平静地道别——**立即急诊，拨打 120，必要时 110**。
> - 已经服药、割伤、吞食异物——**立即拨打 120**，不要催吐，不要让其独处。
> - 听到有声音命令自己去死，或坚信自己该死——**立即急诊**。
> - 混合状态：一边绝望一边坐不住、冲动、整夜不睡——**立即急诊**，这种状态风险最高。
> - 酒后说要去死、往外冲——**不要讲道理，先拦住、陪着，必要时拨打 110**。
> - 青少年自伤、写遗书、突然把账号密码交给别人——**立即联系医生，当天面诊**。
>
> 拿不准时按严重处理。**12356** 心理援助热线可以 24 小时咨询；紧急情况直接拨打 **120**，有人身危险时拨打 **110**。
