# 5.3 丙戊酸盐

丙戊酸盐在双相障碍里出场频率很高，尤其在急性躁狂和混合发作时；它起效相对快，但也带着一串需要认真对待的风险：肝损伤、高氨血症、胰腺炎、体重增加、血小板下降，以及育龄女性绕不开的致畸问题。这一页把这些风险讲清楚，帮你在复诊时知道该问什么、该盯什么。**本页不写剂量；所有用药调整必须由医生决定，不能自行加减或停药。**

## 一、丙戊酸盐是什么，用在哪

丙戊酸盐（包括丙戊酸、丙戊酸钠、双丙戊酸钠等不同盐型）原本是抗癫痫药，后来被发现对躁狂有效，逐渐成为心境稳定剂的一种。它同时用于偏头痛预防，所以在神经内科也很常见。

在双相障碍里，它的位置大致是：

- **急性躁狂**：对情感高涨、活动增多、话多、易激惹有较好的控制作用，起效速度常快于锂盐。【指南】
- **混合发作**：这是它比较有优势的场景。抑郁与躁狂症状同时存在、冲动与自杀风险高时，丙戊酸盐是常用选项之一。【指南】
- **维持治疗**：有一定证据，但整体不如锂盐扎实；很多情况下是“急性期用得好，就继续用”，或与锂盐、抗精神病药联用。【研究】
- **双相抑郁**：不作为首选，单用对抑郁相的效果有限。

它不适合所有人：有肝病、尿素循环障碍、不明原因的脑病、血小板明显偏低、胰腺炎病史的人，通常要避免或格外谨慎。【指南】

## 二、肝功能与高氨：两条不同的危险路径

丙戊酸盐最严重的风险在肝脏和氨代谢，而这两条路径**不是一回事**，容易被混为一谈。

**第一条：肝损伤。** 丙戊酸盐经肝脏代谢，转氨酶轻度升高很常见，多数是一过性的，不需要立刻停药。但极少数人会发生严重的药物性肝损伤，甚至肝功能衰竭。风险较高的情况包括：婴幼儿（尤其两岁以下）、先天性代谢病（如线粒体病、尿素循环障碍）、同时使用多种抗癫痫药、原有肝病、严重营养不良。【指南】

肝损伤的早期信号不典型，容易被当成“感冒”或“胃肠炎”：**持续恶心、食欲明显下降、极度乏力、右上腹不适、尿色变深像浓茶、眼白或皮肤发黄**。出现这些，不要等下次复诊。

**第二条：高氨血症。** 丙戊酸盐会干扰氨的代谢，使血氨升高。关键在于——**血氨升高时可以没有肝功能异常**，转氨酶可能是正常的。这解释了为什么有些人“肝功能报告挺好”，却出现反应变慢、嗜睡、说话含糊、走路不稳、性格改变。严重时会出现意识模糊甚至脑病。

高氨血症的诱因包括：剂量偏高、同时使用其他抗癫痫药、肉碱缺乏、营养不良或长期素食、合并感染、尿素循环障碍（很多人终生不知道自己有）。【研究】

| 风险 | 早期信号 | 该做什么 |
|---|---|---|
| 肝损伤 | 恶心、食欲差、极度乏力、右上腹痛、尿色深、眼黄 | 立即停用并急诊查肝功能，不要等复诊 |
| 高氨血症 | 嗜睡、反应慢、说话含糊、走路不稳、性格改变、呕吐 | 立即就医查血氨，即使肝功能正常也要查 |
| 胰腺炎 | 上腹剧痛、向背部放射、反复呕吐、发热 | 立即急诊，禁食，不要自行吃止痛药硬扛 |
| 血小板下降 | 容易淤青、牙龈出血、鼻血、皮肤瘀点 | 尽快查血常规，避免自行服用阿司匹林等 |
| 体重增加 | 食欲增加、腰围变大、体重上升 | 记录体重，复诊讨论饮食与运动方案 |

## 三、胰腺炎、体重、血小板与其他常见问题

**胰腺炎**是罕见但可能致命的并发症，儿童和青少年风险相对更高。典型表现是上腹部持续剧痛、向背部放射、弯腰时稍缓解、伴恶心呕吐。它可以在用药几个月甚至几年后才出现，所以“吃了很久都没事”不代表可以放松警惕。一旦怀疑，处理原则是立即停药并急诊。

**体重增加**是最影响长期依从性的副作用之一。丙戊酸盐常带来食欲增加、体重上升、腰围变大，进而影响血糖、血脂和胰岛素敏感性。这不是“意志力问题”，而是药物作用。可以做的：定期称体重和量腰围、减少含糖饮料、保持规律运动、复诊时把体重变化如实说出来，由医生判断是否需要调整方案。

**血小板减少**与剂量相关，表现为容易淤青、刷牙出血、流鼻血、皮肤出现小红点。需要定期查血常规；如果同时服用影响凝血的药物（如阿司匹林、部分止痛药），要提前告知医生。做手术、拔牙、胃肠镜活检前，也要说明自己在服丙戊酸盐。

**其他常见副作用**：手抖（震颤）、困倦、头晕、恶心、脱发（多为弥漫性，停药后常可恢复）、月经改变、多囊卵巢样表现。这些多数可以管理，但不建议自己忍着了事——记录下来，复诊时逐条说。

**药物相互作用**里有两条特别重要：

1. **与拉莫三嗪联用**：丙戊酸盐会显著抬高拉莫三嗪的血药浓度，使重症药疹（Stevens-Johnson 综合征、中毒性表皮坏死松解症）的风险上升。因此两药联用时，拉莫三嗪的加量必须更慢，由医生严格安排。**这是“不能自己加量”的典型场景。**【指南】
2. **与碳青霉烯类抗生素联用**：这类抗生素会让丙戊酸盐的血药浓度大幅下降，可能诱发抽搐或情绪不稳。需要抗感染治疗时，务必告诉医生你在服丙戊酸盐。

## 四、育龄女性与孕期：最需要提前谈的风险

这是丙戊酸盐最需要被反复强调的部分。

**丙戊酸盐是已知致畸风险最高的心境稳定剂之一。** 孕期暴露与神经管缺陷、先天性心脏畸形、唇腭裂、尿道下裂等风险升高相关；更值得注意的是，孕期暴露还与子代神经发育问题相关，包括认知发育水平偏低、孤独症谱系障碍风险升高。【指南】【研究】

因此，多个国家的监管机构与指南都提出了严格的使用条件：**育龄女性除非没有其他合适选择，否则不应使用丙戊酸盐；使用前必须充分告知风险，采取有效的避孕措施，并由专科医生定期复核。** 这套要求常被称为“孕期预防计划”。【指南】

对中国的读者，具体做法上可以记住这几条原则：

- **计划怀孕前就要谈**，而不是怀上了才说。理想情况是在备孕阶段由精神科与产科共同评估，看是否可以换成其他药物、如何缓慢过渡。
- **不要自行停药**。突然停用丙戊酸盐可能导致躁狂复发，而复发本身对母亲和胎儿同样危险。
- **不要自行继续**。是否继续用、用多久、孕期如何监测（如产科超声、母血筛查等），需要个体化决策。
- **意外怀孕要尽快就诊**，不要因为害怕被责怪而拖延。
- **避孕是治疗的一部分**。使用丙戊酸盐的育龄女性，应与医生讨论可靠的避孕方式；丙戊酸盐本身不降低口服避孕药效果（这一点与卡马西平不同），但仍需个体化确认。
- **男性用药**：目前证据不支持父亲使用丙戊酸盐会显著增加子代风险，但仍建议在备孕时告知医生。【待验证】

## 五、日常清单与就医边界

- [ ] 记住自己用的是哪种盐型（丙戊酸、丙戊酸钠、双丙戊酸钠），不同盐型的实际含量不同，换药时不能想当然等量替换。
- [ ] 开始用药前完成基线检查：肝功能、血常规、体重、必要时血氨；育龄女性做妊娠试验。
- [ ] 按医生安排定期复查肝功能、血常规、血氨（按需）和体重。
- [ ] 不饮酒，或至少把饮酒量降到最低——酒精与丙戊酸盐叠加，会增加肝损伤风险。
- [ ] 不自行服用其他抗癫痫药、止痛药、抗生素、中药或保健品；新增任何药物前先问医生或药师。
- [ ] 手术、拔牙、侵入性检查前，主动告知医生在服丙戊酸盐（涉及出血风险）。
- [ ] 记录体重与腰围，每月一次，复诊带上。
- [ ] 育龄女性：与医生讨论避孕方案；一旦计划怀孕或发现怀孕，尽快就诊。
- [ ] 出现嗜睡、反应变慢、说话含糊，即使肝功能正常，也要想到血氨。
- [ ] 不因为“体重涨了”“手抖”就自行停药，先和医生讨论替代方案。

### 容易踩的坑

- **“肝功能正常，就说明没问题。”** 高氨血症可以独立于肝功能出现，这是最容易被漏掉的一种情况。
- **“吃了两年都没事，以后也不会有事。”** 胰腺炎、肝损伤可以在长期用药后出现。
- **“怀孕了赶紧把药停掉最安全。”** 突然停药带来的复发风险，可能比药物风险更直接；必须在医生指导下决策。
- **“别人吃这个没事，我也加一点。”** 丙戊酸盐与拉莫三嗪等药物的相互作用很强，自行加量可能带来重症药疹。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现眼黄、尿色深如浓茶、右上腹持续疼痛、反复呕吐、极度乏力：警惕肝损伤，**立即停用并急诊查肝功能**。
> - 出现嗜睡、反应迟钝、说话含糊、走路不稳、性格明显改变：警惕高氨血症，立即就医查血氨。
> - 出现上腹剧痛并向背部放射、频繁呕吐、发热：警惕胰腺炎，立即急诊，不要自行服用止痛药掩盖症状。
> - 出现不明原因的淤青、牙龈出血、鼻血不止、皮肤瘀点：尽快查血常规。
> - 服药期间发现怀孕，或计划怀孕：尽快联系精神科与产科，**不要自行停药**。
> - 出现自杀念头、自伤行为或具体计划：不要独处，立即拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
