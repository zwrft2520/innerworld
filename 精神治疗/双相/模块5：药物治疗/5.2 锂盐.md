# 5.2 锂盐

锂盐是双相障碍治疗里最老、也最特殊的一个药：它便宜、证据厚、能降低自杀风险，同时治疗窗窄、需要长期抽血监测，一不小心就可能中毒。这一页讲清楚它适合谁、监测什么、哪些日常情况会把安全的人推向中毒，以及“长期吃到底值不值”。它适合正在服锂盐、准备开始服锂盐，或家里有人在服锂盐的读者。**本页不写剂量，也不写血锂浓度目标，这些必须由医生个体化决定。**

## 一、锂盐是什么，谁适合

锂是一种天然存在的元素。二十世纪中期，澳大利亚医生 Cade 偶然发现锂盐能让躁狂的动物安静下来，随后它被用于精神科，成为第一个真正意义上的心境稳定剂。今天临床上用的是碳酸锂、枸橼酸锂等盐类，起作用的都是锂离子。

锂盐在双相障碍里的位置，主要有四块：

- **急性躁狂**：可以单用，也常与抗精神病药联用。对典型的情感高涨型躁狂，效果往往比混合状态好。【指南】
- **长期维持**：这是锂盐最强的证据所在。多项随机试验和汇总分析显示，维持期使用锂盐能显著降低复发风险，对躁狂和抑郁两个相位都有预防作用。【指南】
- **双相抑郁的辅助治疗**：单用起效较慢，但常作为“打底”的稳定剂，防止抗抑郁治疗引发转躁。
- **自杀风险降低**：这是锂盐区别于其他药物的一点，后面单独讲。

哪些人更容易从锂盐获益？临床上观察到一些“反应好”的特征：发作呈典型的“躁狂—抑郁—缓解”节律、发作间期功能恢复较好、有双相家族史、没有快速循环、没有物质使用问题。【临床经验】反过来，快速循环、混合发作频繁、有明显肾或甲状腺问题、难以配合抽血监测的人，医生可能会优先考虑别的方案。

还要说清一点：**锂盐不是“最后的选择”，也不是“过时的老药”。** 在多个国际指南里，它仍然是一线维持治疗选项之一。【指南】

## 二、血锂监测与身体监测：这不是可选项

锂盐最需要被理解的一点是：**它的有效浓度和中毒浓度离得很近。** 换句话说，能治病的量，和能伤人的量，中间的安全余量不大。这就是为什么服锂盐的人必须定期抽血。

**血锂监测。** 抽血有时间要求——通常在末次服药后一段时间采血，测的是谷浓度（下一次吃药前的最低点）。如果抽血时间不对，结果会误导医生。医生会为每个人设定一个目标区间，并根据发作情况、副作用、年龄、肾功能调整。**这个区间因人而异，不要拿别人的数值对照自己。**【指南】

监测频率大致是：开始服药或调整剂量后需要较密集地复查，稳定之后转为定期复查，通常每几个月一次；出现脱水、发热、呕吐腹泻、加用新药时，要提前复查。具体节奏由医生安排。

**肾功能。** 锂完全经肾脏排泄。长期使用可能影响肾小管的浓缩功能，表现为**多尿、夜尿增多、总是口渴**；少数人长期下来会出现肾功能的缓慢下降。因此需要定期查肌酐、估算肾小球滤过率，也要避免长期同时使用可能伤肾的止痛药。

**甲状腺。** 锂会干扰甲状腺激素的合成，可能引起甲状腺功能减退、甲状腺肿大，表现为怕冷、乏力、便秘、体重增加、情绪低落、反应变慢。这些症状容易和抑郁复发混淆，所以定期查促甲状腺激素（TSH）很重要。发现甲减通常可以通过补充甲状腺素处理，不必因此停锂，但需要医生判断。

**其他**：血钙（锂可能引起甲状旁腺功能亢进、血钙升高）、体重、心电图（尤其老年人或有心脏病的人）、育龄女性的妊娠试验。

| 监测项目 | 多久看一次（大致） | 主要想发现什么 |
|---|---|---|
| 血锂浓度 | 起始与调量后较密，稳定后定期 | 是否在安全区间、是否接近中毒 |
| 肌酐 / eGFR | 定期 | 肾功能下降、浓缩功能受损 |
| TSH、甲状腺 | 定期 | 甲减、甲状腺肿大 |
| 血钙 | 定期或按需 | 高钙血症、甲状旁腺问题 |
| 体重、血压 | 每次复诊 | 体重增加、代谢变化 |
| 妊娠试验 | 育龄女性按需 | 孕期用药需要重新评估 |

## 三、脱水、发热与锂中毒：最需要记住的一课

锂靠肾脏排出，而肾脏排锂的速度，受体内**水和盐**的状态影响很大。当身体缺水或缺钠时，肾脏会拼命回收钠，顺带把锂也回收了——血锂就升上去了。

常见的“推手”包括：

- **发热、出汗多**：感冒发烧、夏天户外工作、桑拿、热瑜伽。
- **呕吐、腹泻**：胃肠炎、食物中毒、旅行者腹泻。这是最常见的诱因之一。
- **吃得太淡或突然严格限盐**：低盐饮食、减肥断食、只喝白水不进食。
- **大量出汗后只补水不补盐**：马拉松、长时间高温作业。
- **合并用药**：某些止痛药（如布洛芬等非甾体抗炎药）、部分降压药（如普利类、沙坦类）、利尿剂、某些抗生素，都会抬高血锂。
- **肾功能变化**：脱水、老年、原有肾病。

中毒的表现是有层次的，越早识别越安全：

| 阶段 | 常见表现 | 该怎么做 |
|---|---|---|
| 早期 | 明显口渴、多尿、食欲差、恶心、腹泻、**细颤变成粗大的手抖** | 停用下一次锂盐并尽快联系医生，查血锂 |
| 进展 | 走路不稳、说话含糊、头晕、嗜睡、肌肉抽动、呕吐加重 | 立即就医，不要在家补水观察 |
| 急症 | 意识模糊、抽搐、高热、少尿、昏迷 | 立即拨打 **120**，按急症处理 |

要特别区分两种手抖：**细小的、拿杯子时轻微抖**，可能是常见的副作用；**粗大的、幅度明显、影响写字和端碗**，尤其伴随走路不稳、呕吐、反应变慢，就要按中毒处理。宁可白跑一趟。

还有一个容易被忽视的场景：**夏天旅游**。高温、出汗、喝水不规律、饮食变咸变淡、时差打乱服药时间，几件事凑在一起，是锂中毒的高发组合。出门前和医生对一遍“发热、腹泻、吃不下饭时怎么办”，比临时慌张有用得多。

## 四、长期获益与自杀预防：证据有多硬

锂盐最值得说的，是它在**降低自杀风险**上的证据。多项汇总分析报告，长期使用锂盐的人群，自杀死亡和自杀未遂的比例低于不用锂盐的对照人群；一些在地区层面做的生态学研究也观察到，与锂的可得性相关的指标变化，与自杀率变化相关。【研究】

但要把证据的分量说准：

- 这些研究很难做到完美的随机对照（不可能让人随机“不吃锂”多年），所以存在选择偏倚的可能。
- 效果在不同研究间大小不一，但方向比较一致。
- 它**不能理解成“吃锂就不会自杀”**。自杀风险来自多方面，需要配合随访、心理治疗、手段限制和家庭支持。【指南】

除了自杀预防，锂盐的长期价值还体现在：减少复发次数、延长发作间期、可能降低发作后的功能损害。有研究提示长期锂治疗与较低的痴呆风险相关，但这属于观察性研究的发现，不能当成“吃锂防痴呆”的依据。【待验证】

代价也要摆出来：手抖、口渴多尿、体重增加、痤疮、甲状腺功能减退、肾功能影响，以及“必须定期抽血”这件麻烦事。很多人因为这些副作用自行停药，结果在几个月内复发。**停药的决定要在医生指导下缓慢进行，不能突然停。** 突然停锂后复发（尤其躁狂）的风险是明确存在的。【指南】

孕期是另一个必须提前讨论的问题。锂在孕早期与某些先天性心脏畸形（如 Ebstein 畸形）的风险升高相关，虽然绝对风险不高，但需要精神科与产科共同评估，权衡“停药复发的风险”和“继续用药的风险”。**不能自行停药，也不能自行继续。**【指南】

## 五、日常清单与就医边界

- [ ] 随身携带一张卡片或手机备忘录，写明“我在服锂盐”、剂量、开药医生和紧急联系人。
- [ ] 固定时间服药，用手机闹钟；漏服后按医生事先交代的办法处理，**不要一次吃双倍**。
- [ ] 每天喝够水，不要等到口渴才喝；高温、运动、出汗多时更要主动补水，并适当补充电解质。
- [ ] 不自行严格限盐、断食减肥或长期只喝白水。
- [ ] 发烧、呕吐、腹泻、吃不下饭时，**先联系医生**，通常需要暂停下一次服药并尽快查血锂。
- [ ] 加任何新药（包括止痛药、抗生素、中药、保健品）之前，告诉医生或药师你在服锂盐。
- [ ] 按预约抽血，抽血时间按医生要求，不要随意改动。
- [ ] 记录手抖、口渴、夜尿、体重、怕冷乏力等变化，复诊时逐条说。
- [ ] 不因为“最近感觉挺好”就自行减量或停药。
- [ ] 准备怀孕、已经怀孕或正在哺乳，第一时间告知医生。

### 容易踩的坑

- **“多喝水就行”**：光补水不补盐，在大量出汗后反而可能稀释性低钠，间接抬高血锂。补水要配合正常饮食。
- **“手抖是正常的，忍忍就好”**：细颤可以观察，粗颤加走路不稳必须就医。
- **“血锂正常就没事”**：抽血时间不对、近期脱水、肾功能变化，都可能让单次结果失真。
- **“锂盐伤肾，早点停”**：不监测才伤肾；规范监测下，多数人可以长期安全使用。

> **什么时候需要联系医生 / 去急诊**
>
> - 出现粗大手抖、走路不稳、说话含糊、反复呕吐腹泻、嗜睡或意识模糊：**立即急诊查血锂**，不要在家观察。
> - 高热、抽搐、少尿、昏迷：立即拨打 **120**。
> - 发热、呕吐、腹泻、明显吃不下饭超过一天：尽快联系开药医生，按医嘱暂停或调整。
> - 出现严重甲状腺症状（明显怕冷、水肿、极度乏力）或肾功能异常报告：尽快复诊。
> - 出现自杀念头、自伤行为或具体计划：不要独处，立即拨打 **120** 或去最近医院急诊；也可拨打 **12356** 心理援助热线。
