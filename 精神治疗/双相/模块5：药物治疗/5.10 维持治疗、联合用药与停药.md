# 5.10 维持治疗、联合用药与停药

急性期过去、情绪稳定下来之后，治疗才进入最漫长也最容易松懈的阶段。很多人在这时候想：“我已经好了，是不是可以停了？”停药本身不是错，错在“自己决定、说停就停”。这一页讲维持治疗在防什么、要吃多久、联合用药怎么权衡、血药浓度什么时候查，以及减药停药时最容易出事的环节。读完你能分清“症状缓解”和“可以停药”不是一回事。

## 一、维持治疗到底在维持什么

双相障碍的病程有一个特点：发作次数越多，下一次越容易被小事触发，间隔也可能越短。这个现象常被叫作“kindling”，意思是像柴火一样，第一次难点的火，后面越来越容易着。维持治疗的目标不是“让你一直吃药”，而是**把复发概率压下来，保护大脑、工作和关系不被一次次发作磨掉。**

维持治疗保护的东西比“情绪”更具体：

- **防躁狂复发**：锂盐、丙戊酸盐、部分抗精神病药在这方面证据明确。
- **防抑郁复发**：拉莫三嗪、喹硫平、锂盐各有位置。
- **降低自杀风险**：锂盐在长期治疗中与较低的自杀风险相关，这是它难以被完全替代的原因之一。【指南】
- **保住功能**：每次发作都可能带来工作、学业、关系和经济上的损失，维持治疗是在保这些。
- **减少住院**：反复住院不仅花钱，也会打断治疗关系和生活节奏。

所以“我现在很好”恰恰可能是维持治疗有效的结果，而不是可以停的理由。这句话听起来像绕口令，但它是这个病最容易被误解的地方。

## 二、维持多久：没有统一答案，但有判断框架

“要吃多久”是门诊里被问得最多的问题，也是最不该给统一答案的问题。有人一次躁狂后再没复发，有人在减药后几个月就再次发作。指南给出的不是一条硬线，而是一个判断框架。

| 你的情况 | 通常的倾向 | 说明 |
|---|---|---|
| 首次发作、完全缓解、生活稳定 | 维持较长时间后再讨论减药 | 不建议刚稳定就停【指南】 |
| 多次发作，尤其有躁狂史 | 多建议长期维持 | 停药后复发风险高 |
| 有快速循环、混合发作史 | 更倾向长期 | 复发代价大，方案要简化稳定 |
| 有自杀企图或严重抑郁史 | 更倾向长期 | 锂盐的长期保护价值要纳入考虑 |
| 孕期、备孕、哺乳 | 个体化重新评估 | 不是简单“停”或“继续”【指南】 |
| 副作用难以耐受 | 调整方案，而非直接停 | 换药、减量、联合对症处理 |

不少指南把“情绪稳定两年以上”作为可以开始认真讨论减药的前提之一，但这不是自动生效的许可，具体要看发作次数、严重度、支持系统和既往减药经历。**减药是一个需要计划、需要随访的医疗决定，不是一次谈话就能完成的动作。**

## 三、联合用药：什么时候需要，怎么避免越加越多

双相障碍用到两种以上精神科药物很常见，原因通常不是“病情重”，而是单药覆盖不了两个方向：比如锂盐防躁狂和自杀，拉莫三嗪防抑郁；或者心境稳定剂打底，抗精神病药控制残余的兴奋或失眠。

合理的联合有几个特征：**每种药都有明确目标、剂量与副作用不重复叠加、有明确的“什么时候评估要不要减”的计划。** 不合理的联合则常常是“症状多、药就多”，最后人很困、很胖、很木，却说不清每种药在治什么。

| 常见组合 | 目的 | 需要留意 |
|---|---|---|
| 锂盐 + 拉莫三嗪 | 兼顾防躁狂与防抑郁 | 拉莫三嗪需缓慢加量，注意皮疹 |
| 锂盐 + 喹硫平 | 急性期与维持，兼顾睡眠 | 镇静、体重、代谢、体位性低血压 |
| 丙戊酸盐 + 抗精神病药 | 混合发作、躁狂控制 | 体重、肝功能、血小板、镇静 |
| 心境稳定剂 + 抗抑郁药 | 难治性双相抑郁的短期联合 | 转躁风险，需密切监测 |
| 口服药 + 长效针剂 | 依从性差、反复复发 | 注射部位反应、按时复诊 |

联合用药最怕两件事：一是**自行叠加**，把家里剩下的药翻出来一起吃；二是**只加不减**，几年下来方案越来越重，却没人回顾。每次复诊可以问一句：“现在这些药，各自是治什么的？有没有可以减的？”这不是质疑医生，而是让治疗保持清醒。

还要注意相互作用。卡马西平会降低很多药的浓度；氟西汀等会抑制肝酶，抬高其他药的水平；部分抗生素、抗真菌药、止痛药会影响锂盐和抗精神病药的浓度。**任何新加的药，包括中草药和保健品，都值得让医生或药师核一遍。**

## 四、血药浓度监测：查什么、什么时候查

血药浓度（治疗药物监测）不是“抽个血看看”，而是判断“这个剂量在你身上够不够、有没有过量”的工具。不同药的必要性不一样。

- **锂盐**：必须定期监测，是安全使用的底线。脱水、呕吐、腹泻、发热、低盐饮食、加用利尿剂或降压药，都可能让血锂升高。
- **丙戊酸盐**：在疗效不佳、怀疑不依从、出现副作用、合并用药时查，同时要看肝功能、血氨、血常规。
- **卡马西平**：在疗效变化、加用新药、怀疑毒性时查，注意自身诱导导致浓度下降。
- **氯氮平**：一旦使用，血常规监测是强制的，不是可选项。
- **其他抗精神病药和抗抑郁药**：并非常规，但在疗效异常、副作用明显、怀疑不依从时可以查。

抽血时间有讲究，通常按医生要求，在下次服药前采血，这样比较的是“谷浓度”。**不要因为怕麻烦而跳过复查**，也不要拿着一次结果自己调药。结果要结合症状、副作用、肝肾功能和合并用药一起看，单看数字容易误判。

## 五、停药与撤药：最容易出事的一步

突然停药是双相障碍治疗中最常见、也最可避免的失误之一。原因很直接：

- **锂盐突然停**，躁狂复发风险明显上升，且可能比逐渐减量更高；撤药期间还可能出现焦虑、失眠、出汗。
- **抗精神病药突然停**，可能出现失眠、烦躁、恶心、撤药性运动障碍，复发风险也上升。
- **抗抑郁药突然停**，会出现头晕、触电感、恶心、易怒等停药反应，容易被误认为“病又回来了”。
- **拉莫三嗪停一段时间再吃**，不能按原来的量直接恢复，需要重新缓慢加量，否则皮疹风险上升。
- **苯二氮䓬类突然停**，可能反跳性失眠、焦虑，严重时抽搐，必须由医生安排逐渐减。

减药的正确姿势是：**先有计划，再有动作。** 计划包括——为什么减、减哪一种、减完之后怎么观察、出现什么信号要恢复、下一次复诊什么时候。减药通常分阶段进行，以周或月为单位，由医生根据反应调整；不选在考试、换工作、搬家、季节交替这些压力大的时候；减药期间睡眠要格外规律，酒和熬夜要避免。

准备减药前，可以先过一遍这份清单：

- [ ] 和医生确认：现在是否到了可以讨论减药的阶段，依据是什么。
- [ ] 明确这次减的是哪一种药，其他药是否保持不变。
- [ ] 写下未来三个月的复诊时间，以及出现问题时怎么联系。
- [ ] 和家人/同伴说明：接下来几个月要重点观察睡眠和情绪。
- [ ] 准备好心境日记，记录睡眠时长、情绪、花钱、冲动。
- [ ] 把“复发早期信号”写在一张纸上，贴在家里显眼处。
- [ ] 确认家里没有人会“劝你干脆全停了”。
- [ ] 知道一旦出现转躁或自杀念头，立即联系医生或去急诊，不等复诊。

**停药不等于失败，长期服药也不等于软弱。** 它们都是根据病情做出的选择，区别只在于：这个选择是不是在充分评估之后做的。

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊或拨打 120：**
> - 出现自杀念头、计划或准备行为；
> - 突然话多、整夜不睡、冲动消费、危险驾驶、伤人威胁；
> - 严重手抖、走路不稳、频繁呕吐腹泻、意识模糊（警惕锂中毒）；
> - 高热、肌肉僵硬、大汗、心跳很快（警惕恶性综合征）；
> - 抽搐、晕厥、胸痛、呼吸困难；
> - 停药或减药后症状迅速反弹，无法自控。
>
> **尽快联系医生（当天或次日）：**
> - 睡眠时间明显减少，但精力反而变好；
> - 情绪低落加重、兴趣明显下降；
> - 减药后出现头晕、恶心、触电感、烦躁；
> - 发热、呕吐、腹泻、吃不下东西（可能影响血药浓度）；
> - 需要加用新药、抗生素、止痛药或中草药；
> - 计划怀孕、已怀孕或哺乳；
> - 想自行调整方案。

### 常见问题

**“稳定三年了，能不能停？”** 可以讨论，但不能自己停。医生会看发作次数、严重度、上次减药的结果、目前的支持系统，再决定是否减、减多少、减多快。

**“吃药期间怀孕了怎么办？”** 立即联系精神科和产科，不要自行停药。突然停药导致的复发，对母亲和胎儿同样是风险。具体方案需要两边医生一起定。

**“血药浓度正常，是不是就说明药量刚好？”** 不一定。浓度只是参考，还要看症状控制、副作用和个体差异。有些人浓度在参考范围内仍有效，有些人需要更低或更高，判断权在医生。

**“能不能用保健品代替一部分药？”** 不能。目前没有哪种保健品被证实可以替代心境稳定剂，某些产品还会影响药物浓度或诱发转躁。具体见模块 7 中关于补充剂的内容。
