# 5.5 卡马西平与其他抗惊厥药

卡马西平是最早被用来治疗双相障碍的药物之一，但今天它更多出现在“二线”“特殊情况”和“药物相互作用”的讨论里。这一页讲清卡马西平现在还能做什么、为什么它几乎和所有药都“打架”、需要查哪些指标，以及奥卡西平和其他抗惊厥药到底有没有位置。读完你能判断：医生给我开这个药，是出于什么考虑；我该盯哪些风险。

## 一、卡马西平现在的位置

卡马西平原本是抗癫痫药，20 世纪后半叶被用于躁狂和维持治疗，曾经是锂盐之外的主要选择。它通过稳定神经细胞的钠通道，降低异常放电和过度兴奋，对躁狂、混合状态有一定控制作用，对部分快速循环的人也可能有帮助。但和锂盐、丙戊酸盐相比，它的证据基础薄一些，副作用和相互作用又多，所以今天的指南通常把它放在二线，或用在锂盐、丙戊酸盐效果不好、不能耐受的时候。【指南】【临床经验】

它和拉莫三嗪的分工不太一样：拉莫三嗪偏向“防抑郁”，卡马西平偏向“控躁狂、稳混合”，但它对抑郁发作的预防作用不如锂盐和拉莫三嗪。对混合特征明显、情绪像“又烦又冲动”的人，有些医生会考虑它，但这属于个体化判断，不是标准答案。

| 场景 | 卡马西平的位置 | 说明 |
|---|---|---|
| 急性躁狂、混合状态 | 二线 | 有效，但起效和耐受性不如一线方案【指南】 |
| 维持治疗、预防复发 | 二线 | 对抑郁复发的预防弱于锂盐【指南】 |
| 快速循环 | 可考虑 | 证据有限，个体差异大【待验证】 |
| 锂盐或丙戊酸盐无效/不耐受 | 替代选项 | 需要评估相互作用和监测条件 |
| 双相抑郁急性期 | 不作为首选 | 抗抑郁作用证据不足 |

## 二、为什么它几乎和所有药都“打架”

卡马西平是肝脏药物代谢酶的强力“诱导剂”。可以把肝脏想象成一条处理药物的流水线，卡马西平会让这条流水线加速运转，于是很多同时吃的药被更快地分解掉，血药浓度下降，疗效跟着打折。受影响的范围非常广：避孕药、抗凝药、部分抗精神病药、部分抗抑郁药、抗癫痫药、抗生素、免疫抑制剂，甚至一些中草药。这也是它今天使用减少的主要原因。

更麻烦的是“自身诱导”：刚开始吃药的头几周，卡马西平会诱导自己的代谢，血药浓度自己往下掉。所以早期查浓度看起来“够”，过一阵可能就不够了，医生需要重新评估。这不是药“失效”，而是体内处理它的速度变了。

| 同时使用的东西 | 可能发生什么 | 怎么办 |
|---|---|---|
| 复方口服避孕药 | 避孕效果下降，可能突破性出血 | 需要额外避孕方式，和医生/妇科一起定 |
| 华法林等抗凝药 | 抗凝效果下降 | 必须监测凝血指标，不能自己调 |
| 多种抗精神病药、抗抑郁药 | 对方浓度下降，疗效变差 | 由医生评估是否调整，不要自行加量 |
| 锂盐 | 神经系统毒性风险增加 | 有手抖、走路不稳、意识改变要急诊 |
| 红霉素、部分抗真菌药、葡萄柚 | 卡马西平浓度升高，头晕、复视、走路不稳 | 避免同用或由医生调整 |
| 丙戊酸盐 | 相互影响，浓度和副作用都变复杂 | 需要更密切的临床观察 |
| 酒精、大麻 | 镇静叠加、判断力下降 | 治疗期尽量不用 |

这张表说明一件事：**吃卡马西平的人，任何新加的药、保健品、草药，都应该先让医生或药师过一遍。** 包括药店随手买的感冒药、止痛药和“助眠”产品。

## 三、必须盯的检查

卡马西平的问题常常不是“吃下去马上不舒服”，而是悄悄发生的。所以规律复查不是走形式。

- **血常规**：最需要警惕的是粒细胞缺乏和再生障碍性贫血，虽然罕见，但可以很凶险。持续发热、咽痛、口腔溃疡、反复感染，要立刻查血常规，不要当成普通感冒。
- **肝功能**：卡马西平可以引起肝酶升高和药物性肝损伤。出现乏力、恶心、食欲下降、皮肤或眼白发黄、尿色变深，要尽快就诊。
- **血钠**：它会引起抗利尿激素分泌异常，导致低钠血症，老年人更常见。表现是头痛、恶心、乏力、注意力差、走路不稳，严重时会抽搐、意识模糊。很多人以为是“年纪大了”或“抑郁加重”，其实是血钠低了。
- **心电图**：卡马西平可能影响心脏传导，有心脏病、晕厥史、心跳慢的人，用药前和用药中要评估。
- **血药浓度**：在怀疑不依从、疗效变化、加用新药、出现毒性表现时，查浓度很有价值。
- **骨密度与维生素 D**：长期使用可能影响骨代谢，绝经后女性、老年人、长期不晒太阳的人要和医生讨论。
- **HLA-B*1502**：这是和卡马西平严重皮肤反应（SJS/TEN）相关的基因标记，在汉族人群中携带率相对较高。国内外药品说明书和专业共识建议汉族等东亚人群在开始卡马西平前做这项检测，阳性者通常应避免使用。【指南】

清单：

- [ ] 用药前确认是否做过 HLA-B*1502 检测，结果记在用药本上。
- [ ] 记下最近一次血常规、肝功能、血钠、心电图的日期。
- [ ] 发热、咽痛、口腔溃疡超过两天，先查血常规，不要硬扛。
- [ ] 新加任何药、保健品、中草药前，问一句“和卡马西平有没有相互作用”。
- [ ] 女性用复方避孕药时，和医生确认避孕方案是否可靠。
- [ ] 记录走路不稳、复视、头晕加重的出现时间，复诊时说明。
- [ ] 不自行加量、减量、停药；癫痫患者突然停药还可能诱发抽搐。

## 四、奥卡西平和其他抗惊厥药

**奥卡西平**是卡马西平的“后代”，结构相近，但诱导肝酶的作用弱得多，所以药物相互作用比卡马西平少，这是它的主要优势。代价是：它引起低钠血症的比例更高，皮疹风险仍在，而且和卡马西平存在交叉过敏——对卡马西平起过严重皮疹的人，通常也不宜用它。它在双相障碍中的证据比卡马西平更少，指南里很少把它列为常规心境稳定剂，更多是“需要抗癫痫作用、又想减少相互作用”时的个体化选择。【临床经验】【待验证】

**加巴喷丁和普瑞巴林**常被用于焦虑、失眠、神经痛，有些人吃了觉得“情绪平稳”，但它们没有被证实是心境稳定剂，不能替代锂盐、丙戊酸盐或抗精神病药。普瑞巴林还有滥用和依赖风险，尤其在有物质使用史的人身上要谨慎。

**托吡酯**有时被用来对抗抗精神病药引起的体重增加，或辅助控制冲动，但它本身不是心境稳定剂，常见副作用是认知变慢、找词困难、手脚麻、肾结石和代谢性酸中毒。把它当成“减肥药”长期自行服用，不划算。

| 药物 | 在双相中的位置 | 主要监测与风险 |
|---|---|---|
| 卡马西平 | 二线心境稳定剂 | 血常规、肝功能、血钠、心电图、HLA-B*1502 |
| 奥卡西平 | 个体化替代，证据有限 | 血钠、皮疹、交叉过敏 |
| 加巴喷丁/普瑞巴林 | 不作心境稳定剂 | 镇静、水肿、滥用风险 |
| 托吡酯 | 辅助减重或控制冲动 | 认知减慢、肾结石、酸中毒 |

## 五、特殊人群要单独讨论

**育龄女性与孕期**：卡马西平有致畸风险，包括神经管缺陷和颅面部畸形，风险低于丙戊酸盐，但绝不是“安全”。奥卡西平的数据更少。计划怀孕的人要在孕前就和精神科、产科一起评估，讨论是否换药、如何补充叶酸、孕期是否监测浓度，**不能自己停药，也不能自己换药**。哺乳期同样需要个体化评估。【指南】

**老年人**：低钠血症、跌倒、认知影响、心脏传导问题都更突出，合并用药也更多，开始用药和调整时宜更慢，复查更勤。

**肝肾功能不全**：卡马西平主要经肝代谢，肝功能差的人风险更高；奥卡西平及其代谢物经肾排泄，肾功能不全时要特别注意低钠和蓄积。

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊或拨打 120：**
> - 皮疹伴发热、口腔溃疡、眼红、皮肤起疱或脱皮、面唇肿胀（警惕 SJS/TEN）；
> - 高热、咽痛、口腔溃烂、皮肤瘀点瘀斑、牙龈或鼻子出血（警惕粒细胞缺乏或血小板减少）；
> - 皮肤或眼白发黄、尿色深、持续呕吐、意识模糊（警惕肝损伤）；
> - 剧烈头痛、恶心呕吐、走路不稳、抽搐、意识改变（警惕严重低钠血症）；
> - 心悸、胸闷、晕厥、心跳很慢（警惕心律失常）；
> - 手抖加重、走路不稳、说话含糊，尤其在同时使用锂盐时。
>
> **尽快联系医生（当天或次日）：**
> - 新出现皮疹但没有上述危险信号；
> - 持续发热、乏力、食欲明显下降；
> - 血钠、肝酶、血常规复查结果异常；
> - 需要加用任何新药（包括抗生素、止痛药、中草药）；
> - 月经紊乱、突破性出血，或怀疑避孕失败；
> - 计划怀孕、已怀孕或准备哺乳；
> - 情绪转向兴奋、话多、睡得少，或抑郁明显加重。

### 常见问题

**“卡马西平是不是被淘汰了？”** 没有。它在特定情况下仍然有用，尤其是在需要同时控制癫痫、或对其他心境稳定剂不能耐受时。但它需要更多的监测和更小心地管理相互作用，所以不再是首选。

**“为什么医生让我先查基因再吃药？”** 查的是 HLA-B*1502，用来评估严重皮肤反应的风险。这个检测只需要抽一次血，但对汉族人来说很有价值。

**“血钠低是不是多喝水就好？”** 不是。低钠血症的处理要看原因和程度，严重时需要限制液体甚至静脉用药。自己猛喝水或猛喝盐水都可能出事，先就医。

**“能不能用卡马西平代替锂盐？”** 两者作用谱不同。卡马西平对躁狂有效，但对抑郁复发和自杀风险的预防证据不如锂盐。替换要由医生根据你的发作类型决定。

**“吃药期间能喝酒吗？”** 不建议。酒精会加重镇静、影响走路和判断，也可能诱导或抑制代谢，让浓度更不稳定。
