# 5.8 急性躁狂与混合发作的用药

急性躁狂是双相障碍里最需要快速处理的阶段：人可能几天不睡、话停不下来、冲动消费、开车飙速、和人起冲突，甚至出现幻觉和被害想法。混合发作更麻烦，抑郁和躁狂的症状同时出现，自杀和冲动风险都高。这一页讲急性期医生会怎么用药、为什么常常要“两种药一起上”、激越时怎么处理，以及什么情况下必须住院。读完你能判断事情的紧急程度，也能在医生给出方案时知道每一步在解决什么。

## 一、急性期的目标不是“讲道理”

躁狂发作时，大脑的“刹车”是坏的。家属最容易犯的错，是试图用讲道理、摆事实、算账来让患者停下来——这几乎不会成功，还容易激化冲突。急性期的医学目标很具体：**保证人身安全、降低兴奋度、恢复睡眠、控制精神病性症状、防止脱水和体力耗尽，然后把情绪拉回可维持的范围。**

这意味着用药的思路和抑郁期不同。抑郁期是“慢慢托起来”，躁狂期是“先压住火”，所以起效速度被放在很重要的位置。医生通常会在急诊或病房先评估：有没有伤人风险、有没有自杀风险、有没有脱水或感染、有没有用酒精或兴奋剂、有没有怀孕可能、肝肾功能如何。这些信息直接决定用药选择，不是走流程。

还要接受一个现实：急性躁狂的完全缓解通常需要几天到几周，不是吃一次药就安静下来。家属的期待如果放在“今天就必须正常”，很容易失望，也容易逼着医生加药。

## 二、药物策略：心境稳定剂加抗精神病药

目前的主流做法是：**心境稳定剂（锂盐或丙戊酸盐）联合一种非典型抗精神病药**，作为中重度急性躁狂的一线方案；部分情况下，单用抗精神病药也有效，尤其是躁狂程度重、需要快速控制时。【指南】这么搭配的理由是：抗精神病药控制兴奋、精神病性症状和激越更快；锂盐或丙戊酸盐负责把情绪的地基稳住，为后续维持治疗铺路。

| 临床情景 | 常见思路 | 需要留意 |
|---|---|---|
| 首次躁狂、无明显精神病性症状 | 心境稳定剂为主，必要时短期联用抗精神病药 | 先查基线化验，评估肾功能、甲状腺、血常规 |
| 躁狂严重、有幻觉妄想或明显激越 | 抗精神病药为主，联合心境稳定剂 | 监测镇静、体位性低血压、EPS |
| 混合发作 | 丙戊酸盐或抗精神病药常被优先考虑 | 自杀风险评估要放在最前面 |
| 快速循环背景 | 尽量避免抗抑郁药，调整现有方案 | 起效慢，需要耐心和随访 |
| 躁狂伴紧张症、拒食、脱水 | 考虑电休克治疗 | 不能拖，属于急症 |
| 孕期或备孕 | 由精神科与产科共同评估 | 锂盐、丙戊酸盐都有胎儿风险，不能自行处理 |

具体选哪个药，会看既往发作对什么药有效、有没有不能耐受的副作用、有没有合并躯体病、是否在备孕。**“别人吃这个好”不是选药依据**，个体差异很大，以处方为准。

有几个常见误区值得提前说清。第一，**急性躁狂不用抗抑郁药**，包括“看他抑郁得难受，加点抗抑郁药”。混合发作里加抗抑郁药，可能让激越和自杀风险更糟。第二，**不要自行叠药**。有人觉得“医生开的量不够”，把家里的旧药翻出来一起吃，这会显著增加恶性综合征、心律失常和过度镇静的风险。第三，**锂盐起效相对慢**，急性期常需要抗精神病药先顶上去，等情绪稳定后再评估锂盐的位置，这不是“锂盐没用”。

## 三、混合发作：更危险的一种“躁”

混合发作的表现很矛盾：人一边情绪低落、觉得活着没意思，一边又坐立不安、脑子转个不停、容易暴怒、睡得很少。DSM-5-TR 把这种情况描述为抑郁发作伴混合特征，或躁狂/轻躁狂发作伴混合特征。它最危险的地方在于：**抑郁带来的绝望，加上躁狂带来的冲动和能量，可能同时存在。** 这正是自杀风险最高的组合之一。【指南】

所以混合发作的处理有几个原则：

- **先评估自杀和伤人风险**，不是先调药。有没有计划、有没有手段、家里有没有人陪，这些比“今天心情几分”更重要。
- **避免抗抑郁药**，包括原本在吃的抗抑郁药，是否需要减停由医生决定。
- **丙戊酸盐和抗精神病药常被优先考虑**，锂盐在混合发作中的证据相对弱一些，但并非不能用。【指南】【研究】
- **不要用酒精、安眠药、大麻“自己镇静”**，这些会加重冲动、脱水和意识混乱。
- **电休克治疗对严重混合发作有效**，尤其是伴精神病性症状、拒食或高自杀风险时，不必等到“所有药都试过”。

家属要特别注意：混合发作的人可能看起来“还能上班、还能说话”，但内心的冲动控制已经很差。**“看起来还行”不等于安全。**

## 四、激越怎么处理：先环境，后药物

激越是指明显的坐立不安、来回走动、大声喊叫、推搡、拒绝配合。处理顺序应该是：**降低刺激 → 语言安抚 → 提供基本需要 → 必要时药物 → 最后才考虑约束。** 约束和隔离是最后手段，不是首选，而且必须由受过训练的人员在医疗监护下进行。

家属和陪护可以做的：

- [ ] 减少围观的人，关掉刺眼的灯和嘈杂的电视，说话放慢、放低。
- [ ] 不争辩、不讽刺、不威胁，也不轻易承诺做不到的事。
- [ ] 递水、递吃的，问“要不要坐一会儿”，把选择权还给他一点。
- [ ] 保持出口通畅，自己也站在能退开的位置，不去堵门。
- [ ] 把可能伤人的东西（刀、玻璃、钥匙、车钥匙）收好，但不要当面“搜身”激化冲突。
- [ ] 记录从什么时候开始不睡、吃了什么药、喝了酒没有，这些对医生很有用。

医院里，激越明显时可能会用短效的注射药物快速控制，同时监测血压、心率、体温和血氧。**这不是“惩罚”，目的是防止人伤到自己或别人。** 注射后要观察镇静程度和呼吸，尤其是同时用了酒精、苯二氮䓬类或其他镇静药的人。

## 五、什么时候必须住院

急性躁狂的住院判断，核心看三件事：**有没有危险、能不能自己照顾自己、门诊方案还撑不撑得住。**

| 维度 | 需要考虑住院的情况 |
|---|---|
| 人身安全 | 有伤人威胁或行为、危险驾驶、纵火、持械、明显攻击性 |
| 自杀风险 | 有自杀计划或准备行为，混合发作中尤其要警惕 |
| 基本生活 | 连续多日几乎不睡、不吃不喝、脱水、体力耗尽 |
| 精神症状 | 幻觉、妄想、严重思维紊乱、无法配合门诊治疗 |
| 躯体情况 | 高热、感染、电解质紊乱、甲状腺危象、物质中毒或戒断 |
| 支持系统 | 家中无人看护，或家属已无法保证安全 |
| 治疗反应 | 门诊调整无效，症状仍在加重 |

住院不是“关起来”，而是把环境变量降到最低，让药物起效、睡眠恢复、危险因素被看住。很多人住两周左右就能明显好转，具体时长因人而异。关于自愿住院与非自愿住院的法律条件，属于另一页的内容，这里只强调：**当危险已经迫在眉睫，先保证安全，再讨论程序。**

## 六、家属能做什么、不能做什么

能做的：陪诊、记录、把家里的药收好并按医嘱发放、保证有人轮班陪护、减少访客和刺激、准备好既往用药清单和过敏史、在医生问“最近有没有不睡”时如实回答。

不能做的：劝酒“助眠”、把自己的安眠药给患者吃、因为“他太吵了”而锁门关灯、用激将法、在患者面前讨论“要不要送精神病院”、把车钥匙和银行卡留在随手可拿的地方。

> **立即去急诊或拨打 120（必要时 110）：**
> - 明确威胁要伤害自己或他人，或已经动手；
> - 连续多日几乎不睡、不吃不喝，出现脱水、虚弱、意识模糊；
> - 高热、肌肉僵硬、大汗、心跳很快（警惕恶性综合征或躯体急症）；
> - 严重激越无法安抚，或出现幻觉驱使的危险行为；
> - 木僵、拒食、不说话、保持奇怪姿势不动（警惕紧张症）；
> - 混合发作中出现自杀念头或计划。
>
> **尽快联系医生（当天）：**
> - 睡眠时间明显减少、话变多、花钱变多，但还没失控；
> - 门诊加药后出现严重嗜睡、走路不稳、手抖；
> - 情绪在抑郁和兴奋之间快速切换；
> - 患者拒绝吃药，或家属已经无法保证其安全。

### 常见问题

**“能不能在家吃药，不住院？”** 如果危险可控、有人看护、能配合吃药和复诊，部分人可以门诊治疗。但只要出现伤人、自杀、脱水或严重精神病性症状，住院是更安全的选择。

**“医生为什么同时开两种药？是不是太多了？”** 急性期联合用药是常见做法，目的是一个快、一个稳。等急性症状控制后，医生通常会简化方案。可以问清楚每种药的角色，但不要自己减掉其中一种。

**“躁狂期说的话、签的字算数吗？”** 这是法律问题，判断标准是当时是否具备相应的辨认和控制能力，需要具体评估，不能一概而论。涉及合同、转账、离婚等重大事项，建议尽快咨询专业人士并保留医疗记录。
