# 5.4 拉莫三嗪

拉莫三嗪是一种常被用来“守住下限”的心境稳定剂：它对正在发作的躁狂几乎没有控制力，却比较擅长减少双相障碍的抑郁复发。这一页讲清它适合谁、为什么必须慢慢加量、皮疹到底该怎么判断，以及它和哪些药、哪些情况会“打架”。读完你至少能和医生讨论三件事：我为什么用这个药、我该盯哪些副作用、出现皮疹时第一步做什么。

## 一、它在双相障碍里的位置

拉莫三嗪最早是抗癫痫药，后来被发现能减少双相障碍的抑郁发作，于是成为心境稳定剂家族的一员。所谓心境稳定剂，是指能让情绪的高峰和低谷都不那么容易出现的一类药，它们的作用方式是“降低发作概率、减轻发作幅度”，而不是“立刻让人开心”。这一点对拉莫三嗪尤其重要：它起效慢，通常要几周甚至更久才能看出对情绪的稳定作用，不能拿它当救急药。【指南】

它的主要位置是**维持期预防抑郁复发**。CANMAT/ISBD 2018 指南把拉莫三嗪列为双相障碍维持治疗的一线选择之一，特别适合那些“躁狂不重、但抑郁反复来”的人，例如不少双相 II 型患者。【指南】对急性双相抑郁，它有一定辅助作用，但单靠它把一次正在进行的抑郁发作拉起来，效果通常不如喹硫平等抗精神病药，所以更多是“配合使用”。【研究】

反过来，急性躁狂和混合发作不是它的战场。没有可靠证据支持用拉莫三嗪单药去压住一次躁狂，医生也不会这样安排。如果有人说“吃拉莫三嗪能治躁狂”，这句话至少是不准确的。

| 使用场景 | 拉莫三嗪的位置 | 说明 |
|---|---|---|
| 预防抑郁复发 | 一线选择之一 | 需要长期服用才体现价值【指南】 |
| 急性双相抑郁 | 辅助、二线 | 起效慢，单药力度有限【研究】 |
| 急性躁狂或混合发作 | 不用它单药控制 | 没有可靠证据【指南】 |
| 快速循环 | 证据有限 | 可试用，但不能承诺效果【待验证】 |
| 双相 II 型抑郁反复 | 常见选项 | 需与医生讨论获益与皮疹风险【临床经验】 |

## 二、为什么一定要慢慢加量

拉莫三嗪最让人紧张的不良反应是皮疹，而皮疹风险和“加得太快”直接相关。身体需要时间适应这个药，血药浓度一下子升得太高，免疫系统更容易出现皮肤反应。所以医生会从一个很小的剂量开始，隔比较长的时间才往上加一次，整个加量过程可能持续数周甚至更久。这个节奏不是医生保守，而是用无数例严重药疹换来的经验。【指南】

以下几件事会明显增加皮疹风险，值得逐条对照：

- **加量过快、起始量偏高**：自己觉得“效果不够”就多吃半片，是最常见的诱因。
- **同时使用丙戊酸盐**：丙戊酸盐会让拉莫三嗪在体内的浓度明显升高，皮疹和手抖的风险都上升，医生通常会因此把加量节奏放得更慢。
- **以前吃别的药起过药疹**，或有药物过敏史。
- **漏服一段时间后，自己按原来的量接着吃**：这一点最容易被忽略。停药几天后身体对药物的耐受已经下降，直接恢复原剂量相当于“快速加量”。如果漏服超过几天，先问医生要不要重新从小剂量开始，不要自己补。
- **合并病毒感染**（比如感冒、发热）期间开始加量，皮疹更容易和感染疹混在一起，判断变难。

还有一个现实问题：拉莫三嗪起效慢，很多人吃到第二三周觉得“没感觉”，就想加快速度。这时最该做的是把感受告诉医生，而不是自己调整。**慢，是这个药安全使用的一部分。**

## 三、皮疹：普通药疹还是危险信号

吃拉莫三嗪的人里，出现某种皮疹的并不算少，其中绝大多数是良性的、可以消退的药疹。但少数会进展为 Stevens-Johnson 综合征（SJS）和中毒性表皮坏死松解症（TEN）——这两种是可能危及生命的严重皮肤反应，皮肤会像被烫伤一样大片起疱、剥脱。早期表现常常只是发热、口腔溃疡、眼睛发红，很容易被当成“上火”或感冒。区别它们，是每个服药者和家属都该掌握的一课。

| 表现 | 普通药疹 | 需要立即急诊的药疹 |
|---|---|---|
| 分布 | 躯干、四肢散在红点或小丘疹 | 面部、口腔、眼睛、生殖器等黏膜部位也受累 |
| 形态 | 红斑、丘疹，可能有痒 | 水疱、大疱、皮肤成片发暗、开始脱皮 |
| 伴随症状 | 一般没有明显发热 | 发热、咽痛、眼红畏光、口腔溃烂、面部或嘴唇肿胀 |
| 进展 | 几天内相对稳定或逐渐消退 | 数小时到一两天内迅速扩大、疼痛明显 |

还有一种需要认识的反应叫 DRESS（药物反应伴嗜酸性粒细胞增多和全身症状），通常在用药后几周出现，表现为发热、皮疹、面部水肿、淋巴结肿大，还可能累及肝、肾、血液系统。它不像 SJS 那样“看起来吓人”，但同样可以很重。

处理原则要记牢：

- **只是少量皮疹、没有发热、没有黏膜受累**：尽快联系开药医生，由医生判断是否停药、是否需要查血。不要自己一边吃一边观察一两周。
- **出现发热、口腔溃疡、眼红、起疱、脱皮、面唇肿胀、呼吸困难中的任何一项**：立即停用拉莫三嗪，直接去急诊，并告诉接诊医生“我在吃拉莫三嗪、什么时候开始加的量”。不要等预约、不要先吃抗过敏药顶着。
- **不要自行把药加回去**。严重药疹后是否能再次使用，必须由专科医生评估，很多人会就此禁用。

## 四、相互作用：哪些药会让浓度升高或降低

拉莫三嗪本身不太干扰肝脏代谢酶，所以它对其他药的影响相对小，这是它的优点。但反过来，很多药会影响拉莫三嗪的浓度，其中最重要的几个必须知道。

| 合用的药或情况 | 对拉莫三嗪的影响 | 需要注意什么 |
|---|---|---|
| 丙戊酸盐 | 浓度明显升高 | 皮疹、手抖、头晕风险上升，医生会放慢加量 |
| 卡马西平、苯妥英、苯巴比妥、利福平 | 浓度下降 | 可能疗效不足，需要医生评估 |
| 含雌激素的避孕药、激素替代治疗 | 浓度可能下降 | 停药间歇期浓度会回升，情绪和副作用可能波动 |
| 锂盐、奥氮平 | 影响较小 | 仍要观察镇静、头晕等叠加效应 |
| 酒精、大麻 | 不改变浓度，但叠加镇静和判断力下降 | 治疗期尽量不用 |

对女性来说，还有两个绕不开的话题。**避孕药**：含雌激素的复方口服避孕药会加快拉莫三嗪的清除，让浓度偏低；而在每盒药的停药间歇期，浓度又会回升。有些人会发现“吃药那三周情绪稳、停药那几天反而烦躁或起疹”，这值得和医生讨论，而不是自己换药。**怀孕与哺乳**：孕期拉莫三嗪的清除率会逐渐上升，血药浓度可能下降到孕前的几分之一，产后又迅速回升，所以孕前、孕期和产后都需要重新评估和监测，不能沿用孕前的方案不变。哺乳期进入乳汁的量相对不多，但早产儿、新生儿的情况特殊，需要儿科和产科一起看。【指南】

## 五、日常怎么吃、怎么记

拉莫三嗪一天吃一次还是分两次、饭前还是饭后，按医生和说明书的安排执行即可，关键是**固定**。固定时间吃药，能减少血药浓度的大起大落，也让你更容易发现“漏了没有”。

可以照做的清单：

- [ ] 把服药时间绑在一个每天必做的动作上，比如刷牙后、早饭时。
- [ ] 在手机里设提醒，并准备一份“漏服了怎么办”的书面说明，是医生或药师写的。
- [ ] 加量期间，每周拍一次皮肤照片存档，出现变化时能说清“从哪天开始、哪里先起”。
- [ ] 记录睡眠时长和情绪走向，尤其是“话变多、睡得少还很有精神、易怒”这类信号。
- [ ] 每次看诊带上所有正在吃的药、保健品和避孕药，让医生核对相互作用。
- [ ] 换厂家、换剂型时告诉医生，并在换后几周留意皮疹和情绪变化。
- [ ] 计划怀孕、已经怀孕或准备哺乳，提前说，不要等到产检时才提。
- [ ] 不自行加量、减量、停药；不把拉莫三嗪当成“情绪不好就加半片”的救急药。

常见副作用大多是轻微和暂时的：头晕、看东西重影、嗜睡或失眠、头痛、恶心、手抖。手抖在合用丙戊酸盐时更常见。少数人会出现易激惹、坐立不安，这类变化常被误认为“病情本身”，其实可能是药物反应，值得记录后反馈。极少数情况下会出现无菌性脑膜炎（头痛、发热、脖子发硬、怕光）、血液系统异常或肝功能异常，出现相应症状要就医查因。

## 六、什么时候需要联系医生 / 去急诊

> **立即去急诊或拨打 120：**
> - 皮疹同时有发热、口腔溃疡、眼睛红痛、皮肤起疱或脱皮、面唇肿胀、呼吸困难；
> - 剧烈头痛伴发热、脖子发硬、怕光、呕吐（警惕无菌性脑膜炎）；
> - 意识模糊、抽搐、尿量明显减少、皮肤或眼白发黄；
> - 出现自杀念头、自伤行为，或情绪突然转向极度兴奋、整夜不睡、行为失控。
>
> **尽快联系开药医生（当天或次日）：**
> - 新出现皮疹，但没有上面这些危险信号；
> - 加量后头晕、复视、手抖明显，影响走路或工作；
> - 连续几天漏服，或不确定该怎么恢复；
> - 情绪变得易怒、话多、睡得少但精力旺盛（可能是转躁的早期信号）；
> - 开始或停用避孕药、抗癫痫药、抗生素等可能相互作用的药；
> - 计划怀孕、已怀孕或准备哺乳。

### 常见问题

**“起疹子是不是就一定很严重？”** 不是。多数是良性药疹，但“多数”不等于“可以自己赌”。判断权在医生，你要做的是及时报告、及时就诊，并把危险信号记牢。

**“起过一次疹子，以后还能再用吗？”** 由医生判断。轻微药疹在密切观察下有时可以再用，严重药疹（SJS/TEN、DRESS）通常终身禁用。不要自己试着“再吃一点看看”。

**“情绪稳定了，能不能停？”** 拉莫三嗪的价值就在长期维持，突然停可能让抑郁复发。停药要由医生安排，通常需要逐渐减量，并配合睡眠和复诊计划。

**“为什么医生让我和丙戊酸盐一起吃？”** 这个组合在临床上有使用，但丙戊酸盐会抬高拉莫三嗪浓度，所以加量要更慢、观察要更密。不是不能一起用，而是不能按常规速度加。

**“漏了一两天怎么办？”** 偶尔漏一次，想起来就补，但不要一次吃双份。漏了几天，不要自己按原量恢复，先问医生。**这条规则比“补不补”更重要。**

**“吃了两个月还没效果，是不是没用？”** 它的作用是减少未来的抑郁发作，不是立刻提升情绪。评估需要时间，也需要看整个疗程里发作的频率和严重度，而不是某一天的心情。
