# 13.1 心境日记与复发预警表

心境日记不是给医生交的作业，也不是用来证明自己“够不够努力”。它的用处很具体：把“我最近不太好”这种模糊的感觉，换成“我从周三开始每天只睡四小时，话变多，花了两笔计划外的钱”这样能被医生用上的信息。这一页给你一份可以照抄的每日记录表、一张可以填自己信号的复发预警表，以及把它们带进诊室的用法。每天花两分钟，比发作后回忆两周可靠得多。

## 一、为什么值得记

双相障碍的复发往往不是一夜之间发生的。在明显发作之前，常有一段“前驱期”：睡眠先变、脾气先变、花钱先变，本人觉得“还行”，旁人已经看出不对。问题在于，人对自己的变化最不敏感，尤其是轻躁狂——那种状态主观上很舒服，很难被自己识别。【指南】

日记解决的正是这个盲区。它有三个作用：

- **把主观感觉变成可比较的数字。** “今天情绪 7 分”比“今天还行”更能看出趋势。
- **让家属的观察有落点。** 家人说“你最近不对”，可以翻到具体哪几天睡少了、话多了。
- **让复诊更有效率。** 医生最缺的是时间，一份两三行的摘要，胜过十分钟的回忆。

要说明的是，日记不能替代就诊，也不能用来自己诊断、自己调药。它只是把信息攒起来，交给专业判断。【临床经验】

## 二、每天记什么

记太多会坚持不下去，记太少又看不出趋势。下面这几项是性价比最高的。

| 项目 | 怎么记 | 为什么值得记 |
|---|---|---|
| 入睡与起床时间 | 写具体钟点，不写“早/晚” | 睡眠是躁狂最早、最可靠的信号之一 |
| 实际睡眠时长 | 估算总小时数 | 区分“睡得少但不困”和“失眠后很累” |
| 情绪方向 | 低落／平稳／偏高／又高又低 | 混合特征常表现为“又高又低” |
| 情绪强度 | 0 到 10 分，自己定标准 | 单看方向会漏掉“程度在加重” |
| 精力与活动量 | 0 到 10 分，或今天做了几件事 | 活动量骤增常早于情绪被察觉 |
| 冲动念头 | 有无，具体是哪一类 | 花钱、辞职、飙车、争吵是最需要预警的 |
| 服药 | 早／中／晚各打勾，漏了哪次写清楚 | 漏服是复发常见的起点 |
| 副作用 | 手抖、恶心、皮疹、腹泻、心慌等 | 有些副作用需要尽快处理，不能等下次复诊 |
| 月经周期 | 第几天（如适用） | 激素波动与情绪、快速循环可能相关 |

如果只能记三项，就记**睡眠、情绪方向、服药**。这三项已经能覆盖大部分预警信息。【临床经验】

## 三、一张可以照抄的心境日记

下面这份表可以每天抄一遍，也可以打印一叠。用手机备忘录照着写同样可以，不必追求格式。

```
日期：____年__月__日　星期__
昨晚入睡：____　今早起床：____　实际睡眠：__小时
夜里醒了几次：__　睡眠质量（1–5）：__
今天最明显的情绪（圈一个）：低落／平稳／偏高／又高又低
情绪强度（0–10）：__　精力（0–10）：__　焦虑（0–10）：__
今天完成的事（0–10）：__
有没有冲动念头：无／有（花钱／辞职／吵架／开车／其他：______）
服药：早 □　中 □　晚 □　漏了：______
副作用：无／有（手抖／恶心／皮疹／腹泻／心慌／其他：______）
月经周期（如适用）：第__天
今天最想记住的一件事：____________________
```

**简化版（忙的时候用一行）：**

```
10/21 睡4h 偏高7 精力8 漏晚药 无皮疹
```

这一行已经包含了日期、睡眠、情绪方向与强度、精力、服药和副作用。坚持记一行，比三天打鱼两天晒网地写长文有用。

### 本周就能开始的五件事

- [ ] 把模板抄在纸上，贴在床头或牙刷旁
- [ ] 设一个固定提醒，时间选在晚上刷牙后
- [ ] 先只记睡眠、情绪、服药三项，坚持七天
- [ ] 让一位家人知道你在记，必要时可以帮你补
- [ ] 七天后回看一遍，找出“最不正常的那一天”

## 四、复发预警表：写你自己的信号

通用的“睡眠减少、话多、花钱”清单用处有限，因为每个人的前驱信号不一样。有人先失眠，有人先暴躁，有人先疯狂整理房间，有人先变得特别虔诚或特别爱社交。预警表要写“我自己的样子”。【临床经验】

| 信号类别 | 我自己的具体样子 | 家人能做什么 | 出现几天该联系医生 |
|---|---|---|---|
| 睡眠 | 例如：连续两晚只睡四小时还不困 | 不争辩，记录钟点，减少晚上刺激 | 两到三晚 |
| 话量与语速 | 例如：打电话停不下来，同时聊五个话题 | 缩短对话，不激化，记录下来 | 两天 |
| 花钱与投资 | 例如：突然下单大件、想借钱投资 | 暂管大额支付方式，不当场争吵 | 当天 |
| 易怒 | 例如：为小事摔东西、骂人 | 降低音量，离开现场，避免正面冲突 | 当天 |
| 社交与活动 | 例如：凌晨给很多人发消息、突然要见很多人 | 帮忙减少安排，保证睡眠时间 | 两到三天 |
| 抑郁前兆 | 例如：开始不回消息、说“我是负担” | 主动陪伴，直接问有没有轻生念头 | 当天 |
| 混合信号 | 例如：一边哭一边说脑子停不下来 | 不独处，收好危险物品，尽快就医 | 立即 |
| 躯体与药物 | 例如：手抖加重、皮疹、呕吐 | 拍照记录，联系医生，必要时急诊 | 当天 |

填写建议：不要一次写满八行。先挑三条你或家人最能识别的，写具体到“能看见的行为”，不要写“情绪不好”这种没法观察的描述。写好后复印两份，一份给家人，一份放在病历本里。

两个细节值得注意。第一，预警表要写“出现几天该行动”，否则家人容易一直等“再看看”。第二，行动要具体到人：谁打电话、谁陪着去医院、谁保管银行卡，事先说好，发作时就不用现商量。【临床经验】

## 五、复诊时怎么用，以及记不下去怎么办

### 三分钟讲完这段时间

医生时间有限，可以按这个顺序说：

1. **睡眠**：“这两周平均睡五小时，最近三天只睡四小时，白天不困。”
2. **情绪与活动**：“情绪偏高，7 分左右，话比平时多，同时开了三个项目。”
3. **服药与副作用**：“晚间的药漏了两次，手抖比以前明显。”
4. **最担心的一件事**：“我怕又像上次那样花钱失控。”

这四句比“我最近还行吧”有用得多。如果记了日记，直接把本子递过去，指着异常的那几天说。

### 记不下去是常态

很多人记了两周就停了，然后觉得“我又失败了”。其实记录中断本身就是信息：可能那段时间状态差、可能模板太复杂、也可能你并不需要每天记。可以这样调整：

- 把记录改成“只在异常日记录”，平时不写。
- 用手机语音，一句话说完，不用打字。
- 让家人代记睡眠和服药，你只记情绪。
- 设一个每周一次的回看，而不是每天逼自己。

### 隐私与边界

日记里会有很多私人的东西：冲动念头、花销、关系冲突。它默认只给医生看。给家人看之前，先说清楚范围；电子记录建议加锁，不要把内容发到公开群组。病历和诊断属于敏感信息，分享前想清楚后果。【临床经验】

### 容易踩的坑

**“这周断了两天，干脆不记了。”** 记录的价值在趋势，不在满分。断了就从今天接上，在那一行写“断了两天”，本身就是有用的信息。

**“记得很细，但从来不带给医生看。”** 记录如果只留在本子里，作用会少一大半。复诊时至少读出异常的那几天。

**“家人为了‘关心’翻我的日记。”** 这需要提前谈边界：可以约定“只看预警信号，不看内容”，或者由你每周口述一次摘要。信任比监控更能帮上忙。

## 六、什么时候需要联系医生或去急诊

> **立即呼叫 120 或去最近医院急诊：**
> - 出现自杀念头、计划或自伤行为
> - 混合状态下同时绝望和“停不下来”，冲动明显
> - 躁狂状态下行为失控、冲动伤人、危险驾驶、离家出走
> - 服锂盐后严重手抖、走路不稳、反复呕吐、意识模糊
> - 服药后高热、肌肉僵硬、意识改变，或皮疹伴发热、口腔溃疡、起疱脱皮
>
> **建议一到三天内联系医生：**
> - 日记显示连续三晚睡眠明显减少，白天不困
> - 情绪连续多天偏高或易怒，家人说“像换了个人”
> - 抑郁加重两周以上，或开始回避所有人
> - 漏服药超过两三天，或出现新的、让人难受的副作用
>
> 拿不准时按严重处理。也可拨打 **12356** 心理援助热线。
