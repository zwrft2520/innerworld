# 13.3 复诊沟通单与用药记录

很多人复诊时只有五分钟，坐下后脑子一片空白，最后只说了一句“还行”，拿了同样的药回家。问题不在你不会表达，而在没人教过你怎么在五分钟里说清两周的事。这一页是一份可以直接打印带走的沟通单：诊前准备什么、诊中必说哪几句、必问哪几个问题、用药和副作用怎么记，以及锂盐、丙戊酸盐、拉莫三嗪这三类药各自要盯什么。照着填，复诊会变得具体很多。

## 一、诊前：把“说不清”变成“说得出”

复诊前一天花十分钟，比在候诊区临时回忆有用得多。

- [ ] 把这段时间的药盒、处方、化验单装进一个袋子
- [ ] 写下最近两周的睡眠：平均几点睡、几点起、夜里醒几次
- [ ] 写下情绪最高和最低的那两天，各发生了什么
- [ ] 写下有没有漏服药、漏了哪几次、为什么漏
- [ ] 写下让你最难受的三个副作用，以及出现的时间
- [ ] 写下这次最想问的一个问题（只能选一个，想清楚）
- [ ] 如果家属陪同，让家属也写三条观察，进诊室后交给医生

为什么要写下来？因为诊室里容易被医生的提问带着走，出来才想起“忘了说手抖”。一张纸能兜住这些。【临床经验】

家属的观察尤其重要。轻躁狂和早期复发，本人往往不觉得有问题，家人却已经看出“话变多了、晚上不睡、开始乱买东西”。把这些具体行为写下来，比说“他最近不太正常”有用得多。

## 二、诊中必说：四句话讲清这段时间

医生需要的信息是结构化的。可以按下面这个顺序说，每句都带具体数字或事实。

| 要说的 | 别这样说 | 可以这样说 |
|---|---|---|
| 睡眠 | “睡得不太好” | “这两周平均睡五小时，最近三晚只睡四小时，白天不困” |
| 情绪 | “情绪不太稳定” | “上周三开始明显偏高，话多、坐不住，昨天又突然很低落” |
| 服药 | “药有在吃” | “早晚都吃了，晚上的药漏了两次，都是加班太晚” |
| 副作用 | “有点不舒服” | “手抖比以前明显，拿筷子会抖，下午更重” |
| 功能 | “还行” | “这周请了两天假，开会时注意力跟不上” |
| 风险 | （不说） | “有过不想活的念头，但没有计划” |

最后一行最容易被跳过，也最重要。很多人怕说了被住院、被加药，就干脆不提自杀念头。但医生无法处理你不知道的事，而自杀风险是双相评估里必须问的一项。如果当面说不出口，可以提前写在纸上递过去。【指南】

## 三、诊中必问：把决定权用起来

复诊不是“听医嘱”，是双向沟通。下面这些问题可以挑两三个问，不必一次问完。

- 这次诊断或判断的依据是什么？是症状变了，还是病程有了新信息？
- 现在这个方案，主要是控制哪一个方向：躁狂、抑郁，还是预防复发？
- 如果出现什么情况，需要提前联系你，而不是等下次复诊？
- 这个药最需要我注意的副作用是什么？出现到什么程度要联系你？
- 需要多久查一次血、查哪些项目？下次复查安排在什么时候？
- 如果漏服了一次，应该怎么处理？
- 如果要减药或停药，应该怎么安排？什么情况下不适合减？
- 现在能不能喝酒？能不能熬夜？运动和出差要注意什么？
- 有没有需要同时做的心理治疗或作息调整？
- 下次复诊前，我需要记录什么带给你？

关于减药停药，一定要问清楚“怎么安排”，而不是自己决定。突然停用某些药物可能出现撤药反应、失眠反跳或复发；锂盐突然停用后复发风险会升高。这些都需要医生安排节奏。【指南】

## 四、用药记录表：照抄就能用

药物记录不需要复杂，能坚持才有用。下面这份可以打印成一张表，一行一天。

```
日期　　药名（早）　　药名（中）　　药名（晚）　　漏服？　副作用　　睡眠
10/21　□　　　　　　□　　　　　　□　　　　　无　　　手抖　　　5h
10/22　□　　　　　　□　　　　　　□　　　　　漏晚　　无　　　　4h
```

如果同时吃几种药，建议单独列一张“用药清单”，写清楚药名、外观（颜色、形状）、每次吃几片、什么时候吃、为什么吃。这张清单在急诊、住院、换医生、出国时都能救命——尤其是意识不清、无法自己说明的时候。

| 记录项 | 为什么重要 |
|---|---|
| 药名与外观 | 急诊时能快速核对，避免重复用药 |
| 服用时间 | 判断漏服、判断副作用与服药的关系 |
| 漏服情况 | 漏服常常是复发的前奏，值得和医生讨论原因 |
| 副作用与出现时间 | 区分“刚加药的反应”和“需要处理的信号” |
| 血液检查结果 | 锂盐、丙戊酸盐需要看趋势，不只看单次 |
| 同时使用的其他药 | 感冒药、止痛药、抗生素都可能与心境稳定剂相互作用 |

要特别提醒：很多常见的止痛药、感冒药、利尿剂会影响锂的血浓度，一些抗生素和抗癫痫药会影响拉莫三嗪和丙戊酸盐的血浓度。看其他科时，主动告诉医生你在服哪些精神科药物，别等医生问。【指南】

## 五、三种需要重点监测的药

这三类药在双相治疗里很常用，也各有必须盯住的风险。下面写的是“监测什么、警惕什么”，具体多久查一次、查哪些项目，由医生根据你的情况安排。

| 药物 | 常规监测 | 必须立即处理的信号 |
|---|---|---|
| 锂盐 | 血锂浓度、甲状腺功能、肾功能、体重、口渴与尿量 | 严重手抖、走路不稳、反复呕吐腹泻、意识模糊、抽搐 |
| 丙戊酸盐 | 肝功能、血氨、血常规（尤其血小板）、体重、月经与妊娠计划 | 严重腹痛呕吐、意识改变、皮肤或眼白发黄、异常出血 |
| 拉莫三嗪 | 皮疹（每次加量后尤其注意）、肝功能 | 皮疹伴发热、口腔溃疡、眼红、皮肤起疱脱皮 |

### 锂盐：浓度是一把双刃剑

锂盐是双相维持治疗里证据最扎实的药物之一，但它有一个很窄的安全范围，所以需要定期查血锂。抽血时间通常有讲究（多在下一次服药前），按医生和检验科的要求来，否则结果没有意义。具体的目标范围由医生判断，不要拿别人的数值套自己。【指南】

锂盐的风险常被低估，也常被夸大。真实情况是：脱水、大量出汗、发烧、呕吐、腹泻、严格低盐饮食，以及同时使用某些止痛药、降压药、利尿剂，都可能让血锂升高，引发中毒。夏天户外工作、拉肚子、吃不下饭的时候要格外小心，出现手抖加重、走路不稳、呕吐、意识改变，要立即急诊查血锂。【指南】

长期用锂盐还要关注甲状腺和肾功能，可能出现甲状腺功能减退、多尿、口渴、体重增加。这些不是“忍忍就过去”的小事，需要定期复查、及时处理。

### 丙戊酸盐：肝脏、血氨、胰腺和生育风险

丙戊酸盐对躁狂和混合发作有效，但需要盯的项目比较多：肝功能、血氨（高氨血症可表现为嗜睡、呕吐、意识模糊）、血常规（血小板下降、异常出血）、体重增加、脱发、手抖。急性胰腺炎虽然少见，但表现为持续加重的上腹痛、呕吐，需要急诊。【指南】

还有一条必须单独讲：**丙戊酸盐在孕期有明确的致畸风险，也会影响胎儿神经发育。** 育龄女性使用前必须和医生讨论避孕、备孕计划；已经怀孕或计划怀孕，不能自行停药，也不能自行继续用，要尽快找医生联合评估。突然停药可能导致复发，同样有风险，这个决定必须由医生和你一起做。【指南】

### 拉莫三嗪：皮疹是要紧事

拉莫三嗪对双相抑郁的维持治疗有帮助，它最需要警惕的是皮疹。多数皮疹是良性的，但极少数会进展为 Stevens-Johnson 综合征（SJS）或中毒性表皮坏死松解症（TEN），这类反应可能危及生命。加量必须缓慢、按医生安排，不能自己加速；与丙戊酸盐合用时加量通常更慢。【指南】

出现皮疹，尤其伴随发热、口腔溃疡、眼红、面部或颈部肿胀、皮肤起疱或脱皮，要**立即停药并急诊**，不要抱着“再看看”的心态等它自己消。停药后也不要自行恢复用药，是否再用、怎么用，必须由医生判断。【指南】

## 六、诊后与紧急情况

复诊结束前，做三件事：把医生说的方案复述一遍确认（“所以我早上的药不变，晚上的药做了调整，两周后复查血，对吗”）；把下次复诊时间写进日历；把这次的用药清单更新一遍。

如果诊后出现新问题，不要等到下次复诊。多数医院有电话咨询、互联网医院或复诊加号渠道，可以先问清楚。

> **立即呼叫 120 或去最近医院急诊：**
> - 出现自杀念头、计划或自伤行为
> - 服锂盐后严重手抖、走路不稳、反复呕吐、意识模糊、抽搐
> - 服丙戊酸盐后严重腹痛呕吐、意识改变、皮肤或眼白发黄、异常出血
> - 服拉莫三嗪后皮疹伴发热、口腔溃疡、眼红、起疱脱皮
> - 服药后高热、肌肉僵硬、意识改变、大汗（警惕恶性综合征）
> - 同时使用多种增加 5-羟色胺的药物后出现高热、震颤、反射亢进、腹泻、躁动
>
> **建议当天或次日联系医生：**
> - 漏服药超过两三次，或连续两天完全没吃
> - 出现新的副作用，虽然不严重但让人难受
> - 睡眠连续三晚明显减少，白天不困
> - 情绪明显高涨或易怒，家人说“像换了个人”
> - 抑郁加重两周以上，或开始回避所有人
>
> 拿不准时按严重处理。也可拨打 **12356** 心理援助热线。

### 容易踩的坑

**“医生太忙，我不太好意思问。”** 把问题写在纸上递过去，通常比开口容易。一次问两三个，比一次问十个更容易得到回答。

**“副作用忍忍就过去了。”** 有些副作用会随时间减轻，有些（皮疹、意识改变、严重腹泻、异常出血）必须立刻处理。分不清就问。

**“血检结果我自己看不懂，反正医生会说。”** 可以请医生把关键几项圈出来，写上“正常/需要关注”，下次自己也能对照。
