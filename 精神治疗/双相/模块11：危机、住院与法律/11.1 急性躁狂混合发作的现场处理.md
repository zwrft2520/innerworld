# 11.1 急性躁狂混合发作的现场处理

这一页讲家人或同伴在躁狂、混合发作现场可以做什么：怎么减少刺激、怎么说话、什么时候打 120 或 110、哪些事绝对不要做。它不教你“制服”任何人，也不鼓励强行按压或捆绑。目标是让场面先安全下来，把人送到能处理的地方。适合正在面对发作的家属，也适合提前做准备的本人和同伴。

## 先处理环境，再处理对话

躁狂发作时，人的感官常常是过载的：声音显得更响，灯光更刺眼，别人的动作更快，信息涌进来却很难筛选。这时候讲道理、争论、围一圈人看着，都会让情况更糟。

先做的是“减法”：

- 减少人数：只留一两个本人信任、说话能听进去的人，其他人先离开房间。
- 降低声音：关掉电视、音乐，说话放低、放慢。
- 降低光：拉上窗帘或调暗灯光，避免闪光和强光。
- 清出空间：把易碎、可投掷、可伤人的东西收走，包括刀具、玻璃杯、酒瓶、工具、车钥匙，但不要当着面大动作地搜。
- 保留出口：确保本人和你都有可以离开的通道，不要把人堵在角落。
- 不要围堵、不要按住、不要几个人同时说话。

如果场面已经失控，比如砸东西、持械、打人、自伤，环境处理让位给安全撤离：其他人先离开，报警，不要试图用身体挡住。财物可以再买，人受伤了很难补。

### 先判断这是不是医疗急症

有些躁狂样表现其实是躯体问题：高热、感染、脱水、甲状腺危象、药物中毒、谵妄、低血糖。这些会要命，处理顺序完全不同。

出现以下情况，不要在家“观察”，直接打 120：

- 高热、大汗、意识模糊、抽搐。
- 几天几乎不吃不喝，站不稳、眼窝凹陷、尿很少。
- 正在服锂盐，出现严重手抖、走路不稳、反复呕吐腹泻。
- 突然变得非常安静、不动不说话、维持奇怪姿势，可能是紧张症。
- 误服或过量服药。

## 怎么说话：短、慢、具体、给选择

急性躁狂时，抽象的劝说基本无效。“你冷静一点”“你这样不对”“你生病了”这类话，容易被听成否定和挑衅。

可以用的原则：

- 句子短：一句话一个意思，不超过十几二十个字。
- 语速慢、音量低：比对方慢半拍，音量比对方低一点。
- 说感受，不说诊断：“我看你现在很烦躁”比“你在躁狂”更容易被接住。
- 认可情绪，不认可危险内容：“我知道你现在觉得这件事特别重要”，不必附和“你必须马上投这笔钱”。
- 给两个具体选择：“你想在客厅坐一会儿，还是去阳台透透气？”比“你去休息”有效。
- 一次只问一件事，给时间等回答。
- 保持距离：一臂半到两臂，不背对，不突然伸手。
- 提前说明动作：“我要把桌上的杯子拿走，避免打碎。”不要突然抢东西。

不要争辩。争论妄想内容，比如“你说的那个人根本不存在”，通常只会升级冲突。你不需要同意，也不需要驳倒，只需要把话题带回安全和具体的事：“这件事我们记下来，等医生来了再说。”

也不要用激将、嘲讽、威胁。“你再这样我就报警”“你就是作”这类话，可能暂时压住，也可能直接点燃。报警可以是必要措施，但不该被当作吓唬人的筹码。

| 情形 | 不建议 | 可以试 |
|---|---|---|
| 说话很快、停不下来 | 打断、纠正每一句 | 听一会儿，用短句回应，慢慢降速 |
| 坚信被针对、被监视 | 争论“没人害你” | “我知道你有这种感觉，在这里你是安全的” |
| 要求马上出门、开车 | 抢钥匙、堵门 | 先拖时间，提议坐下谈，必要时报警 |
| 砸东西 | 冲上去夺、几个人按住 | 撤到安全处，清场，报警 |
| 拒绝吃药 | 强行灌药、把药混进饮料 | 不硬来，联系医生或急诊 |
| 自伤 | 抢工具、指责 | 移除危险物，保持陪伴，去急诊 |
| 辱骂、推搡 | 对骂、还手 | 后退、离开房间、求助 |

说话的目标不是“说服他承认有病”，而是“让接下来的十分钟更安全”。这两件事经常被混在一起，结果两件都做不到。

## 什么时候打 120、什么时候打 110

这是最容易犹豫的一步。原则是：**只要有即时的人身危险，就先打电话，不要先想着“再劝劝”。**

打 120，急救：

- 意识不清、昏迷、抽搐、高热、严重脱水、虚弱到站不住。
- 疑似药物中毒、过量服药、严重过敏、胸痛、呼吸困难。
- 自伤或伤人后有明显外伤、出血。
- 紧张症表现：不吃不动不说话、维持奇怪姿势、对外界反应很差。
- 需要医疗转运才能安全到达医院。

打 110，报警：

- 持械、威胁伤人、已经动手、砸毁财物、纵火。
- 危险驾驶、要开车上路、在马路中间、高处、水边等危险位置。
- 有明确的伤人计划或目标。
- 你无法靠近，无法保证自己和他人安全。
- 需要协助送医时，警方是现场处置的力量。

顺序上：有人受伤或意识问题，先 120；有暴力或持械，先 110，必要时两个都打。打电话时说清楚：地址、几个人、有没有武器、有没有人受伤、对方现在的状态、有没有孩子在场。

注意：报警的目的是“让现场安全、让人得到评估”，不是“惩罚”。跟接线员说“他生病了，现在有危险”，比说“他疯了”更有用，也更不容易让现场对抗升级。

如果本人还愿意配合，让他自己走出门、自己上车，通常比被抬走好。可以这样说：“我们去医院让医生看看，先把现在这个难受劲处理一下。”不要承诺“看完就回来”这类你做不到的事，也不要在车上继续争论。

## 不要做的事

- **不要强行制服。** 几个人按住、压在地上、用绳子或胶带捆绑，可能导致窒息、骨折、肌肉损伤，尤其在被按压胸背时；也会极大增加对方的恐惧和反抗，让冲突升级。约束是医疗行为，应在医疗机构由受过训练的人按规范实施，不是家属在现场该做的事。
- 不要扇耳光、泼冷水，或者用“打醒”的方式。
- 不要围一圈人盯着看，不要拿手机拍。
- 不要争辩妄想，不要嘲笑，不要模仿对方的语速。
- 不要强行灌药，不要把药混进饮料里。
- 不要在对方激动时突然触碰，或者从背后靠近。
- 不要拿走手机、钥匙、钱包作为“惩罚”。因安全原因暂管可以，但要说明，并尽快归还。
- 不要让本人开车，也不要自己一边吵架一边开车。
- 不要用酒精“让他冷静”。
- 不要独自处理有武器、有暴力史的场面。
- 不要在发作现场讨论“你到底有没有病”“要不要住院”这类大问题。

关于“不要强行制服”，值得再解释一句。很多家属是出于爱和害怕才按住对方，但现场按压的风险被严重低估：人在剧烈挣扎时，胸腹受压几分钟就可能缺氧；有心脏病、肥胖、喝酒的人风险更高。而且一旦动手，信任很难修复，下一次发作时对方会更抗拒求助。真正专业的做法是降级、撤离、求助，而不是比力气。

### 等急救到来之前，家里可以做的准备

- 一个人负责沟通，其他人退到安全距离。
- 把其他家人、孩子、宠物带到另一个房间或邻居家。
- 清出通道，把门口的车挪开，方便急救人员进出。
- 准备好信息：姓名、年龄、诊断、正在吃的药（拍照或带药盒）、过敏史、既往住院医院、主治医生电话、医保卡和身份证。
- 记录时间线：从哪天开始睡不好、说了什么、做了什么，医生会问。
- 如果本人愿意，让他自己走出去、上车。
- 保持电话畅通，把 120、110、医生、12356 的号码放在手边。

- [ ] 只留一两个人，声音和灯都调低
- [ ] 危险物品和车钥匙已移开
- [ ] 我站在能退出的位置，没有堵住对方
- [ ] 我说话短、慢、低，没有争辩
- [ ] 我已经判断要不要打 120 或 110
- [ ] 证件、药盒、医生电话在手边
- [ ] 孩子和老人已转移到安全处
- [ ] 我没有试图按压或捆绑对方

### 容易踩的坑

- 觉得“家丑不可外扬”，拖到出事才求助。
- 把“他在骂人”当成“他不会伤人”，忽略升级的可能。
- 为了让他吃药，把药混进饭里，结果信任彻底破裂。
- 在楼道里大声争执，围观的人越多，越难下台。
- 报警时只说“他疯了”，没有说清有没有武器、有没有人受伤。
- 事后不复盘，也不和医生讨论这次是怎么升级的。

## 什么时候需要联系医生 / 去急诊

> **出现以下任何一条，立即呼叫 120，必要时拨打 110：**
>
> - 持械、伤人、纵火、危险驾驶。
> - 明确的自杀计划或自伤行为。
> - 意识不清、抽搐、高热、几天几乎不吃不喝。
> - 疑似中毒或过量服药。
> - 紧张症表现：不吃不动不说话、维持奇怪姿势。
> - 你无法保证任何人的安全。
>
> 如果还没有到立即危险，但已经连续几天睡很少、话多、花钱失控、和家人冲突升级，当天联系精神科医生，要求加急评估，不要等到“明天看看”。不确定时按严重处理，也可以拨打 **12356** 心理援助热线。
