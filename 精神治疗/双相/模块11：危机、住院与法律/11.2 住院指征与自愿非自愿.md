# 11.2 住院指征与自愿非自愿

这一页讲什么情况需要住院、自愿住院和非自愿住院在法律上分别是什么条件、病房里大概会发生什么、出院前要准备什么。它只讲原则，不替代法律条文，具体认定和程序以现行法律和当地规定为准。适合正在犹豫“要不要送医院”的家属，也适合担心“被关起来”的患者。

## 什么情况需要住院

住院不是因为“病得丢人”，而是因为门诊条件不够：需要 24 小时观察、需要快速调整治疗、需要把危险因素从环境里拿掉。

常见的住院理由可以分几类。

安全类：

- 有自杀念头、计划、准备行为，或近期有自杀尝试。
- 有伤人、纵火、危险驾驶等风险。
- 严重自伤，比如割伤、烧伤、吞异物。
- 无法保证基本安全，比如在马路中间、高处、水边徘徊。

精神症状类：

- 幻觉、妄想明显，影响判断和行为。
- 严重躁狂：几天不睡、行为紊乱、无法自理、冲动失控。
- 混合状态，烦躁到坐立不安，冲动和绝望同时存在。
- 紧张症：不吃不动不说话、木僵、维持奇怪姿势。
- 需要与躯体疾病、物质使用、谵妄鉴别，门诊做不完。

躯体与治疗类：

- 需要监测药物不良反应，比如锂盐、丙戊酸盐相关问题。
- 需要电休克治疗等只能在医院完成的治疗。
- 门诊调整失败，症状持续加重。
- 严重的共病：感染、脱水、拒食、体重骤降。

支持系统类：

- 家里没有人能看护，或者家庭环境本身就是高风险，比如持续冲突、暴力、家里有可得的危险物品。
- 居住地离医院很远，无法及时复诊。

| 情况 | 门诊能不能处理 | 是否考虑住院 |
|---|---|---|
| 轻躁狂、能自理、有家人看护 | 多半可以 | 加急门诊，密切随访 |
| 躁狂伴冲动消费、彻夜不眠 | 风险高 | 建议住院评估 |
| 有自杀计划但能配合 | 需要立即评估 | 通常需要住院 |
| 拒食拒水、意识不清 | 不能 | 急诊，可能需要住院 |
| 紧张症 | 不能 | 住院，可能需要电休克 |
| 药物不良反应需监测 | 视情况 | 可能需要住院 |

“要不要住院”不是一个非黑即白的问题。可以和医生讨论：能不能加急门诊、能不能增加随访、能不能先调整家里环境、有没有日间病房或社区支持。把选项摆出来，比只问“必须住吗”更有用。

## 自愿与非自愿：法律上的两条路径

中国《精神卫生法》确立了一个总原则：**精神障碍的住院治疗实行自愿原则。** 也就是说，患者自己同意，是住院的默认前提。

在这个原则之外，法律规定了可以对严重精神障碍患者实施非自愿住院的情形，通常概括为两类：

1. 已经发生伤害自身的行为，或者有伤害自身的危险。
2. 已经发生危害他人安全的行为，或者有危害他人安全的危险。

这两类的共同前提是：**诊断为严重精神障碍，并且有相应的行为或危险。** 不是“家属觉得需要”，也不是“医生觉得麻烦”，更不是“不听话”。

几个容易误解的点：

- “严重精神障碍”有特定的医学和法律含义，不等于日常说的“病得比较重”。
- 非自愿住院需要符合法定条件的诊断和评估，并按程序办理，不是家属签字就能把人留下。
- 伤害自身的情形，通常还涉及监护人是否同意的问题；法律对监护人不同意时的处理有规定。危害他人安全的情形，法律规定了再次诊断、鉴定等程序，监护人阻碍治疗时也可能需要公安机关协助。具体以现行法律条文和当地实施规定为准。
- 即使是非自愿住院，患者仍然享有通信、会见、申诉等权利，具体范围按法律和医院规定执行。
- 不同地区在送诊主体、复核流程、社区衔接上可能有细化规定。

| 对比项 | 自愿住院 | 非自愿住院 |
|---|---|---|
| 谁提出 | 本人同意并签署 | 符合法定情形，由相关主体送诊或决定 |
| 核心条件 | 本人自愿 | 严重精神障碍，加上伤害自身或危害他人安全的行为或危险 |
| 知情同意 | 本人签署 | 按法定程序，保障告知与救济 |
| 主要目的 | 治疗与合作 | 安全保护与治疗 |
| 权利 | 通信、会见、申诉等 | 同样享有法定权利，程序上有额外保障 |

### 家属能做什么

- 把观察到的行为具体写下来：哪天、几点、做了什么、有没有伤人或者自伤。
- 不要夸大，也不要隐瞒。夸大可能让患者失去信任，隐瞒可能耽误评估。
- 了解医院的急诊评估流程，问清楚“接下来会发生什么”。
- 如果患者拒绝，先问医生：现在是否符合非自愿的条件？依据是什么？程序怎么走？
- 保留好病历、告知书、决定书等材料。

家属最容易犯的错，是把“住院”当成惩罚或者抛弃。可以换一种说法：“这段时间我们一起把它处理好，等你稳定了我们再商量下一步。”这不是欺骗，而是把住院放回治疗的位置。

## 病房流程：从入院到出院

不同医院细节不同，但大致会经历这些环节：

1. 急诊或门诊评估：精神检查、风险评估、躯体检查、必要的化验和影像。
2. 入院手续：身份核验、医保登记、签署知情同意，或者按程序办理非自愿手续。
3. 物品管理：危险物品通常由病房保管，包括刀具、打火机、绳索、玻璃制品、部分电子设备；现金和证件建议家属带回。
4. 入院初期观察：记录睡眠、进食、行为、情绪、服药反应，可能需要一段时间的密切观察。
5. 治疗调整：药物、心理支持、必要时的物理治疗；医生查房，护士做日常评估。
6. 家属探视与沟通：按病房规定时间探视，可以提前准备想问的问题。
7. 出院评估：症状、风险、自理能力、家庭支持、复诊安排。
8. 出院：带药、出院小结、复诊预约、危机联系方式。

病房里可能让人不适的事，提前知道会好一些：

- 不能随便使用手机，不同病房规定不同，联系外界会受限。
- 随身物品被检查、保管。
- 作息统一，活动空间有限。
- 同病房有其他病情不同的患者。
- 在极少数必要情况下，可能实施保护性约束或隔离。这有严格的医学和法律条件，不是惩罚。

家属可以问的问题：

- 诊断是什么？依据是什么？
- 现在主要的风险是什么？
- 治疗方案是什么？需要监测什么？
- 预计住多久？取决于什么指标？
- 探视、通话怎么安排？
- 如果对住院有异议，走什么程序？

不用一次问完。可以写在一张纸上，查房或探视时逐条问，把答案记下来。住院期间信息多、情绪重，很容易听完就忘。

## 出院计划：出院不是结束

出院是风险最高的时间点之一：环境变了、随访还没接上、药可能还没完全起效、家属以为“好了”。所以出院计划要和住院治疗一起做，而不是出院当天才想。

一份可用的出院计划包括：

- 药物：名称、作用、怎么吃、可能副作用、漏服怎么办、多久续方。
- 复诊：出院后几天内？找谁？怎么挂号？
- 监测：需要查血、查心电图、查体重的时间。
- 预警信号：个人的前三条，出现后找谁。
- 睡眠与作息：起床时间、见光、避免熬夜。
- 危机预案：谁能陪着、去哪个急诊、120、110、12356。
- 工作学习：病假、复工节奏、需要单位配合什么。
- 家庭分工：谁提醒药、谁陪同复诊、谁负责钱和钥匙。
- 物质使用：酒、大麻、兴奋剂的处理。
- 出院带药的数量和续方时间，避免断药。

- [ ] 出院诊断和这次住院的主要原因
- [ ] 每种药的作用和主要副作用
- [ ] 出院后多久复诊、找谁
- [ ] 需要复查的化验和大概时间
- [ ] 出现哪些情况要提前回来
- [ ] 危机时打哪个电话、去哪个急诊
- [ ] 病假条、出院小结、费用清单是否拿到
- [ ] 家里谁负责什么

### 容易踩的坑

- 把住院当成“关起来”，不告诉患者实情，导致信任破裂。
- 出院当天就恢复全职工作，或者安排一整天应酬。
- 出院后觉得“好了”，自行停药。
- 家属把所有药收走，却不约定什么时候交还。
- 不复诊，或者复诊一次就再也不去。
- 出院计划只写在纸上，家里没人知道放在哪。

## 什么时候需要联系医生 / 去急诊

> **出现以下情况，联系病房或门诊医生；情况紧急去急诊，必要时拨打 120。**
>
> - 住院期间或出院后出现自杀念头、自伤行为。
> - 出院后几天内失眠加重、话多、烦躁、行为冲动。
> - 拒绝吃药、拒绝进食饮水。
> - 出现高热、意识改变、严重僵硬、不能坐、眼球上翻、皮疹。
> - 出院后无法复诊、断药，或者家里没人看护。
>
> 如果对住院有异议，先走医院沟通和法律规定的复核渠道，不要用冲突代替程序。情绪支持可以拨打 **12356** 心理援助热线。
