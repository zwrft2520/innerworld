# 6.3 CBT与DBT情绪调节

认知行为治疗（CBT）和辩证行为治疗（DBT）经常被一起提到，但它们解决的问题不太一样：CBT 更擅长处理“想法怎么把情绪越推越低”，DBT 更擅长处理“情绪一下子冲上来、马上就要做点什么”的时刻。这一页讲清两者的核心技术和分工，给出一套可以本周就开始练的最小版本，也说明它们各自在什么阶段不该硬做。适合已经进入稳定期、想做点结构化练习的患者和家属。

## 一、两种治疗在双相里分别管什么

| 维度 | CBT（认知行为治疗） | DBT（辩证行为治疗） |
|---|---|---|
| 主要目标 | 识别并修正失真的想法，减少回避，恢复活动 | 提高情绪耐受与调节能力，减少冲动和自伤 |
| 典型问题 | 反复抑郁、焦虑、自责、社交回避、拖延 | 情绪爆发、自伤、冲动消费、人际冲突、空虚感 |
| 核心假设 | 想法影响情绪和行为，改变想法与行为能改善情绪 | 情绪敏感加上长期不被理解的环境，会让人用极端方式调节情绪 |
| 主要技术 | 思维记录、行为实验、行为激活、复发预防计划 | 正念、痛苦耐受、情绪调节、人际效能 |
| 在双相中的位置 | 缓解期抑郁与焦虑的残留症状、复发预防【指南】【研究】 | 共病边缘型人格、自伤、情绪失调时的补充【研究】【待验证】 |
| 什么时候不宜做 | 急性躁狂、注意力无法集中、判断力明显受损时 | 严重躁狂或混合状态、无法安坐完成练习时 |

两者都是“加在药物治疗之上”的，不是替代。差别在于：CBT 更偏“想清楚再行动”，DBT 更偏“先撑过这一波，再想办法”。

## 二、CBT：把“想法—情绪—行为”拆开

CBT 的基本功是把一个模糊的难受，拆成三个可以观察的部分：当时脑子里闪过什么念头、情绪是什么、接下来做了什么。这三者互相喂养，抑郁时尤其明显：觉得自己没用，于是推掉聚会，推掉之后更确信自己没用。

**认知重构**不是“往好处想”，而是检验想法是否站得住。常用的一步是问自己几个问题：

- 支持这个想法的证据是什么？反对的证据是什么？
- 有没有别的解释？
- 如果朋友遇到同样的事，我会怎么跟他说？
- 这个想法对我有帮助吗，还是让我更动不了？

| 常见想法模式 | 例子 | 可以问自己 |
|---|---|---|
| 全或无 | “这次没做好，我就是个失败者。” | 这件事有多少是全部，有多少只是一部分？ |
| 灾难化 | “这次复发肯定又要住院，工作保不住了。” | 最坏会怎样？最可能怎样？我能做的是什么？ |
| 读心 | “他们没叫我，肯定是嫌我麻烦。” | 还有没有别的可能？我有没有问过？ |
| 应该式 | “我应该一直保持高效。” | 这个标准对病人也成立吗？是谁定的？ |
| 情绪化推理 | “我觉得没希望，所以就是没希望。” | 感觉是信息，还是事实？ |

**行为实验**是把想法当假设去检验，而不是靠说服。比如抑郁期认定“我去了也没人理我”，可以约定：去待二十分钟，记录三个人有没有跟我说话、我的情绪从几分变到几分。结果常常是“没有想象中好，但也没有想象中糟”，这个真实的差别比任何鼓励都有用。

**行为激活**的核心是“按计划行动，而不是等心情好了再行动”。把目标拆到很小：不是“恢复运动”，而是“周二下午下楼走十分钟”。完成后打勾，不评价好坏。

**复发预防**部分通常包括：写下自己的早期信号、列出触发情境、准备一张“当睡眠开始变少时我做什么”的应对卡。这部分和 6.4 的社会节律内容可以配合使用。

需要提醒的是，CBT 在双相里的证据主要集中在缓解期的抑郁症状和复发预防，对急性躁狂没有多少用武之地。躁狂期做认知作业，既做不到，也容易变成新的挫败。【指南】

## 三、DBT：情绪冲上来的时候先撑住

DBT 把技能分成四组，顺序有讲究：先能稳住自己，再谈改变。

**正念**是基础，练的是“注意到自己现在在想什么、感觉什么，但不立刻反应”。最简单的是三分钟呼吸空间：注意呼吸，注意身体感觉，注意念头的来去，然后回到当下。

**痛苦耐受**用于“现在很难受，但暂时改变不了”的时刻。常用技能包括：

- **STOP**：停下来（Stop）、退一步（Take a step back）、观察（Observe）、继续有意识地行动（Proceed）。
- **改变身体状态**：用冷水洗脸、短时剧烈运动、缓慢呼吸，先把生理唤醒降下来。
- **转移注意**：用活动、付出、比较、换个情绪、推开念头、想象、身体感觉等方式，暂时离开痛苦的漩涡。
- **自我安抚**：用五感——看、听、触、闻、尝，找一件当下能做到的小事。
- **权衡利弊**：写下“冲动行事”和“忍住不做”各自的短期与长期后果。

**情绪调节**包括：给情绪命名（是愤怒、羞耻，还是被抛弃的恐惧）、减少情绪脆弱性（睡眠、饮食、运动、规律服药）、积累正性体验、反其道而行（情绪想让你躲起来时，做一点相反的小动作）。

**人际效能**分两套：一套是提出请求或拒绝（把事实说清楚、表达感受、提出具体要求、说明好处、保持自信）；另一套是维持关系（认真听、认可对方、温和表达）。对双相患者来说，这套技能在家庭冲突和职场沟通里很实用。

DBT 在双相领域的直接研究比 CBT 少，样本通常较小，结论也不完全一致；目前更常见的做法是用它处理情绪失调、自伤和共病人格障碍，而不是当作双相的核心治疗。【研究】【待验证】

## 四、CBT 和 DBT 怎么分工

- **主要问题是“越想越低落”**：反复自责、回避、对什么都没兴趣——先做 CBT 的行为激活和认知重构。
- **主要问题是“一下子炸掉”**：情绪几秒钟冲到顶点、摔东西、自伤、说完就后悔——先做 DBT 的痛苦耐受和情绪调节。
- **两者都有**：可以先学 DBT 的稳定技能，再进入 CBT 的认知工作；顺序反过来也常见，取决于当前最危险的问题。
- **共病边缘型人格障碍**：DBT 的证据更充分，通常需要更长周期和团体加个体组合。【研究】
- **急性期**：先药物和休息，技能训练推迟到能坐下来的时候。硬推作业会让人觉得“连治疗都做不好”。

## 五、一周可以怎么练：一个最小版本

- [ ] 每天睡前用两分钟记：今天情绪最高几分、最低几分，睡眠几小时，有没有吃药。
- [ ] 一周做一次思维记录，只挑一个最难受的瞬间，不用写满整页。
- [ ] 一周做一次小的行为实验，提前写下预测，事后记录真实结果。
- [ ] 把 STOP 写在手机备忘录第一行，情绪上来时先停十秒。
- [ ] 给自己列三个五分钟内能做完的“安抚动作”，难受时不用现想。
- [ ] 周末花十分钟回顾：哪一条有用，哪一条做不到，下周只保留一条继续练。

## 六、容易踩的坑

**把 CBT 变成自我批评的新工具。** 思维记录不是“找出自己哪里想错了再骂自己一遍”，而是好奇地看看想法有没有别的可能。

**把“正面思考”当目标。** 否认症状、强行乐观，往往让情绪反弹得更厉害。CBT 要的是更准确的想法，不是更开心的想法。

**在躁狂期硬做认知作业。** 这个阶段注意力、判断力都受影响，做了也记不住，还容易起冲突。

**用 DBT 压住所有情绪。** 痛苦耐受是“撑过这一波”，不是“从此不许难受”。长期压抑反而增加爆发风险。

**只上课不练。** 技能是练出来的，不是听会的。每周一次会谈、其余六天不练，效果通常有限。【临床经验】

> **什么时候需要联系医生 / 寻求额外帮助**
>
> - 出现自杀念头、自伤冲动，或已经在准备方法：不要独处，立即拨打 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 自伤后伤口较深、出血不止、意识不清：立即急诊。
> - 练习中反复出现强烈的创伤画面闪回、解离、惊恐，难以自行平复：暂停练习并联系治疗师。
> - 睡眠连续几天显著减少、话多、冲动加重：先处理病情，暂停认知作业。
> - 服药后出现严重皮疹、高热、肌肉僵硬、意识改变：立即急诊。
