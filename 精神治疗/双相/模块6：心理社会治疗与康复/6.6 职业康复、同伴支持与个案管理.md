# 6.6 职业康复、同伴支持与个案管理

症状稳定不等于生活恢复。很多人停药、复诊都做到了，却卡在“回不去工作”“不敢回学校”“不知道该找谁帮忙”上。这一页讲三件常被忽略的事：怎样分阶段复工复学，支持性就业和同伴支持分别能提供什么，个案管理怎样把医院、社区、单位之间的碎片连起来。适合病情已相对稳定、正在考虑回归工作学习的患者，以及想帮忙找资源的家属。

## 一、康复的目标不是“回到病前”，而是找到能持续的生活

很多人把康复理解成“变回生病前的样子”。这个目标听起来合理，实际上常常做不到，也没必要：生病这几年，人的年龄、体力、家庭责任、职业环境都变了。

更现实的目标是：有一份自己能承受的工作或学习节奏，有几位能说真话的人，能照顾好自己的吃睡和吃药，遇到波动知道找谁。这四项里任何一项改善，都是康复的进展。【临床经验】

工作对康复有明确的好处：它提供结构（每天有事做）、身份（我不只是病人）、收入、社交。但工作也是压力源，尤其是夜班、频繁出差、高压考核、人际复杂的岗位。所以问题不是“要不要工作”，而是“什么样的工作、以什么节奏、配什么支持”。

## 二、复工复学：先评估，再分阶段

**什么时候可以考虑。** 通常需要症状稳定一段时间、睡眠相对规律、药物方案稳定（最近没有频繁调整）、精力和注意力能支撑几小时的活动。具体多久由医生结合病程判断，没有统一标准。【临床经验】

**先做一次功能评估。** 和医生一起看几件事：注意力能不能连续集中半小时以上、有没有明显的镇静或手抖影响操作、体力能撑多久、情绪波动会不会被特定场景触发。这些比“我感觉好多了”更能预测能不能撑住。

**分阶段回去，而不是一步到位。** 常见的路径是：先做志愿者或兼职，每周几个小时；适应后再增加天数；最后恢复全职。复学可以先修少量课程、申请缓考或延长学制。阶梯式回归的复发风险通常低于直接满负荷。【临床经验】

**和单位或学校怎么谈。** 没有标准答案，取决于环境、关系和个人意愿。可以只谈“需要什么安排”，不必完整交代诊断：

- 固定的白班，尽量不排连续夜班；
- 减少频繁出差和跨时区飞行；
- 允许定期请假复诊；
- 一段时间的弹性工时或部分工作量；
- 安静一些的工位，减少持续高强度的人际消耗。

如果单位或学校愿意配合，把这些安排写下来，约定试行多久、怎么评估。口头承诺容易在忙起来之后消失。

**关于要不要告知。** 法律禁止基于精神障碍的就业歧视，患者也有隐私权，但现实中歧视仍然存在。是否告知、告知多少、什么时候告知，需要结合岗位、单位文化、病情稳定程度来权衡，没有统一建议。可以先把“需要什么便利”想清楚，再决定说到什么程度。涉及法律权益时，以《中华人民共和国精神卫生法》《中华人民共和国残疾人保障法》和当地规定为准。

| 复工前的准备 | 具体做什么 |
|---|---|
| 医疗评估 | 和医生确认稳定程度、副作用对工作的影响、复诊频率 |
| 节奏设计 | 先兼职或部分课程，设定每周上限，留出恢复日 |
| 睡眠安排 | 固定起床时间，避免夜班和跨时区，提前和单位沟通 |
| 支持人选 | 指定一位同事或同学，在状态不对时能提醒你 |
| 预警方案 | 写好睡眠、情绪、花钱的早期信号，出现时怎么处理 |
| 经济预案 | 算清收入变化、医保和补贴是否受影响，留出缓冲 |

动手之前，先过一遍这份自查：

- [ ] 最近一个月睡眠基本规律，没有连续熬夜。
- [ ] 药物方案稳定，最近没有频繁调整。
- [ ] 能连续专注半小时以上，副作用不影响操作和通勤。
- [ ] 已经和医生讨论过工作强度、复诊频率和夜班问题。
- [ ] 有一份写下来的早期信号和应对办法，家人或朋友也知道。
- [ ] 算过收入变化对医保、低保或其他补助的影响。

## 三、支持性就业：先上岗，再训练

传统做法是“先长期培训、等能力够了再找工作”，支持性就业反过来：先按本人的意愿找到真实岗位，再在工作中提供持续支持。国际上比较成熟的是“个体安置与支持”模式，几条原则很清楚：以竞争性就业为目标、快速上岗、尊重本人意愿、把就业服务和治疗团队结合起来、提供长期跟进。【研究】

在严重精神障碍人群中，这类模式的就业率通常高于“先训练后就业”的传统路径；专门针对双相障碍的研究相对少一些，但结果方向一致。【研究】国内一些地区有辅助性就业、按比例就业、残疾人就业服务机构，具体形式和覆盖范围差异很大，需要向当地残联和人社部门确认。

支持性就业不是“随便找个活干”。它强调岗位和人的匹配：避开连续夜班和高压销售，优先考虑节奏可控、任务清楚、允许请假的岗位。收入增加可能影响低保或其他补助，复工前要算清楚，必要时咨询当地民政或残联。

## 四、同伴支持：过来人的作用与边界

同伴支持是受过培训的康复者，用自己的经历提供陪伴、信息和希望。形式包括医院里的康复小组、社区同伴支持员、线上互助群、家属互助组织。

它最独特的作用是“你不需要解释，对方就懂”。这种被理解的感觉，很难从医生或家人那里完全获得。同伴还能提供非常具体的信息：怎么跟单位请假、哪家医院复诊排队短、哪种副作用别人是怎么熬过去的。【个人体验】

但同伴支持有明确边界：

| 能做 | 不能做 |
|---|---|
| 分享自己的经历和应对办法 | 替你判断该吃什么药、该不该停药 |
| 陪你去看诊、帮你整理问题 | 替代医生做诊断 |
| 在低谷时提供陪伴和希望 | 承诺“照我的方法就能好” |
| 介绍资源和政策信息 | 推荐偏方、保健品、收费疗程 |

遇到劝你停药、减药、换医生的“同伴”，要警惕。经验可以参考，处方只能由医生开。【指南】

## 五、个案管理：有人帮你把碎片连起来

双相障碍的治疗常常散在不同地方：医院开药、社区随访、心理治疗、康复训练、就业服务、医保报销。个案管理的作用是找一个人（社工、社区精防医生、医院个案管理师）把这些连起来：评估需求、制定计划、陪同转介、定期跟进、危机时协调。

适合考虑个案管理的情况：反复住院、同时跑好几个科室、独居或家庭支持薄弱、经常漏诊漏药、经济或住房困难。

在中国大陆，社区卫生服务中心的精神卫生防治医生通常承担随访和服药管理；部分地区对包括双相障碍在内的严重精神障碍有规范化的社区管理，具体内容和频率以当地规定为准。【指南】

## 六、社区资源地图：遇到问题可以找谁

| 你需要什么 | 通常可以找 |
|---|---|
| 调药、急性期处理 | 精神专科医院或综合医院精神心理科 |
| 日常随访、服药管理 | 社区卫生服务中心精防医生 |
| 结构化心理治疗 | 医院心理治疗门诊、有资质的心理治疗师 |
| 康复训练、日间活动 | 社区康复站、日间医院、阳光家园等 |
| 找工作、职业培训 | 当地残联就业服务机构、公共就业服务 |
| 经济困难 | 民政低保、临时救助、残联补贴 |
| 家属支持 | 家属互助组织、医院家属课堂 |
| 危机 | **120**、**110**、**12356** 心理援助热线 |

政策各地差异很大，同一个城市不同区也可能不同。最省事的办法是问社区精防医生或医院社工：“我这个情况，本地能申请什么？”

## 七、常见问题与容易踩的坑

**“等我完全好了再工作。”** 完全好的标准很难达到，等待本身会让人更退缩。更现实的做法是从很小的量开始试。

**“一复工就上全职。”** 这是复发的常见诱因。前三个月按七成负荷安排，往往比满负荷撑得更久。

**“把同伴支持当治疗。”** 同伴能陪你走一段，但不能替代药物和复诊。

**“复发一次就再也不敢找工作。”** 复发是疾病的一部分，不是能力的判决。可以和医生、就业服务一起分析上次是什么触发了，下次怎么改。

**“不知道有补贴，白扛了几年。”** 主动问。很多政策不会主动找上门。

> **什么时候需要联系医生 / 寻求额外帮助**
>
> - 出现自杀念头、自伤行为，或已经在准备方法：不要独处，立即拨打 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 复工复学后连续几天睡眠明显减少、话多、冲动、无法完成任务：尽快联系医生，必要时暂停工作或学习。
> - 工作或学校里遭遇歧视、霸凌、被强制透露病情：保留证据，向单位人事、学校或法律途径求助。
> - 出现严重的职场恐慌、无法出门、持续回避：这可能是焦虑共病，需要评估而不是硬撑。
> - 经济困难到影响吃饭、住房、买药：联系社区、民政或社工，不要自行减药。
> - 服药后出现严重皮疹、高热、肌肉僵硬、意识改变：立即急诊。
