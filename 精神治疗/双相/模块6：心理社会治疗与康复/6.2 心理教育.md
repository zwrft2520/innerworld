# 6.2 心理教育

心理教育是双相障碍心理社会干预里最基础、也最容易被做坏的一环：内容不难，难的是怎么讲。这一页写给两类人——想弄明白自己到底得了什么、该怎么配合治疗的患者，以及想帮忙却一开口就吵起来的家属。读完你可以拿到一份“该讲什么”的清单、几种把话说得不伤人的方法，以及一张可以自己填的早期信号表。

## 一、心理教育到底教什么

心理教育不是把诊断书念一遍，也不是劝人“想开点”。它通常包含四块内容，缺一块效果都会打折。【指南】

**第一块，疾病本身。** 双相障碍有躁狂或轻躁狂发作，也有抑郁发作，两者可以分开出现，也可以混在一起。它是发作性、容易复发的疾病，不是性格缺陷，也不是意志力问题。多数人经过规范治疗可以回到工作和生活，但“根治”这个说法不准确，更合适的词是缓解、稳定、康复。【指南】

**第二块，治疗为什么这样安排。** 为什么情绪好了还要继续吃药，为什么医生不肯单用抗抑郁药，为什么要查血药浓度、甲状腺和肾功能。把这些讲清楚，依从性往往比反复叮嘱“记得吃药”更稳。【指南】

**第三块，复发的早期信号。** 每个人不一样，但常见的有睡眠需求减少、话变多、想法特别快、突然特别有把握、花钱变多、易怒、社交突然增多；抑郁前兆则是睡不好或睡太多、提不起劲、回避人、觉得自己没用。重点是让患者和家属都知道“这个人”的前兆是什么，而不是背教科书。【临床经验】

**第四块，生活里哪些事会推高风险。** 熬夜、倒班、跨时区旅行、睡眠剥夺、酒精和兴奋剂、重大生活变故、停药或自行减量。这些不是“注意身体”的空话，而是可以具体安排的：固定起床时间、提前倒时差、聚会时怎么拒绝酒。【指南】

## 二、给患者的版本：把“你得了什么”讲清楚

患者最需要的往往不是安慰，而是解释。可以用“天气预报”作比：情绪本来就有起伏，双相的问题是起伏的幅度和持续时间超出了可调节的范围，所以需要药物把幅度压住，需要作息把节律稳住。比喻只是帮助理解，不能代替诊断标准。

要明确告诉患者三件事：

1. **这不是你的错，但需要你参与。** 疾病有生物学基础，不是“想太多”。同时治疗需要患者记录睡眠、按时复诊、在波动时求助，这些是能做的事。
2. **副作用可以说，不要自己扛。** 手抖、发胖、嗜睡、口干都值得讲，多数可以调整。自己偷偷减药，风险比副作用大得多。【指南】
3. **稳定期是学东西的时候。** 等到复发再学识别信号，学习能力已经被症状打断。

对刚确诊的人，一次讲太多会记不住。可以分两三次，每次聚焦一个问题，给一份写下来的要点，下次复诊再核对。【临床经验】

## 三、给家属的版本：能做什么、不做什么

家属最常见的两个极端，一是把患者当病人全权代管，二是把波动当成“不努力、作”。心理教育想帮家属找到中间位置：**观察而不监视，支持而不代替，提醒而不训话。**

| 主题 | 对患者讲什么 | 对家属讲什么 |
|---|---|---|
| 疾病性质 | 发作性疾病，不是性格问题，可以稳定 | 波动是症状，不是针对你；不要用“你就是懒”解释一切 |
| 治疗 | 药物需要长期维持，副作用可以谈 | 不要劝停药、不要推荐偏方；帮忙记服药和复诊 |
| 早期信号 | 你自己的前兆是什么，出现时找谁 | 观察睡眠、话量、花钱、易怒的具体变化，记录而不是质问 |
| 生活节律 | 固定起床、少熬夜、限酒 | 家庭作息一起稳定；不要把聚会都安排在深夜 |
| 危机 | 有自杀念头要说出来 | 直接问、认真听、收好危险物品、必要时送急诊 |

家属也需要被教育的一件事是：**照护很累，累到发脾气是正常的**，但需要有自己的支持，而不是把全部精力压在患者身上。照护者耗竭之后，家庭氛围往往更紧张，反而增加复发风险。【临床经验】

## 四、怎么讲才不像说教

说教的特点是：讲道理、下判断、给命令、反复重复。它的效果通常是把对方推远。下面这些替换句，可以直接拿去用。【临床经验】

| 容易说出口、但没什么用的话 | 换成合作式的说法 |
|---|---|
| “你就是不肯吃药，才老复发。” | “上次停药后大概两周就睡不好了，我们要不要跟医生聊聊怎么让吃药这件事没那么麻烦？” |
| “你又在乱花钱。” | “这个月有两笔大额支出，我有点担心，我们一起看看账单好吗？” |
| “你想开点，别整天躺着。” | “我看你这一周都没出门，是没力气，还是不想见人？” |
| “你就是熬夜熬的。” | “这三天你都是两点后睡，我们要不要把起床时间先固定下来？” |
| “我都是为你好。” | “我担心的是……你希望我怎么帮你？” |

几条原则比句子本身更重要：

- **说具体行为，不说人格标签。** “这周有三天没睡好”比“你最近很不稳定”有用。
- **一次只谈一件事。** 把吃药、花钱、作息、态度一起翻出来，必然吵起来。
- **选时机。** 争吵中、酒后、深夜都不适合谈。约一个双方都不赶时间的白天。
- **先承认感受，再谈事实。** “我知道你觉得被管着很难受”不等于同意对方，但能让对话继续。
- **给选择，不给命令。** “你想自己设闹钟，还是我提醒你？”比“你必须按时吃”更容易被接受。
- **允许对方拒绝。** 说不通就先停下，改成写下来、下次复诊一起说。逼到墙角只会加深对抗。

## 五、早期信号：一起做一张自己的表

早期信号的价值在于“提前几天到几周”争取到调整治疗的时间。做法是：回顾过去两三次复发，找出最早出现、家属也能看到的两三个变化，写下来，标好第一步该做什么。

| 信号 | 可能意味着 | 第一步做什么 |
|---|---|---|
| 连续两三天只睡四五个小时仍不困 | 可能进入轻躁狂前期 | 当晚减活动、固定上床时间，48 小时内联系医生 |
| 话明显变多、语速加快、别人插不上话 | 躁狂谱系波动 | 减少刺激和社交安排，避免做重大决定，尽快复诊 |
| 突然要投资、要大额消费、要辞职 | 冲动风险上升 | 暂缓决定，家人共同管理大额支出，联系医生 |
| 一周内回避所有社交、起床困难 | 抑郁前兆 | 记录睡眠与活动，预约复诊，不逼着“振作” |
| 易怒、为小事爆发、摔东西 | 混合或躁狂前期 | 降低对话强度，先保证安全，必要时急诊 |

这张表建议每半年和医生一起更新一次。人的前兆会变，旧表不一定一直准。【临床经验】

可以用下面几条自查，看看心理教育有没有真正做到位：

- [ ] 我能说出自己的诊断名称，以及它和单相抑郁的区别。
- [ ] 我能说出自己最常见的两个早期信号，家属也知道。
- [ ] 我知道现在每种药的作用和主要副作用，副作用出现时该找谁。
- [ ] 我知道睡眠明显变少时，第一步联系谁、多久之内联系。
- [ ] 家里至少有三句“不容易吵起来”的替换说法。
- [ ] 全家对“什么情况打 120、什么情况去急诊”有共识。

## 六、常见问题

**“讲太多会不会吓到人？”** 会，所以分次讲。但完全不讲，患者会把复发当成“自己失败”，家属会把波动当成“故意作对”，代价更大。

**“患者不承认自己有病，怎么讲？”** 先不谈诊断，谈具体困扰：“你最近睡不好、脾气大，这本身很难受，我们去看看怎么改善睡眠。”在急性躁狂、缺乏自知力时，说服往往无效，重点是保证安全和就医，而不是赢得辩论。【指南】

**“家属该不该看病历和诊断？”** 患者有隐私权。成年患者在清醒时可以自己决定告诉谁；涉及照护和安全时，可以商量一个双方都能接受的共享范围。具体权利义务以《中华人民共和国精神卫生法》和当地规定为准。

**“一次心理教育就够了吗？”** 不够。疾病阶段会变，问题会变，建议在确诊时、每次调整方案时、每次复发后各回顾一次。

**“青少年怎么讲？”** 用他们能懂的语言，保留自主感，同时让家长参与作息和安全管理。学校和老师知道多少，由青少年和家长共同决定。

> **什么时候需要联系医生 / 寻求额外帮助**
>
> - 出现自杀念头、自伤行为，或已经在准备方法：不要独处，立即拨打 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 连续几天睡眠显著减少、话多停不下来、冲动消费或危险驾驶：尽快精神科急诊，必要时拨打 **120** 或 **110**。
> - 家属发现患者出现新的、持续加重的异常想法（被监视、被针对、听到别人听不到的声音）。
> - 家庭沟通反复失败、冲突升级到威胁或动手：先保证安全，再寻求家庭治疗或社区帮助。
> - 服药后出现严重皮疹、高热、肌肉僵硬、意识改变、剧烈呕吐腹泻：立即急诊。
