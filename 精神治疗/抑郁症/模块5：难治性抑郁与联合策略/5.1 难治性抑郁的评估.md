# 5.1 难治性抑郁的评估

“两种药都吃过了，还是不好”——这句话背后，可能是真正的难治性抑郁，也可能是剂量不够、药没吃对、诊断偏了，或者有别的问题在拖着。这两者的处理方向完全不同：前者需要升级治疗，后者需要先纠正那些“看起来像难治”的原因。这一页讲怎么定义难治性抑郁、哪些因素会造成“假难治”、以及一次系统复评应该包含什么。读完你可以带着一张清单去和医生讨论，而不是只带着“我没救了”的感觉。

## 一、什么叫“难治”：一个有用但不精确的概念

难治性抑郁（treatment-resistant depression，TRD）不是一个有统一标准的诊断，而是对“治疗反应不够”的描述。临床上最常用的定义是：**经过两种不同类别的抗抑郁药，足量、足疗程治疗，症状仍然没有明显改善。**

这句话里有三个关键词需要拆开：

- **足量**：指剂量达到了治疗剂量范围，通常是说明书推荐的上限附近，或者你能耐受的最大剂量。吃了半片、吃了“最小有效量”就判断无效，不算。
- **足疗程**：指在足量前提下持续足够长的时间。多数抗抑郁药需要四到八周才能判断是否有效；只吃两周就说“没用”，往往太早。
- **不同类别**：两种同类的药（比如两种 SSRI）先后使用，证据上不如换到不同机制的药。

还要区分“应答”和“缓解”。症状评分下降一半左右叫“应答”，症状基本消失、功能恢复叫“缓解”。有些人从“很重”变成“中等”，算应答但没缓解，这种情况仍然需要继续调整，不能因为“好了一点”就停在这里。

难治性抑郁还有轻重之分：试过两种药无效，和试过四种药、做过物理治疗仍无效，不是一回事。医生有时会用“阶段”来描述——第几次足量足疗程失败，对应不同的治疗强度。这不是给你贴标签，而是帮助判断下一步该走多远。

| 说法 | 大致含义 | 容易误解的地方 |
|---|---|---|
| 应答 | 症状减轻约一半 | 减轻一半不等于好了，功能可能仍受损 |
| 缓解 | 症状基本消失，接近病前状态 | 缓解后仍需维持治疗防复发 |
| 难治 | 两种不同类别药物足量足疗程无效 | 不是“永远治不好”，也不是“必须试遍所有药” |
| 假难治 | 因为剂量、依从、诊断等问题造成的“看起来无效” | 纠正后可能对原来的药有反应 |

## 二、先排除“假难治”：最常见也最容易被忽略

在把一个人归入“难治”之前，负责任的医生会先问一句：**有没有可能，之前那些治疗根本不算“足量足疗程”？**

这不是苛责患者，而是临床上非常常见的现实。原因包括：

**剂量不够。** 有些人因为担心副作用，一直停在低剂量；有些医生为了“安全起见”，加量很慢；有些人吃到中等剂量觉得“好了一点”就不再往上调。剂量不足时判断无效，等于没试。

**疗程不够。** 抗抑郁药起效慢，四到六周才开始显现是常态。吃了十天半月就换药，可能把本来会有效的药换掉了。反过来，吃了三个月一点变化都没有，也不该无限期等下去。

**依从性差。** 这是最隐蔽的一条。漏服、隔天吃、感觉好了就停、因为副作用自行减量、把药藏在舌下吐掉——这些情况家属和医生都未必知道。抑郁本身会损害执行功能，让人记不住、懒得吃；副作用又让人不想吃。询问依从性时，直接问“最近一周有几天没吃”比问“你按时吃药了吗”更容易得到真实答案。

**诊断不对。** 这是最需要警惕的一条：

- **双相障碍**。被当成单相抑郁治疗了很多年，只用抗抑郁药，效果自然不好，还可能诱发转躁。要问：有没有过一段时间睡得很少却精力旺盛、话多、思维奔逸、冲动消费、特别自信？家族里有没有双相或躁狂史？【指南】
- **甲状腺问题**。甲减（包括亚临床甲减）会表现为乏力、情绪低、反应慢、怕冷、便秘、体重增加，和抑郁高度重叠。查一次促甲状腺激素（TSH）就能发现大部分问题。
- **贫血、维生素 B12 或叶酸缺乏**。会带来乏力、注意力差、情绪低落。
- **睡眠呼吸暂停**。打鼾严重、白天嗜睡、晨起头痛、夜间憋醒的人，抑郁症状可能主要是缺氧和睡眠碎片化造成的，抗抑郁药效果自然有限。
- **药物或物质引起**。某些降压药、激素、干扰素、部分止痛药可能引起抑郁样症状；长期饮酒、使用大麻或其他物质也会干扰治疗。
- **早期痴呆、帕金森病等神经系统疾病**。老年人出现“抑郁”伴记忆下降、走路变慢、手抖，需要进一步评估。
- **人格特质、创伤史、长期应激**。这些不是“诊断错误”，但会影响治疗效果，需要心理治疗同步介入。

**药物相互作用与吸收问题。** 有些药会让抗抑郁药的血药浓度下降（比如某些抗癫痫药、利福平、圣约翰草），有些会影响吸收（胃肠手术后、慢性腹泻、乳糜泻）。吸烟也会影响某些药物的代谢。这些需要医生逐条核对，不是患者自己能判断的。

**心理社会维持因素。** 如果一个人每天都在遭受家暴、被裁员、照顾重病家人、住在没有隐私的环境里，药物很难单独对抗这些现实压力。这不是“想开点”能解决的，但需要被看见、被纳入计划。

## 三、一次系统复评应该包含什么

如果你已经试过两种以上的药，效果不理想，可以主动要求一次“系统复评”，而不是直接在原有方案上再加一种药。复评通常包括：

- [ ] **诊断复核**：重新确认是不是抑郁症，有没有双相、精神病性症状、紧张症、物质使用、躯体疾病。
- [ ] **用药时间线**：把每一种药用过多久、多大剂量、有没有加到足量、效果如何、副作用如何、为什么停，一条条列出来。
- [ ] **依从性评估**：最近一个月漏服几次？有没有自行减量？有没有因为副作用偷偷停？
- [ ] **实验室检查**：甲状腺功能、血常规、铁蛋白、维生素 B12、叶酸、电解质、肝肾功能，必要时查维生素 D、血糖、心电图。
- [ ] **睡眠评估**：有没有打鼾、憋醒、白天嗜睡；必要时做睡眠监测。
- [ ] **物质使用**：酒精、烟草、大麻、镇静催眠药、咖啡因。
- [ ] **药物相互作用审查**：把所有在吃的东西（包括中药、保健品）列给医生。
- [ ] **心理社会评估**：近期重大生活事件、家庭关系、工作状况、经济压力、社会支持。
- [ ] **症状与功能评估**：用标准化量表（如 PHQ-9）和功能评估，而不是只凭“感觉好点没”。
- [ ] **自杀风险评估**：直接问，不要回避。

| “假难治”原因 | 常见线索 | 怎么查 |
|---|---|---|
| 剂量或疗程不足 | 一直吃低剂量、几周就换药 | 核对用药时间线 |
| 依从性差 | 家里剩药多、复诊时说不清 | 直接问漏服天数、让家属参与 |
| 双相障碍 | 有过兴奋少眠、冲动、家族史 | 详细追问、用筛查工具 |
| 甲状腺问题 | 怕冷、便秘、体重增加、反应慢 | 查 TSH、必要时查抗体 |
| 睡眠呼吸暂停 | 打鼾、憋醒、白天嗜睡、晨起头痛 | 睡眠监测 |
| 药物相互作用 | 同时用抗癫痫药、圣约翰草、吸烟 | 逐条核对用药清单 |
| 心理社会压力 | 持续冲突、贫困、照护负担 | 面谈、社会支持评估 |

这张表不是让你自己诊断，而是让你知道：**“两种药无效”这句话，值得被拆开来看。** 很多时候，纠正其中一个环节，治疗反应就变了。

## 四、复评之后，怎么理解“难治”这个标签

如果系统复评做完了，确实排除了上述问题，两种不同类别的药都足量足疗程用过，效果仍不理想，那么“难治性抑郁”这个描述是成立的。但它描述的是一段治疗史，不是一个人的本质。

有几件事值得记住：

- 难治性抑郁仍然可以治疗。换药、增效、rTMS、MECT、氯胺酮、心理治疗、康复支持，都还有空间。具体怎么组合，可以看[5.3 难治性抑郁的综合路径](<5.3 难治性抑郁的综合路径.md>)。
- “难治”不等于“对所有治疗都无效”。很多人是在第五种、第六种方案，或者第一次物理治疗时才好转的。
- 反复失败会带来习得性无助，这种无助本身会让人觉得“没必要再试”。这时候，家属和医生的态度很重要：不空喊“会好的”，也不附和“确实没救了”，而是一起看“下一个具体选项是什么”。
- 复评本身就有治疗意义。把混乱的用药史理清楚、把没查的检查补上、把没说出口的压力说出来，很多人会发现，自己并不是“无药可救”，而是“一直没被完整地评估过”。

## 五、什么时候需要联系医生 / 去急诊

> **立即呼叫 120 或去急诊**：出现自杀计划或准备行为、已经自伤；拒绝进食进水、明显脱水；意识模糊、高热、肌肉僵硬（警惕严重药物反应）；抽搐、晕厥、胸痛。
>
> **尽快联系精神科医生**：情绪在调整方案后明显恶化；出现转躁迹象（睡得少却精力旺盛、话多、冲动）；副作用严重到影响生活；连续多日几乎不睡。
>
> 有自杀念头时不要独处，让家人陪着，把可能用于自伤的物品交给他人保管，拨打 120 或 12356 心理援助热线。

## 六、常见问题与容易踩的坑

**“我吃了两种药都没好，是不是没救了？”** 不一定。先确认这两种药是不是足量足疗程、是不是不同类别、有没有漏服、有没有被误诊。很多“难治”在复评后会发现可以纠正的因素。

**“是不是药吃得越多越好？”** 不是。加药要有理由，也要有监测。叠加多种药会增加副作用和相互作用，未必提高缓解率。

**“我自己要求换药行不行？”** 可以提出，但不要自行换。换药涉及撤药反应、交叉耐受、复发风险，需要医生根据你的情况安排。

**“查甲状腺、查血有必要吗？”** 有必要。这些检查便宜、容易做，能排除一批可纠正的原因。

容易踩的坑：

- 把“感觉好一点”当成“够了”，停在不足的剂量上。
- 因为早期副作用自行减量，却告诉医生“我一直在按你说的吃”。
- 只看情绪，不看睡眠、体重、怕冷、打鼾这些线索。
- 频繁换医生、换医院，每次从头开始，没人看到完整的治疗史。
- 把“难治”当成身份，停止尝试；或者反过来，拒绝承认困难，不停加药。
