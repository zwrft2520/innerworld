# 5.2 换药还是增效

当第一种抗抑郁药效果不理想时，下一个决定往往卡在这里：是把药换掉，还是在原来的基础上加一种？这两个选择没有绝对的优劣，答案取决于你之前用了什么、反应如何、副作用能不能忍、有没有共病、经济和时间上能不能支撑。这一页把两种策略的证据、适用场景和风险摊开讲，帮你在诊室里问出关键的那几个问题。

## 一、两种策略分别在做什么

**换药（switch）**，是把现在这种药停掉或逐渐减掉，换成另一种。换的药可以是同一类里的另一种（比如一种 SSRI 换成另一种 SSRI），也可以是不同机制（比如 SSRI 换成 SNRI、安非他酮、米氮平），还可以换到更老的类别（三环类、单胺氧化酶抑制剂）。思路是：既然这条路走不通，换一条路试试。

**增效（augment）**，是在保留原来抗抑郁药的基础上，加一种本身通常不算抗抑郁药的药物，或者加第二种抗抑郁药。思路是：原来的药可能已经起了一部分作用，只是不够，加一个“帮手”把效果推上去。

两者的根本区别在于：换药是“替换”，增效是“叠加”。这决定了它们在风险、费用、起效时间和适用人群上的差异。

## 二、证据：谁更占优

到目前为止，没有哪一项研究能证明“换药一定优于增效”或反过来。多部指南的建议是：两种策略都可以，根据具体情况选。【指南】

被引用最多的是 STAR*D 研究。它分四步治疗难治性抑郁：第一步用一种 SSRI，无效的人第二步随机分到“换药”或“增效”，第三步、第四步继续调整。研究结果显示，每一步都有一部分人达到缓解，但缓解的比例逐步下降；四步累积下来，大约三分之二的人在某一步缓解。【研究】

这个结果常被这样解读：“只要坚持试，大多数人最终会好。”这话有一部分道理，但需要补充几点：

**STAR*D 说明了什么：**

- 难治性抑郁不是“试一种药无效就结束”，多步调整是有意义的。
- 换药和增效在第二步的缓解率接近，没有哪一种是明显更优的默认选项。
- 每一步都需要足够的时间和剂量，频繁更换反而浪费机会。
- 即便达到缓解，后续复发也不少见，维持治疗很重要。

**STAR*D 不能说明什么：**

- 它不能告诉你“哪一种药对你最合适”。它比较的是策略，不是个体。
- 它是开放标签研究，没有安慰剂对照，医生和患者都知道在用什么，期望效应难以排除。
- 脱落率很高，中途退出的人可能恰恰是效果最差的，结果可能被高估。
- 它用的是当时的药物和剂量策略，和现在的临床实践有差距。
- 它不适用于双相抑郁、精神病性抑郁、紧张症，这些人需要另外的路径。
- 它不能证明“所有治疗都差不多”，也不能证明“只要一直试就一定能好”。

所以，STAR*D 的正确用法是：**它告诉你“多步治疗是合理的”，而不是“照着它的顺序走”**。具体到个人，还要看既往反应、副作用、共病和偏好。

## 三、什么情况优先换药，什么情况优先增效

| 情况 | 更倾向 | 理由 |
|---|---|---|
| 一点效果都没有，副作用也明显 | 换药 | 既无效又难受，没必要继续叠加 |
| 有效果但只好了部分，副作用可耐受 | 增效 | 保住已有的疗效，再加一把力 |
| 第一次发作、希望方案简单 | 换药 | 减少用药种类，依从性更好，费用更低 |
| 既往对某类药有明确疗效 | 换同类或换回 | 个人反应史比群体数据更有参考价值 |
| 共病多、已在吃多种药 | 谨慎增效或换药 | 叠加越多，相互作用和副作用越难管理 |
| 有转躁风险、双相可能 | 先评估双相 | 单用抗抑郁药可能加重病情，需心境稳定剂 |
| 孕期、哺乳期 | 个体化评估 | 换药和增效都涉及胎儿暴露，需专科会诊 |
| 经济压力大 | 换药（仿制药） | 增效往往意味着两种药加更多监测 |

还有一条常被忽略：**换药不一定比增效“轻”**。换药要经历旧药减量、新药起效的空窗期，这段时间症状可能反复，撤药反应也可能很难受。增效则要承担两种药的副作用叠加、相互作用和更复杂的服药方案。没有免费的选项。

## 四、换药：怎么换，风险在哪

换药有几种方式：直接换（停一种、马上开始另一种）、交叉换（旧药逐渐减、新药逐渐加，两者有一段时间重叠）、以及经过清洗期的换（先停旧药一段时间再上新药）。具体用哪种，取决于药物的半衰期、相互作用、撤药反应的强弱。**这一步必须由医生安排，不要自己操作。**

换药的风险包括：

- **撤药反应**：头晕、恶心、失眠、电击感、焦虑加重，尤其在短半衰期的药突然停用时。
- **空窗期复发**：旧药停了、新药还没起效，症状可能反弹。
- **新药的副作用**：每种药的副作用谱不同，换药不等于“没有副作用”。
- **失去已有的部分疗效**：有些人换药后反而怀念原来那种“虽然不够好但还能过”的状态。
- **相互作用**：某些换药组合（尤其是涉及 MAOI、三环类）需要严格的清洗期和监测，处理不当有严重风险。

换药的优点是方案简单、费用通常更低、依从性更好。缺点是可能把已有的部分效果丢掉，而且下一次起效仍要等几周。

## 五、增效：加什么，代价是什么

增效的选项不少，证据强弱差别很大。下面按证据分量大致排一下，具体用哪个由医生决定。

| 增效药物 | 证据分量 | 主要代价 |
|---|---|---|
| 非典型抗精神病药（如阿立哌唑、喹硫平） | 研究支持较多，部分有适应证 | 体重增加、代谢异常、嗜睡、静坐不能 |
| 锂盐 | 经典增效方案，研究支持较早 | 需定期查血药浓度、甲状腺和肾功能 |
| 甲状腺素（T3） | 有一定研究支持 | 心悸、失眠、长期对骨骼和心脏的影响 |
| 安非他酮联合 | 临床常用，研究支持中等 | 失眠、焦虑、降低癫痫阈值 |
| 丁螺环酮等 | 证据较弱，效果有限 | 头晕、恶心，起效慢 |

增效的共性风险是：**药越多，相互作用和副作用越难归因**。出现一个新症状时，很难判断是哪种药引起的；服药方案变复杂，漏服和吃错的概率上升；费用和复诊次数增加。有些增效药物（如锂盐、部分抗精神病药）需要定期抽血监测，这对偏远地区、行动不便的人是实际的门槛。

增效的优点是：不用放弃已经起效的那部分，避免换药空窗期的风险；对“部分应答”的人，往往比彻底换药更划算。

## 六、怎么根据既往反应和副作用选

这是最个体化的一部分，也是指南给不出标准答案的地方。可以沿着几条线索想：

**既往哪种药有效过？** 不管是这次还是几年前，只要有过明确的疗效，同类药或同一机制的药再次有效的概率更高。家族里有人对某种药反应好，也可以作为参考，但证据不强。

**哪种副作用你最不能接受？** 如果上一种药让你体重增加很多、性功能受影响、整天犯困，那么换药时要优先避开同类副作用；增效时也要考虑新加的药的副作用会不会叠加。有人宁愿情绪差一点也不要发胖，有人宁愿嗜睡也不要焦虑加重——这是价值判断，没有对错。

**你更怕“反复”还是更怕“复杂”？** 怕反复的人，可能更愿意增效保底；怕吃太多药、怕相互作用的人，可能更愿意换药。

**现实条件允许什么？** 增效可能需要更频繁的复诊和抽血；某些药价格高、医保不覆盖；换药可能需要请假度过调整期。

**有没有必须先处理的问题？** 如果还没查甲状腺、还没排除双相、还在大量饮酒、还在失眠，那么先处理这些，比急着换药或加药更有效。

## 七、共同决策：把这些问题带回诊室

- [ ] 我之前用过的药，剂量和疗程够不够？有没有可能其实没试到位？
- [ ] 我现在是“完全没效”还是“好了一部分”？这决定换还是加。
- [ ] 换药的话，选哪一种？为什么？怎么换？空窗期怎么处理？
- [ ] 增效的话，加哪一种？证据有多强？需要监测什么？
- [ ] 两种方案各自的风险、费用、起效时间大概是什么样？
- [ ] 如果这个方案无效，下一步是什么？有没有一个大致的时间表？
- [ ] 我现在的其他药、保健品、饮酒习惯，会不会有相互作用？
- [ ] 我需要观察哪些副作用？出现什么要马上联系你？

把这些问清楚，不是为了“考医生”，而是为了让决定是两个人一起做的。共同决策不等于“患者说了算”，也不等于“医生说了算”，而是把双方掌握的信息放在一起，选一个都能接受、也能执行的方案。

## 八、什么时候需要联系医生 / 去急诊

> **立即呼叫 120 或去急诊**：服用锂盐后出现持续呕吐、腹泻、手抖明显加重、走路不稳、意识模糊、抽搐（警惕锂中毒）；服用抗精神病药后出现高热、肌肉僵硬、意识改变、大汗（警惕恶性综合征）；出现转躁伴冲动伤人、极度兴奋、连续多日不睡；出现自杀计划或自伤行为。
>
> **当天联系医生**：换药后出现严重撤药反应（剧烈头晕、电击感、恶心呕吐、焦虑失控）；新药引起皮疹、面唇肿胀、呼吸困难；心悸、胸痛；情绪急剧恶化。
>
> 有自杀念头时不要独处，让家人陪着，拨打 120 或 12356 心理援助热线。

## 九、常见问题与容易踩的坑

**“换药是不是说明之前的药白吃了？”** 不是。每种药对每个人的效果不同，试错是治疗的一部分。重要的是把每次用药的反应记录下来，让下一次选择更有依据。

**“增效是不是药越吃越多，以后更难停？”** 增效确实会增加用药种类，但不等于“停不下来”。很多人在缓解后可以逐步简化方案，关键是不要在最不稳定的时候自行减药。

**“能不能两种一起上，好得快？”** 换药和增效同时进行，会让副作用和相互作用难以判断，通常不建议在没有明确理由时这么做。

**“医生说换药，我在网上查到另一种更好，能不能要求换那种？”** 可以讨论，但“别人说好”不等于“对你好”。把查到的信息带给医生，让医生解释为什么选这个、不选那个。

容易踩的坑：

- 因为一次换药失败，就认定“所有药都没用”。
- 自己把两种药叠着吃，或把旧药停得太快。
- 只盯着情绪，不记录睡眠、体重、性功能、排便这些副作用，复诊时说不清。
- 在还没排除双相、甲状腺问题、物质使用时，就急着升级治疗。
- 把 STAR*D 的“三分之二能缓解”当成对自己的承诺。
