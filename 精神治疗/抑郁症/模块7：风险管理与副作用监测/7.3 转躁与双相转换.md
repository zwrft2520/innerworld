# 7.3 转躁与双相转换

有些人在抑郁治疗过程中，会突然滑到另一头：睡三四个小时也不困，脑子转得飞快，话多到停不下来，觉得自己什么都能做成。这不是“病情好了”，很可能是转躁。这一页讲清楚转躁的早期信号、哪些人风险更高、家里第一时间该做什么，以及怎么把它和“药物起效”区分开。

## 转躁是什么：从抑郁滑到另一头

先解释三个词。

**躁狂**是一种状态：情绪异常高涨或异常易怒，精力明显变多，睡得很少也不觉得累，说话又快又多，想法一个接一个，容易冲动，做出平时不会做的决定。**轻躁狂**是同样性质的改变，但程度轻一些，不至于严重影响工作生活，也不出现幻觉妄想，所以常被本人和家属当成“状态特别好”。

**双相障碍**，就是抑郁发作和（轻）躁狂发作交替出现的一类疾病。很多人第一次发作是抑郁，医生也只能看到抑郁，于是按抑郁症治疗；直到某次用药后“转躁”，或家属回想起几年前有过一段“特别亢奋”的时期，才把拼图拼完整。这种情况在临床上并不少见，国内指南也把“系统筛查双相”列为抑郁症评估的常规内容【指南】。

需要强调的是：**转躁不等于医生治错了**。它可能是疾病本身的下一次发作，也可能是药物把潜在的倾向提前暴露出来。这两种情况处理方式不同，但都不该由患者自己下结论。

还有一种情况叫**混合特征**：抑郁和躁狂的表现同时存在——情绪低落、想死，同时坐立不安、话多、思维飞快。这种状态格外危险，因为绝望感和冲动性叠在一起。如果出现，按急症处理。

## 早期信号：睡眠需求减少是最灵的风向标

转躁的早期信号里，最可靠、也最容易被家属发现的，是睡眠的变化——但不是“睡不着”，而是“不需要睡”。

**失眠**是躺在床上翻来覆去，白天累、困、没精神。**睡眠需求减少**是只睡三四个小时，第二天照样精力充沛、眼睛发亮、说话有劲。前者让人痛苦，后者常常让人感觉良好，所以本人往往不觉得有问题，家属才看得出不对劲。

其余信号可以对照下表观察。

| 信号 | 具体是什么样子 | 家属可以怎么描述给医生听 |
|---|---|---|
| 睡眠需求减少 | 只睡三四小时，不困不乏，甚至更精神 | “他这几天每天只睡三小时，白天还很有劲” |
| 话多、语速快 | 说话停不下来，别人插不上嘴，话题跳得很快 | “从早说到晚，我一句话都插不进去” |
| 思维奔逸 | 想法一个接一个，自己说“脑子转得太快” | “他说脑子里同时有十件事在跑” |
| 夸大 | 觉得自己有特殊能力、要大干一场、要投一大笔钱 | “他突然说要辞职创业，谁劝都不听” |
| 冲动 | 大额消费、借贷、赌博、危险驾驶、轻率的性行为 | “三天花了平时半年的钱” |
| 易激惹 | 一点小事就爆发，摔东西、骂人、和家人冲突 | “最近特别暴躁，完全不像他” |
| 目标性活动增多 | 同时开很多项目，熬夜干活不觉得累 | “同时报了三门课、接了四个活” |
| 注意力跳转 | 一件事没做完就换下一件，坐不住 | “十分钟换八件事” |
| 社交异常 | 突然特别爱交际、到处约人、给陌生人打电话 | “半夜给多年不联系的人发长消息” |

不需要等到“全都会”才警觉。**睡眠需求减少 + 话明显变多 + 花钱变冲**这三样里出现两样，就值得当天联系医生。

## 哪些人风险更高

不是所有人吃抗抑郁药都会转躁。风险高低和几个因素有关，下面这些情况需要在治疗开始前就告诉医生【指南】【研究】。

- **双相家族史**：一级亲属（父母、兄弟姐妹、子女）中有双相障碍，风险会升高。这里说的不只是“确诊过”的，也包括“有过一段特别亢奋、后来自己好了”的家人。
- **本人既往有过轻躁狂或躁狂**：哪怕只有几天，哪怕当时觉得“状态很好”，都要说。这一条最容易被漏掉，因为当事人不认为那是病。
- **既往抗抑郁药治疗后转躁**：上一次吃药后出现过类似状态，这次风险更高。
- **起病年龄早**：青少年期就出现第一次抑郁发作的人，双相的可能性相对更高。
- **快速循环**：一年内情绪高低起伏四次以上。
- **发作特点**：抑郁发作很频繁、很短、突然开始又突然结束；或伴有明显的易激惹、精神运动性迟滞。
- **共病**：注意力缺陷多动障碍（ADHD）、物质使用、边缘型人格特征，都会让评估更复杂。
- **特殊时期**：产后、季节性情绪变化明显的人，也需要额外留意。

除了药物，还有几个“点火器”会独立诱发转躁，和吃不吃药无关：**连续熬夜或睡眠剥夺、跨时区飞行、大量饮酒或使用兴奋类物质、甲状腺功能异常、分娩、强烈的情感事件**。这也是为什么治疗期间要把“规律睡眠”当成处方的一部分。

## 处理原则：联系医生，不要自己动药

发现转躁信号，家里最常见的两种反应都不太合适：一种是“终于好了，赶紧把抗抑郁药加量巩固一下”，另一种是“这药有问题，立刻全停”。前者可能把躁推得更高，后者可能带来撤药不适和情绪急转。

比较稳妥的顺序是这样：

1. **当天联系开药医生**，把睡眠时长、话多不多、花钱有没有失控、有没有说大话，一条条讲清楚。能拍照、能记录更好。
2. **不要自行加抗抑郁药，也不要自行停药**。是否调整、怎么调整，由医生判断；有时需要减抗抑郁药、加心境稳定剂或非典型抗精神病药，这些都属于处方决定。
3. **优先保睡眠**。固定上床时间，睡前不刷手机、不喝咖啡和酒，白天不补长觉。睡眠是成本最低、效果最直接的一道闸。
4. **减少刺激**：暂缓重大决定，不签合同、不投资、不辞职、不长途自驾。
5. **管住钱和钥匙**：信用卡、支付密码、车钥匙可以暂时交给家人保管。这不是不信任，是替处在冲动期的人踩一脚刹车。
6. **有人陪**。轻躁狂阶段人往往自我感觉良好、不愿就医，家属的陪同和坚持很关键。
7. **记录这次发作**。时间、诱因、用了什么药、多久缓解，对以后每一次选药都有价值。

如果医生判断需要调整诊断，也不必恐慌。双相障碍有成熟的治疗路径，关键是把“抗抑郁药单打独斗”换成“以心境稳定为基础的综合方案”。这一点在 [6.5 双相抑郁的识别与禁忌](<../模块6：特殊人群与特殊时期/6.5 双相抑郁的识别与禁忌.md>) 里有更详细的说明。

### 清单：家里可以提前做好的事

- [ ] 治疗开始前，主动告诉医生家族里有没有“特别亢奋”的时期
- [ ] 家里约定一个“睡眠观察员”，每天记录入睡和起床时间
- [ ] 手机里存一个情绪记录表，每天一行：睡眠、精力、话多程度、花钱
- [ ] 提前说好“如果连续两晚只睡三四小时还很精神，就一起去医院”
- [ ] 大额支出设置家属提醒或双人确认
- [ ] 车钥匙、信用卡的保管方式提前商量，不要等到冲突时再抢
- [ ] 把“最近有没有特别亢奋的时期”写进复诊问题清单，每次问一遍
- [ ] 家里不囤酒，治疗期间尽量不熬夜赶工

## 怎么和“药物起效”区分

这是最容易混淆的地方。抗抑郁药起效时，人确实会变好：愿意说话、愿意出门、开始做事。转躁看起来也像“变好”，但方向不一样。下面这张表可以帮助分辨。

| 维度 | 药物起效（好转） | 转躁 |
|---|---|---|
| 睡眠 | 睡得踏实一些，白天精力回升但仍会累 | 睡得明显变少，却完全不觉得累 |
| 情绪 | 平稳地往上走，能感到轻松，也会疲惫 | 异常高涨或异常易怒，像踩了油门 |
| 说话 | 愿意交流，语速正常 | 话明显变多、变快，别人插不上嘴 |
| 花钱 | 恢复正常消费 | 突然大额消费、借贷、送人贵重东西 |
| 自我评价 | 从“我不行”回到“我还行” | 从“我不行”跳到“我无所不能” |
| 判断力 | 基本正常 | 明显变差，听不进劝 |
| 别人怎么看 | 家人觉得“慢慢好起来了” | 家人觉得“不太对劲，像换了个人” |

一个简单的判断句：**好转是“回到自己”，转躁是“不像自己”。** 如果家属心里冒出“他最近怎么这么亢奋”的疑问，这个疑问本身就该带去给医生。

## 什么时候需要联系医生或去急诊

> **立即拨打 120 或去急诊，不要等门诊：**
>
> - 出现幻觉、妄想（比如坚信自己有特殊使命、被人迫害），或说话已经无法听懂；
> - 极度兴奋、整夜不睡、行为失控，家人完全拦不住；
> - 有伤害自己或他人的言语、动作；
> - 连续多日几乎不吃不喝，出现脱水、虚弱、意识模糊；
> - 混合状态下出现自杀念头，同时坐立不安、冲动明显。

> **当天联系精神科医生：**
>
> - 睡眠需求明显减少，连续两晚只睡三四小时仍精力充沛；
> - 话明显变多、思维飞快、坐不住；
> - 出现大额消费、借贷、危险驾驶、轻率性行为；
> - 情绪突然从低落转为异常高涨或异常易怒；
> - 开始想自行加抗抑郁药或自行停药。

拿不准时按严重处理。**躁狂本身是可以伤人的急症**，越早干预，恢复越快，对大脑和生活的损耗越小。
