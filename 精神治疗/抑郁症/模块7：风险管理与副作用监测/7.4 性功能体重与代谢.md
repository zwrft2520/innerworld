# 7.4 性功能体重与代谢

抑郁治疗里，有两件事最容易被咽回去：一是性方面的变化，二是体重和腰围。它们不致命，却实实在在影响一个人要不要继续吃药。这一页讲清楚：哪些药更容易带来这些问题、怎么开口和医生说、等待/减量/换药/加药各自要付出什么代价，以及体重、腰围、血糖血脂该怎么盯。

## 为什么这两件事总被忍着不说

很多人宁可偷偷把药减半，也不愿在诊室里说“我最近那方面不太行”。原因大致有三种：

- **说不出口**。性在中国人的日常对话里本身就是隐私，何况是对着医生讲细节。
- **怕被当成挑剔**。觉得医生已经很忙，自己为了“不影响生命”的事去调整方案，好像不识好歹。
- **以为只能二选一**。要么忍着副作用吃下去，要么停药让抑郁回来。

这三种想法都能理解，但都会让治疗吃亏。**性功能和体重是依从性最强的预测因素之一**——一个人可以忍受恶心两周，却很难忍受半年性生活消失，也很难忍受裤子一条条穿不上。忍到最后往往是“自己悄悄停了”，而医生完全不知道原因。

需要先说清楚一个前提：**抑郁本身就会影响性欲和体重**。抑郁发作时性欲下降很常见，食欲可能减退也可能增加，活动量下降会让人发胖。所以判断“是不是药的问题”，最好有治疗前的基线——这也是为什么第一次就诊时如实讲这些，是有用的。

## 性功能：哪些药更常见，具体是什么

抗抑郁药对性功能的影响，主要集中在几个方面：性欲下降、勃起或润滑困难、射精延迟、高潮困难或快感减弱。不同类别差别不小，但**个体差异很大，同类药也不是都一样**【指南】【研究】。

| 药物类别 | 性功能影响的大致特点 | 常见具体表现 |
|---|---|---|
| SSRI（如舍曲林、帕罗西汀、氟西汀、西酞普兰、艾司西酞普兰） | 最常见，尤其是射精延迟 | 性欲下降、高潮延迟或难以达到、快感变淡 |
| SNRI（如文拉法辛、度洛西汀） | 较常见，通常略低于 SSRI | 性欲下降、射精延迟、勃起困难 |
| 米氮平（NaSSA） | 相对较少 | 性欲下降报告较少，但可能体重增加 |
| 安非他酮（NDRI） | 相对最少，常被用来改善 | 少数人反而性欲增强 |
| TCA（如阿米替林、氯米帕明） | 较常见 | 性欲下降、勃起困难、射精障碍 |
| 曲唑酮 | 影响较小，但可能引起异常勃起（罕见急症） | 需立即就医 |

这张表只说明“群体趋势”，不能用来给自己选药。有人吃 SSRI 完全没影响，也有人吃所谓“影响最小”的药照样出问题。

关于“会不会永久坏掉”，这是最让人害怕的问题。目前的认识是：**大多数人在停药或换药后，性功能会逐步恢复**；少数人报告症状持续较久，相关研究质量有限，还没有定论【待验证】。把这个不确定性如实说出来，比拍胸脯保证“肯定没事”更负责，也比吓唬人“会毁掉一辈子”更接近事实。

## 怎么开口和医生谈

不用组织语言，也不用铺垫。最有效的方式是**具体、简短、说影响**。下面这张表可以直接借用。

| 不太好开口的说法 | 更容易被接住的表达 |
|---|---|
| “那个……最近有点那个……” | “吃药以后性生活有变化，我想说一下。” |
| “没什么事。”（其实有事） | “有一件事影响我继续吃药，我想解决。” |
| “是不是这药把我弄废了？” | “这个变化大概什么时候能恢复？需要调方案吗？” |
| “我能不能自己减一半试试？” | “有没有可能在不影响疗效的前提下调整？” |

三个信息点，说清楚就够了：

1. **什么时候开始的**：吃药前有没有、加量后有没有变。
2. **具体是什么**：性欲、勃起、润滑、射精、高潮，哪一环。
3. **影响有多大**：用 0–10 分打分，或直接说“影响到我不太想继续吃药了”。

如果当面实在说不出口，可以提前写在纸上、写在手机备忘录里递给医生，或者在复诊前发给门诊护士。很多医院的门诊记录里有一栏专门问这个，填了医生就会看到。

**重要的是让医生知道“这件事对你有多重要”**。同样是性功能受影响，有人觉得可以接受，有人觉得必须处理。医生不会读心，说出来才会被纳入考量。

## 体重与代谢：不是“意志力”问题

体重增加是抗抑郁药最影响长期坚持的副作用之一，也是“病耻感”最重的一个——很多人把它理解成自己管不住嘴，其实不完全是。

常见机制有三条：**食欲增加**（尤其对甜食和碳水）、**镇静和疲倦导致活动量下降**、**部分药物对糖脂代谢的直接影响**。三条叠加，几个月下来体重上一个台阶并不奇怪。

不同药物的大致倾向如下（同样只是群体趋势，个体差异大）：

| 药物类别 | 体重影响的大致倾向 |
|---|---|
| 米氮平 | 增加较常见，早期尤其明显 |
| 帕罗西汀等部分 SSRI | 中长期增加较常见 |
| TCA | 增加较常见 |
| 舍曲林、氟西汀、西酞普兰等 | 短期多中性，长期部分人增加 |
| 文拉法辛、度洛西汀 | 多中性，部分人初期下降 |
| 安非他酮 | 多中性或轻度下降 |

监测不需要复杂设备。家里有一台体重秤、一根软尺就够了：

- [ ] 治疗开始前称一次体重、量一次腰围，记下来当基线
- [ ] 之后每 2–4 周固定时间称一次（晨起、空腹、同一件衣服）
- [ ] 腰围每 1–3 个月量一次（男性 ≥90 cm、女性 ≥85 cm 需要留意，中国人群标准）
- [ ] 有糖尿病、高血压、高血脂、多囊卵巢的人，治疗前后查血糖、血脂
- [ ] 记录食欲变化：是不是特别想吃甜食、夜里想吃东西
- [ ] 记录活动量：每天走路多少分钟，是否比治疗前明显减少
- [ ] 体重短期内快速上升（比如一个月内明显增加）要报告医生

体重上升本身不可怕，可怕的是它带来的一系列代谢变化。**腰围比体重更能反映内脏脂肪**，所以量腰围这件事，比每天称体重更有意义。

## 四条路的取舍：等待、减量、换药、加药

发现问题后，能走的路大致四条。每一条都有代价，没有“只有好处”的选项。

| 选择 | 可能得到什么 | 要付出什么 |
|---|---|---|
| 等待观察 | 部分副作用在数周内减轻，尤其是恶心、头晕 | 性功能问题往往不会自行消失，拖着可能让人悄悄停药 |
| 减量 | 副作用可能减轻 | 疗效可能下降，复发风险上升；必须由医生决定 |
| 换药 | 换成影响较小的药，问题可能明显改善 | 需要经历换药期的不适，新药可能带来新副作用，情绪可能波动 |
| 加药（如加安非他酮） | 有研究支持可改善部分人的性功能 | 多吃一种药、多一层相互作用风险，可能引起焦虑、失眠，双相倾向者需谨慎 |

关于“加安非他酮”这条路，需要多说两句。安非他酮属于 NDRI，主要作用于多巴胺和去甲肾上腺素，和 SSRI 的机制不同。有研究显示，在 SSRI 基础上加用它，可以改善一部分人的性功能【研究】。但它不是万能钥匙：可能加重焦虑和失眠，降低癫痫阈值（有癫痫史的人要特别说明），也可能和多种药物发生相互作用。**是否加、加多少，必须由医生决定。**

关于“减量”，还有一个常被忽略的点：**很多人是在疗效刚稳定时自行减量的**，结果副作用轻了一点，情绪却又滑下去，最后分不清是副作用难受还是病难受。这也是为什么调整要在有随访的情况下做。

### 常见坑

**坑一：以为“忍过去就好了”。** 恶心、头晕多半会过去，性功能障碍常常不会。忍不是策略。

**坑二：把体重增加全算在自己头上。** 药物改变食欲和活动量是真实的生理作用，不是意志力薄弱。自责只会让人更不想面对。

**坑三：为了性生活自行停药。** 突然停药带来的情绪反弹，往往比副作用本身更影响关系和生活。

**坑四：用减肥药、保健品“对冲”。** 很多减肥产品成分不明，和抗抑郁药同服可能增加心血管和肝脏风险。

**坑五：只和伴侣吵，不和医生说。** 伴侣之间的误解（“你是不是不爱我了”）很常见，把药物因素讲清楚，关系压力会小很多。

## 什么时候需要联系医生或去急诊

> **出现以下情况，尽快（当天到数日内）联系开药医生：**
>
> - 性功能变化已经影响到是否愿意继续服药；
> - 体重在短期内明显上升，或腰围快速增长；
> - 食欲失控、暴食，尤其集中在夜间；
> - 出现明显口渴、多尿、乏力（可能提示血糖问题）；
> - 已经在考虑自行减量或停药。

> **出现以下情况，立即去急诊或拨打 120：**
>
> - 阴茎异常勃起（持续数小时、疼痛、与性刺激无关）——这是泌尿科急症，延误可能造成永久损伤；
> - 胸痛、晕厥、心跳异常加快或不规则；
> - 严重过敏：皮疹迅速扩散、面唇肿胀、呼吸困难；
> - 高热、意识模糊、肌肉僵硬或抽动、大汗。

拿不准时，先联系开药医生；联系不上又明显不对劲，直接去急诊。也可以拨打 **12356** 心理援助热线，先缓解“说不出口”的焦虑。
