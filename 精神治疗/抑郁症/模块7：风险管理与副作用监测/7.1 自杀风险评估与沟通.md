# 7.1 自杀风险评估与沟通

这一页写给两类人：自己反复冒出“活着没意思”的念头、不确定该不该说出口的人；以及发现家人状态不对、想问又不敢问的家属。读完你会知道：为什么直接问不会“把人问出事”、一次完整的评估要问到哪些方面、风险高低大致怎么分，以及在家里最实在的两件事——安全计划和手段限制——具体怎么做。

## 为什么可以直接问

很多人不敢开口，是怕“本来没想，被一问反倒想起来了”。这个担心很自然，但它和目前的专业认识相反。**询问自杀念头不会诱发自杀**，这是精神科评估里反复验证过的一条基本原则，也是 NICE 指南和国内抑郁障碍防治指南共同要求的常规动作：只要在评估抑郁，就应该直接问自杀相关的想法【指南】。

反过来，不问的代价更大。很多人在诊室里不会主动说，因为怕被贴标签、怕被送住院、怕家人知道；但如果医生或家属平静地问一句，他们常常会松一口气，把憋了很久的话讲出来。**沉默不等于没有风险，只等于风险没被看见。**

开口时注意三件事：

1. **场合**：找一个能坐下说话、不会被别人打断的地方，不要在饭桌上顺口一提，也不要在亲戚面前问。
2. **语气**：平静、具体、不惊讶、不评判。像问“最近胃还疼吗”一样问。
3. **位置**：先说明你为什么问——“我最近看你晚上都睡不着，我有点担心”，再问具体的问题。

需要先解释两个词。**自杀意念**，就是“想死、不想活了、希望睡着不再醒”这类念头，它可以是偶尔一闪，也可以是每天都在。**自杀计划**，是指脑子里已经出现了“怎么做”的具体想法。两者不是一回事，评估时要分开问。

## 问什么：从想法到准备的五个层次

评估不是问一句“你想不开吗”就结束。有效的询问是从轻到重一层层往下走，每一层都问清楚。下面这张表可以直接照着用。

| 层次 | 可以怎么问 | 听到“有”之后先做什么 |
|---|---|---|
| 1. 想法 | “最近有没有觉得活着没意思，或者不如死了算了？” | 别急着劝，先让他把话说完 |
| 2. 频率与强度 | “这种念头多久来一次？来的时候有多强烈，能撑过去吗？” | 记下来，作为复诊时要讲的信息 |
| 3. 计划 | “有没有想过具体会怎么做？” | 回答“想过”，风险等级就要往上提 |
| 4. 准备 | “有没有为这个做过什么准备，比如攒药、查方法、写过东西？” | 当天联系医生，同时开始做手段限制 |
| 5. 既往尝试 | “以前有没有做过伤害自己的事？最近一次是什么时候？” | 既往尝试是最强的风险因素之一，必须告诉医生 |

除了这五层，还有几项信息同样重要，很多人会漏掉：

- **保护因素**：有没有放不下的人、有没有还没做完的事、有没有明确的求助意愿、家里有没有人可以陪着。保护因素不是“免死金牌”，但它决定了接下来能怎么安排。
- **冲动性**：是长期反复想，还是一气之下就做。冲动性高的人，风险窗口很短，需要更密集的看护。
- **酒精和药物**：喝酒、混用镇静药、自行加量，都会让判断力和控制力在短时间内明显下降。
- **睡眠**：连续多日几乎不睡，本身就是风险升高的信号，也会加重冲动。
- **近期的丧失**：分手、失业、亲人去世、被羞辱、经济崩盘，这类事件之后的几周是高风险期。
- **独居与手段可及**：一个人住、家里有大量药物或其他危险物品，都会影响安全安排。

问的时候不必一次问完。可以分几次，也可以先问最重的那一层：“你现在有没有想过要结束自己的生命？”如果对方回避，可以换个说法再问一次，不要因为一次“没有”就彻底放下。

## 风险分级：把“想死”分成几档

分级不是为了给谁贴标签，而是为了决定**下一步做什么、由谁来做、多快做**。临床上会综合上面所有信息判断，不存在一个能精确算出分数的公式；下面这张表是帮助理解的粗略框架【临床经验】。

| 等级 | 常见表现 | 大致处置方向 |
|---|---|---|
| 低 | 偶发念头，没有计划，没有既往尝试，能明确说出“我不会去做”，身边有人 | 门诊随访，把安全计划和求助电话写下来，缩短复诊间隔 |
| 中 | 反复出现念头，有模糊计划，或有过既往尝试，或近期重大丧失，或经常饮酒 | 尽快联系医生（当天到数日内），加强陪护，做手段限制，考虑增加复诊频率 |
| 高 | 有具体计划并有准备行为，或近期尝试过，或处于极度激动、绝望、无法保证安全的状态 | 立即急诊评估，不独处，必要时住院；途中由人全程陪同 |

有几种情况，无论自评是几档，都按高风险处理：

- 出现**命令性幻听**（听到有声音命令自己去死），或坚信自己已经没救了、罪不可赦；
- 已经写好遗书、把东西送人、突然异常平静地道别；
- 刚刚经历过一次尝试，或从医院回来后短时间内念头再次出现；
- 处于极度激越、坐立不安、无法入睡的状态。

最后一条常被忽略：**“突然变平静”不一定是好转**。如果一个人在长期痛苦之后突然安静下来，还开始交代事情，要当作危险信号，而不是放心。

## 安全计划与手段限制

安全计划是一张写下来的纸，不是一句“有事给我打电话”。它的作用是：在脑子最不清楚的时候，替你做决定。

一份可用的安全计划至少包含六步（详细模板见 [9.2 安全计划模板](<../模块9：复发预防与危机干预/9.2 安全计划模板.md>)）：

1. **我的预警信号**：连续几晚睡不着、开始躲人、反复说“没意义”。
2. **我自己能做的事**：洗热水澡、出门走十分钟、听固定的歌单。
3. **能让我分心的人和地方**：可以去的朋友家、24 小时便利店、客厅。
4. **可以求助的人**：写下两三个名字和电话，不要只写“家人”。
5. **专业渠道**：开药医生的电话、医院急诊地址、12356 心理援助热线。
6. **让环境变安全**：这一步最具体，也最常被跳过。

**手段限制**是指减少身边能造成伤害的东西。指南明确把它列为自杀预防的重要措施【指南】。它不需要讲道理，只需要动手：

- [ ] 家中药物由家人保管，按次给，不把整瓶放在患者房间
- [ ] 不在家里囤积过量药物，过期的及时处理
- [ ] 刀具、利器、绳索、农药等收进上锁的柜子或放到别处
- [ ] 高层住所注意窗户和阳台，必要时加装限位
- [ ] 不让患者独自长时间待在封闭空间，尤其是夜间
- [ ] 家中有人轮流陪护，交接时说清楚“今晚谁在”
- [ ] 把急诊地址、路线、电话写在冰箱上或手机备忘录置顶
- [ ] 家人之间约定：一旦出现计划或准备行为，不争论、不劝说，直接陪同就医

清单里的第 7 条和第 8 条看起来琐碎，但在真正慌乱的时刻，人想不起地址，也容易在争执中耽误时间。

需要提醒的是：**手段限制不应该变成监视**。翻手机、跟踪出门、把门反锁，短期可能有安全感，长期会让患者学会隐瞒。比较好的做法是事先一起商量——“哪些东西你愿意交给我保管，哪些我们放在公共区域”，让患者参与决定。

## 家属怎么接话

家属最常问的问题是：“我到底该说什么？”答案不是准备好一套说辞，而是先做到两件事：**不打断，不评价**。

| 比较有用的话 | 容易伤人、也容易让对话结束的话 |
|---|---|
| “你愿意跟我说这些，我很在意。” | “你想开点，多大点事。” |
| “我不会因为你说这些就觉得你矫情。” | “别人比你惨多了，你怎么不想想父母。” |
| “现在不用解决所有问题，我先陪你把今晚过完。” | “你要是敢做，我就不认你这个孩子。” |
| “我不知道该说什么，但我不想走开。” | “你保证以后再也不许想这些。” |
| “要不要我陪你去看医生，我陪你进去。” | “你就是太闲了，找点事做就好了。” |

右边这些话之所以伤人，不是因为家属坏，而是因为它们把责任推回给了已经没力气的人。抑郁发作时，“想开一点”不是不愿意，而是暂时做不到——就像让一个腿骨折的人“跑两步就好了”。

还有几个具体动作，比说话更管用：

- **陪着，但不逼着聊**。坐在同一个房间各做各的事，也是一种有效的陪伴。
- **把“随时找我”换成具体的约定**：“今晚十一点我给你发消息，你回我一个字就行。”
- **不要承诺保密**。如果涉及生命危险，必须告诉医生和能帮忙的家人；事先说明这一点，比事后背叛信任好。
- **照顾者也要有人接手**。长期陪护的人本身会耗竭，情绪耗竭的照顾者容易说出伤人的话。

### 不要用“保证不自杀”的承诺代替评估

“你答应我，不管怎么样都不能做傻事。”这句话几乎每个家属都说过。它的出发点是爱，但它不能替代评估，原因有三个：

第一，**承诺在症状面前不可靠**。自杀念头受睡眠、酒精、冲动、疼痛、药物调整影响，会在一夜之间变化。一个人上午真心答应，凌晨三点可能完全做不到。这不是不守信用，而是症状本身的特点。

第二，**要求承诺会让真话消失**。当患者发现“说实话会被要求保证、会被盯着”，下一次就会选择不说。风险不会因此降低，只会转入地下。

第三，**承诺把责任放错了地方**。它暗示“你不做，就是你对得起我们；你做了，就是你辜负我们”。这会让本就自责的人更自责。

更有效的替代做法，是把“保证”换成“计划”：

- 今晚谁陪你，睡哪个房间；
- 药放在谁那里，每次给几片；
- 难受时按什么顺序打电话（先打给谁，打不通再打给谁）；
- 什么情况下不再商量，直接去医院；
- 下一次复诊是哪天，由谁陪。

**能落实的安排，比一句誓言可靠。**

## 什么时候需要联系医生或去急诊

> **出现以下任何一种情况，不要等、不要劝、不要独自留守：立即拨打 120 或前往最近医院急诊。** 途中由人全程陪同，暂时收起家中可能造成伤害的物品。
>
> - 已经做出准备行为（攒药、查看方法、写遗书、道别、送东西）；
> - 刚刚发生过自伤或服药，哪怕看起来“没事”；
> - 出现命令性幻听，或坚信自己罪不可赦、已经没救；
> - 极度激越、无法入睡、行为失控，家人无法保证其安全。

> **出现以下情况，当天联系开药医生或精神科门诊，不要拖到下次复诊：**
>
> - 自杀念头从“偶尔一闪”变成“每天都在”，或强度明显加重；
> - 新出现具体计划，但还没有行动；
> - 近期有过尝试，最近念头再次出现；
> - 开始大量饮酒、自行加药或停药；
> - 连续多日几乎不睡，情绪突然变得异常平静。

如果不确定算不算严重，按严重处理。也可以拨打 **12356** 心理援助热线，先把当下这一刻撑过去，再谈后面的安排。
