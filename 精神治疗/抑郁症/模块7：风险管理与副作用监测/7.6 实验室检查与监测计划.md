# 7.6 实验室检查与监测计划

“我来看情绪问题，为什么要抽血、做心电图？”这是精神科门诊里很常见的疑问。答案是：有些身体疾病会伪装成抑郁，有些药物需要看肝肾功能才能安全使用，有些副作用只有化验才能早期发现。这一页讲清楚基线该查什么、复诊多久一次、什么情况要加查，以及拿到报告后该怎么看——既不漏查，也不过度检查。

## 为什么精神科也要抽血

大致有四个理由。

**第一，排除“伪装成抑郁”的躯体疾病。** 甲状腺功能减退、贫血、维生素 B12 缺乏、慢性感染、电解质紊乱，都可能表现为乏力、情绪低落、注意力差、睡眠紊乱。不查就按抑郁治，可能治了很久没效果。

**第二，建立基线。** 吃药前先知道肝肾功能、电解质、血常规是什么水平，后面出现异常时才知道“是药引起的”还是“本来就那样”。

**第三，监测已知风险。** 低钠、出血倾向、血糖血脂变化、肝功能损伤，早期往往没有感觉，只能靠化验发现。

**第四，指导用药安全。** 肝功能、肾功能会影响药物在体内的代谢和清除；心电图能发现 QT 延长的高危者。这些信息决定了“能不能用、要不要更密切地看”。

国内指南和 NICE 都建议：在开始抗抑郁治疗前做基本评估，包括必要的实验室检查，尤其对有躯体共病、老年人、多重用药的人【指南】。

## 基线查什么

不是每个人都要查全套。查什么，取决于年龄、既往病史、合并用药和准备用的药物。下表是常见的项目和大致的适用情况。

| 检查项目 | 主要为了看什么 | 哪些人尤其需要 |
|---|---|---|
| 血常规 | 贫血、血小板数量（影响出血风险判断） | 几乎所有人；有出血倾向、老年人 |
| 肝功能 | 药物代谢能力、有无肝炎或脂肪肝 | 几乎所有人；饮酒、肥胖、肝病史 |
| 肾功能 | 药物清除能力、电解质平衡 | 老年人、糖尿病、高血压、肾病史 |
| 电解质（钠、钾、氯） | 低钠的基线；钾镁与心脏风险相关 | 老年人、合用利尿剂、有呕吐腹泻 |
| 甲状腺功能（TSH 等） | 甲减或甲亢都可能导致情绪症状 | 几乎所有人，尤其女性、老年人 |
| 空腹血糖、血脂 | 代谢基线；部分药物会影响 | 肥胖、糖尿病家族史、40 岁以上 |
| 心电图 | QT 间期、有无心律失常、缺血 | 心脏病史、老年人、用 TCA 或西酞普兰类、合用多种药物 |
| 妊娠试验 | 是否怀孕，直接影响用药选择 | 育龄女性，尤其月经推迟时 |
| 维生素 B12、叶酸 | 缺乏可导致乏力、认知下降、情绪低落 | 素食、老年人、胃肠手术后、长期饮酒 |
| 乙肝、梅毒等筛查 | 部分情况需要，视病史而定 | 有相关风险因素时 |

几点说明：

- **心电图不是人人都必须做**，但对老年人、有心脏病、准备用 TCA 或西酞普兰类、同时用其他可能延长 QT 的药物的人，通常建议做【指南】。
- **妊娠试验很重要**。怀孕早期用药和没怀孕时的选择完全不同，育龄女性月经推迟时一定要先排除。见 [6.3 孕产期抑郁](<../模块6：特殊人群与特殊时期/6.3 孕产期抑郁.md>)。
- **药物基因检测**近年被讨论得很多，目前证据有限、价格差别大，多数指南还没有把它列为常规【待验证】。可以作为和医生讨论的选项，但不建议因此推迟治疗。
- **不必追求“查得越全越好”**。没有指征的检查会增加费用、假阳性带来的焦虑，以及不必要的后续检查。

## 复诊频率：不同阶段不一样

复诊不是“有空就去”，频率本身是治疗的一部分。国内指南和 NICE 的建议大致如下【指南】。

| 阶段 | 大致频率 | 复诊重点 |
|---|---|---|
| 开始用药的前 4 周 | 每 1–2 周一次，或至少有一次电话/线上随访 | 副作用、睡眠、激越、自杀念头、能不能坚持吃 |
| 急性期（约前 6–12 周） | 每 2–4 周一次 | 症状变化、剂量是否合适、是否需要调整方案 |
| 巩固期（症状缓解后 4–9 个月） | 每 1–2 个月一次 | 是否稳定、有没有残留症状、副作用是否影响生活 |
| 维持期 | 每 2–3 个月一次；稳定多年后可延长 | 复发预警信号、代谢指标、生活事件、停药计划 |
| 减药或停药阶段 | 比稳定期更密，减量后数周内应有随访 | 撤药反应、复发信号、睡眠变化 |

现实中门诊资源紧张，不一定能做到这么密。如果约不到，可以用电话、互联网医院、社区随访补上；关键是**前四周别断联**。

## 什么情况要加查

下面这些情况，即使还没到复查时间，也值得主动要求加查。

- [ ] 新加一种药，或明显加量（尤其是可能影响心电图、电解质、肝功能的药）
- [ ] 开始合用利尿剂、降压药、抗凝药、抗血小板药、NSAIDs 止痛药
- [ ] 老年人首次用药，或近期出现跌倒、意识变化
- [ ] 连续呕吐、腹泻、吃不下饭、大量出汗（电解质容易乱）
- [ ] 出现心悸、晕厥、抽搐、明显乏力
- [ ] 出现黑便、呕血、异常瘀斑、出血不止
- [ ] 发热、黄疸、尿色变深、右上腹不适（警惕肝损伤）
- [ ] 明显口渴、多尿、体重快速下降（警惕血糖问题）
- [ ] 怀孕或准备怀孕
- [ ] 长期饮酒或近期大量饮酒
- [ ] 疗效一直不好，需要排查“假难治”（见 [5.1 难治性抑郁的评估](<../模块5：难治性抑郁与联合策略/5.1 难治性抑郁的评估.md>)）

## 怎么看懂报告

拿到化验单，先看三件事：**哪些项目有箭头、箭头偏离多少、和上次比变化多大**。不要只盯着箭头。

| 常见项目 | 大致看什么 | 容易误会的地方 |
|---|---|---|
| 血钠 | 低于参考范围要重视，尤其在用药早期 | 轻度偏低可能没症状，但需要复查；不要自己猛喝盐水 |
| 血钾 | 过低会增加心律失常风险 | 腹泻、利尿剂、吃太少都会低 |
| 转氨酶（ALT/AST） | 升高提示肝细胞受损 | 轻度升高很常见，可能和脂肪肝、饮酒、剧烈运动有关 |
| 肌酐 | 反映肾功能 | 肌肉量大的人可能偏高，不代表肾坏 |
| 血红蛋白 | 贫血 | 女性生理期后可能偏低 |
| TSH | 甲状腺功能 | 边缘升高需要复查，不一定要立刻吃药 |
| 心电图 QTc | 是否延长 | 机器自动读数常不准，需要医生人工判读 |

几个原则：

1. **参考范围是群体的，不是个人的。** 略高于或略低于上限，不等于生病。
2. **单次异常不如趋势重要。** 一次转氨酶轻度升高，和连续三次逐步上升，意义完全不同。
3. **不要拿报告自己下诊断，也不要自己买药“纠正”。** 比如看到血钠低就大量喝盐水，可能适得其反。
4. **报告要给开药医生看，不要只看化验科的解释。** 同一个数值，在不同药物背景下处理方式不同。

### 一份可以照抄的监测记录

把每次检查结果记在一张纸上，复诊时直接给医生看，比翻手机相册有效得多。

- [ ] 日期、医院、检查项目
- [ ] 关键数值：血钠、血钾、转氨酶、肌酐、血红蛋白、TSH、空腹血糖、血脂
- [ ] 心电图结论（QTc 数值，如有）
- [ ] 当时的用药清单（药名、每天几次、每次几片）
- [ ] 当时有没有症状（乏力、心悸、出血、水肿等）
- [ ] 医生的处理意见和下次复查时间

### 不要过度检查，也不要漏查

这句话听起来像废话，但两头都常见。

**过度检查**的样子：每次复诊都要求查全套、反复做心电图、花大钱做各种“营养评估”“基因检测”，结果报告一堆箭头，越看越焦虑，反而不敢吃药。检查是为了回答具体问题，没有问题就没有必要查。

**漏查**的样子：吃了几年药从没查过电解质；老人开始用药前没查过血钠；同时吃布洛芬和 SSRI 却没人提过出血风险；心悸晕厥过一次但没做心电图。这些漏掉的项目，往往正是最容易出问题的地方。

一条实用原则：**治疗开始前查一次基线，之后按风险定期复查，出现症状随时加查。** 具体查什么、多久查一次，由医生根据你的情况决定。

## 什么时候需要联系医生或去急诊

> **立即拨打 120 或去急诊：**
>
> - 晕厥、抽搐、意识模糊；
> - 呕血、黑便；
> - 胸痛、持续心悸伴头晕大汗；
> - 高热伴肌肉僵硬、意识改变；
> - 皮肤或眼白发黄并迅速加重。

> **当天联系开药医生：**
>
> - 化验报告出现明显异常（血钠低、血钾低、转氨酶明显升高、QTc 延长）；
> - 新出现出血倾向、明显乏力、水肿、尿量减少；
> - 准备开始吃新的处方药、非处方止痛药或中成药；
> - 怀孕或怀疑怀孕；
> - 连续呕吐腹泻、吃不下饭超过一两天。
