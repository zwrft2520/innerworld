# 13.2 用药与副作用记录表

抗抑郁药的效果和副作用，都不是一句话能说清的：“吃了有点晕”和“吃完两小时头晕，站起来眼前发黑，持续三天，第三天开始减轻”，对医生来说是完全不同的两条信息。这一页给你一张可以照抄的记录表，教你怎么把副作用描述到医生能用的程度，以及复诊时怎么在三分钟里把关键信息讲完。它不教你调药，只教你把话说清楚。

## 一、这张表解决什么问题

- **记得住**：今天吃了什么、几点吃的、有没有漏，隔两周常常想不起来。
- **说得清**：副作用什么时候开始、有没有加重，靠回忆很容易说错。
- **看得出**：换药前后对比、加量后第一周的反应，只有记录才能对上时间。
- **防遗漏**：中药、保健品、感冒药、止痛药，常常忘了告诉医生，而它们可能相互作用。

还有一条：记录能帮你避免“凭感觉调药”。很多人因为难受自己减半，过几天又加回去，血药浓度忽高忽低，副作用和疗效都变得难以判断。

## 二、记哪些字段

最少记这几项，够用了：

| 字段 | 怎么填 | 为什么重要 |
|---|---|---|
| 药名 | 通用名 + 商品名，比如“舍曲林（左洛复）” | 同名不同厂、同厂不同名很常见，写全才不会混 |
| 时间与剂量 | 早上/晚上，几片或多少毫克，按处方原样抄 | 复诊时医生要核对，别凭记忆 |
| 漏服 | 哪顿漏了、有没有补、补了多少 | 漏服会影响判断“疗效不好”的原因 |
| 副作用 | 什么时候开始、什么感觉、多严重、持续多久 | 决定要不要调整方案的关键信息 |
| 睡眠 | 入睡多久、夜里醒几次、总共几小时 | 睡眠既可能是症状，也可能是副作用 |
| 其他药物 | 中药、保健品、感冒药、止痛药、避孕药、酒 | 相互作用常常藏在这里 |

如果只记一栏，就记“药名 + 时间 + 副作用”。如果还有余力，加上“今天情绪几分”和“今天最影响我的一件事”。

**不要在这张表上写“我觉得该减了”。** 记录是给医生看的材料，不是处方。想减药，把想法写下来，复诊时问。

## 三、怎么描述副作用

医生最怕听到的是“我不舒服”，最需要的是四件事：

1. **什么时候开始的**：换药后第几天？加量后第几天？还是吃了某样东西之后？
2. **和吃药的时间关系**：吃完一小时出现，还是第二天早上？和某顿饭有关吗？
3. **多严重**：轻（能忍，不影响做事）、中（影响做事，但还能撑）、重（做不了事，或需要别人帮忙）。也可以打个 0–10 分。
4. **持续多久、有没有变化**：一直这样，还是一天比一天轻？有没有哪个时间段特别重？

再加一句“影响了什么”，信息就完整了：影响开车、影响开会、影响睡觉、影响吃饭、影响性生活。

| 模糊的说法 | 医生能用的说法 |
|---|---|
| “吃了很难受” | “换药第三天开始恶心，早饭后一小时最重，持续到下午，这几天在减轻” |
| “头晕” | “起身时眼前发黑，一天两三次，量过血压偏低” |
| “睡不着” | “入睡要两小时，凌晨三点醒，醒了就睡不着，持续五天” |
| “没性欲” | “这两周完全没有性欲，之前是正常的，影响到了伴侣关系” |
| “拉肚子” | “每天三四次，水样，饭后明显，没有发烧和便血” |
| “心慌” | “每天下午心跳快，坐不住，持续半小时左右，和喝咖啡有关” |

描述副作用时，**不要只报坏消息**。好转的部分也要说：睡眠从四小时变成六小时、恶心从每天变成隔天、能出门了。医生需要同时看到收益和代价，才能判断值不值得继续。

**换药或加量后的前两周，每天照着勾一遍：**

- [ ] 今天吃了几次、几点吃的、有没有漏
- [ ] 有没有新出现的不舒服，什么时候开始的
- [ ] 睡眠几小时，夜里醒几次
- [ ] 有没有吃其他药、中药、保健品，有没有喝酒
- [ ] 有没有影响到开车、上班、上课
- [ ] 有没有出现需要立刻联系医生的情况

## 五、复诊时怎么用

三分钟讲完，按这个顺序：

1. **先讲变化**：“这两周整体比上次好一点，睡眠从四小时到六小时。”
2. **再讲问题**：“但早上吃药后恶心，持续了五六天，现在轻了。”
3. **讲依从性**：“有一次晚上忘吃，第二天没有补。”
4. **讲新增的东西**：“上周感冒，吃了两天复方感冒药，还喝了两次酒。”
5. **讲想问的**：“这个恶心要不要处理？下次什么时候复查？”

带的东西：

- 药盒或药品照片（比说药名可靠）；
- 这张记录表，或者手机里的记录；
- 上次的处方和化验单；
- 一张写好的问题清单，最多三个。

如果医生说“最近怎么样”，不要只回答“还行”。可以拿出表，指给他看这三行：“这周睡眠、这周恶心、这周漏服。”医生看到具体的时间线，判断会快很多。

### 几个容易踩的坑

- **只记商品名**：不同厂家的商品名不一样，通用名才是“身份证”。
- **漏服不说**：怕被批评，就瞒着。其实漏服是常见现象，说出来医生才能判断“疗效不好”是不是因为这个。
- **把新症状都归给药**：感冒、失眠、焦虑、躯体病也会引起类似表现。记录时间线，让医生判断。
- **保健品不算药**：圣约翰草、鱼油、褪黑素、中药，都可能相互作用，都要记。
- **记录完自己调药**：这是最危险的一条。记录的目的是沟通，不是自行处方。
- **只记副作用，不记好转**：医生会误以为这个方案只有代价没有收益。
- **用记录替代复诊**：数据再多，也不能代替面诊。

## 六、什么时候需要联系医生或去急诊

> **什么时候需要联系医生 / 去急诊**
>
> - 皮疹迅速扩散、面唇肿胀、呼吸困难：立即呼叫 **120**，可能是严重过敏。
> - 高热、大汗、肌肉僵硬或抽动、意识混乱、心跳很快：立即急诊，可能是血清素综合征（一种由药物相互作用或过量引起的、可能危及生命的反应），带上药盒。
> - 黑便、呕血、明显皮下出血、持续头痛：尽快急诊。
> - 抽搐、晕厥、胸痛、意识丧失：立即呼叫 **120**。
> - 开始吃药或加量后，出现自杀念头加重、极度坐立不安、冲动行为：当天联系医生，不要等复诊。
> - 尿不出、严重便秘、视物模糊、心跳很慢：尽快联系医生。
>
> 出现以上任何一条，**不要自行停药或加药**，先联系医生或急诊。

**常见问题**

**“副作用写下来，医生会不会觉得我事多？”** 不会。副作用是调整方案的重要依据，写清楚反而省时间。

**“我漏服了，要不要下次补两倍？”** 不要自行加倍。按医生或药品说明书的漏服指引处理，记下来，复诊时说。

**“记录表要天天填吗？”** 换药、加量、出现新症状的那几周建议天天填；稳定期一周记两三次就够。

**“药名太长记不住怎么办？”** 拍药盒照片，或者让医生把通用名写在处方上。
