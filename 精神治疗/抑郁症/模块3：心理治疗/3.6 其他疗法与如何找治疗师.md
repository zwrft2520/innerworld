# 3.6 其他疗法与如何找治疗师

> 除了 CBT、行为激活、IPT、MBCT，还有几类常被问到的治疗：ACT、短程动力、支持性心理治疗、家庭与伴侣治疗。这一页先简单介绍它们，再把重点放在更实际的问题上：谁能算合格的治疗师、频率和设置怎么看、怎么判断这个人是否适合你、哪些行为是明确的红旗，以及为什么换治疗师不是背叛。

## 先认识另外四种疗法

| 疗法 | 核心在做什么 | 更适合谁 | 大致疗程 |
|---|---|---|---|
| 接纳承诺疗法（ACT） | 不跟想法辩论，练习接纳体验、按价值行动 | 长期与想法纠缠、反复回避的人 | 常8–16次 |
| 短程动力治疗（STPP） | 看重复的关系模式和被回避的情绪 | 问题反复出现、想理解“为什么总这样” | 十几次到几十次 |
| 支持性心理治疗 | 稳住关系与情绪，协助现实应对 | 急性期、老年、合并躯体疾病 | 频率弹性大 |
| 家庭／伴侣治疗 | 把抑郁放回关系里处理 | 关系冲突明显、青少年、照护负担重 | 视情况而定 |

### 接纳承诺疗法（ACT）

ACT 属于“第三代行为疗法”，和 CBT 是亲戚，但着力点不同。CBT 会去检验“我不行”这个想法是否准确；ACT 不太争论内容，而是练两件事：**接纳**（不再花力气赶走不舒服的体验）和**按价值行动**（即使难受，也朝在意的事情走一步）。

它常被概括成六个过程：接纳、认知解离、关注当下、以己为景、澄清价值、承诺行动。听起来抽象，落到操作上很像这样：注意到“我又在跟自己讲道理了”，把这句话放到一边，然后问“如果这次不逃避，我会做什么”。

ACT 在抑郁中有随机对照研究支持，但多数指南还没有把它列为一线的首选心理治疗，证据积累不如 CBT 厚。【研究】它常被用在多次治疗无效、慢性化、以及“越想解决越陷进去”的人身上。

要澄清一点：ACT 里的“接纳”不是认命，也不是放弃治疗。它接纳的是**此刻的感受已经在了**，不接纳的是**让感受决定你接下来做什么**。

### 短程动力治疗（STPP）

动力取向的治疗关注那些反复出现却说不清的模式：为什么总在关系变近时推开对方，为什么被批评时立刻道歉，为什么明明想要却先拒绝。它假设这些模式与早期经历有关，并且在治疗关系里会重演——治疗师会把这些“重演”指出来，和你一起看。

短程动力治疗通常有明确次数（十几次到几十次）、有焦点、有结束日期，不是“做到想停为止”。NICE 把短程动力治疗列为较轻抑郁可选的心理治疗之一。【指南】

它适合想理解“我为什么会变成这样”、问题反复出现、对纯技能训练不满足的人。它不承诺“挖出童年就好了”，也不会要求你相信某种解释——解释要能对上你的体验才有用。

### 支持性心理治疗

支持性心理治疗听起来最普通，但它在几个场景里不可替代：急性期症状重、刚出院、合并严重躯体疾病、认知功能下降、暂时做不了结构化治疗的人。

它做的是：稳定而持续的关系、情绪上的承接、现实问题的协助、鼓励按医嘱治疗。它不深挖童年，也不做系统的技能训练。这不等于“低配”——对某些人，先能稳定地活下来、按时复诊，就是最重要的目标。它常与药物联合使用。【临床经验】

### 家庭与伴侣治疗

抑郁会改变关系：人变得易怒、沉默、拒绝外出，伴侣和父母容易感到被推开，于是加紧追问或干脆回避，关系进一步紧张。家庭和伴侣治疗把这一环纳入工作。

- **伴侣治疗**：适合关系冲突明显、抑郁与关系问题互相加重的情况。研究显示，对这类人群，伴侣治疗对抑郁和关系满意度都有帮助。【研究】
- **家庭治疗**：常用于青少年抑郁，也用于照护负担重的家庭。重点是调整沟通方式与边界，不是追究谁的责任。

有一个例外必须说清：**如果关系中存在家暴、威胁或人身控制，不做伴侣联合治疗。**安全优先，先分别处理，必要时报警。

## 资质与受训背景：谁是合格的治疗师

在中国，能提供心理服务的人有好几类，权限不同。

| 身份 | 能做什么 | 不能做什么 |
|---|---|---|
| 精神科医师 | 诊断、开药、做心理治疗 | —— |
| 心理治疗师（卫生系统职称） | 在医疗机构内开展心理治疗 | 不能开药 |
| 心理咨询师 | 一般心理困扰的咨询 | 不得从事心理治疗或精神障碍的诊断、治疗 |
| 学校心理老师、社工 | 支持、筛查、转介 | 不能诊断、不能治疗 |

需要知道一个背景：2017年以后，人力资源社会保障部不再统一组织心理咨询师职业资格鉴定，市面上的证书种类很多，培训时长和考核标准差异很大。**一张证书不能说明水平**，更不能说明他能治抑郁症。

按《中华人民共和国精神卫生法》，心理咨询人员不得从事心理治疗或者精神障碍的诊断、治疗；发现来访者可能患有精神障碍的，应当建议其到医疗机构就诊。也就是说，**确诊抑郁症之后的“心理治疗”，应当在医疗机构内、由有相应资质的人提供**。

挑选时，比头衔更值得看的是这几样：

- 有没有系统的、为期数月以上的受训经历（不是三五天的培训班）。
- 有没有接受过督导，督导是谁、多久一次。
- 有没有自己的被治疗经历（很多流派要求）。
- 在什么机构执业，出了危机能不能转诊。
- 愿不愿意主动说明自己的方法、限制和不擅长的情况。

## 频率、费用与“设置”

**频率**：多数治疗每周1次，固定在同一天、同一时间。稳定比密集重要——每周固定出现，本身就是安全感的来源。

**时长**：每次约45–60分钟。准时开始、准时结束，不是冷漠，而是让会谈有边界。

**费用**：因城市、机构性质（公立医院、私立机构、个人执业）和治疗师资历差异很大，从公立医院心理治疗门诊到私人执业，跨度可能相当大。这里不写具体数字，因为写出来很快就会过时，也容易误导。可以问清楚：怎么计费、多久付一次、请假或取消怎么算、有没有低价号或团体形式。

**设置**指那些看起来琐碎、其实很重要的约定：固定时间地点、费用与取消规则、保密范围与例外（自伤、伤人风险、依法报告的情形）、治疗师休假时怎么办、危机时怎么联系。**一个愿意在开始就把这些说清楚的人，通常更可靠。**

**远程治疗**：视频形式对轻中度抑郁有研究支持，也方便异地和行动困难的人。【研究】但要考虑隐私（有没有独立空间）、网络稳定，以及出现危机时怎么办。风险较高的人，通常更适合线下。

## 怎么判断治疗师是否合适

匹配度不是玄学，可以看这些具体信号：

- [ ] 3–5次之后，你能说出“我们在做什么、为什么这样做”
- [ ] 你感到被听懂，而不是被评价、被教育
- [ ] 你可以说“不”“我不想谈这个”，对方不会生气或施压
- [ ] 时间稳定，准时开始和结束
- [ ] 对方会主动问睡眠、用药、风险，而不只是听你讲情绪
- [ ] 保密范围和例外，一开始就讲清楚了
- [ ] 你愿意再去下一次，而不是每次出门都后悔
- [ ] 如果是家庭治疗，家属也感到被尊重，而不是被审问

前3–5次可以看作“试用期”。不匹配很常见，**不匹配不等于你有问题**，也不等于治疗没用——可能只是方法和人不搭。

## 不靠谱治疗师的红旗

以下行为出现任何一条，都值得停下来认真对待：

- [ ] 承诺“包治”“永不复发”“几次就能断根”
- [ ] 贬低精神科医生和药物，劝你停药或“别信西医”
- [ ] 越界：私下约会、暧昧、不必要的身体接触、送贵重礼物、向你借钱
- [ ] 索要与治疗无关的隐私，比如社交账号密码、要求查看你全部聊天记录
- [ ] 双重关系：同时是你的客户、合伙人、亲戚、微商或课程代理
- [ ] 收费不透明、临时加价、向你推销课程、保健品或“能量产品”
- [ ] 要求你对治疗内容绝对保密，包括对你的医生
- [ ] 用羞辱、威胁、“你就是不够努力”来推动改变
- [ ] 没有危机处理方案，你出事时找不到人
- [ ] 做了很久仍说不清目标，也从不复评进展

遇到越界或侵害，可以这样做：先停止预约，保留聊天记录、转账记录等证据，向所在机构投诉；涉及性骚扰、性侵害或诈骗，拨打 **110** 报警；涉及医疗机构和执业人员，可向当地卫生健康部门反映。

## 换治疗师不是背叛

很多人明知不合适也不敢换，怕伤人心，怕“前功尽弃”，怕被说成“难搞的病人”。需要明确一点：**治疗是为你的康复服务的，不是为维持一段关系服务的。**

常见的换人理由都很正当：方法不匹配、目标方向不同、搬家或时间冲突、费用承担不了、关系里总觉得不舒服、治疗师休假或离职。

可以这样开口：“我觉得现在的方法对我帮助有限，想和你讨论一下转介。”一个合格的治疗师会协助转介，而不是让你内疚。如果对方用“你这是在逃避”“换了谁都一样”来阻止你，这本身就是信息。

两点平衡：一方面，别因为“他人很好、很耐心”就留下——善意不等于有效；另一方面，也别在3次以内频繁更换，那时还看不出什么。换之前，把自己做过什么、什么有效、什么无效、接下来的目标、目前的用药整理成一页，带到下一次会谈，这样不必从零开始。

## 什么时候需要联系医生 / 寻求额外帮助

> **出现以下情况，请优先处理安全与权益**
>
> - 出现自杀念头、计划或准备行为，或已经自伤：不要独处，立即呼叫 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 治疗师有性暗示、身体接触、私下约会、借钱等越界行为：立即停止预约，保留证据，向机构投诉；涉及侵害请拨打 **110**。
> - 被要求停药、被推销高价课程或保健品：暂停付费，向机构或当地卫生健康部门反映。
> - 治疗期间情绪明显恶化，连续多日无法进食、入睡或照顾自己。
> - 出现话多、睡得很少却不困、冲动消费等转躁迹象，尽快联系精神科医生。
> - 换了两次以上治疗师仍毫无进展，建议复评诊断、共病和用药方案，而不只是继续换人。
