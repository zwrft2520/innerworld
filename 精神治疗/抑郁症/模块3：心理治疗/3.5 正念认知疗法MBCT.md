# 3.5 正念认知疗法MBCT

> 正念认知疗法（Mindfulness-Based Cognitive Therapy，简称 MBCT）最常被问到的是三个问题：8周到底在练什么？为什么它能防复发？我这种情况能不能做？这一页按这三个问题讲清楚，也说明它不适合谁、练习时会遇到什么困难。它不是放松课，也不是“停药替代方案”。

## MBCT 从哪里来，想解决什么问题

MBCT 诞生于上世纪九十年代，由 Segal、Williams、Teasdale 三位学者把正念减压课程（MBSR）和认知治疗结合起来，专门针对一件事：**抑郁反复发作**。

他们注意到一个现象。第一次发作时，抑郁往往由某件具体的事触发；但发作次数越多，触发它所需的条件越少。到后来，可能只是一晚没睡好、一句无心的话，就能启动一整套熟悉的东西：低落、自责、“我怎么又这样”、“我永远好不了”。这条通路被走得越熟，复发越容易。

所以 MBCT 的目标不是“让你开心”，而是**在你和低落之间留出一点空隙**：早一点认出来，少一点被卷走，不让一次低落滚成一次发作。

## 8周课程在练什么

标准形式是团体课程：每周1次、每次约2小时，共8周，中间或结尾有一次较长的静修日；每天还有半小时左右的家庭练习。班级通常由一位受过专门训练的老师带领，有讲解、有练习、有分享。

八周的内容大致是这样一条线：

| 周次 | 主题 | 在练什么 |
|---|---|---|
| 第1周 | 自动导航 | 注意当下，发现“人在这里，心在别处” |
| 第2周 | 活在自己的头脑里 | 区分“直接感受”和“对感受的解释” |
| 第3周 | 聚拢散乱的心 | 正念呼吸，练习把注意力带回 |
| 第4周 | 认出厌恶 | 看见“我不想要这个”如何加重痛苦 |
| 第5周 | 允许如其所是 | 不急着改变，先与不适共处 |
| 第6周 | 想法只是想法 | 去中心化，看见想法不等于事实 |
| 第7周 | 怎样最好地照顾自己 | 把觉察带进日常，识别耗竭信号 |
| 第8周 | 维持与扩展 | 写下自己的复发预防计划 |

注意第5周。很多人以为正念就是“把不舒服赶走”，其实那一周练的恰恰相反：先不赶，先允许它在。这不是认命，而是发现“对抗本身也在消耗你”。

## 三个核心练习：正念呼吸、身体扫描、去中心化

### 正念呼吸

坐下来，把注意力放在呼吸带来的身体感觉上——鼻尖的气流、胸口的起伏、腹部的胀落。不用刻意呼吸得深，也不用数到十。

它唯一的技术要点是：**走神了，发现走神，带回来。**这个“发现—带回”的动作本身就是练习。一次坐十分钟走神二十次，只要带回来二十次，就是二十分钟的练习。走神不是失败，没发现才是。

### 身体扫描

躺下或坐着，把注意力从脚趾开始，一寸一寸移到头顶，感受每个部位当下的感觉——酸、麻、热、紧，或者“什么都感觉不到”。

要澄清两个误会。第一，它**不是放松训练**，目标不是让你睡着或舒服，而是练习“注意到”，哪怕注意到的是难受。第二，犯困、烦躁、想动、觉得无聊，都是常见反应，不是练错了。

身体扫描对某些人不合适：有创伤史、容易解离、对身体感觉特别警觉的人，闭眼静躺可能引发不适。这种情况要提前告诉老师，可以睁眼、只做手和脚、缩短时间，或者换成其他练习。

### 去中心化

这是 MBCT 最关键的技能。对比一下两句话：

- “我不行。”（想法就是事实，人被吞没）
- “我注意到，有一个‘我不行’的想法出现了。”（想法是心里发生的一件事）

第二句就是去中心化，也叫认知解离。它不否认想法的内容，也不强迫你反驳它，只是把你和想法之间拉开一点距离。距离一出现，你就有得选了：可以继续想，也可以先去做别的。

课程里还有一个很实用的小工具，叫“三分钟呼吸空间”：一分钟觉察现在有什么，一分钟把注意力收到呼吸上，一分钟扩展到全身。适合在情绪刚起来、没法安静坐下的时候用。

## 为什么能预防复发，尤其对三次以上发作的人

复发最常见的推手是**反刍**：情绪一低落，就开始追问“为什么是我”“我是不是永远这样”“我哪里做错了”。这些追问看起来像在解决问题，实际上是在反复给低落加燃料。

MBCT 的假设是：只要能在反刍刚启动时认出来——“哦，又开始了”——就有机会不跟着它走。不是把低落消灭，而是不让低落自动升级成一套完整的故事。

证据方面可以这样说：

- 对有过**3次及以上**发作、目前状况较好的人，MBCT 能降低复发风险，NICE 明确推荐。【指南】
- 对有2次发作的人，证据相对弱一些，获益不如三次以上明确。【研究】
- 与维持用药的比较：有研究显示，在医生评估可以安全减药的人中，MBCT 配合有计划地减药，与继续服药相比复发率相近。【研究】但**这不等于可以自己停药**，减药必须在医生指导下进行。
- 对**当前正处于急性发作**的人，MBCT 不是一线选择，效果不如 CBT 或行为激活直接。【指南】
- 近年一些分析显示，MBCT 的实际效果可能小于早期研究，个体差异较大。【待验证】

一句话总结：MBCT 是**缓解期的防复发工具**，不是急性期的灭火器。

## 不适合谁

这一节很重要，因为“正念有益”常被说成万能。

- **当前急性重度发作**：注意力维持不了几分钟，坐下反而更焦虑、更自责。
- **有明确自杀计划或近期自伤**：先处理风险，正念不是危机干预。
- **解离、创伤后闪回未稳定**：闭眼静坐、身体扫描可能触发症状，需要先做稳定化工作。
- **有精神病性症状或处于躁狂期**。
- **严重躯体疾病**导致无法静坐或静躺。
- **把 MBCT 当成停药工具**：这是最常见的误用。
- **期待“被治疗”、不打算每天练习的人**：只上课不练，效果非常有限。
- **童年创伤史者**：现有研究结果不一致，有人获益，有人不适，需要个案评估。【待验证】

决定报名之前，可以先问自己，也问机构：

- [ ] 我现在是缓解期，还是正在发作（发作期优先考虑别的治疗）
- [ ] 我每周能固定留出2小时上课，加每天半小时练习吗
- [ ] 带课老师受过 MBCT 或 MBSR 的系统师资训练吗，有没有督导
- [ ] 课上有人出现强烈情绪反应时，老师会怎么处理
- [ ] 我有没有创伤史或解离经历，需要提前说明吗
- [ ] 我是否在服药，减药计划是否已和医生讨论过

## 练习常见困难

**“静不下来，越坐越焦虑。”** 很常见。把时间缩到3分钟，睁着眼，或者改成走路时注意脚底。焦虑升高本身也可以是观察对象，但不必硬扛。

**“一坐下来就睡着。”** 多半是睡眠债太多。改成白天、坐姿、开窗，或者先做身体活动再坐。睡着了不算失败，只是需要调整条件。

**“没时间练。”** 家庭练习不必都是正式静坐。吃饭时注意味道，走路时注意脚感，洗澡时注意水温，都算。但正式练习仍建议保留，哪怕每天十分钟。

**“我总觉得自己做得不对。”** 正念没有“做得对”。唯一的评判标准是：你有没有注意到当下正在发生什么。带着“我做得不对”的念头坐完十分钟，也是练习。

**“身体扫描让我不舒服，甚至想起一些事。”** 立刻睁眼、坐起来、只做手部或脚部，必要时停止，并告诉老师。不要为了“坚持”硬撑。

**“听别人分享，我更焦虑了。”** 团体里容易比较。可以只听不说，也可以课后和老师单独谈。

**“上完8周，好像没什么变化。”** 变化常常在结束后几个月才显出来，尤其是复发的时候。也可能这门课不适合你，这不算你的失败。

## 什么时候需要联系医生 / 寻求额外帮助

> **出现以下情况，不要自己扛着继续练**
>
> - 练习中反复出现强烈闪回、解离、身体麻木或自伤冲动：暂停练习，联系老师和精神科医生。
> - 出现自杀念头、计划或准备行为，或已经自伤：不要独处，立即呼叫 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 情绪持续恶化，连续多日无法起床、进食、入睡。
> - 出现话多、睡得很少却不困、冲动行为等转躁迹象。
> - 想减药或停药：先找开药医生评估，不要用“我在练正念”作为自行减药的理由。
> - 出现幻听、被控制感、思维紊乱，尽快精神科就诊。
