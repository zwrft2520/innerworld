# 3.3 行为激活

> 抑郁最磨人的地方之一，是“什么都不想做”。很多人等着“有心情了再动”，结果越等越动不了。行为激活（Behavioural Activation，简称 BA）反过来：先把行动排进日程，让情绪慢慢跟上。这一页讲它的原理、四个步骤——活动监测、分级任务、价值清单、奖励与复盘——以及它和 CBT 的关系、适合谁、常见卡点。

## 抑郁把“做事”和“感觉好”的顺序弄反了

先看一个正常的小循环：

> 想做点什么 → 去做 → 过程中有愉快感或“我做到了”的感觉 → 更愿意做下一次

抑郁时，这个循环断了，而且断成一个向下的螺旋：

> 没劲、没兴趣 → 不做 → 生活里的愉快感和掌控感变少 → 更没劲、更没兴趣 → 更不做

这个循环在短期内是“有效”的：躺着确实比出门轻松，推掉聚会确实比硬撑舒服。问题在于代价延迟发生——一个月后，生活半径变小了，能做的事变少了，人也更确信“我不行了”。

行为激活的主张只有一句：**情绪没法靠意志直接调，但行为可以安排。**它不要求你先开心起来再行动，而是先把行动放回去，让情绪有机会被行动带动。这不是“逼自己开心”，也不是“假装正常”，而是重新接触那些本来会带来愉快感和掌控感的活动。

行为激活关心两类感受：

- **愉快感**：这件事本身让我舒服、有趣、放松。
- **掌控感**：做完这件事让我觉得“我还行”“我完成了一件事”。

抑郁时两者都会下降，但通常**掌控感恢复得早一些**。所以刚开始做的时候，“做完了”比“做得开心”更值得记。

它适合谁？主要是这几类人：

- 快感缺失明显：以前喜欢的事现在没感觉，什么都提不起兴趣。
- 乏力、起床困难、白天大部分时间躺着或刷手机。
- 退缩、回避社交、拖延到事情堆积。
- 说不出具体消极想法，做 CBT 的思维记录很吃力。
- 老年、青少年、产后人群（需要按情况调整强度）。

证据方面，行为激活既被视为 CBT 的核心有效成分，也被作为独立疗法验证过；NICE 把行为激活列为较轻抑郁可选的心理治疗之一，较重抑郁的指南推荐里更常点名 CBT 与 IPT。【指南】【研究】

## 第一步：活动监测，先看清一周是怎么过的

行为激活的第一件事不是“改”，是“看”。在不改变任何安排的前提下，记录3–7天，每小时或每半天记一格。

| 时间 | 活动 | 愉快感（0–10） | 掌控感（0–10） |
|---|---|---|---|
| 周一上午 | 躺着刷手机 | 2 | 1 |
| 周一下午 | 遛狗20分钟 | 6 | 4 |
| 周一晚上 | 给家人做了顿饭 | 5 | 7 |
| 周二上午 | 请假没出门 | 1 | 0 |

记录时有三个要点：

1. **只记事实，不评价。**不写“又浪费一天”，只写“上午在床上”。
2. **“什么都没做”也要记。**空白本身就是重要信息。
3. **分数凭第一感觉给。**不用反复琢磨，0–10分足够。

记几天之后，通常能看出三件事：哪些活动之后分数明显高；一天里情绪最低的是哪一段；以及**哪些预期是错的**——以为会开心的刷手机只有2分，以为没意思的散步有6分。小 A 在记录一周后发现，自己唯一稳定在6分以上的时段是遛狗和做饭，而这两件事恰好是他生病后最先砍掉的。这个发现比任何劝说都有说服力。

## 第二步：分级任务，把“整理房间”拆到能开始

抑郁时最典型的一句话是“我知道该做，但我做不动”。问题往往不在意愿，而在任务颗粒度太大。“整理房间”这四个字，对一个精力只剩两成的人来说，等于“搬一座山”。

解决办法是把它拆到**小到不可能失败**。

| 想做到的事 | 从易到难的拆解 |
|---|---|
| 整理房间 | 把桌上的杯子拿到厨房 → 扔掉明显垃圾 → 衣服放进筐 → 擦桌面 → 铺床 |
| 恢复运动 | 穿好运动鞋在门口站2分钟 → 楼下走5分钟 → 走10分钟 → 快走20分钟 |
| 重新联系朋友 | 发一条“最近怎么样” → 回复对方的消息 → 约一次20分钟的咖啡 |

几条原则：

- **宁可小，不要大。**第一步最好是“五分钟能完成、几乎不可能失败”的动作。
- **完成比完美重要。**做到第三步就停下，也算完成，不扣分。
- **一次只加一档。**这周走5分钟，下周再走10分钟，别跳级。
- **做不到就退一档，不是放弃。**退档是调整参数，不是失败。

## 第三步：价值清单，给自己一个不只是“应该”的理由

只靠“医生说要多活动”，很难坚持。行为激活会用“价值”来提供理由。这里的价值指的是：**你想成为什么样的人、你看重什么**，不是必须达成的目标，也不是此刻的心情。

| 领域 | 可以问自己的一句话 |
|---|---|
| 关系 | 我希望在家人、朋友眼里是个什么样的人 |
| 工作与学习 | 我看重的是能力、稳定、创造，还是帮助别人 |
| 身体健康 | 我希望怎么对待自己的身体 |
| 兴趣与意义 | 什么事让我觉得活着不只是熬过去 |
| 自我照顾 | 我允许自己怎么被照顾 |

做法很简单：从上面选3个你在意的领域，各写一句“我在这个方向上想成为什么样的人”，再各写一个**这周能做的最小动作**。比如“我想做一个还愿意和朋友联系的人”，对应的动作是“周三给老同学发一条消息”。

价值清单的作用，是在“想不想”这个信号坏掉的时候，提供一个替代的决策依据。心情说“不想动”，价值说“这件事对我重要，先做五分钟”。

要小心的是，别把价值变成新的考核表。“我想做个好妈妈”很容易滑成“我必须每天陪孩子读书两小时”，然后又变成一次失败。**价值是方向，不是 KPI。**

## 第四步：奖励与复盘，让大脑重新学会“这件事值得”

行为激活要对抗的是一个已经学会“做什么都没用”的系统，所以“做完之后的反馈”很关键。

- **即时奖励**：完成之后给自己一点具体的小回报——一杯喜欢的饮料、十分钟音乐、在记录本上打一个勾。奖励要小、要当下、不要太依赖别人配合。
- **记“做到了”清单**：每天写下完成了什么，哪怕只是“洗了澡”“回了消息”。不要记“没做到”清单。
- **每周复盘15分钟**：这周做了哪些安排、愉快感和掌控感各几分、下周加什么减什么。可以自己复盘，也可以带去和治疗师一起看。

复盘的目的不是审判，是调参。分数低不代表你不行，可能只是这件事不适合现在的你，或者安排得太满。

**一页可以照着做的清单：**

- [ ] 连续记录3天活动，只记事实，不打分评价自己
- [ ] 圈出愉快感或掌控感最高的两件事
- [ ] 选一个在意的领域，写一句“我想成为什么样的人”
- [ ] 把这个方向拆成三步，第一步控制在5分钟内
- [ ] 本周只做第一步，写清具体哪天、几点、和谁
- [ ] 完成后打勾，给自己一个具体的小奖励
- [ ] 周末15分钟复盘，决定下周加一档还是减一档

## 行为激活和 CBT 是什么关系，它适合谁

行为激活本来就是 CBT 的一个组成部分——CBT 里的“活动安排”就是它。后来研究者发现，单把这一部分拿出来做，效果也不错，而且更简单、更容易培训，于是它成了独立疗法。

| 维度 | 行为激活 | 完整 CBT |
|---|---|---|
| 主要改动的地方 | 日常行为与生活结构 | 行为加想法、信念 |
| 门槛 | 较低，不需要说清想法 | 需要一定反思和书写能力 |
| 典型疗程 | 常10–20次 | 常12–20次 |
| 形式 | 个别、团体、电话、自助都可行 | 多为个别，也有团体 |

两者不是“低配”和“高配”。对精力很差、注意力维持不了、说不出具体想法的人，行为激活往往比一上来就做思维记录更现实；对反复被某种信念困住的人，完整 CBT 更对症。很多人是先做行为激活，状态回升后再加认知部分。

## 常见困难与容易踩的坑

**“我没心情做。”** 这正是行为激活要处理的核心。心情是行动的结果之一，不是行动的前提。先从五分钟开始，不用等到想动。

**“做了也不开心。”** 这很常见，尤其是前两三周。此时把评价标准从“开不开心”换成“有没有完成”。愉快感的恢复通常比掌控感慢。

**“计划排太满，又失败了。”** 失败几乎总是因为排太多。把计划砍一半，砍到你觉得“这也太少了”为止。

**“是家人逼我做的。”** 别人安排的日程很难坚持。哪怕动作一样，也要由你自己选、自己定时间。家属更适合做提醒和陪伴，不适合做监工。

**“这是不是自欺欺人？”** 不是。自欺是假装问题不存在；行为激活是承认情绪还在，同时不让生活彻底停摆。

**“做完更累了。”** 先降强度，再看有没有躯体原因——贫血、甲状腺问题、睡眠呼吸暂停、药物副作用都可能表现为极度乏力，值得和医生讨论。

## 什么时候需要联系医生 / 寻求额外帮助

> **出现以下情况，不要只靠自己调整活动量**
>
> - 出现自杀念头、计划或准备行为，或已经自伤：不要独处，立即呼叫 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 严重到连续多日起不了床、拒绝进食进水，需要尽快精神科评估，必要时住院。
> - 稍微活动就胸痛、心悸明显、晕厥或呼吸困难，立即急诊，不要当成“缺乏锻炼”。
> - 出现话多、睡得很少却不困、活动量突然暴增且停不下来，警惕转躁，尽快联系精神科医生。
> - 规律练习4–6周，活动量和情绪都毫无变化，需要复评诊断、共病与用药方案。
