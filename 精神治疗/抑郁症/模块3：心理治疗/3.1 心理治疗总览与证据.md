# 3.1 心理治疗总览与证据

> 确诊抑郁症之后，人常会听到两种建议：一种是“赶紧吃药”，一种是“去做心理治疗”。真到要选的时候，问题往往更具体：CBT、行为激活、正念、人际治疗各指什么？一周去几次、要做多久、怎么判断自己做的是不是规范治疗？这一页把主流心理治疗的方法、适用人群、频率疗程和与药物的关系讲清楚，读完你可以带着具体问题去和医生讨论。

## 心理治疗不是“聊聊天”

先把一个误会拆掉。心理治疗确实靠说话进行，但“靠说话”不等于“聊天”。区别不在说得多不多，而在于有没有一套可以重复的结构。

| 维度 | 朋友开导 | 规范的心理治疗 |
|---|---|---|
| 目标 | 让你当下舒服一点 | 针对明确问题设定可评估的目标 |
| 方法 | 凭经验、善意和常识 | 有理论模型和操作步骤，治疗师受过系统训练 |
| 结构 | 随时开始、随时结束 | 固定时间、时长、地点，每次约45–60分钟 |
| 记录 | 一般不记录 | 会做评估、写个案概念化、定期复评 |

规范治疗的第一步是评估：现在最困扰的是什么、持续多久、以前治过没有、有没有自杀风险、睡眠和进食如何。评估之后，治疗师会和你一起形成“个案概念化”。用大白话说，就是**用一套解释把你眼下的困难串起来，再据此决定先动哪里**。它是一个可以修改的工作假设，不是给你贴标签。

所以，如果你坐在咨询室里，对方主要是在听、偶尔给点建议、从不布置练习、也说不清接下来几次要做什么，那很可能不是规范的心理治疗。这不代表对方是坏人，只代表它大概帮不到你。

## 七种主流方法，分别适合谁

下面这张表是全景。每一行在后面的小节里展开。

| 方法 | 核心在做什么 | 更适合谁 | 常见形式 |
|---|---|---|---|
| 认知行为治疗（CBT） | 找出想法、行为里能改的环节，用记录和实验去检验 | 消极想法多、回避、拖延明显的人 | 个别，每周1次，常12–20次 |
| 行为激活（BA） | 不等情绪好转，先按计划恢复活动 | 快感缺失、乏力、退缩、整天躺着的人 | 个别或团体，常10–20次 |
| 人际心理治疗（IPT） | 聚焦四类人际问题，改善沟通与角色适应 | 抑郁与丧亲、换岗、冲突、孤立明显相关的人 | 个别，经典设计12–16次 |
| 正念认知疗法（MBCT） | 训练“注意到想法而不被卷走” | 已缓解、反复发作、想预防复发的人 | 团体8周课程 |
| 问题解决治疗（PST） | 把压倒性的问题拆成可执行的步骤 | 现实压力大、老年人、基层就诊者 | 个别，常6–12次 |
| 支持性心理治疗 | 稳住关系与情绪，协助现实应对 | 急性期、刚出院、合并躯体疾病的人 | 个别，频率弹性大 |
| 短程动力治疗（STPP） | 看重复的关系模式与回避的情绪 | 问题反复出现、想理解“为什么总这样”的人 | 个别，十几次到几十次 |

### 认知与行为取向：CBT、行为激活、问题解决治疗

CBT 是研究积累最多的一种。它假设：让人难受的往往不只是事件本身，还有事件发生时脑子里闪过的解释。CBT 不要求你“想开”，而是教你把想法当成假设去检验——支持它的证据是什么，反对它的证据是什么，有没有另一种更贴近事实的解释。【指南】

行为激活更直接：抑郁时人会退缩，退缩让生活里的正反馈变少，情绪更低，于是更退缩。行为激活从“安排活动”入手打断这个循环。对说不出具体想法、但明显没劲和回避的人，它常常比追问认知更管用。【指南】

问题解决治疗把“我完蛋了”这种笼统感受，转成“这周有三件事，先处理哪件、第一步做什么”。它不追问童年，也不深挖认知，适合现实压力集中、时间精力有限的人。【指南】

### 人际与动力取向：IPT 与短程动力治疗

IPT 的假设是：抑郁常发生在人际关系变化之后或之中——丧亲、生育、换工作、退休、离婚、查出重病。它把工作焦点收在四个领域之一（悲伤、角色转换、人际冲突、社交困难），用沟通分析和角色扮演练新的应对方式。【指南】

短程动力治疗关注重复出现的关系模式和被回避的情绪，比 CBT 更在意“你为什么会变成这样”，疗程也更长一些。NICE 把短程动力治疗列为较轻抑郁可选的心理治疗之一。【指南】

### 正念与支持性：MBCT 与支持性心理治疗

MBCT 不是放松训练。它练的是在情绪刚开始下滑时，认出“我又在反刍了”，然后把注意力从想法里带出来。它最主要的证据在**预防复发**，尤其是三次以上发作、目前已经缓解的人；急性期症状很重时，它通常不是首选。【指南】

支持性心理治疗听起来最“普通”，但对急性期、刚出院、合并慢性病或认知功能下降的人很重要。它做的是稳住关系、减少混乱、协助现实问题，而不是挖根源。【临床经验】

## 频率、疗程与见效时间

- **频率**：多数个别治疗每周1次。稳定比密集更重要——每周固定出现，本身就是治疗的一部分。
- **时长**：每次约45–60分钟。首次会谈通常更长，用于评估。
- **疗程**：8–20次是常见区间。指南描述的高强度 CBT 常是16–20次、历时3–4个月；12–20次只是常见范围，不是标准答案。【指南】
- **团体**：MBCT 是固定的8周课程，不是“上到不想上为止”。
- **巩固**：症状缓解后，可以把频率从每周一次拉成两周一次、一月一次，用来巩固技能、预防复发。

关于见效时间，可以有一个大致预期：4–6次之后，通常能看到一些具体变化——睡眠规律一点、出门次数多一点、回避少了、能把一件事说完。【临床经验】但“心情整体好起来”往往更晚，10次以后才明显改善也很常见。如果8–12次后目标毫无移动，值得和治疗师一起复评：方法是否匹配、诊断是否需要重新看、有没有共病没被处理。

也要说另一面：心理治疗不是次数越多越好。没有目标、没有复评的长期谈话，容易变成昂贵的陪伴。

## 轻度可单用，中重度常联合药物

NICE 的分层用的是“较轻”和“较重”，不完全等于我们平时说的轻、中、重度，但大方向可以借用：

| 情况 | 心理治疗的位置 | 与药物的关系 |
|---|---|---|
| 较轻 | 可单独作为一线治疗 | 可以先不用药，4–8周复评，无改善再讨论 |
| 中度 | 一线选择之一，也可与药物同时开始 | 联合通常优于单用其中一种 |
| 较重 | 常作为联合治疗的一部分 | 药物通常是基础，心理治疗并行 |
| 伴精神病性症状或高风险 | 不是主力 | 以药物和必要的物理治疗为主，稳定后再加心理治疗 |

联合治疗的研究结论比较一致：对中重度抑郁，药物加心理治疗的效果通常好于单用其中一种。【研究】【指南】原因不难理解——药物较快地减轻症状，让人有力气出门、做事、练习；心理治疗改善应对方式、减少回避、降低复发风险。两者不是替代关系。

两个常见错误。一个是“我要做心理治疗，所以把药停了”：减药停药要在医生指导下进行，突然停可能带来撤药反应和复发风险。另一个是“我在吃药，心理治疗没必要”：对反复发作、人际模式或思维方式明显卡住的人，心理治疗带来的复发预防是药物替代不了的。

## 怎么判断自己有没有在做“真正的心理治疗”

下面这份清单可以逐条对照。符合得越多，越可能是在做规范治疗。

- [ ] 开始前做过评估：问过症状、病程、既往治疗、风险
- [ ] 和你一起定过目标，而且写下来过
- [ ] 每次会谈有大致议程，不是想到哪说到哪
- [ ] 有家庭作业或练习，下次会回顾
- [ ] 治疗师解释过方法原理，你能说出“我们在练什么”
- [ ] 时间、时长、地点、费用固定，且事先说清
- [ ] 有保密说明，也说明了保密例外（自伤、伤人风险）
- [ ] 每隔一段时间复评进展（量表或目标回顾）
- [ ] 你可以直接说“我觉得这没用”，而不会被批评
- [ ] 不会要求你停药，也不会贬低你的医生
- [ ] 没有“保证治好”“包不复发”的承诺
- [ ] 边界清楚：没有私下频繁联系、借钱、送礼、暧昧

如果前六条大多不符合，值得考虑换一种形式或换一个人，不必先怪自己“不够配合”。

## 常见问题与容易踩的坑

**“心理治疗就是劝我想开？”** 不是。劝是单向的，治疗是双向的，而且治疗会要求你做事：记录、练习、实验、复盘。

**“做心理治疗就不用吃药了吧？”** 较轻和部分中度的人可能可以；中重度常常需要联合。是否用药由医生评估，“我在做心理治疗”不是自行停药的理由。

**“做一两次就该有效果？”** 前一两次多半是评估和建立关系。能感到“被听懂”已经有价值，但症状改善一般要看几周。

**“越贵的治疗师越好？”** 价格和效果没有稳定关系。受训背景、方法是否匹配、关系是否可信，比价格重要。

**“一直做下去总没坏处？”** 没有目标、没有复评的长期治疗，可能让人停在“被陪伴”里，也可能掩盖需要调整的诊断或用药问题。

**家属常犯的错**：替患者约好时间再通知、追问每次谈了什么、把治疗当成“修理”患者的工具。更有效的做法是负责接送和提醒、不追问内容，需要时自己也参加家庭会谈。

## 什么时候需要联系医生 / 寻求额外帮助

> **出现以下情况，不要等到下次会谈**
>
> - 出现自杀念头、计划或准备行为，或已经自伤：不要独处，立即呼叫 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 治疗期间情绪明显恶化，连续多日几乎不进食、不睡，或无法照顾自己。
> - 出现话多、睡得很少却不困、冲动消费、行为失控等转躁迹象。
> - 治疗师出现越界行为：私下约会、借钱、要求你对治疗绝对保密、贬低你的医生、劝你停药。
> - 规范治疗8–12次后目标毫无移动，或你开始怀疑“是不是我没救”。
> - 创伤相关治疗中出现明显加重的闪回、解离或自伤冲动。
