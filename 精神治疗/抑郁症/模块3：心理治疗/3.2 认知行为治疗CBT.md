# 3.2 认知行为治疗CBT

> 很多人听说过 CBT，也大概知道它“跟想法有关”，但真做起来是什么样、一次会谈里发生什么、为什么总被布置作业，并不清楚。这一页讲认知模型怎么用、思维记录和行为实验具体怎么写、CBT 不是什么、做多久能见效，以及最常见的两个卡点：作业没做、想法找不到。读完你可以判断自己正在做的 CBT 是不是“真的在练”。

## 认知模型：事情不直接决定情绪

CBT 的起点是一句很朴素的话：**让你难受的，往往不是发生的事，而是你对这件事的解释。**用一条链子表示：

> 情境 → 想法 → 情绪 → 行为 →（结果反过来又强化了想法）

同一个情境，两种解释，会走出完全不同的路。给同事发消息，对方半天没回：

| 环节 | 解释 A | 解释 B |
|---|---|---|
| 想法 | “他在忙，等下会回” | “他是不是讨厌我” |
| 情绪 | 平静，有点着急 | 失落、焦虑、生气 |
| 行为 | 继续做自己的事 | 反复看手机，不敢再发，开始回避他 |
| 结果 | 第二天正常合作 | 对方觉得你冷淡，关系真的变远 |

解释 B 不是“事实”，是一个假设；但它带来的行为，最后真把关系推远了。这就是 CBT 关心的循环。

CBT 里常把想法分三层，从浅到深：

- **自动思维**：事情发生的一瞬间，脑子里自动蹦出来的那句话。“我搞砸了”“他们一定觉得我很蠢”。
- **中间信念**：规则和假设。“如果我出错，就会被看不起”“不能麻烦别人”。
- **核心信念**：关于自己、他人、世界的总判断。“我不够好”“别人靠不住”。

治疗通常从自动思维入手，因为最好抓；信念层面要等工作到中后段、有了工具再碰。

这里必须澄清一件事，否则很容易变成自责：**CBT 不认为抑郁是你“想错了”想出来的。**抑郁有生物学、躯体、社会多重原因，认知模型解释的是另一件事——抑郁一旦发生，那些消极解释会参与把低落**维持**下去。改变想法，是为了松开这个维持机制，不是追责。

## 一次会谈里发生什么

一次典型的 CBT 会谈约45–50分钟，结构相当固定：

1. **开头5分钟**：简短心境检查（这周0–10分打几分）、睡眠、用药、有没有风险。
2. **回顾作业**：上次布置的记录或练习，做了没有、发现了什么。这一段很重要，不是走过场。
3. **设定议程**：一起定1–2个议题。你也有发言权，可以要求“今天我想谈别的”。
4. **中段25–30分钟**：处理一个具体议题。可能是一条思维记录、一个行为实验的设计、一个决定的两难。
5. **结尾10分钟**：总结今天学到了什么、布置新作业、问你对这次会谈的反馈。

整个疗程大致分三段：

| 阶段 | 大致次数 | 主要工作 |
|---|---|---|
| 评估与目标 | 1–2次 | 评估、风险、讲清模型、列出目标清单 |
| 技能训练 | 3–12次 | 思维记录、行为实验、活动安排、解决问题 |
| 巩固与预防 | 最后3–4次 | 总结哪几件工具对你最有用，写复发应对卡，拉长间隔 |

你会发现它不像“聊到哪算哪”。但结构不等于僵化：如果你这周出了急事，议程可以改；如果你觉得某个练习没必要，也可以说出来，这本身就是治疗的一部分。

## 工具箱：思维记录、认知歪曲、行为实验、家庭作业

### 思维记录：把脑子里那句话抓出来

思维记录是 CBT 最核心的纸面工具，一张表五到七栏。第一次写通常要20分钟，写熟了5分钟。

| 栏目 | 写什么 | 例子 |
|---|---|---|
| 情境 | 何时、何地、和谁、发生了什么（只写事实） | 周五会上，我的方案被否了 |
| 情绪 | 给情绪起名，并打分0–100 | 羞耻80，焦虑60 |
| 自动思维 | 当时脑子里蹦出的原话，越原话越好 | “我根本不适合这份工作” |
| 证据 | 支持它的、反对它的，分开列 | 反对：上个月方案通过了两次 |
| 替代想法 | 更贴近事实的说法，不必“很积极” | “这次方案被否了，不代表我不适合” |
| 结果 | 再给情绪打分，接下来做什么 | 羞耻降到40，去问具体哪里不合适 |

几个要点。第一，在情绪最强烈的时刻写，事后再补容易失真。第二，一次只写一条，别想着一口气处理五个。第三，替代想法不需要“很阳光”，只需要**比原来更准确**；从“我是废物”到“我这次没做好”，已经是进步。

### 认知歪曲：一份“可能漏看了什么”的清单

认知歪曲指的是几种常见的、系统性偏离事实的思维方式。列出名字不是为了给想法判罪，而是提醒自己：这里可能还有别的信息没看到。

| 名称 | 长什么样 | 例子 |
|---|---|---|
| 全或无 | 只有满分和零分 | “没做到最好就是失败” |
| 以偏概全 | 一次经历推及全部 | “他拒绝我一次，我这人没人会要” |
| 心理过滤 | 只盯负面细节 | 十句表扬里只记住那一句批评 |
| 读心术 | 认定别人怎么想 | “他没笑，肯定是对我有意见” |
| 算命 | 把预测当结论 | “面试肯定过不了，不用去了” |
| 灾难化 | 一路推到最坏结局 | “出错就会被开除，然后全完了” |
| 情绪化推理 | 把感觉当证据 | “我觉得没希望，所以真的没希望” |
| 应该式 | 用“必须”要求自己 | “我必须一直坚强，不能让人看见我难受” |

要提醒的是：**拿这张表骂自己“我又歪曲了”，是反效果。**它的用途是好奇，不是考核。

### 行为实验：去收集数据，而不是说服自己

思维记录是“在纸上检验”，行为实验是“在生活里检验”。它的关键区别是：不靠辩论，靠结果。

步骤大致是：

1. 写下一条具体、可检验的预测：“如果我拒绝同事的临时请求，他会觉得我不合作。”
2. 给相信程度打分（0–100）。
3. 设计一个**小、安全、本周能做**的实验，不要一次赌上工作和关系。
4. 记录真实发生了什么，包括对方的表情、原话、后续。
5. 重新给相信程度打分。
6. 写一句结论，哪怕只是“从90降到70”，也算收获。

| 预测 | 实验 | 可能学到什么 |
|---|---|---|
| “我说累，朋友就会觉得我敷衍” | 对一次邀约说“这周太累，下周约” | 对方通常只是回“好”，关系没有断 |
| “一停下来就会崩” | 周末半天不安排任何事 | 焦虑会升高，但会过去，人没崩 |

### 家庭作业：它是治疗的一半

CBT 的疗效很大程度来自会谈之间那六天。常见作业有：思维记录、活动安排、行为实验、渐进式暴露、阅读材料。

好的作业通常符合三个条件：具体、小（5–10分钟能完成）、讲得清为什么做，而且布置前和你商量过。

## CBT 不是什么

- **不是“正能量洗脑”**：不要求你每天对镜子说我很好，也不否认现实里确实有难处。
- **不是“你的病是你想出来的”**：抑郁有生物学基础，CBT 处理的是维持它的那部分。
- **不是只讲道理**：没有记录、没有练习、没有复盘，就只是上了几节心理学课。
- **不是“治标不治本”**：对复发预防有明确证据支持。【指南】
- **不是几次就能“根治”**：它教的是可带走的技能，不是一次性清除。
- **不是药物的替代品**：中重度抑郁常常需要药物与 CBT 并行。【指南】

## 做多久能见效

12–20次是常见范围，但**这只是常见范围，不是标准答案**。指南描述的高强度 CBT 通常是16–20次、历时3–4个月。【指南】

一个可以参考的时间线：

- **4–6次**：能认出自动思维，开始会写记录，知道自己在哪些时刻最容易下滑。
- **6–12次**：能检验想法，活动量上升，回避减少，遇到事有第二反应。
- **12–20次**：巩固技能，处理信念层面，做复发预防计划。

判断有没有效，别只看“我还难不难受”。更可靠的三个指标是：**功能**（能不能上班、出门、见人）、**趋势**（量表分数几周内的走向）、**技能**（遇到低落时你手上有没有工具）。

也有人8次就够了（问题比较局限），有人需要30次以上（慢性化、共病、人格层面的议题）。这不说明谁更“严重”，只说明问题的大小不同。

如果你正准备开始 CBT，可以先用这份清单问问治疗师：

- [ ] 我们打算先处理哪个目标，大概几次复评一次
- [ ] 每次会不会布置作业，作业占多少时间
- [ ] 如果某次没做作业，我们怎么处理
- [ ] 如果做了8次没变化，你会怎么调整
- [ ] 出现自杀念头时，我该按什么顺序联系谁

## 卡住的常见情况：作业没做、想法找不到

### 作业没做

这是最常见的，也非常正常。常见原因有几类：作业太大（“每天写三条”对已经没力气的人就是负担）、太模糊（“觉察一下自己的想法”无从下手）、忘了、怕写了更难受、觉得没用。

对应处理也不复杂：把作业缩到5分钟能完成；会谈里当场写半条，让治疗师看着你写；用手机闹钟或和家属互相提醒；把“没做”当成信息带回会谈，而不是当成失败藏起来。**一个能坚持的小作业，胜过一个完不成的完美计划。**

### 想法找不到

很多人坐下准备记录，发现脑子一片空白，只记得“很难受”。这通常不是你不会，而是缺一个入口。可以试这些：

- **从身体进**：当时胸口是什么感觉、肩膀是不是绷着，再问“这个感觉配的是哪句话”。
- **从行为倒推**：我当时做了什么、没做什么？逃避的背后通常有一句判断。
- **回放具体镜头**：不要想“这周”，只想“周三下午三点他说那句话的那十秒”。
- **用第三人称**：如果是朋友遇到这件事，你觉得他心里会想什么？
- **往下问三层**：这件事对你意味着什么？那又意味着什么？最怕的到底是什么？

还有两种常见的卡点。一种是“我知道了但做不到”——知道和熟练是两件事，CBT 靠重复，不靠顿悟。另一种是“越写越难受”——说明节奏太快或碰到敏感区域，要告诉治疗师，必要时放慢或换方式；如果有创伤经历，更要提前说明。

## 什么时候需要联系医生 / 寻求额外帮助

> **出现以下情况，不要等到下次会谈**
>
> - 出现自杀念头、计划或准备行为，或已经自伤：不要独处，立即呼叫 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 做行为实验或暴露练习时情绪失控、出现自伤冲动，先停下，联系治疗师和医生。
> - 情绪明显恶化，连续多日几乎不睡、不吃，或无法照顾自己。
> - 出现话多、睡得很少却不困、冲动消费等转躁迹象，尽快联系精神科医生。
> - 写记录时反复出现强烈闪回、解离、身体麻木，暂停练习并告知治疗师。
> - 规范练习8–12次后功能毫无改善，需要重新评估诊断、共病和方案。
