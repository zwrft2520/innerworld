# B 参考文献与指南版本

这一页列的是本资料库主要依据的指南、法规和公共来源，写明它们各自的用途、发布或更新年份，以及证据是怎么分级的。它适合想追原文的人、想判断“这条说法出自哪里”的人，也适合需要向单位、学校或保险公司说明依据的人。只列真实存在、可以核对到出处的来源；不确定的宁可不列。

## 这份清单怎么用

三种用法：

- **查依据。** 某篇正文写了“指南推荐”，可以到这里找对应来源，再去看原文的那一节。
- **判断新旧。** 对照发布和更新年份，判断你看到的信息是不是已经过期。
- **准备沟通材料。** 需要向单位、学校、保险公司说明治疗合理性时，指南名称和年份比“网上说”有分量。

要说明的是：本资料库是科普，不是指南的替代品。指南给出的是人群层面的推荐，具体到个人还要看病情、共病、用药史和偏好。

这张表里有一条容易被忽略的区别：**指南、法律、说明书、热线，是四种不同性质的东西**。指南说“通常怎么治”，法律规定“什么能做、什么不能做”，说明书是药品的法定文本，热线是服务通道。它们不能互相替代，也不该混着引用。

## 三份最常用的指南，各自适合查什么

**NICE NG222** 的长处是路径清楚：轻度、中度、重度分别怎么起步，心理治疗放在什么位置，什么情况下换药或加增效，难治性抑郁往哪走。它的推荐用词有严格层次，“提供”“考虑”“不要提供”之间不是修辞差别，而是推荐强度差别。想看“标准流程长什么样”，从这份入手最快。

**CANMAT 2023** 的长处是药物细节和序贯策略：第一轮、第二轮、第三轮分别有哪些选择，换药和增效怎么权衡，联合用药的证据到什么程度。它的表格密度高，适合带着具体问题去查，不适合从头读到尾。

**《中国抑郁障碍防治指南（第二版）》** 的长处是本土情境：国内可及的药物、医保与分级诊疗的现实、常见的中西药联用问题。它的出版年份较早（2015），读的时候要留意：部分药物信息和证据在那之后已经更新，遇到具体用药问题仍以当前说明书和面诊医生为准。

## 证据等级怎么读

不同指南用的符号不一样，粗略可以这样对照：

| 大致级别 | 通常指什么 | 举例 |
|---|---|---|
| 高（如 1 级 / A） | 多项随机对照试验或 meta 分析，结果一致 | 某种心理治疗对轻中度抑郁有效 |
| 中（如 2 级 / B） | 单项随机对照试验，或结果不完全一致 | 某类药在特定人群中的增效作用 |
| 低（如 3 级 / C） | 非随机对照、队列研究、个案系列 | 罕见副作用的信号 |
| 很低（如 4 级 / D） | 专家意见、病例报告、机制推测 | “可能通过某通路起效” |

读这张表要带着四个提醒：

**第一，证据等级不等于推荐强度。** 一条建议可能证据等级不高，但因为风险小、成本低、患者看重，仍然被“可以考虑”。反过来，证据等级高的干预，也可能因为副作用、费用或可及性，不被列为一线。

**第二，等级高不等于对你有效。** 研究纳入的是“平均患者”，不是你。孕产妇、老年人、青少年、肝肾功能不全的人，常常被试验排除在外，套用结论要格外小心。

**第三，等级低不等于无效。** 罕见副作用、特殊人群的经验，很难做大样本试验，但不能因此忽略。

**第四，还要看结局指标和利益关系。** 量表降两分和“能回去上班”是两回事；药企资助的研究可以用，但要知道利益在哪。

本资料库正文里的【指南】【研究】【临床经验】【待验证】【个人体验】五个标签，是上面这套分级的**简化版**，方便普通读者快速判断分量，不等于指南的正式分级。

## 怎么判断一条信息是不是过时了

- [ ] 它引用的指南是哪一年的？超过五年的药物治疗建议，要重新核对。
- [ ] 它说的药，现在还在用吗？有没有撤市、新增禁忌或适应证变化？
- [ ] 热线号码、医保政策、病假规定，是不是近两年内的信息？
- [ ] 它有没有标注“截至某年某月”？没有日期的科普，默认按过期处理。
- [ ] 它引用的研究，后来有没有更大规模的试验得出相反结论？
- [ ] 它说的人群和你一样吗？青少年、孕产期、老年的结论常常不能通用。
- [ ] 它是不是把“指南推荐”写成了“必须”，或把“可以考虑”写成了“首选”？

最后一条尤其常见：把有条件推荐说成绝对推荐，是最容易误导人的改写方式。

## 引用这份资料时请注意

- 引用时请注明“《抑郁症治疗资料库》V1.0，2026-10”，并附上具体篇目名称。
- 不要摘取单句当作医嘱转发。一句话离开上下文，很容易变成另一个意思。
- 不要修改数字、年份和来源名称；不确定的地方标注“待核”，不要猜。
- 涉及具体个人的用药，请引用面诊医生的意见，而不是本资料库。
