# 2.2 常见药物分类与代表药物

这一页把常用的抗抑郁药按“作用机制”分成几组，告诉你每组大致是什么脾气、常见的不舒服在哪、医生为什么会在这组里挑一个。它不教你选药，也不写剂量，只帮你听懂处方上的名字。看完之后，你至少能分清“我吃的是哪一类”，以及复诊时该重点说哪些感受。

## 先理解“分类”这件事：按什么分，为什么要分

抗抑郁药的分类依据是**它主要作用于哪种递质、通过什么方式起作用**。同样是提高5-羟色胺，有的药阻止它被回收（SSRI），有的药同时影响去甲肾上腺素（SNRI），有的药干脆绕开它去作用别的受体（安非他酮、米氮平）。机制不同，副作用谱就不同，药物相互作用也不同。

分类是地图，不是排行榜。同一类里的药，疗效大体接近，但副作用、代谢途径、停药难度可以差很多。比如同属 SSRI，氟西汀半衰期（药物在体内浓度减半所需的时间）很长，停药时比较“平缓”；帕罗西汀半衰期短，撤药反应更明显；舍曲林在孕期和哺乳期的数据相对多一些。这些差别才是医生真正在权衡的东西。【指南】

一句话：**类别决定“大致方向”，具体药物决定“你个人能不能受得了”。**

## 九类常用药物一览

下表按机制分组，只列常见代表药和特点，不涉及剂量与适应证细节。国内不同医院的可及性差异很大，表里没有的药不代表不能用，表里有的药也不代表适合你。

| 类别 | 代表药物（举例） | 主要特点 | 常见不适 |
|---|---|---|---|
| SSRI（选择性5-羟色胺再摄取抑制剂） | 舍曲林、艾司西酞普兰、西酞普兰、氟西汀、帕罗西汀、氟伏沙明 | 一线用药，疗效稳、安全性好、过量风险相对低 | 恶心、腹泻、头痛、失眠或嗜睡、出汗、性功能受影响 |
| SNRI（5-羟色胺和去甲肾上腺素再摄取抑制剂） | 文拉法辛、度洛西汀 | 兼顾精力与疼痛，对伴随躯体疼痛者常被考虑 | 恶心、出汗、血压升高、口干、撤药反应较明显 |
| NaSSA（去甲肾上腺素和特异性5-羟色胺能抗抑郁药） | 米氮平 | 镇静明显，改善睡眠和食欲，常作增效或助眠 | 嗜睡、体重增加、食欲增加、水肿 |
| NDRI（去甲肾上腺素和多巴胺再摄取抑制剂） | 安非他酮 | 偏“激活”，较少影响性功能和体重 | 失眠、焦虑、口干、震颤；癫痫风险人群慎用 |
| 褪黑素能抗抑郁药 | 阿戈美拉汀 | 调节昼夜节律，助眠，较少性功能影响 | 头痛、恶心、肝功能异常（需监测） |
| SARI（5-羟色胺拮抗和再摄取抑制剂） | 曲唑酮 | 低剂量多用于助眠，抗抑郁需较高剂量 | 嗜睡、头晕、体位性低血压、口干 |
| TCA（三环类抗抑郁药） | 阿米替林、氯米帕明、多塞平 | 老药，疗效确切，但副作用和过量风险大 | 口干、便秘、尿潴留、视力模糊、心悸、嗜睡 |
| MAOI（单胺氧化酶抑制剂） | 吗氯贝胺等 | 用于难治性抑郁，饮食与药物禁忌多 | 体位性低血压、失眠、体重增加；高血压危象风险 |
| NMDA受体拮抗剂 | 艾司氯胺酮 | 起效快，用于难治性抑郁，须在医疗机构给药观察 | 解离感、血压升高、头晕、恶心；有滥用潜力 |

## 镇静、体重与性功能：最影响日常生活的几件事

患者最常抱怨的不是“疗效不够”，而是“吃了想睡”“吃了睡不着”。这跟药物对组胺、去甲肾上腺素等系统的影响有关。

- **偏镇静**：米氮平、曲唑酮、帕罗西汀、氟伏沙明，以及多数 TCA。常被安排在晚上吃，利用它的困倦感改善入睡。代价是第二天上午可能发沉、反应变慢。
- **偏激活**：安非他酮、氟西汀，以及较高剂量的文拉法辛。常安排在早上吃，避免影响夜间睡眠。代价是初期可能心慌、坐立不安、焦虑加重。
- **相对中性**：舍曲林、艾司西酞普兰、阿戈美拉汀。多数人白天不困、晚上也能睡，但个体差异仍然很大。

需要提醒的是，**“镇静”和“激活”在用药初期最明显，之后常会减弱**。如果四周后仍然白天睁不开眼，或者仍然整夜清醒，那不是“忍一忍”的问题，而是需要和医生讨论换时间、换药或调整方案。

### 体重与性功能：最容易被忍着不说的两件事

这两件事对生活质量的影响，往往比情绪症状本身更持久，也是擅自停药的头号原因。它们不是“小事”，更不是“矫情”。

| 类别 | 镇静或激活 | 体重与性功能 | 撤药反应风险 |
|---|---|---|---|
| SSRI | 中性偏激活（帕罗西汀偏镇静） | 体重多无明显变化；性功能受影响较常见 | 中等，帕罗西汀较明显 |
| SNRI | 中性偏激活 | 体重变化不一；性功能受影响较常见 | 较高，尤其文拉法辛 |
| 米氮平 | 明显镇静 | 体重增加较常见；性功能影响相对少 | 中等 |
| 安非他酮 | 偏激活 | 体重多不增加；性功能影响少 | 较低 |
| 阿戈美拉汀 | 中性偏镇静 | 体重多不增加；性功能影响少 | 较低 |
| 曲唑酮 | 明显镇静 | 体重变化不一；性功能影响相对少 | 较低 |
| TCA | 明显镇静 | 体重增加常见；性功能影响常见 | 较高 |
| MAOI | 不定 | 体重增加常见；性功能影响常见 | 较高 |
| 艾司氯胺酮 | 短暂解离 | 长期体重与性功能数据有限 | 需在医疗监护下使用 |

表里的“常见”“较少”是群体层面的概率，不是对你的预测。有人吃米氮平体重纹丝不动，也有人吃 SSRI 完全没有性功能变化。**出现问题时，解决方案不止“停药”一种**：换同类里的另一个药、换类别、调整服药时间、短期加辅助药，都是医生手里的选项。具体见[7.4 性功能体重与代谢](<../模块7：风险管理与副作用监测/7.4 性功能体重与代谢.md>)。

## 药物相互作用：哪几类需要特别小心

相互作用不是“多多益善”的反面，而是两件很实在的事：**一种药让另一种药在血里变多或变少**，以及**两种药的作用叠加**。

- **MAOI** 是相互作用最多的一类。与 SSRI、SNRI、曲马多、哌替啶、部分曲普坦类、拟交感药合用，可能引发高血压危象或血清素综合征。换用或停用 MAOI 都需要足够的间隔期，必须由医生安排。【指南】
- **TCA** 的治疗窗窄，过量可致严重心律失常。与其他延长 QT 间期的药、抗胆碱能药合用要谨慎，通常需要心电图监测。【指南】
- **SSRI 与 SNRI** 与抗凝药、抗血小板药、NSAIDs（布洛芬、阿司匹林等）合用，出血风险上升；与曲马多、曲普坦类、圣约翰草合用，血清素综合征风险上升。
- **氟西汀、帕罗西汀、氟伏沙明** 对肝药酶 CYP2D6、CYP1A2、CYP3A4 的抑制较强，会影响很多合并用药的浓度，比如某些抗心律失常药、他汀、抗精神病药。
- **阿戈美拉汀** 主要经 CYP1A2 代谢，与氟伏沙明这类强抑制剂合用属禁忌；用药期间需要查肝功能。
- **安非他酮** 降低癫痫阈值，与某些药物、饮酒、进食障碍史叠加时风险更高。

这些细节不需要你背下来。你只需要做一件事：**把正在吃的所有东西告诉医生和药师，包括中药、保健品、减肥药、助眠药。** 详细内容见[2.9 药物相互作用与禁忌](<2.9 药物相互作用与禁忌.md>)。

## 同类药也不是都一样：三个真实存在的差异

第一，**半衰期不同，停药体验不同**。氟西汀在体内停留很久，突然停用往往比较平缓；帕罗西汀、文拉法辛离开身体快，撤药反应更明显。这不是“好”与“坏”，而是“适合慢慢减”还是“必须更慢地减”。

第二，**代谢途径不同，合并用药的冲突不同**。肝功能不好、同时在吃多种药的人，医生会优先选相互作用少的那种。

第三，**特殊人群的数据量不同**。孕期、哺乳期、青少年、老年人，不同药物积累的研究证据多少不一样。医生在这些人群里选药，往往不是选“最强”的，而是选“资料最多、最有把握”的。

### 就诊时可以问的几个问题

- [ ] 我吃的是哪一类药，主要作用机制是什么？
- [ ] 这个药偏镇静还是偏激活，我应该早上吃还是晚上吃？
- [ ] 常见副作用有哪些，哪些会自己好，哪些要报告？
- [ ] 它和我现在吃的其他药、保健品有没有冲突？
- [ ] 如果效果不够，下一步通常是加量、换药还是联合？
- [ ] 需要定期查血、查心电图或查肝功能吗？
- [ ] 如果将来要停，大概怎么安排？

> **什么时候需要联系医生 / 去急诊**
> - 服药后出现高热、大汗、肌肉僵硬或抽动、意识混乱、心跳很快：**立即急诊**。
> - 皮疹迅速扩散、面唇或喉咙肿胀、呼吸困难：**立即呼叫 120**。
> - 出现解离感、幻觉、血压明显升高（尤其使用艾司氯胺酮后）：立即告知给药医护。
> - 突然异常兴奋、话多、几天不怎么睡却不困、冲动花费：尽快联系精神科医生，不要自行加药。
> - 排尿困难、严重便秘腹胀、视力突然模糊、心跳明显不规则：当天联系医生。
> - 任何自伤或自杀念头：**立即呼叫 120 或去急诊**，不要独处。

### 容易踩的坑

**“新药一定比老药好。”** 新药的优势通常在副作用和安全性，不在于疗效更强。TCA 是老药，对某些难治性抑郁仍然有效，只是需要更多监测。

**“同一类药换一个肯定也一样。”** 不一定。同类之间在代谢、半衰期、副作用上差异不小，换同类有时正好能解决耐受问题。

**“别人吃这个好，我也要吃这个。”** 疗效的个体差异很大，别人的有效方案只能作为线索，不能作为处方。

**“中药和西药一起吃没关系。”** 圣约翰草是明确有相互作用的例子，部分中成药也可能影响肝酶或出血风险。加任何东西之前，先问医生或药师。
