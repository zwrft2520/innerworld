# 2.8 停药与撤药反应

“我感觉好了，能不能停？”“停了两天头晕得厉害，是复发还是撤药？”“为什么别人停药没事，我一停就难受？”这一页讲停药时会遇到什么、哪些药更难停、怎么把撤药反应和复发分开、以及一个合格的停药计划应该包含哪些内容。

## 先明确：停药是一个决定，不是一个动作

在规范治疗里，停药和开始用药一样，需要评估、计划和随访。需要考虑的因素包括：这次发作有多重、发作过几次、缓解持续了多久、有没有残留症状、生活里有没有即将到来的高压事件、有没有复发预警信号。

这些条件合适，医生会和你一起制定减量计划；条件不合适，继续维持治疗往往是更划算的选择。**停药不是“治疗结束”的仪式，而是治疗阶段之间的一次转换。**

## 撤药反应长什么样

撤药反应是身体对“药物浓度突然下降”的适应过程，通常出现在停药或减量后的几天内。常见表现可以分成几组：

- **神经和感觉**：头晕、眩晕、走路发飘、手脚发麻、像“脑子里有电流闪过”的触电感、耳鸣。
- **胃肠**：恶心、呕吐、食欲下降、腹泻。
- **全身**：乏力、流感样酸痛、出汗、心慌。
- **睡眠和情绪**：入睡困难、多梦、易怒、焦虑、情绪低落、坐立不安。
- **运动**：手抖、走路不稳、动作不协调。

这些症状的共同特点是：**来得快、以身体感觉为主、补回原来的药后很快缓解**。多数人在一两周内逐渐减轻，但有些人会拖得更久，尤其是减量过快或反复停药的人。

### 哪些药更容易出现撤药反应

| 药物 | 撤药反应风险 | 主要原因 |
|---|---|---|
| 帕罗西汀 | 较高 | 半衰期短，离开身体快 |
| 文拉法辛 | 较高 | 半衰期短，且同时影响两种递质 |
| 度洛西汀 | 中等偏高 | 半衰期较短 |
| 舍曲林、艾司西酞普兰 | 中等 | 个体差异大 |
| 氟西汀 | 较低 | 半衰期长，自行“缓慢减量” |
| 米氮平、曲唑酮 | 中等 | 镇静作用反跳、睡眠反弹 |
| TCA、MAOI | 较高 | 长期使用后受体适应明显 |

表里的“半衰期”，指药物在体内浓度减少一半所需的时间；越短，停药后浓度掉得越快。这张表只能作为参考。**同样的药，有人停得毫无感觉，有人反应强烈**，和用药时间、剂量、减量速度、个人代谢都有关。氟西汀也不是“绝对安全”，只是它自己减得慢。

需要特别说明：撤药反应不是“成瘾”。它不具备成瘾的核心特征（渴求、失控、越用越多），而是身体对药物存在的适应。这个区别很重要，因为它决定了应对方式：不是“戒断”，而是“减速”。

## 撤药反应和复发怎么区分

这是停药期最实际的问题。两者可能同时发生，也可能互相掩盖。可以从四个角度分辨：

| 维度 | 撤药反应 | 复发 |
|---|---|---|
| 出现时间 | 停药或减量后数天内 | 数周内逐渐出现 |
| 主要表现 | 头晕、电击感、恶心、流感样、出汗 | 情绪低落、兴趣丧失、早醒、自责、无力 |
| 对补回药物的反应 | 几小时到一两天内明显缓解 | 需要重新治疗一段时间才缓解 |
| 持续时间 | 通常一两周，逐渐减轻 | 持续加重，不会自行消退 |

一个实用的判断：**如果你补回一点原来的药，症状在一天内明显好转，更像撤药反应；如果补回后仍持续低落、兴趣全无，更像复发。**

但不要自己做这个实验。补回药物、调整剂量都要问医生，因为“补一点看看”可能打乱整个计划。

## 减量原则：慢，而且越到后面越慢

抗抑郁药的减量不是“每周减一半”那么简单。药物在体内的作用与受体占用率不是直线关系：**在低剂量区间，同样的减量幅度，带来的生理变化可能更大。** 所以很多医生会采用“先快后慢”的方式：前期可以稍快，越接近停药，每一步越小、间隔越长。

具体的节奏因人而异，取决于：

- 你吃的是哪种药、吃了多久
- 之前有没有撤药反应史
- 减量过程中症状有没有波动
- 生活里有没有同时发生压力事件

**原则性的话可以说三句**：不要突然停；每一到两步都要观察；出现明显不适时，可以退回上一档稳定后再继续。具体的减量方案，必须由医生给。

### 突然停药的风险

**第一，撤药反应更重。** 浓度骤降，头晕、恶心、电击感集中出现，很多人因此以为“病又回来了”，慌乱中彻底停药。

**第二，复发风险上升。** 尤其是在缓解后不久、发作次数多、有残留症状的人身上。突然停掉维持治疗，等于撤掉了防止复发的支架。

**第三，可能出现罕见但严重的反应。** 突然停用某些药后，极少数人会出现明显的焦虑激越、失眠、甚至短暂的意识混乱，需要医疗处理。

**第四，你会失去判断依据。** 突然停药后症状一团乱，医生很难分清是撤药、复发还是新问题，下一步决策会变得更难。

## 一个合格的停药计划包含什么

- [ ] 停药的理由和时机：是缓解足够久，还是因为副作用、怀孕、费用
- [ ] 减量的步骤：每一步大概多久、减多少（由医生写清楚）
- [ ] 观察指标：睡眠、情绪、焦虑、身体症状，每天简单记一笔
- [ ] 复诊节点：减到哪一步回来复诊，出现问题找谁
- [ ] 撤药反应的处理预案：出现什么程度可以观察，什么程度要联系医生
- [ ] 复发的预警信号：你自己的前驱症状清单
- [ ] 恢复用药的条件：如果复发了，怎么快速回到治疗
- [ ] 非药物治疗的衔接：心理治疗、运动、睡眠、社会支持
- [ ] 家人或同伴知道计划，能帮你观察
- [ ] 生活事件的评估：接下来几个月有没有考试、搬家、换工作、丧亲

计划写得越具体，执行时越不容易慌。可以把它抄在纸上，和药盒放在一起。

### 停药之后：监测至少几个月

停药不等于结束。停药后的几个月是复发的高风险期，尤其是前半年。这段时间建议：

- 保持规律复诊，即使感觉很好
- 继续记录睡眠和情绪，关注早期信号
- 维持运动、社交、睡眠节律这些保护因素
- 知道复发的预警信号，并且知道找谁
- 如果出现持续两周以上的情绪低落、兴趣丧失、早醒，尽快复诊

## 常见问题

**“感觉好了就可以停吗？”** 症状消失是巩固期的开始。通常还需要继续一段时间，具体多长取决于发作次数和严重程度。【指南】

**“隔天吃一次，是不是就算减量了？”** 不建议自行采用这种方式。隔天服药会让血药浓度大幅波动，反而更容易出现撤药反应。

**“停了以后难受，是不是说明我离不开药？”** 更可能是撤药反应，不是“上瘾”。告诉医生，调整减量速度通常能解决。

**“中药能不能替代西药来停药？”** 目前没有证据支持用中药替代规范的维持治疗。突然替换可能带来撤药反应和复发风险。

**“停药后怀孕可以吗？”** 这是需要提前规划的事，不是停药就能解决。见[6.3 孕产期抑郁](<../模块6：特殊人群与特殊时期/6.3 孕产期抑郁.md>)。

> **什么时候需要联系医生 / 去急诊**
> - 停药或减量后出现自杀念头、自伤行为：**立即呼叫 120 或去急诊**，不要独处。
> - 出现严重头晕、无法站立、反复呕吐、心慌到无法休息：当天联系医生。
> - 出现意识混乱、抽搐、高热：**立即急诊**。
> - 情绪在两周内持续下滑、早醒、兴趣丧失：尽快复诊，不要自行加回原剂量。
> - 出现兴奋、话多、睡眠骤减：当天联系精神科医生。
> - 不确定是撤药还是复发：联系开药医生，不要自己试。
