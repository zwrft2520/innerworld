# 2.9 药物相互作用与禁忌

抗抑郁药很少单独存在。你还可能吃降压药、止痛药、胃药、感冒药、中药、保健品，可能喝酒、喝咖啡、喝葡萄柚汁，可能要做手术、拔牙、做胃镜。这一页讲哪些组合需要小心、为什么、以及看医生前该交代什么。它不要求你记住所有药名，只要求你养成一个习惯：**加任何东西之前，先问一句。**

## 相互作用有四种常见机制

理解机制，比背药名有用。

**第一种：作用叠加。** 两种都提高5-羟色胺的药一起吃，血清素综合征风险上升；两种都镇静的药一起吃，白天更困；两种都延长 QT 间期（心电图上的一个时间指标，延长会增加心律失常风险）的药一起吃，心脏风险上升。

**第二种：影响代谢。** 肝脏里的 CYP450 酶负责分解大多数药物。一种药抑制了某个酶，另一种药就分解变慢、血里浓度升高；一种药诱导了某个酶，另一种药就分解变快、浓度不足。这是最隐蔽的一类，因为你看不到浓度变化，只能看到结果。

**第三种：影响吸收或排泄。** 比如改变胃内酸碱度、影响肾脏排泄，或者像圣约翰草那样影响药物的转运。

**第四种：药理对抗。** 一种药升血压，另一种药降血压；一种药让心跳快，另一种让心跳慢。

## 需要特别小心的组合

| 组合 | 可能后果 | 怎么办 |
|---|---|---|
| MAOI + SSRI/SNRI/曲马多/哌替啶 | 血清素综合征、高血压危象 | 属禁忌或需严格间隔，必须由医生安排 |
| MAOI + 含酪胺食物 | 血压骤升、剧烈头痛 | 严格忌口，具体清单由医生给 |
| SSRI/SNRI + 曲马多、曲普坦类、圣约翰草 | 血清素综合征 | 尽量避免；必须合用时密切观察 |
| SSRI/SNRI + NSAIDs、阿司匹林、抗凝药 | 消化道出血、瘀斑 | 告知医生，必要时加胃保护药 |
| 多种延长 QT 的药物合用 | 心律失常、晕厥 | 查心电图、纠正低钾低镁 |
| 氟西汀/帕罗西汀 + 经 CYP2D6 代谢的药 | 后者浓度升高、副作用增加 | 由医生或药师核对 |
| 氟伏沙明 + 阿戈美拉汀 | 后者浓度大幅升高 | 属禁忌 |
| 安非他酮 + 降低癫痫阈值的药 | 癫痫风险上升 | 评估病史，避免叠加 |

这张表不是全部，只是最常见的高风险组合。**表中的“怎么办”不是让你自己执行，而是让你知道该去问谁。**

## 几类高风险药物与食物

### MAOI：禁忌最多的一类

MAOI 通过抑制单胺氧化酶，让去甲肾上腺素、5-羟色胺、多巴胺分解变慢。问题是，酪胺（一种存在于发酵食物中的氨基酸）也靠这个酶分解。酶被抑制后，吃进去的酪胺会让血压骤升。

**需要忌口的典型食物**包括：陈年奶酪、腌肉腌鱼、发酵豆制品（腐乳、豆豉、豆瓣酱）、部分酱油、啤酒酵母、某些生啤和红酒、隔夜剩菜。具体清单在不同国家、不同医院略有差异，以开药医生给的为准。

**需要避免的药物**包括：含伪麻黄碱的感冒药、含麻黄碱的中成药、曲马多、哌替啶、右美沙芬、部分曲普坦类、部分抗帕金森药，以及其他抗抑郁药。

**高血压危象的表现**：突然剧烈头痛、后颈发硬、心悸、大汗、恶心呕吐、视力模糊、胸闷。这是急症，**立即急诊**，不要等它自己过去。

MAOI 在国内的可及性有限，用得不多，但一旦用上，饮食和用药纪律是治疗的一部分，不是“注意一下就好”。

### 曲马多、哌替啶、曲普坦类：止痛药里的坑

**曲马多**是常用的中等强度止痛药，它有5-羟色胺能作用，和 SSRI、SNRI、MAOI 合用可能引发血清素综合征，也可能降低癫痫阈值。拔牙、骨科疼、术后镇痛都可能用到它，**开止痛药时要主动说你正在吃抗抑郁药**。

**哌替啶**（杜冷丁）同样有5-羟色胺能作用，与 MAOI 合用是明确禁忌。

**曲普坦类**（治疗偏头痛，如舒马曲普坦）与 SSRI/SNRI 合用，血清素综合征风险虽低但确实存在，偏头痛患者尤其要注意，因为这两类药经常同时出现在一个人的药盒里。【研究】

**右美沙芬**是很多止咳药的主成分，也有5-羟色胺能作用，容易被忽略。

### SSRI/SNRI 与止痛、抗凝：出血风险

血小板要靠5-羟色胺才能正常聚集。SSRI 和 SNRI 削弱了这个功能，单独使用时出血风险不高，但叠加以下药物时明显上升：

- **NSAIDs**：布洛芬、双氯芬酸、萘普生、塞来昔布等
- **阿司匹林**，尤其是小剂量长期服用
- **抗凝药**：华法林、利伐沙班、阿哌沙班等
- **抗血小板药**：氯吡格雷、替格瑞洛等

需要留意的不只是“会不会流血”，还有**黑便、呕血、不明原因的贫血、月经量突然增多**。如果必须合用，医生可能会加用胃黏膜保护剂，或选择对血小板影响小的止痛药。具体怎么选，问医生或药师。

### 圣约翰草：最容易被低估的“天然”产品

圣约翰草（贯叶金丝桃）是常见的抗抑郁草药，也是强效的肝药酶诱导剂。它会让很多药物分解加快、浓度下降，包括部分抗抑郁药、口服避孕药、抗凝药、抗排异药。同时它本身有5-羟色胺能作用，与 SSRI 合用可能引发血清素综合征。

**它不是“天然所以安全”。** 很多中成药、复方制剂里含有贯叶金丝桃，成分表上不一定写得很显眼。加任何中成药前，把成分表拍给药师看。

### 酒精：不是绝对禁忌，但不划算

酒精和抗抑郁药的关系，可以从三个层面看：

- **药理学**：酒精加重镇静、影响平衡和判断，和镇静类抗抑郁药（米氮平、曲唑酮、TCA）叠加时尤其明显。
- **疾病层面**：酒精本身会加重抑郁、焦虑和失眠，也会干扰治疗效果。
- **器官层面**：长期饮酒影响肝功能，而肝功能影响药物代谢。

所以多数医生会建议治疗期间尽量不喝，或者严格限量。**不要用酒来助眠**，它会让后半夜的睡眠更碎。

## CYP2D6 与 CYP3A4：两个最常被提到的酶

| 酶 | 常被它代谢的药 | 常抑制它的药或食物 | 常诱导它的药或食物 |
|---|---|---|---|
| CYP2D6 | 部分抗抑郁药、部分抗精神病药、美托洛尔、可待因、他莫昔芬 | 帕罗西汀、氟西汀、安非他酮 | 一般较少 |
| CYP3A4 | 部分抗抑郁药、部分他汀、部分钙拮抗剂、某些安眠药 | 氟伏沙明、葡萄柚汁、部分抗真菌药 | 圣约翰草、利福平、卡马西平 |

你不需要记住这张表。需要记住的是：**如果你同时在吃三种以上的药，或者要开始一种新药，值得让医生或药师做一次“相互作用核对”。** 很多医院有药学门诊，这项服务常常是免费的。

### 葡萄柚：影响没有传说中那么广，但确实存在

葡萄柚汁会抑制肠道里的 CYP3A4，让部分药物吸收增多、血药浓度升高。受影响的药物名单不长，但包括一些安眠药、部分他汀、部分降压药。对多数抗抑郁药影响有限，但**具体到你在吃的药，问一句药师最稳妥**。西柚、柚子、部分柑橘类果汁也建议一并问。

## 手术、麻醉、拔牙、胃镜之前

这是最容易被忽略的场景：要手术了，麻醉医生问“平时吃什么药”，你说“就一种抗抑郁药”，然后就没下文了。

需要主动交代的内容：

- [ ] 药名、剂量、每天什么时候吃、最后一次吃是什么时候
- [ ] 有没有吃过 MAOI（这类药与麻醉药的相互作用最复杂）
- [ ] 有没有抗凝药、抗血小板药、NSAIDs
- [ ] 有没有中药、保健品、圣约翰草
- [ ] 有没有出血倾向、瘀斑、鼻血
- [ ] 有没有心脏病史、心电图异常

**不要自己决定手术前停药。** 是否停、停多久、要不要桥接，需要精神科和麻醉/手术团队一起定。突然停用可能引发撤药反应，也可能让情绪在围手术期崩掉。

### 看病时的一句万能话

“我在吃抗抑郁药，药名在这里，麻烦帮我看一下会不会冲突。”

把药盒拍照存在手机里，或者写一张卡片放钱包。这比记住药名可靠得多。

> **什么时候需要联系医生 / 去急诊**
> - 服药后突发剧烈头痛、后颈发硬、心悸、大汗、视力模糊：**立即急诊**，警惕高血压危象。
> - 高热、肌肉僵硬、抽搐、意识混乱：**立即急诊**，警惕血清素综合征。
> - 呕血、黑便、鼻血止不住、大片瘀斑：**立即急诊**。
> - 晕厥、持续心悸、胸闷：**立即急诊**并做心电图。
> - 皮疹迅速扩散、面唇肿胀、呼吸困难：**立即呼叫 120**。
> - 刚加了一种新药或保健品后明显不适：停用新增的东西并联系医生。

## 常见问题

**“中药和西药隔开两小时吃，是不是就不冲突了？”** 隔开时间能减少一部分胃肠道层面的影响，但不能消除肝酶层面的相互作用。关键还是看成分。

**“感冒药不是处方药，应该没关系吧？”** 含伪麻黄碱、右美沙芬的感冒药恰恰是常出问题的一类。买之前问药师。

**“偶尔喝一点酒没事吧？”** 少量、偶尔，多数人不会有严重问题，但它会加重困倦、影响判断，也会拖慢恢复。治疗期能不喝就不喝。

**“保健品天然，应该不会和药冲突。”** 圣约翰草、银杏、大剂量鱼油都有明确的相互作用或出血风险。
