# 2.3 医生如何选药

同样诊断为抑郁症，为什么隔壁床吃的是舍曲林，你拿到的是米氮平？这一页讲医生在处方背后真正权衡的东西：不是“哪个药最好”，而是“哪个药和这个人最匹配”。适合刚拿到处方想不通的人，也适合吃了几个月效果不理想、准备和医生谈换药的人。

## 选药不是“找最强的药”，而是“找最合适的匹配”

抗抑郁药之间，整体疗效的差距没有想象中那么大。多数一线药物在群体研究里的有效率接近，真正拉开差距的是三件事：**这个人能不能耐受、会不会和现有治疗打架、以及他能不能长期吃下去**。

所以选药更像配眼镜，而不是打靶。验光要看你近视多少度、有没有散光、平时开车还是看电脑；选药要看你的症状长什么样、身体有什么底子、生活里有什么限制。同一个诊断，不同的人，合理的方案可以完全不同。

这也意味着：**别人的“神药”对你不一定好，别人吃了难受的药对你不一定差。** 听到这类经验，可以当作线索去问医生，但不要当作依据去要求处方。

## 医生通常会权衡的十个维度

| 维度 | 医生想知道什么 | 为什么重要 |
|---|---|---|
| 既往用药反应 | 吃过哪些药、吃了多久、有没有效、有什么副作用 | 有效且耐受的药，再次使用往往仍有效 |
| 家族反应 | 直系亲属用某类药的效果和不良反应 | 药物反应有部分遗传基础，可作参考 |
| 症状特点 | 睡眠、食欲、精力、焦虑、疼痛、思维迟滞哪个突出 | 不同药对不同症状的改善速度不同 |
| 共病 | 焦虑、强迫、物质使用、躯体疾病、进食障碍 | 有些药一箭双雕，有些药会加重共病 |
| 副作用偏好 | 你最怕发胖、性功能受影响，还是白天犯困 | 耐受性决定能不能长期吃 |
| 相互作用 | 正在吃的所有药、保健品、中药 | 有些组合会改变血药浓度或叠加风险 |
| 肝肾功能 | 有没有肝病、肾病，近期化验结果 | 影响药物代谢和清除，决定要不要调整 |
| 孕产计划 | 是否备孕、已孕、哺乳 | 需要单独权衡，不能照搬普通方案 |
| 费用与可及性 | 医保、自费能力、当地能不能买到 | 吃不起、买不到的药等于没有效 |
| 个人偏好 | 对药物的态度、对副作用的容忍度、生活节奏 | 依从性差，再好的方案也落不了地 |

这十个维度不会每次都问全，急诊或轻症时医生可能只抓最关键的几条。但如果你主动提供，决策质量会明显不一样。

### 症状特点：为什么“抑郁”两个字不够

抑郁症是一个综合征，不同人的症状组合差别很大。药物的“性格”正好和这些组合对应：

- **睡不着、早醒、没胃口、体重掉**：可能优先考虑镇静作用强一些的药，比如米氮平，或安排在晚上的曲唑酮。睡眠和食欲常常是最先改善的。
- **整天没劲、动不起来、注意力散**：可能优先考虑偏激活的药，比如安非他酮、氟西汀，或较高剂量的 SNRI。但这类药初期可能加重焦虑和失眠。
- **焦虑、反复担心、躯体紧张突出**：SSRI 和 SNRI 通常是不错的选择，起效后对焦虑也有效。初期可能有一过性的焦虑加重，需要提前知道。
- **伴随慢性疼痛、纤维肌痛样表现**：度洛西汀等 SNRI 有较多证据。【指南】
- **季节规律明显、入睡困难**：阿戈美拉汀或光照治疗会被考虑。【研究】
- **思维迟滞、表情淡漠、快感缺失突出**：可能需要考虑作用谱更广的方案，或评估是不是双相。

这只是“可能优先考虑”，不是规则。医生还会看年龄、体重、既往反应，把几条线合起来判断。

### 既往反应与家族反应：最有分量的两条线索

如果一个人两年前吃舍曲林好过，这次复发，医生大概率会先考虑再用舍曲林。**“曾经有效”是临床上最有说服力的证据之一**，比任何指南里的一线推荐都更贴近你本人。【临床经验】

反过来，如果某个药吃到足量足疗程完全没反应，再次使用价值就低；如果是有效但副作用受不了，可以考虑同类换药或换类别。

家族反应的价值在于：药物代谢酶的活性、受体敏感性有遗传成分。如果父母或兄弟姐妹用某类药效果特别好或特别差，这条信息值得主动告诉医生。它不是决定性的，但常能帮医生少走一轮弯路。

### 共病与身体情况：一张处方要管好几件事

抑郁症很少单独出现。共病会改变选药逻辑：

- **合并焦虑或强迫**：SSRI、SNRI 通常能同时覆盖，有时需要更高剂量和更长疗程。
- **合并双相**：这是最重要的一条红线。单用抗抑郁药可能诱发转躁或快速循环，通常需要先用心境稳定剂。选药前必须筛查有没有轻躁狂史。【指南】
- **合并心脏病、心律失常**：TCA 要慎用，部分 SSRI 与 QT 延长相关，可能需要心电图监测。
- **合并肝病**：肝功能不好会影响代谢，医生可能选对肝脏负担小的药，并更频繁复查。
- **合并肾病**：部分药物及其代谢产物经肾排泄，需要调整。
- **合并青光眼、前列腺增生**：抗胆碱能作用强的药（如 TCA、帕罗西汀）可能加重症状。
- **合并癫痫**：安非他酮会降低癫痫阈值，通常避免。
- **老年**：低钠血症、跌倒、多重用药的风险更高，选药更保守，监测更密。

### 副作用偏好：你更怕哪一个，直接说

这一条常常被患者忽略，其实非常关键。医生手里有几个疗效相当的选项时，**你的优先级就是决定因素**。

有人最怕发胖，因为体重增加会直接影响坚持治疗的信心；有人最怕性功能受影响，因为这关系到亲密关系；有人最怕白天犯困，因为要开车、要上班；有人最怕失眠，因为失眠本身就是最痛苦的症状。

这些偏好没有对错，也不需要不好意思。你越具体，医生越容易选对。比如“我下个月要考试，不能白天犯困”比“我不想有副作用”有用得多。

## 一张处方要照顾的其他事：相互作用、身体、钱与偏好

这三件事属于“不主动说就可能出事”的类型。

**相互作用**：不只是处方药，还包括中药、中成药、保健品、减肥产品、助眠软糖。圣约翰草、部分含贯叶金丝桃的中成药会明显影响肝酶，可能让抗抑郁药失效或浓度升高。

**肝肾功能**：体检报告上的转氨酶、肌酐、肾小球滤过率，医生会看，但如果你最近在别的医院查过，主动出示能省一次抽血。

**孕产计划**：备孕、已孕、哺乳是三条不同的决策线。核心不是“吃药一定危险”或“停药一定安全”，而是**不治疗的风险和治疗的风险哪个更大**，需要精神科和产科一起评估。计划怀孕时提前说，医生有时间选数据更多的药、安排更慢的调整，而不是等测出两条杠才慌乱处理。具体见[6.3 孕产期抑郁](<../模块6：特殊人群与特殊时期/6.3 孕产期抑郁.md>)。

### 费用与可获得性：这不是“次要问题”

一个药再好，如果每月自费负担不起，或者当地医院经常断货，它就不是一个现实的选择。医生通常清楚本院的药品目录和医保情况，你可以直接问：

- 这个药在医保里吗，自付大概多少？
- 有没有同类的、价格更低的替代？
- 医院药房能开到吗，还是需要去外面买？
- 如果换成国产仿制药，疗效和副作用会有差别吗？

仿制药与原研药在有效成分上一致，辅料和工艺可能不同，少数人对辅料敏感。如果换厂家后感觉不对，告诉医生，而不是自己停。

### 个人偏好：你想参与到什么程度

有人希望“医生你决定就好”，有人希望知道每一种选择的利弊再决定。两种都可以，重要的是让医生知道。共同决策不等于医生把选择推给你，而是医生提供专业判断，你提供自己的处境和优先级，一起定一个能执行的方案。

如果你对某类药物有顾虑（比如看过负面报道、家里有人吃出过问题），说出来。医生可以解释，也可以换方案；憋着不说，最后往往变成私自减药。

## 换药不是失败

这是这一页最想说的一句话。

治疗无效或不能耐受，说明的是**这个方案和你不匹配**，不是“你的病没救了”，也不是“你没配合好”。抑郁症的治疗本身就带有试错性质：没有哪种检查能提前告诉你哪个药有效，医生只能根据证据和你的反馈逐步逼近。

换药有很多种方式：直接换、交叉重叠、逐步减量后再换，MAOI 相关的换药还需要洗脱期。这些都必须由医生安排，因为不同组合的风险差别很大。具体见[2.7 换药联合与增效](<2.7 换药联合与增效.md>)。

判断“该不该换”的时机也很重要：剂量是否足够、疗程是否够长、有没有在按时吃、有没有同时喝酒或使用其他物质、有没有被忽略的共病。这些“假难治”的因素排除了，再谈换药才有意义。

### 复诊前可以准备的清单

- [ ] 现在吃的药名、厂家、剂量、每天几点吃
- [ ] 从什么时候开始吃，中间有没有调整过
- [ ] 最困扰的3个症状，按严重程度排序
- [ ] 副作用清单：出现时间、持续多久、有没有减轻
- [ ] 睡眠、食欲、体重的变化（有记录最好）
- [ ] 正在吃的其他药、中药、保健品
- [ ] 最近的化验单、心电图
- [ ] 你想问医生的3个问题，写在纸上

> **什么时候需要联系医生 / 去急诊**
> - 出现自杀念头、自伤行为或具体计划：**立即呼叫 120 或去最近医院急诊**，不要独处。
> - 服药后高热、大汗、肌肉僵硬、意识混乱：**立即急诊**。
> - 皮疹迅速扩散、面唇肿胀、呼吸困难：**立即呼叫 120**。
> - 突然兴奋、话多、睡得极少却不困、冲动消费：尽快联系医生，不要自行加药。
> - 换药后症状明显反弹、焦虑剧烈加重、整夜不睡：尽快联系开药医生。
> - 黄疸、尿色明显变深、持续呕吐、心跳明显不规则：当天就医。
