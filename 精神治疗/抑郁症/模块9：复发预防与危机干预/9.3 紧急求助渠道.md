# 9.3 紧急求助渠道

> 危机发生时，最难的不是“要不要求助”，而是“打哪个电话、第一句说什么”。这一页把 120、110、12356 和医院急诊各自管什么、什么情况打哪个、接通后怎么描述、陪护者在等待救援的那段时间做什么，写成可以直接照做的步骤。适合患者本人提前读，也适合家属在慌乱时翻开来照着做。

## 三个号码，各管什么

先把分工记住。打错电话不会有人责怪你，但会耽误时间。

| 号码 | 主要管什么 | 什么时候打 | 局限 |
|---|---|---|---|
| 120 | 医疗急救与转运：意识不清、服药过量、自伤出血、抽搐、高热、胸痛、晕厥 | 需要救护车、需要马上有医疗处置、患者无法自行走动 | 不负责现场制服与破门；接线员需要你给出准确地址 |
| 110 | 正在发生的危险：持械、站在高处或桥边、反锁房间、失联、有人阻止救治 | 现场有即时人身危险、需要警察到场或破门、需要协助送医 | 不做医疗判断；到场后通常会联动 120 |
| 12356 | 心理援助热线：情绪支持、危机干预、转介信息 | 念头很强但还没有行动、需要有人陪着说话、不知道该去哪看 | 不能派车、不能开药；高峰期可能占线，需要重拨或换渠道 |

12356 是国家卫生健康委自 2025 年起推行的全国心理援助热线，各地接通时段和坐席数量不同，以当地卫健委公布为准。**它不是急救电话**，如果已经在准备行动，先打 120 或去急诊，再打热线。

除了这三个号码，还有两类地方资源值得提前存在手机里：

- **精神专科医院的急诊**。不是每家精神专科医院都有 24 小时急诊，提前查清楚哪家开、怎么走、夜间从哪个门进。
- **区县级精神卫生中心（疾控精神卫生科）**。它们通常承担社区随访，能提供转介和危机处置信息，电话以当地卫健委公布为准。

### 什么时候打哪个：三种场景

| 场景 | 先做什么 | 再做什么 |
|---|---|---|
| 已经有行动：吞药、割伤、站在高处 | 直接打 120；同时让身边的人做手段限制 | 不要试图自己开车送，路上可能恶化；把药盒、空药板带上 |
| 有明确计划但还没行动：攒了药、写了信、反复说“今晚就结束” | 不让其独处；先移走药物和利器；打 120 或直接去急诊 | 同时打 12356 让专业人员介入通话；通知开药医生 |
| 念头很强、极度痛苦、但无计划 | 打 12356；联系家属或朋友来陪伴 | 当天加号看精神科；不要独自过夜 |

判断不了的时候，按最重的那一档处理。多叫一次救护车不会有人追究你“浪费资源”，但少叫一次可能是不可逆的。

## 电话接通后怎么说

接线员需要的是**事实**，不是情绪描述。慌的时候容易说成“我朋友不行了，你们快来”，对方无法判断轻重，也无法定位。可以按下面五句话的顺序讲，甚至照着念：

1. **谁**：“我是他姐姐，患者是我弟弟，男性，29 岁，有抑郁症，正在吃药。”
2. **在哪**：“我们在某某区某某路某小区 3 号楼 2 单元 501，门牌清楚，楼下有便利店。”
3. **发生了什么**：“半小时前他把自己反锁在房间里，说吃了不少安眠药，现在门打不开，说话开始含糊。”
4. **现在是否安全**：“房间里有刀，门是木门，我们已经打了 110。他还在说话，但越来越慢。”
5. **联系方式与配合**：“我的手机是 138xxxxxxxx，我在门口等，楼下有人接你们。”

如果不知道吃了什么药，把药盒、药板、空瓶全部收好带去医院——**药盒比描述有用**。如果喝了酒，一定要说，酒精会改变很多药物的作用和预后。

有几句话尽量不要说，它们会让接线员误判：

- “他心情不好”“他有点想不开”——太模糊，容易被当成非紧急。
- “你们快点”但不给地址。
- “别告诉他是我们叫的”——先救命，再谈感受。
- “他以前也这样，没事的”——每一次都可能是例外。

## 去急诊：从出门到见到医生

**出门前五分钟**：带上医保卡、身份证、正在服用的所有药（或药盒照片）、既往病历和检查单、一部电量足够的手机、少量现金。留一个人在家收拾危险物品，或者把患者带离有危险物品的环境。**不要**让患者单独去洗手间或回房间“拿东西”。

**路上**：如果患者还能走，坐后排，靠车门一侧，由一名家属同侧陪同。如果已经意识不清、抽搐、呕吐，不要强行喂水、催吐，侧卧位，等救护车。

**到急诊后**：先分诊，直接说“有自杀行为/计划”这几个字。分诊护士会据此分级，隐瞒这一句可能意味着等更久。就诊时如实说三件事：吃了什么、吃了多少、什么时候吃的；最近在吃什么药；最近喝没喝酒。不要因为怕“被贴标签”而少说。

**可能需要等**。综合医院急诊夜里很忙，精神科会诊可能要等几小时。等待期间不要离开，不要留患者一个人在走廊椅子上。可以问护士：“大概还要多久？我们现在能做哪项检查？”把能提前做的检查先做掉，往往能省时间。

## 陪护者：该做什么、不该做什么

陪护者的状态会直接影响患者的状态。慌是正常的，但可以按下面的清单行事。

**该做的：**

- [ ] 保持语速慢、声音低、句子短。一次只说一件事。
- [ ] 坐在患者的侧前方，不要堵住门口，也不要站在其正前方俯视。
- [ ] 直接问：“你现在有伤害自己的打算吗？”问出来不会让人去死，反而常常让人松一口气【指南】。
- [ ] 把药物、利器、酒精移走，动作平静，说明“先放我这儿，等好一点再给你”。
- [ ] 记录时间：最后一次见到人、最后一次服药、最后一次喝酒、说了什么。
- [ ] 对医生说实话，包括患者不想让说的部分（正在准备、藏了药、写过东西）。生命安全优先于“替他保密”。
- [ ] 给自己找一个替补。危机可能持续几天，一个人扛不住。

**不该做的：**

| 常见做法 | 为什么可能有害 |
|---|---|
| “你想开点，比你惨的人多了” | 等于告诉对方“你的痛苦不算数”，会让人闭嘴 |
| 反复追问“你为什么这样” | 当事人往往说不出原因，追问会变成审讯 |
| “我保证不告诉任何人” | 一旦需要叫救护车，这个承诺必然被打破，信任反而崩得更彻底 |
| 抢手机、夺刀、强行拖拽 | 容易激化，造成二次伤害；需要处置时打 110，让专业的人来 |
| 让患者“一个人静一静” | 危机期独处是最危险的状态，哪怕只有十分钟 |
| 在患者面前哭诉、崩溃 | 不是不许你难过，而是先找一个不在场的人承接你的情绪 |

## 等待救援的那段时间怎么保证安全

从打完电话到人真正被接走，可能是十分钟，也可能是两小时。这段时间最需要具体动作：

1. **把人留在视线内。** 同处一室，不锁门，不背对。上厕所也请另一位家人陪同或在门外说话。
2. **改变位置。** 从窗边、阳台、厨房、车库移开，去客厅或门口这类“不好实施”的地方。住高层的，先把窗户关好、阳台门锁上。
3. **继续说话，但聊小事。** “你上次说的那个游戏更新了吗”“猫今天又打翻水了”。不要谈人生意义，也不要分析病情。目的是让对方的注意力留在对话里。
4. **不要争辩“你该不该这样想”。** 可以说“我不知道你有多难受，但我在这儿”，这句话比任何道理都稳。
5. **准备好交接。** 身份证、医保卡、药盒放在一个袋子里；门禁卡、电梯卡提前拿好；把宠物关进房间，方便救护人员进出。
6. **如果情况突然变化**——突然安静、突然起身、走向某个房间——立刻跟上去，同时再打一次 120 或 110，说明“情况恶化”。

> **什么时候需要联系医生 / 去急诊**
>
> **不要等，立即拨打 120 或去最近医院急诊**：已经吞药、割伤、坠落；有明确的自杀计划并开始准备；意识模糊、抽搐、高热、呼吸异常；拒绝喝水进食超过一天；出现冲动伤人的行为。
>
> **当天联系精神科医生**：自杀念头反复出现但能自我控制；安全计划失效；睡眠连续多日几乎为零；刚换药或加药后情绪急剧恶化。
>
> **随时可打**：12356 心理援助热线；110（现场有即时危险）；120（需要医疗转运）。地方热线号码以当地卫健委公布为准，不要拨打来源不明的“危机干预”号码。

## 五个容易踩的坑

1. **怕留下记录，不敢打 120。** 急救记录不会进入你的档案、不会通知单位。犹豫的每一分钟都在放大风险。
2. **热线占线就放弃。** 占线很常见，隔几分钟重拨，或者换一个渠道；同时让身边的人继续陪着，不要因为“没打通”就认为没办法。
3. **只打热线，不打 120。** 热线能陪你说话，但不能派车。已经有行动时，热线不是第一选择。
4. **送到医院又带回家。** 急诊评估后如果医生建议留观或住院，尽量配合。觉得被冒犯可以事后投诉，但不要在当下赌气离院。
5. **危机过去就当没发生。** 事后 48 小时内是再次尝试的高风险期，需要有人陪、需要复诊、需要把这次的经过告诉医生并修改安全计划。

还有一件事值得提前做：把 120、110、12356、开药医生、两位紧急联系人，存进手机“紧急联系人”并写一张卡片放钱包。危机时找不到号码，比没有号码更常见。
