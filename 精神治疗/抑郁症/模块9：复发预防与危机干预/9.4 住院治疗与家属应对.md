# 9.4 住院治疗与家属应对

> 提到“住院”，很多人的第一反应是害怕：是不是被关起来、会不会被绑、出来会不会被贴标签。这一页讲清楚四件事：什么情况医生会建议住院，自愿住院和非自愿住院在法律上分别是什么条件，病房里一天到底怎么过，家属在探视、送东西、出院安排上能做什么。适用于正在被建议住院、或者家里有人已经住院的人。读完你应该能判断“这次该不该住”，以及住进去之后怎么把这段经历变成康复的一部分。

## 什么情况需要住院

住院不是为了“惩罚”或者“让你反省”，它解决的是门诊解决不了的问题：**安全、观察、强度**。门诊一次二十分钟，看不出整夜的睡眠和全天的波动；家里只有一两个家属，挡不住持续的自伤冲动；药物需要几天内密切调整时，也需要有人在旁边看着。

| 情形 | 为什么通常需要住院 | 一般处理方向 |
|---|---|---|
| 有自杀计划或近期有自杀行为，家中无法保证安全 | 需要 24 小时看护与手段限制；门诊无法覆盖夜间 | 封闭或半封闭病房，严密观察，调整治疗 |
| 自伤频繁、拒食、拒水、木僵、生活不能自理 | 存在躯体并发症风险，需要医疗监护 | 补液、营养支持、药物调整，必要时物理治疗 |
| 精神病性症状：幻觉、妄想、严重激越、伤人风险 | 需要快速控制症状并排除器质性原因 | 抗精神病药治疗，环境管理 |
| 药物调整期需要密切观察（如难治性抑郁换方案、MECT 疗程） | 副作用与疗效都需要每日评估 | 住院完成调整，稳定后转门诊 |
| 共病严重躯体疾病、孕产期、老年多重用药 | 需要多科协作 | 综合医院精神科或会诊联络病房 |
| 门诊治疗无效且功能严重受损 | 需要结构化环境与强化治疗 | 评估后转介专科中心 |

反过来说，下面这些情况**不一定**需要住院：只是情绪低落但无自伤风险、门诊能规律复诊、家里有人能陪、睡眠虽差但还能维持基本生活。住院本身也有代价——中断工作学业、离开熟悉环境、费用、以及“被贴上标签”的感受。是否住院，是医生评估与患者、家属共同讨论的结果，不是单方面“通知”。

如果医生建议住院而你犹豫，可以直接问三个问题：**不住院的话，回家需要满足什么条件？出现什么情况必须马上回来？有没有日间病房或强化门诊这类替代方案？** 这三个问题问出来，讨论才有实质内容。

## 自愿住院与非自愿住院：法律怎么规定

《中华人民共和国精神卫生法》确立了一个基本前提：**精神障碍的住院治疗实行自愿原则**。也就是说，能门诊就门诊，住院原则上要本人同意。下面这段只讲原则，不构成法律意见；具体条文以官方公布文本为准，各地执行细节以当地卫健部门和医疗机构的规定为准。

非自愿住院不是“医生说了算”，法律设了两类情形，且都要求先满足“严重精神障碍患者”这一诊断与评估前提：

| 情形 | 法律表述（大意） | 谁来决定 |
|---|---|---|
| 伤害自身 | 已经发生伤害自身的行为，或者有伤害自身的危险 | 需经监护人同意，医疗机构方可实施住院治疗；监护人不同意的，不得强制住院，但应做好在家看护 |
| 危害他人安全 | 已经发生危害他人安全的行为，或者有危害他人安全的危险 | 应当实施住院治疗；监护人阻碍或患者擅自离院时，可由公安机关协助采取措施 |

还有几条常被忽略的程序性权利：

- **再次诊断与鉴定。** 患者或监护人对“需要住院”的诊断结论有异议、不同意住院的，可以要求再次诊断；对再次诊断结论仍有异议的，可以依法委托鉴定。这是法律给的救济渠道，不是“闹事”。
- **告知义务。** 医疗机构应当把患者在治疗中享有的权利告知患者或监护人。
- **约束与隔离的条件。** 只有在患者发生或即将发生伤害自身、危害他人、严重扰乱医疗秩序的行为，且没有其他可替代措施时，才可以实施保护性医疗措施，并应记录在病历中；禁止用约束、隔离惩罚患者。
- **通讯与探视。** 患者有通讯和会见探访者的权利，除急性发病期或为避免妨碍治疗可暂时限制外，不得随意剥夺。

需要说明的是：**“非自愿”不等于“没有权利”**。非自愿住院期间，患者仍然有知情同意（除法定例外）、隐私、申诉、通讯探视等权利。如果你觉得程序有问题，可以要求复印病历、向医院医务科或当地卫健部门反映，也可以咨询法律援助。这类事情超出科普范围，建议找专业人士。

## 病房里会发生什么

第一次住院的人，最难受的往往不是治疗，而是“不知道接下来会发生什么”。下面按时间线说。

**入院当天**：办手续、测生命体征、问病史（会问得很细，包括喝酒、用药、月经、既往自伤）。随身物品要清点，危险物品（刀具、打火机、绳子、玻璃制品、大量现金、部分电子产品）由护士站暂存，出院时归还。会换病号服，做安全检查，包括口袋和行李。这个过程会让人觉得被冒犯，但它是病房的常规流程，不是针对某个人。

**头三天**：以观察为主。医生会安排抽血、心电图等检查，排除躯体原因；护士会记录睡眠、进食、排便、情绪和风险等级。这几天药效通常还没起来，人可能更烦躁，这是常见的。

**日常节奏**：起床、吃药、查房、活动、吃饭、熄灯。多数病房有工娱治疗（手工、绘画、阅读、体能活动）、团体心理活动、个别谈话。查房是家属了解情况最重要的窗口，尽量参加。

**关于约束**：如果出现冲动、自伤、攻击行为，医护人员可能实施短暂的保护性约束或隔离。合规的做法是有医嘱、有时间记录、有巡视、解除后记录。家属看到这一幕会很受冲击，可以事后向主管医生询问原因和记录情况，但当场争执通常无助于患者。

**出院**：由医生评估后办理。如果本人没有能力办理，监护人应当为其办理。出院不是“治好了”，而是“风险降到可以在门诊管理”。

### 探视、物品与通讯

探视对恢复有帮助，但探视也可能带来刺激。去之前先想清楚：这次见面是让对方安心，还是让自己安心。

| 类别 | 具体物品 | 说明 |
|---|---|---|
| 可以带 | 换洗衣物（无绳带、无金属件）、软底拖鞋、洗漱用品（非玻璃瓶）、纸笔、书籍 | 先问护士站，各病房规定不同 |
| 通常不可以带 | 刀具、剪刀、打火机、火柴、绳子、腰带、玻璃容器、酒精、大量现金、自备药品 | 自备药一律交护士站，不能自己吃 |
| 需要商量 | 手机、充电器、电脑、零食、化妆品、指甲刀 | 多数病房限时使用手机；指甲刀常需代管 |
| 不建议带 | 大量补品、成箱饮料、贵重物品 | 占地方、易丢失、可能引发纠纷 |

探视时的几条经验：

- **不要问“他们有没有欺负你”。** 这句话会把患者推向警惕和对抗，也会让家属自己越问越焦虑。
- **不要承诺“我马上带你出去”。** 做不到的承诺会变成第二次伤害。
- **带一件具体的东西。** 家里的毯子、一只玩偶、几张照片，比十句“你要坚强”有用。
- **控制人数和时间。** 一次两三个人、半小时左右，比一屋子人围着更舒服。
- **和护士聊两句。** 问睡眠、吃饭、吃药后有没有不舒服，比问“今天怎么样”得到的信息多。

通讯方面，多数病房允许在固定时段使用手机，但可能限制拍摄。如果患者想联系外界而受限，可以问清是治疗性限制还是常规管理，并要求说明依据。

## 出院计划：从入院第一周就开始

出院后前两周是复发和再次自伤的高风险期，很多问题出在“出院那天才开始想”。建议在入院第一周就和医生谈出院计划，把下面这份清单逐项落实：

- [ ] **出院日期与条件**：什么情况下可以出院，谁来判断。
- [ ] **出院诊断与药物方案**：药名、剂量、吃法、可能副作用，写在纸上带回家。
- [ ] **复诊时间**：出院后多久复诊，挂谁的号，怎么加号。
- [ ] **病假与手续**：出院小结、病假证明、报销材料一次开齐（见[11.3 费用医保病假与权益](<../模块11：就医、费用与权益/11.3 费用医保病假与权益.md>)）。
- [ ] **危险期安排**：出院后第一周谁陪着、能不能请假、夜里谁值守。
- [ ] **药物保管**：由谁保管、按次发放还是自取、什么时候评估归还。
- [ ] **危机预案**：复发预警信号是什么、打给谁、去哪家急诊（把[9.2 安全计划模板](<9.2 安全计划模板.md>)更新一遍）。
- [ ] **生活安排**：睡眠、吃饭、活动、暂时不接的工作或课程。
- [ ] **家属分工**：谁陪同复诊、谁负责药、谁负责和单位学校沟通。

出院后一个月内，尽量做到“三不”：不自行减药、不立刻恢复满负荷、不取消复诊。这三件事是再入院最常见的诱因【临床经验】。

## 患者权益与隐私

住院期间的权利，可以记成下面这张表。遇到问题时，先找主管医生，再找医务科，仍无法解决再向当地卫健部门反映。

| 权利 | 具体含义 | 遇到问题找谁 |
|---|---|---|
| 人格尊严 | 不被侮辱、打骂、嘲笑；不被当作“案例”在无关人员面前讨论 | 主管医生、护士长、医务科 |
| 知情同意 | 知道诊断、治疗方案、主要风险和替代方案；特殊治疗需书面同意 | 主管医生 |
| 隐私 | 病历、病情属于敏感信息，未经同意不得向单位、学校、亲友泄露 | 医务科、病案室 |
| 查阅病历 | 有权查阅、复制病历资料（具体范围按现行规定） | 病案室 |
| 通讯与探视 | 除法定情形外不得限制 | 护士长、医务科 |
| 申诉与救济 | 对诊断、住院有异议可要求再次诊断、鉴定；可投诉 | 医务科、当地卫健部门、法律援助 |
| 不受歧视 | 入学、就业、医疗等合法权益受法律保护 | 单位工会、人社部门、法律援助 |

关于隐私，有两点实务提醒。**第一，住院信息可能被单位知道**，如果涉及医保报销、病假，人事部门通常会看到就诊类别。想尽量避免扩散，可以在请假时只提供必要的证明，并书面说明保密要求。**第二，家属之间也会泄露。** 住院这件事，建议由患者指定“可以告诉谁”，其他人统一口径为“身体不舒服住院调理”。这不是撒谎，是划定边界。

> **什么时候需要联系医生 / 去急诊**
>
> **住院期间，立刻找护士或值班医生**：患者突然异常安静或开始交代后事；出现高热、意识模糊、肌肉僵硬、抽搐；拒食拒水超过一天；与其他患者发生冲突或被打；被约束后出现肢体麻木、疼痛。
>
> **出院后，立即去急诊或拨打 120**：自杀念头重新出现且有计划；自伤；几乎不睡且兴奋话多；停药后出现严重不适。
>
> **出院后当天联系医生**：药物吃完了没续上、副作用明显、情绪在几天内快速下滑、复诊挂不上号。随时可拨 12356 心理援助热线；地方热线以当地卫健委公布为准。

## 四个容易踩的坑

1. **把住院当成“关起来”。** 现代精神科病房多数是开放式或半开放式管理，重点是治疗和观察，不是限制自由。真正被限制的部分，法律有明确条件。
2. **入院时隐瞒用药和饮酒。** 隐瞒会直接影响医生判断，尤其是药物相互作用和撤药风险。说清楚，医生不会因此“给你加罪”。
3. **出院就停药、就复工。** 出院时症状减轻，不等于病程结束。维持治疗的时间通常以月计，减药要在医生指导下慢慢来。
4. **家属替患者做所有决定。** 哪怕是非自愿住院，也应尽量让患者参与能参与的部分（吃什么、什么时候探视、出院后住哪）。被当成“物件”对待，是住院体验里最难修复的部分。
