# 8.4 维持治疗与依从性

治疗到一定阶段，问题会从“这药有没有效”变成“我还要吃多久”和“我怎么才能一直吃下去”。这两件事其实是一件事：维持治疗的时间越长，越需要一套能运转的日常系统；而系统能不能运转，又取决于副作用、花费、病耻感和身边人的态度。这一页讲清楚维持多久、哪些人需要更长、依从性为什么会掉，以及家属怎么帮而不变成控制。

## 维持多久：没有一个数字适合所有人

维持治疗的目的不是“多吃几年”，而是**把复发的概率压下来**。时间长短取决于复发风险，而复发风险由几件事决定：发作过几次、缓解得彻不彻底、有没有残留症状、起病早晚、家族史、共病、生活是否长期高压。

| 情况 | 维持治疗的大致方向 |
|---|---|
| 首次发作，缓解彻底，功能恢复好 | 通常至少 6–12 个月，之后可讨论逐步减停 |
| 两次发作，或首次发作但有明显残留症状 | 一般建议更长，常以年计 |
| 三次及以上发作 | 通常建议长期维持，部分人需要多年甚至“不确定期限”的长期治疗 |
| 慢性化（一次发作持续两年以上） | 往往需要长期维持，重点转向功能康复 |
| 合并焦虑、物质使用、慢性躯体疾病 | 需要更长，且要同时处理共病 |
| 既往停药后很快复发 | 再次维持的时间通常要比上次更长 |

“indefinite”这个词在指南里常被译成“长期”或“不确定期限”，意思是**没有预设的停药时间点，定期评估、能减则减，但不强求停**。这不是“一辈子被困住”，而是“把复发风险控制在一个可接受的范围内”。

剂量的原则比较简单：**维持期通常沿用急性期有效的剂量**，不是“好了就减半”。这一点在 [8.1 为什么要足疗程](<../模块8：疗程、依从性与停药/8.1 为什么要足疗程.md>) 里有更详细的说明。

### 哪些人需要更长

把上一节的判断标准说得更具体一些，下面这些人通常属于“需要更长”的那一类【指南】【研究】。

- **多次复发**：发作次数越多，下一次越容易来，间隔也可能越短。
- **有残留症状**：疲劳、失眠、焦虑、注意力差，即使很轻，也会抬高复发风险。
- **慢性化**：症状持续两年以上，恢复往往更慢，需要更长的维持。
- **共病**：焦虑障碍、物质使用、人格障碍、慢性疼痛、糖尿病、心血管病，都会让治疗更复杂。
- **起病年龄早**：青少年期起病的人，复发风险通常更高。
- **家族史明显**：一级亲属中有抑郁症或双相障碍。
- **既往停药后复发**：这是最直接的信号——上一次的教训值得参考。
- **长期高压的生活处境**：照护重病家人、长期夜班、贫困、持续的人际冲突。这些不是“想开点”能解决的，需要社会支持和现实调整。
- **老年人和孕产期女性**：生理和社会因素都更复杂，需要个体化评估。

需要强调的是：**“需要更长”不等于“永远不能停”**。它意味着停药要更慢、监测要更密、决定要更谨慎。

## 依从性差的常见原因

“不听话”是最没用的解释。人不会无缘无故放弃对自己有好处的事，掉队背后通常有具体原因。下面这张表把常见原因和对应的解法放在一起。

| 原因 | 常见表现 | 可以怎么处理 |
|---|---|---|
| 副作用 | 性功能、体重、嗜睡、恶心、出汗 | 见 [7.4 性功能体重与代谢](<../模块7：风险管理与副作用监测/7.4 性功能体重与代谢.md>)，和医生谈调整，不要自己停 |
| 病耻感 | 不想让人看见吃药，把药装进维生素瓶 | 换一个中性药盒；只告诉必要的人；理解“吃药”和“糖尿病打胰岛素”没有本质区别 |
| 感觉好了 | “我已经好了，不用吃了” | 把维持治疗的理由讲清楚；设定下一个评估时间点，而不是“无限期吃” |
| 费用 | 自费压力大、进口药贵 | 问医生有没有同类可及的选择；了解门诊慢特病、医保报销 |
| 忘记 | 作息不固定、出差多 | 分装盒、闹钟、和固定动作绑定（见 [8.2 漏服忘服与自行减量](<../模块8：疗程、依从性与停药/8.2 漏服忘服与自行减量.md>)） |
| 信息混乱 | 网上说“伤肝”“上瘾”“吃傻”，与医生说法冲突 | 把疑问带给医生，而不是自己停药验证；见 [12.1 常见治疗误区40条](<../模块12：误区、问答与决策/12.1 常见治疗误区40条.md>) |
| 害怕依赖 | “是不是要吃一辈子” | 区分“依赖”和“维持治疗”；成瘾是另一回事 |
| 没有反馈 | 觉得“吃了也没用” | 用记录看趋势；和医生讨论疗效评估的时间点 |
| 酒精或物质使用 | 吃药时喝酒、用其他物质 | 如实告诉医生，这会影响方案和风险评估 |
| 治疗关系 | 觉得医生不重视自己、沟通不畅 | 可以换医生，但不要停治疗；见 [1.3 共同决策与治疗联盟](<../模块1：治疗总论/1.3 共同决策与治疗联盟.md>) |

有一点值得单独说：**副作用是依从性最强的预测因素之一**。很多人不是“不想治”，而是“受不了”。如果医生不知道你受不了什么，他就没法帮你调整。

## 把“坚持”变成系统

靠意志力坚持一件要做几百次的事，成功率很低。更可靠的办法是把决定“外包”给流程。

- [ ] 固定一个服药时间，和每天必做的事绑定（刷牙、早饭、睡前）
- [ ] 一周分装一次药盒，看格子就知道吃没吃
- [ ] 手机设两个闹钟，第二个用来确认
- [ ] 包里放一份应急量，用密封袋标注药名
- [ ] 每次复诊结束，当场约好下一次的时间
- [ ] 把复诊日写进日历，提前一天设提醒
- [ ] 记录睡眠、情绪、副作用三行，复诊时带上
- [ ] 算好取药周期，提前一周去开药，别等到断药
- [ ] 出差、旅行、节假日提前备药
- [ ] 把“我为什么吃这个药”写在纸上，状态差的时候拿出来看

最后一条常被低估。人在抑郁状态下会丧失“为什么要做这件事”的记忆，一张自己写的纸条，比当下的判断更可靠。

还有一个实用策略：**把“坚持”换成“再吃一周”**。不要想“我还要吃两年”，只想“这一周我按时吃”。长期目标太大，短期承诺更容易兑现。

### 家属怎么帮而不控制

家属的参与对依从性影响很大，但“帮”和“控制”只有一线之隔。区别在于：**帮是把选择权留给对方，控制是把选择权拿走。**

| 帮忙的样子 | 控制的样子 |
|---|---|
| “今天的药吃了吗？我帮你倒了水。” | 每天翻包、数药片、查手机 |
| “这次复诊我陪你去，需要我进去吗？” | 不经同意就替对方跟医生说话 |
| “你不想说也没关系，我在客厅。” | 逼问“你到底怎么想的” |
| “我们提前说好，如果连续几天睡不着就去医院。” | 一出问题就没收药物、限制出门 |
| “这个月药费我先垫，你方便再还。” | 用钱来要求“必须听我的” |
| 提醒一次，然后交给对方 | 反复叮嘱，直到对方发火 |

几条具体建议：

- **把提醒变成约定**：一起商定“谁在什么时候提醒、提醒几次”，而不是随时监督。
- **接受“对方有权拒绝”**：成年人有权对自己的治疗做决定，包括决定暂时不减量、决定换医生。
- **不要替对方保密到危险的程度**：涉及自杀风险时，保密要让位于安全，但要事先说清楚这个边界。
- **照顾好自己的情绪**：长期照护的人容易耗竭，耗竭之后的“帮”往往变成指责。
- **在稳定期谈规则**：不要等到吵起来才定规矩，平静时商量好的方案才执行得下去。

## 常见坑

**坑一：把“维持治疗”理解成“医生想多开药”。** 维持治疗针对的是复发风险，不是药厂利益。

**坑二：把“感觉好了”当成“可以停了”。** 感觉好常常是药在起作用。

**坑三：把“副作用”忍到底。** 忍到最后往往是突然停药，比一开始就沟通更糟。

**坑四：把“依从性差”当成道德问题。** 它通常是流程问题、信息问题或副作用问题。

**坑五：家属用“我都是为你好”压过对方。** 短期可能有效，长期会让人学会隐瞒。

## 什么时候需要联系医生或去急诊

> **立即拨打 120 或去急诊：**
>
> - 出现自杀念头、计划或准备行为，或已经自伤；
> - 意识模糊、高热、肌肉僵硬或抽动、大汗；
> - 晕厥、胸痛、抽搐、严重过敏。

> **尽快联系开药医生（当天到数日内）：**
>
> - 已经停药或减量，情绪开始下滑；
> - 副作用已经影响到是否愿意继续治疗；
> - 连续两周以上睡不好、兴趣下降、精力变差；
> - 因为费用问题打算自行减量或停药；
> - 需要调整维持治疗的时长或剂量。
