# 8.3 停药计划与撤药管理

停药是治疗的一部分，不是治疗的失败。但“停药”这两个字里藏着两件完全不同的事：一件是**有计划地慢慢减**，另一件是**某天突然不吃了**。前者大多顺利，后者常常以头晕、电击感、失眠、情绪反弹收场，甚至把好不容易稳住的病情推回去。这一页讲清楚什么时候可以考虑停、怎么慢减、撤药反应和复发怎么分，以及停药后几个月该盯什么。

## 什么时候可以考虑停

停药不是凭“感觉好了”决定的，它有几个前提条件。国内指南和 NICE 的建议大体一致：**在缓解并稳定足够长的时间后，结合复发风险、功能恢复和患者意愿，共同决定**【指南】。

| 可以考虑 | 建议暂缓 |
|---|---|
| 症状缓解，且已维持足够长时间（首次发作通常至少 6–12 个月，具体由医生判断） | 刚缓解几个月，或症状时好时坏 |
| 功能基本恢复：能工作/学习、能社交、能照顾自己 | 能上班但一加班就崩，或仍有明显残留症状 |
| 生活相对稳定，近期没有重大变动 | 正面临换工作、搬家、考试、丧亲、离婚等重大应激 |
| 知道自己的复发预警信号，也有应对计划 | 说不清自己最早会有什么变化 |
| 副作用明显影响生活，且已尝试过其他办法 | 因为“不想吃药”“觉得丢人”而想停 |
| 有医生参与，能定期随访 | 独自在外、复诊不方便、联系不上医生 |

有几类人通常需要更长的维持治疗，甚至长期治疗：

- **多次复发**（一般认为三次及以上，或两次但间隔很短）；
- **有残留症状**：疲劳、失眠、焦虑、注意力差；
- **慢性化**：一次发作持续两年以上；
- **起病年龄早**、有明确家族史；
- **共病**：焦虑障碍、物质使用、人格障碍、慢性躯体疾病；
- **既往停药后很快复发**。

这些不是“永远不能停”，而是“停之前要更谨慎、停之后要更密地看”。

## 缓慢减量的原则

减量的核心不是“快”，而是**让身体有时间适应**。具体怎么减、减多快，必须由医生定；这里只说原则。

**原则一：医生主导，不自己动手。** 减量方案要考虑药物半衰期、用了多久、剂量多大、既往有没有撤药反应。同样的药，不同人的减法可能完全不同。

**原则二：一步一步来，每步之间留观察期。** 通常以周为单位，越到后面减得越慢。原因是：剂量越低，同样的减量幅度对血药浓度的影响比例越大。

**原则三：一次只改一件事。** 减药期间不要同时换工作、搬家、开始节食、戒咖啡、尝试新的保健品。变量太多，出了状况分不清原因。

**原则四：最后一段最需要耐心。** 很多人减到最后一点时觉得“都到最后了，干脆停掉”，结果撤药反应恰恰出现在这一步。

**原则五：减量期要记录。** 每天记睡眠、情绪、有没有头晕/电击感/恶心。这份记录是判断“撤药反应还是复发”的关键。

**原则六：选一个相对平稳的时间窗口。** 避开考试、项目截止、家庭重大事件、长途旅行。

关于“减到多少可以停”，没有通用答案。有的人减到很小的量后顺利停掉，有的人需要在很小的量上再维持一段时间。这不是“意志力”问题，是药物代谢的个体差异。

## 撤药反应和复发怎么分

这是停药阶段最实际的问题。两者看起来都像“又不舒服了”，但性质完全不同，处理方式也相反。

| 维度 | 撤药反应 | 复发 |
|---|---|---|
| 出现时间 | 减量或停药后数小时到数天内 | 通常数周到数月，逐步出现 |
| 典型表现 | 头晕、走路发飘、恶心、乏力、流感样感觉、电击感、失眠、焦虑、易激惹、多梦 | 原来抑郁的那套症状回来：情绪低落、兴趣丧失、自责、绝望 |
| 变化速度 | 来得快，也可能去得快 | 逐步加重，不会自己好转 |
| 对补服的反应 | 恢复原剂量后很快缓解 | 补回剂量只能部分缓解，仍往下走 |
| 持续时间 | 一般数天到数周，逐渐减轻 | 持续加重，超过两周不缓解要重视 |
| 伴随想法 | 多为身体不适，不一定有绝望感 | 常伴无望感、自责、自杀念头 |

“电击感”值得单独解释一下：很多人描述为“脑子里突然闪过一道电流”“转头时眼前一晃”“像被静电打了一下”。它听起来吓人，但通常是良性的撤药反应，恢复用药或减量慢一点就会缓解。

**最需要注意的一种情况**：撤药反应和复发同时发生。比如减量后出现失眠和焦虑，几周后情绪也开始往下走——这时候不能只当成撤药反应硬扛，要联系医生。

哪些药更容易出现撤药反应？一般来说，**半衰期短的药**（如帕罗西汀、文拉法辛）更明显；**半衰期长的药**（如氟西汀）相对轻；三环类、米氮平也有各自的撤药表现（米氮平常见失眠反弹）。这只是群体规律，个体差异很大。

**一个常见的错误判断**：把撤药反应当成“我果然不能停药，一停就犯”，于是彻底放弃停药的可能。实际上，多数撤药反应可以通过“减得更慢”来解决。

### 停药后前几个月怎么监测

停药不是终点，是另一个观察期的开始。复发风险在停药后的几个月内相对集中，所以这段时间反而要看得更紧【指南】。

- **前 1–2 个月**：每 1–2 周做一次简单自评（睡眠、情绪、兴趣、精力），每 2–4 周联系一次医生或复诊。
- **第 3–6 个月**：每月自评一次，每 1–2 个月复诊一次。
- **6 个月以后**：如果稳定，可以拉长到 2–3 个月，但至少每半年复盘一次。
- **任何时候**出现预警信号，不等预约，直接联系。

盯什么？按重要性排序：

1. **睡眠**：入睡时间、早醒、总时长。睡眠往往是最早变化的指标。
2. **兴趣**：对原本喜欢的事还有没有感觉。
3. **精力**：是不是又出现“做什么都要很大力气”。
4. **思维**：注意力、决策、自责频率。
5. **身体**：食欲、体重、疼痛、胃肠不适。

如果这几项里有两项连续两周变差，就该联系医生，而不是“再观察观察”。

## 怀孕、备孕时的调整必须提前讨论

这是最不能自作主张的一类情况。

很多人一发现怀孕就立刻把药停掉，觉得“为了孩子好”。但**停药本身也有风险**：孕期抑郁复发会影响睡眠、营养、产检配合，严重时危及母婴安全。而药物在孕期的风险，也和孕周、剂量、具体药物有关——这些必须由产科和精神科一起评估。

需要提前做的事：

- **计划怀孕前就开始讨论**，不要等怀上了再问。理想情况是提前几个月，让医生有时间调整方案。
- **不要自行停药或减量**。突然停药带来的撤药反应和情绪波动，对孕早期并不友好。
- **告诉医生你已经在吃的所有药**，包括保健品和中成药。
- **产后要格外留意**。产后是情绪问题的高发期，也是用药需要重新评估的节点。
- 具体原则见 [6.3 孕产期抑郁](<../模块6：特殊人群与特殊时期/6.3 孕产期抑郁.md>)。

哺乳期同理。很多药物在哺乳期是可以用的，但需要医生根据药物特性和婴儿情况判断，不能凭“吃药就不能喂奶”一刀切。

## 清单：停药前要问医生的七个问题

- [ ] 我现在满足停药的条件吗？如果不满足，还差什么？
- [ ] 我属于复发风险较高的那一类吗？依据是什么？
- [ ] 减量大概分几步、每步间隔多久？
- [ ] 出现哪些症状算撤药反应，哪些算复发？
- [ ] 如果减到一半就难受，是退回去还是继续？
- [ ] 停药后多久复诊一次？出现什么要提前来？
- [ ] 如果将来再次发作，之前的方案还能不能用？

把这七个问题的答案记下来。**“医生同意了”不等于“我听懂了”**，写下来才算数。

## 什么时候需要联系医生或去急诊

> **立即拨打 120 或去急诊：**
>
> - 出现自杀念头、计划或准备行为；
> - 停药后出现严重焦虑、极度激越、无法入睡，伴失控感；
> - 晕厥、抽搐、意识模糊；
> - 高热、肌肉僵硬、意识改变。

> **尽快联系开药医生（当天到数日内）：**
>
> - 减量后出现明显头晕、电击感、恶心，影响生活；
> - 停药后情绪持续下滑超过两周；
> - 失眠连续一周以上，且越来越重；
> - 出现复发预警信号（见 [9.1 复发预警信号清单](<../模块9：复发预防与危机干预/9.1 复发预警信号清单.md>)）；
> - 发现怀孕或计划怀孕；
> - 想加快减量进度。
