# 1.3 共同决策与治疗联盟

治疗抑郁，不是把处方单接过来照做就行。同样一套方案，有人执行得很好，有人两个月就放弃，差别常常不在药，而在“这个方案是不是我们一起定下来的”。这一页讲三件事：怎么和医生一起做决定、怎么把顾虑说出口、以及当你觉得“这个医生不适合我”时该怎么办。读完你可以带着一份自己的偏好清单进诊室，而不是空着手、点着头出来。

## 一、共同决策是什么

医患沟通大致有三种样子：

- **家长式**：医生定，你照做。好处是快，坏处是你不知道为什么，遇到副作用或生活变化时容易慌。
- **告知式**：医生把选项摊开，你自己选。听起来自由，但缺少专业判断的引导，患者常常更焦虑。
- **共同决策**：医生提供专业信息和证据，你说出自己的处境、价值和顾虑，双方一起定一个都认账的方案。【指南】

共同决策不是“患者说了算”，也不是“医生推卸责任”。它的前提是：医生懂病，你懂自己的生活。两边信息合起来，才可能做出一个既医学上合理、现实里又执行得下去的决定。

它还有一个实际好处：一起定下来的方案，执行率更高，复诊也更愿意去。【研究】

## 二、共同决策的六个步骤

这六步不必每次都走全，但心里有个顺序，谈话会顺很多。

**第一步：明确这次要决定什么。** 是“要不要开始吃药”，还是“现在这个药没效果，换还是加”，还是“要不要做心理治疗”。问题越具体，讨论越有效。

**第二步：请医生列出选项。** 包括“先观察一段时间”“先做心理治疗”“药物加心理治疗”“换一类药”。别忘了“什么都不做、只随访”也是一个选项，尤其对轻度抑郁。

**第三步：问每个选项的收益、风险和不确定性。** 比如：大概多久能看到变化？常见副作用是什么？如果无效，下一步是什么？这个方案有多少把握？证据强不强？

**第四步：说出你的价值和顾虑。** 你最怕的是什么？是发胖、是性功能受影响、是白天犯困没法开车、是怕被单位知道、是担心吃上就停不下来？这些不是“不配合”，是方案能不能落地的前提。

**第五步：讨论现实条件。** 费用、医保、请假、路程、复诊时间、家里有没有人帮忙、能不能固定每周同一时间做心理治疗。

**第六步：一起决定，并约定复评。** 明确“我们先按这个方案走，几周后回来看什么；如果出现什么情况，提前联系”。这一步最容易被跳过，但它决定了后面有没有退路。

| 步骤 | 你可以这样问 | 医生通常会怎么回应 |
|---|---|---|
| 明确问题 | “这次我们需要决定的是什么？” | 把问题收敛成一两个具体选择 |
| 列出选项 | “除了这个，还有别的选择吗？” | 补充心理治疗、观察随访等 |
| 比较利弊 | “这个方案大概多久能看出效果？常见副作用是什么？” | 给出时间框架和监测计划 |
| 说出顾虑 | “我最担心的是白天犯困，因为我要开车。” | 调整用药时间或换方案 |
| 谈现实条件 | “这个治疗每周要请半天假，我请不了。” | 换成周末门诊、线上随访或别的形式 |
| 约定复评 | “如果两周后更差了，我该怎么办？” | 给出提前复诊或急诊的指引 |

## 三、把偏好和顾虑说出口

很多人不是没有想法，是说不出来。怕耽误医生时间，怕被当成“不听话的病人”，怕说错。下面这些句式可以直接用：

- “我想先弄清楚……再决定。”
- “我最担心的是……，这个担心合理吗？”
- “我之前试过……，那次体验很不好。”
- “如果……，我可能坚持不下来。”
- “我查到的说法和您说的不太一样，能不能帮我分辨一下？”
- “我需要回去想一想，可以下次再定吗？”

如果当面说不出口，可以提前写在纸上或手机备忘录里，进诊室递给医生。也可以让陪同的家属帮忙补充。写下来不丢人，反而是效率最高的办法。

还要区分两件事：**“我不愿意”** 和 **“我担心”**。不愿意是价值选择，比如不想吃药；担心是信息不足，比如怕伤肝。对前者，医生需要尊重；对后者，医生可以解释。把两者混在一起，讨论就容易变成争执。

| 心里的话 | 可以怎么说 |
|---|---|
| “我不想吃药，怕上瘾。” | “我担心长期吃会依赖，这个担心有依据吗？” |
| “这药让我白天昏沉，没法工作。” | “我上午开会必须清醒，现在的困倦影响到工作了，有没有调整空间？” |
| “我没钱做心理治疗。” | “自费心理治疗我负担不起，有没有别的途径或更便宜的选项？” |
| “我不信任这个医生。” | “我有一些顾虑想说，可以占用两分钟吗？” |
| “我想停药。” | “我现在状态不错，想了解什么时候可以减量、怎么减。” |

**进诊室前，可以照着勾一遍：**

- [ ] 我最想解决的一个问题是什么
- [ ] 我最担心的副作用或后果是什么
- [ ] 我能接受的时间、费用和复诊频率大概是多少
- [ ] 我希望家属参与到什么程度（陪同、旁听、还是不参与）
- [ ] 我准备好的三个问题，按重要程度排好序

### 现实因素不是小事

诊室里最容易被忽略的，往往是决定治疗能不能坚持下去的那些事。

- **费用**：不同药物、不同心理治疗的自费比例差别很大。可以问“有没有医保内可选的”“门诊慢特病能不能报”。费用问题不丢人，说不出口才麻烦。
- **副作用与工作**：嗜睡、注意力下降、手抖、出汗，都会影响开车、操作机器、开会发言。这些要具体说，医生才能调整服药时间或换方案。
- **哺乳与备孕**：不是“吃药就一定不能喂奶”，也不是“喂奶就一定不能吃药”。这需要精神科和产科一起评估，把两边风险放在一起看。见 [6.3 孕产期抑郁](<../模块6：特殊人群与特殊时期/6.3 孕产期抑郁.md>)。
- **时间与路程**：心理治疗通常需要固定时段、连续多次。如果每次要跨城、要请假，方案本身就会崩。
- **隐私**：单位、学校、家人知道多少，是你的边界。可以问医生病历和诊断证明会怎么写、会给谁看。

这些因素不改变“医学上该怎么做”，但会改变“现实中能怎么做”。一个好的方案，是两者都能成立。

## 四、治疗联盟：三个零件

治疗联盟（therapeutic alliance）是心理治疗研究里的概念，后来被用到整个精神科治疗中。它大致由三部分组成：

1. **目标一致**：你和医生对“要治到什么程度”有共识。
2. **任务一致**：你认可这个方案里的任务，比如按时吃药、做记录、每周来一次。
3. **情感联结**：你觉得被听见、被尊重，而不是被审问、被评判。【研究】

三者缺一个，联盟就会松。比如目标一致但任务不接受，人就会表面答应、背后减药；任务接受但情感联结差，人就会越来越不想来。

**联盟破裂的信号**：每次复诊前都紧张、想请假；觉得医生总打断你；方案从来没被解释过；你开始瞒着漏服；迟到、失约变多；走出诊室觉得“说了也没用”。

**可以怎么办**：

- **先试一次当面说。** “我有个感受想说：上次我讲副作用的时候，我觉得没被听完。”很多误会一句话就能解开。
- **给一次机会，也给自己一个期限。** 比如“这次说清楚，如果还是这样，我就换”。
- **换医生不是背叛，也不是矫情。** 匹配度是治疗的一部分，换一个更合适的人，比硬撑着中断治疗好。
- **换的时候别断药。** 提前拿到处方、病历摘要和检查结果，向新医生说明既往用药、效果和副作用。突然停药的风险，比多跑一趟医院大得多。
- **如果暂时换不了**，可以先把需求写下来、请家属陪同、或先解决最急的一个问题，不必等到“关系完美”才开始治疗。

| 情况 | 可以怎么做 |
|---|---|
| 觉得医生不解释方案 | 直接问“能不能帮我讲讲为什么选这个” |
| 觉得被评判 | 说出感受，或换一位医生 |
| 想换医生但怕断药 | 先要到处方和病历摘要，再约新医生 |
| 医生很忙、每次几分钟 | 提前写纸条，把三个重点放在最前面 |
| 家属和医生意见冲突 | 让患者本人表态，家属补充信息而非代替决定 |

## 五、家属在其中的角色

家属能做的事，比想象中多，也比想象中需要分寸。

**能做的**：陪同就诊、帮忙记录、在患者说不清时补充观察（“他这两周每天凌晨三点就醒”）、提醒复诊和服药、观察危险信号、在患者犹豫时帮忙问出那个问题。

**需要分寸的**：不代替患者做决定（除非本人已无法表达意愿）、不隐瞒病情、不在诊室里替患者“认错”、不把治疗当成“管教”。患者对隐私的边界要尊重，哪些话可以对家人说，由患者决定。

**家属自己也需要支持。** 长期照护会耗尽一个人。家属可以有自己的咨询、自己的休息、自己的求助渠道。你倒下了，对谁都没有好处。

## 六、什么时候需要联系医生或去急诊

> **什么时候需要联系医生 / 去急诊**
>
> - 出现自杀念头、自伤行为，或开始安排后事、把东西送人：**不要独处**，立刻联系信任的人，呼叫 **120** 或去最近医院急诊；也可以拨打 **12356** 心理援助热线。
> - 因为对治疗不满而打算自行停药：先联系医生说明，不要突然停。突然停药可能出现撤药反应，也会增加复发风险。
> - 出现严重副作用（皮疹扩散、面唇肿胀、呼吸困难、高热、意识混乱、肌肉僵硬）：立即急诊。
> - 治疗关系严重破裂、无法继续，同时症状在加重：尽快联系医院转诊或换医生，不要空档期拖太久。

**常见问题**

**“换医生会不会得罪原来的医生？”** 一般不会。医生更在意你能否继续治疗。带上病历，说明原因，体面地转过去就好。

**“医生说必须吃药，我不同意，怎么办？”** 可以要求医生解释依据、说明替代方案和不治疗的后果。你也可以选择先做心理治疗，但要约定复评时间，并知道什么情况下需要回来。

**“家属该不该进诊室？”** 由患者决定。患者愿意就可以，家属可以补充观察、帮忙记；患者不愿意，也应尊重。

**“我什么都说不出来，是不是没救了？”** 说不出来很常见。写下来、让家属陪、先只说一件事，都是办法。治疗不要求你口才好。
