# 1.4 一页式治疗路径图

治疗抑郁像走一条有岔路的长路：先要看清起点，再决定走哪条道，中间要定期回头看有没有走偏，最后还要知道什么时候可以慢下来。这一页把整条路压缩成一张图、几张表，方便你贴在病历本上、存在手机里。它不能代替医生判断，但能让你在每次复诊时知道自己走到哪一步、下一步该问什么。如果只读一页，就读这一页。

## 一、总览：从初诊到维持

```
初诊：挂号、说明来意、带上既往资料
   │
   ▼
评估：症状 + 功能 + 风险 + 躯体情况 + 既往治疗
   │
   ├── 有红旗信号 ──► 急诊 / 住院 / 专科会诊
   ▼
诊断与分层：轻度 / 中度 / 重度（含风险等级）
   │
   ▼
共同决策：心理治疗 / 药物 / 两者联合 / 物理治疗
   │
   ▼
急性期治疗（数周至两三个月）
   │
   ▼
复评：有没有应答？副作用能不能耐受？风险有没有变化？
   │
   ├── 无应答 ──► 核对诊断与依从性 ──► 调整方案 ──► 再复评
   │
   ▼
缓解：症状基本消失
   │
   ▼
巩固期（数月，常以半年为参照）：固定疗效、恢复功能
   │
   ▼
维持期（通常一年以上，复发多者更久）：防复发
   │
   ▼
停药计划（与医生共同制定、缓慢减量）
   │
   ▼
停药后随访：识别早期预警信号
```

这张图里有两个地方最容易被跳过：**复评**和**停药计划**。前者决定治疗有没有效，后者决定会不会白治一场。

## 二、逐个节点：每一步在做什么

| 节点 | 要做什么 | 大致时间点 | 谁负责 |
|---|---|---|---|
| 初诊 | 说清最困扰的三件事、带齐既往资料和正在吃的药 | 首次就诊 | 患者 + 家属 |
| 评估 | 症状、功能、风险、躯体疾病、用药史、家族史 | 初诊及每次复诊 | 医生 |
| 分层 | 判断严重程度与风险等级，决定治疗场所 | 初诊后 | 医生，与患者讨论 |
| 决策 | 比较选项、说明利弊、结合现实条件 | 初诊或第二次就诊 | 医生 + 患者 |
| 急性期 | 规范治疗、监测副作用与风险 | 数周至两三个月 | 医生 + 患者 |
| 复评 | 判断应答、耐受性、安全性，决定继续或调整 | 治疗后数周、之后定期 | 医生 |
| 巩固期 | 维持原方案、恢复功能、处理残留症状 | 缓解后数月 | 医生 + 患者 |
| 维持期 | 继续治疗、监测预警信号、处理生活事件 | 通常一年以上 | 医生 + 患者 |
| 停药 | 评估时机、制定缓慢减量计划、约定随访 | 由医生判断 | 医生 + 患者 |
| 随访 | 观察复发信号、调整生活节奏 | 停药后数月到一年 | 患者 + 家属 + 医生 |

**初诊时最值得带来的东西**：正在吃的所有药（包括保健品、中药）、既往的处方和化验单、之前看过的诊断记录、一张写好的“三个最困扰我的问题”。很多人第一次进诊室会大脑空白，写下来说是最省力的办法。

**评估不只是问心情。** 医生还会问睡眠、食欲、体重、注意力、兴趣、自责、自杀念头，也会问有没有过异常兴奋的时期（排查双相）、有没有躯体疾病、有没有在吃其他药。这些不是八卦，是选方案的前提。

## 三、分岔口：不同情况走不同的路

| 情况 | 优先考虑 | 需要特别留意 |
|---|---|---|
| 轻度抑郁 | 心理治疗、行为激活、规律随访、睡眠与运动调整 | 不用药也要有复评节点，别“自己扛着” |
| 中度抑郁 | 药物或心理治疗，多数时候两者联合 | 定期评估应答，别在无效方案上停太久 |
| 重度抑郁 | 药物联合心理治疗，必要时 rTMS（经颅磁刺激）、MECT（无抽搐电休克），部分需住院 | 安全评估放在第一位 |
| 伴精神病性症状 | 抗精神病药联合抗抑郁药，常需住院 | 这类情况门诊很难处理，尽快专科 |
| 伴自杀风险 | 安全计划、密切随访、必要时住院 | 不要独处，不要隐瞒念头 |
| 怀疑双相 | 先明确诊断，慎用抗抑郁药单药 | 转躁的信号要提前告知 |
| 孕产期 | 精神科与产科共同评估 | 治疗与不治疗都有风险，需要一起权衡 |
| 老年 | 低起点、慢调整、查相互作用与低钠风险 | 跌倒、认知、多重用药 |
| 青少年 | 心理治疗为主，药物需密切监测 | 家庭与学校配合，关注自伤 |
| 治疗无效 | 核对诊断、剂量、疗程、依从性、共病 | 排除“假难治”再谈换药 |

这张表只给方向，不给处方。同一格里的人，具体方案也可能完全不同，因为年龄、体重、肝肾功能、合并用药、既往反应都不一样。

## 四、红旗信号：看到就动

红旗信号的意思是“不能等到下次复诊”。下面这些情况，按严重程度处理，宁可白跑一趟。

| 红旗信号 | 可能是什么 | 你要做什么 | 时间 |
|---|---|---|---|
| 自杀念头、计划、准备行为，或已经自伤 | 抑郁加重、风险升高 | 不要独处，移除危险物品，呼叫 120 或去急诊，拨 12356 | 立即 |
| 幻觉、妄想、坚信被害、行为紊乱 | 精神病性症状 | 尽快精神科就诊，必要时住院 | 当天 |
| 拒食、几乎不喝水、明显消瘦、站起就晕 | 脱水、营养不良 | 急诊，可能需要补液 | 立即 |
| 突然兴奋、话多、睡得少却不困、冲动花钱 | 转躁 | 尽快联系精神科医生，不要自行加药 | 24 小时内 |
| 高热、大汗、肌肉僵硬或抽动、意识混乱、心跳很快 | 血清素综合征（药物相关的严重反应） | 立即急诊，带上药盒 | 立即 |
| 皮疹迅速扩散、面唇肿胀、呼吸困难 | 严重过敏 | 呼叫 120 | 立即 |
| 黑便、呕血、明显皮下出血 | 出血 | 急诊 | 立即 |
| 抽搐、胸痛、晕厥、意识丧失 | 需排除躯体急症 | 呼叫 120 | 立即 |
| 产后两周内出现混乱、幻觉、极度兴奋或极度低落 | 产后精神病 | 立即急诊 | 立即 |

> **什么时候需要联系医生 / 去急诊**
>
> - 自杀念头、自伤行为、安排后事：不要独处，呼叫 **120** 或去最近医院急诊，也可拨打 **12356** 心理援助热线。
> - 拒食脱水、意识不清、抽搐、胸痛、晕厥、严重过敏：立即呼叫 **120**。
> - 转躁、幻觉妄想、副作用明显加重但意识清楚：当天或 24 小时内联系精神科医生。
> - 症状在几天内快速恶化、无法工作或照顾自己：尽快提前复诊，不要等预约日。

## 五、复诊节奏与自我监测

复诊不是“去拿药”，是整条路径的校准点。

**每次复诊，尽量说清四件事**：

1. 睡眠和食欲这两周怎么样；
2. 情绪最低的那天大概几分，持续了多久；
3. 药有没有漏、有没有副作用；
4. 有没有自杀念头，或者“活着没意思”的念头。

**每次复诊，尽量问清四件事**：

1. 现在这个方案的目标是什么，多久评估一次；
2. 如果没效果，下一步有哪些选择；
3. 出现什么副作用需要立刻联系、什么可以观察；
4. 下次复诊什么时候，中间出问题找谁。

**家里可以提前准备的东西**（照着勾）：

- [ ] 一份正在服用的药物清单（药名、剂量、每天几次）
- [ ] 一本记录睡眠和情绪的本子，或手机备忘录
- [ ] 一份安全计划：危机时打给谁、去哪里、把什么收起来
- [ ] 家属知道的“红旗信号”清单
- [ ] 主治医生/医院的联系方式，以及 12356 这个号码

## 六、常见问题

**“路径图上说数周复评，我两周没变化，是不是要换药？”** 不一定。早期先是副作用，疗效通常要更久。但如果一点改善都没有、副作用又难受，值得提前联系医生，而不是自己停。

**“我能不能跳过评估直接开药？”** 不建议。评估决定诊断和分层，跳过它，后面可能一直在治错的方向。

**“我一直在门诊看，需要去专科医院吗？”** 看情况。诊断明确、治疗顺利的门诊随访就够；出现红旗信号、治疗无效、需要物理治疗或复杂用药时，专科更有条件。

**“停药后还要复查吗？”** 要。停药后的一段时间是复发的高风险期，通常需要随访观察，具体频率听医生的。

**“这张图能当诊断依据吗？”** 不能。它是帮你理解流程和沟通的工具，诊断与处方只能由医生面诊决定。
