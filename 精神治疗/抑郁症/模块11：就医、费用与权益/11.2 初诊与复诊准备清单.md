# 11.2 初诊与复诊准备清单

> 精神科门诊的时间通常很短：初诊十几到二十分钟，复诊可能只有五分钟。同样的五分钟，有人能说清关键，有人出来才发现“忘了问”。这一页给你两份可打印的准备单：初诊带什么、怎么讲症状，复诊怎么用三句话讲完重点，以及一张可以照着问的问题清单。适合第一次就诊的人，也适合复诊多次却总觉得“没说清楚”的人。

## 初诊带什么

初诊的信息量最大，医生要在有限时间里拼出一张完整的图。你带得越全，误判越少。

**证件与手续**

- [ ] 身份证、医保卡（或电子医保凭证）、就诊卡。
- [ ] 既往在本院或其他医院的就诊卡、门诊病历本。
- [ ] 如果是复诊转院，带上转诊单或出院小结。

**病历与检查**

- [ ] 出院小结、门诊病历、既往化验单（甲状腺功能、血常规、生化、维生素等）。
- [ ] 心电图、脑电图、影像报告（有的话）。
- [ ] 做过的心理测评报告，注意看日期——两年前的量表说明不了现在。
- [ ] 既往心理治疗的记录（做了多久、什么流派、有没有效果）。

**用药**

- [ ] 正在吃的所有药，**带药盒**，不要只报药名。很多药名相近，剂量写法也不同。
- [ ] 吃过的药：药名、吃了多久、有没有效、有什么副作用、为什么停。
- [ ] 保健品、中药、助眠药、减肥药，也要说。它们会影响判断和相互作用。
- [ ] 过敏史：对什么药过敏、当时什么反应。

**自己准备的材料**

- [ ] 一张时间线（见下一节），手写或打印都行。
- [ ] 最近两周的睡眠记录：几点睡、几点醒、中间醒几次。
- [ ] 情绪或症状日记（如果有）。
- [ ] 想问的问题，按重要性排序，写在纸上。
- [ ] 一位了解你情况的家属或朋友，能补充你注意不到的变化。

## 怎么讲症状：一条时间线，四件必说的事

医生不是靠“我不舒服”来诊断的，而是靠**时间、变化、功能、风险**。把这四样讲清楚，比描述得多生动都有用。

| 医生想知道的 | 怎么讲 | 例子 |
|---|---|---|
| 时间线 | 第一次什么时候、之前有没有类似、这次从什么时候开始变 | “去年三月开始睡不着，去年九月明显加重，今年一月起请了长假。” |
| 变化 | 是持续变差、时好时坏、还是某件事之后突然变 | “过年回家后好了一周，回来又不行了。” |
| 功能影响 | 工作、学习、家务、人际具体受影响到什么程度 | “两个月没上班；能做饭但做完要躺一下午；不接电话。” |
| 风险 | 有没有自杀念头、计划、准备、既往尝试 | “想过，觉得活着没意思；没计划；三年前有过一次吞药。” |

关于**功能影响**，很多人只会说“还行”“不太好”。可以换成可数的事实：这周上了几天班、请了几天假、几天没出门、几天没洗澡、一天能看几页书、还联不联系朋友。医生判断严重程度，主要看这些，而不是看你哭没哭【临床经验】。

关于**自杀念头**，请务必主动说，不要等医生问。可以按四个层次讲：**想过（有没有）→ 想过什么（具体内容）→ 有没有计划（怎么做、在哪、什么时候）→ 有没有准备（攒药、查方法、写过东西）**。主动说不会让你被“抓走”，反而能让医生给出更合适的方案——指南本身就把“直接询问自杀念头”列为评估的常规步骤【指南】。多数医生听到这些，第一反应是帮你降低风险，而不是评判你。

**其他必说**：最近喝不喝酒、抽不抽烟；月经是否规律、是否备孕或怀孕；有没有躯体疾病（甲状腺、肝病、心脏病、癫痫、青光眼）；家族里有没有人得过精神疾病或自杀。这些直接影响选药。

### 一段可以照着说的话

不知道从哪开口，可以用这个结构，三十秒讲完：

> “医生，我这次主要是因为睡不好和什么都提不起劲来的。大概从去年十月开始，最早是凌晨三四点醒，后来白天也没力气，最近一个月连班都上不了。我之前没吃过抗抑郁药，只在社区开过安眠药，吃了两周就不敢吃了。最近两周想过‘不如算了’，但没有计划。我想知道这算不算抑郁，要不要吃药，吃了会不会影响工作。”

这段话包含了时间、症状、功能、既往治疗、风险、诉求，医生接得住。

## 复诊只有五分钟，讲什么

复诊不是“汇报近况”，而是**让医生做出下一步决定**。带上记录，用三句话开场：

1. **哪里变了**：“这两周睡眠从四小时到六小时，白天能出门一次了。”
2. **有没有问题**：“早上还是恶心，大概一小时后缓解；性功能有影响。”
3. **这次想问什么**：“能不能减量？如果要吃半年，中间能不能停几天？”

如果医生只有五分钟，这三句话能让他立刻抓到重点。剩下的时间留给他追问。

| 医生常问 | 提前准备什么 | 一句话回答 |
|---|---|---|
| 药还在吃吗？ | 数一下这周漏了几次 | “这周漏了一次，周三晚上忘了。” |
| 睡得怎么样？ | 看睡眠记录 | “平均六小时，早醒三次。” |
| 情绪怎么样？ | 用 0–10 打分，和自己的基线比 | “比上次好一点，6 分，之前是 4 分。” |
| 有没有不舒服？ | 记副作用出现的时间和持续时间 | “吃完两小时恶心，下午就好。” |
| 有没有想不开？ | 直接说，不回避 | “有过一次，很快就过去了，没计划。” |
| 有什么想问的？ | 纸条，按顺序 | 见下一节清单 |

一个实用习惯：**每次复诊后，用手机记一行**“日期、药名剂量、主要变化、下次复诊时间”。三个月后回看，趋势就出来了，比回忆可靠。

## 可以问医生的问题清单

不必一次问完，挑三到五个最要紧的。问题按主题分组，方便勾选。

**关于诊断**

- [ ] 我现在的诊断是什么？依据是什么？
- [ ] 需要排除哪些其他可能（甲状腺、双相、睡眠障碍、药物影响）？
- [ ] 这个诊断会不会随时间改变？什么情况下需要重新评估？

**关于治疗**

- [ ] 为什么选这个方案，而不是心理治疗/另一种药？
- [ ] 大概多久能见效？如果四周没变化，下一步是什么？
- [ ] 有没有需要我现在就做的检查？

**关于药物**

- [ ] 这个药叫什么、作用是什么、最常见的前三个副作用是什么？
- [ ] 副作用大概多久会减轻？出现什么必须停药并联系您？
- [ ] 漏服了怎么办？能和别的药、酒一起吃吗？
- [ ] 要吃多久？什么时候评估能不能减？
- [ ] 有没有疗效相近、价格更低的同类药？

**关于生活与风险**

- [ ] 我现在能上班/上学吗？需要开病假条吗？
- [ ] 能运动、能开车、能喝酒吗？
- [ ] 出现什么情况必须马上来，而不是等复诊？

**关于下次**

- [ ] 下次什么时候复诊？怎么加号？临时不舒服找谁？

如果医生对某个问题明显不耐烦，仍然值得问完最重要的两个：**“出现什么情况必须马上来”和“多久没效要换方案”**。这两个答案直接关系到安全。

> **什么时候需要联系医生 / 去急诊**
>
> **不要等到复诊，当天联系**：吃药后出现皮疹、高热、抽搐、意识模糊；情绪在几天内急剧恶化；自杀念头变强或出现计划；连续多日几乎不睡且兴奋话多；呕吐腹泻到无法进食。
>
> **立即去急诊或拨 120**：已经自伤或服药过量；有明确自杀计划并开始准备；出现幻觉、冲动伤人、木僵拒食。
>
> **不确定时**：拨 12356 心理援助热线；地方资源以当地卫健委公布为准。

## 六个容易踩的坑

1. **一次准备二十个问题。** 五分钟问不完，反而一个都记不住。挑三个最影响治疗的。
2. **隐瞒自杀念头或饮酒量。** 这两项被隐瞒，方案就容易偏离，风险反而更高。
3. **只讲情绪，不讲功能。** “我很痛苦”很难量化，“两个月没上班”医生一听就明白。
4. **复诊只说“还行”。** “还行”提供不了任何决策信息，至少说出睡眠、副作用、情绪分数三项。
5. **换医院不带病历。** 重复检查、重复试药，既花钱也耽误时间。
6. **家属抢答。** 家属的补充很有价值，但请让患者先说完；医生需要听到本人的表述。

最后提醒一句：准备清单不是为了“表现得像个好病人”，而是为了让有限的门诊时间用在刀刃上。**你不需要讲得专业，只需要讲得具体。**
