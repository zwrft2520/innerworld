# 11.1 如何选择医院与医生

> 第一次去看精神科，最难的一步往往不是开口，而是“去哪看、挂谁的号”。这一页把精神专科医院、综合医院精神科/心理科、社会心理咨询机构放在一起比较，讲清楚各自的资质、能做什么、不能做什么，以及第一次该挂什么号、远程医疗什么时候够用。读完你可以按自己的情况排出两三个备选，而不是在网上乱搜。

## 三类机构，先分清它们能做什么

同样是“看抑郁”，不同机构的法律权限和工作方式差别很大。分不清这一点，最容易出现两种浪费：在只能做咨询的地方等诊断，在只能开药的地方期待长谈。

| 机构类型 | 能做什么 | 不能做什么 | 适合谁 |
|---|---|---|---|
| 精神专科医院（含区县精神卫生中心） | 诊断、开药、住院、物理治疗（如 MECT、rTMS）、复杂评估、危机处置 | 挂号紧张、等待久；离家可能远 | 症状重、需要调药或住院、诊断不明确、共病复杂 |
| 综合医院精神科/心理科/心身医学科 | 诊断、开药、门诊心理治疗、会诊联络（躯体病共病） | 多数无精神科急诊或病房；心理治疗排期长 | 首次就诊、合并躯体疾病、孕产期、老年、行动不便 |
| 社会心理咨询机构 | 心理咨询与心理治疗（谈话为主）、部分团体课程 | 不能诊断、不能开药、不能开病假条、通常不能医保 | 轻中度、已确诊且稳定、关系与成长议题、复发预防 |

几个容易混淆的名字，先说明白：

- **“心理科”不等于“心理咨询”。** 很多综合医院的心理科（或临床心理科）由精神科医生坐诊，可以诊断开药；也有些医院的“心理咨询门诊”只做评估和谈话治疗，不能开药。挂号前看一眼科室介绍和出诊医生资质。
- **“心身医学科”通常也是精神科。** 名字不同，权限类似，擅长处理躯体症状与情绪相互影响的情况。
- **社会机构里的“心理医生”不是法定称谓。** 中国没有“心理医生”这个执业类别，只有精神科执业医师、心理治疗师、心理咨询师等不同身份。

## 资质怎么看

不需要成为资质专家，但要知道自己面对的是哪一类人。最简单的办法是看**执业证书上的执业范围**，而不是看头衔和宣传语。

| 身份 | 关键资质 | 能做什么 | 注意 |
|---|---|---|---|
| 精神科执业医师 | 医师资格证书 + 医师执业证书，执业范围为精神卫生专业 | 诊断、开药、开住院单、开病假条 | “主任医师”“副主任医师”是职称，不是资质本身；职称高不等于擅长你的问题 |
| 心理治疗师 | 卫生专业技术资格（心理治疗），多在医疗机构内执业 | 在医疗机构内开展心理治疗 | 不能开药；《精神卫生法》规定心理治疗活动应在医疗机构内开展 |
| 心理咨询师 | 2017 年国家职业资格统一鉴定已取消，现存证书多为培训或行业协会颁发 | 心理咨询 | 不能诊断、不能治疗精神障碍；看系统培训（如 CBT 长程项目）、督导时数、从业年限 |
| “健康管理师”“婚姻家庭咨询师”等 | 与精神卫生无直接执业关系 | — | 不能替代上述任何一类 |

两条底线值得记住：

1. **诊断和处方只能由精神科执业医师做出。** 咨询师说“你这是中度抑郁”，只能当作观察，不能当诊断。
2. **心理治疗和心理咨询不能处理需要医疗监护的情况。** 有自杀风险、精神病性症状、拒食、意识问题时，先去精神科。

## 第一次去，挂什么号

第一次就诊的目标通常不是“马上治好”，而是**把诊断和治疗方向定下来**。所以第一次优先挂“能诊断、能开药、能给方案”的号。

| 你的情况 | 建议挂 | 理由 |
|---|---|---|
| 第一次看，症状明显，影响工作学习 | 精神科普通门诊 | 普通号足够完成初诊评估，专家号留给疑难 |
| 有自伤、自杀计划、幻觉、木僵、拒食 | 精神科急诊（或综合医院急诊） | 需要当天处置，不能等预约 |
| 未成年人 | 儿童青少年精神科 | 评估方式、用药考虑、家庭参与都不同 |
| 孕产期 | 有孕产期经验的精神科，或会诊联络精神科 | 需要权衡用药与不治疗的风险 |
| 已确诊、稳定，只想做谈话治疗 | 心理治疗门诊，或医院内的心理治疗 | 药物由原医生继续管 |
| 以失眠为主，情绪问题较轻 | 睡眠医学门诊或精神科 | 先排除睡眠障碍与躯体原因 |
| 躯体病合并情绪问题 | 综合医院精神科/心身医学科 | 方便多科协作、减少奔波 |

挂号渠道以医院官方公众号、App、电话和现场自助机为准。**不要通过“代挂号”买号**，既有信息泄露风险，也可能遇到假号。

## 远程医疗：什么时候够用，什么时候不够

互联网医院和线上问诊这几年很普遍，它确实解决了一部分人的困难，但边界要清楚。

| 适合远程 | 不适合远程 |
|---|---|
| 已确诊、病情稳定者的复诊与调药 | 首次诊断、症状复杂、需要鉴别诊断 |
| 取药、看检查结果、问副作用 | 有自杀计划或近期自伤 |
| 稳定期的心理咨询（视频） | 需要体格检查、量表施测、心电图等 |
| 异地、行动不便、照顾孩子走不开 | 意识障碍、兴奋冲动、拒食、木僵 |
| 家属代问护理与沟通问题 | 需要开病假条、伤残鉴定、住院手续 |

用远程之前，问自己三个问题：**这个平台能不能查到医生的执业信息？出现紧急情况，我身边有没有人能立刻到场？我在的地方网络和隐私够不够？** 三个都过关，再考虑线上。

远程还有一个常被忽略的限制：**急救可及性**。线上问诊时如果情绪突然失控，医生无法派人到你身边。所以远程更适合“稳定期管理”，不适合“危机期兜底”。

## 怎么判断“这个医生适不适合我”

好医生不等于“说话好听”，也不等于“职称最高”。可以用下面这份清单在头两次就诊后自查，符合五条以上，通常可以继续；低于三条，可以考虑换一位。

- [ ] 他/她让我把话说完，没有在我讲到一半时打断或下结论。
- [ ] 他/她给出了明确的诊断或“目前还不能确定，需要观察”的说明，而不是含糊其辞。
- [ ] 治疗方案讲清了：吃什么、吃多久、可能有什么副作用、什么时候复诊。
- [ ] 我问的问题被正面回答了，包括“这个药会不会影响性功能”“能不能少吃一点”。
- [ ] 他/她问过自杀念头、睡眠、饮酒，而不只是问“心情好点没”。
- [ ] 复诊时间、加号方式、出现什么情况要提前来，都交代清楚了。
- [ ] 费用和疗程我能承受，不需要靠借钱维持。
- [ ] 我感到被当作一个人对待，而不是一个“病例”。

**可以考虑换医生的情况**：连续几个月方案没有任何调整也不解释；你提出疑问被嘲讽或威胁（“你不吃就等着住院”）；超范围执业（咨询师给你开药、推荐保健品）；频繁爽约、每次只给两分钟；涉及让你不舒服的边界行为。

换医生时不必“撕破脸”，可以说“我想再听一个意见”，并把既往病历、用药记录带全。**不建议频繁换**——治疗联盟本身就有作用，每换一次都要重新建立信任、重讲一遍病史。

> **什么时候需要联系医生 / 去急诊**
>
> **首次就诊前如果出现以下情况，不要等预约**：有自杀计划或准备行为、已经自伤、几乎不睡且兴奋话多、拒食拒水、出现幻觉或言行紊乱——直接去精神科急诊或综合医院急诊，必要时拨 120。
>
> **就诊后**：加药或换药后情绪急剧恶化、出现高热抽搐、皮疹迅速扩散，立即联系开药医生或去急诊。
>
> **不确定去哪看**：可拨 12356 心理援助热线询问转介方向；地方资源以当地卫健委公布为准。

## 五个容易踩的坑

1. **只看头衔和宣传。** “名医”“首席”不等于适合你；执业范围、沟通方式、可达性更重要。
2. **把心理咨询当成诊断。** 咨询师没有诊断权，如果你还没确诊，先去医院。
3. **一次挂好几个科，同时吃几套方案。** 药物相互作用是真实风险，所有医生都应该知道你正在吃什么。
4. **迷信“基因检测选药”。** 目前这类检测对多数人的用药选择帮助有限，不能替代医生的临床判断【待验证】。
5. **因为一次不愉快就认定“所有医生都一样”。** 换个机构、换个医生，体验常常差别很大。

选医院和选医生，本质上是选一段能持续几个月甚至几年的合作关系。**能稳定复诊、能把话说清楚、出事能找到人**，这三点比“最有名”实用得多。
