# 4.1 重复经颅磁刺激rTMS

这一页讲清楚 rTMS 是什么、哪些人适合、一次治疗和整个疗程是什么样、有哪些副作用和禁忌，以及为什么它和“电击”完全不是一回事。如果你吃药效果不理想，或因为副作用没法继续加量，正在考虑物理治疗，这一页可以帮你把问题问到点上。

## 一、rTMS 是什么：在头皮外“敲门”，不打开颅骨

rTMS 的英文全称是重复经颅磁刺激（repetitive transcranial magnetic stimulation）。做法是把一个线圈放在头皮上，通入快速变化的电流，线圈周围产生磁场；磁场穿过颅骨几乎不衰减，在大脑表层（医学上叫“皮层”）引起一小股电流，让那一小片区域的神经细胞变得更容易或更不容易兴奋。

可以把它想成“隔着门敲墙”：门（颅骨）没打开，墙（大脑）也没碰，但敲击的震动传进去了。治疗结束后，被“敲”过的区域，其兴奋性会在一定时间内保持在改变后的状态，这正是治疗想要的效果。

rTMS 和抑郁的关系，建立在一个相对稳定的观察上：抑郁的人，左侧前额叶（背外侧前额叶）的活动往往偏低，这个区域参与情绪调节、动机和“做决定”。所以常见做法是刺激左侧前额叶，试图把这块区域“叫醒”；也有刺激右侧或其他部位、采用不同模式的方案，由医生根据病情和中心条件决定。【研究】

需要强调：rTMS 不是“磁疗”。市面上磁石手环、磁疗床垫那类产品，磁场强度极低，穿透不了颅骨，也没有可靠证据能治疗抑郁。名字里都有“磁”，但完全不是同一件事。【指南】

**为什么它不是“电击”。** 很多人一听“刺激大脑”，立刻想到电影里被绑在床上、全身抽搐的场面。那是旧式电休克留下的印象。两者的区别可以看这张表：

| 对比项 | rTMS | 无抽搐电休克（MECT） |
|---|---|---|
| 是否麻醉 | 不需要，人是清醒的 | 需要全身麻醉和肌松 |
| 是否通电 | 线圈产生磁场，不向头皮送电 | 短暂电流诱发一次受控发作 |
| 是否引起抽搐 | 不引起，癫痫是需避免的并发症 | 治疗目的就是诱发发作 |
| 对记忆的影响 | 一般不明显 | 可能出现记忆减退，需重点评估 |
| 治疗后的状态 | 休息后即可离开 | 需复苏观察，当天不宜独处 |

简单说：rTMS 是“用磁场在门外敲”，MECT 是“在麻醉下按一次重启键”。两者各有适应证和风险，不能互相替代。关于 MECT，可以看[4.2 无抽搐电休克MECT](<4.2 无抽搐电休克MECT.md>)。

## 二、谁适合，谁暂时不适合

多部指南把 rTMS 列为抗抑郁药效果不理想时可以考虑的治疗之一，通常在精神专科医院或专门的治疗中心、由受过训练的团队实施。【指南】它不是“所有人都该先做”的首选，也不是“最后没办法了才试”的兜底。

比较适合考虑的情况：诊断明确的中度到重度抑郁，已经用过至少一种（临床上常见是两种）抗抑郁药，足量、足疗程，效果仍不理想；因为恶心、性功能受影响、体重增加、出汗等副作用，没法耐受足够剂量的人——rTMS 不经过肝肾代谢，不与其他药物发生代谢层面的相互作用，这对同时吃很多药的人有意义【临床经验】；孕期、哺乳期希望“尽量少用药”的人，但孕期做 rTMS 的研究并不多，必须由产科和精神科一起评估【待验证】；老年人，需额外评估听力、脑血管状况和是否长期卧床【临床经验】。

还有一个很实际的条件：**能配合**。每次几十分钟要坐着或半躺着，头部保持相对不动，能听懂指令、能戴耳塞、能坚持每周多次、连续数周。严重激动、谵妄、无法静坐、理解配合困难的人，做起来会很困难，效果也难以保证。

需要谨慎、或通常不建议做的情况：头部或颈部有金属植入物（动脉瘤夹、脑深部刺激器电极、人工耳蜗、某些颅内支架、金属碎片残留），这类金属可能在磁场中发热或移位；心脏起搏器、植入式除颤器、胰岛素泵等电子植入设备，属于相对禁忌，需要心脏科和设备厂商信息共同确认；有癫痫病史或家族史，或正在用会降低癫痫阈值的药物（部分抗精神病药、某些抗生素、茶碱等），或近期大量饮酒、严重缺觉；颅内压增高、脑肿瘤、近期脑卒中或严重头部外伤；严重听力障碍或对噪音特别敏感；处于急性谵妄、严重兴奋状态。

| 你的情况 | 通常怎么处理 |
|---|---|
| 头部有金属夹、人工耳蜗、脑深部电极 | 一般不做，除非专科评估确认设备兼容 |
| 心脏起搏器 | 相对禁忌，需心脏科与设备信息确认 |
| 有癫痫史，但目前控制稳定 | 可能可以做，需调整方案并加强观察 |
| 牙龈有金属补牙材料、腿上有钢板 | 多数不影响，但仍要如实告知 |
| 怀孕 | 需产科与精神科共同评估，线圈远离腹部 |

绝对禁忌和相对禁忌的界线，必须由医生画，不是由患者自己对照网上的清单画。你要做的是“如实交代”：体内有什么植入物、以前有没有抽搐、最近在吃什么药和保健品、睡眠和饮酒情况。隐瞒这些，是把风险留给自己。

## 三、一次治疗是什么样：流程与疗程

第一次去，通常先做评估，不是直接上机：确认诊断、回顾既往用过的药和疗程、筛查禁忌（金属植入物、癫痫史、心脏设备、听力）、必要时做头部影像或听力检查、测量血压。有的中心还会用问卷评估抑郁严重程度，作为治疗前后的对照。

接着是定位。医生要确定线圈放在头皮的哪个位置。简单的方法是根据头部测量定位，精确的方法是用你自己的磁共振影像做导航。定位准不准，直接影响效果，这也是“在正规中心做”和“随便找地方做”的差别之一。然后可能做一次“运动阈值”测定：用单次磁刺激找到能让拇指轻微抽动的最小强度，用来个体化设定治疗强度。这个过程有点奇怪，但不疼。

正式治疗时，你坐在治疗椅上或半躺着，戴上耳塞，线圈贴着头皮。机器启动后你会听到连续的“哒哒”声，同时感觉头皮被轻轻敲击，有时面部或下颌的肌肉会跟着抽动。整个过程人是清醒的，不需要麻醉、不需要禁食，做完休息一会儿就能自己回家。

疗程通常是每个工作日做一次，持续四到六周，总共二十到三十次。【指南】有些中心采用单次时间更短的模式（比如间歇性 θ 爆发刺激，iTBS），对上班上学的人更友好，但不是每个中心都有。【研究】

起效时间因人而异。有人两三周开始感觉变化，也有人要做完整个疗程才能判断。所以医生通常会在疗程中途和结束时各评估一次，而不是做三五次没感觉就停。如果有效，后面往往还需要维持治疗——把频率逐渐拉长，或按需再做一段时间，否则效果可能在几个月内减退。【临床经验】

## 四、副作用、禁忌与效果预期

rTMS 的副作用整体上是物理治疗里比较轻的，但“轻”不等于“没有”。最常见的是头痛和头皮不适：头痛多在治疗当天出现，几小时内缓解，性质像紧张性头痛；头皮可能有刺痛、发麻、紧箍感或轻微红肿。面部、下颌、眼周的肌肉抽动也很常见，是刺激波及浅表肌肉，不代表“伤到神经”。

治疗时的响声是实打实的。不戴耳塞，长期下来可能影响听力，所以耳塞不是可选项。少数人会短暂觉得耳朵闷、耳鸣加重，出现这种情况要告诉治疗团队。

比较少见但需要认真对待的是癫痫发作。它的发生率很低，但不是零。风险在有癫痫史、脑损伤、颅内病变、同时使用某些药物、酒精戒断、严重缺觉的人身上更高。正规治疗室会配备急救设备和受过训练的人员，这也是 rTMS 不该在美容院、健身房、家里做的原因。

| 反应 | 多常见 | 怎么办 |
|---|---|---|
| 头痛、头皮发麻、紧箍感 | 很常见 | 多可自行缓解，必要时问医生能否用止痛药 |
| 面部或下颌肌肉抽动 | 常见 | 属刺激波及肌肉，告诉治疗师调整位置 |
| 耳鸣、耳朵闷 | 少见 | 检查耳塞是否戴好，持续不缓解要评估听力 |
| 癫痫发作 | 罕见 | 立即停止治疗、急救、呼叫 120 |

关于效果，研究里 rTMS 确实能让一部分人明显改善，也有一部分人改善有限，还有人对完全缓解没有反应。【研究】研究之间的差异很大，和人群、方案、疗程长短、是否继续原药物都有关系。所以任何“百分之多少有效”的说法，都要打个折扣听。

可以期待的是：如果有效，通常在疗程中后段开始出现，表现为睡眠、兴趣、精力、思维速度中的某一项先松动，而不是“突然开心”；效果通常在疗程结束后维持一段时间，但可能逐渐减退；副作用多数可耐受，不影响日常生活。

不该期待的是：做完立刻好、一次见效；做完就一辈子不复发（rTMS 不改变复发的底层风险，后续维持治疗、心理治疗、生活调整仍然重要）；可以替代药物（多数情况下 rTMS 是在原有药物基础上叠加）；一定比药“高级”（它对有些人有效、对有些人无效，和药物一样是概率问题）。

还有两个现实问题值得提前想清楚：一是费用，rTMS 在不少地区需要自费或部分自费，一个疗程总花费不低；二是时间，每周多次、连续数周，对上班、上学、带孩子的人都是不小的负担。这两点不解决，疗程很容易做到一半就断掉，而中断本身会影响判断效果。

## 五、决定之前问清楚，出现什么要就医

- [ ] 我的诊断是否明确？有没有排除双相、甲状腺问题、睡眠呼吸暂停？
- [ ] 我之前用过的药，剂量和疗程够不够？有没有可能是“假难治”？
- [ ] 这个中心做 rTMS 的医生和治疗师是什么资质？一年做多少例？
- [ ] 用的是什么设备、什么刺激模式？为什么给我选这个？
- [ ] 总共要做多少次、持续几周？中途怎么评估有效没效？
- [ ] 全部费用多少？医保或商业保险能不能报？
- [ ] 如果有效，维持治疗怎么安排？如果无效，下一步是什么？
- [ ] 我体内的植入物、癫痫史、正在吃的药，需不需要先调整？
- [ ] 治疗期间我要观察什么？出现什么情况必须马上联系？

> **立即呼叫 120 或去急诊**：治疗中或治疗后出现抽搐、意识丧失、口吐白沫、双眼上翻、大小便失禁；剧烈头痛伴反复呕吐；视物模糊或重影；一侧肢体无力或麻木、说话含糊、嘴角歪斜；胸痛、心悸伴晕厥。
>
> **当天联系治疗团队或精神科医生**：治疗部位皮肤红肿、起疱、破溃；持续耳鸣或听力下降；头痛越来越重、止痛药无效；情绪明显恶化，出现自伤或自杀念头（此时不要独处，让家人陪着，必要时拨 120 或 12356）；治疗后极度疲倦、意识模糊。
>
> 如果拿不准算不算严重，按严重处理。宁可多跑一趟，不要赌。

**“做完能自己开车回家吗？”** 大多数人可以。第一次治疗、或出现头晕疲劳时，建议有人陪同，当天不要安排需要高度集中注意力的工作。

**“会不会改变性格？”** 没有可靠证据支持 rTMS 会改变性格。治疗期间可能出现短暂的情绪波动、易激惹或疲倦，通常随疗程减轻；持续加重要报告。

**“能不能只做 rTMS，把药停了？”** 不建议自己停。rTMS 多数是叠加治疗，突然停抗抑郁药会带来撤药反应和复发风险。是否减药、什么时候减，由医生决定。

**“做一次没效果，是不是就没希望了？”** 一次治疗本来就不是用来判断疗效的。要看完整疗程，通常还要看疗程结束后几周的状态。即使 rTMS 无效，也不代表 MECT、氯胺酮、换药、心理治疗都无效。

容易踩的坑：把 rTMS 当保健品，症状一好就频繁加做；在非医疗机构、由没有资质的人操作；隐瞒金属植入物、癫痫史、正在吃的药，觉得“说了就不让做了”；疗程做到一半因为“没感觉”自行中断；只做 rTMS，不处理睡眠、饮酒、心理社会问题，效果被这些因素抵消。
